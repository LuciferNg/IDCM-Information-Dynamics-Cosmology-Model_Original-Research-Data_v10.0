## 〇、一句話

R2/R3 只係**掃描證明**唯一性（1e-45 內冇其他命中）。本輪用 **Niven 定理**將唯一性升級為**閉式定理**：
對任何半整數 j 同任何晶格大小 N，等式 4sin²(πn/N) = j(j+1)（n 整數，1≤n≤N/2）**只有 j=1、n=N/4（4|N）** 先成立。
⟹ **「j(n) 可擴展配對」被定理排除**：IDCM 44 模同 LQG 半整數自旋之間**唔可能存在完整映射** —— L1 最多只可係單點對應。

## 一、證明骨架（Niven）

```
γ_n = 4 sin²(πn/N) = 2(1 − cos(2πn/N))        u = 2πn/N = 有理倍π
等式 γ_n = j(j+1)（有理）⇒ cos(u) = 1 − j(j+1)/2 係有理數

Niven 定理：若 u/π 有理且 cos(u) 有理 ⟹ cos(u) ∈ {0, ±½, ±1}
⟹ j(j+1) ∈ {0, 1, 2, 3}
    半整數 j 解：只有 j=0（平凡 j(j+1)=0）同 j=1（j(j+1)=2）
    j=1 ⟹ cos(u)=0 ⟹ u=π/2 ⟹ n = N/4（需 4|N）
```
