## ★★★ 核心機制: N_gen = B − 1

### 推導

```
K_Chain/K_Tree 結構關係:
  K_Tree = N_d − L₅     (K_Tree = K_Chain minus one mode group)
  L₅    = N_d/B          (K_Chain modes split into B groups)

N_gen = K_Tree / L₅
      = (N_d − L₅) / L₅
      = N_d/L₅ − 1
      = B − 1
```
