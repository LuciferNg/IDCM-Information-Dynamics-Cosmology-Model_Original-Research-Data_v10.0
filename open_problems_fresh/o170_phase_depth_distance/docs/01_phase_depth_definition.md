## 1. 問題

ΛCDM 嘅徑向觀測量 D_H(z) = c/H(z) 係由 FRW 度規定義 (**膨脹** + 尺度因子)。
IDCM 冇膨脹: z 係**相位深度** (level ℓ = log₄(1+z) 嘅級聯), 唔係運動學紅移。
⟹ 「徑向距離」必須由**晶格結構 + 觀測者取樣**定義, 唔可以搬 FRW 公式。

## 2. 定義 (本 O 提出)

**相位深度**: ℓ ≡ log₄(1+z)。 一個 level = 1+z 乘 4 = 4 個 cell 嘅 coarse-graining。

**IDCM 本徵徑向距離**:

    D_H(ℓ) ≡ R_world · (dℓ/dz) · M(ℓ),        dℓ/dz = 4^{−ℓ}/ln4
    ⟺  D_H(ℓ) = R_world · 4^{−ℓ} · M(ℓ) / ln4

其中:
- **R_world = c/H₀^local = 4129.94 Mpc** — 世界半徑 (= 哈勃半徑, O167 定義; H₀ = 72.59 km/s/Mpc,
  同 SH0ES 73.0 ± 1.0 差 −0.41σ ✓)。R_world 係**唯一嘅長度輸入**。
- **M(ℓ)** — **徑向取樣核 / 徑向載波阻抗** (無量綱):
  每單位相位深度嘅徑向步長 (以 R_world 為單位)。
  結構上 M = 1/v_g = sec θ_c (載波模嘅群速度倒數, O167 scripts/12 語言)。

**橫向對照** (O169/O167): D_M(ℓ) = R_world·(1−4^{−ℓ})·E(ℓ),  E = 1+2φ⁻¹ℓ+δ。
兩者共用同一個 fiducial r_d = 147.088 Mpc ✓ (橫向 2.6% RMS, 徑向見 docs/02)。

## 3. 觀測者嵌入 (為何 M 係「取樣核」)

O159 嘅 half-site 結構: 觀測者嵌喺晶格嘅**半位點** (偏移 ±½, ΔE₀ = sin(π/12))。
⟹ 徑向取樣唔係連續積分, 而係**離散模取樣**: 邊啲載波模 (n ∈ 1..44, v_g = cos(πn/88))
   喺 depth ℓ 仲「睇得到」。
⟹ M(ℓ) 由**當時存活嘅載波模**決定; 模被 coarse-grain 掉就會**跳級** (ladder) — 見 docs/02 §3。

## 4. 唔係咩 (避免污染)

- ❌ 唔係 D_H = c/H(z) 嘅重寫: IDCM 冇 H(z) 呢個對象。
- ❌ 唔係 D_M 嘅導數 (FRW 身份 D_H = dD_M/dz) — 呢個身份喺 IDCM **唔係必需**;
     佢係一個**一致性測試**, 結果係一個 fork (見 docs/03)。
- ❌ 唔係 fit: M(ℓ) 由 IDCM 原子常數生成 (φ, 88/44, N_gen=3, B=4, F₅=5, ln4), 零自由參數。

## 5. 用法 (example)

```python
import mpmath as mp
R = mp.mpf("4129.94"); rd = mp.mpf("147.088")
ell  = lambda z: mp.log(1+z, 4)
# ★ 現行核 (arch, docs/06): n_c = N_d/2 + B·sin(πℓ) (ℓ<ℓ_t) | N_d/2
M    = lambda e: mp.sec(mp.pi*(22 + 4*mp.sin(mp.pi*e))/88) if e < mp.log(3,4) else mp.sqrt(2)
D_H  = lambda z: R * 4**(-ell(z)) * M(ell(z)) / mp.log(4)   # Mpc
print(D_H(0.510)/rd)   # → 21.584  (DESI LRG1: 21.863 ± 0.425)  [4^{-ℓ} = 1/(1+z)]
```
