### 2.2 🔴 真確錯誤: 徑向延伸積分法 (已修正)

核喺 ℓ_t 有跳躍 (arch 1.55464 → 1.41421), 舊 scripts/12 用單一梯形積分跨跳躍:

| 量 | 舊 (梯形 n=4000) | **正確 (分段精確)** |
|:--|--:|--:|
| ∫₀^ℓ_t M dℓ (淺區) | 1.260293 | **1.2603071** |
| 深區 √2(ℓ_nyq−ℓ_t) | 1.827845 | 1.8278445 |
| 合計 | 3.088161 | **3.0881516** |
| vs πR | −1.70% | **−1.7011%** |
| step 核合計 | 3.119657 | **3.1196434** (−0.6987%) |

**根因 (兩個獨立誤差)**:
1. 梯形法跨跳躍只餘 O(h) 精度 → 必須分段 (深區用精確 √2·Δℓ)。
2. 淺區**唔可以用有鎖定分支嘅 `M_arch`** — 最後一格節點 (e = ℓ_t) 會取到鎖定值 √2
   而唔係左極限 1.55464 → 誤差 = h·Δ/2 ≈ 1.4e-5 (n=4000)。
   驗證: 用連續公式 + n=20000 → 1.2603071, 同 mpmath quad 一致到 1e-12。

scripts/12 已改為分段 + 連續淺區公式 (n=20000), 重跑 exit 0, 值 = 3.088152 ✓

### 2.3 ⚠️ 本審計腳本自身 bug (已修)

首輪 scripts/14 有兩處 bug, 導致 9 項 FAIL:
- **σ 單位錯**: χ²(D_H) 用 M 空間殘餘, 但除以 raw D_H/r_d 誤差 → 少乘轉換因子 0.04938(1+z)。
  修: 加 `sM_of(sdh, z) = sdh·RD·(1+z)·ln4/R_world` (同 Mobs 同一因子)。χ²(D_H) 由 0.041 → 3.4712 ✓
- **J 段公式錯**: `((X − Mobs)/sdh) ** 2` 寫成除法加平方而非平方殘餘 → 得負 χ² (−0.195)。
  修: 顯式 `chi2_param(A,W,ℓ_t)`。修後結構值 χ² = 3.4712, Δ = 1.7563 ✓

**教訓**: 審計腳本自己都要被驗 — 首輪 9 個 FAIL 全部係審計腳本 bug, 唔係結論 bug;
反過來, 首輪 J 段「PASS」係假 PASS (公式錯但期望值鬆) — 呢個係更危險嘅失敗模式。
