## 1. 問題 (docs/04 §3 O1)

徑向律 `D_H(ℓ) = R_world·(dℓ/dz)·M(ℓ)` 嘅阻抗 `M(ℓ) = sec(π·n_c(ℓ)/88) = 1/v_g(n_c)`。
**n_c(ℓ) 係咩?** 舊版 (docs/02) 用兩區 step: n_c = 25.5 (黃金模 half-site 量化) | 22。
問題: (i) 25.5 係「反推後貼身份」, 唔係推導; (ii) step 模型 M(0) = 1.63007 ⟹ **H₀ = 61.73**
(被 SH0ES 73.0 ± 1.0 **排除 11.27σ**); (iii) z ≈ 0.934 bin 殘餘 +2.95σ 無解。

## 2. ★ 結構核 (零參數)

```
M(ℓ) = sec(π·n_c(ℓ)/88),   n_c(ℓ) = N_d/2 + B·sin(πℓ)     ℓ < ℓ_t = log₄N_gen = 0.792481
                           n_c(ℓ) = N_d/2                   ℓ ≥ ℓ_t
```

| 量 | 結構身份 | 值 |
|:--|:--|:--|
| N_d/2 | 88-site 鏈 Z₂ 自對偶中心模 (γ₂₂ = 2 = μ², v_g = 1/√2) | 22 |
| B | K_tree 分支數 = 4 | 4 |
| sin(πℓ) | 相位深度調制, **arch 寬度 = 1 個 cascade level** (1+z: 1 → B = 4) | — |
| ℓ_t | log₄N_gen (1+z = N_gen = 3) | 0.792481 |
| M(0) | sec(π·22/88) = sec(π/4) = **√2** | 1.414214 |
| M(1/2) | sec(π·26/88) (n_c = N_d/2 + B = 26) | **1.668676** |
| M(ℓ ≥ ℓ_t) | sec(π/4) = **√2** | 1.414214 |

**物理讀法**: 徑向載波係 **Z₂ 自對偶中心模 (n = N_d/2)**, 喺觀察者扇區 (ℓ < log₄N_gen) 以
**樹分支數 B 為振幅**、**一個 cascade level 為 arch 寬度** 繞自對偶點振盪; 進入世界扇區
(ℓ > log₄N_gen) 就**鎖死**喺自對偶點。峰值喺 ℓ = 1/2 (1+z = 2)。
