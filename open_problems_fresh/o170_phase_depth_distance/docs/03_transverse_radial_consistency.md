## 3. 讀數

**(a) 統一相位深度律 (L3/L4) 對 BAO 明顯更好**: joint 13.30–17.63 vs L1 27.85 (Δχ² = 14.6, 零額外參數)。
   即係: 若要求橫向/徑向係同一結構, 「D = R_world∫sec(πn_c/88)dℓ」係最佳描述 ✓

**(b) 但統一律嘅 z→0 斜率 ⟹ H₀ = 61.7–62.2**, 同 SH0ES 73.0 差 ~11σ ✗

**(c) 關鍵約束 (新)**: 局部 H₀ 由 SNe 斜率量度 ⟹ **D_H(0) = c/H₀ = R_world ⟹ M(ℓ→0) = ln4 = 1.386294**。
   即係: **淺區平台 M ≈ 1.63 唔可以延伸到 ℓ = 0** — M 必須由 ln4 (ℓ=0) 升到 1.63 (ℓ ≳ 0.15)。
   BAO 最低點係 BGS ℓ = 0.1865, **睇唔到呢個上升** ✓; SNe (z ≲ 0.15) 就睇得到。

**(d) 若加入低 ℓ 上升** (M: ln4 → 1.63, 例如 M = ln4 + (M_sh−ln4)(1−4^{−10ℓ})):
   H₀ → c/R_world = 72.59 ✓✓ 同 SH0ES 一致; BAO 部分 (ℓ ≥ 0.19) 幾乎不變 ⟹ L4 嘅 χ² 保持 ~13 ✓
   ⟹ **fork 可能消失** — 但呢個上升係**未測**嘅 (🔴), 預言: SN Hubble diagram 喺 z ≈ 0.05–0.15 有輕微曲率。
