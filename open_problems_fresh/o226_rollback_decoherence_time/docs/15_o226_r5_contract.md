## §2 預註冊

### 2.1 結構
- **Pv-1【盲】**：`H = Stab(v₀)` 之階 = 10，其作用於 31 軸之**有效階 = 5**（中心 `{±1}` 作用平凡）；
  軌道分解 = **V：`1 + 5`；F：`5 + 5`；E：`5 + 5 + 5`**（合 31）。
- **Pv-2【盲】**：軌道因數式之**每軌道落月牙軸數**（近對／遠對）：
  - 近：V 軌道 `1 → 1`、`5 → 3`（合 4）；F `5 + 5 → 3 + 3`（合 6）；E `5+5+5 → 1 + 2 + 2`（合 5）
  - 遠：V `1 → 0`、`5 → 2`（合 2）；F `5 + 5 → 2 + 2`（合 4）；E `5+5+5 → 1 + 0 + 0`（合 1）
  （I32：若個別軌道數與預註冊不同，原樣記 FAIL ＋ `-c`。）
- **Pv-3【導出（見數前）】**：**值盲定理** —— 凍結 `run_pass` 之讀取路徑只比較 **context 索引**（`L[-1][0] == ctx`）並以 `MUL[s][hx[ctx]]` 推進狀態，**從不查閱 `K` 之數值** ⟹ 任意改變核值（同尺寸 ±1 矩陣）帳本不變。
- **Pv-4【已知】**：等變慣例下類數 12、類分割相同（R4 U5）。

### 2.2 慣例
- **Pv-5【盲】**：上游 F3 之保真關係**只**在凍結慣例下成立（等變慣例下 `x_a`／`x_b` 改變 ⟹ 關係破裂）
  ⟹ 慣例非「口味選擇」，而係**被上游凍結數據釘死**。
- **Pv-6【盲】**：影響矩陣之分類 —— **慣例不變**：J1／J2 之預算與時間閉式（純算術）、類數與類分割（R4 U5）、一趟帳本（Pv-3）；
  **慣例相對**：陳舊度值集（R3／R4）、配對輸出 `x`、保真關係（Pv-5）、以及一切由 `x` 導出之量。
- **Pv-7【盲】**：若 Pv-5 成立，則 R3／R4 之「🟡 協定建議」**無需再提**（慣例已被數據固定）；
  若 Pv-5 不成立（兩慣例皆保真），則 🟡 保持為「自由但度量不同」之選擇。
