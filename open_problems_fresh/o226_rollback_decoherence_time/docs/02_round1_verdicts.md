## §3 J2 — 預算守恆定理（`scripts/04`，8/10 ＋ 2 修正）

### 3.1 閉式與充要條件（🟢）
- **閉式**：`m* = ⌊(B − θ)/c⌋ + 1`、`Σ = m*·c`；終止 = 每次讀前檢查 `B_rem < θ`（per-read）。
- **充要條件**：**恰好耗盡（`Σ = B`）⟺ `c | B`**。於 `B = 88θ`、`c = kθ` 家族下 ⟺ `k | 88`；k = 1..88 全掃**零反例**；推廣至 120 × 40 = 4800 格（`B = jθ`、`c = kθ`）**零反例**。
- **主案**：`k = 2` ⟹ `m* = 44`、`Σ = 44 × 123/88 = 123/2 = B` **EXACT**。
- 可行前綴（凍結字典序，全 120 初始態**同一**）：15 個完成對、**44 次計費讀**、終止對 `(0,15)`、`B_rem = 0` EXACT、（對內 15 pops）。
- `k = 1`（`c = θ`）**亦**恰好耗盡：`m* = 88`、`Σ = 88θ = 123/2 = B` ⟹ 成本律無法僅由「耗盡」定出 ⟹ 與 J1 Pr-1.3 同一結論（**零判別力必須明寫**）。

### 3.2 讀寫律與 hits 閉式
- **Pr-2.1（全量重現，非引用 F4）**：一次 pass 對 120 初始態**皆同一**：讀操作 `3N² = 11532`、hits `2N = 124`、misses `3N² − 2N = 11408`、pops `N² = 3844`；帳本深度 ≤ 3（1 carry ＋ 2 push）。
- **Pr-2.2（閉式）**：`hits(order) = N + C(order)`，`C = #{k ≥ 1 : b_{k−1} = a_k}`（carry 命中）；`C(字典序) = 62`、`C(反序) = 62`。
- **★Pr-2.2 之預註冊方向被否證（保留 FAIL）**：預期「隨機次序 `C ≪ N`」；實測 10⁴ 個隨機次序之 hits 分布 = **min 96 / 中位 124 / max 152**，均值 **123.910**，理論 `E[C] = (N²−1)/N = 61.984` ⟹ **`hits = 2N` 係任何次序之典型值**，唔係凍結次序之產物 ⟹ **`124 = 2N` 這個數字本身無訊息量**（`q_obs ≈ 50%`，見 §6）；內容在閉式 `N + C`，唔在 `2N`。

### 3.3 樣本外盲測（見數前寫死值）
| 盲測 | 預言（見數前） | 實測 | 結果 |
|:--|:--|:--|:--:|
| `B′ = 123`（2 tick） | `m* = 88`、`Σ = 123` | 88 讀、`Σ = 123` | ✅ |
| `B″ = 123/4` | `m* = 22`、`Σ = 123/4` | 22 讀、`Σ = 123/4` | ✅ |
| `c‴ = 3θ`（同 B） | `m* = 30`、`Σ = 11070/176 > B` | 30 讀、`Σ = 5535/88` | ✅（**比較器瑕疵**：`11070/176 ≡ 5535/88`，原樣保留 FAIL ＋ 立 Q6-c） |
- **θ 整數核算（`scripts/07` A6/A7，獨立）**：`B = 88θ`、`c = 2θ`、`θ = 1` ⟹ `m* = 44`、`Σ = 88θ` 恰好；`176θ → 88`；`44θ → 22`；`(88θ, 3θ) → 30`、`Σ = 90θ > 88θ`（超支）。
- 超支因子（與 F4/F6 一致）：A2 協議（2 讀/對 = 7688 讀）= `1922/11 = 174.727`；全 pass（`3N²` 讀）= `2883/11 = 262.091`。

**J2 判決**：🟢 閉式＋充要條件（零反例）；🟡 數值層 `2N` 之判別力（已量化 ≈ 50%，明寫為**無訊息量**）。
