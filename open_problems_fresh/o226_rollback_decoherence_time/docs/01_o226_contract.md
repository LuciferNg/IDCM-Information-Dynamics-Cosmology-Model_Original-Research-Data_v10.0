## §3 時間身份之類型學（先寫死，後驗證）

機器之操作分兩型（**類型學係本輪之核心對象**）：
- **D 型（duration 型）**：向前、可累積、消耗預算者 = 一次 **miss 讀**（含狀態推進 `G ← G·h(ctx)`）。
- **R 型（restoration 型）**：**逆元**；`pop` 還原狀態、唔消耗預算（I1 明文）。
- **H 型（hit 型）**：memo 命中；回值、零寫入、零成本、零狀態推進。

**時間對映表之格 =（物件，結構謂詞，精確有理數／× tick）**；「無時間延展」= 該物件**唔係 D 型**（而非「值 = 0」之數值斷言）。

## §4 預註冊（**見數前寫死**；每條附可計算謂詞）

### J1 時間對映
- **Pr-1.1**：匹配表可填滿全部物件（≥ 12 行），每行皆有 (物件／結構謂詞／精確有理數)；**預期**：無空格、無浮點。
- **Pr-1.2**：`1 miss 讀 = 1/44 tick`；`1 tick = 44 miss = N_d`；`整 pass（3N² 讀）= 11532/44 = 2883/11 tick` EXACT。**預期**：三個精確分數全中。
- **Pr-1.3（判別力之否證）**：於成本家族 `c = k·θ`（k = 1..88）下 `reads/tick = 88/k`；命中「結構數池」{1, 2, 3, 4, 8, 22, 44, 88, 176} 之 k 數目 **≥ 5** ⟹ **「44 = N_d」之數值匹配本身零判別力**（`k = 1` 亦給 `88 = 2N_d`）。**預期**：成立（≥5）；此為「無效才是正確」型預註冊。
- **Pr-1.4（無時間延展之推導）**：對**全部** 3844 對 × 120 初始態，四操作對 `read(a);read(b);rollback;read(b)` 與二操作對 `read(a);read(b)` 之 `(x_a, x_b, s_final, top_ctx)` **完全相同** ⟹ pop（連同 reconcile 讀）在 (值, 世界線, 帳本頂) 三個可觀測面上係**冗餘** ⟹ pop 之時間延展 = 0 係**定理**，唔係約定。**預期**：不一致 = 0。
- **Pr-1.5（唯一性之形式）**：對映唯一性 = **條件唯一**：(i) 給定成本律（I4）＋(ii) 給定錨 tick（F7）後，全部物件之 tick 倍數被 I5 唯一決定；**無條件唯一 🔴**（因 Pr-1.3 顯示數值層不可判別）。**預期**：報出「充要條件 = 成本律 + 錨」之分解。
- **Pr-1.6（gauge）**：全部絕對時間（以 Gyr 計）之 `s_X = −1`（對 `c` 標度）；只有**比值**屬結構內容 ⟹ 絕對值標 🟡（1 錨）。**預期**：報 s_X 表 ＋ 標註。

### J2 預算守恆定理
- **Pr-2.1**：一次 pass 之精確帳（全 120 初始態全量）：`pairs = N²`、`read 操作 = 3N² = 11532`、`hits = 2N = 124`、`misses = 3N² − 2N = 11408`、`pops = N² = 3844`。**預期**：全中（＝停止 F4 之引用，改為自建機器重現）。
- **Pr-2.2（hits 之閉式）**：`hits(order) = N + C(order)`，`C = #{k ≥ 1 : b_{k−1} = a_k}`（carry 命中）；凍結字典序 ⟹ `C = N` ⟹ `2N`；**對 3 個隨機次序預期 `C ≪ N`** ⟹ **`2N` 非普適律，係凍結次序 ＋ carry 之產物**（誠實收窄）。**預期**：成立。
- **Pr-2.3（Σ 閉式 ＋ 充要條件）**：`m* = ⌊(B − θ)/c⌋ + 1`、`Σ = m*·c`；**恰好耗盡 ⟺ `c | B`**（在 `B = 88θ`、`c = kθ` 家族下 ⟺ `k | 88`）。**預期**：對 k = 1..88 全掃，等價關係**無反例**。
- **Pr-2.4（可行前綴）**：凍結次序下可行前綴 = **15 對**、完成讀 = **43**、第 16 對首讀為第 **44** 讀（耗盡）、次讀被終止條件拒；`Σ = 44c = B` EXACT。對全部 120 初始態**相同**（count 只依 ctx 序列，唔依狀態）。**預期**：全中。
- **Pr-2.5（樣本外盲測，見數前寫死數值）**：同一閉式對三組**未跑過**之輸入的預言：
  `B′ = 123`（2 tick）⟹ `m* = 88`、`Σ = 123` EXACT；
  `B″ = 123/4`（¼ tick）⟹ `m* = 22`、`Σ = 123/4` EXACT；
  `c‴ = 3θ`（同 B）⟹ `m* = 30`、`Σ = 11070/176 ≈ 62.8977 > B`（**預期超支**，i.e. 該成本律**唔**守恆）。**預期**：三個盲測值全中。
- **Pr-2.6**：與 F4／F6 之一致性：`argmin` 超支因子：A2 協議（2 讀/對 = 7688 讀）= `1922/11 ≈ 174.727`；**一次 pass（3N² 讀）= `2883/11` 倍預算對 44** — 兩者皆須重現。**預期**：全中。

### J3 多輪／多步帳本
- **Pr-3.1**：`R = 1..8` 輪 × 120 初始態：每輪 counts 全同（3N²／2N／N²）、終止對全同、行可行前綴全同；**跨輪邊界 carry**（上輪尾 ctx = 61 vs 下輪首 a = 0）**唔**產生額外命中 ⟹ 每輪 `hits = 2N` 恆定。**預期**：全量 120×8 無例外。
- **Pr-3.2**：逐對狀態對映 = **右平移**（`s_final = s·g(a,b)`）⟹ 雙射 ⟹ `p_k ≡ 均勻`（L1 dev = 0）對全部輪次；每輪世界線字 `W` 之階 `ord(W) | 60`（於 60-coset 商）。**預期**：L1 dev = 0；`ord(W)` 作**報告格**（預註冊「屬 60 之因數」，唔寫死具體值 — 避免推理寫死基數之陷阱）。
- **Pr-3.3（剛性）**：換 3 個隨機次序 ⟹ 每輪 counts 不變（次序無關）＋ `p_k` 仍均勻；但 `C(order)`（hits）改變 ⟹ 區分「次序無關之結構」與「次序相關之計數」。**預期**：成立。

### J4 陳舊度-退相干對偶
- **Pr-4.1（二值性）**：定義 `σ(ctx, s_rec, s_now) = [K[s_now][ctx] ≠ K[s_rec][ctx]]`；全量 62×120×120：`σ ≡ 0 ⟺ g ≡ s_rec⁻¹ s_now ∈ Z₂ = {±1}`；對所有 `g ∉ Z₂` 存在至少一條翻轉軸 ⟹ **陳舊係二值（0 或 >0），無連續漸變** ⟹ 對偶於 B2（無連續複相位）。**預期**：全中。
- **Pr-4.2（量化值集）**：翻轉集大小 `|D(g, w)|`（`w` = 幀軸 ∈ 62 軸）之值集係**量化集**，`0` 只出現於 `g ∈ Z₂`；值集大小 **< 62**；報出值集 ＋ 最小非零 `|D|`。**預期**：值集 size ∈ [3, 40]（預註冊為區間，唔寫死）。
- **Pr-4.3（結構歸屬）**：`|D(g, w)|` 之多重集按 `g` 之共軛類（9 類）分解；**預期**：主要依賴類 ＋ 幀 `w`（唔一定係純類函數 — 誠實報，若唔係類函數則該「non-class」本身係 finding）。
- **Pr-4.4（壽命以深度界，非時間）**：帳本條目之存活 = **深度**（≤ 2，含 carry ≤ 3），唔以時間計 ⟹ 帳本**無老化（aging）通道** ⟹ 任何「指數衰減／dephasing rate」形式之聲稱在凍結協定內**結構上不可能**（立場對稱 B3：無 envelope 權重）。**預期**：全量深度界成立；形式化陳述 + 可證偽推論（未來任何 τ_deco 之衰減式聲稱必偽）。
- **Pr-4.5（τ_deco 之正確類型）**：`τ_deco = 2 tick` 係**資源預算時間**（2 個預算耗盡 pass），**唔係**帳本老化常數；與 pop（深度 1）之關係 = **類型錯配**，唔可以數值比（「88 倍」係誤讀）。**預期**：成立。
