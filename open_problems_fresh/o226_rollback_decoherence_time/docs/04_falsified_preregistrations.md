## §1 測量層否證（FAIL 原樣保留）

### 1. Pr-2.2（`Q2`）— 「隨機次序 `C ≪ N`」**方向錯誤**
- **預註冊原文**：「`hits(order) = N + C(order)`…對 3 個隨機次序預期 `C ≪ N` ⟹ `2N` 非普適律，係凍結次序 ＋ carry 之產物」。
- **實測**：`C(字典序) = 62`、`C(反序) = 62`；**10⁴ 個隨機次序**之 hits = min **96** / 中位 **124** / max **152**、均值 **123.910**；理論 `E[C] = (N²−1)/N = 61.984`。
- **結論（修正 Q2-c）**：`C` 之期望**本身就 ≈ N** ⟹ **`hits = 2N` 係任何次序之典型值**，**唔**係凍結次序之產物 ⟹ `124 = 2N` 這個數字**無訊息量**（`q_obs ≈ 50%`）。
- **方法學意義**：原預註冊假設「隨機次序會破壞 carry 命中」；實測顯示 carry 命中係**相鄰巧合**，而 `N²` 對上 `N` 個 ctx 值之密度恰好使 `E[C] ≈ N`。若唔跑 null，就會把「典型值」錯當「結構強制」。

### 2. Pr-2.5 第三盲測（`Q6`）— **比較器瑕疵（預測本身正確）**
- **預註冊值**：`c‴ = 3θ` ⟹ `m* = 30`、`Σ = 11070/176 > B`。
- **實測**：`m* = 30` ✓、`Σ = 5535/88`。**`11070/176 ≡ 5535/88`**（同一有理數，僅未約分）。
- **處置**：原樣保留 FAIL（字串比較器）+ 立 `Q6-c` 以有理數比較 ⟹ 三組盲測**數值全中**，超支（`Σ > B`）為真。
- **方法學意義**：**盲測應以有理數比較，唔可以字串比較**（已在 `scripts/07` A6/A7 以 θ 整數單位複核）。

### 3. Pr-3.3（`R6`）— **單位錯配**
- **預註冊檢驗**：把**全 pass** 之閉式 hits（118／125／121）與**可行前綴**內之 hits 相比。
- **實測**：前綴內 hits = 1／0／1（前綴只含 15 對，全 pass 之 `N + C` 唔適用）。
- **修正 `R6-c`**：換次序下 **預算律剛性**（計費讀恆 44、`Σ = B`、`B_rem = 0`）、**內容非剛性**（完成對 15/14/15、前綴 hits 1/0/1）⟹「**預算是律，前綴是結果**」。
- **方法學意義**：閉式之**適用域**必須寫進檢驗；跨域比較會製造假 FAIL。

## §4 方法學結論

1. **8 項預註冊被否證，冇一項係「框架弱」**：全部係「我以為嘅結構」被實測推翻。其中 `S3/S4/S6/S8` 之修正**加強**結論（12 類商 ＋ `C₁₀` ＋ 量化度量 ＋ 深度界）。

3. **判準適用域必須寫入檢驗**（`R6`、`Q6`）：跨域／字串比較會製造假 FAIL，亦可能製造假 PASS。
4. **GATE 之修改必須披露**（§2 #3）：即使只係範圍收窄，亦要留紀錄，否則 GATE 失去審計價值。
