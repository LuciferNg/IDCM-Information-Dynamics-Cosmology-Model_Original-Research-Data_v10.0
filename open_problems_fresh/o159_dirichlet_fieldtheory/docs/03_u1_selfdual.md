## 1. U(1) 從譜結構現 (R5)

### 1a. 複結構 J = half-shift (docs/01 事實 3)

偶扇區: J² = +1 — 實。複場:

```

```

### 1b. 作用量嘅精確 U(1)

S = Σ|∂Φ|² + μ²|Φ|² (docs/02) 對 Φ → e^{iα}Φ 精確不變 —
U(1) 唔係貼上去: 大質量作用量嘅動能同質量項都係 |Φ|² 型 (相位無關),
而質量 μ² = 2 本身由扇區結構 (E−O = γ₄₄) 推出。

**2 實自由度 ↔ E−O = 2**: 複場每 mode 2 實自由度 (ρ, θ);
扇區能量隙 E−O = 2 = 複自由度數目 — 身份鏈:

```
E−O = 2 = #(實自由度 of ℂ) = γ₄₄ = μ²
```

### 1c. U(1) 電荷 = 動量; 扇區電荷不對稱

世界/觀察者 = U(1) 電荷嘅 Z₂ 分級 (charge parity)。

### 1d. 稅身份 (T18 Π₄₄ 延續)

## 2. 自對偶錨 k=44: 相位鎖定點 (R6)

### 2a. 三合一身份

```
k=44 = Z₂ 配對不動點 (88−44 = 44)
2γ₄₄ = B                (自對 pair 坍縮: γ₄₄ = B/2)
γ₄₄ = E−O = μ²          (自對偶本徵值 = 扇區隙 = 質量)
```

唯一一個「self-pair」mode — 配對結構喺 k=44 退化,
其本徵值恰好 = 扇區不對稱 = 大質量場論嘅質量參數。

### 2b. Pair 分解 (U(1) 不變量 + 各向異性)

每個 Z₂ pair (k, 88−k) 寫成複 mode Φ_k = (c_k + i·c_{88−k})/√2:

```
γ_k|c_k|² + γ_{88−k}|c_{88−k}|² = B·|Φ_k|² + (γ_k − μ²)·(|c_k|² − |c_{88−k}|²)
                                   ↑U(1) 不變      ↑各向異性
```

- 不變部分係數 = B = 4 (每 pair 總能 = 畢氏不變量)
- 各向異性係數 (γ_k − μ²) **喺 k=44 精確消失** (γ₄₄ − 2 = 0)
- γ_k < 2 for k<44, γ_k > 2 for k>44 — 錨點分隔 sub/super-self-dual modes

→ **k=44 係 pair 結構嘅相位鎖定點**: U(1) 不變量 B|Φ|² 同質量尺度 μ²
喺呢度重合; 各向異性以 μ² 為零點 — 錨點 = 「質量基準」= 相位鎖定成本。

  破缺嘅「尺度」就係質量本身 (spontaneous: 冇貼上參數)
