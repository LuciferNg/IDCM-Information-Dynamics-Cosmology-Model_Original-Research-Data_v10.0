## 1. 新定理: 176-Laplacian 本徵函數閉式

176-Laplacian (O159, half-site D-D 鏈, diag(3,2,…,2,3), −1 off-diagonal) 嘅本徵函數:

```
v_k(j) = sin(k · x_j),   x_j = (2j−1)π/176,   k, j = 1…88
```

- **精確** (A1: 88/88, max rel residual 1.65e-12)
- 譜一致 4sin²(kπ/176) (A2: max dev 2.22e-15); 正交 (A3)
- **範數閉式**: ‖v_k‖² = 44 (k < 88), = 88 (k = 88 Nyquist) (A4)
  — 由 Σ_j cos(k(2j−1)π/88) = 0 (k ≠ 88), = −88 (k = 88) 導出

**幾何內容 (B)**: 站點位置 x_j = (2j−1)π/176 係「半格點」= **176-cycle 邊中點**
(邊 (m, m+1) 中點 = π(2m+1)/176, m = 0…175; 摺疊 j ↔ 176−j 後 = 88 個值)。
兩端站點對角權重 3 = 摺疊固定點 ⟹ BC 成本 2 = μ² (O159 一致)。
**呢個就係「half-site」命名嘅精確內容** — 之前只有譜 (γ_k) 記錄, 冇本徵函數/站點幾何。

## 2. 範疇判定: 鏈相位 = colatitude (半週期), 唔係 longitude (全週期)

| 對象 | 範圍 | 週期性 |
|:-----|:-----|:-------|
| site phase 2θ_k = kπ/88 | (0, π] | **半週期** (C1) |
| 模態變數 x_j = (2j−1)π/176 | (0, π) | **半週期** (C2) |
| Galactic longitude | [0, 2π) | 全週期 |
| 球面 colatitude Θ | [0, π] | **半週期** |

**結構強制**: 鏈嘅自然角變數跨 π (半週期) ⟹ 佢對應天球嘅 **colatitude (Θ)**, 唔係 longitude。

**量化錯配 (C4)**: O143 Step-1 window 用 σ = 2π/88 = 4.091° (全週期格距);
鏈自身格距 = π/88 = 2.045° — **2× 錯配**。方向 + 尺度兩層都錯。

⟹ O143 判據 FAIL (7/60) 嘅根源 = **範疇錯誤** (半週期對象當全週期坐標用),
唔係「方向集揀得差」。呢個解釋咗 O182 docs/05 §2 嘅規則依賴現象
(longitude 規則 7/38 vs latitude 規則 2/48 — 兩個都係錯座標, 所以唔一致)。

## 3. 投影算子 𝒫 (唯一性)

**等距嵌入 (F1-F2)**: 鏈坐標區間 (0,π) 長度 π。單位球 S² 上弧長 π 嘅曲線**唯一**係
大圓半圓 (great semicircle); 半圓兩端**對極** (測地距 = π) = 鏈兩端 (Dirichlet 端點)。

```
𝒫[f](n̂) = f( arccos(n̂ · â) ),     f ∈ ℋ₈₈,  n̂ ∈ S²
```

- 像空間 = **軸對稱 (m=0) 子空間** (F4) — 鏈冇方位角數據, 唯一 rotation-equivariant 像
- **自由度**: SO(3) placement (3 參數) (F3) — **誠實聲明: 176-Laplacian 唔 fix 軸向 â**
- 零參數 (給定 â); 冇窗口函數, 冇 σ_site, 冇座標選擇

**軸向候選 (結構, 未定)**:
1. 鏈端點 (Dirichlet 兩極) — 但天球位置未定
2. 錨 k = 44 (自對偶, γ₄₄ = μ² = 2) → Θ = π/2 = 赤道
3. A₅ 對稱軸 31 個 (6 C₅ + 10 C₃ + 15 C₂) — 由 60 節點幾何自身導出 (H 節已全數偵測)

## 4. Φ_base 嘅真實身份: 純四極 (ℓ=2) + 單極

O143 Step-2 基態 Φ_base(k) = cos(πk/44) 喺新座標下:

```
Φ_base(k) = cos(2Θ_k),   Θ_k = kπ/88          (D1, EXACT)
cos(2Θ)   = (4/3)P₂(cosΘ) − (1/3)P₀           (D2: a₀ = −1/3, a₂ = 4/3, 其餘 ℓ 全零)
```

- 節點: Θ = π/4, 3π/4 → **2 條節點圓** = ℓ = 2 標誌 (D3)
- ⟹ 「相位場」= **四極 (ℓ=2) 軸對稱模 + 單極**, 唔係任意環諧波

**結構意義**: Φ_base 唔係「1D 環嘅 m=1 諧波」咁簡單 — 喺子午線讀法下佢係
球面上嘅純四極。O143 Step-4 嘅「節點分化」語言因此有咗幾何內容:
正交 = 四極節點圓 (Θ = 45°/135°), 波腹 = 極點/赤道。

## 5. 零點帶上限: 「48/60 正交」判據嘅死刑

| 量 | 值 |
|:---|:---|
| 解析 P(\|cos2Θ\| < 0.2), Θ 均勻 | 2·arcsin(0.2)/π = **12.82%** (E1) |
| 離散 88 site 計數 | 10/88 = **11.36%** (E2, O182 一致) |
| O143 判據要求 | 48/60 = **80%** |

80% ≫ 12.82% ⟹ **數學上不可能** (E3)。上限**只依賴 Φ_base 嘅近零測度**,
唔依賴方向集/採樣規則 ⟹ 換 88 格、換規則、換對稱群都救唔到 (E4)。

⟹ 判據必須換成 **profile 形狀判據** (場 vs cos(2Θ) 嘅相關/振幅), 唔可以係
「數幾多節點正交」。
