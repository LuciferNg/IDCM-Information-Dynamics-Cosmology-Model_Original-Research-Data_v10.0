## 1. 阻挫度 k 係咩 + 為何要核對

- k(i) = 節點 i 連接嘅阻挫邊數 (圖結構量); 由 2-著色決定
- O143 用嘅著色 = O7 `anchored_coloring.txt` (BFS from node 0, 已核對 ✅ 完全一致 up to flip)
- **關鍵問題**: 2-著色係咪唯一? (O7 docs/01: 「錨定著色係唯一嘅阻挫飽和 2-著色 up to global flip」)

## 2. ★★ 發現 1: 2-著色**唔唯一** (O7 唯一性聲稱證偽)

| 檢驗 | 結果 |
|:-----|:-----|
| 60 個 BFS 根 → 相異阻挫邊集 | **30 個** (每個 32 條) |
| 隨機二分對照 (4000 次) | 同色邊 min 42, mean 60.2 → 32 = **最小值** |
| 全部 30 個符合 O7 飽和條件? | **✅ 全部** (奇面 20Δ+12⬠ 每面啱啱 1 條; 正方形 0 或 2 **對邊**) |
| 顏色類大小 | 全部 30/30 |
| k 分佈 | 全部 8 / 40 / 12 |
| 端點 isotropy R_len | 全部 **0.0029** (同錨定值一樣) |
| 幾何指紋 (88 中點距離多重集) | **相異** ⟹ 唔係 icosahedral 對稱等價 |

**面結構驗證** (scripts/07, face-walk 平面嵌入): 20 三角形 + 30 正方形 + 12 五邊形 = 62 面 ✓
(Euler 120−60+2 ✓); 每條邊屬 2 面 ✓。

⟹ **O7「唯一飽和 2-著色」係 false**: ≥30 個飽和著色, 全部滿足 O7 列出嘅全部結構條件
(32 條 / 每奇面 1 條 / 正方形對邊 / 30-30 / 8-40-12 / R_len = 0.0029), 但幾何唔等價。

**O7 原論證嘅缺口**: 佢哋嘅對照係「**隨機** 30/30 著色」(0/50000 出到飽和) —
呢個只證明「隨機唔飽和」, 唔證明「飽和者唯一」。BFS 家族係結構性構造, 唔喺隨機樣本內。

## 3. ★★ 發現 2: k-selector 係「30 選 1」選擇效應

| 量 | 30 個飽和著色嘅分佈 |
|:---|:-------------------|
| corr(k, \|T\|) | **−0.382 至 +0.280**, 中位數 **−0.0085** |
| p < 0.05 嘅著色 | **1/30** (就係 root 0 = 錨定版) |
| k=2 集 ≡ ΔE=0 集 | **1/30** (其餘 29 個畀出唔同嘅 12 節點集) |
| 相異 k=2 集 | **30 個** (全部唔同) |

⟹ O143 docs/02 嘅兩個核心聲稱:
1. **corr(k,\|T\|) = −0.382 (p = 0.0014)** — 重現 ✅ (scripts/05 T2: −0.3819, p = 0.0016)
   **但**只喺 30 個 admissible 著色中嘅 1 個成立; 中位數 ≈ 0
   ⟹ 多重性校正後 p ≈ 0.0014 × 30 ≈ 0.04 (邊緣)
2. **「k=2 ⟺ ΔE=0 精確恆等式」** — 只喺 1/30 成立 ⟹ 唔係結構恆等式, 係著色選擇嘅後果

**判決**: k-selector 嘅支持依賴「揀邊個著色」— 需要一個**獨立結構原則**揀出錨定著色
(目前未有; 「錨定」= 來自 08-15 cmb_cold_spot 檔案, 同 sign(T) 只 61.7% 一致,
唔係單純數據擬合, 但亦唔係結構推導)。

## 4. 發現 3: k 嘅「軸對稱」性質 (scripts/05 T3)

- max_â \|corr(k, cos2Θ(â))\| = **0.5183**, p = 0.0015 (permutation null)
- 環分析 (scripts/06 §A): k **唔係** C₅ 環常數 (η² 0.07–0.39); 只有某 C₂ 軸 η² = 1
- ⟹ k 有軸對稱成分, 但唔係乾淨嘅 Θ 函數 (因為 k 唔係 I_h-不變 — 著色非唯一)
- 同樣受 §3 嘅著色選擇影響 (k 隨選擇變)

## 5. 發現 4: 88 格幾何非唯一 + 非對稱

| 檢驗 | 結果 |
|:-----|:-----|
| O182 g88 邊集 | = 120 − frust(**BFS root 0**) ✅ (來源確認) |
| ≠ 120 − frust(root 7) | ✅ (唔同) |
| 88 格 C₅ 軸 72° 旋轉 score | 0.025–0.080 (60 節點 = ~1e-6) ⟹ **唔係 icosahedral 對稱** |
| 30 個著色 → 88 格幾何 | 幾何指紋相異 ⟹ **30 個唔等價嘅 88 格** |

⟹ O182「88 格 = 88 條透明邊中點, 零新常數, 唯一確定」需加註:
- canonical 嘅只有**計數** 88 = 120 − 32 (= 2N_d ✓)
- 具體幾何係「≥30 選 1」, 依賴著色選擇
- 「可用作 𝒫 方向基準 ✅」(O182 裁決 §1) 仍然成立 (任何一個都係合法方向集),
  但唔可以叫「結構唯一嘅方向集」
