## 一、★★ 定律

**定義** (G = 有限旋轉群 ⊂ SO(3); h_G(j) := dim(Harm^j)^G):

```
A(G) := { j ≥ 2 : h_G(j) ≠ 0 }        active Legendre 次數
e(G) := min{ j ∈ A : j 偶 }            首個活躍偶次數
o(G) := min{ j ∈ A : j 奇 }            首個活躍奇次數   (無則 o = ∞)
```

**定律**:

```
M(G) = { 偶 n : n < e }  ⊔  { 奇 n : n < o }
|M(G)| = (e − 2)/2 + (o − 1)/2 = (e + o − 3)/2
```

**證明 (一行)**:

```
T_n(x) = Σ_{j≤n} a_j(n) P_j(x),    a_j(n) = ((2j+1)/2)∫_{−1}^{1} T_n P_j dx
a_j(n) ≠ 0  ⟺  j ≤ n  且  j ≡ n (mod 2)                      [標準]
模式條件:  Σ_{j ∈ A, j ≤ n} a_j(n) m_j(ĉ) = 0   ∀ ĉ
⟹ n 係模式  ⟺  冇 j ∈ A 使 j ≤ n 且 j ≡ n (2)
            ⟺  n < min{ j ∈ A : j ≡ n (2) }
⟹ 偶 n 係模式 ⟺ n < e;   奇 n 係模式 ⟺ n < o                 ∎
```

**註**: j = 1 永不貢獻 — 因 I-不變軌道有 Σ_i v_i = 0 ⟹ m_1 ≡ 0。故 A 由 j = 2 起。

## 二、★ e 同 o 之 Coxeter 身份

唔止數值吻合 — e 同 o 係**純 Coxeter 群資料**:

| 群 | Coxeter | 基本次數 | 指數 | #反射 | e | o | 身份 |
|:--|:--|:--|:--|--:|--:|--:|:--|
| T | A₃ | 2, 3, 4 | 1, 2, 3 | 6 | 4 | 3 | e = 最小偶次數 ≥ 4; **o = 奇基本次數 3** |
| O | B₃ | 2, 4, 6 | 1, 3, 5 | 9 | 4 | 9 | e = 4; **o = #反射 = 9** (無奇次數) |
| I | H₃ | 2, 6, 10 | 1, 5, 9 | 15 | 6 | 15 | e = 6; **o = #反射 = 15** (無奇次數) |

**規則**:

```
e(G) = 最小偶基本次數 ≥ 4              (次數 2 被調和投影 (1−t²) 消去)
o(G) = min{ 奇基本次數 (若有),  #反射 }
```

**關鍵**: A₃ 有奇基本次數 3 ⟹ o = 3 (細)。B₃ 同 H₃ **全部基本次數皆偶**
⟹ 首個奇不變調和 = **交錯形式 (alternating form)**, 其次數 = **#反射**。
故 H₃ 之 o = 1+5+9 = **15 = deg δ** — 與 docs/29 之 δ 恆等式**同一個數**。

⟹ docs/29 之「deg δ = 15」同本文之「o = 15」係**同一件事**:
δ 係首個奇不變調和，其次數即模式截斷參數。

## 四、★ 為何係 I? — I 同時最大化 e 同 o

```
e:  C/D → 2    T → 4    O → 4    I → 6      (I 最大)
o:  C/D → 3    T → 3    O → 9    I → 15     (I 最大)
⟹ |M| = (e+o−3)/2 亦最大 = 9
```

**機制**: e 由「最小偶基本次數 ≥ 4」決定 — H₃ 之 6 係三族中最大。
o 由「#反射」決定 (因 H₃/B₃ 無奇基本次數) — H₃ 之 15 亦最大。
⟹ **I 之所以獨特，係因 H₃ 有最大之偶基本次數 (6) 同最多反射 (15)**。
兩者皆 H₃ 之 Coxeter 不變量，**唔係額外選擇**。
