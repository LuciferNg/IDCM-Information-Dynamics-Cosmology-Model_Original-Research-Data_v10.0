## 3. ★ v₂(n) 子環規則 (scripts/08) ✅ 閉合

### 3.1 發現

L ∈ {4, 11, 22, 44} = {B, L₅, Nd/2, Nd} 本身係 **chain-side MERA 子環結構**:
44 = 4×11, B=4 分支 → 子環長度 {11, 22, 44} = Nd/2^k (k=2,1,0) + 邊界 B=4。

**模式 n 嘅子環類由 2-adic valuation 決定**:

```
L(n) = Nd / 2^{v₂(n)}
  v₂(n) = 0 (odd)     → L = 44 = Nd
  v₂(n) = 1 (2 mod 4) → L = 22 = Nd/2
  v₂(n) = 2 (4 mod 8) → L = 11 = Nd/4 = L₅
  v₂(n) ≥ 3 (8|n)     → L = 5.5, 2.75, ... 非整數 → 冇子環可繞 → 純玻色子
```

### 3.2 驗證

| 檢驗 | 結果 |
|:---|:---|
| 六候選全部 v₂ ≤ 2 | ✅ (1:0, 7:0, 14:1, 20:2, 33:0, 34:1) |
| 純玻色子 = {n: v₂≥3} | ✅ **{8, 16, 24, 32, 40} = n ≡ 0 (mod 8) 完全匹配** |
| 候選 L 分配 | e,μ,b → L=44; s,c → L=22; τ → L=11 |

**純玻色子 {8, 16, 24, 32, 40} 嘅排除係零參數、一次過、結構性**:
v₂ ≥ 3 ⟺ 8|n ⟺ Nd/2^{v₂} 非整數 ⟺ 冇整數長度子環可繞 half-integer 次。

**44 = 22 + 11 + 6 + 5** (v₂ = 0,1,2,≥3 類嘅模式數):
- L=44 類: 22 個 odd modes
- L=22 類: 11 個 (n ≡ 2 mod 4)
- L=11 類: 6 個 (n ≡ 4 mod 8)
- 純玻色子: 5 個 (n ≡ 0 mod 8)
