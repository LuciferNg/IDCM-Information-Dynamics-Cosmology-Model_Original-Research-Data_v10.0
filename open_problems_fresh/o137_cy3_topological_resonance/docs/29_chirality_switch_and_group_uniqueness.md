## §2 ★ δ 嘅身份：I₁₅ = ∏_{a∈A2}(a·x)

### 2.1 動差嘅完全平方性

`m_j(v;c) := Σ_{g∈I} P_j((gv)·c)` 對 c 係 I-不變且調和 ⟹ `m_j(v;·) ∈ (Harm^j)^I`。
當 h(j) = 1 時 `m_j(v;·) = λ_j(v)·I_j(·)`。而

```
λ_j(v) = ⟨P_j(v··), I_j⟩
```

作為 v 嘅函數係 j 次 I-不變調和 ⟹ `λ_j(v) ∈ (Harm^j)^I = span(I_j)` ⟹ **λ_j = κ_j·I_j**。

**⟹ m_j(v; v) = κ_j·I_j(v)²  【完全平方，恆 ≥ 0】**

數值確認（600 隨機 chiral 種子，scripts/44 §2–3）：

```
m₁₅(v;v) min = −1.498e−09  (#負 = 0)
m₂₁(v;v) min = −3.375e−09  (#負 = 0)
m₂₅(v;v) min = −6.516e−09  (#負 = 0)
```

（負值僅為浮點零。）

### 2.2 δ 之構造與調和性

設 **A2** = I 嘅 15 個 2-fold 軸（= 正二十面體 15 個鏡面之法向）。定義

```
δ(x) := ∏_{a∈A2} (a·x)
```

| 檢驗 | 值 |
|:---|:---|
| deg δ | **15** |
| 項數 | **136** = C(17,2)（3 變量 15 次全部單項式） |
| Δδ 最大係數 | **4.108e−15**（float64）；**4.278e−61**（mpmath 60 位，精確 Q(√5) 座標）⟹ **δ 精確調和** ✅ |
| \|δ(v)\| 分佈（20000 隨機方向） | median 5.44e−07，max 1.99e−06 |

δ 係 I-不變（det = +1），但係 I_h-**反**不變（反射 det = −1 ⟹ δ ↦ −δ）。
呢個就係 Coxeter H₃ 嘅 **alternating form**。

### 2.3 ★ 精確比例：m₁₅(v;v) = κ δ(v)²

481 個良好條件樣本（\|δ\| > 1e−7）：

```
m₁₅(v;v) / δ(v)² :  min = 2.329089e+12   median = 2.329090e+12   max = 2.329090e+12
max/median = 1.0000        κ δ² 重現 m₁₅ 之最大相對偏差 = 1.544e−09
```

**⟹ I₁₅ = δ（差一常數）。** 即：**二十面體群嘅 15 次不變調和 = 15 個鏡面線性型之積。**

對 j = 21, 25 同樣 ∝ δ²（常數不同，因 I_j ∝ δ·(偶不變量)）：

```
m₂₁/δ² = 1.9769e+12      m₂₅/δ² = 1.8498e+12
```

**⟹ 所有奇 j 之 m_j(v;v) 同時 ∝ δ(v)² ⟹ 同時消失。** 呢個係 §3 二分定理嘅機制。

## §4 為何截斷於 13 同 4 —— Coxeter H₃ 結構

### 4.1 生成函數

I ⊂ I_h（正二十面體全群 = Coxeter H₃，order 120）。
H₃ 基本次數 = **2, 6, 10**；#反射面 = (2−1)+(6−1)+(10−1) = **15**。

```
R^{I_h} = R[f₂, f₆, f₁₀]
R^I     = R^{I_h} ⊕ δ·R^{I_h},        deg δ = 15
```

⟹ Hilbert series：`(1 + t¹⁵)/((1−t²)(1−t⁶)(1−t¹⁰))`
⟹ 調和不變量生成函數（乘 (1−t²)）：

```
Σ_l h(l) t^l = (1 + t¹⁵) / ((1 − t⁶)(1 − t¹⁰))
```

### 4.2 h(l) 結構

| l | h(l) | 說明 |
|:-:|:-:|:---|
| 1–5 | 0 | **5-design**（H₃ 之 5-design 性） |
| **6** | 1 | 首個非零（偶） |
| 10, 12 | 1 | |
| **15** | **1** | **首個非零奇**（= δ） |
| 16, 18, 20, 21, 22, 24, 25, 26, 27, 28, 30 | 1–2 | |

⟹ 奇模式條件：需 `a_j(n) = 0 ∀ j ∈ {15,21,25,…} ∩ [2,n]` ⟹ **n ≤ 13**（7 個）
⟹ 偶模式條件：需 `a_j(n) = 0 ∀ j ∈ {6,10,12,…} ∩ [2,n]` ⟹ **n ≤ 4**（2 個）
⟹ **合計 9**

### 4.3 「15」嘅結構來源

```
deg δ = 15 = #H₃ 正根 = #H₃ 反射面 = #正二十面體鏡面 = #I 之 2-fold 軸
```

（四者同為 15 —— 全部由 H₃ 決定。）

## §5 ★★ 為何係二十面體群 —— 9 之唯一性

### 5.1 掃描所有有限旋轉群

**⟹ 全部 12 個群之中，只有 I 畀出 9 模式。模式數值集 = {1, 2, 5, 9}。**

### 5.2 群層級 = 球面設計強度

首個非零 h(l) 即「設計強度 + 1」：

```
C/D → 1-design   T → 2-design   O → 3-design   I → 5-design
```

I 嘅軌道係 **5-design**（古典事實：正二十面體 12 頂點 = 5-design），
且 **5 係所有有限旋轉群軌道之中嘅最大設計強度**。

**⟹ 完整結構鏈：**

```
(1) 有限旋轉群中唯 I 之軌道達 5-design（其他 ≤ 3-design）
(2) 5-design  ⟹  h(l) = 0 對 l ≤ 5
(3) 由 H₃: R^I = R^{I_h} ⊕ δ·R^{I_h}, deg δ = 15 ⟹ 首個奇調和 = 15
(4) ⟹ 奇模式 n ≤ 13（7 個）;  首個偶調和 = 6 ⟹ 偶模式 n ≤ 4（2 個）
(5) ⟹ 9 模式 = {1,2,3,4,5,7,9,11,13}
```

## §6 🟡 誠實修正：docs/27 §7「準則脆弱性」

### 6.1 觀察

600 隨機 chiral 種子之模式數**分佈**（唔係全部 9）：

```
絕對容差 1e-3: {9: 518, 10: 18, 11: 12, 12: 14, 13: 5, 14: 4, 15: 1, 16: 1, 17: 1, 18: 6, 19: 1, 20: 2, 22: 3, 23: 1, 24: 13}
絕對容差 1e-6: {9: 580, 10: 4, 11: 2, 12: 5, 14: 1, 15: 3, 17: 1, 18: 1, 24: 3}
```

### 6.2 機制（唔係結構，係容差偽影）

```
m_j(v;v) = κ_j·δ(v)²，  而 |δ| median ≈ 5.4e−07  ⟹  δ² ≈ 2.9e−13
```

δ 係 **15 個因子之積**（典型 |a·v| ≈ 0.38），所以對典型種子 δ² 極細 ⟹
`|D_n| = |a₁₅ m₁₅|` 細 ⟹ 跌入絕對容差以下 ⟹ 偽陽性模式。

**證據**：容差由 1e−3 收緊至 1e−6，9 模式比例 518/600 → 580/600，中間模式數單調減少。

**結構真值**：chiral ⟹ 9，achiral ⟹ 24（精確二分，§3）。

### 6.3 docs/27 §7 之更正

docs/27 §7 記錄「0.01° 擾動即崩潰，模式數 [3,2,1,2,3]」。
**本輪釐清**：該現象係**破壞 I-不變性**所致（載入節點集之 I-不變殘差 = 9.7e−5°，
令奇 j ≤ 13 之動差由 0 升至 1.134e−05），**唔係判準本身脆弱**：

```
載入節點集 (9.7e−5° 殘差):  奇 j≤13 最大動差 = 1.134e−05  ⟹ tol 1e−6 下低模式亦失敗
精確 I-不變軌道:            9 模式 @ tol 1e−10
```

**結論**：判準對「I-不變性」敏感（此為結構要求），對「容差」敏感（此為數值偽影）。
兩者必須分開記錄。
