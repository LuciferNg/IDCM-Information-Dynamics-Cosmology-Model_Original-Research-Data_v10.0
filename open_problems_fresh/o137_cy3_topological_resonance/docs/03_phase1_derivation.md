**耦合方程** (88-site 環 ⊗ CY₃):


## 2. 項目 B: 駐波條件 (Quantization Rule) ✅ ★核心發現

駐波條件 (roadmap 原式): ∮_{C_k} dφ_n = 2πm。

88-site 環: 每個 site 嘅相位步進 = 2π/88。循環 C_k 有長度 L (以 site 為單位)。

**玻色子 (單值)**:  Δφ = 2πm ⟹ n·L/88 ∈ ℤ ⟹ n·L ≡ 0 (mod 88)
