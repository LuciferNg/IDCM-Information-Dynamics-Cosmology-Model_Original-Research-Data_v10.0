## §二 截斷階結構機制（scripts/73，12/12 PASS）

### ① 代數階：ε 極小多項式 deg = 2

```
ε = 1/(Bφ),  φ²−φ−1 = 0,  φ = 1/(Bε) ⟹ 1/(B²ε²) − 1/(Bε) − 1 = 0
⟹ B²ε² + Bε − 1 = 0         (ε 極小多項式, [ℚ(ε):ℚ] = 2)
⟹ ε² = (1−Bε)/B²,  ε³ = 2ε/B² − 1/B³      (任何 ε^k, k≥2, collapse 到 {1,ε})
```

**關鍵後果**：ε(1+ε) 之「規範型」全由 B 決定：

```
ε(1+ε) = ε+ε² = 1/B² + (B−1)ε/B            ⟹ 1/16 + (3/4)ε  (B=4)
```

係 2 項（而唔係 3 項）嘅最小必要型式：ε⁰ 係數 + ε 係數 — 一維（ε）之上無更多代數維度。**「二階」= ε 對 ℚ 嘅擴張度 2 → 修正量嘅最大必要階 = 2**（更深重和項無新代數內容）。

### ② N_d 因式：44 喺 ℤ[√5] 分解

```
α = 3√5 − 1
α(α+2) = (3√5−1)(3√5+1) = 45−1 = 44 = N_d     ★ 鏈長因式分解
α² = 44 − 2α                                  (特徵方程 x²+2x−44 = 0)
α = −1 + 3√5                                   (a,b 整數, N = a²−5b² = −44)
```

**44 喺 ℤ[√5] 非素**（分解 α·α' 存在）。N_d = 44 係 88-site dual chain 嘅鏈長（O137 全域中心量）。

### ③ 橋：ε(1+ε) = α/32 — D−1 繼承鏈長

```
D−1 = r·ε(1+ε) = (2N_gen²/L₄²)·ε(1+ε)
     = N_gen²·α/(B²L₄²)      （∵ 2·ε(1+ε)·B² = 32ε(1+ε) = α, B=4, 2B²=32）
     = 9·(3√5−1)/784 = (775+27√5)/784     （O134 docs/05 ① 閉式, dev=0）
```

**核心**：D−1 分子 = N_gen² × [N_d 之 ℤ[√5] 因式 α]；分母 = (B·L₄)² = 28²。

### ④ ★ 唯一性定理（何階令 D−1 繼承 N_d 因式）

掃描 x_N = ε·Σ_{k<N}ε^k，檢驗 32x_N = a + b√5 是否 a,b ∈ ℤ（ℤ[√5] 整數）且 |N(a+b√5)| = 44：

| N | 32x_N | a+b√5 | \|N\| | 命中 |
|:-:|:------|:------|:----:|:----:|
| 1 | 4.94427191 | −4+4√5 | **64 = B³** | ✘ |
| **2** | **5.70820393** | **−1+3√5 = α** | **44 = N_d** | **★★** |
| 3 | 5.82623792 | 非整數 | 57.25 | ✘ |
| 4 | 5.84447518 | 非整數 | 52.42 | ✘ |
| 5 | 5.84729299 | 非整數 | 54.47 | ✘ |
| 6 | 5.84772836 | 非整數 | 53.66 | ✘ |

**只有 N=2 令 32x_N ∈ ℤ[√5] 且範數 = ±44（鏈長）**。一階（N=1）其值係 −4+4√5，範數 = 64 = B³ — 係「B 立方」而非「鏈長」；更高階全部跌出 ℤ[√5] 整數環。

⟹ **二階 = 唯一令 D−1 繼承鏈長 N_d = 44 因式身份嘅階**。若採用一階，D−1 會喪失 44 因式；若用高階，D−1 唔係 ℤ[√5] 整數（代數封閉性破壞）。

### ⑤ 完整裁決

```
層級: ① 代數階 (ε minpoly deg=2)          → 二階係「最小必要」
      ② N_d 因式 (44 = α(α+2))           → 二階係「鏈長身份」
      ③ 唯一性 (N=1..6 掃描)              → 二階係「唯一實現」
      ④ 統計 (N=1 排除, N=2 vs ∞ 唔銳利)  → 統計唔反, 結構裁定
⟹ 截斷階 = 2 為結構必然 (三層獨立一致)
```

## §三 良好界線（誠實標記）

1. **「為何 D 必須繼承 N_d 因式」** — 本推導立於 D 之物理角色（O134 docs/05 §三：下型兩步間距退化之破缺量，`(m_b/m_s)/(m_t/m_b) = D`）：D 係**鏈上兩步間距**嘅量，鏈長 N_d 自然嵌入。若有人主張 D−1 唔應附鏈長因式，整個下型階梯（44.5254 裸退化）會失去 N_d 錨定 — 此為可證偽前提（替代：一階 B³ 或無窮重和機制必須自洽解釋自身鏈長關聯）。
2. **「32 = 2B²」** 係由 r 分子（2N_gen²）同 ε(1+ε) = α/(2B²) 之間鎖定，唔係額外輸入；32 = 2B² = 2·16。唯一性命題本身**對 32 之選擇敏感**（檢驗界係「繼承 44 因式」而非任意比例）。
3. **統計上 N=2 vs N(∞) 仍唔銳利** — 本推導唔冒充觀測證據；佢將截斷階由「形式/統計」升為「代數/唯一」級。若要觀測銳利化，需 m_b/m_s/m_t 更高精度（或新結構量測 33/26/19 間距）。
4. **未觸及**：下型扇區選擇律（D 為何附下型而非 up/lepton）— 仍屬 O136 開放（O134 docs/04 §五 #1），本輪唔推。
