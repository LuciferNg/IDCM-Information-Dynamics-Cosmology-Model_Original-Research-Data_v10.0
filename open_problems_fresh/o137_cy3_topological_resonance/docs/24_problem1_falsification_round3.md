## 2. (B) ★★ 枚舉測試: Φ 目錄【無法】重現輕子質量集 (決定性)

**方法**: 枚舉所有 (e, μ, τ) → (Φ 條目 ÷ {1,2,4}) 指派, 檢查三個質量能否同時 1% 內閉合。

| 約束 | 有效指派 / 總數 | 比例 |
|:---|:---:|:---:|
| 無世代約束, tol = 1% | **0 / 148,824** | 0.000% |
| 有世代約束 (e→x₃=1, μ→x₃=5, τ→x₃=9), tol = 1% | **0 / 5,832** | 0.000% |
| 有世代約束, tol = 0.2% | **0 / 5,832** | 0.000% |

**根本原因 (e 嘅問題)**:

```

⟹ 3.5941 冇任何 Φ 表示

μ: C_μ = 15.4794 → Φ[(1,4)]/2 = 31/2 = 15.5  (0.13%) ✅
τ: C_τ = 37.1259 → Φ[(2,3)]   = 37          (0.34%) ✅
```

**★★ 判定**: docs/19/23 宣稱「C_f = φ=9 相交矩陣值」——
- **μ, τ (2/3) ✅ 成立** (Φ = 31, 37 係矩陣真值)
- **e 🔴 唔成立** — C_e = 18/5 = L₆/F₅ 屬 **Lucas/Fibonacci 家族**, 唔係 Φ 家族

**⚠️ 唔可以為救 e 而擴張除數集**: 試 Φ[(1,6)]/10 = 36/10 = 3.6 (36 = h¹¹ 真值) 雖可命中,

## 8. 診斷與下一步

**診斷**: O137 嘅質量框架 (`m = M₀γ_n C_f`) 有兩個結構性缺陷:
1. **Φ 家族唔完備** — e 需要 Lucas 家族 (L₆/F₅), 即 C_f 至少兩個來源
2. **模式分配未經統計驗證** — 在唯一有統計支持嘅判準 (|Δm|) 下落敗

**⚠️ 唔可以嘅做法**: 擴張除數集/符號庫去救 e (§2) — O136 致命傷 #1。

**可行方向**:
1. **測試 A₅ 模式集在 O137 γ_n 框架下嘅 C_f 反解** — 睇能否用單一 Φ 家族閉合 (需 O136 模式↔粒子對應)
2. **尋找同時滿足 v₂≤2 + |Δm| 統計 + Φ C_f 嘅模式集** — 三約束交集
3. **承認雙家族結構** — C_f ∈ Φ 家族 ∪ Lucas 家族, 並檢驗有無統一生成規則 (如 C = Φ 或 L/F, 由模式奇部決定)

**本輪結論**: #1 充分性 **仍然 🔴 開放**, 但邊界已大幅收窄 —
唔係「唔知點解選呢啲模式」, 而係「O137 嘅模式分配與 O136 A₅ 分配互斥, 且 Φ C_f 家族唔完備」。
