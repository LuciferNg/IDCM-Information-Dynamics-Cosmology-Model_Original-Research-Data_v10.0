## 零、問題

O182 之構造: **88 格 = A₅ 60 節點網 (RH 圖) 之 88 條「透明邊」中點**。
其中 32 條「阻挫邊」由 `cmb_cold_spot/scripts/17_exact_graph_coloring.py` 生成 —
**方法 = 由 node 0 錨定之 BFS 二著色，取【同色】之邊**。

🔴 **威脅**: BFS 二著色係【算法產物】。圖非二分 (有三角形) ⟹ BFS 必有同色邊。
「32」係圖不變量，定係遍歷順序/錨點之產物? 若後者，`88 = 2N_d` 就係偽影。

## 二、★★ MaxCut 定理 (MILP 精確)

用 `scipy.optimize.milp` (HiGHS) 精確求解最大割:
```
變數: x_i ∈ {0,1} (i = 0..59),  y_k ∈ {0,1} (k = 0..119, 邊)
目標: max Σ y_k
約束: x_u + x_v − y_k ≥ 0 ;  −x_u − x_v − y_k ≤ −2     (y_k = x_u XOR x_v)
```

| 圖 | MaxCut (精確) | 最小 mono |
|:--|--:|--:|
| **觀測 IDCM 60 節點圖** | **88** | **32** |
| **RH 幾何圖** | **88** | **32** |
| BFS 著色 | 88 (達最優) | 32 |

```
★★ MaxCut = 88 = 2N_d        (HiGHS Status 7: Optimal)
★  最小 mono = 32 = 2B²
★  BFS 著色確實達到最大割 ⟹ O182 之「32 條阻挫邊」= 最小阻挫集
```

**⟹ O182 之 88 = 120 − 32 係【圖不變量】，唔係 BFS 偽影。** ✅ 地位修復。

**附加**:
- 兩圖**同構** (VF2 `nx.is_isomorphic` = True; 譜最大差 0.0) ⟹ 觀測集之最近鄰圖 = RH 圖

## 三、★★★ 面結構: 32 = 20 + 12

RH 圖之組合結構:

```
60 頂點, 120 邊, 4-正則, girth 3
  20 個三角形 (邊兩兩不相交, 每頂點恰在 1 個內)      ⟹ 20×3 = 60
  12 個 5-環 (橋接子圖, 2-正則)                    ⟹ 12×5 = 60
  60 條三角形內邊 + 60 條橋接邊 = 120
```

| 量 | 值 | 結構 |
|:--|--:|:--|
| 三角形數 | **20** | 正二十面體面數 |
| 5-環數 (橋接子圖之環) | **12** | 正十二面體面數 = 正二十面體頂點數 = F₆ |
| 每三角形之同色邊 | 恰 **1** | (20 個三角形 → 20 條) |
| 同色邊總數 | **32** = 20 + 12 | **三角形內 20 + 三角形外 12** |
| 三角形外之同色邊 | **12** = B·N_gen | |
| 同色子圖 | 20 條**路徑** (森林, 最大度 2) | 覆蓋 52 節點; 8 個節點零同色邊 (= F₆) |
| 割後度數分佈 | {2:12, 3:40, 4:8} | |

★★ **`32 = 20 + 12` = 三角形面數 + 五邊形面數** — 每條阻挫邊「對應」一個面。

## 九、方法論教訓

1. **算法產物 ≠ 偽影，亦 ≠ 不變量 — 必須用精確優化判定。**
   BFS 二著色係算法，但其同色邊數恰等於圖之最小阻挫 (MILP 證最優)。
   若只做「換 seed 重跑」檢定 (32 對 60 錨點 + 300 順序不變) 仍**唔夠** —
   要證「32 = 最小」必須精確優化。
2. **null 集合之約束必須精確匹配。**
   集合 A (純 4-正則) → 101.7; 集合 B (20 三角形 + 隨機 2-正則) → 97.0;
   集合 C (20 三角形 + **12 五邊形**) → 88.00, sd = 0。
   只有集合 C 揭示結構強制。**粗糙 null 會給出錯誤嘅「唔係結構」結論。**
3. **幾何直覺須檢定。** 「88 = 2N_d」看似應有平面實現 — 實測半空間最多切 20 (22.7%)。
   緊框架 (VᵀV = 20·I) 令半空間恆平衡，但圖之邊幾乎全在同半球。
4. **跨檔索引約定歧義** (docs/31 §9 同): 阻挫邊須用檔案自帶 RA/Dec 直算。
