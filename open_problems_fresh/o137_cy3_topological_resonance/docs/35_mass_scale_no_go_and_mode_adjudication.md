## 一、幾何供給審計 — 「幾何每模式供給乜嘢?」

A₅ 幾何 (chiral I-60-軌道) 對每模式 n 供給之數據, 逐項檢查:

| 項 | 內容 | 是否 f(n) |
|:--|:--|:--|
| ① | n 本身 (整數標籤) | 是 (定義) |
| ② | parity(n) = n mod 2 | 是 |
| ③ | block(n) = ⌈rank/3⌉ | 是 |
| ④ | γ_n = 4sin²(nπ/88) (K_chain 特徵值) | 是 |
| ⑤ | 活躍不變調和次數 {l : h(l) ≠ 0, l ≤ n, l ≡ n (2)} | 是 |

**⟹ 【每模式之幾何數據完全由 n 決定】 — 冇第二個幾何自由度。**

**⟹ 「質量由 A₅ 幾何決定」⟺ `m = f(n)`。** 呢個係一個**歸約定理**, 唔係假設。
所以 Round 11 之 FAIL 唔係「搵唔到 f」, 而係**幾何本身唔攜帶足夠信息**。
