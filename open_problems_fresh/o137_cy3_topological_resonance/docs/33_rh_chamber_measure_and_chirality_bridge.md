## 3. T3 — 缺口 ⑤：幾何 chirality 之模式移除數 = 其次數 o

### 3.1 ★ 恆等式

```
o = N_gen·F₅ = 15 = #H₃ 反射 = #H₃ 正根 = deg δ
e = 2N_gen = 6
N_d + 1 = N_gen·o = 45          ⟺  N_d − o + 1 = 2o = 30

|M_chiral|  = (e + o − 3)/2 = 9  = N_gen²
|M_achiral| = N_d/2 + (e − 2)/2 = 22 + 2 = 24

★★ |M_achiral| − |M_chiral| = 24 − 9 = 15 = o = deg δ
   代數: (N_d − o + 1)/2 = o   [因 N_d + 1 = 3o]
```

**⟹ 幾何 chirality 序參量 δ 之【次數】= 其【移除之模式數】。**

### 3.2 ★★ 判準釐清（方法論修正）

首次驗證失敗（Legendre 判準給 RH = 26、觀測集 = 2），**根因**：

- **純 Legendre 判準係錯的**：`P_n(v·c)` 之調和內容**只在次數 n**，
  故判準退化為 `h(n) = 0`，**睇唔到截斷**。
- 原記錄（`scripts/43b_diag_modecount.py`）用 **Chebyshev**：
  `F_n(c) = Σ_i T_n(v_i·c)`，參考值 `|P|·a₀(n)`，`a₀(n) = 0`（奇）/ `1/(1−n²)`（偶），tol = 1e−3。
  Chebyshev 展於 Legendre 次數 n, n−2, n−4, … ⟹ 判準成為
  **「無活躍不變調和次數 j ≤ n 且 j ≡ n (mod 2)」** ⟹ 正確產生截斷。

### 3.3 ★★ 實際軌道獨立重現（原判準）

| 軌道 | 模式數 | 模式集 |
|:---|:---|:---|
| achiral RH | **24** | {2,4} ∪ {奇 n ≤ 43} |
| chiral 觀測集 | **9** | {1,2,3,4,5,7,9,11,13} |

✅ 與 docs/01、docs/18、docs/28–32 之記錄一致（獨立重現，非引用）。

### 3.4 判定

```
⟹ 由「譜對 sign(δ) 盲」之【定性】陳述,
   升級為「δ 之次數 = 移除之模式數」之【定量】橋
```
