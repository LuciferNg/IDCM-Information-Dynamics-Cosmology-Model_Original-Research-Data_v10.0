## 2. ★★ 座標 bug 發現: O174 docs/16「3% 地圖系統差」係假象

**O174 script 20 (docs/16 嘅數值來源) 用 `theta = 90°−Dec, phi = RA` 直接喺銀河座標地圖採樣** — Planck 地圖係銀河座標, ICRS RA/Dec 唔可以當 theta/phi 用。逐節點測試 (script 05):

| 採樣法 | 節點 0 (冷斑) | 4.17° M1 |
|:---|:---|:---|
| ang2pix 銀河 (正確) | −134.19 μK ✓ | 0.24435 |
| get_interp_val RA/Dec 當 theta/phi (O174 script 20 bug) | **+58.49 μK ✗** | 0.25995 |

**後果**: docs/16 嘅「Commander 0.25166 / SEVEM 0.25263, spread 3%」採樣咗**錯位置** (M1 係穩健統計所以數值「巧合」差唔多)。正確採樣後:

*NILC 地圖: `o175_entropy_theorem/data/planck/COM_CMB_IQU-nilc_2048_R3.00_full.fits` (nside 2048, 100% finite)。

**11/45 命中係跨地圖一致** (唔係「SMICA 特有」)。O174 docs/16 嘅「地圖系統差 3% ≫ dev 0.04%」結論需要更正 → 系統差實測 ~1%, 但 11/45 依然唔可以轉正 (原因見 docs/04: 高斯基線)。
