## 1. 問題重述

## 2. 幾何構造候選 (由結構推出, 零新常數)

### 候選 A: C60 + 對偶面中心 28 點
- C60 (Rhombicosidodecahedron): 60 節點, 20 三角 + 30 正方 + 12 五邊 = 62 面
- 面中心: 62 點 — 太多。唔係 28。
- **排除**: 62 ≠ 28

### 候選 B: 44 對極點 (N_d = 44)
- 88 = 2 × 44: 44 個方向 + 各自對極點
- 結構對應: N_d = 44 (O159 176-Laplacian 半譜), 88-site 鏈有 44 對 ±k 模態
- 44 對極點 = 鏈模態 k 同 88−k 嘅天球對應
- **可行**: 需定義 44 個基礎方向 (候選: A₅ 60 節點中嘅 44?或 Fibonacci 44?)
- 問題: 44 個基礎方向點樣由結構選出?

### 候選 C: Fibonacci 格 88 點 (θ_k = kπ/176 相位對應)
- Fibonacci 球面格: N 點均勻分佈, 第 k 點緯度 θ_k = arccos(1 − 2(k+0.5)/N)
- 88 點 → θ_k 直接對應 site phase 2θ_k = kπ/88? 唔直接。
- **需檢查**: Fibonacci 88 點嘅 ⟨|cosθ|⟩ 理論期望 (均勻 = 0.5, 唔係 0.244)

### 候選 D: 88-site 鏈模態節點投影
- 鏈模態 ψ_n (n=1..88), 176-Laplacian D-D BVP (O159)
- 模態節點 (ψ_n = 0 嘅位置) → 天球方向?
- 88 個模態 → 88 個節點位置?
- **最結構**: 直接由 176-Laplacian 特徵函數推出
- 需檢查: D-D BVP 模態 ψ_n(x) 嘅零點集合 x ∈ [0, L], n = 1..88

### 候選 E: 60 A₅ + 28 = 「B₅ 補集」
- B₅ = 另一 5 階對稱多面體? (A₅ = 60 節點 icosahedral 對稱)
- 5 階群: icosahedral group I (60 元素) — A₅ = I 群嘅 60 個元素作用
- B₅ 可能係: A₅ 對偶 / 另一群軌道?
- 28 = 唔整除 60 — 唔係群軌道 (群軌道大小整除 |G|=60: 1,2,3,4,5,6,10,12,15,20,30,60)
- **28 唔係 60 嘅因數** → B₅ 補集 28 點唔係 A₅ 群軌道!幾何定義有問題

## 3. ★ 關鍵發現 (開題即見)

**28 唔整除 60** — 若 88 = 60 (A₅) + 28 (B₅ 補集), 且 A₅ 有 icosahedral 對稱
(60 元素群軌道), 咁 B₅ 補集 28 點**唔可能係同群嘅軌道** (群軌道大小必須整除 |I| = 60)。
→ 「B₅ 補集」呢個名稱可能誤導; 88 格幾何需要重新思考。
