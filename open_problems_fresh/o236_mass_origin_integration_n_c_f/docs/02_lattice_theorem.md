## 一、定理陳述（R1 形式化完成）

### T-C 計數引理（相位類佔據）

```
F = {1,2,3,4,5,7,9,11,13} = 前μ²偶 ∪ 前L₄奇 (O137)
佔據模式 n ∈ F 記 (rank%2, n%4)，rank = 排序位置 (O233 γ升序質量階梯)：

(1,1):4  (0,3):2  (1,3):1  (0,0):1  (0,2):1     合計 9
s1 = {1,5,9,13} 全滿 (4/4)   s3 = {3,7,11} (3 個)
s0 = {4} (1)                  s2 = {2} (1)
```

**證明（計數）**: F 嘅奇數部分 = odd ∩ [1,13]。13 = 3·4+1 ⟹ odd ≡1 有
{1,5,9,13} 共 4 個、odd ≡3 有 {3,7,11} 共 3 個（15 > 13 出界）。偶數部分 = 前 μ²=2 個
偶數 {2,4} ⟹ s2:{2}, s0:{4}。⟹ (|s1|,|s3|,|s0|,|s2|) = (4,3,1,1) —— 零自由度。

**對稱破壞引理（C11, 新）**: s1−s3 嘅不平衡由截斷 C mod 4 決定：
C ≡ 1 (mod 4) ⟹ s1−s3 = +1（s1 滿 4）；C ≡ 3 (mod 4) ⟹ 平衡。實測 cutoffs
{9:(3,2), 11:(3,3), 13:(4,3), 15:(4,4)} 全中。

### T-P 奇偶保持引理（s1 子序列 rank 奇偶恆同）

s1 子序列 {1,5,9,13} 內，段間距 (1,5):{2,3,4}=3、(5,9):{7}=1、(9,13):{11}=1
—— 之間 F 成員數**全 odd** ⟹ rank 遞增值全 even ⟹ 奇偶保持；由 rank(1)=1 (odd)
開始 ⟹ **全部 s1 mode rank 奇**。s3 子序列 {3,7,11}：(3,7):{4,5}=2 even ⟹ 翻轉、
(7,11):{9}=1 odd ⟹ 保持 ⟹ rank 奇偶 = [odd, even, even] ⟹ d:(1,3), c/b:(0,3)。

**結論**: (1,1) 全滿 4/4 ＝ s1 全滿（T-C）× s1 全 odd-rank（T-P）兩引理合流 —— 並非偶然。
