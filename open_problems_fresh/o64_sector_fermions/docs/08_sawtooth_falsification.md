## 二、證偽發現

### 2.1 O233 嘅 H0（log-uniform random）係錯誤零模型

```
物理質量唔係 log-uniform random — 有 3 代階層結構 (e 0.5 → t 172690, 跨度 3.4e5)
{O233 用 log-uniform H0 啱 log-space 有 order, 但排除咗「質量有階層」呢個
 最基本物理事實 — 錯誤零模型}
```

### 2.2 正確 H0（保留真實質量值）下完美交替唔顯著

| H0 | P(完美交替) | ✓/✗ |
|:---|:----------:|:---:|
| log-uniform random (O233 原) | 0.0077 | ✗ 依賴唔合理 H0 |
| **真實質量 8! 排列**（固定 γ 指派） | **0.0672** (2708/40320) | ✗ >5% |
| **固定質量 + γ 指派置換** | **0.0733** (2956/40320) | ✗ >5% |
| 先天概率（128 種 7-bit 模式中 2 種） | 0.0156 | — |

```
⟹ 完美交替喺「真實質量」H0 下 P≈7%, 唔顯著 (p>0.05)
     而且 7% > 先天 1.56% — 質量階層反而「偏愛」交替 4.7×
⟹ 鋸齒唔係 C_f 特有結構, 係「質量階層 × A₅ γ網格」嘅必然 zigzag
```

### 2.3 Z₂ rank 分裂（docs/06 更正後嘅「真身」）亦唔顯著

```
even>odd 4/4 喺真實質量排列 H0: P = 0.0414 (1668/40320)
→ p=0.041, 勉強過 5% 但唔穩陣 (同 O233 主張「4/4 係充要條件」嘅結構地位相悖)
雙子序列單調 (even+odd 各自增): P = 0.0001 (6/40320)
→ 但呢個反映「升序指派係結構選擇」而唔係隨機 — 要進一步搞清 (見 §2.5)
```

### 2.4 ★ BIC 決定性比對：C_f 冇鋸齒結構

| 模型 | 參數 | RSS | BIC | 判定 |
|:-----|:----:|:---:|:---:|:----:|
| 純方波 (2 常數) | 2 | 21.15 | 11.94 | ❌ 最差 |
| 兩條線 (each flow) | 4 | 2.07 | -2.49 | 🟡 過擬合懲罰 |
| **單線 (全局)** | **2** | **2.57** | **-4.94** | ✅ **最好** |

```
BIC 最低 = 單線 ⟹ C_f 數據最好由「單條平滑直線」描述
「完美交替」只係「大方向單調增 + 每 pair 細微回落」嘅殘差視覺
+步係大跳 (×11.3), −步係細跌 (×0.73) — 唔係對稱鋸齒
⟹ 鋸齒形狀冇統計地位: 單線模型已解釋 96%+ 方差
```

### 2.5 「子序列單調」係 m/γ 跨度比嘅必然結果

```
m 跨度 (e→b) = 8180× ; γ 跨度 = 115× ; m/γ = 71×
C_f = m/(M₀γ) 全局增長 ~71× ⟹ 任何有序子序列幾乎必然單調增
⟹ docs/06「even/odd 子序列單調」冇獨立內容 — 係跨度比之必然
```
