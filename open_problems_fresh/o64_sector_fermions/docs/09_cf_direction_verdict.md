## 一、方向 A 盲測：斜率 5/7 係 post-hoc 巧合

### 1.1 發現

```
統一 scheme (O234 freeze v2) 下 ln C_f 對 rank 線性回歸:
  斜率 a = 0.714348
  命中 5/7 = 0.714286 (dev 0.009%)  ← 睇落好靚
  e^a = 2.0429（每步倍率）— 呢個先係實質：×2.04，冇靚身份
```

### 1.2 決定性盲測（scripts/08）

```
模型: C_f ≈ C₀·(5/7)^{rank-1}  (r 固定 = 5/7, 零額外自由度)
RMS |ln dev| = 2.4734 → 平均 |dev| = 658% ❌❌
LOO 預言: RMS = 2.8268 → 平均 |dev| = 1007% ❌❌❌

對照:
  e^a 自由斜率 (a=0.7143, 即 ×2.04/步) RMS = 0.5663
  自適應倍率 (AR1) LOO RMS = 1.1778

判決:
  5/7 係「ln 空間嘅 8 點平均斜率」嘅有理近似 — 但 C_f 唔係幾何級數 (5/7)^rank!
  真正倍率係 ×2.04 (≈e^{0.714}, 每步幾乎相同但 rank 1-4 唔跟)
  → 0.7143≈5/7 命中 = 後驗 (post-hoc) 巧合, 冇預言力
  → 方向 A (斜率身份) 正式否證
```

## 二、方向 B 審視：質量比層面

### 2.1 質量比閉合 = C_f 定義嘅重言式

```
m_j/m_i = (γ_j/γ_i)·(C_j/C_i)  — M₀ 完全抵消
C_f 比近結構數 (±2%):
  b/tau C比 = 1.6020 ≈ 8/5 (dev 0.13%) — 但同時大概 φ/11/7/13/8 1.5-2%

  → C_f 比命中冇獨立意義 (C_f 本身冇源, O233)
```

### 2.2 方向 B 結論

```

O64 可交付「質量比表」(零參數, 定義閉合), 但唔係新結構
質量比嘅「結構性」要等質量生成機制 (O209) 先有源頭
```
