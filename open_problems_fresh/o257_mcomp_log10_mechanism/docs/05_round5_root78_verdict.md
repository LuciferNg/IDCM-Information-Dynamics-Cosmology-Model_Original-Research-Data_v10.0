## 一、R5 核心問題

R2/R3 曾重構 M_comp = M_pl·⁷⁶√10/(88³/2)（「無 log 形式」，dev 0.066%），root 次數取 76 = N−hop_max。若 76 喺 log10 修正係後驗（R4），root 次數 76 又是否後驗？

## 二、答案：係——root 形式 76 都唔係帶內最優

```
無 log root 形式 M = M_pl·10^(1/x)/(88³/2), x ∈ [60,100]:
  x=75 dev 0.1075%    x=76 dev 0.0671%
  x=77 dev 0.0277%    x=78 dev 0.0106% ★最優
  x=79 dev 0.0480%    x=80 dev 0.0844%

帶內 |dev|<0.05%: 3 個 x (77,78,79)
帶內 |dev|<0.1% : 5 個 x (76,77,78,79,80)
```

- **root 次數最優 = 78 = N−2F₅ = 88−10**（log 底 10=2F₅ 嘅補數!），dev 0.011%
- 但 76/77/78/79/80 全部 <0.1% 近命中——**帶內連續**，78 唔係「唯一」
- MC null（20000 抽, target∈[5,6]）：x=78 同 x=76 出現率都係 0.01%——揀 78 定 76 都零信息量
- **78 = N−2F₅ 有趣**（log 底 10=2F₅ 嘅 hop 週期補數），但同 76 = N−hop_max 一樣係「身份後配」：帶內所有近命中÷揀有身份嗰個唔係推導
- log10 形式（1/γ₆−1/x）：x*=74.72→75 最優（R4 已判）；結構池 75 dev 0.0009% 都唔係 76

**結論：R4 判死擴大**——唔只「1/76 log10 修正」，連「⁷⁶√10 root 次數」都係後驗。任何單一修正常數（75–80）都係帶內揀值，冇 operator 機制。

## 三、主項缺口（新量化）

```
M_pl·10^{-1/γ₆}（主項, dev vs 校準）= −3.03%
gap = (M_cal − M_main)/M_main = 0.031289
1/gap = 31.960 ≈ 32 = N_d−hop_max（dev 0.124%）
```

- 主項單獨唔閉合（3% 差距）；缺口 1/gap ≈ 32 = N_d−12（hop 補數族又現）
- dev 0.124% = 近對偶唔升格（同 O186 先例）
- 主項 operator 出處 = 1/γ₆（det ratio / propagator），但 10^ 冪仍然係計數壓縮（R2）

## 四、大數對偶恆等（R5b 驗證）

```
88³/2 = 340736 = 11 × 176² = L₅ × (2N)² = L₅ × Πγ(176)   EXACT (dev 0)
Πγ(1..175, 176 譜) = 176² = 30976  (Chebyshev, dev 4e-47)
```

- **對偶鏈譜積表述**：大數 = Lucas₅ × 對偶鏈譜積（R3 嘅 44³×γ₄₄ = N_d³×Πγ_odd 等價重寫）
- 176 = 2N = 4N_d = B·N_d；L₅ = 11 = hop_max−1
- 唔係新數（= 340736），但 operator 表述新增一層：譜積⇄Lucas 對偶
- **注意**：88³/2 = L₅(2N)² 與 R3 88³/2 = N_d³·γ₄₄ 等價（176²×11 = 16·44²·11 = 44³·4）——記為「等價重寫」，唔虛報新恆等

## 六、O257 最終答案

1. **核心問題「1/76 log10 修正嘅 operator 機制」= 假問題**——機制唔存在。76 係誤差階梯掃描產物；所有候選修正常數（74-80）帶內連續，分辨力不足（0.05% ≫ 修正差異 0.003%）。
2. **M_comp 公式誠實狀態**：`M_comp ≈ M_pl·10^{-1/γ₆}`（主項, operator 出處 = 1/γ₆ det ratio）+ 擬合修正（~+3%, 常數後驗）。M_comp 冇「精確 operator 閉合」——有嘅係量級閉合（seesaw）+ 主項 operator 出處。
3. **保留**：seesaw 閉合（m_ν₃ = 53.7 meV ✅）、大數 88³/2 譜積身份（EXACT）、76 自身身份（L₉/N−hop_max/4×19，真身份但唔 support M_comp 修正）。
4. **P6 剩餘項 #2 對應**：「機制唔存在」（falsified），唔係「機制待推」。
