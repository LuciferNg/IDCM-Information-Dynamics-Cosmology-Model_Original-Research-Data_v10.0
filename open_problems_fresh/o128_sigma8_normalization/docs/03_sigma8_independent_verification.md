## 二、獨立路線（閉式代數）

O100 之路線係逐步數值管線（ℓ_m → A_m → D_ℓ → C_ℓ → varT → transfer → Δ² → ΣW²）。
本檔改走**閉式代數**，先化簡再求和：

```
C_ℓ        = D_ℓ·2π/(ℓ(ℓ+1)),          D_ℓ = D₁·A_m
⟨(δT/T)²⟩ = C_ℓ(2ℓ+1)/(4πT_CMB²)
transfer   = (2ℓ²)²                     [δ = 2(k/k_H)²(δT/T), k/k_H = ℓ 恆等]
⟹ Δ²_m = (2ℓ²)²·C_ℓ(2ℓ+1)/(4πT²) = 2·(D₁/T²)·10⁻¹²·A_m·ℓ³(2ℓ+1)/(ℓ+1)
σ8² = Σ_m Δ²_m·W²(k_mR8),   W(x) = 3(sin x − x cos x)/x³
x_m = k_mR8 = ℓ_m·R8/(R_world·h)
```

**結構常數**：`R_world = c/H₀ = 4129.941562 Mpc`（c = 299792458 m/s SI 定義，H₀ = ω_ring = 72.59）、
`h = 0.6727`、`R8 = 8 h⁻¹Mpc`、`T_CMB = 2.72548 K`、`D₁ = 5750 μK²`。

## 四、★ 審計發現（對 O100）

### 4.1 χ* = πR_world 敏感度行**內部不一致**

O100 `scripts/03_sigma8_boss.py`（第 100–103 行）之 χ* 變體：

```python
for chi_name, fact in [("R_world", 1.0), ("πR_world", math.pi)]:
    x2 = k_h*fact*R8
    s8 = math.sqrt(np.sum(Delta2*top_hat(x2)**2))
```

**只改窗函數 argument（x → πx），冇同步改 transfer 係數 2(k/k_H)²。**
但 χ* = πR_world 物理上係 `k_m = ℓ_m/(πR_world)` ⇒ `k/k_H = ℓ/π` ⇒ transfer 必須變 `2(ℓ/π)²`
（Δ² 縮 π⁻⁴），同時窗 argument 變 **x/π**（唔係 πx）。

| 寫法 | σ8 |
|:---|:---:|
| O100 記錄（只改窗，x→πx） | 0.1305084 |
| **正確 χ*=πR_world（transfer 同步）** | **0.22472991** |

**結論不變**（兩者皆脫靶），但 O100 `docs/01` §2 表與 `scripts/03` 之 `0.131` 需更正為
**0.2247**（正確 χ=πR）—— 本檔以 3 條獨立路線確認（`scripts/02` I5a/I5b、`scripts/04` Q/R）。

### 4.2 ℓ_m 公式之 m = 5 例外（脆弱點）

通用式 `44(M − C(9−m,2)) + ((m−1)·9) mod 25` 在 m = 5 給
`44×(33−6) + 36 mod 25 = 1188 + 11 = 1199`，**唔係**觀測值 1121。
O100 `scripts/02` 用手寫例外 `44(M − F₆) + F₈ = 44×25 + 21 = 1121`。

⟹ **ℓ_m 公式有一個手寫補丁**。本檔**只記錄、不裁決**（O83/O9 之推導來源需另核）；
但該補丁係潛在 post-hoc 風險點，應由 O83 側交代其結構來源。
