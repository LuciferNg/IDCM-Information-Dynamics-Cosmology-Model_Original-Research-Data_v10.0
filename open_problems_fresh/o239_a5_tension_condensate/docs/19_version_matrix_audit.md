## 四、版本依賴數據使用規則（audit 結論, 記入 SESSION_START）

1. **每次引用跨版本數字必須標版本 tag**——`PDG2024` / `freeze_v1.0` / `freeze_v1.1` /
   `freeze_v2` 四選一, 禁止裸數字。
2. **主線結論一律 freeze v1.0**（O239 全鏈 = O206 MASS = data/09, 已歸一）。
3. **其他版本只準做「對照/敏感度」**, 且必須同 script 同段標明——scripts/12 S3、
   scripts/13 RGI ensemble、scripts/22 B5 已符合。
4. **local 級結構（單點斜率等）跨版本比較係誤導源**——μ local 示範: 同一量三個版本
   三種判決（2.4/10.0/6.3σ）。細 scale 量必須 freeze 層內判。
5. **freeze v3（lattice 直量 1-2%）**冇解決「版本選擇」問題, 係解決「版本內誤差」——
   版本框架照舊 v1.0 主 + 對照。
