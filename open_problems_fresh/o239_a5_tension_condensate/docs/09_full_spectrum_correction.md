## 二、結構判讀

### A 部分: 冪律區 = 質量模態區（n≤13）

```
n=1..13:  β=−1.828±0.045, R²=0.9934   ← 冪律區（9 質量模態全喺度）
n=1..22:  β=−2.499±0.301, R²=0.775    ← 開始偏離
n=1..88:  β=−0.223±0.271, R²=0.008    ← 非冪律
```
- 最遠離線係 n=44/88（|dm| 暴漲 1.3e5/5.0e4 = 駐波節點）同 n=22（|dm|=0.26 谷）
- **「質量 = 冪律區選模」**: IDCM 9 費米子模態（1,2,3,4,5,7,9,11,13）全部落喺 θ↔|dm| 冪律區——呢個係「質量模態點解係呢啲 n」嘅**必要條件**結構（唔係充分, 區內仲有 6,8,10,12 非質量）

### B 部分: 合成殘餘 ∝ 能量（高能時空離散效應）

```
差對（d7~1e-4）: (1,2),(1,3),(1,5),(1,6),(2,4),(2,5),(1,12),(2,7),(2,6),(1,10)
  全部 η_sum > 5.5（細 n = 高 rapidity = 高能）
好對（d7<1e-8）: (11,41),(27,43),(40,41),(9,34),(14,22)
  全部 η_sum 中等/大 n（低能區）
```
- 「η_a+η_b 唔落格」嘅精確性**唔均勻**: 高能合成殘餘大, 低能殘餘可忽略
- 物理意義: 離散時空（88-gon 階梯）喺高能量端嘅「格子誤差」最大——**同 DSR/κ-Poincaré 嘅物理動機一致**（高能探測離散性）, 但**唔係** DSR: O239 已證殘餘仍收斂（冇非封閉鎖死）, 所以唔需要變形色散; 只有「殘餘隨能量分佈」呢個可量度結構
- **可證偽預言**: 若 freeze v2 或觀測能分辨「合成精度随能量退化」, 應見 d(η_sum) 單調關係
