## 〇、背景（docs/03 §六 誠實缺口）

同 88-gon 相位格（θ_n = nπ/88）冇整除關係」——β 嘅「10」同 88 之間冇整數橋。

## 一、P1: β 位置 = 8.8 步 EXACT（dev 5.6e-17）

scripts/23 重跑（**θ 格 = nπ/88, IDCM PAIR 定義**）:

```
β = sin(π/10); θ 格步長 = π/88
β 位置 = (π/10)/(π/88) = 8.8 步 = 88/10
sin(8.8·π/88) = 0.309016994374947 ≈ sin(π/10)   dev = 5.6e-17  ✅ EXACT
```

**對照（全圓步長 π/44 = 2π/88）**: sin(4.4·π/44) = sin(π/10), 同樣 dev 5.6e-17——
4.4 步 = 88/20（20△ 挫阻面數）。兩個計法係同一相位 π/10 嘅兩種步長單位,
**θ 格（π/88）先係 IDCM 定義**, 全圓步（π/44）只作對照。

```
P1 判決: β 唔需要整除 88——佢係「88/10 步」, 啱好係 88-gon 每 10 個相位格一次
        （而 88/20 = 4.4 步對應 20△ 面結構）
```

## 二、P2/P3: 結構身份

```
P2: 88/20 = 2L₅/F₅ = 2×11/5 = 4.4
    β 單位 = 「88-gon 步長 × 88/20」——20△ 挫阻面數係相位分母
P3: 72°（⬠ 面角）= 88/F₅ = 88/5 = 17.6 步（88 步 = 360°, 1° = 88/360 步）
    ——⬠ 面角都係結構分數步, 同 β 同一語言
```

## 三、P5: 冇整數步替代

全 θ 格窮舉（n=1..87）: **最近整數步 n=9, dev = 0.0068（2.19%）**——冇任何整數步
啱好命中 sin(π/10)。β 位置 8.8 步係**真分數步**, 唔係整數格點巧合。

**盲測聲明**: 恆等 sin(8.8π/88) ≡ sin(π/10) 係代數 boolean 事實（dev 5.6e-17, 零擬合）;
「8.8 步 = 88/10」嘅結構連結係後見命名（啱好 = β 分母 10）, 唔係預寫新預言。
