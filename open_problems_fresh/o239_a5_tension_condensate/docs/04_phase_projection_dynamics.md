# O239 docs/04 — 相位投影動力學:移動=相位旋轉 ⟹ γ=cscθ 與質量=非線性阻力

> **日期**: 2026-10-12 (第四輪)
> **來源**: 調律者問題「空間移動即是相位旋轉, 咁質量就唔過係兩個點旋轉時產生嘅非線性阻力; 或者話如果移動只係旋轉, 點解速度越快加速所要嘅能量越大?」
> **性質**: prior-proved 數嘅直推（O180 v_k=c·cosθ_k dev1e-60 + O237 U4 γ_n=|1−U|² + 三角恆等）——**冇新可調參數, 冇新預言; 係一致性重述 + 機制 re-frame**

---

## 〇、一句話

**如果速度 = 光速嘅相位投影(v = c·cosθ, O180 已證), 咁 Lorentz factor 就係相位餘割 γ = cscθ, 相對論縱向質量 m·γ³ 直接由 dp/dv 推出, 加速成本 dE/dv → ∞ 係 cos 投影喺頂點效率歸零嘅幾何必然——「加速越嚟越難」唔係神秘效果, 係投影幾何; 質量 = 兩點(1 與 U_n)旋轉分裂嘅弦長 = sin(θ/2) 非線性阻力(O237 U4)。**

---

## 一、推導鏈（全部已證結構）

### 1.1 前置定理（不重推）

- **O180**: `v_k = c·cosθ_k`（FSR 速度階梯, dev 1e-60）; `r_k = 2πR_world·cos²θ_k` ⟹ `v_k² = a₀r_k EXACT`; `a₀ = (c/π)²·∇θ`
- **O237 U4**: `γ_n = |1−U_n|²`, `U_n = e^{inπ/44}`; `m_n = M₀·|1−U_n| = M₀·2sin(nπ/88)`（弦長 = 相位差嘅非線性函數）
- 三角恆等: `cos²θ + sin²θ = 1`

### 1.2 推導：γ = cscθ

```
v/c = cosθ
⟹ 1 − (v/c)² = 1 − cos²θ = sin²θ
⟹ γ = 1/√(1−v²/c²) = 1/sinθ = cscθ        【Lorentz factor = 相位餘割】
```

### 1.3 推導：加速效率 dv/dθ 歸零

```
dv/dθ = −c·sinθ
θ→0 (v→c): sinθ→0 ⟹ dv/dθ→0
```
同一相位步 dθ 產生嘅速度增量縮細——cos 曲線頂部平坦 ⟹「越推近天花板, 投影效率越低」。

### 1.4 推導：加速成本發散（動能/動量/縱向質量）

```
E = γmc² = mc²·cscθ            （能量 = 相位餘割, θ→0 爆升）
p = γmv = m·cscθ·c·cosθ = mc·cotθ
dp/dv = (d/dθ mc·cotθ)/(dv/dθ) = (mc·(−csc²θ))/(−c·sinθ) = m·csc³θ = m·γ³   【縱向質量】
dE/dv = mc·cosθ/sin³θ → ∞      （θ→0）
```

「速度越快, 加速所需能量越大」= **投影頂點幾何**: 速度係相位嘅 cos 投影, 投影喺 θ→0 效率歸零, 能量成本發散。

### 1.5 質量 = 兩個點旋轉嘅非線性阻力（調律者第一句）

```
m_n = M₀|1−U_n| = M₀·2sin(θ_n/2)
|1−U|² = 2−2cosθ = 4sin²(θ/2) = γ_n
d|1−U|/dθ = cos(θ/2)            增長率隨 θ 變, 愈遠愈慢
```
- 「兩個點」= 單位圓上嘅 1（identity/同步）同 U_n（第 n 步相位旋轉）
- 「非線性阻力」= 弦長對相位差係 sin(θ/2), 唔係線性
- 質量 = 旋轉分裂嘅弦 = 相位差嘅非線性可測量

### 誠實缺口

1. **θ ↔ rapidity 未正式接**:
   - O180 θ_k = 88 模態幾何角; 相對論 rapidity η: v = c·tanhη ⟹ γ = coshη
   - 兩個參數化同胚（cos 同 tanh 都係 [0,c]→[1,∞) 嘅單調映射）, 但**未證明 IDCM θ = rapidity**——可能只係「同一個 kinematics 兩種坐標」
   - 判別: 若 θ = rapidity, 咁 cosθ = tanhη 對應嘅加法律/速度合成應自動成立; 若只係同胚, 合成律就要另行驗證
2. **「加速成本」嘅物理接線**: dp/dv = mγ³ 係 kinematics 重述; 真正嘅「加速」要 F = dp/dt, 而 dt 喺 IDCM = tick = T_ring/88（O237 docs/02 §1.6 已證時間標）——「相位步/時間」先係動力學, 未併入本鏈
3. **88 格離散 vs 連續 θ**: O180 得 88 個模態角; 連續 rapidity 空間嘅嵌入未建
