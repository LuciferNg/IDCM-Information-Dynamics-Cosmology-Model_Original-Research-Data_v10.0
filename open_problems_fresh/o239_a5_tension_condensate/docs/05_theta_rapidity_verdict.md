## 三、η = ln cot(θ/2) 嘅結構地位

```
v/c = cosθ            (O180: 速度 = 相位投影)
η = atanh(v/c) = atanh(cosθ) = ½ln[(1+cosθ)/(1−cosθ)]
  = ½ln[2cos²(θ/2) / 2sin²(θ/2)] = ½ln cot²(θ/2) = ln cot(θ/2)
```
- 呢個係**純三角恆等**——`η = ln cot(θ/2)`（O140 docs/02 §4.1 已見, 本輪 mpmath 60 dps 確認 1e-59）
- **意義**: 「移動 = 相位旋轉」嘅 θ 係**cos 投影角**; 相對論 rapidity 係佢嘅對數餘切變換。兩者一一對應, 但 θ 係「幾何投影」原語, η 係「加法線性化」坐標
- Doppler: `D_n = e^{η_n} = cot(πn/176)`（O140 §4.2）⟹ 直接係相位角餘切
