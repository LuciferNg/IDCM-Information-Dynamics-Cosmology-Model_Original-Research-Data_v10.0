## 二、★★關鍵證據: 三點讀法檢定

```
33 (Up)    : 含 3/16 二項分解 = 冇
26 (Down)  : 含 3/16 二項分解 = 冇
19 (Lepton): 含 3/16 二項分解 = 3+16 ✓

**N_gen+B² 係「單點專用」讀法**——佢只解釋 19, 唔解釋 33/26。

## 三、60 = |A₅| 嘅角色(冇非平凡)

- |A₅| = 60(O223: |GeoAut|=60 手性 I; O137: I 對 60 軌道正則; 88-gon=A₅ 網 O182)
- 19/60 = 0.316667: A₅ 份額讀法存在

- 60/4 = 15 = N_gen·F₅ = 3×5: 平凡拆解(60 永遠可除 4)
- 19×60/4 = 285 = 3×5×19: 非標準 IDCM 數(非 Fib/Lucas/44 因數)
- ⟹ **60 對 γ 冇非平凡角色**——「19/60 投影預算」係另類讀法, 唔係 γ 結構

## 四、γ 嘅「分枝預算」讀法(N5, 誠實檢查)

```
γ_new = −(N_gen + B²)/B = −19/4
      = −B − N_gen/B = −4 − 0.75 = −4.75

「4 係分枝預算」可以讀做: γ = −B(附帶 N_gen/B 修正)——但呢個冇 stair 上下文,
同 3+16 一樣係單點巧合讀法。
