## 三、「越快加速越難」嘅離散力學（G3-G5）

每 tick 相位步 Δα = π/44 固定（世界旋轉, 不能變）:
```
Δp/tick = mc·Δcotθ ≈ mc·(−csc²θ)·(π/88)   — θ→0 (v→c) 時 → −∞  (動量注入發散)
Δv/tick = −c·sinθ·π/88                     — θ→0 時 → 0          (速度增益歸零)
加速成本 = ΔE/Δv ∝ csc³θ → ∞
```
數字實例（同一 tick, 同一相位步）:
- 高速區（θ=2.05°, v=0.9994c）: Δv=0.0019c / tick, ΔE=−14.0 mc² / tick
- 低速區（θ=40.9°）: Δv=0.0239c / tick, ΔE=−0.0595 mc² / tick

**「點解速度越快加速所需能量越大」答案: 相位步固定, 但 cot 函數嘅斜率 csc²θ 喺 θ→0 發散——喺 cos 頂部推相位, 動量注入爆漲而速度增益消失。**

## 四、γ 上限 = 相位 Nyquist（G6, 可證偽預言）

```
γ_max(ℓ) = csc(π/(88·4^ℓ))                minimal 可辨相位 = π/(88·4^ℓ)
         ≈ (88/π)·4^ℓ
ℓ=0: 28.017   ℓ=1: 112.0   ℓ=2: 448.2   ℓ=3: 1792.7 (×4 每層)
```
- 「c 不可達」唔係公設, 而係**離散相位步嘅 Nyquist 極限**: 最小可辨相位 = π/88（44 模態 88-gon 半格）, γ 最大 ≈ 28
- 加速到更高 γ 必須**升層**（ℓ 遞增, O140 FSR 尺度精化）: 每層 γ 上限 ×4
- **可證偽**: 若觀測 γ > γ_max(ℓ) 而冇升層機制 → 結構錯。現有宇宙射線 γ~1e11 對應 ℓ~15-16（(88/π)·4^15 ≈ 3.7e10, 4^16 ≈ 1.5e11）——量級吻合 FSR 層結構（非新預言, O140 已有）
