## 問題回顧

節點 9 (l=214.92°, b=-31.16°) 喺 SMICA 4.17° 平滑下溫度 **-106.99 μK**，係全場第二冷節點（僅次冷斑節點 0 = -134.19 μK）。但佢嘅著色係 **熱色 (color=0)** — 因為 hop=1, 所以 `color = 1 - (hop % 2) = 0`。

**核心問題**: 點解一個 hop=1 節點（冷斑嘅直接鄰居）會係全場第二冷？係巧合、結構定前景？

---

## 分析方法

### 1. GRF Bootstrap @ 4.17° (10,000 實況)
- 從 SMICA 4.17° 平滑地圖計算 Cℓ 功率譜
- 生成 10,000 組高斯隨機場，以 60 個 A₅ 節點抽樣
- 雙重條件: 第 2 冷節點 T ≤ -106.99 μK **AND** hop=1 **AND** color=0

### 2. GRF Bootstrap @ 10.0° (10,000 實況)
- 同上，但分析第 1 冷（Node 9 喺 10° 係全場最冷）

### 3. 測地線剖面 (0°→9°)
- Slerp 插值 200 點沿大圓弧
- 提取 1.0°/3.0°/4.17° 平滑下嘅溫度剖面

### 4. 交叉地圖驗證 (SMICA × NILC × Commander)
- 從 PLA 下載 NILC/Commander 原始地圖 → 平滑至 4.17° → 比較節點 9

### 5. 透明度框架延伸驗證
- P1: Hop=1 節點集體高斯一致性
- P2: Frustration vs Normal edge |ΔT| 拓撲信號
- P3: BFS hop 層 GRF 透明度對照
- P4: 所有 hop 層喺 10,000 GRF 中嘅極端概率

## 結果

### 1. Bootstrap @ 4.17°

| 量 | 值 |
|:---|:---|
| 第 2 冷分佈 mean ± std | -86.09 ± 14.35 μK |
| Node 9 觀測 | **-106.99 μK** |
| z-score | **-1.46σ** |
| P(T_2nd ≤ -107 μK) | **8.2%** (818/10000) |
| P(hop=1 ∩ color=0 \| T_2nd ≤ -107) | 7.7% |
| 隨機期望 (hop=1 ∩ color=0) | 6.7% (4/60) |
| P_joint | 0.63% (63/10000) |

**結論**: Node 9 嘅溫度作為第 2 冷節點只係 -1.46σ，p=8.2% — **唔顯著**。拓撲條件 (hop=1, color=0) 冇增加顯著性：條件概率 7.7% 接近隨機 6.7%。

### 2. Bootstrap @ 10.0°

| 量 | 值 |
|:---|:---|
| 最冷分佈 mean ± std | -80.28 ± 15.48 μK |
| Node 9 觀測 | **-90.3 μK** (rank 1/60) |
| z-score | **-0.65σ** |
| P(T_coldest ≤ -90 μK) | **23.2%** |
| P(coldest is node 9) | 0.40% (隨機: 1.67%) |
| P(coldest is hop=1) | 1.6% (隨機: 6.7%) |

**結論**: 即使 Node 9 喺 10° 係全場最冷，z = -0.65σ 完全唔顯著。最冷節點係 hop=1 嘅概率 (1.6%) 低於隨機期望 (6.7%) — 拓撲條件冇貢獻。

## 透明度框架 — 理論整合

### 核心結構

```
A₅ 晶格 = 120 條邊
  ├── 32 條 Frustration 邊 (同色) → 不透明 🟥 → 拓撲信號載體
  │   └── 冷斑 (node 0): 全場最冷 -134.19 μK
  │   └── ΔE=0 節點 (12 個): 振幅抑制 ~0 μK
  │   └── |ΔT| gap 18.64 μK (p=0.0164)
  └── 88 條 Normal 邊 (異色)     → 透明 🟩 → CMB 穿過無修改
      └── Node 9: 高斯隨機 (z=-1.46σ, p=8.2%)
      └── Hop=1 集體: 高斯一致 (p=0.28)
      └── 所有 hop 層: 高斯一致 (全部 p>0.05)
```

### Node 9 喺框架中嘅位置

Node 9 嘅 4 條邊全部係 normal bichromatic（鄰居 nodes 0, 16, 33, 58 全部冷色）：
- 佢位於 **透明區域** — 冇拓撲缺陷
- 佢嘅 -107 μK 係 **CMB 穿過透明晶格嘅正常隨機漲落**
- 唔係巧合，而係**晶格結構預言 hop=1 節點應該透明**
