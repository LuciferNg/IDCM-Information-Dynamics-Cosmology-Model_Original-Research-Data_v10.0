## 二、核心定理

### 定理陳述

給定 K_Chain 44-site 結構及 CY₃ 關係：

| 量 | 公式 | 數值 | 來源 |
|:--|:-----|:----:|:-----|
| h¹¹ | N_gen × 12 | 36 | O53: 3×12 Schur block-triangular |
| h²¹ | B×L₅ + N_gen × L₆ | 98 | O56: Lucas 分解 |
| h²¹−h¹¹ | Nd + L₆ | 62 | O56: 結構約束 |

則 **N_gen = 3 被 h²¹−h¹¹ = Nd+L₆ 強制鎖定**。

### 證明

```
h²¹ − h¹¹ = (B×L₅ + N_gen×L₆) − N_gen×12
          = 44 + N_gen×18 − N_gen×12
          = 44 + N_gen×6

但 h²¹ − h¹¹ = Nd + L₆ = 44 + 18 = 62

所以: 44 + N_gen×6 = 44 + 18
     → N_gen = 3
```

