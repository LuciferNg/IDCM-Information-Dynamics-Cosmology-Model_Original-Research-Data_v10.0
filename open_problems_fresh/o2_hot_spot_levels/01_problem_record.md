# O2: 熱斑等級驗證 — Fibonacci 等級熱斑 SMICA 掃描

## 問題陳述

IDCM 冷斑閉合: 冷斑 = 5×RMS = F₅×ε⁵/8 = -150μK。Fibonacci 等級結構預測更高級熱斑:

```
RMS (1×)  = 30.0 μK
F₃ = 2    = 60.1 μK
F₄ = 3    = 90.1 μK
F₅ = 5    = 150.2 μK (冷斑, 已閉合 ✅)
F₆ = 8    = 240.3 μK (熱斑預測)
F₇ = 13   = 390.4 μK (更強)
F₈ = 21   = 630.7 μK
```

**O2 目標: 用 Planck SMICA 真數據搵出 F₆/F₇/F₈ 等級熱斑, 驗證 Fibonacci 等級結構!**
