## 零、問題

O175 已閉合「星系盤角動量來源 = 相位繞數」(θ_k = kπ/176 均勻梯度, Wilson = i,
winding 22.25 = F₁₁/4, Noether Q = 44 守恆, 寫入每圈重鎖), 但**到星系盤空間投影嘅
嚴格場論翻譯未做**:

1. j_spec = √a₀·R_c^{3/2} = 19,867 km/s·kpc 需要**投影核 K(ℓ)** 嚴格定義 —
   相位繞數點樣變成盤旋轉速度場 v(r)?
2. **ψ_k(1) 邊界值機制** (O158 系): 鏈模態 ψ_k 喺空間邊界嘅值點樣編碼相位梯度?
3. 「有序旋轉 = 相位鎖定 = 低熵」目前係**定性**陳述 (O175 docs/04 Part F) —
   需要定量: 相位鎖定能量 / 鬆弛時標 / 角動量守恆嘅場論表述

## 一、攻堅路徑 (docs/01 詳細)

1. 投影核: 88 模態 → 盤坐標 (r, φ) 嘅 Fourier-Bessel 投影 (O140 FSR 譜)
2. ψ_k(1) 邊界值: Dirichlet-Dirichlet BVP (O159) — 邊界相位 = 寫入重鎖點
3. 要求: 投影後 azimuthal 速度場 v_φ(r) ∝ √(a₀r) (RAR 平軌, O32) — j_spec 由投影核積分出
4. 判準: 零新常數; 重現 j_spec = 19,867 (唔係 fit); 可證偽 (盤速度場形狀)
