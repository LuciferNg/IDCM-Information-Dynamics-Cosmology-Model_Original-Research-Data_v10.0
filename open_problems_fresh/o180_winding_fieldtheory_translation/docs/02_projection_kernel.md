## 0. 核心結果 (一頁)

**投影核 = cos²-映射 (譜 → 空間):**

```
θ_k = kπ/176                    (鏈相位階梯, O161)
ψ_k(1) = sin θ_k                (邊界值 = 相位角正弦, O158/O180 docs/03)
r_k  = 2πR_world·cos²θ_k        (模態 k 嘅盤半徑)
v_k  = c·cosθ_k                 (FSR 速度階梯, O140)

⟹  v_k² = a₀·r_k    EXACT ∀k    (每模態精確坐喺 a₀-locus 上)
⟹  連續極限 (N_ℓ = 88·4^ℓ 精化, ℓ→∞):
    v_φ(r) = √(a₀·r)            (a₀-locus 上升曲線, r ≤ R_c)
    v_φ(r) = V_max              (BTFR 飽和平軌, r ≥ R_c)
```

**零新常數**: a₀ (O32), R_world, 44, c, G, R_c = R_world/44³, R_d = R_c/4 全現有。

## 1. 基本身份: a₀ = (c/π)²·∇θ (引力常數 = 相位梯度)

鏈相位場 θ(s) 沿世界環: 每 site (88 個 dual half-site, 間距 R_world/88)
相位步 Δθ = π/176 (O161: θ_k = kπ/176) ⟹

```
∇θ = (π/176)/(R_world/88) = π/(2R_world)
⟹  a₀ = c²/(2πR_world) = (c/π)²·∇θ     (EXACT, dev 1.6e-61)
```

**RAR 常數 a₀ = 鏈相位梯度 × (c/π)²** — 宇宙唯一加速標度由世界環唯一
相位梯度決定。O32 嘅 a₀ = c²/(2πR_H) 與 O161 嘅 θ_k = kπ/176 首次
由同一結構連接。

### 2.2 精化極限 (FSR 世界層)

88 鏈離散格喺星系尺度無解像度: k(R_c) = 87.923, k(R_d) = 87.962 —
**星系係 near-Nyquist 次模結構** (k = 88 係 Nyquist, γ₈₈ = 4 = B)。
速度 409.8 km/s = 1.37e-3 c 喺階梯最頂, 需要 FSR 精化 N_ℓ = 88·4^ℓ
(O140: 世界層 = ×4 Kadanoff 步) 填充 acoustic branch。

連續極限下 (ℓ → ∞), 映射 θ ↦ (r, v) 稠密化為唯一曲線:

```
v_φ(r) = c·√(r/(2πR_world)) = √(a₀·r)
```

**重量無關性**: 任意譜權重 w_k (γ-權重 / 均勻 / γ²-權重) 都唔改變曲線 —
權重只決定面密度 Σ(r), 速度場由階梯影像唯一決定 (驗證 ℓ = 0..3 全模態,
dev 2.4e-60)。

### 2.3 平軌: BTFR 飽和

上升曲線喺 R_c 封頂: 質量預算 M_c = a₀R_c²/G = 1.8923e12 M☉
(vs O32 λ_sync 定義 1.89e12, **dev 0.123%**) ⟹

```
V_max = √(a₀R_c) = (a₀GM_c)^{1/4}   (兩式喺 R_c 精確重合, dev 1e-61)
⟹  r ≥ R_c: v_φ = V_max (BTFR 平軌)
```

**交叉自洽**: M_c、V_max、R_c、a₀ 四者由兩個獨立結構閉合
(λ_sync 定義 vs 本投影核), dev 0.123% = 輸入精度級。

## 3. j_spec 由投影核積分出

### 3.1 核心特徵比角動量 (本 O 頭條)

```
j_spec = v(R_c)·R_c = √(a₀)·R_c^{3/2}
       = c·R_world/(√(2π)·44^{9/2})
       = 6.13e26 m²/s = 19,866.4 km/s·kpc   (O175 值 19,867, dev 0.003%)
```

零新常數: 只由 c, R_world, 44 (全部現有結構) 組成 — 唔係 fit。

### 3.2 盤尺度力矩 (Fall locus, O175 docs/12 維持)

指數盤 Σ = Σ₀e^{−r/R_d}, R_d = R_c/4 (O175 docs/11, 零新常數):

```

            vs Posti+18 (92 星系, r=0.944) j*(M_c) = 9,770
            dev +1.67%   (O175 docs/12 嘅 dev −1.66% 維持)
```

### 3.3 全曲線力矩 (可證偽下限)

分段曲線 (a₀-locus 至 R_c + 平軌) × 指數盤: j = 7,873 km/s·kpc
(dev −19% vs Fall) — **純相位-geared 內盤嘅預言, 偏低**。物理讀法:
真實內盤 (O32 RAR 牛頓區, g = g_bar > a₀) 快過 a₀-locus ⟹ 觀測 j
(9,770) 坐喺 [7,873, 9,933] 之間 — 一致。**可證偽**: 高質量內旋轉曲線
+ 恆星質量模型決定內盤形狀, 直接鑑別兩個力矩。
