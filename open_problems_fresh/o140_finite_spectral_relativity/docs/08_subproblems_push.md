## 1. O140/velocity-composition — 加速合成群結構

### 1.1 No-go 定理 (數值窮舉驗證)

快度階梯 η_n = ln cot(πn/4N)。SR 合成 = 快度加法 η_a + η_b。

**定理**: 有限階梯喺 SR 合成下唔封閉。減去 identity rung (n=44, η=0, 靜止參考系) 後, N=44 全部 946 個非平凡對, **0 對**落喺階梯 (|n'−round|<1e-9)。最近距離: (a=1, b=26) → n' 偏差 8e-4。

```
0 封閉對 / 946 總對 (排除 (a,44) identity)
只有 ℓ→∞ 連續極限先回復封閉性
```

**結構結論**: 唔存在有限距離黎曼群覆蓋 N 個離散 boost。呢個係 FSR 離散性嘅本質代價——快度加法精確 (加法群 ℝ), 但可觀測 rung 係離散採樣。

### 1.2 投影合成 (⊕_FSR) — 定義

```
⊕_FSR(a,b) = proj(η_a + η_b)      proj = 投影到最近 rung
```

- **誤差上界**: max|n'−round(n')| = 0.4994 < 0.5 (即唔會跳過 rung)
- **質量殼保持**: 投影後仍用階梯值 (E²−p²c²=m²c⁴ 精確, 所有 1035 對通過)
- **associativity**: 快度層係精確加法群 (ℝ,+), 投影係單值函數 ⟹ 三體合成唯一 (29³ 組合, max 偏差 3.55e-15)
- **詮釋**: 快度加法係「精確數學層」, 投影係「測量量子化層」——同 QM 嘅測量投影一致

### 1.3 κ-Poincaré 路線裁決

Gemini/文獻建議 κ-Poincaré coproduct 變形。**本攻堅顯示唔需要**: 快度加法本身已經精確 (ℝ 群), 缺嘅只係「階梯封閉性」, 而呢個係測量層嘅離散投影, 唔係動力學變形。階梯 = 可觀測本徵值, 投影 = 測量量子化。

**狀態**: 🔴 → 🟡 (投影合成已定義, no-go 已窮舉; 剩: ⊕_FSR 嘅 associativity 檢查)

## 3. O140/k-n-dual-index — 質量-速度雙指標

### 3.1 E² = (2mc²)²/ε_n — 能量平方反比特徵值

γ_n = csc(πn/2N) = 2/√ε_n ⟹ E_n² = m²c⁴csc² = **4m²c⁴/ε_n**

驗證 (n=1,11,22,44): 精確到浮點。能量平方 = 特徵值倒數×常數——**離散質量殼嘅譜形式**。

### 3.2 統一算符: E_{k,n} = 2M₀c²√(ε_k/ε_n)

m_k = M₀√ε_k (譜幾何質量候選) ⟹

```
E_{k,n} = m_k·γ_n = 2M₀c²·√(ε_k/ε_n)
```

驗證: (k=1,7,20)×(n=1,22) 全部精確, E_{k,n}=m_k·γ_n 一致。

### 3.3 雙指標 = 特徵值比值, 唔係兩個獨立量子數

|k,n⟩ 嘅本質係 ε-譜上兩個點嘅**比值**。證據:
- ε₇/ε₂₀ = 0.142618 = n/p (BBN 跨域閉合) — 質量比 = 特徵值比
- γ₇²γ₂₀² = 16/(ε₇ε₂₀) — Lorentz 因子平方 = 特徵值乘積倒數 ×16
- 兩個指標共享同一 ε 譜 — 質量維 (k) 同速度維 (n) 係同一算符嘅兩個投影

**狀態**: 🔴 → 🟡 (譜形式已導, ratio 結構已證; 剩: collective sector 算符結構、m_k=M₀√ε_k 嘅質量表校準)
