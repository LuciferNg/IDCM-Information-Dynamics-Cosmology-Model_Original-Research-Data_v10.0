## 結論：ζ_N(s) 對所有正整數 s 都有有理多項式閉式

```
ζ_N(s) = Σ_{k=1}^N ε_k^{-s} = Σ csc^{2s}(πk/2N)/4^s
       = N^{2s} 次有理多項式  (對所有 s, 奇偶一樣)
```

**關鍵結構觀察（v1 擬合失敗嘅教訓）**：
- ε_k^{-s} = csc^{2s}(πk/2N)·4^{-s}——**即使 s 奇，csc 冪 2s 係偶數**
- Σ csc^{2m}(πk/2N) 係 N 嘅 2m 次有理多項式（Euler/Bernoulli 結構）
- ⟹ 冇「奇 s 例外」，docs/08 判斷錯嘅原因就係喺 csc 冪睇漏咗 2s 係偶數
