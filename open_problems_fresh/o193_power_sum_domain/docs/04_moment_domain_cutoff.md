# O193 docs/04 — moment-domain Nyquist cutoff (n < 88): 物理/觀測對應

> 2026-09-14 · scripts/04 (U08-U14) · 接 O76 P4 (z>17), O140 FSR, O138 (F_proj=17)
> (header 日期由 09-13 更正 — scripts/04 同 docs/04 實際寫於 09-14)

## 一句話本質

n < 88 = **矩確定性邊界**: 88 個矩 (n = 0..87) 唯一決定 88-atom 測度 —
閉式 (arcsine 連續) 同離散測度嘅資訊內容恰好重合 88 個矩, 第 89 個矩 (n=88)
開始 aliasing。同 z > 17 (投影到環對面) 平行: **兩個都係「結構閉式嘅精確域
= 鏈嘅 Nyquist 容量」**, 一個喺紅移階 (z), 一個喺關聯階 (n), 一個喺溫度階 (β)。

## 一、矩確定性: 資訊內容 = 鏈長 (scripts/04 U08-U09 ✅)

```
88-atom 測度 (等權, 位置固定 γ_k = 4sin²(kπ/176)):
  - 自由參數: 0 (位置同權重全由鏈結構定)
  - 矩 n = 0..87 同 arcsine-on-[0,4] 連續測度完全一致 (O193 譜定理)
  - n = 88: odd sector 首個偏差 dM = −88·C(2n, n−88) (j=88 諧波, rel dev 3.5e-52)
```

- **詮釋**: 閉式 (arcsine 矩) 唔係「無限精確」— 佢同離散測度喺首 N 個矩上不可分辨
  (矩確定性: 有限測度由首 2N 矩定, 等權固定位置 ⟹ N 個矩已夠), n ≥ 88 嘅矩
  **唔再攜帶新資訊** — 閉式公式撞到離散性嘅信息邊界
- **類比採樣定理**: N 個採樣點攜帶 N 個獨立數字; 第 N+1 個「採樣」(矩) 係
  連續重構嘅混疊 (aliasing) — 同 Shannon-Nyquist 同構

## 二、同 z > 17 平行 (scripts/04 U10-U12 ✅)

| | z-domain (O76/O140) | moment-domain (O193) | β-domain (O193) |
|:---|:---|:---|:---|
| 結構閉式 | D_app(ℓ), 1+z = 4^ℓ | Σγ^n = 88C(2n,n) + 2^{2n−1} | Z = e^{−2β}[N·I₀(2β)−sinh(2β)] |
| 精確域 | z < 17 = L₆−1 (F_proj) | n < 88 = 2N_d | β ≪ N² = 7744 |
| 斷裂機制 | 投影到環對面 ℓ_max = log₄18 = 2.085 | j=88 諧波共振 (1e-52) | I₁₇₆ aliasing 階梯 |
| 觀測對應 | JWST: z>17 源唔應存在 (O76 P4) | n≥88 關聯不可預言 (結構上) | 高溫區 Bessel 精確 |
| 鏈容量 | 1+z ≤ L₆ = 18 (最後可分辨 ℓ 階) | n ≤ N−1 = 87 (最後獨立矩) | β < N² (最後無混疊溫度) |

- **同源**: 離散譜嘅「頻率內容」(z 階 ℓ / 矩階 n / 諧波階 j) 撞鏈長 (N=88, 2N=176)
  — 閉式公式嘅參數超過鏈 Nyquist 容量 ⟹ 公式斷
- z>17 嘅 17 = F_proj = L₆−1 (O138/O143), 1+z_max = 18 = L₆; ℓ_max = log₄18 = 2.08496
  (O76 記 2.08 係四捨五入; D_app(ℓ_nyq) ≈ πR_world, ratio 0.9990 — O76 自洽)
- moment-domain 嘅 88 = 2N_d (觀察者維度 = 鏈長) — 同 z-domain 嘅 L₆ 不同數值但同角色:
  **公式有效域 = 鏈結構數**

## 三、EFT 對應: n 階矩 = n 點關聯 (scripts/04 U13 ✅)

```
n=2: 方差 (功率譜 C_2 / power spectrum)
n=3: 三點關聯 (bispectrum)
n=4: 四點關聯 (trispectrum)
n ≥ 88: 高階關聯超越 88-site 晶格分辨率 — 閉式斷裂 (aliasing 壓制 1e-52)
```

- **同 EFT**: 維數 ≥ 截斷嘅算子係 irrelevant (被截斷壓制, 結構上不可預言) —
  n ≥ 88 嘅關聯函數就係「超越晶格截斷嘅不可約算子」, 佢哋嘅值受離散性混疊,
  閉式 (連續 arcsine) 唔再描述佢哋
- **觀測含義**: 宇宙學觀測只到 trispectrum (n=4) — n ≥ 88 遠超可觀測,
  所以呢個 cutoff 係「原則性邊界」: 結構公式嘅可證偽範圍唔包括 n ≥ 88 關聯
  (同 aliasing 修正 1e-52 永遠 float 不可見平行 — 原則成立, 實踐永遠安全)

## 四、三域 cutoff 統一表述

**結構閉式 = 鏈嘅 Nyquist 容量以內嘅連續描述**; 超過容量:
- z > 17: 觀測上唔存在 (源到環對面, O76 P4 — JWST 可證偽)
- n ≥ 88: 結構上不可預言 (關聯階超越晶格, 本 O — 原則性)
- β ≥ N²: 數值上 aliasing 階梯接管 (溫度超越無混疊窗, docs/02 — 原則性)

三個 cutoff 唔係三個獨立假設 — 係**同一個離散譜 (176-Laplacian) 嘅三個參數化**
(z / 矩 / 溫度) 各自撞鏈長嘅同一現象。IDCM 第二、三、四個 Nyquist 結構邊界
(第一個: z>17, O76/O51)。

## 五、判決

- 🟢 矩確定性: 88 矩決定 88-atom 測度; n=88 首個 odd-sector 偏差 (dM = −88C)
- 🟢 z-domain 平行: z_max = 17 = F_proj = L₆−1, ℓ_max = log₄18 = 2.08496
- 🟢 三域 cutoff 同源: 鏈 Nyquist 容量 (z/矩/β 三個參數化同一現象)
- 🟢 EFT 對應: n ≥ 88 關聯 = 超越晶格截斷嘅不可約算子 (結構上不可預言)
- 🟡 觀測對應: n ≥ 88 關聯冇直接觀測渠道 (宇宙學只到 trispectrum) —
  cutoff 係原則性, 唔係可觀測預言
- 🟡 z>17 嘅 JWST 驗證 (O76 P4 時程 — 數據門控)
