## 一、Euler-Maclaurin 修正 (scripts/02 W01-W02 ✅)

```
Z_N(β) = e^{−2β}[N·I₀(2β) − sinh(2β)] + 2N·e^{−2β}·Σ_{m≥1} I_{2Nm}(2β)   (Poisson 精確式)
       ≈ e^{−2β}[N·I₀(2β) − sinh(2β)]                                    (β ≪ N² = 7744)
```

- **機制 (W01)**: f(θ) = e^{2βcosθ} 對 θ=0 同 θ=π **都偶** ⟹ 所有奇階導數喺端點消失
  ⟹ Euler-Maclaurin 導數級數 = 0 ⟹ 淨低**邊界項** −sinh(2β) (端點 f(0), f(π) 唔對稱)
- **數值**: β=0.001..100 修正後 dev ≤ 3.1e-32 (β=100 嘅殘餘係 I₁₇₆ 階梯, 見 W02);
  naive dev 0.0023%→25.2% 同 β 單調升 — 舊 V15 嘅「dev<2%」只係 β≤1 幸運
- **Poisson 求和 (W02)**: aliasing 階梯 = 2N·e^{−2β}·I_{2Nm}(2β) — 176 點圓網格嘅
  譜混疊; β=100 時 I₁₇₆ 項 dev 5.8e-115, β=300 時 6.1e-44, β=1000 時 2.1e-13 —
  **階梯顯著喺 β ~ N² = 7744**, 遠超任何物理溫度
- **矩展開一致 (W10)**: Z_corr = 88 + Σ_{n≥1}(−β)^n/n!·[88·C(2n,n) + 2^{2n−1}] 到 1e-50
  — 邊界項 −½(1−e^{−4β}) 嘅 β 展開**精確**畀出閉式矩 (n=0 特殊: 2^{−1}=½ 唔適用,
  k=N 原子喺 n=0 計 1; −½+½=0 對消, Z(0)=88 ✓ W08)

## 二、邊界項 = Nyquist 半原子熱力學面 (scripts/02 W07-W08 ✅)

```
Σ_{n≥1} (−β)^n/n! · 2^{2n−1} = (e^{−4β} − 1)/2 = −e^{−2β}·sinh(2β)
```

- 矩域 (O193 核心): parity-gap = Σγ^n_even − Σγ^n_odd = γ_N^n/2 = 2^{2n−1}
- β-domain: 呢個 Nyquist 半原子矩級數求和 = −½(1−e^{−4β}) — **同一個對象**:
  k=N 原子 (γ=4, 只喺 even sector) 嘅熱權重 e^{−4β} 以半原子形式進入 Z
- Z(0) = 88 要求 n=0 特殊處理: γ_N^0/2 = ½ 但實際 k=N 計 1 — 常數 −½ 由 e^{−4β}−1 提供
