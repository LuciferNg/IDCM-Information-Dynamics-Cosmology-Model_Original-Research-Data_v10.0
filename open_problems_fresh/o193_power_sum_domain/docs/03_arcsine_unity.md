## 一、映射 = affine (scripts/04 U01-U05 ✅)

```
δ̂_k = A_k/μ² = (γ_k − μ²)/μ² = −cos(2θ_k),  θ_k = kπ/176,  k 奇
γ_k = μ²(1 − cos(2θ_k)) = μ² + A_k        (O157 統一 identity, EXACT U05)
```

- arcsine-on-[0,4] 密度 1/(π√(x(4−x))) 經 x = 2(1+δ): dx = 2dδ ⟹
  P(δ) = 2/(π√(4−4δ²))·... = **1/(π√(1−δ²))** — arcsine-on-[−1,1], Jacobian 純幾何
- **矩 (U01/U02)**: ⟨δ̂^{2m}⟩_odd = C(2m,m)/4^m 精確 (m=1..43, 即 2m<88);
  奇矩 = 0 (對稱) — arcsine-on-[−1,1] 矩 C(2m,m)/4^m 全對
- **MGF (U03)**: (1/44)Σ_{k odd}e^{t·δ̂_k} = **I₀(t)** — arcsine-on-[−1,1] 嘅
  特徵函數 (∫e^{tx}/(π√(1−x²))dx = I₀(t)); 兩邊一致到 1e-40
- **零偏差 (U04)**: Σ_{k odd}A_k = 0, ⟨δ̂⟩ = 0 — O157 零偏差定理 = 一階矩 (δ̂ 對稱 ⟹ 全奇矩零)

## 二、同一測度三個出場 (scripts/04 U06 ✅)

| 出場 | 對象 | 形式 | 來源 |
|:---|:---|:---|:---|
| ① 譜測度 | 觀察者 sector γ_k (k 奇) | arcsine-on-[0,4], 矩 (N/2)C(2n,n) | O193 譜定理 |
| ② 密度漲落 | δ̂ = −cos(2θ_k) ∈ [−1,1] | arcsine-on-[−1,1], P = 1/(π√(1−δ²)) | O157/O174 D6 |
| ③ 熱統計 | Z_odd(β) = 44e^{−2β}I₀(2β) | arcsine MGF (冇邊界項) | O193 docs/02 §四 |

- ③⟺①②: e^{−2β}I₀(2β) = E[e^{−βγ}|γ~arcsine[0,4]] = E[e^{−β(2+2δ̂)}] = e^{−2β}·I₀(2β) ✓
  (arcsine MGF 恒等, 自洽閉環)
- **統一表述**: 觀察者嘅 (a) 譜密度, (b) 密度漲落統計, (c) 熱配分函數 — 三個物理面
  係同一個數學對象 (arcsine 測度) 嘅三個投影。δ̂ = (γ−μ²)/μ² 係唯一令 ΣA=0
  (零偏差) 嘅歸一化 — 結構強制, 唔係湊數
