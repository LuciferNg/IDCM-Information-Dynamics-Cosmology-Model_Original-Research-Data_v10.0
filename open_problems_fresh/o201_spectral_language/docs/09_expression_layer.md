## 一、問題 (由 docs/02 + docs/08 跑出)

單原子 / 深度 2 掃描**只測得到單項表達** (一個原子, 或兩個原子一次算術)。4 個目標有

## 二、表達樹語法 (typed leaves)

| 葉類型 | 內容 | 例子 |
|---|---|---|
| `SPECTRAL` | 譜泛函 | γ_n, Σγ^n, 扇區跡, v_g, sec, δ̂, T̂ 譜 (φ, L_n, F_n) |
| `STRUCT` | 結構整數 | N_d, B, N_gen, L₅, F₅, F₈, F_proj, K_tree, h¹¹ |
| `GEOM` | 幾何耦合 | κ_ijk (CY₃ 交集數, CYTools) |
| `OBS` | 觀測輸入 | 只准喺比較側 (**唔可以**做表達式嘅葉) |
| `LIT` | 裸數值字面值 | **自動 FAIL** (擬合參數) |

運算: `+ − × ÷ ^n`、張量縮併 (κ·γ³)。

## 三、表達層 6 步判準

1. **語法合法** — 所有葉屬 {SPECTRAL, STRUCT, GEOM}; LIT / OBS 禁
2. **獨立出處** — 每葉有 O 編號 + file:line
3. **零自由參數** — 冇擬合字面值
4. **精度證據** — dev vs **觀測目標**; 落陷阱窗 (1e-5, 1e-3) ⇒ 標「精度不足」
5. **機制證據** — null test P < 1e-4 / 零擬合算子 / 整族排除 (需註冊出處)
6. **數域相容** — 值 ∈ {Q, Q(√5), Q(ζ₁₇₆)⁺}

判決: ①②③⑥ 必過, 且 (**④ 成立 或 ⑤ ✅**) ⇒ ✅ 表達層合格;
①②③⑥ 過但 ④ 不足且 ⑤ 🟡/🔴 ⇒ 🟡 表達層形式合格 (機制未成立)。

### ★ 為何要拆 ④ 精度 / ⑤ 機制 兩步 (v1→v2 教訓)

v1 只用 5 步 (精度律單獨判)。**V_Λ vs V_obs dev = 2.448e-05 落陷阱窗** ⇒ v1 會誤殺。
但 O62 有 null test: random t 0/10000、random κ 0/500、γ 方案唯一命中、其他自然方案
(φ^−i, 2^−i, Lucas) 全部唔中 ⇒ **機制證據強**。所以精度律唔可以單獨用 —
必須配一個機制證據步, 否則會把「機制驅動」嘅閉合同「數值湊出」嘅巧合一齊判死。
