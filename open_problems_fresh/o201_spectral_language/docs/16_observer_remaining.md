## 一、B1「為何乘 L₄」→ 端點公因數還原 ✅

```
K(0) = 21 (⟨sec⟩ 讀法, 數據選定)     K(F_proj) = 28 (πR/Nyquist, 數據選定)
gcd(21, 28) = 7 = L₄
21 = L₄·N_gen = 7×3   28 = L₄·B = 7×4   28/21 = 4/3 = B/N_gen EXACT
公因數候選 (2..29): [7] ⇒ 唯一非平凡
```

**結論**: 「為何 K = L₄·N_eff」**還原**為「端點為何 21/28」。
L₄ = 7 唔係新選擇——佢係兩個數據端點嘅**唯一非平凡公因數**，而 N_eff 嘅
邊界 (N_gen → B) 由 B/N_gen = 4/3 EXACT 配對。
⇒ 剩餘 🔴: 端點 21/28 嘅來源（O169 docs/08 §五: 需 z ≳ 3 數據或結構論證）。
