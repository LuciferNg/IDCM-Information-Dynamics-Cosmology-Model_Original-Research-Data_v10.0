## 二、S1 環圖唯一性 — ✅ 定理級

**定理 (譜動差)**: 對圖 G (N 頂點, E 邊, 度 d_i), Laplacian L 譜 {λ_i} 滿足

```
Σλ_i = 2E,        Σλ_i² = 2E + Σ d_i²
```

C_N 譜 λ_k = 4sin²(πk/N) 嘅動差 (用恆等式 Σsin²(πk/N) = N/2, Σsin⁴ = 3N/8):

```
Σλ = 4·(N/2) = 2N          ⇒ E = N
Σλ² = 16·(3N/8) = 6N       ⇒ 2E + Σd² = 6N ⇒ Σd² = 4N
⇒ ⟨d⟩ = 2E/N = 2,  Var(d) = Σd²/N − ⟨d⟩² = 4 − 4 = 0
⇒ **所有 d_i = 2** ⇒ 連通 + 2-正則 ⇒ 唯一 = C_N   ∎
```

驗證 N = 6, 8, 10, 22, 44, 88, 176: Σλ = 2N EXACT, Σλ² = 6N EXACT, Var(d) = 0 EXACT。

★ **λ_max = 4 單重 (N 偶)** ⇒ 排除「多個環之和」(E = N, Σd² = 4N 都成立) ⇒ 單一連通分量。

★★ **結論**: 譜**唯一決定**圖 = C_N。所以 γ_n = 4sin²(πn/88) **唔係選擇**, 係 N = 88 嘅
必然結果。問題歸約到 S3: 為何 N = 88。
