## 三、null control (判別力檢查 — 本 script 嘅核心紀律)

```
Tier A (池 2382, 整數值原子 254 個):
  非整數隨機目標 2000 個: P(dev<1e-3) = 0.1500   P(<1e-5) = 0.0015   P(<1e-9) = 0.0000
  整數隨機目標         : P(dev<1e-9) = 0.0210
  => 非整數目標有判別力; 整數目標判別力低 (整數原子會 trivial 命中) → 靠 provenance 判準 (docs/03)
Tier B (深度 2):
  整數隨機目標 500 個: P(<1e-9) = 0.5400  ← ⚠️ 零判別力
  非整數隨機目標 500 個: P(<1e-9) = 0.0000  ✅ 有判別力
```

★ **兩個真陷阱 (本 script 跑出嚟, 唔係事前知道)**:
1. **深度 2 整數重言式陷阱**: 池對 {+,−,×} 封閉 ⇒ 任何整數目標必然被「4+32=36」式算術分解命中。
   null = 0.54 ⇒ **零判別力**。故 Tier B 必須拆 `B-int`(整數) / `B-real`(非整數), 只有後者算證據。
2. **v1 空洞化**: 第一版池含衍生原子 + tol 1e-3 ⇒ null 命中率 1.000 (完全冇判別力)。
   修法: 原子池只放原語, 衍生 (sqrt/inv) 另放, 深度 2 只用原語池。
