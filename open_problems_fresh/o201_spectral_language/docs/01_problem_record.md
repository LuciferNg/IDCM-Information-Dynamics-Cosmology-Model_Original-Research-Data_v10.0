## 四、攻擊路線

```
1. 譜字典掃描 (完備性)
   → 對 ~40 個已註冊結構常數逐個查譜表達 (γ 泛函 / T̂ 泛函 / θ 泛函 / 扇區跡)
   → 產出: 完備率 + 未命中清單 (未命中就係 C1 嘅反例集)

2. 判準 script 化 (C3)
   → 4 步判準: ① 有冇譜表達 ② 每因子有冇獨立出處 ③ 零參數 ④ 過陷阱窗
   → 對已知 3 案例驗證判決正確: b_spec = 1/⟨v_g⟩_{1..22} / √5/2 / C_old = −0.1697
   → ★ 必須注入必然錯案例, 證明判準識 FAIL (O148 check 簽名坑教訓)

3. 歸約定理 (C2)
   → φ-冪族 / F-數族 / L-數族 → 譜 嘅映射
   → 成功 1 條 = 語言合併 (C2 加強); 失敗 = 語言獨立 (C2 受挑戰) — 兩者都係真結果

4. 反例狩獵 (最強證偽)
   → 主動搵「必需但無譜表達」嘅量 (例如某個唯象上必要嘅常數)
   → 明確成功/失敗結論; 失敗要記錄搜尋空間 (唔可以講「搵唔到」了事)

5. 自指層 (C4)
   → 譜算子 (L_odd / T̂ / 投影核) 嘅代數封閉性; 奇扇區 = 觀察者嘅算子形式化
   → 判準: 要算子級陳述, 唔接受詮釋級

6. 語言層回歸測試
   → 用 O169 已閉合結果做 test set: 語言層能否零參數重現技術層所有結果?
   → 重現唔到 = 語言層唔係「完備描述」, 只係事後命名
```
