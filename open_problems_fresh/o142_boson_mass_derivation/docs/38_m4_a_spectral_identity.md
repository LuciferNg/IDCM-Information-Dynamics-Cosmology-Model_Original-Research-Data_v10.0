## §4 結構理由（唔係「試過唔得」）

1. **σ 橋係標度生成器，唔係譜讀數算子。** 橋嘅內容 = `Λ = ρ√λ_max·M₀`、`v = √λ_max·M₀·2N_d(2F₅ + B L₄ γ₇)` ——
   輸出全部係「質量標度 × 無量綱結構因子」。A 嘅單位係 **eV/γ²**（每單位鏈本徵值平方），
   即 A 係 **P6 鏈嘅歸一化讀數**，唔係一個場嘅質量。橋冇「γ_n 指標」呢個自由度 ⟹ 結構上唔可能生成 A 嘅定義域。
2. **量級斷層係結構性的。** 橋最短步長 = `ln(Λ/M₀) = 0.484` e-folds（γ₂₀：0.540；γ₁：5.279）。
   x 距 1 有 **16.65 e-folds** ⟹ 需要 `a ≈ −34.4`（或 γ₂₀ 嘅 −30.85、γ₁ 嘅 +3.153），三者皆非整數（§2②）。
   要用組合落點，就至少要 3 個生成元；而 3 個生成元嘅族密度已 ≥6.4%（§2④）⟹ **命中即無鑑別力**。
3. **後見之明陷阱實錄。** FB 最佳 dev 只有 **0.0312%**（表面「極準」），但 density **77.55%**：
   每 4 個隨機目標就有 3 個「命中」。呢個正正係「看到目標凑算子」嘅量化反例 —— 0.03% 嘅吻合零信息。
4. **P6 已有獨立負結果互證。** P6 §A 攻堅：13104 組合 0 命中，族 density **5.21%** ⟹ 兩條獨立路線
   （P6 廣族 vs O142 σ 橋窄族）同一結論：**A 嘅數值身份在算子代數層唔可辨識**。

## §5 回應與歸屬（裁決在彼）

- **可交付**：本 O 唯一與 A 相關嘅結構量 = 共用核心 `√λ_max·M₀ = 45.28487 MeV` 與比值 `Λ/M₀ = ρ√λ_max = 1.623060367`。
  兩者對 1e-8 級目標**無鑑別力**（§4.2）⟹ 交付 = 負結果 + 量化閘，唔係算子。
- **歸屬**：A 屬 **M4**（譜讀數單位，Q4 產權在 M4）＋ **P6**（中微子機制）。O142 唔接手 Q4。
- **若 M4 仍要推**，唯一有結構意義嘅方向係**機制側**（例如 seesaw 形式 `A = v²/M_R` 反推 `M_R` 嘅 K_chain 身份），
  唔係 `A/M₀` 嘅算子分解 —— 本 O 唔代做（Q4 產權在 M4）。
- **O86 通道**：如需，M4 應直接對 O86 發 handoff（`Λ_eff` 屬 O86）；本 O 唔代發，理由見 §3-4（差 2.86 個數量級）。
