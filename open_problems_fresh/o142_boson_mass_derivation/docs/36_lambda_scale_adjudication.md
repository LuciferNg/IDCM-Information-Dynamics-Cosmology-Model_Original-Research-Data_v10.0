## §3 ★ Λ 作 N_O38 獨立 pin — 🔴 不可行

**O38 之 pin 判準**（`docs/04 §1`）：`M₀ = 觀測 × f_i`，f_i 必須係**機制強迫結構數**，且 obs 唔同源。

**Λ_IDCM 嘅問題有二：**

### 3.1 同源（公式自帶 M₀）

```
Λ_IDCM = ρ√λ_max · M₀      ⟹  Λ_IDCM/M₀ = ρ√λ_max = 常數（純結構）
```
Λ_IDCM 只係 M₀ 嘅線性重述（同 7 條 M₀-origin 公式同性質）— **公式本身零獨立資訊**。

### 3.2 唯一外部錨（α_s）精度不足 + 循環

pin 只能經 `Λ_req(α_s) = M_Z·exp(−2π·α_s⁻¹/L₄)` 反推 `M₀ = Λ_req/(ρ√λ_max)`：

```
α_s=0.1179 → Λ_req=45.036 MeV → M₀=27.748 MeV (dev −0.55%)
α_s=0.1180 → Λ_req=45.327 MeV → M₀=27.927 MeV (dev +0.09%)
```

**★ 精度傳播（致命）：**
```
δα_s = 0.0009  →  δα_s⁻¹ = δα_s/α_s² = 0.0647463
δln M₀ = (2π/L₄)·δα_s⁻¹ = (2π/7)·0.064746 = 0.0581161
⟹ δM₀/M₀ = 5.81 %   (即 M₀ = 27.9009 ± 1.62 MeV)
```
N_O38 閉合需 ~0.1% 級精度（對齊其他錨）——**5.81% 差 2 個數量級，毫無閉合力**。

### 3.3 循環性（α_s-as-anchor 唔係獨立證據）

v13 嘅 `ratio_target = strong_scale/Λ_world(α_s) = √λ_max·M₀/45.327 = 3.66322`，
而 `L₅/N_gen = 11/3 = 3.66667`（**dev 0.094%**）。**ρ = N_gen/L₅ 正正係由 α_s 反選出嚟** ⟹
用 α_s 去 pin = 用被擬合嘅目標去驗證擬合 → **局部循環，不可作獨立證據**。
