## 1. 關鍵結構事實: P(k_m) ∝ A_m (精確, 非近似)

O100 ℳ 逆投影 (scripts/02 已驗證):
```
Δ²_m = transfer²·⟨(δT/T)²⟩ = (2ℓ²)²·C_ℓ·(2ℓ+1)/(4πT²)
C_ℓ  = D_ℓ·2π/(ℓ(ℓ+1)),  D_ℓ = D₁·A_m
⇒ Δ²_m ∝ A_m·ℓ³   ⇒   P(k_m) = 2π²Δ²_m/k_m³ ∝ A_m   (k_m=ℓ_m/R_world)
```
**驗證**: P(m=2) = 1911.7 ≈ P(m=3) = 1912.3 Mpc³ (差 0.03%, 因為 A₂=A₃=4/9) — 母函數直接變成 P(k) 包絡。⚠️ 早期記錄「582 Mpc³」係 (Mpc/h)³ 單位換算混淆 (582 = 1912·h³, h=0.6727), 物理 P 以 Mpc³ 計 = 1912。

## 4. 根因: 母函數繼承 = 聲學峰 zigzag 植入物質 P(k)

- A_m 係 **CMB 聲學峰幅度** (O83): 偶峰 ((k+1)/(4k−1))², 奇峰 4/9, 3/14, 1/7
- 奇偶峰 zigzag (A₃=A₂, A₅>A₄) 係聲學振盪結構 (重子效應)
- **物質 P(k) 係平滑傳遞函數, 冇聲學峰 zigzag**
- P ∝ A_m 把 CMB 峰結構直接變物質 P(k) → 形狀錯 (太扁 + zigzag)

ΛCDM 對照: 物質 P(k) 來自傳遞函數 T²(k) (平滑), CMB 峰係聲學振盪疊加 — **兩者唔同來源**。IDCM 嘅 ℳ 線對線把兩者混埋 → 結構性缺陷。
