## 一、問題陳述

IDCM 目前係**無量綱結構 + 逐項有量綱標度**：
```
M₀ = 27.9009 MeV    A = 134.2 μK    R_world = 4129.94 Mpc
a₀ = c²/2πR_H       ω_ring = 72.73   T_CMB = 2.725 K
```
每個量各自帶單位，冇統一收束機制。

**維度定理**（O73 §7）說：任何無量綱結構理論需 **1 個有量綱錨**（自由度 ≥ 1，數學必然）。
O204 C5 判「1-錨最優已達成」，但錨**全觀測供給**，且「單錨 → 全標度」映射未證。

### ★ 本 O 嘅論題

> **維度本身係單位系統嘅產物，唔係物理結構。**
> 所有有量綱量 = **無量綱結構數 × 幀單位**（frame unit）。
> **普朗克時間 = 離散幀** — 唔係要被推導嘅物理常數，而係**計數單位**。

若成立 ⟹ 維度定理嘅「1 錨」唔係有量綱常數，而係**離散幀**（計數單位），
框架可以完全無量綱化。

### 命題 1 — 幀收束
```
任何時間量  t  =  N_t × τ        (τ = 幀單位, N_t = 無量綱整數/結構數)
任何長度量  L  =  N_L × ℓ        (ℓ = c·τ 由結構關係鎖定)

```
**關鍵**: ℓ 同 ε **唔係獨立單位** — 由結構關係鎖定：

⟹ **只需 1 個幀單位 τ**，長度/質量單位係導出。
