- IDCM 對 5 個非-4258 星系完美匹配; ΛCDM 對全部 6 星系都唔匹配 → IDCM 喺低紅移幾何距離上**優於** ΛCDM

### NGC 4258 異常 — peculiar velocity, 非結構效應

NGC 4258 直接 cz/D = 89.6 km/s/Mpc 看似離譜, 但:
- M106 群有 ~130 km/s infall (已文獻證實)
- IDCM 需要 v_pec = +129 km/s → 完全合理 (0.52σpec)
- **ΛCDM D_A 對 NGC 4258 一樣 fail: +22.5σ** (10.06 vs 7.58 Mpc)
- → 呢個係 peculiar velocity 污染, 唔係 IDCM 問題

### 模型依賴量化 (script 04, 200 次 mock)

- **ΛCDM 分析 bias = -0.35 km/s (-0.48%)** — 200 次模擬 fit 平均 72.24 ± 0.81

- → 模型依賴 < 統計漲落, 數據唔足以分辨兩種距離模型

## 5. 「+1.80% 偏移」解剖

```
73.9 vs 72.59: z = 0.44σ → 唔顯著
73.9 嘅 1σ range: 70.9–76.9 → 含 72.59 ✅
MCP 5 種 pv 處理: 71.8–76.9 → 全含 72.59 ✅
2025 profile likelihood 73.5: z = (73.5−72.59)/3.0 = 0.30σ, offset = +1.254% → 亦含 72.59 ✅
```

**73.9 唔係「73.9」** — 佢係 peculiar velocity 處理嘅函數:
- fiducial (250 km/s 固定): 73.9
- 2M++/CF3 flow 修正: **71.8**
- M2000: 76.9

用 flow 修正後嘅 71.8, 偏移係 -1.1% (負!)。所以「+1.80%」純粹係 fiducial 選擇嘅產物。
