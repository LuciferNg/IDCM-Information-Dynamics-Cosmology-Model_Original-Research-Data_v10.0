## 關鍵公式

- 共同頻率（fiducial）: `ω = μ² = √γ_max = √γ_44 = 2`（ring 慣例；由 k_44 = 0 唯一選定）
- 動態頻率: `ω_n^dyn = √γ_n = 2sin(πn/88)`（逐模不同，n=1..44）
- 逐模式頻率（雙場 Z₂-奇）: `ω_±(n) = μ² ∓ g·cos(πn/88)`，`g = 1/45`
- 質量盲性: `ω(k=0) = m_n` 精確（耦合項 ∝ |k|）
- 譜: `γ_n = 4sin²(πn/88) = 2−2cos(πn/44)`；`Σγ = 90 = 2N_d + μ²`
- 簡併災難定理: 共同頻率作 resolvent 能量 ⟹ 分母全零 ⟹ 級數未定義
- 非微擾診斷: `|Σ_n/γ_n| ∈ [190, 3.3e6]`（A₅ 模式）⟹「二階自能」係錯名
- 缺口: O136 `|Δm|` RMS = 0.5872（ring 慣例），R² = 0.9768，α = 2.6333
