## 六、★ 下一輪唯一提案（一步）

**提案：把 |Δm| 由「微擾級數對象」重構為「譜權重比對象」，並檢驗其結構身份。**

理由（本輪實證）：
1. |Σ_n/γ_n| ~ 10⁵（docs/04 §三）⟹ 級數讀法唔適用；
2. 秩完美（docs/06 §二）⟹ 形狀問題係**間距律**；
3. 所需位移係 O(γ) 級（docs/06 §五）⟹ 唔可能係「小修正」。

具體第一步（最平）：
```
scripts/07: 譜權重比之結構分解
  候選: |Δm_n| = Σ_m V_nm²/(γ_n−γ_m) 之「主導項」分解
        → 檢查 |Δm_n| 係唔係 ≈ w_n · (1/Δγ_min(n)) 之單項近似
        → 若係, 則間距律 = 最近鄰 γ 間隙之結構律 (零參數)
        → 若唔係, 記錄主導項結構 (邊個 m 支配), 再找身份
```
驗證標準：主導項分解之殘餘 < 5%（即 |Δm| 之 95% 由單一 (n,m) 對貢獻）→ 則形狀問題
降級為「最近鄰 γ 間隙律」問題，可獨立攻擊。
