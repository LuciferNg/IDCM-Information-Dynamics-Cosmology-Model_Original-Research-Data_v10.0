## 二、★ 零參數兩項閉式（本輪主要成果）

```
|Δm_n| ≈ | V²_(n,n−1)/(γ_n − γ_(n−1)) + V²_(n,n+1)/(γ_n − γ_(n+1)) |
```

⟹ |Δm| 由一個 **44 項密集和** 簡化為一個 **零參數兩項閉式**（結構層面之實質簡化）。

## 三、★★ 缺口定位（本輪最重要之診斷）

```
★★ 兩項閉式極準 (1.25%)，但形狀 RMS 完全唔改善 (0.5878 / 0.5873 vs 精確 0.5872)
⟹ 1.80× 殘餘【唔喺 |Δm| 之計算層】
⟹ 缺口喺【ln m ↔ ln|Δm| 映射層】(冪律 α = 2.6333 + M₀)
```

**對 O206 問題之最終重新定位**：

| 層 | 狀態 |
|:--|:--|
| 模式集（邊個 n） | 🟢 A₅ 動差準則 {1,2,3,4,5,7,9,11,13}（O136 P = 0.0155） |
| 耦合算子（V） | 🟢 位置算子 X = diag(i−⟨i⟩)，精確 Z₂-奇（O136 P = 0.0080） |
| \|Δm\| 之計算 | 🟢 **本輪**：零參數兩項閉式，1.25% |
| 排序 | 🟢 完美（docs/06：Spearman = 1.000000） |
| **映射 m = M₀·\|Δm\|^α** | 🔴 **缺口所在**（殘餘 0.5872 = 典型 1.80×） |

⟹ 「逐模式頻率」問題（O206 主題）最終**唔係頻率問題、亦唔係 |Δm| 問題**，
而係**映射層問題**：點解 m ∝ |Δm|^α 之冪律只有 R² = 0.977（差 11.7× 於閉合門檻）。
