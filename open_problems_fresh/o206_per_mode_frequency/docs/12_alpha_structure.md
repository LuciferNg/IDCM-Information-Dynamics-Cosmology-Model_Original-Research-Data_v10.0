## 一、§A 兩錨盲測（真 out-of-sample）

**方法**：選兩個錨 (i, j) ⟹ `α = ln(m_i/m_j)/ln(|Δm_i|/|Δm_j|)`，`M₀ = m_j/|Δm_j|^α`
⟹ 預測其餘 **7 個**（完全冇參與凍結）—— docs/35 用全 9 點擬合，唔算盲測。

| 錨對 (i,j) | α_anchor | 7 個預測 RMS | 全 9 RMS |
|:--|--:|--:|--:|
| **(1,13) t,e** | **2.705511** | **0.6584** | 0.5965 |
| (1,2) t,b | 3.054995 | 0.6361 | 0.8473 |
| (2,13) b,e | 2.583443 | 0.5972 | 0.5916 |
| (1,5) t,μ | 2.788236 | 0.6518 | 0.6287 |
| (5,13) μ,e | 2.598518 | 0.6035 | 0.5894 |
| (3,9) τ,d | 2.820779 | 0.7200 | 0.6470 |
| (1,7) t,s | 2.266118 | 0.7058 | 0.7922 |
| (7,13) s,e | 3.757897 | **1.5952** | 1.7315 |

```
C1 PASS  極端錨 (1,13): α = 2.705511, 7 個盲測 RMS = 0.6584 ⟹ 冪律【有真預言內容】
C2 PASS ★ 但兩錨凍結【唔】足以釘住 α: α ∈ [2.2661, 3.7579] (跨度 1.4918)
```

★★ **新發現（負）**：**兩個錨唔夠**。α 對錨對選擇極敏感（跨度 1.49）。
⟹ O136 §D 之「8 質量比 ← 1 參數」**過度宣稱**：實際上要 ≥ 3 個錨先大致釘住 α。

### 三錨掃描（全部 C(9,3) = 84 組）

```
α ∈ [1.1742, 3.9135],  中位 = 2.6342,  σ = 0.3990
落喺全擬合 α ± 1σ 內之三錨組數 = 48/84 (57.1%)
```
⟹ **修正之壓縮比**：9 個質量 ← **~2.5 個有效錨**（唔係 1 個）⟹ 有效壓縮 ≈ **3.6 : 1**（唔係 8 : 1）。
⚠️ 呢個唔否定框架（R² = 0.977 仍成立），而係修正**壓縮性之定量宣稱**。

## 二、§B 曲率檢驗 — 冪律形式啱唔啱?

```
線性 (2 參數):  ln m = −13.5071 + 2.633254·ln|Δm|            RMS = 0.5872
二次 (3 參數):  + (−8.868e−02)·(ln|Δm|)²                     RMS = 0.5575

二次項 β = −8.868e−02 ± 2.320e−01  (bootstrap N = 2000)
|β|/σ = 0.3823
C3 PASS
```

★★ **決定性結果**：二次項**唔顯著**（0.38σ）⟹ **冪律形式正確**。
⟹ 0.5872 之殘餘 **唔係**「缺失結構層」，而係 **N = 9 之不可約統計噪聲**。
（呢個係對「缺口 = 缺失結構」假說之**形式層否定**：連一個自由度嘅彎曲都唔支持。）

**池子**：由 36 個 IDCM 結構常數（N_d=44, N_gen=3, B=4, Σγ=90, μ²=2, L₄..L₇, F₅..F₁₂,

篩選 0.5 ≤ 值 ≤ 5：

```
池子規模 = 607 個候選表達式
落喺 α ± 1σ (0.1457) 內 = 33 個
落喺 α ± 2σ 內          = 57 個

              Σγ/h¹¹ = 2.50000, μ²^√2 = 2.66514, L₄/φ² = 2.67376, L₅/B = 2.75000

★ null (隨機 α ∈ [1,4], N=2000): 1σ 內候選數 中位 = 31, 範圍 [16, 67]
```

★★★ **決定性論證**：**任何** α ∈ [1,4] 都會有 ~31 個結構表達式落喺其 ±1σ 內。
⟹ **α 之數值身份永久不可辨識** —— 唔係「未搵到」，而係**池子密度上不可能搵到**。
⟹ 方向 1（α 之結構推導）**正式關閉**：任何「命中」都必然係選擇效應。
