**★★ 結論**：
- 簇結構喺 **OLS α ± 0.1**（即 1σ 內，σ_α = 0.1425）**穩健**（F ≥ 44, P < 0.01）

- ⟹ 簇係**「擬合殘餘」嘅性質**——OLS 殘餘嘅三水平結構，**唔係** α 無關嘅本徵性質
