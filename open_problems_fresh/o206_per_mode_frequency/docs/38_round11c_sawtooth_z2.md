## 三、本體論算子對應（調律者主張 → IDCM 結構）

**主張**: (x,p) 唔係測唔到, 而係「同時精確位置與動量」根本唔係一個存在嘅狀態；性質係關係產物。

**IDCM 算子級對應（已存在, O136/O206 第五輪）**:
1. **位置算子 X = diag(i−⟨i⟩) 之對角元精確零**（純 Z₂-奇）——「一個鏈能量態擁有位置標籤」
   = **空集**（任何能量本徵態嘅 ⟨X⟩ 對角貢獻 = 0）。
2. **X 矩陣元 V_nm = (1/178)[csc²(π(n+m)/178) − csc²(π(n−m)/178)]：非零只在 n+m 奇**
   ——位置只以「模式對 (n,m) 之間嘅耦合」存在, 唔係單模屬性。
3. ⟹ **「同時 (E, x)」喺算子結構上不存在**：X 喺鏈基（能量基）唔對角, 冇共同本徵態。
   Heisenberg 不等式 = X 唔對角之**推論**（方差下界）, 唔係「測唔到」嘅斷言。
4. **費米/玻色結構分離定理**（O206 第五輪）: X 純 Z₂-奇 ⟹ 費米子質量機制（Z₂ 偶扇區）
   結構上觸唔到位置算子——即「位置」唔係費米子嘅內稟量子數。

⟹ 調律者嘅「Reality = Relations + Distinctions」喺 IDCM 有**算子證明**：位置 = 模式對關係
（n+m 奇耦合）; 質量 = 模式 n 喺 γ-階梯上嘅投影; 兩者由 Z₂ 奇偶性分離。
