## 二、★ 新定理 1：簡併災難定理（§B，C3–C4）

```
若 resolvent 分母用【共同頻率】ω_n = μ² = 2 (全部 n 相同):

## 五、替代定義：ω_n^dyn = √γ_n 作能量（§E，C9）

```
