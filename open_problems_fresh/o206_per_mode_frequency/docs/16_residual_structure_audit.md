## §2 「PDG 又不是 SI」——✅ 論點成立，且捉到一個真實輸入缺陷

### 2.1 原輸入之 scheme 混用（🔴 真實缺陷）

```
t  → pole mass   (172.69 GeV)
b/c/s/u/d → MS-bar (各自標度: m_b, m_c, 2 GeV)
e/μ/τ → pole mass
```

**即係我混用咗兩個 scheme 做同一條擬合。** 呢個係真實嘅輸入不一致，調律者一針見血。

### 2.2 統一 scheme 後重擬合（§C, script 14）

| scheme | α | RMS | vs 原 |
|:--|--:|--:|--:|
| 原輸入（混用） | 2.633217 | 0.5875 | 1.0000× |

| 全 MS-bar | 2.624622 | 0.5884 | 1.0015× |

**★ 裁決**：統一 scheme **唔**令殘餘消失（最佳改善 1.0015×，即無改善）。scheme 混用係真缺陷，但**唔係**殘餘來源。

### 2.3 加權擬合（§B, script 14）

按 PDG 不確定度加權後：

```
加權 χ² (9 點, dof 7) = 1.64e8  ⟹  χ²/dof = 2.34e7
```

**★** 以 PDG 自身嘅不確定度衡量，擬合差 **七個數量級**。呢個係比 RMS 更嚴格嘅陳述：**無任何合理誤差模型可以令呢條式閉合**。

### 2.4 ★ t 之單點線索（唯一未解項）

```
m_t(MS-bar)/m_t(pole) = 162.5/172.69 = 0.940993
```

**⚠️ 但**：同一邏輯對 b 要求因子 1/0.562 = 1.780（實際 MS-bar/pole = 1.144），對 c 要求 0.401（實際 0.760）——**全部唔吻合**。
⟹ **單點巧合，非證據**。記錄為未解線索。

## §4 ★ 具體檢驗「變焦 = RGE = 標度失配」（§5, script 15）

調律者框架（O156）：「RGE 已重新解釋為變焦效應」。此假說有**一個決定性結構預言**：

> 若殘餘 = IDCM 標度 μ₀ 與 PDG 引用標度之間嘅 QCD running，
> 則修正**只影響夸克，唔影響輕子**（輕子只受 QED，~α/π ≪ 1%）。

### 4.3 裁決

**🔴 「殘餘 = QCD running / 標度失配」實測否定。** 三重否定：①掃描唔閉合 ②相關唔顯著 ③加參數唔值。

**⚠️ 誠實記錄（自家 check 修正）**：C4 初版寫「輕子 RMS 唔變」——**mis-designed**。輕子嘅**修正量**確實 ≡ 0（結構保證），但**重擬合會令擬合線移動**，故輕子殘餘仍由 0.1816 → 0.1575。已改測正確對象（修正量 ≡ 0），並保留說明。

### 4.4 ★ 間接證據：輕子殘餘一樣大 ⟹ 殘餘非 QCD 性質（支持幾何透鏡版本 B）

調律者質詢（2026-09-21）：「否定了 RG 跑動的原因是透鏡效應嗎」——澄清：否定嘅係**版本 A（標度跑動）**，唔係**版本 B（焦距幾何）**。以下補一條上輪已有數據之**間接證據**：

> **版本 A 預言**：輕子唔受 QCD 跑動 ⟹ 輕子殘餘應 ≈ 0（QED 修正 ~α/π ≪ 1%）。
> **版本 B 預言**：全部粒子都經過 CY₃ 鏡頭 ⟹ 殘餘**唔分**輕子/夸克。

實測殘餘（script 14 §A 表，非新計算）：

| 扇區 | 殘餘 |
|:--|:--|
| 輕子 | τ −0.0582 ／ μ **−0.4741** ／ e **−0.4029** |
| 夸克 | t −0.0627 ／ u −0.0422 ／ b −0.5765 ／ d −0.4533 ／ c +0.9130 ／ s +1.1569 |

- 3 個輕子中 **2 個**（μ, e）有 |殘餘| > 0.4，與典型夸克殘餘（b, d）**同一數量級**
- 若殘餘係 QCD 性質（版本 A），輕子殘餘應精確 ≈ 0——但 μ（−0.474）同 e（−0.403）明顯唔係
- ⟹ **版本 A 之必要條件（輕子殘餘 ≈ 0）實測違反** ⟹ 版本 A 喺標度掃描之外**再被排除一次**
- ⟹ 殘餘性質**似幾何**（人人有份），**唔似 QCD**（只係夸克）——間接支持版本 B

⚠️ 嚴謹性標記：**間接**證據（非獨立檢驗）。版本 B 嘅**正預言**（不同 detent 度數之質量預言）未直接測試——屬 O206-OPEN-4 延伸。
