## 二、投影 P 之秩虧（946 = C(N_d,2)）

O57 之 L7 投影：$P: 946 \to 134$。兩個維數皆為結構數：

$$\boxed{\,946 = \binom{N_d}{2} = \binom{44}{2}\,}, \qquad \boxed{\,134 = N_d + \Sigma\gamma = 44 + 90\,}$$

**驗證**（script C1–C3）：
- $\binom{44}{2} = 44\cdot43/2 = 946$ **EXACT**（$946 = 2\cdot11\cdot43$）
- $N_d + \Sigma\gamma = 44 + 90 = 134$ **EXACT**（$= \mathrm{Tr}\,G$，O211）
- 秩虧 $= 946 - 134 = 812 > 0$

### ★ 結構讀法

- **946 = $\Lambda^2(K_{\rm chain})$**：44 維鏈空間之**反對稱 2-張量**維數 = 鏈站點**對數**
- **134 = 跡 + 譜**：$\mathrm{Tr}\,G = N_d + \Sigma\gamma$
- ⟹ 投影 = **由「對關聯」降至「跡 + 譜」**；壓縮比 $946/134 = 7.0597$

**$P$ 冪等**（$P^2 = P$，投影算子之定義）⟹ **奇異**（$\dim\ker P = 812 \ne 0$）⟹ $P^{-1}$ **唔存在（作為函數）**。

## 三、★ 核心：映射型別 —— 函數（前向）vs 關係（後向）

細化流之 decimation：$D_\ell: V_\ell \to V_{\ell-1}$，$N_\ell = N_d\cdot4^\ell$。

| | 前向 $D_\ell$ | 後向 $D_\ell^{-1}$ |
|---|---|---|
| 型別 | **函數**（well-defined 映射） | **關係**（多重值） |
| 每個像之原像數 | 1 | $4^{N_{\ell-1}}$ |
| ℓ = 1 | $176 \to 44$ | 每個粗態 $4^{44} \approx 10^{26.5}$ 個細態 |
| 確定性 | ✅ 係 | ❌ 需「揀邊個原像」 |

### ★★ 定理（方向性）

> **一個確定性定律必須係函數。** decimation 之前向係函數、後向係關係 ⟹ **唯一「定律式」方向 = $\ell \to \ell-1$（粗粒化）**。

後向需要「揀邊個原像」= **額外結構（選擇律）**；而 IDCM 之紀律係零新結構 ⟹ 後向**唔係**定律。

$$\boxed{\;\text{方向性} = \text{映射型別之推論（結構）}\;}$$

**第二定律係推論**（C10–C11）：$\Delta S_\ell = (N_\ell - N_{\ell-1})\ln2 > 0$，且 $\Delta S_2/\Delta S_1 = 4$ **EXACT**。

| $\ell \to \ell-1$ | $\Delta S$ (nats) |
|---|---|
| 0 → −1 | 22.8739 |
| 1 → 0 | 91.4954 |
| 2 → 1 | 365.9817 |
| 3 → 2 | 1463.927 |

## 四、κ 閘極 —— 冪等 + 單向

O164 §C 之可見性閘極：$\kappa = \gamma_{\max}^{-2} = B^{-2} = 1/16$。

**驗證**（script C12–C13）：
- 夾層 $e^{-2} = 0.135335 > \kappa = 0.0625 > e^{-3} = 0.049787$ **EXACT**
- $\ln(1/\kappa) = \ln B^2 = 2\ln B = 2.7725887$
- $N_{\rm gen} = \lceil \ln(1/\kappa)\rceil = \lceil 2\ln B\rceil = \lceil 2.77259\rceil = 3$ **EXACT** = $N_{\rm gen}$

### ★ 閘極同型於投影

硬閾值閘極 $F(x) = x\cdot\Theta(x - \kappa)$：

| 性質 | 後果 |
|---|---|
| **冪等** $F(F(x)) = F(x)$ ∀x | 非可逆 |
| $F^{-1}(y)$ for $y < \kappa$ = $\{x < \kappa\}$（**集合**，非單點） | 逆向需被丟棄之資訊 |
| 通過方向唯一（世界 → 觀察者） | **單向** |

> **★ 冪等 + 非可逆 ⟹ 閘極本身內稟定向** —— 同 $P$ 同型。**投影類算子 = 定向算子**。

## 六、★★ IDCM 無起始 ⟹ 箭頭必為結構

O51 三層證明：**$K_{\rm chain}$ 冇起始**。真年齡：

$$t_{\rm true} = 131\,T_{\rm sync} + \tau = 131\times 84.6349 + 13.4701 = 11{,}100.642\ \text{Gyr}$$

## 七、殘餘 —— 絕對定向（🔴）

方向已定（= 秩遞減）；但「**兩 sense 之命名**」（邊個叫「過去」）仍需要一個**定向**。

**候選**：**幾何手性**。

- O143 已裁定：幾何點集只係**手性 $I$（60 等距）**，唔係 $I_h$（120）
- $I_h = I \times \mathbb{Z}_2$（含反演）⟹ $120 = 2\times60$
- **手性結構定義一個定向**（如螺絲之旋向）⟹ 可提供絕對定向

**可證偽**：

| 情境 | 後果 |
|---|---|
| 幾何係手性（$I$，60） | 絕對定向存在 ⟹ §七 可閉合；**宇稱奇（parity-odd）簽名必須存在** |
| 幾何係非手性（$I_h$，120） | 無絕對定向 ⟹ §七 **唔可以**閉合 |
