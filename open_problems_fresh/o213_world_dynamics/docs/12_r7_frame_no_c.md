## 三、★ 定理 1（no-go）：「唔用 c」導出 τ 之不可能性

### 3.1 c-free 基之無量綱不變量

「唔用 c」時可用之基 = `{ħ, k_BT, G, m_p}`（4 量，3 維 M/L/T ⟹ **1 個**無量綱不變量）。
解 `ħ^a (k_BT)^b G^c m_p^d` = 無量綱：

```
M: a + b − c + d = 0
L: 2a + 2b + 3c  = 0     ⟹  a = 2b,  c = −2b,  d = −5b
T: −a − 2b − 2c  = 0
```

$$\boxed{\;\Pi = \frac{\hbar^2\,k_BT}{G^2 m_p^5} = 7.1759306296\times 10^{63}\;}$$

### 3.2 定理

`{ħ, k_BT}` 唯一可造之**時間** = `ħ/(k_BT)`（因 `[ħ] = ML²T⁻¹`、`[k_BT] = ML²T⁻²`）。

$$\tau = \frac{\hbar}{k_BT}\cdot f(\Pi), \qquad f \text{ 由結構決定}$$

實測：`X ≡ τ·k_BT/ħ = 1.51678388496e29`，而 `Π = 7.1759e63`。

### 3.3 X 繼承重力階層（C2）

```
X = N·(T_CMB/T_Pl)   EXACT  (dev = 1.15e-41)
N = τ/t_Pl = 7.88468594512e60    ← O200/O212 已證: **非結構** (null P = 0.875)
```

若 `f(Π) = Π^p` ⟹ `p = 0.4570`（非整數/半整數/結構比）。

> **★ 定理 1**：任何 c-free 之 τ 表達式 = `(ħ/k_BT)·f(Π)`，而 `Π ∝ m_p^{-5}G^{-2}`
> ⟹ `f` **必含重力階層** `m_p/m_Pl`。故「唔用 c 導出 τ」**等價於導出重力階層** ⟹ **O86**。
> 呢個唔係技術不足，而係**維度定理之推論**。
