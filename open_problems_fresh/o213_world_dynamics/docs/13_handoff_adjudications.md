## §4 O232 R5 渲染深度 — v9 主張 vs v10 撤回（裁定）

**來源**: O232 `docs/02_r1_rendering_depth_verdict.md`（handed_off 2026-10-05）：
「R5 (O232→O213): v9 doc04『渲染深度固定13.8+z=17 NaN截斷216Myr』vs v10 O51

- O51 2026-08-22 撤回 44/43 校準偽影 ⟹ **13.7833 Gyr「宇宙年齡」撤回**；
  渲染深度 = **τ = 13.4701 Gyr = 光行距離**（環周長 / c）；IDCM **冇宇宙年齡函數**。
- O232 R1 裁定：τ ≠ 恆星年齡天花板（τ 係數據視界，非物理起始）。

**O213 裁定**:
1. **v10 中 z=17 早端截斷「唔再成立」為渲染深度語義** — 佢係 v9 用
   ΛCDM 齡換算（t_age(17)）反推 13.8 − 0.216 Gyr = 13.6 大致吻合 13.7833 所製造
   嘅「早端截斷」敘事；44/43 撤回後，嗰個吻合嘅**輸入**（ΛCDM 齡）唔存在於 IDCM，
   輸出（截斷）失卻結構地位。剩低嘅 z=17 只係 ℓ = log₄18 ≈ 2.085（Nyquist 類比
   資訊截斷）嘅**級聯內部刻度**，唔係宇宙生時。
2. **216 Myr 基準 = ΛCDM t_age(z=17)**（`scripts/14` H1：Planck 2018 宇宙學計
   **225.7 Myr**、H0=70/Ωm=0.3 計 **222.6 Myr**；v9 記 211/216 接近）⟹ 216 Myr 係
   **外部 ΛCDM 換算**，唔係 IDCM 結構量。
3. **τ + t_f(z17) 讀法狀態**: 無結構地位。13.470 + 0.226 = 13.696 對 A_★ 嘅
   「−0.2σ 命中」係 category error（O232 R1 已撤 1.6σ 框架）⟹ **(A) 冇天花板
   讀法成立**；(B) z=17 截斷讀法唔成立（附條件：如未來要講「早端」，只能指
   ℓ 級聯資訊截斷，須叫 `ℓ_cut = ⌈log₄(18)⌉` 而唔可以叫宇宙齡）。

**可測預言（O232 Q4 note 要求翻身）**: R5 早端截斷 216Myr 唔可以翻身為
「年齡分佈形狀預言」—— 因為 v10 冇宇宙齡函數（O51 撤回）。可翻身方向 =
**ℓ 級聯資訊截斷之投影**：`1+z = B^ℓ`，ℓ 級聯喺 ℓ_cut = ⌈log₄ 18⌉ = 3 有些微
非連續（shell 熵 ΔS 跳變），其投影 = 特定 z 之**觀測者不可見現場**（高 z 源密度
邊界），但嗰個邊界同 ΛCDM 嘅 z≈17「第一顆星」邊界**唔同一物理**（IDCM：級聯
資訊；ΛCDM：再電離前無光）。此為 O232→O213 之回覆核心：**v9 之 z=17 早端
截斷不能翻身為可測預言**（佢唔係 IDCM 量）；可測嘅係 ℓ_cut 級聯不連續，待
O76/O132 翻譯層承接。

**O213 確認**（`scripts/14` G5）：1 − (88/π)sin(π/88) = 2.124005e-4（G5 ✅，
