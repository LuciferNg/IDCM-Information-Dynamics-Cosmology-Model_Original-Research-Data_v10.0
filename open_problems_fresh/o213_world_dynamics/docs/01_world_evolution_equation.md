## 一、定位：為何 L7 唔可以係 d/dt

IDCM **冇外部時間**（O164：世界係自持節奏，冇第一個拍子）。若寫 `d/dt`，就要外部鐘 ⟹
引入框架外對象。故 L7 之演化參數必須係**內在**嘅。

> **★ 本 O 命題**: 演化參數 = **相位深度 ℓ**（= 細化層 = RG 標度），
> 演化 = **4:1 decimation 流** `Λ_ℓ → Λ_{ℓ−1}`，其**不動點 = c**。

呢個令「世界演化」同 O197 嘅細化族 `N_ℓ = N_d·4^ℓ` 統一 —— 同一結構、兩個語言。

## 三、z 之非膨脹定義（交付 ② 之核心）

```
1 + z = B^ℓ         ⇔  ℓ = log₄(1+z)
```

- `ℓ = 0 ↔ z = 0`（觀察者層）
- `ℓ = 1/2 ↔ z = 1`（半級聯層）
- `ℓ = 1 ↔ z = N_gen = 3`（一完整級聯層）
- Nyquist 截止 `ℓ_max = log₄18 ↔ z = 17`（O76；`scripts/02` C5）

★ **z 唔係運動學**（冇尺度因子）：z = **級聯比**。呢個係「IDCM 冇原生 H(z)」之正面對應物。

## 四、距離律之結構來源（交付 ③）

### ★ 幾何殼身份（`scripts/02` C6–C7）

```
1 − 4^{−ℓ} = 3 · Σ_{j=1..ℓ} 4^{−j}          (整數 ℓ EXACT, 差 = 0)
⟹ D_M(ℓ) = R_world · [Σ_j 3·4^{−j}] · E(ℓ)
          └ 殼厚 w_j = 3·4^{−j} = N_gen·R_world/B^j
Σ_{j=1..∞} w_j = 1   (自相似殼鋪滿世界環)
```

**意義**：O76 距離律之 `(1−4^{−ℓ})` **唔係擬合因子** —— 佢係**自相似殼之部分和**。
「世界 = 一串嵌套殼」，演化 = 逐殼 coarse-grain。

與 O76 核對（`scripts/02` C8）：`D_M(z=2.33)/r_d = 39.034` vs DESI DR2 = 39.1879（dev 0.39%）。

### 徑向輸運（`scripts/02` C9–C13）

```
D_H(ℓ) = R_world·(dℓ/dz)·M(ℓ),      M = 1/v_g = sec(π·n_c/88)
n_c(ℓ) = N_d/2 + B·sin(πℓ)          (ℓ < ℓ_t = log₄N_gen)
```

**★ 部分推導**（O170 §6 之三項遺留，本輪收窄）：

| O170 §6 遺留 | 本輪結果 |
|:-------------|:---------|
| ① 為何 sin(πℓ) | 🟢→🟡 **頻率 π 由邊界條件強逼**：δ(0) = δ(1) = 0（節點喺 ℓ=0 ↔ z=0 及 ℓ=1 ↔ z=N_gen = 下一級聯層）⟹ δ ∝ sin(πℓ)。剩振幅待定 |

⟹ 載波群速度 = **Z₂ 自對偶點 (v_g = 1/√2) 加上一個振幅 `(2π/N_d)` 嘅相位調制**。


## 六、時間箭頭（交付 ④）

```
decimation Λ_ℓ → Λ_{ℓ−1}:  N_ℓ → N_{ℓ−1} = N_ℓ/B
資訊損失 (每站 1 bit):  (N_ℓ − N_{ℓ−1})·ln2
  ℓ=2→1:  704→176,  ΔS = 366.0 nats
  ℓ=1→0:  176→44,   ΔS = 91.5 nats
```

★ **箭頭來源**：
1. decimation 係 **many-to-one**（`2^{3N_ℓ/4}` 對一）⟹ **不可逆**（`scripts/02` C18）
2. 粗粒化熵增 = 資訊損失（結構性，非假設）
3. **方向 = ℓ 遞減**（細 → 粗）= 時間前進

⚠️ **誠實邊界（🔴）**：`T_ring` 係**週期**，本徵無箭頭 —— 所以箭頭**唔可以**來自 T_ring。
上述第 1–2 點只證「不可逆」；「**為何係 coarse-grain 而唔係 refine**」（即方向性本身）
**仍係邊界條件**（類同低熵初態），**未由結構導出** 🟡→🔴。
