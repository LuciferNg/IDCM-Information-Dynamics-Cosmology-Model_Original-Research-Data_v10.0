## 六、c 失配（0.193%）之判定：**gauge 未定**，非錨錯亦非公式錯

```
ω_ring(BBN) = 72.73  → c_W = R_world·ω_ring = 300370.536 km/s
ω_ring(c/Rw)= 72.59  → c_W = R_world·ω_ring = 299792.458 km/s (= SI c 精確)
失配 = 578.1 km/s = 0.192826%
```

**同一個自由度嘅兩個獨立讀數**：
- 讀數 A: BBN → η_B → ω_ring = 72.73

```
η_B(c_SI) = 6.2145e-10   → D1 pull +2.86σ

```
⟹ **偏好 c_SI，但分辨力 < 1σ** ⟹ 現有數據**未能定案**。
