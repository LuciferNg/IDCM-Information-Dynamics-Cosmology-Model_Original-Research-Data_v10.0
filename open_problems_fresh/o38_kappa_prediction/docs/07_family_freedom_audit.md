
**用戶例本身離 N 好遠** (83.7% dev) — 但正正示範咗 log 尺度嘅幻覺:

`1.80188×10^40 = 尾數 1.80188 × 冪 10^40`, 但尾數依然可以被無限多「方法」逼近 —
自由度唔喺目標數值大細, 喺**式族參數空間**。

## 2. 密度判準 [B]

```
ρ = N_expr / D_range    [候選式數目 ÷ 覆蓋範圍 (dex)]
E = ρ × tol_dex         [目標附近命中期望]
E >> 1  ⟹ 零資訊 (隨機目標幾乎必中)
E << 0.1 ⟹ 有資訊 (命中先算數; 負結果亦有資訊)
E ≈ 0.3~1 ⟹ 可報, 但必須連帶報告 E + 家族命中數
未有 E 記錄嘅命中 = 後驗 → 證據權重 0
```

## 4. 式族註冊制 [D] (正式入 skill)

任何「N ≈ 表達式」主張必須附:
1. **定義**: 式族 (基底集 + 指數集 + 組合數) — 可重算
2. **覆蓋檢查**: 目標必須喺族覆蓋範圍內, 先繼續
3. **密度 E**: 覆蓋內對同量級隨機目標嘅命中期望 (≥200 樣本)
4. **家族命中數**: 同一族喺容差內有幾多個唔同式 (多 = 稠密 = 零資訊)
5. **機制語義**: 基底/指數點解係呢啲數 (譜結構直接生成, 唔可以由 88/44/2 再組合)

缺一即後驗。全部齊 + E<<1 先有資格報「命中」/「負結果」。
