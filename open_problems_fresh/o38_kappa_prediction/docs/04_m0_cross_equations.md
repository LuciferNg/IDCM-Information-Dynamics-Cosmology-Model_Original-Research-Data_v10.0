## 4. ★ N 嘅多 pin 表達式 (scripts/21 [C])

```
對任何需-M₀ 公式 M₀ = obs × f_i:   N = obs·f_i/(ħω_ring)  (恒等)
m_e pin:  N = F_e·[m_e/ħω_ring]
m_7 pin:  N = (1/√γ₇)·[m_7/ħω_ring]
m_μ pin:  N = F_μ·[m_μ/ħω_ring]   (F_μ = 0.264067)
m_p pin:  N = F_p·[m_p/ħω_ring]   (F_p = 0.029736)
v_SM pin: N = f_v⁻¹·[v_SM/ħω_ring] (f_v = 8824.786)
```

**數學事實**: 每個 pin 都係恒等 — 因為 obs_i × f_i ≡ M₀ (f_i 定義為 M₀/obs_i)。
⟹ 任何一條公式都唔會【自動】閉合 N; 必須 f_i 係**機制強迫**嘅結構數。

## 6. ★★ 核心重寫: N 缺口 ≡ F_e 缺口 ≡ 電子嘅鏈格

```
N = M₀/(ħω_ring) = F_e · [m_e/(ħω_ring)]
                                     └─ 全由觀測+閉合錨 (m_e PDG, ħω_ring 維度側)
⟹ N 嘅閉合 ⟺ F_e = M₀/m_e 嘅閉合
⟺ 「電子喺 88-鏈嘅邊格」(O34 scripts/19 開放問題: e 嘅模態指數未解!)
   — 同一個洞, 三個睇法:
     N 純數 (O38/m0-scale)  ⟷  F_e 標度因子  ⟷  電子模態指數 (O34 開放)
```

> 呢個重寫有意義: 未來任何候選機制只需回答「**電子點樣出嚟**」—
> 若 F_e 由機制強迫閉合 (e.g. 電子 = 某模態/某因子組合), N 即閉合, 且預言 m_e 到輸入精度。
