## 1. 分子重推——123/180 層面（分母 = 180 = B(N_d+1)）

S8 嘅錯處: 攞 41/60 = (N_d−N_gen)/(B²+N_d) 做原子化，但 123/180 嘅分子唔係 41——係 123。
分母 180 = B(N_d+1) ≠ 60 = B²+N_d。**喺規範形式層面，全部分子都要 ×N_gen**:

```
Ω_b = 9/180   分子 9  = N_gen² = 3²
Ω_c = 48/180  分子 48 = N_gen·B² = 3×16
Ω_m = 57/180  分子 57 = N_gen·(N_d/2−N_gen) = 3×19      ← 補數 (Ω_total=1)
Ω_Λ = 123/180 分子 123 = N_gen·(N_d−N_gen) = 3×41 = 2⟨W⟩²
─────────────────────────────────────────────────────────
全部分子 = N_gen × {N_gen, B², N_d/2−N_gen, N_d−N_gen}
和: 9+48 = 57 (baryon+dark = matter) ✓;  57+123 = 180 (物質+真空 = 全預算) ✓
```

**結構**: 世界側表示 = 一代/譜量表示 × N_gen（三代）。123/180 = 41/60 × (N_gen/N_gen)。
123 = 3×41 = 3×(44−3) = L₁₀; 57 = 3×19 = 3×(22−3)。
