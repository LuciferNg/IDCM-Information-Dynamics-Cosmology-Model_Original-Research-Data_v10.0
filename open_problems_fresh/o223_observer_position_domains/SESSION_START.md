## 三、★ 核心發現（四項）

```

   └── 60 個純組合自同構（任何 O(3) 變換都實現唔到，殘餘 1.31–1.85）
```

**本 O 獨立重算確認**：`scripts/02` 以回溯法窮舉全部自同構 = **120**；
`scripts/01` 以 O(3) 精確三點解 = **60（proper 60 / improper 0）**。

⟹ 物理讀法：**單一 GL 疇內只有 60 個 proper 等距可用；穿越 π 相位滑移（疇壁）時局部標架鏡像，
另 60 個 improper 組合自同構才解鎖。**

### 3.2 阻挫圖案係 anchor-相對（非規範不變量）

```
60 個 anchor（BFS 2-著色）→ 30 個相異阻挫邊集合

⟹ **拓撲位元圖案 = (圖, anchor) 嘅聯合性質，唔係圖單獨嘅不變量。**

### 3.3 圖論身份修正 — 一個既有紅旗被解釋

`cmb_cold_spot/data/graph_identity.txt` 原載：

```
