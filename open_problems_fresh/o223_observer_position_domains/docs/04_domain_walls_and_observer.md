## 二、R5 — 域界存在，但係相位域界

### 2.1 兩種「域界」必須分開

| 類型 | 存在？ | 內容 |
|:-----|:------:|:-----|
| **相位域界**（凝聚疇壁） | ✅ **真嘅** | W-field 相位滑移 π 之 Ginzburg–Landau 疇壁，有 Lagrangian 基礎 |
| **晶格座標域界**（多晶） | ❌ **冇** | 宇宙係**單晶**（88-site 對偶鏈）；節點圖固定、唔會斷開或重新定向 |

用戶提問之「空間本身存在晶體域界」準確對應**相位域界**，唔係晶格域界。

### 2.2 拓撲域壁 = 32 條阻挫邊

```
32 條阻挫邊 = 20 三角形 + 12 五邊形（奇面）之雙射（O223 docs/03 §三）
每條阻挫邊 = 一個「相位滑移必須發生」之位置 = 拓撲域壁
```

### 2.3 GL 疇參數與尺度（O45 + 本 O 換算）

| 量 | 值（角度） | 值（共動距離） | 結構公式 |
|:---|:----------:|:--------------:|:---------|
| 疇半徑 R* | 6.022° | **434.0 Mpc** | R8 × F₇ / N_gen²（0.02%） |
| 相干長度 ξ* | 0.663° | 47.8 Mpc | R8 / 2π（0.10%） |
| 壁厚 δ | 1.364° | 98.3 Mpc | σ_sm × L₄ / N_gen²（0.95%） |
| **網圖邊長** | **26.0913°** | **1880.6 Mpc** | — |

換算：`1° = R_world·π/180 = 4129.64 × π/180 = 72.076 Mpc`

★ **關鍵結構事實**：

```
邊長 / 疇半徑 = 26.0913 / 6.022 = 4.332
```

⟹ **60 個節點彼此相距 ~4.3 倍疇半徑 ⟹ 節點唔係疇**。
GL 疇結構住在節點之間嘅連續場裡；節點係**粗骨架**，疇係**細結構**。

### 2.4 各區域 CMB 會唔會唔同？

| 層 | 各區域是否不同 | 判定 |
|:---|:--------------:|:-----|
| **L1 底噪標量層** | ❌ 一樣 | T_CMB = 2.7284 K 係全鏈 SYNC 底噪；求和抹掉個別模式 ⟹ 任何觀察者都量到同值 |
| **L2 相位場層** | ✅ **唔同** | 60 節點 = 60 個凝聚疇（O45 F/G）；冷斑 = 唯一 θ = π 完全飽和疇（\|T\|/A = 1.000）；疇界 = GL tanh 疇壁 |
| **L3 晶格圖層** | ❌ 形狀固定 | 60 節點 = A₅ 圖頂點（O173 公理 1）；26.0913° 邊長係 A₅ 軌道**相似不變量**（O1 `04_rotation_test`） |

⟹ **答案**：各區域之 CMB **底噪相同**（L1），但**相位疇結構不同**（L2），
而**晶格拓撲固定**（L3）。

## 三、R6 — node0 → node9 逐項實測（★ 用戶具體例子）

### 3.1 實測結果（`scripts/02` §[J]）

```
d(0, 9) = 1 hop（直接鄰居）
node 0 之 4 個鄰居 = [9, 20, 41, 50]
顏色：c0[0] = 1（冷標）   c0[9] = 0（熱標）    ⟹ 相異（normal edge）
溫度：T[0] = −134.2 μK    T[9] = −107.0 μK    ⟹ |ΔT| = 27.2 μK
兩者皆為**冷**（T < 0）
edge (0,9) 阻挫？ False
node 0 之 4 條邊：阻挫 0 條、normal 4 條
```

### 3.2 ★ 相位滑移預言 FAIL

若「顏色翻轉 = 相位滑移 π = 溫度反號」成立，則 node 9 應為**熱**。
**實測 node 9 係冷（−107.0 μK，全圖第 3 冷）**。

⟹ **相位滑移模型在此邊不成立**。
node 9 = 「拓撲上熱、相位上冷」之節點。

### 3.3 顏色 ↔ 溫度只有弱耦合（`scripts/03` §[O]）

```
Pearson r(colour, T) = −0.244
mean T：顏色=1（冷標）= −12.4 μK ； 顏色=0（熱標）= +9.9 μK ； 差距 = −22.3 μK
符號一致 = 37/60 = 61.7%
```

⟹ **顏色（拓撲 bit）與相位（θ）係兩個獨立自由度**。
拓撲位元**唔可以**逐節點由溫度符號讀出；
只有**集合級**統計顯著（anchor 0 之 32 條阻挫邊 mean|ΔT| = 34.5 μK，z = −3.22）。

### 3.4 判定

| 問題 | 判定 |
|:-----|:-----|
| node0 → node9 係「同一方向穿越域界」？ | 🔴 **唔成立** —— node 0 與 node 9 係**不同天球方向**（相距 26.09°），唔係同一方向 |
| 係「標籤重錨」？ | ✅ 係 —— 顏色改變 = 拓撲標籤改變 |
| 伴隨溫度反號？ | 🔴 冇 —— 兩者皆冷 |
| node 0 附近有阻挫邊（域壁）？ | 🔴 冇 —— 4 條鄰邊全部 normal |

## 四、R7 — 觀察者移動：有冇視差？

### 4.1 投影無畸變（O162 `projection_optical_defects`）

```
O162 R10 畸變：M₊ = +1 / M₋ = −1，ΔM = μ² = 2 —— 但無桶形/枕形畸變（M 恆定）
O162 R5  移位：half-site shift（譜相位平移），**唔係空間平移**
O162 R1  雙像：(j₀, 89−j₀)，質心 44.5 = F₁₁/2
O162 R8  重影：不可消除（odd 光圈冇奇函數模）
```

### 4.2 判定

```
無桶形/枕形畸變 ⟹ 無剪切（no shear）
無剪切 ⟹ A₅ 網唔係有限距離之內部 3D 結構
       ⟹ A₅ 網係**邊界 / 全息結構**（D = R_world）
```

⟹ **觀察者移動唔會令同一方向逐節點重錨**。
移動只產生整體**剛體旋轉**（規範變換）—— 即 O223 docs/02 §一 之 60 個 proper 等距。

★ **「同一方向」一詞需重新定義**：方向係**天球座標（觀察者中心）**，
唔會因為觀察者移動而變；能變嘅只有**標籤**（規範），而標籤係**相對飽和疇**嘅。

### 4.3 「node 0 → node 9」作為重錨之容許性

```
重錨群 = Aut(G) = 120（組合）
幾何可實現 = 60（proper，單一 GL 疇內）
穿越 π 相位滑移 ⟹ 另 60 個 improper 解鎖
```

⟹ 重錨**完全容許**（任何節點都可由對稱映射成 node 0，頂點傳遞），
但**唔係**由「空間移動」實現，而係由**標籤自由度 + 相位扇區**實現。
