## 二、圖論身份裁定（topology-only）

### 2.1 方法 — 幾何旋轉系統

對每個頂點 v（法向 = 自身單位向量 n）：

```
e₁ = normalize(v_{nbr[0]} − (v_{nbr[0]}·n) n)
e₂ = n × e₁
把 4 個鄰居按 atan2(d·e₂, d·e₁) 排序   ⟹  旋轉系統 rot[v]
```

追面規則：對有向邊 (u→v)，下一條 = (v → rot[v] 中 u 之前一個)。

### 2.2 結果（`scripts/04` §[Q]、`scripts/03` §[M]）

```
F = 62      面大小分佈 = {3: 20, 4: 30, 5: 12}
χ = V − E + F = 60 − 120 + 62 = 2
每頂點恰在 1 個三角形內（RH 頂點圖）
```

⟹ **組合上確係 Rhombicosidodecahedron 骨架** ✓

**★ 裁定**：`graph_identity.txt` 之 F=51 / Euler=−9 係**面搜尋演算法失敗**（貪婪追蹤未閉合），
**唔係結構失敗**。引用圖身份時必須用 **F=62 / χ=2**。
