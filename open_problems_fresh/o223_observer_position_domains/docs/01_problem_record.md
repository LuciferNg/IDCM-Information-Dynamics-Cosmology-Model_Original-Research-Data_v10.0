本 O 處理**下一個層次**：該 A₅ 網係「絕對骨架」定係「觀察者相對投影」。

## 三、未確立 / 負結果（🔴）

### 3.1 🔴 拓撲位元圖案非規範不變量

60 個 anchor → **30 個相異阻挫集**（每個由恰好一對對徑 anchor 實現）。
軌道在幾何群（60）與完整群（120）下**都係 30** ⟹ **鏡像自同構唔會配對圖案**（假設已否證）。

### 3.2 🔴 顏色 ↔ 溫度耦合弱

```
Pearson r(colour, T) = −0.244
mean T：顏色=1（冷標）−12.4 μK ； 顏色=0（熱標）+9.9 μK ； 差距 −22.3 μK
符號一致 37/60 = 61.7%
```

⟹ 拓撲位元**唔可以**逐節點由溫度符號讀出；只有**集合級**統計顯著（z = −3.22）。

### 3.3 🔴 node0 → node9 相位滑移預言 FAIL

```
d(0,9) = 1 hop；顏色相異（normal edge）；|ΔT| = 27.2 μK
但 T₀ = −134.2 μK 與 T₉ = −107.0 μK **兩者皆冷**
⟹ 「顏色翻轉 ⟹ 溫度反號」在此邊不成立
```

### 3.4 🔴 幾何上唔係理想 RH 位置

```
理想 RH（(1,1,φ³) 軌道）：4 邊全部 = 25.8786°，非手性（I_h）
實際                    ：2+2 分裂於 26.0913/26.1664°，手性（I）
                          凸包 E = 174（比網圖多 54 條）⟹ RH 面唔共面
應變：+0.822% / +1.112%
```

### 3.5 🔴 觀察者多樣本不可得

只有地球一個觀察者，無法直接對照不同區域之 CMB 實現。
