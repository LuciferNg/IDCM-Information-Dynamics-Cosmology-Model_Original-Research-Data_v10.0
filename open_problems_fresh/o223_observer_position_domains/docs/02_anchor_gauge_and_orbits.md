## 〇、一句話

「node 0」係**規範標籤**（頂點傳遞，任何節點都可由對稱映射成 node 0），
但**拓撲位元圖案唔係規範不變量** —— 60 個 anchor 給出 **30 個相異阻挫集**，
每個由**恰好一對對徑 anchor** 實現。

## 一、兩層對稱群

### 1.1 幾何 Aut（`scripts/01` §[B]）

**方法**：取 3 個線性獨立頂點 {0, 9, 20} 為標架；對每個候選 (i₀, 有序對 from nbr(i₀))，
精確解 M（`Q.T @ Pinv.T`），要求 M 正交 + 把 60 點映到 60 點集內。

```
|GeoAut| = 60    proper = 60    improper = 0
−I ∉ GeoAut  ⟹  點集手性（無反演對稱）
```

### 1.2 組合 Aut（`scripts/02` §[G]）

**方法**：BFS 排序 + 回溯，逐頂點對已映射鄰居做鄰接一致性剪枝。

```
|Aut(G)| = 120
其中 O(3) 可實現 = 60    純組合 = 60
```

★ 兩種獨立方法互相一致，且對上 O143 docs/08（|Aut| = 120）與 docs/10（真等距 60，全 det=+1）。

### 1.3 物理讀法

```
單一 GL 疇內：只有 60 個 proper 等距可用
穿越 π 相位滑移（疇壁）：局部標架鏡像 ⟹ 另 60 個 improper 組合自同構才解鎖
```

## 三、阻挫集之 anchor 依賴

### 3.1 構造

對每個 anchor a ∈ {0..59}：BFS 2-著色（c[a] = 1）→ 阻挫集
`F(a) = {邊 (i,j) : c[i] = c[j]}`。

### 3.2 結果

```
|F(0)| = 32（= 20 三角形 + 12 五邊形之奇面數）
相異 F(a) 之數目 = 30
每組大小 = 2（60 / 30）
30/30 組之兩個 anchor 恰為圖直徑對（對徑點）
```

### 3.3 穩定子

```
Stab(F(0)) ∩ GeoAut 之階 = 60/30 = 2   = {id, 對徑映射}
Stab(F(0)) ∩ Aut    之階 = 120/30 = 4
```

⟹ **node 0 與 node 57 給同一阻挫集**。此即 O45 §3「對徑點雙重確認」之**圖論必然**
（O45 原文已正確指出「呢個係圖論必然，唔係 anomaly」）。

### 3.4 統計檢定（`scripts/01` §[D]）

```
隨機著色 null（5000 樣本，同尺寸 32-邊集）：mean = 48.02 μK，std = 4.21 μK
anchor 0 : mean|ΔT| = 34.5 μK  ⟹  z = −3.22
anchor 57: 同值（z = −3.22）
60 個 anchor 之 z 分佈：min = −3.22、max = +3.75、mean = +0.40、std = 1.55
z < −2 之 anchor 數 = 2（恰為 {0, 57}）
```

⟹ 與 `cmb_cold_spot/21_anchor_control.md` 完全一致（z = −3.24 vs 本 O −3.22，差 0.02 源於
null 樣本數 5000 vs 原文之基準）。

## 四、★ 鏡像假設之否證（誠實負結果）

### 4.1 假設

「另 60 個 improper 組合自同構（鏡像扇區）會把兩個阻挫集配對，
故完整軌道應為 15（= 30/2）。」

### 4.2 檢定（`scripts/02` §[I]，check I2）

```
阻挫集軌道  幾何群（60）下 = 30
            完整群（120）下 = 30
```

**I2 FAIL** ⟹ 鏡像**唔會**配對圖案。

### 4.3 結論

**30 個圖案在完整 I_h（120）下全部唔等價**（軌道大小 = 30、穩定子階 = 4）。

⟹ 拓撲位元圖案 = **(圖, anchor) 嘅聯合性質**，唔係圖單獨嘅不變量。
「觀察者相對」在此有精確代數意義：**圖案隨 anchor 變，而 anchor 由觀察者所在之飽和疇釘死**。

★ 記錄此負結果之意義：否證了一個「看起來應該成立」之對稱性論證，
並將軌道大小由推測之 15 修正為實測之 30。
