## 一、問題

EPR/Bell 型關聯可以「即時」（共享 Goldstone 相位／全域相干），但信息
（A→B 選擇性編碼，可分辨）唔可以超光速。兩者嘅嚴格結構界喺邊?

## 三、核心區分（結構內容）

| | 模態 | 速度 | 性質 |
|:--|:--|:--|:--|
| **關聯** | n=0 Goldstone（uniform, 全域相干） | 即時（v=c 但冇色散） | 共享 W-field 凝結相位 — EPR/Bell 型對應；非局域、零信息容量 |
| **信息** | n>0（有色散） | v_g < c 嚴格 | A→B 可分辨傳播；越快嘅模色散組合越高, 但上限 v_g(1)=0.99936…c |

**結構界定理**：`即時關聯模態 ∩ 信息載體模態 = ∅`。同一條譜入面，
「夠快」（n=0）嘅模**冇得載信息**（uniform，冇局部分辨能力），
「載得信息」（n>0）嘅模**必然亞光速**。所以：

> **no-signaling 係結構定義：任何 A→B 選擇性編碼嘅載體必有色散 ⟹ v<c；
> 即時性只屬於全域相干（統計關聯），而統計關聯唔構成信息。**

## 四、no-communication theorem 嘅 IDCM 翻譯

QM 版 no-comm theorem：局部操作唔改變遠方嘅 reduced density matrix
（`ρ_B → ρ_B' = Tr_A(U_A ρ U_A†) = ρ_B`）。IDCM 結構版（N4+N6 定量）：

1. 局部自由度差異（信息）只載於 n>0 模——**非局部（n=0）模冇可分辨內容**
2. 資訊沿色散模傳播，每跳最短時間 τ_n ≥ L/(c·v_g) > L/c（n>0 嚴格）
3. 即時部分（n=0）係全域相干——測量佢只得到「共享相位」統計量,
   唔含 A→B 可編碼差異（容量 0）

翻譯結果：**QM「唔可以超光速通信」= IDCM「信息載體必有色散」** —
同一句結構事實嘅兩種語言。QM 要證明；IDCM 由譜直接可見。
