## 一、定理陳述（速度-質量圓定理，Speed-Mass Circle）

令 K_Chain 88-site 譜 `γ_n = 4sin²(πn/88)`、頻率 `ω_n = 2sin(πn/88)`、
波數 `k_n = 2πn/88`（O254 scripts/03 慣例）。則：

```text
T1  群速度閉式:   v_g(n) = dω/dk = cos(πn/88)
T2  速度-質量圓:  v_g(n)² + γ_n/4 = 1            (EXACT, 全 45 模)
T3  上界唯一性:   v_g(n) ≤ 1 = c,  等號 ⟺ n=0     (Goldstone 相位模)
T4  Nyquist:      v_g(44) = 0                    (駐波端)
T5  單調:         v_g(0) > v_g(1) > … > v_g(44)
T6  相速度:       v_p(n) = (88/πn)·sin(πn/88) ≤ 1,  n→0 極限 1
T7  色散曲率:     d²ω/dk² = −½ sin(πn/88) ≤ 0,  零 ⟺ n=0
                  ⟹ 零色散 ⟺ Goldstone（唯一 v=c 嘅模）
T8  ω 圓形式:     (2v_g)² + ω_n² = 4
```

**核心結構內容**：c 唔係輸入公設——係 `γ=4sin²(πn/88)` 譜入面
**無質量模（Goldstone, γ=0, ω=0）嘅群速度**。所有有質量模（γ>0）必然
v_g < c；速度同質量由同一條圓鎖死（`v_g² = 1 − γ/4`），零自由參數。

## 二、N 普適性（scripts/02 U1）

`γ_n(N) = 4sin²(πn/N) ⟹ v_g(n) = cos(πn/N) ≤ 1` 對 **N ∈ {44, 88, 176, 352}**
全成立（全環 + 正半 + 唯一性逐 N 驗證）。⟹ c 上限**唔係 88 嘅特例**，係
`sin²` 譜族嘅普適性質。半整數 shift（O159 176-Laplacian half-site 鏈、
O34 half-site 位置）**唔改變群速度界**（U2/U3：譜 γ 不變 ⟹ v_g 不變）。

**Z₂ 互補對**（U6）：`γ_{88−n} = γ_n`（譜對稱）但 `v_g(88−n) = −v_g(n)` ——
互補對係**反向行波**（同 ω 同 |速度| 反方向），唔係同向。k=0 同 k=176
喺 176-chain 係**雙向 Goldstone**（+c / −c，scripts/02 U2 修正語義）。

## 三、beat 繼承定理（scripts/02 U4, O149 交叉確認）

O149 beat 定理 `beat(a,b) = 4·sin(dπ/176)·v_g((a+b)/2)`（d=|a−b|）——
對**全部 946 對** (a,b) 逐對重驗：**EXACT**（max dev 5.55e-16），且
`v_beat = v_g((a+b)/2) ≤ 1`。⟹ **拍頻傳播同樣受限 v≤c**：資訊經 beat
通道亦冇得超 c。946 對 = C(44,2)（BPT 結構），beat 速度繼承模態群速度。

## 四、扇區和（scripts/02 U5, O201 交叉）
