## 一、定理陳述（速度-質量圓定理，Speed-Mass Circle）

令 K_Chain 88-site 譜 `γ_n = 4sin²(πn/88)`、頻率 `ω_n = 2sin(πn/88)`、
波數 `k_n = 2πn/88`（O254 scripts/03 慣例）。則：

```text
T1  群速度閉式:   v_g(n) = dω/dk = cos(πn/88)
T2  速度-質量圓:  v_g(n)² + γ_n/4 = 1            (EXACT, 全 45 模)
T3  上界唯一性:   v_g(n) ≤ 1 = c,  等號 ⟺ n=0     (Goldstone 相位模)

                  ⟹ 零色散 ⟺ Goldstone（唯一 v=c 嘅模）
T8  ω 圓形式:     (2v_g)² + ω_n² = 4
```

**核心結構內容**：c 唔係輸入公設——係 `γ=4sin²(πn/88)` 譜入面
**無質量模（Goldstone, γ=0, ω=0）嘅群速度**。所有有質量模（γ>0）必然
v_g < c；速度同質量由同一條圓鎖死（`v_g² = 1 − γ/4`），零自由參數。
