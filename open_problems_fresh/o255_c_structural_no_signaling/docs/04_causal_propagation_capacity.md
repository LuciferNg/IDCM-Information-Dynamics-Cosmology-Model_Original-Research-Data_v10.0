## 一、離散亮錐定理（scripts/06 C1-C2）— 時間域核心結果

wave equation `u_tt = Δu`（K_Chain 動力學）離散步進 `u_j(t+1) = u_{j+1}(t) + u_{j−1}(t) − u_j(t−1)`：

```text
初始 δ 於 site C ⟹ u_j(t) = 0 EXACT ∀ |j−C| > t    (Fraction 零容差, 冇 float)
首次響應時間 τ_first(d) = d EXACT (d=1..39)
⟹ 前沿速度 = 1 site/步 = a/τ = c
```

**結構內容**：no-signaling 嘅時間域版本係**精確定理** — 每步資訊至多移動
1 site，遞歸結構直接保證亮錐（唔係數值近似）。`τ_first(d) = d` 以等號
實現 scripts/03 N4 嘅下界 `τ_n ≥ L/c`（n=0 Goldstone 前沿）。

## 二、連續時間尾巴 — Bessel 型指數壓制（scripts/06 C3, 新發現）

連續時間譜和 `u(j,t) = (1/88)Σ_k cos(2πkj/88)cos(ω_k t)`：

```text
|u(t+d, t)|:  d=1 ≈ 0.065 (transition 尺度) → d=7 < 5e-4
每 site 幾何收縮比率 < 0.6 (指數壓制, Lieb-Robinson 型)
限制: t≤30 (j+d<44 半環, 避免 ring wrap)
```

**結構分野（重要）**：
- **離散步進時間**（C1）：嚴格林零 — 尖銳亮錐，資訊絕不越 c·t
- **連續時間極限**（C3）：**唔係嚴格零**，係指數壓制尾巴（Bessel 型）
  — 振幅細但唔消失

物理詮釋：IDCM 嘅「即時測量」操作對應離散步進（每次 tick = 一個 τ），
所以可觀測因果係**嚴格亮錐**；連續時間係數學極限，出指數尾巴但
唔載信息（尾巴振幅衰減，信息容量由速度階梯鎖 — 見 §四）。

## 三、群速度 vs 前沿速度分離（scripts/06 C4）

波包（n=8 載波, v_g=cos(8π/88)=0.9595c）：峰以 v_g·t 移動（實測
60.0 vs 57.6），**同時**前沿以 c 行 — Sommerfeld-Brillouin 型分離：
信息（包峰）< c，前沿（首信號）達 c。與 docs/02 N4/N6 一致：
「最快信息載體 = n=1, v=cos(π/88)=0.99936c」（本 O Round 1 最早信息
模）；呢度補上操作層確認。

## 四、距離相關信道容量 C(L,T)（scripts/07 — 新閉式）

**通道計數閉式（零參數）**：
```text
C(L,T) = #{ n∈{1..43}: τ_n(L) ≤ T } = floor((88/π)·arccos(L/(cT)))
τ_n(L) = L/(c·v_g(n)),  v_g(n) = cos(πn/88)
```

驗證（scripts/07 K1-K6）：
- **閉式 ≡ 暴力**（抽樣格仔全一致）
- **因果閾值**：`C(L,T)=0 ∀ L>cT` — 冇通道 = 結構禁區
- **首次通道**：`C≥1 ⟺ L ≤ cT·cos(π/88)`（n=1 最快信息載體）
- **容量上限 = 43 = N/2−1**（**新發現**）：n=44 Nyquist 駐波 v_g=0 永遠
  唔到達 — **信息行波總量 43, 唔係 44**（駐波只做振盪唔做傳遞）
- 單調：C↑ in T, C↓ in L

**結構意義**：C(L,T) 完全由速度階梯（=群速度譜）計數得來 — 信息可達性
係譜結構嘅直接後果，零自由參數。43 係「信息載體模數量」（88 環扣除
Goldstone 全域相干 1 + Nyquist 駐波 1：88/2 − 1）。
