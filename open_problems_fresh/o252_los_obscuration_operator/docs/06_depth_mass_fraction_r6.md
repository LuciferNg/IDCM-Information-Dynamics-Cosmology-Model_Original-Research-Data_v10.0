## 2. 候選 D-e: 質量 fraction

O179 已閉合 (非 W 算子): M₄/M₀ = 7/15 = L₄/(L₅+B) (hop=4 波節質量 vs hop=0 錨點)

```
τ_eff = ⟨hop⟩·(M₄/M₀) = 4·(7/15) = 28/15 = 1.8667
depth  = 1 − e^{−28/15} = 0.8454
obs 中位 = 0.8158 → dev 3.50% ✅
```

物理: 凝聚層唔係實心全質量 — 有效遮蔽質 fraction = 凝聚重心 vs 錨點質量。

```

        帶幾何 (|v| 依賴)           mass fraction (D-e)
```
