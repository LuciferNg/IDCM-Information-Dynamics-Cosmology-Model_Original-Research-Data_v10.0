## 3. 第二輪: hop 凝聚重心窗 (script 04-05)

推導鏈 (零新常數):
1. hop 階梯 [1,4,8,11,12,11,8,4,1], Σ=60 (O179)
2. 凝聚重心 ⟨hop⟩ = Σh·n(h)/60 = **4.000000 = B** (O179 434/434 錨定)
3. hop=4 → O180 cos² 映射 (θ=π/4→cos²=1/2) → r₄ = R_c/2 = 24.24 kpc
4. 凝聚層轉速 v(r) = √(a₀·r) (O180 EXACT) → **v_abs = √(a₀·R_c/2) = V_max/√2 = 289.76 km/s**

```
τ(v) = τ₀·ℓ_band(θ(v)) + τ_w·exp(−(v∓v_abs)²/2σ²)
  ℓ_band: 近/遠分支光程差 (smooth 帶, 藍弱方向)
  v_abs  = V_max/√2 = 289.76 km/s   ← 凝聚重心窗 (事前預言)
  σ      = c·π/5632 = 167.23 km/s   ← FSR ℓ=3 quantum (record 14)
```
