## 1. τ(v) v2 算子 (零新常數整合版)

```
I_obs(v) = I_int(v) · exp(−τ(v))

τ(v) = τ₀·ℓ_band(θ(v)) + τ_w·exp(−(v∓v_abs)²/2σ²)
     = 帶遮蔽 (常青)       + 凝聚窗 (dip)

帶:  ℓ_band(θ) = 近/遠分支光程差 (R_b/R = 17/15, hop 直徑 8/Σ60)
     確定: 藍弱方向 (record 21 一致) ✅
窗:  v_abs = V_max/2 = 204.89 km/s  (hop=2 候選, post-hoc —— R11)
                   vs V_max/√2 = 289.76 (hop=4 事前 —— R10 出 CI)
     σ = σ₃·(17/15) = 189.52 km/s    (FSR ℓ=3 quantum × 帶厚比) ✅
深度: τ_w = ⟨hop⟩ = 4 → depth_max 0.982 (R2, 上限 top-3 0.923) 🟡
      τ_eff = 4·M₄/M₀ = 28/15 → 0.845 (R6, 中位 hit 3.5%) 🟡
方向: sign ∓ = per-source 側向 — 未閉合 (two-sided p=0.092) 🔴
```

## 6. append-only 註記 (R13 後續): hop 階梯統計量 ≠ 204.9

hop 階梯質量統計 (今日實算):
- Σn = 60 (hop 階梯 [1,4,8,11,12,11,8,4,1])
- ⟨v⟩ = Σ n(h)·v(h) / Σ n(h) = **280.03 km/s** (質量加權平均速度)
- 質量中位層 = h=4 (累積到 36/60), v = 289.8 km/s
- v(h) 階: h=2 → 204.9, h=3 → 250.9, h=4 → 289.8, h=5 → 324.0

⟹ **204.9 (hop=2) 唔可以由 hop 階梯任何質量統計推出** — 任何 hop 質量
加權量 (平均 280 / 中位 289.8) 都喺 280-290 帶, 而唔係 204.9/235.7。
若窗中心真係 ~204-236, 佢需要「吸收截面權重」(每層遮蔽截面 ∝ 唔同
幾何) 而唔係質量權重 — 呢個係**新機制**, 唔係 hop 階梯自然產物。

⟹ hop=2 (204.9) 嘅結構身份進一步削弱: 佢只係「現有結構數中最近
μ_hat 嘅一個」 — 唔係「由結構推出」, 同一 hop=4 (289.76) 事前預言
地位唔對等。窗中心結構身份仍然**開放** (未有第一性原理候選命中
觀測 μ_hat=235.7±21.6), 需要新幾何/機制或高解像樣本分辨。
