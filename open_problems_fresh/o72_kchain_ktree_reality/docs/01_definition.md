## 0. 一分鐘版

**K_Chain** 係一條 44 格嘅圓環 (periodic ring)，上面有 44 個振動模式。每個模式有個「能量」γ_k = 4sin²(πk/88)。呢條環嘅圓周 = R_H = c/H₀ ≈ 4130 Mpc (即係可觀測宇宙嘅「Hubble 半徑」級別)。

**K_Tree** 係一個 33 級嘅尺度階梯，每級尺度 = 上一級 × φ⁻¹，φ = 黃金比例 = 1.618…。即係一條對數尺度嘅樹。

**兩者張量積** K = K_Chain ⊗ K_Tree 產生 44×34 = 1496 個複合模式，每個模式 = (環振動) × (尺度階梯)。

## 1. K_Chain：一條 44 格嘅圓環

### 1.1 定義

K_Chain 係一條由 **44 個點 (site)** 組成嘅週期性圓環 (periodic ring)。喺環上面可以定義波：

```
位置:  1 -- 2 -- 3 -- ... -- 44 -- 1   (週期邊界)
```

每個點嘅「位移」可以振動。呢條環嘅圓周長度係

```
R_H = c / H₀ = 4129.94 Mpc ≈ 1.35 × 10²⁶ m
```

其中 c = 光速, H₀ = 72.59 km/s/Mpc (Hubble 常數)。注意：**R_H 用咗觀測宇宙學嘅 H₀** — 呢個係 IDCM 同 LCDM 共享嘅觀測輸入。

### 1.2 振動模式 (譜)

一條 44-site 週期環嘅振動模式，由離散拉普拉斯算子 (discrete Laplacian) 嘅本徵值決定：

```
γ_k = 4 sin²(πk/88),   k = 1, 2, ..., 44
```

呢個公式係**標準晶格場論**結果：任何一條 N-site periodic ring 上嘅 free scalar field，其色散關係都係 γ_k = 4sin²(πk/2N)。所以：

> **翻譯**: K_Chain = 緊緻 S¹ 圓周 (半徑 R_H/2π) 上 free massless scalar field 嘅晶格正則化。

已驗證 (scripts/01): 88-site Laplacian 本徵值 = 4sin²(πk/88), max err 4e-15。

## 2. K_Tree：一條 33 級嘅尺度階梯

### 2.1 定義

K_Tree 係一條由 **33 個尺度級** 組成嘅對數階梯：

```
μ_m = φ^{L−m},   m = 0, 1, ..., 33
```

其中 φ = (1+√5)/2 = 1.618… (黃金比例), L = 53/8 = 6.625。

- m=0 (最大尺度): μ_0 = φ^6.625 ≈ 24.24
- m=33 (最小尺度): μ_33 = φ^(−26.375) ≈ 3.08×10⁻⁶
- 每級尺度 = 上一級 × φ⁻¹ ≈ ×0.618

即係話 K_Tree 係一個**尺度層級 (scale hierarchy)**，每層之間係黃金比例。

### 2.2 33 嘅來源

33 = h¹¹ − N_gen = 36 − 3，其中:
- h¹¹ = 36 = CY₃ 流形嘅 Kähler moduli 數 (O53/O59 已驗證)
- N_gen = 3 = 粒子物理代數 (三代)

> **翻譯**: K_Tree 嘅 33 級 = CY₃ 內部空間 moduli 36 減去 3 代 = 33 個自由度。

### 2.3 複合譜

張量積 K = K_Chain ⊗ K_Tree 產生複合模式:

```
λ_{n,m} = γ_n · μ_m,   n = 1..44, m = 0..33
```

44 × 34 = **1496** 個複合模式。每個模式 = (環振動能量) × (尺度因子)。
