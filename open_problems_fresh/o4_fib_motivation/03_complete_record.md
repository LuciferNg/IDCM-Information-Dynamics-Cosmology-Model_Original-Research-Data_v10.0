## 1. 問題陳述

SMICA 驗證發現: 節點振幅唔係 uniform, 而係近似 Fibonacci ladder (F₃/F₄/F₅ by BFS 距離)。6level 模型 χ²=1.31 最佳。但**點解係 Fibonacci? 點解 F₃=2, F₄=3, F₅=5? 點解按 BFS 距離? 點解 3 級?** — 未有物理推導。

## 2. 三個核心答案 (閉合!)

### 答案 1: 點解 Fibonacci? — A₅ 群論內建 φ

**A₅ (正二十面體旋轉群) 結構上內建黃金比例:**

| 結構 | 數值 | 閉合 |
|:-----|:-----|:----:|
| cos(36°) = φ/2 | 0.809016994 | 精確 0.00e+00 |
| cos(72°) = (φ-1)/2 | 0.309016994 | 精確 0.00e+00 |
| χ₃(5A) = φ | 1.618034 | 群論事實 |
| χ₃(5B) = 1-φ | -0.618034 | 群論事實 |
| irrep 維數 1,3,3,4,5 | 含 F₄=3, F₅=5 | 維數平方和=60 |

**關鍵: A₅ 有 5-fold 旋轉 (72°) — 正五邊形幾何強制 φ 出現喺群不變量。**

### 答案 2: 點解按 BFS 距離? — 圖譜 λ₂ = φ⁻² 精確閉合

**A₅ Cayley 圖 (60 節點 Rhombicosidodecahedron) 嘅 Laplacian 第二特徵值:**

```
λ₂ = 0.381966011250... = φ⁻² (精確到 8.33e-16, 3.63e-13%)
```

**驗證鐵證 (三層):**
1. **Vertex-transitive**: 60/60 節點 BFS profile 完全一樣 (1,4,8,11,12,11,8,4,1) → 譜唔依賴節點
2. **旋轉不變**: 20 次隨機旋轉 → λ₂ std = 0.00e+00 → 軌道內稟量
3. **對照組**: 隨機 60 點圖 λ₂ ≈ 0 (連通性都冇) → λ₂ = φ⁻² 係 A₅ 結構性稀有

**波方程閉合:**
```
ω₂ = √λ₂ = √φ⁻² = φ⁻¹ = 0.6180339887 (精確到 1.11e-15)
```

→ **圖波方程主模頻率 = φ⁻¹ → 每 hop 振幅衰減 φ⁻¹** → BFS 距離 = 自然衰減坐標!

### 答案 3: 點解 3 級? — ε³ 截斷 = 2+1 結構

```
IDCM 核心: 0,1 → NOT → 2 bits → 2+1 = 3 (data + inversion)
→ 3 代 (SM) = 3 級 (A₅ 振幅) = 同一結構喺兩個維度重現
→ ε³ = 0.003689 → ε³×30 μK = 0.111 μK << 噪聲 45.8 μK
→ ε³ 以下結構不可分辨 → 截斷為 3 級
```

### 冷斑閉合 (振幅)

```
RMS = ε⁵/8 × T_cmb = 30.00 μK   (ε = φ⁻¹/4 = 0.1545084972, T_cmb = 2.72548 K)
A   = 5 × RMS = 5ε⁵/8 × T_cmb = 150.00 μK = F₅
觀測: 冷斑 (node 0) = -134.2 μK @ SMICA 4.17° 平滑, rank 1/60
偏差: |150.0 - 134.2| / 134.2 = 11.8% (振幅, 符號由冷熱決定)
```

3 級 = 3 個拓撲地位: **源 (d=0) + 第一層 (d=1) + 基態 (d≥2)**

## 3. 統計判決: continuous φ^-d 勝出 (BIC)

| 模型 | 參數 k | χ² | χ²/dof | AIC | BIC |
|:-----|:------:|:---:|:------:|:---:|:---:|
| uniform | 1 | 422.5 | 7.16 | 424.5 | 426.6 |
| **continuous φ^-d** | **1** | **33.5** | **0.57** | **35.5** | **37.6** |
| 3lv | 3 | 51.4 | 0.90 | 57.4 | 63.7 |
| 5lv | 5 | 29.6 | 0.54 | 39.6 | 50.1 |
| 6lv | 6 | 30.1 | 0.56 | 42.1 | 54.6 |

**BIC 判決: continuous φ^-d (1 參數) 係最簡模型。**
- 6lv χ² 低只係離散近似嘅自由度優勢 — BIC 懲罰後輸俾 continuous
- **Fibonacci 等級 = φ^(-d) 連續衰減嘅整數閉合取樣**, 唔係 3 個獨立級!

## 4. Fibonacci = φ 嘅整數閉合

| d | F_{5-d} | 5φ^(-d) | 差 |
|:-:|:-------:|:-------:|:--:|
| 0 | F₅ = 5 | 5.000 | 0.0% |
| 1 | F₄ = 3 | 3.090 | 2.9% |
| 2 | F₃ = 2 | 1.910 | 4.7% |

```
F₅ = F₄ + F₃ → 5 = 3 + 2 → 冷斑振幅 = 鄰居層 + 基態層 (疊加原理!)
A(d+1)/A(d) = φ⁻¹  (連續)
F₄/F₅ = 0.600 ≈ φ⁻¹ = 0.618 (2.9%)
F₃/F₄ = 0.667 ≈ φ⁻¹ = 0.618 (7.9%)
```

## 6. 完整結構推導鏈

```
0,1 → NOT → 2 bits → 2+1=3 (data+inversion)   [IDCM 核心]
  → 3 級結構 (ε³ 截斷)
  → K_Chain 44-site ⊗ A₅ (尺度維)
  → A₅ 有 5-fold 元素 → 幾何綁定 φ  [cos(72°)=(φ-1)/2]
  → A₅ 特徵標 χ₃(5A) = φ  [群論]
  → A₅ Cayley 圖譜 λ₂ = φ⁻²  [圖論, 精確 3.6e-13%]
  → 波方程 ω₂ = √λ₂ = φ⁻¹  [動力學, 精確 1.1e-15]
  → 每 hop 振幅衰減 φ⁻¹  [傳播]
  → A(d) = F₅·φ^(-d)  [連續, BIC 最佳]
  → Fibonacci 整數閉合: F₅, F₄, F₃ = 5, 3, 2  [離散取樣]
  → 3 級截斷 (ε³ = 2+1)  [IDCM 結構]
```
