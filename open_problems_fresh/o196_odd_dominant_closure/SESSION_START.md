### T1 🟢 v₁₁(k_n) 11-adic 結構證明（O195 D1 機制化）

**定理**: n < 121 ⟹ v₁₁(k_n) = −n + ⌊(n−1)/11⌋, 即 v₁₁(den k_n) = n − ⌊(n−1)/11⌋。

**證明骨架**（cumulant-MGF 展開, 5 步）:
1. 矩結構: m_j = C(2j,j) + 2^{2j−4}/11 (j≥2), m₁ = 89/44 ⟹ **v₁₁(m_j) = −1 ∀j** (11 ∤ 2^{2j−4})
2. k_n = n![tⁿ]ln M(t) = Σ_{π⊢n} n!·(−1)^{k−1}·((k−1)!/Πp_j!)·Π_j (m_j/j!)^{p_j}
3. 項估值公式: v₁₁(項) = ⌊n/11⌋ + ⌊(k−1)/11⌋ − Σ_j⌊p_j/11⌋ − k − Σ_j p_j⌊j/11⌋
   (Σ⌊p_j/11⌋ 係 p_j! 嘅 Legendre 和, 唔係 v₁₁(p_j) — 本 O 誠實修正 #1)
4. **all-1 分拆 (p₁=n) 係唯一最低 v₁₁ 項**: v = ⌊(n−1)/11⌋ − n = 目標;
   其他分拆 v ≥ 目標+1 (k + Σp_j⌊j/11⌋ ≤ n−1 + Legendre 補償), 窮舉 n=1..30 確認
5. 唯一最低項 ⟹ 冇相消 ⟹ v₁₁(k_n) = −n + ⌊(n−1)/11⌋ QED

**週期 11 = L₅ 機制**: ⌊(n−1)/11⌋ 項 = v₁₁((n−1)!) — all-1 分拆係數 (n−1)!
每過 11 倍數食多一個 11 因子。**anomaly 位 n ≡ 1 mod 11 (12,23,34,45,56,67,78)
= 階乘 11-adic 估值嘅必然跳躍, 唔係 Bell 多項式嘅神奇性質**。
