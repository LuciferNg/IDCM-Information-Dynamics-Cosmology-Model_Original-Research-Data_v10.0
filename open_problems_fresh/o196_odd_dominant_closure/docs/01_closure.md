## 二、T1 — v₁₁(k_n) 11-adic 結構證明 (閉合 🟢)

### 定理

n < 121 ⟹ v₁₁(k_n) = −n + ⌊(n−1)/11⌋, 即 v₁₁(den k_n) = n − ⌊(n−1)/11⌋。

### 證明 (cumulant-MGF 展開, 5 步)

**Step 1 — 矩結構**: M(t) = e^{2t}I₀(2t) + (e^{4t}−1)/176 = Σ m_j t^j/j!,
m_j = C(2j,j) + 2^{2j−4}/11 (j≥2), m₁ = 89/44 = 2 + 1/44。
關鍵: **v₁₁(m_j) = −1 ∀j** — 因為 11 ∤ 2^{2j−4} (11 唔整除 2 嘅任何次方),
C(2j,j) ∈ ℤ 唔影響 11-adic 分母。

**Step 2 — 累積量展開**: k_n = n![tⁿ]ln M(t) = Σ_{π⊢n} n!·(−1)^{k−1}·((k−1)!/Πp_j!)·Π_j (m_j/j!)^{p_j}
其中 k = Σp_j = 分拆部分數, Σ_j p_j·j = n。

**Step 3 — 項估值公式**: 對每個分拆 π:
v₁₁(項) = ⌊n/11⌋ + ⌊(k−1)/11⌋ − Σ_j⌊p_j/11⌋ − k − Σ_j p_j⌊j/11⌋
(注意: Σ⌊p_j/11⌋ 係 v₁₁(Πp_j!) 嘅 Legendre 和, 唔係 v₁₁(p_j)!)

**Step 4 — all-1 分拆係唯一最低項**:
- all-1 (p₁=n, k=n): v = ⌊(n−1)/11⌋ − n = 目標 ✓ (n<121 時 v₁₁(n!) 冇 121 因子)
- 其他分拆: k + Σp_j⌊j/11⌋ ≤ n−1 (等號 iff 唯一 2-part + 其餘 1, 而嗰個 case
  Σ⌊p_j/11⌋ 貢獻 +1 令估值升返) ⟹ v ≥ 目標+1
- 窮舉驗證 n=1..30: all-1 唯一最低 ✓

**Step 5 — 唯一最低項 ⟹ 冇相消**: v₁₁(和) = min(v₁₁(項)) 當最低項唯一。
⟹ v₁₁(k_n) = −n + ⌊(n−1)/11⌋ QED。

### 週期 11 = L₅ 嘅機制來源

v₁₁(k_n) 嘅 ⌊(n−1)/11⌋ 項直接來自 all-1 分拆嘅 (k−1)! = (n−1)!:
**v₁₁((n−1)!) = ⌊(n−1)/11⌋** — (n−1)! 每過 11 倍數多一個 11 因子。
所以 anomaly 位 n ≡ 1 mod 11 (12, 23, 34, 45, 56, 67, 78) 正正係
(n−1)! 啱啱食到新 11 因子嘅位置 — **週期 11 = L₅ 唔係額外輸入, 係
階乘 11-adic 估值嘅必然跳躍**。呢個係 O195 D1「11 週期 anomaly」嘅
組合層證明: 唔係 Bell 多項式嘅神奇性質, 係 m_j 分母 11 + 累積量係數 (k−1)!
嘅標準 11-adic 力學。

**零新常數**: 證明只用 m_j 結構 (11 分母 = L₅ 由 88 = 8·11 邊界項嚟) + 階乘估值。

## 三、T2 — D_n 增長閉式 (閉合 🟢, 修正 O195 B3)

### 奇異點分析 (α 指數)

k_odd = n![tⁿ]artanh(δ), δ = sinh/(88I₀)。奇異點 δ=±1 根 |t| = R = 1.202532。
a_n = [tⁿ]artanh(δ) ~ c·R^{−n}·n^{−α}:

- a_n·Rⁿ·n 線性上升 (0.134@11 → 0.929@79) ⟹ **α = 0 主導** (a_n ~ c·R^{−n})
- a_n·Rⁿ 緩慢收斂 (~0.0118, 尾端變化 0.2%) ⟹ 次 log 修正項 ~ d·R^{−n}/n
- ⟹ k_{n+2}/k_n = (n+2)!/n!·R⁻²·(α=0) = (n+1)(n+2)·R⁻² ✓

**點解 α=0 而唔係 log 奇異點嘅 α=1?** artanh(δ) 喺 δ=±1 兩點都有 log 分支,
但兩根等距 (|r₁|=|r₂|=R) 且相位差 0.70° — 兩根干涉令 1/n 因子相消,
主導變常數。O195 已記錄「δ=±1 等距 ⟹ 交替符號 + 慢收斂」— 呢度係同一結構。

### 殘差結構: 兩根干涉, 唔係 1/n 修正

dev 全部負, 冇符號翻轉, |dev| 由 5.7e-4 (n=9) 緩慢升到 1.5e-3 (n=59)。
dev·n 唔收斂 (−0.005 → −0.089) ⟹ **唔係純 1/n 修正**。
來源: r₁ = 0.0074 + 1.2024i, r₂ = −0.0074 + 1.2024i (實部鏡像對, O195),
1/r₁ⁿ + 1/r₂ⁿ = 2R^{−n}cos(n·Δθ/2)·e^{iθ̄n}, Δθ = 0.70° — cos 項緩慢衰減嘅
干涉修正, 量級 1e-3, 冇獨立閉式 (結構來源清楚: δ=±1 對稱根)。

**結論**: D_{n+2}/D_n = (n+1)(n+2)·R⁻² 係精確首階閉式 (dev ≤ 2e-3),
O195 B3 嘅「1/n 修正項」撤銷 — 正確 pred 唔需要修正項, 殘差係幾何干涉。
