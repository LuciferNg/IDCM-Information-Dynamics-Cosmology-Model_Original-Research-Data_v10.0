## 詳細測試

### 1. 方差檢驗 — 🔴 冇連續異常
- 連續異常 (每節點 +δ 隨機 sign) ⇒ 節點 std 膨脹 √(σ²+δ²)
- 觀察: 節點 std 46.19 vs 隨機場 44.27 μK → F=1.089, χ²(59)=64.2, p=0.596
- 冇膨脹 → 冇全節點幅度增加 (一致性: 06 嘅 mean|T| z=−0.65σ)

### 2. 相位正交檢驗 — 🔴 單尺度無相位結構
- 相位模型 δT=A·cos(θ), A=134.2 μK → |cosθ|=|T|/A
- mean|cosθ| = 0.244 vs 均勻相位期望 2/π=0.637
- fraction(|cosθ|<0.5) = 85.0% vs 均勻 33.3%
- **但** bootstrap 比較隨機場: mean|cosθ| = 0.260±0.025 → z=−0.65σ, p=0.258
- 解讀: 觀察到嘅「正交集中」**同隨機場無異** — 4.17° 平滑後節點 |T| 就係呢個水平
- 相位正交假說**冇額外證據** (但亦冇被否定 — 需要更高 S/N 尺度)

### 3. 跨尺度穩定異常計數 — 🟢🟢 離散性核心證據
- 每節點 10 尺度 (0.5°–10°) z 分數 → 跨尺度 mean|z̄|
- 觀察: 5 節點 |z̄|>2 (idx 0,9,33,47,53), max=2.78σ (node47)
- 隨機模擬 1000 組 (同緯度隨機 60 點, 全尺度): **count(>2σ)=0.00±0.00, max=0.81±0.14**
- p(count≥5) < 0.001, p(max≥2.78) < 0.001
- **結論: 跨尺度穩定異常係真實結構, 唔係隨機場漲落 — 離散性成立**

### 4. BIC — 🔴 單尺度 |T| 分佈無離散雙峰
- M_null (HalfNormal, 1 param): σ=45.82, BIC=550.2
- M_disc (2-component mixture, 3 params): σ1=20.62 (49%), σ2=60.92 (51%), BIC=550.4
- ΔBIC = −0.3 → null 微弱勝出, 冇統計顯著嘅雙峰
- 解讀: 4.17° 單尺度, 5/60 = 8% 異常節點佔比太低, 分佈混合後睇唔出
- **離散性唔需要單尺度雙峰** — 跨尺度穩定性 (test 3) 先係關鍵判據

### 5. 剩餘節點異常上限 — 🔴 剩餘 46 節點完全乾淨
- 剔除 {0, 9, 33, 47, 53} (5 個穩定異常) + ΔE=0 12 節點 (重疊: 33 係 ΔE=0?) → 剩餘 46
- 剩餘 mean|T| = 32.51 vs 隨機 34.97±3.86, z=−0.64σ (單尾 p=0.74)
- 喺隨機 95% 分位 (41.50 μK) 內 ✅
- **異常幅度上限: −2.46±7.72 μK (2σ) → 每節點殘餘 < 5.3 μK (mean|T|)**
- 遠低於 F₅=150 μK 預測 → 剩餘節點**零異常**
