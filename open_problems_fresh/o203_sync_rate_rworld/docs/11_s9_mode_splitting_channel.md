## 一、★ 簡併定理 — 漂移係頻率展寬嘅**唯一**來源

```
O169 docs/13 原文: 「頻率 ω = μ² = 2 係共同常數（唔係逐模自由參數）」
⟹ 冇漂移時, 44 個模態嘅輸運頻率分佈 = DELTA 函數 (完全簡併, 展寬 = 0)
⟹ 漂移係唯一令佢展寬嘅機制
```

漂移下: `ω_±(n) = μ² ∓ g·cosθ_n`, `g = 1/45`, `θ_n = πn/88`。

**精確譜和 (本輪新算, 全部 EXACT)**:

```
Σ_{n=1..44} cos²(πn/88) = 43/2            ⟹ ⟨cos²⟩ = 43/88
Σ_{n=1..44} cos⁴(πn/88) = 16 = 2⁴         ⟹ ⟨cos⁴⟩ = 4/11 = B/L₅   ★
   [閉式推導: cos⁴ = (3 + 4cos2θ + cos4θ)/8; Σcos(πn/44) = −1, Σcos(πn/22) = 0
    ⟹ (1/8)(132 − 4 + 0) = 16]
```

★ **`⟨cos⁴⟩ = 4/11 = B/L₅`** — 同 **O179 嘅 `C = 4/11`** 係同一個常數 (獨立出現)。

**漂移刻印嘅展寬**:

| 量 | 值 |
|:---|:---|
| `σ_ω = g·√⟨cos²⟩` | `(1/45)√(43/88) = 0.0155339` |
| **`σ_ω/μ²` (模分辨展寬)** | **0.7766948%** |
| `⟨cos²⟩_γ = Σγcos²θ/Σγ` | **22/90 = 11/45 = 0.2444444 EXACT** ★ |
| **profile kurtosis** | `⟨cos⁴⟩/⟨cos²⟩² = 2816/1849 = 1.5229854` |

逐模**相對**頻率分裂 `δω/ω = (g/μ²)cosθ_n = (1/90)cos(πn/88)`:

```
n =  1   v_g/c = 0.99936283   δω/ω = 1.1104031%   ← 最大
n = 11   v_g/c = 0.92387953   δω/ω = 1.0265328%
n = 22   v_g/c = 0.70710678   δω/ω = 0.7856742%   ← 半功率模
n = 33   v_g/c = 0.38268343   δω/ω = 0.42520381%
n = 43   v_g/c = 0.035692334  δω/ω = 0.039658149%
n = 44   v_g/c = 0          (Nyquist 駐波)  δω/ω = 0   ← 完全唔分裂
```

⟹ **分裂 ∝ 該模自己嘅群速度** (`δω/ω = (g/2)·(v_g(n)/c)`) — 快模分裂大, Nyquist 模唔分裂。

## 二、★ 判準定理 — 邊類泛函睇得到

| 泛函階 | 漂移效應 | 裁決 |
|:---|:---|:---|
| **一階 (mean)** | `Σ w_n (δ⁺ + δ⁻)/2 = 0` **精確** (任何權重) | 🔴 **結構性盲** (唔係精度不足) |
| **二階** | `⟨δω²⟩ = g²⟨cos²⟩` (均勻: `g²·43/88`; 譜測度: `g²·11/45`) | 🟢 可見 |
| **四階 (kurtosis)** | profile 形狀 `2816/1849` vs 冇漂移時**未定義** (0/0) | 🟢 可見 |

**★ 判準 (可執行)**: **一個通道對漂移敏感 ⟺ 佢讀嘅係輸運頻率分佈嘅 ≥ 二階矩。**

呢個係 docs/10「均值精確不變」嘅**一般化證明** — 唔再係逐案例驗證, 而係一條定理:
任何一階 (線性) 通道**結構上**盲, 唔係「精度未夠」。

**交錯變體 (staggered, docs/10 T3 用過嘅)**: `δω_n = (−1)^n g/μ²`

```
均勻測度: 一階 = 0        (Σ(−1)^n = 0, N_d 為偶)
譜測度:   一階 = (g/μ²)(Tr(LJ)/Σγ) = (1/90)(1/45) = 1/4050 = 2.469e-4  ≠ 0
⟹ 交錯變體**係** mean-visible, 但幅度 1.23e-4 (對應 docs/10 T3 嘅 Δχ² = 0.033 級)
```
