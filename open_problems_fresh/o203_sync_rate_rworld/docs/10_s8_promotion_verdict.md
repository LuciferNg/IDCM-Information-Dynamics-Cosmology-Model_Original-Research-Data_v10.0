## 一、係數唯一性 — 分派 (partition) 論證

**前提 (全部已註冊)**:
- 環嘅運動**精確**係 c: `L_ring = c·T_ring` (O73)。
- 譜跡 `Σγ = 90` 係**守恆荷** (O51); 扇區權重 `Σ_even = 46`, `Σ_odd = 44` (O169/O201)。
- 譜上嘅自然測度係 `γ/Σγ` (機率測度)。

**論證**: 兩個扇區**分派**環嘅運動 ⟹ 份額相加必須 = 1 ⟹ 速度相加必須 = c。

| 歸一化 | 世界份額 | 觀察者份額 | 和 | 漂移 | 判定 |
|:---|:---|:---|:---|:---|:---|
| **A: 守恆荷 Σγ = 90** | 46/90 = 23/45 | 44/90 = 22/45 | **1 (精確)** | **μ²/Σγ = 1/45** | 🟢 **唯一合法** |
| B: site-count 2N_d = 88 | 46/88 | 44/88 | 90/88 = 45/44 = 1.0227 > 1 | μ²/(2N_d) = 1/44 | 🔴 **違反分派** |

⟹ **`g = C_energy·c = c/45` 被唯一強迫**:
`v_world = 23c/45`, `v_obs = 22c/45`, 漂移 `= (46−44)c/90 = c/45`。

### ★ 2.27% 差嘅解釋 (解決 docs/01 C5 / docs/04 遺留)

docs/01 C5 記「O7 寫入 c/44 vs c/45 dev 2.27% **唔閉合**」。本輪證明呢個 2.27% **唔係矛盾**:

```
(1/44)/(1/45) = 45/44 = 90/88 = Σγ/(2N_d) = 1.022727
```

即係**兩個唔同測度之比**:

| 量 | 歸一化 | 身份 |
|:---|:---|:---|
| **c/45** | 守恆荷 Σγ = 90 | **漂移** (扇區速度差; 分派環運動) |
| **c/44** | site-count 2N_d = 88 | **寫入 / site 訪問率** (O7, m/88 過程族) |

兩者係唔同對象, 唔應該相等 — **「唔閉合」係歸一化誤配, 唔係結構矛盾**。

### T4 分支倍增 (mean-invariant) 實現 — 只到 O(g²)

每個 k 同時得 `v⁺` 同 `v⁻` (docs/09 C2) ⟹ **群速度均值精確不變** (docs/09 C2c);
但 `sec = ω/k` 係非線性 ⟹ `<sec>` 只係**一階不變**, 剩 O((g/μ²)²) 修正:

```
Δ<sec>_21 = +0.000177938      (= O((g/μ²)²) = 1.235e-4 量級)
χ² = 2.6496000/6   vs 窗律基線 2.6309184/6   ⟹ Δχ² = +0.0187
```

⟹ **所有 O169 閉合 (ω² = k²+m² 44/44, 組裝律 E(ℓ) = ℓ+⟨sec⟩, 窗端點 21/28, a=1) 完好** —
最大擾動 Δχ² = 0.033 ≪ 1 (6 dof)。

### 物理讀法

Z₂-奇量嘅後果: 漂移喺**群速度均值上精確抵消** (C2c), 喺 `<sec>` 上只剩 O(g²) 殘餘。
呢個解釋咗「點解一直冇見到漂移」— 唔係因為佢唔存在, 而係因為**所有既有通道都係 mean**,
而漂移嘅 mean 效應係 O(g²) = 1.2e-4 級 ⟹ Δχ² ~ 0.02 級, 任何既有擬合都睇唔到。
效應只出現喺**模分裂** (非 mean), 需要模分辨 (非平均) 嘅通道先睇得到。
