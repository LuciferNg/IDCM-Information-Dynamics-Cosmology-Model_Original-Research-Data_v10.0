## 一、三個嚴格定理 (排除「自主動力學」路線)

### A1 Niven 定理 — 冇任何單一模態嘅 v_g = c/45

`v_g(n) = cos(πn/88)`。Niven 定理: `cos(qπ)` 為有理數 ⟺ `cos ∈ {0, ±1/2, ±1}`。
本譜 q = n/88, `cos = 1/2` 需要 `n = 88/3 ∉ ℤ` ⟹ 唯一有理值 = `{0}` (n=44)。

```
44-mode 譜:   min |cos(πn/88) − 1/45| = 0.0134701   (n=43, 相對 60.6%)
176-鏈譜:     min 相對偏差 = 19.68%                  (最近 k=87)
相速度族:     sec(πn/88) ≥ 1 > 1/45  ∀n  ⟹ 相速度唔可能係漂移
Nyquist n=44: v_g = 0 精確 (駐波) ⟹ sec 發散 (1/v_g = 1.75e+61)
              ⟹ 所有調和平均 / sec-加權速度族**結構上發散而排除**
```

**結論**: 單模、相速度、以及全部 sec-加權族 (含調和平均) 結構上排除。**冇新常數可用。**

### A2 k-對稱 / 時間反演 — 自由理論冇定向漂移

`ω² = k² + m²` 為 k 嘅偶函數 (44/44 驗證) ⟹ `v_g(k) = −v_g(−k)`。
自由 IDCM Lagrangian **冇偏好方向** ⟹ **任何漂移必須由外部不對稱 (Z₂-奇源) 提供**。
(呢個係後面 §三 嘅關鍵: 漂移唔可能「自主」, 只可能係「響應」。)

### A3 [L,J] = 0 — Z₂ 荷係守恆譜不變量, 唔係流

模式基下 `L = diag(γ_n)`, `J = diag((−1)^n)` ⟹ `[L,J] = 0` 精確 (max = 0.0)。

```
Tr(LJ) = Σ_n (−1)^n γ_n = γ_22 = μ² = 2  EXACT
C_energy = Tr(LJ)/Tr(L) = μ²/(2N_d+μ²) = 1/45  EXACT
```

**結論**: Z₂ 荷**精確守恆** ⟹ 冇 Z₂ 流 ⟹ 唔可以從它構造漂移速度。
`C_energy` 係**靜態譜權重** (superselection 份額), 唔係輸運係數。
