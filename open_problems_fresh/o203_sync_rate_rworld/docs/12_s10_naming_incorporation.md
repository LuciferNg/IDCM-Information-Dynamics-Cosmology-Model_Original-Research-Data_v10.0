## 二、★ 收編判決 — 「同步速率」係**族名**, 唔係參數名

```
「同步速率」 ≜ 同步速度譜 (sync velocity spectrum)
             = O140 §2.1 嘅 v_g 階梯  {v_g(n) = c·cos(πn/88), n = 1..44}
```

**關鍵語意裁定**: 「同步速率」**唔可以當參數用**。
docs/02 雙維度 PSLQ 已證: 任何 `v_sync = βc` 代入 `R_world = ω_ring(1±β)^p φ^q` 全滅 + null 背景
(1/β 全 tautology/trap)。所以呢個名**只能**指向已註冊結構, 唔可以引入自由標度。
⟹ 呢個係 O203 嘅核心答案: **K_Chain 有速率而無「同步速率」之名** — 命名缺口, 唔係結構缺口。

**命名紀律 (本輪確立)**:
1. **族名 vs 參數名** — 族名 (N1/N2) 唔可以出現在擬合式作為自由標度; 只可作結構指涉。
2. **一名一結構** — 每個新名必須指向**已註冊**結構 (零新常數); 唔可以係新推導嘅別名。
3. **語意補註唔改公式** — 本檔零公式改動; 舊文檔 (O140/O138/O7) **原文不動**, 只加交叉引用。
4. **同名不同量要標** — 見 §四。
