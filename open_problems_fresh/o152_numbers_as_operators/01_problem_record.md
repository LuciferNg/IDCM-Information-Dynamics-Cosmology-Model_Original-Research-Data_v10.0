## 一、問題

O149 定理 1-2 確立：beat(a,b) = 4sin(dπ/176)·v_g((a+b)/2), ω_n = 2v_g(44−n), γ_n = 4v_g(44−n)² — **數字係算子嘅譜數據**。
O151 確立：C_obs = N_d·log₂B = 88 = Σγ_odd（dev=0）, E_min = (41/60)×(90/88) = f_unproj×(Σγ_even/Σγ_odd) EXACT — **數字係算子比率**。

**核心假定（Postulate）**:

> **數字即算子**：IDCM 中任何有意義數字 n 唔係裸值 — 佢係某個算子嘅譜數據（本徵值 / 跡 / 行列式 / 維數 / 秩 / 拍頻 / 投影係數 / 資訊量），而「算子功能」就係該算子喺 K_chain ⊗ K_tree 結構中所執行嘅操作。

**任務**: 用譜幾何系統性地找出**所有**數字（整數、分數、半整數）及每個數字嘅**算子功能**，建成「算子字典」（Operator Dictionary）：

1. **整數**: 2, 3, 4, 6, 8, 11, 12, 13, 16, 17, 18, 22, 30, 33, 36, 41, 44, 45, 46, 60, 66, 77, 88, 90, 98, 123, 124, 132, 137, 143, 176, 178, 192, 264, 369, 528, 946, ...
2. **分數**: 1/2, 3/2, 13/2, 19/123, 41/60, 61/88, 90/88, 123/176, 123/88, 4/(φ⁴−1), ...
3. **半整數**: 43.5（beat 零點縫, O36/O39）, 61.5（L₁₀/2, O41）, 6.5（F₇/2 = Ω_DM/Ω_b）, 0.5（log₄2）, 44 個半整數縫 {0.5..43.5}（觀察者子空間, O34）, ...

**關鍵問題**:

- Q1: 有冇一個**完備算子族**（生成算子 × 譜函數）可以產生 IDCM 所有數字, 而唔係每個數字各自搵來源？
- Q2: 每個數字嘅「算子功能」係咩？— 例如 88 唔單止係數值, 佢係「觀察者容量算子」C_obs = N_d·log₂B；528 係「全息維數算子」N_d×dim(G_SM)。
- Q3: 數字之間嘅**算子代數**係咩？— 例如 88×E_min = 61.5, 528×E_min = 369：乘法 = 算子複合（容量 ∘ 能量）。
- Q4: 邊啲數字未有算子身份（🔴 naming / 巧合）？— 誠實清單。

## 四、攻擊路線

- **R1 算子分類法**: 定義生成算子族（T̂, K_chain, K_tree, v_g, beat, projection, log₂, SU(12), CY₃）× 譜函數（本徵值/跡/維數/秩/和/比率/拍頻/投影係數）→ 分類矩陣
- **R2 數字庫盤點**: 從 memory + docs + verify_all formulas.yaml + O 系列記錄抽取所有數字（整數/分數/半整數）, 建成 YAML 數字庫
- **R3 逐數分類**: 每個數字 → 算子功能 → 驗證（計算復現, 唔准命名）
- **R4 算子代數**: 數字之間嘅乘法/加法/比率 = 算子複合; 檢查 C×E_min 全階梯、f_unproj 共同因子、Lucas 階梯互鎖
- **R5 誠實判決**: 每個數字標 🟢（零參數結構閉合）/ 🟡（側推/多重身份）/ 🔴（naming/巧合）; φ-陷阱窗 (1e-5, 1e-3) 內一律排除
- **R6 字典輸出**: 完整算子字典表（數值 × 算子 × 譜函數 × 功能 × 狀態）+ docs 推導 + scripts 驗證
