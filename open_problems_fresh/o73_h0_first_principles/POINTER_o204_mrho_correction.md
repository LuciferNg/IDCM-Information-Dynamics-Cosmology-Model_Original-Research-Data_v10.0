## 註記內容

**此值為錯。** 正確值 = `V''(W₀) = 4μ² = 8`。

## 代數 (O204 scripts/03 §B5 已驗證, 4/4 PASS)

```
V = −μ²|W|² + λ|W|⁴,  μ² = 2, λ = 2/123, ⟨W⟩² = μ²/(2λ) = 61.5
V''(W) = −2μ² + 12λW²
V''(W₀) = −2μ² + 12λ·61.5 = −2μ² + 6μ² = 4μ² = 8
數值二階差分獨立確認 = 8.0
```

反證 2μ²: 需 `12λW² = 4μ²` ⟹ `W² = μ²/(3λ) = 41.0`, 但 `V' = 0` 要求 `W² = 61.5`
⟹ 矛盾 ⟹ 2μ² 不可能。

# ★ 附錄（2026-09-18 第三輪）：根因修正

## 兩個歸一化

| 版本 | 極分解 | 徑向二階導 | 值 |
|---|---|---|---|
| v6.0 `W_field_waves` §2.1 | `W = (1/√2)ρe^{iθ}`，`ρ = √2\|W\|` | `V''(ρ₀) = −ε + 3κρ₀²` | **2ε** |

鏈鎖律：`ρ_v6 = √2·\|W\|` ⟹ `d²/dρ_v6² = ½·d²/d\|W\|²` ⟹ **`2ε = 4ε/2`** ✓
兩者係同一量之兩個場歸一化。**歸一化無關之結構比值：`m_ρ²/μ² = 4`**（兩版本一致）。

## 根因

v6.0 用 `W = (1/√2)ρe^{iθ}` 得 `V''(ρ₀) = 2ε`。
O73 §1 換成 v10 之 `\|W\|` 分解（`W = (W₀+ρ)e^{iθ}`）時，**只換了 ε → μ² 而冇換因子 2**。

> **同一文檔內『分解約定係 \|W\| 但數字用 2×』⟹ 自身不一致。**
> **裁決值 `4μ² = 8` 維持**（O73 自身之分解約定要求此值）。
> 性質由「算錯」修正為「跨版本約定搬字」。

## 可複用教訓

跨版本引用數字時，**必須同時核對歸一化約定**（此例：`2ε` vs `4μ²` 差因子 2，
源自 `ρ = √2\|W\|` 之鏈鎖律）。只換參數符號（ε→μ²）而唔換因子 = 系統性錯誤模式。
