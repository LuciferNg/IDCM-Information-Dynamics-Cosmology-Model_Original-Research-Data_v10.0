## 1. ★ 誤判修正 — 上輪「影響 = 0 於 c」不成立

`docs/16` §5 寫「c = R_world·ω_ring 影響 = 0（裸環頻率身份不變）」。
**該恆等本身無誤**, 但**漏查 `docs/14` §9.2 之 c 自洽解**:

```
§9.2 自洽解:  c⁵ = R_world² · (8πG/3) · (η_B m_p/Ω_b) · (2ζ(3)/π²) · (k_B T)³ / ħ³
              ⇒ c ∝ (η_B/Ω_b)^(1/5)   [若 η_B 為獨立輸入]  ⇒ 依賴 Ω_b ✗
```

| η_B 輸入 | Ω_b | c_derived | dev vs SI c |
|:--|:--|:--|:--|
| 6.0636e-10 (O73 舊結構) | 19/450 | 299600.87 | **−0.064%** ← docs/14 §9.2 報值 ✓ 重現 |
| 6.104e-10 (Planck D/H) | 19/450 | 299999.04 | +0.069% |
| 6.0636e-10 | **1/20** | 289639.17 | **−3.387%** ✗✗ |
| 6.104e-10 | **1/20** | 290024.10 | **−3.258%** ✗✗ |

⇒ **Ω_b = 1/20 直接代入令 c 自洽解爆開 −3.3%。上輪「影響 = 0」為誤。**

> ★ 補充結構洞察: `docs/14` §9.2 用嘅 η_B = 6.0636e-10 係 **O73 結構值** (配 Ω_b = 19/450,
> h = 0.7259), 唔係 Planck 觀測值 6.104e-10。因 η_B = Ω_b h²·C (結構定義),
> 故 η_B/Ω_b = h²C **唔依賴 Ω_b** ⇒ 該式之真正輸入係 **h**, c⁵ ∝ h²。
> 呢個隱含結構令「Ω_b 改變」表面上被 η_B 吸收, 但一旦 η_B 改用外部值 (Planck),
> Ω_b 依賴立即顯現。

## 3. ★ 新張力 — Ω_b h² 之 h 類別問題

### 3.1 舊版「Ω_b h² 閉合」係類別錯誤

`Ω_b h²` 中嘅 h 係 **FRW 膨脹率 H₀/100**, 唔係裸環頻率 ω_ring/100。

| Ω_b | h 用值 | Ω_b h² | dev vs Planck 0.02237 | σ |
|:--|:--|:--|:--|:--|
| 19/450 | 裸 ω_ring/100 = 0.7259 | 0.0222482 | −0.545% | −0.81σ ← 舊「閉合」**用錯 h** |
| 19/450 | h_cmb = 0.674071 | 0.0191846 | **−14.24%** | **−21.2σ** ✗✗ |
| 3/60 | 裸 ω_ring/100 = 0.7259 | 0.0263465 | +17.78% | +26.5σ ✗✗ |
| **3/60** | **h_cmb = 0.674071** | **0.0227186** | **+1.558%** | **+2.32σ** 🟡 |
| **3/60** | **h = 2/3 = 0.666667** | **0.0222222 = 1/45** | **−0.661%** | **−0.99σ** ✅ |

⇒ 用**正確嘅 h_cmb**: 新版 (+1.56%) 遠優於舊版 (**−14.24%**)。舊版嘅「−0.55% 閉合」係
因為用裸 ω_ring 當 h — 類別錯誤下嘅巧合。

### 3.2 剩餘 🟡 張力 — IDCM 嘅 H₀ 精確值

```
若 H₀ = h_cmb × 100 = 67.4071 (O167 🟢, vs Planck H₀ 0.09σ):
   Ω_b h² = 0.0227186  ⇒  η_B = 6.2116e-10   ⇒  +1.558% vs Planck (+2.32σ) 🟡
若 H₀ = 2/3 × 100 = 66.6667:
   Ω_b h² = 1/45 EXACT  ⇒  η_B = 6.0759e-10   ⇒  −0.661% vs Planck (−0.99σ) ✅
   但 H₀ = 66.667 vs Planck 67.36 = −1.02% (1.3σ); vs h_cmb 67.407 = −1.10%
```

★ 兩者各有優劣: `h_cmb` 贏 H₀ 層 (O167 已驗證 🟢); `2/3` 贏 Ω_b h² 層 (O199 強逼值 1/45)。
差 **1.11% = 1/90**。此為**新開放項** (需上游裁定 IDCM 之 H₀ 精確結構值)。
