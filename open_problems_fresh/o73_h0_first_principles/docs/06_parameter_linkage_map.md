## 3. 命名決定: Ω_Λ / Ω_m 要改 (建議)

### 3.1 點解要改

```
❌ 「Ω」符號包袱: Ω = ρ/ρ_c, ρ_c = 3H²/8πG — 依賴 FLRW 臨界密度!
   IDCM 冇膨脹 → 冇 ρ_c 概念 → 用 Ω 係語意矛盾

✅ IDCM 真實身份: K_Chain 譜能量配分 (E_unproj/E_total)
   Ω_Λ = 61.5/90 = 未被投影能量比例 (O33/O34 已閉合)
   → 唔係「密度參數」, 係「能量配分」— 同 ΛCDM 嘅 Ω_Λ 名同實異
```
