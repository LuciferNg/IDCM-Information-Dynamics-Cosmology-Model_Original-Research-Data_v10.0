## 一、Part A（#3）：tie 宇稱動力效應之**機制層**——已定

**★ 機制公式（A3a，7440/7440 條目精確）**
```
non-tie (s,a)：K = K_prod = K_neg = sgn(⟨U[a], KV[s]⟩)                      （三變體同值）
tie     (s,a)：K = ε(s) := firstsgn(KV[s])            ← 只依「態」
               K_prod = γ(a,s) := firstsgn(u × r)     ← 依「列 a」與「態」

```
⟹ tie 條目之差異**完全**由「讀出物件」決定：機器讀 `r`（= ε，只依態），正則讀 `(⟨u,r⟩, u×r)`（= γ，依列與態）。

**★ 分解（A2）**：`overrides = OT^clean + OT^tie`，`OT^clean = 5760` 於三變體**逐態相同**；
