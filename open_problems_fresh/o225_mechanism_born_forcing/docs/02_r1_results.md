## §0 一句話
**障礙唔係「K 帶號」、亦唔係「列和 ≠ 1」，而係一條精確、可定位、可移除嘅結構**：
凍結 62 軸係**對負封閉**（31 對蹠對），非 tie 條目兩兩抵消；而 **tie 規則（dot = 0）對 u → −u 係「偶」**
⟹ 每 row 之 10 個 tie 條目唔抵消且**同號** ⟹ `R(s) = Σ_a K[s,a] = Σ_{tie} = ±10`。
由此：仿射 Born 權重族**唯一**歸一解 = 均勻（態盲目）；而**改 tie 規則之 u-宇稱（1 個二元約定、0 新參數、0 新欄）**即令 `R ≡ 0`，
態敏感、非負、歸一之 Born 型權重族**即刻出現** ⟹ **障礙厚 1 bit，唔係 10 欄。**

## §1 判決項 1 — 障礙定理（充要形式）✅（在仿射族內為充要）
**定理 A（精確，機器 P4a–P4d ＋ 審計 A5）**：設讀出表 `X ∈ R^{120×n}`，`W = alpha·J + beta·X`（全域 alpha, beta）。
則存在「非負 ＋ 歸一 ＋ 態敏感」解
```
⟺ R_X(s) := Σ_a X[s,a] 在 s 上恆常數
```
- 若 `R_X` 非常數：歸一方程 `n·alpha + beta·R_X(s) = 1` 迫使 `beta = 0` ⟹ `alpha = 1/n` ⟹ `W` 均勻 ⟹ 態盲目。
- 若 `R_X ≡ r`：`alpha = (1 − beta·r)/n`，`|beta| <= 1/n` 時非負、`beta ≠ 0` 時態敏感（相異 row 數 = 12）。
- 凍結 `K`：解集 = **單點** `{(1/62, 0)}`（精確 Gauss；Cramer 獨立覆核 det = −1240）⟹ `W = 1/62` 恆等均勻。
⟹ **比 O222 之「列和 ≠ 1」更精確**：真正條件係 **`R` 非常數**（`R ≠ 1` 只係其必要但唔充分之表述）；
`K` 之實際值域 = `{−10, +10}`（60/60），**唔止「≠ 1」**。

**定理 B（`R = ±10` 之精確機制，`scripts/07` T1–T3）**：
```
T1  凍結 62 軸對負封閉（31 對蹠對）；非 tie 條目因 dot 變號而兩兩抵消 ⟹ 對 R 零貢獻
T2  tie 條目總數 = 1200（= 16.13% of 7440，與 O222 docs/13 §2(b) 之 16.13% 一致），每 row 恰 10 個
T3  tie 規則取「r_s 之首個非零分量之符號」= 與 u 無關（u-**偶**）⟹ 對蹠對**唔**抵消
    ⟹ R(s) = Σ_{tie} tie_sign，且每 row 之 10 個 tie **同號** ⟹ R(s) = ±10 恰（逐 row 精確吻合）
```
（120 個 row 全部「5 對 tie 同號」——若隨機，機率 = (1/16)^120；此為**結構剛性**，非巧合。）

## §2 判決項 2 — 最小修改族（5 族全部判定）
| 族 | 判定 | 精確依據 |
|:--|:--|:--|
| **M-a 附加欄（±1、欄平衡）** | 🟡 可行但**唔係最小** | `m_min = 10` = `ceil(Delta/2)`（`Delta = 20`）；**唯一**解 = 10 欄完全相同之 `−theta`（`theta = sign R`），自動欄平衡（`Σ_s c_i = 0`）；`m <= 9` 不可能（`2m >= Delta`，P7 [PROOF]）；修復後 `n = 72`、`R' ≡ 0`、`alpha = 1/72`、**1 參數族**、`|beta| <= 1/72` 非負、`beta ≠ 0` 態敏感（相異 row = 12） |
| **M-b 改 tie 規則之 u-宇稱** | ✅ **最小（0 新欄、0 新參數、1 bit 約定）** | tie 規則改為 u-**奇**（`dot = 0 ⟹ sgn(u × r_s 之首非零分量)`）⟹ `R ≡ 0`；`W = 1/62 + beta·K_b`（`beta = ±1/62`）皆非負＋歸一＋態敏感；讀出表仍屬 `{±1}` 族（T4–T6） |
| **M1 複讀出（per-context 相位）** | 🔴 不可能 | 相位修復存在 ⟺ `1 ∈ range(K)` ⟺ `rank[K\|1] = rank(K)`；實測 **7 > 6** ⟹ 不存在（精確秩判準，零三角）。全域相位：`|z| ≡ 1` ⟹ 均勻 ⟹ 態盲目 |
| **M2 非決定讀出** | 🔴 唔屬「修改」 | `W = p` 任意需 `120·61 = 7320` 個自由實數；凍結機器可及隨機性 = 60 行為（`2^5 = 32 < 60 <= 64 = 2^6`，< 6 bits）⟹ 係加新獨立隨機源 |
| **M3 多副本 k** | 🔴 障礙線性加劇 | `Delta_k = 20k`、`m_min = 10k`（k = 1..4 全部驗）⟹ 加副本**唔會**產生 Born 權重 |

**★ 最小性結論**：障礙之最小移除 = **tie 規則之 1 bit 宇稱選擇**（M-b）；若限定「唔准改凍結之 tie 約定、只准加欄」，
則最小 = **10 欄之 `−theta`**（M-a），而 `10 = Delta/2 = |Stab(theta)| = 120/12`（三者一致，見 §4 null）。
