## Part A —— 軌跡引理 ＋ 事件歸約 ＋ 逐事件 x-和（Σf 機制）

**A1【推導 + 核】軌跡引理**：協定狀態推進為右乘 ⟹ `s_t(s0) = s0·Γ_t`，`Γ_t := h(c_1)·…·h(c_t)`
（`Γ` **與 s0 無關**）。識別程序：全協定從 `s0 = e` 跑一次取 `Γ_t`；另取 4 個 `s0` 跑**前 300 對**
之截斷協定，逐 (s0, t) 核 `s_t = s0·Γ_t`，要求 **0 偏離**。

**A2【推導 + 核】事件歸約**：每比較事件記 `(a, t_w, t_r)`（`a` = 列、`t_w`/`t_r` = 寫／讀之時間指數），
`g_e := Γ_{t_r}^{-1}·Γ_{t_w}`（⟹ `s_w = s_r·g_e`）。由於 `s0 ↦ s0·Γ_{t_r}` 為雙射：
```
Σ_{s0} f_tf(s0) = Σ_{e∈TF} W_e,   W_e := Σ_{x∈120} d(x,a_e)·ε(x)·sgn⟨U[a_e], KV[x·g_e]⟩
Σ_{s0} f_ft(s0) = Σ_{e∈FT} W'_e,  W'_e := Σ_{x∈120} d(x,a_e)·ε(x)·ε(x·ĥ_e),  ĥ_e := Γ_{t_w}^{-1}·Γ_{t_r}
```
識別程序：以 R8 `data/31_r8_group.json` 之逐態 f 為輸入（左側 = **0**），右側逐事件算出，要求**相等（0 偏離）**；
並以三條獨立算式（直接 120 項和／按 (a,g) 快取／按 (a,g) 群化重算）互核。

**A3【推導 + 核】逐 tie 條目恆等式**：對 tie 條目（`ε,γ ∈ {±1}`）：
```
ε(x)·d(x,a) = (ε(x) − γ(a,x)) / 2
```
識別程序：全部 tie 條目（120 態 × 各 10 = 1200 條）逐條核，要求 **0 偏離**。
⟹ 推論：`W(a,g) = ½[ W1(a,g) − W2(a,g) ]`，`W1 := Σ_{tie x} ε(x)B(x)`、`W2 := Σ_{tie x} γ(a,x)B(x)`、
`B(x) := sgn⟨U[a], KV[x·g]⟩`（求和域 = `tie(x,a)` 之 x）。

**A4【見數前預測】事件級依賴**：`Φ_e(x) := d(x,a_e)ε(x)·sgn⟨U[a_e],KV[x·g_e]⟩` 之 120 維向量
**只依 `(a_e, g_e)`**（同 `(a_e,g_e)` 之兩事件之 120 維向量逐分量相同），要求 **0 偏離**。

**A5【見數前預測】逐事件 x-和之消失**（本輪核心）：
- **A5a**：對**全部** (T,F) 事件 `W_e = 0`，且對**全部** (F,T) 事件 `W'_e = 0`（0 偏離）
  ⟹ 即 `Σ_s f_tf = Σ_s f_ft = 0` 之**局部**機制（非僅全域抵消）。
- **A5b**：對 (T,T) 事件 `W''_e := Σ_x [d(x,a) ≠ d(x·ĥ,a)]·ε(x)·ε(x·ĥ)`；報告其值集與 **Σ = 64** 之承載。
- **A5c**（A5a 若敗才判）：`W(a,g) = −W(ā,g)`（`ā` = `a` 之對徑列）逐 `(a,g)`。
- **A5d**（A5a 若敗才判）：`W(a,g) = −W(a,g^{-1})` 逐 `(a,g)`。

**A6【見數前預測】兩半相等**：對全部 (T,F) 事件，`W1(a,g) = W2(a,g)`（即 A3 推論之兩半逐事件相等）。

**A7【報告】`(a,g)` 表**：相異 `(a,g)` 對數、`n(a,g)` 重數分佈、`W` 之值集與值譜、`g` 之階分佈；
事件類計數（TF/FT/TT）與 R6 之 11200/1120/1280/1280 對照。
