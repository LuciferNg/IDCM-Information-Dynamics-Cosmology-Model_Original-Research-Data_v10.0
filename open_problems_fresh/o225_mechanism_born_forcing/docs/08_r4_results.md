## 一、核心結論（四條）

**① 障礙之算術機制（R1 重導）**
```
62 軸恰成 31 對精確負（U[ā] = −U[a]；15 edge + 10 face + 6 vertex）
非 tie 條目  K[s][ā] = −K[s][a]  ⟹ 26 對精確對消
tie  條目  K[s][ā] = +K[s][a]  ⟹ 5 對相加（因凍結 tie 分支只依 r_s，唔依 U[a]）
⟹ R(s) = Σ_a K[s][a] = 2·τ(s)·n_tie(s)，n_tie ≡ 5，τ(s) = sgn(r_s 之第一個非零分量)
⟹ R ∈ {−10,+10}、Δ = 20、m_min = ceil(Δ/2) = 10 = 2×5（A = 0，m = 9 不可行）
```
R1 之三個 10 之關係因此清楚：`m_min = Δ/2 = n_tie×2/2 = n_tie`（**同一計數**：tie 對數），
而 `|Stab θ| = 120/12 = 10` 係**另一個獨立群論量**（子表 face/vertex 之 `n_tie = 0` ⟹ 兩者非同一機制）。

**② ★★ 頭條：M-b 唔係「額外修改」，而係同一符號函數之正則延拓**
```
定義 乘積層讀出 Λ(conj(r)·u) = Λ(⟨u,r⟩, u×r)（首非零分量；次序：實部, i, j, k）
P4a：全部 7440 條目 == M-b                       （7440/7440，0 例外）
P4b：全部非 tie 條目 == 機器 K                    （6240/6240，0 例外）
P4c：tie 條目只 600/1200 一致
⟹ 機器之 tie 分支（讀 r 自身）唔係「單一物件之首非零分量」函數；乘法層讀出才是
⟹ 正則性判決：M-b = 同一個 sgn(⟨u,r⟩) 讀出函數在 tie 上之**正規延拓**；
   「機器 K 之 tie 分支」才是偏離者（讀另一個物件）
```

**③ u-宇稱充要（障礙 = 一個宇稱位）**
```
候選族（6 個）逐個造 tie 規則、逐個算 R：
  X = r（機器型）      u-奇 = False  ⟹ R = {−10, +10}
  X = u                u-奇 = True   ⟹ R = {0}
  X = u×r              u-奇 = True   ⟹ R = {0}
  X = u+r              u-奇 = False  ⟹ R = {−10,−6,0,6,10}
  X = u−r              u-奇 = False  ⟹ R = {−10,−6,0,6,10}
  X = conj(r)·u        u-奇 = True   ⟹ R = {0}
判準「R ≡ 0 ⟺ tie 規則 u-奇（X(−u,r) = −X(u,r)）」在整族上成立
200 旋轉機器：u-偶規則 ⟹ |R(s)| = 2·n_tie(s)（200/200）；u-奇 ⟹ R ≡ 0（200/200）
子表：edge(30) n_tie = 5, R = ±10, m_min = 10；face(20)/vertex(12) n_tie = 0, R ≡ 0, m_min = 0
⟹ 障礙量由**一個宇稱位**完全決定，無其它自由度
```

**④ tie 位之分解（R1 開放項 #2 之判決）**
```
障礙位（affects R）：讀出物件之宇稱 —— 「乘積層（u-奇）」vs「r-only（u-偶）」
R-中性位（唔 affect R）：向量部符號（(⟨u,r⟩,+u×r) 與 (⟨u,r⟩,−u×r) 兩者皆 R ≡ 0，
                        但 tie 值全 1200 條相異）
⟹ 「乘積層 + 非 tie 一致」唔足以唯一固定 tie 位（本輪預註冊之唯一性**被否證**，誠實報）
⟹ 判決：M-b 之「1 bit」= **讀出約定**，唔係新增物理輸入；
   真正有動力效應者只有「產品層 vs r-only」一項（而正則選擇 = 產品層）
```
