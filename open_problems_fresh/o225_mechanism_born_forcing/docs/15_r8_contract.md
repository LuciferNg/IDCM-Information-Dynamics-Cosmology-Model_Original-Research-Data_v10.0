## Part C（★ 推導項；**先寫推導，後核實**）— 每態 `Σ_a d ≡ 5` 之解析來源

**C1（對徑配對律，推導）**：對 tie 條目 `(s,a)`，設 `ā` = `a` 之對徑列（`U[ā] = −U[a]`）。則
```
γ(ā,s) = firstsgn(cross(−u_a, r)) = −firstsgn(cross(u_a, r)) = −γ(a,s)
⟹ d(ā,s) = [−γ(a,s) ≠ ε(s)] = [γ(a,s) ≠ −ε(s)] = 1 − d(a,s)      （因 γ、ε ∈ {±1}）
```
⟹ 每個「對徑列對」恰貢獻 1 個分歧；且 `tie(s,a) ⟺ tie(s,ā)`（因 `−U[a] ⟂ KV[s] ⟺ U[a] ⟂ KV[s]`）。
宣稱：逐 tie 條目 `d(s,ā) = 1 − d(s,a)`（0 偏離）。

**C2（每態 tie 條目數 = 10，推導）**：`tie(s,a) ⟺ U[a] ⟂ KV[s]`。由 R6 C2 之完備正交圖（與一個頂點方向正交者 = 5 edge 線 × 2 取向 = 10 列）
宣稱：每態 tie 條目 = **10**（0 偏離）。

**C3（∴ Σ_a d(s,a) = 10/2 = 5，推導）**：由 C1（每個對徑對恰 1）＋ C2（5 個對徑對）
宣稱：**每一態 `Σ_a d ≡ 5`**（120/120），並解釋 R7 A2 之 `Σ_tie d = 600 = 1200/2`。
