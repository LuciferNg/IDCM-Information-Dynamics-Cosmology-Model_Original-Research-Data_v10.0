## §3 ★ 本輪新量度（O222 未記錄之精確不變量）
```
N1  R(s) = sum_a K[s,a]  恰取兩值：+10（60 個態）／-10（60 個態）；Delta = max-min = 20
N2  「(1+K)/2 投影」之列和 = 26 / 36（= (62 -/+ 10)/2）——120/120 ≠ 1（即 O222 所述「列和 ≠ 1」之精確版本）
```

## §4 由此得到嘅攻擊形狀（本輪合約之依據）
1. 仿射族 `W = alpha·J + beta·K` 之歸一方程 = `62 alpha + beta·R(s) = 1`。
   `R` 取兩值 ⟹ 方程組之**唯一**解為 `(alpha, beta) = (1/62, 0)` ⟹ `W` 均勻 ⟹ **態盲目**。
   ⟹ 「障礙」之精確講法 = **R 非常數**（≠「列和 ≠ 1」；後者只係其必要但唔充分之表述）。
2. 最小修改族之判準因此變成一個**可計算整數**：使 `R` 變成常數所需之最少附加欄數 `m_min`。
   本輪證明 `m_min = 最小 m 使 ∃A 整數：|A - R(s)| <= m 且 A - R(s) ≡ m (mod 2) ∀s`；對凍結 K 得 **10**。
3. `m_min = 10`，且 `10 = |Stab(theta)| = 120/12 = Delta/2` —— 三個 10 互相一致（本輪以 null 檢定其偶然性）。
