## Part A — #3：tie 宇稱動力效應之機制層

**A1（K-無關讀事件集）** 協定之每一次「比較」（hit test）產生事件 `(ctx, s_w, s_r)`：`s_w` = 頂端條目寫入時之態、`s_r` = 比較時之態。
宣稱：事件序列（含次序）**只依 ctx 序列與狀態演化**，與 K 值無關 ⟹ 三個 K 變體**以及**人造 `K ≡ 0` 之逐態事件雜湊完全相同。

**A2（分解）** `overrides(K) = OT^clean(K) + OT^tie(K)`，其中 clean = 事件之 `tie(s_w,ctx) = tie(s_r,ctx) = False`，
tie = 其餘。宣稱：**`OT^clean` 於三變體逐態完全相同**（非 tie 條目三變體取值相同）⟹ 全部變體差異只由 tie 事件承載。

**A3（機制公式）** 逐條目恆等（7440）：
```
non-tie (s,a)：K = K_prod = K_neg = sgn(⟨U[a], KV[s]⟩)
tie     (s,a)：K = ε(s) := firstsgn(KV[s])          （只依 s）
               K_prod = γ(a,s) := firstsgn((0, u×r))  （依 a 與 s）
               K_neg  = −γ(a,s)
```
- A3a：上述恆等於 7440/7440 條目成立。
- A3b：事件層面 `(tie(s_w),tie(s_r))` 四類之事件數與各變體之錯配數（報告）。
- A3c：tie 事件之錯配恆等式 —— 於 `(T,T)` 事件，`K` 側判定 = `[ε(s_r) ≠ ε(s_w)]`；`K_prod` 側 = `[γ(a,s_r) ≠ γ(a,s_w)]`。

**A4（差異承載者）** `Δ(s0) := overrides_prod(s0) − overrides_machine(s0)` = Σ 事件 (mis_prod − mis_machine)；

## Part B — #1：edge 參考軸之 6 條 tie 之完整刻畫

**B1（推導出之奇偶約束）** 設 edge 參考之 tie 集型別分解 = `2 vertex + f face + e edge`。
R5 Q3b 已證每個 edge 軸 ⟂ 恰 2 條頂點軸 ⟹ vertex 數 = 2；且 edge–edge 正交對數 `P` 滿足 `15e = 2P` ⟹ **e 為偶數**，
故 `f + e = 4`、`f` 偶 ⟹ **(f,e) ∈ {(0,4), (2,2), (4,0)}**（三選一）。宣稱：型別分解恰為此三種之一（報告係邊一種）。

**B2（群論）** `H_edge`（edge 線之線穩定子，階 8 = 2×4）：6 條 tie 軸**不可能**為單一軌道（6 ∤ 8）；
每型別類必為 `H_edge` 軌道之並（軌道大小 ∈ {1,2,4,8}）。宣稱：報告實測軌道分解並核此約束。

**B3（精確幾何）** 6 條 tie 軸與參考軸之點積全 0（定義）；兩兩點積之 `Q(√5)` 精確值譜（含歸一化平方值 `⟨·,·⟩²/(N_iN_j)`）報告，
