## §0 一句話
R2 實測到嘅唯一結構律 `overrides(s) = overrides(−s)`，R3 給出**機制**並判其**充要性**：
```
定理：(i) 等變更新 s ↦ MUL[s][h(ctx)]   ＋   (ii') 逐欄比率恆定 K[-s][a]·K[s][a] = λ_a（λ_a 唔依賴 s）
      ⟹ G1 計數器（hits/stale/agree/stale_agree/overrides）與全部伴隨量 中心不變
```
刀刃測試唔止驗定理，仲**修正咗定理本身**：原合約寫法「破 (ii) ⟹ 必失效」**過寬** —— 中心奇縮放 `σ·K` 破壞 (ii) 但不變仍成立（因比較只涉「相等／唔等」，對兩邊同乘常數不變）⟹ 正確判準係**(ii') 比率恆定**。
**結構結論（新）**：`2I/{±1} ≅ A₅`（階 60，共軛類 1＋12＋12＋15＋20，換位子群 = 全群，中心平凡 ⟹ A₅），而 `overrides` 係**商上之函數（60 → 26 值）**、且**唔**由 A₅ 共軛類決定 ⟹ **G1 語義透過 A₅ 商分解**。
