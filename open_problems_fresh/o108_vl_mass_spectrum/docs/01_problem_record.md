## 二、結構基礎

### 2.1 72 = 48 SM + 24 VL 來源

SU(12) → SU(4) × SU(3) [tensor product: 12 = (4,3)] (O85, 18/18 PASS)

12 嘅分解:
```
12 = (4, 3)    under SU(4)_PS × SU(3)_flavor
12̄ = (4̄, 3̄)   under SU(4)_PS × SU(3̄)_flavor
```

4 嘅分解:
```
4 = (2, 1) ⊕ (1, 2)    under SU(2)_L × SU(2)_R
4 = 3₁ ⊕ 1₋₃           under SU(3)_C × U(1)_{B-L}
```

所以每代 12⊕12̄ = 24 Weyl:
```
12 = 3×(2,1) ⊕ 3×(1,2)   = 3×(左-handed) ⊕ 3×(右-handed)
12̄ = 3̄×(2,1) ⊕ 3̄×(1,2)  = 3̄×(左-handed) ⊕ 3̄×(右-handed)
```

### 2.2 SM 16 Weyl 吸收機制

每代 16 SM Weyl (標準計數):
```
Q_L = (3, 2)_{1/6}     — 左-handed 夸克雙重態 (3色×2 = 6)
u_R = (3, 1)_{2/3}     — 右-handed 上夸克 (3色 = 3)
d_R = (3, 1)_{-1/3}    — 右-handed 下夸克 (3色 = 3)
L_L = (1, 2)_{-1/2}    — 左-handed 輕子雙重態 (2)
l_R = (1, 1)_{-1}      — 右-handed 帶電輕子 (1)
ν_R = (1, 1)_0         — 右-handed 中微子 (1)
總計: 6+3+3+2+1+1 = 16
```

### 2.3 8 VL 狀態來源

每代 8 VL = 24 - 16 = 未被 SM 吸收嘅部分。

從 12⊕12̄ 分解, 8 VL 可能來自:
- **SU(2)_R 雙重態** (Pati-Salam 延伸): 右-handed 夸克+輕子嘅 SU(2)_R 夥伴
- **額外單態**: 12⊕12̄ 中多餘嘅 SU(3)_C×SU(2)_L 單態
- **鏡像 fermion**: 同 SM 表示相同但相反手性

### 2.4 O89 VL 閾值修正 (gauge coupling unification)

O89 從 gauge coupling unification 推導出 VL 質量標度:
```
M_VL_c ≈ 1.26×10¹⁴ GeV  (colored VL)
M_VL_s ≈ 2.52×10¹³ GeV  (singlet VL)
```

呢啲係 RG 運行嘅閾值, 非直接質量公式。VL 質量由以下決定:
1. **K_Chain 模式分配** (每個 VL 態對應嘅 n 值)
2. **VL 標度因子** (f_VL, 可能同破缺標度有關)
3. **RG 運行** (從 M_GUT 到 M_VL 嘅 gauge 修正)

## 四、攻擊路線

### 路線 A: 12⊕12̄ → 48 SM + 24 VL 分裂矩陣
```
1. 寫出 12 = (4,3) 喺 SU(2)_L×SU(2)_R×SU(3)_C 下嘅完整分解
2. 分出 16 SM 態 (標準 model representation)
3. 剩餘 8 VL 態 = 12⊕12̄ − 16 SM
4. 每代 8 VL = 3 代 × 8 = 24 VL
```

### 路線 B: VL 質量公式
```
1. VL 質量 = M₀ × ω_n/ω_7 × f_VL
   - M₀ = 27.9009 MeV (W-field VEV)
   - ω_n = 2sin(nπ/88) (K_Chain 頻率)
   - ω_7 = 2sin(7π/88) (DM 模式, 對應 m_7 = 13.8 MeV)
   - f_VL = VL 標度因子
2. VL 標度因子 f_VL:
   - 從 O89: M_VL_c ≈ 10¹⁴ GeV → f_VL ≈ 10¹⁶
   - 從 M_GUT: f_VL ≈ M_GUT/M₀ ≈ 10²¹
   - 從 M_PS: f_VL ≈ M_PS/M₀ ≈ 10¹⁹
3. VL 模式分配:
   - 24 VL 態 = 12⊕12̄ 中未被吸收嘅 K_Chain 模式
   - 每個 VL 態對應特定 n ∈ [1,44]
```

### 路線 C: VL/SM 混合角
```
1. VL 同 SM 質量混合矩陣 (類似 seesaw)
2. VL 混合角同 CKM/PMNS 嘅關係
3. VL 對 SM 觀測量嘅閾值修正
```
