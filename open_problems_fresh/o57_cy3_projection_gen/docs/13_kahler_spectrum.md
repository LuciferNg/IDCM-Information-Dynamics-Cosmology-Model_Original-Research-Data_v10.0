### α 掃描（scripts/76）

```
φ^(α·(35-i)) 家族:
  α=0.10: 110 finite, 階層 6e12（top9 全 ≈ 1）
  α=1.0: 5 finite, 9.8e16

→ 連續 trade-off: 要階層就犧牲 finite 數
→ 「9 個有限 + 階層 1e8」唔存在喺 φ 家族！
```

### ★★ 結構性定律

```
Kähler 參數動態範圍 trade-off:
  動態範圍大 (φ^(35-i)) → 少數有限 + 深階層
  動態範圍細 (φ^(-i)) → 多數有限 + 淺階層

SM 需要「9 個有限 + 1.7e8」= 需要 3 type 各自嘅 volume 階梯
  → 單一全局 Kähler 參數俾唔到
  → 需要 sector-dependent 幾何（Yukawa 矩陣結構）
```
