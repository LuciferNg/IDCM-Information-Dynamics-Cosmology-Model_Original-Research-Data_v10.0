### 2.4 第 3 步：★ Z₂ 對稱 = 時間反演 + Mirror 候選 ★

44-site 嘅 Z₂ 對偶 (n ↔ 44−n) 作用喺 beats：

```

ω(n,m) = γ_n − γ_m → γ_{44−n} − γ_{44−m} = (4−γ_n) − (4−γ_m) = γ_m − γ_n = −ω
```

**Z₂ = 時間反演 T: ω → −ω**

作用結構：

| Non-fixed orbits | **441** | = 21² = F₈² |
| Nyquist beats (n=44) | **43** | = Nd − 1 |
