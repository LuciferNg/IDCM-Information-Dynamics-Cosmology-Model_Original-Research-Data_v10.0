## 1. 核心公式

### 1.1 通用結構公式

**Cepheid PL 斜率 α(λ) 由 K_Chain 結構決定：**

```
α(λ) = φ² + ε + κ · S(λ)
```

| 分量 | 值 | 來源 |
|:----|:--:|:-----|
| φ² | 2.618034 | K_Chain 基本斜率 |
| ε = φ⁻¹/4 | 0.154509 | 2D 分支修正 (photosphere) |
| κ = 1/16 | 0.0625 | QG 尺度 (深層耦合) |
| S(λ) | 波段依賴 | 結構投影數 |

### 1.2 物理圖像

Cepheid 大氣層由外到內有唔同嘅 K_Chain 投影深度：

```
表面 (Photosphere) ── V-band ── ε 修正 (2D)
    ↓
次表面 ── I-band ── κ·L₄ (4 維 Lucas)
    ↓
上色球層 ── H-band ── κ·(φ⁵-φ⁻⁵-1) (減基本模式)
    ↓
深色球層 ── W-band ── κ·(φ⁵-φ⁻⁵) (完整整數閉合)
```

短波 (B) 受 extinction 主導，長波 (W) 趨近**固有斜率**。

## 2. 波段推導

### 2.1 V-band (550 nm) — 基準波段

**S(V) = 0** — ε 直接應用，唔經 κ 縮放。

```
α_V = φ² + ε = 2.618034 + 0.154509 = 2.772543
```

| 量 | 值 |
|:--|:--:|
| 預測 | 2.7725 |
| 觀測 (Freedman+2010) | 2.76 ± 0.03 |
| 偏差 | **0.45%** ✅ |

**物理：** V-band 量度 Cepheid 光球層 (photosphere)，係 2D 表面 → ε 修正 (2D MERA 分支)。

### 2.2 I-band (800 nm) — 深層光球

**S(I) = 7 = φ⁴+φ⁻⁴** (Lucas 4, 第一非三重 Lucas 數)

```
α_I = φ² + κ·(φ⁴+φ⁻⁴) = 2.618034 + 0.0625 × 7 = 2.618034 + 0.4375 = 3.055534
```

| 量 | 值 |
|:--|:--:|
| 預測 | 3.0555 |
| 觀測 (Freedman+2010) | 3.06 ± 0.03 |
| 偏差 | **0.15%** ✅ |

**物理：** I-band 穿透更深 → 3D 結構 → κ 縮放。L₄ = 7 = φ⁴+φ⁻⁴ 係第一個非 SM 嘅 Lucas 整數 (同 DM 模式 n=7 同源！)。

### 2.3 H-band (1650 nm) — 上色球層

**S(H) = 10 = φ⁵-φ⁻⁵-1** (整數閉合減基本模式)

```
α_H = φ² + κ·(φ⁵-φ⁻⁵-1) = 2.618034 + 0.0625 × 10 = 2.618034 + 0.625 = 3.243034
```

| 量 | 值 |

| 觀測 (Riess+2022) | ~3.25 |

**物理：** H-band 探測色球層，K_Chain 投影接近完整，但仍有基本模式 n=1 嘅「缺失」。

### 2.4 W-band (3500 nm, mid-IR) — 深色球層 / 固有斜率

**S(W) = 11 = φ⁵-φ⁻⁵** (完整整數閉合)

```
α_W = φ² + κ·(φ⁵-φ⁻⁵) = 2.618034 + 0.0625 × 11 = 2.618034 + 0.6875 = 3.305534

**物理：** W-band 係最接近「固有」PL 斜率嘅波段 — 最少 extinction、最少溫度效應。**完整 K_Chain 投影。**

## 3. B-band 與 Extinction 模型

### 3.1 B-band (440 nm) — 短波修正

**S(B) = -6 = -(φ⁵-φ⁻⁵-F₅)** (負修正，extinction 主導)

```
α_B = φ² + ε - κ·(φ⁵-φ⁻⁵-F₅) = 2.772543 - 0.0625 × 6 = 2.772543 - 0.375 = 2.397543
```

| 量 | 值 |
|:--|:--:|
| 預測 | 2.3975 |
| 觀測 (Freedman+2010) | ~2.4 |
| 偏差 | **0.10%** ✅ |

**物理：** B-band extinction 最大，修正為負。F₅ = 5 係 Fibonacci 5，代表「基準」消光水平。

### 3.2 Extinction 結構

B-band 相對 V-band 嘅 extinction 差：

```
A_B - A_V = κ·(φ⁵-φ⁻⁵-F₅) = 0.0625 × 6 = 0.375 mag
```

標準 Milky Way 消光：A_B - A_V = 0.3 mag (偏差 20%)。

IDCM 預測 extinction 差比標準高 20% — 呢個可能係 Cepheid 宿主星系 (LMC/SMC) 嘅消光特性差異 (LMC 消光比 MW 細)。

```
