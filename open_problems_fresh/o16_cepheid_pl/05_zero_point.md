## 1. 核心命題

### 1.1 零點嘅結構意義

PL 關係：

```
M(λ) = α(λ) · log P + β(λ)
```

零點 β(λ) 係 log P = 0 (P = 1 天) 時嘅絕對星等。佢代表 Cepheid 基本模式 (n=1) 透過 K_Chain 耦合到 W-field sync node 嘅**絕對光度標度**。

### 1.2 Sync Node 耦合

Cepheid 嘅基本模式 (n=1) 透過 3 個結構因子耦合到 sync node：

| 因子 | 值 | 來源 |
|:----|:--:|:-----|
| γ₁ | 0.005096 | K_Chain 基本模式 eigenvalue |
| κ | 1/16 = 0.0625 | QG 耦合尺度 |
| λ_sync | 294.88 | Sync node 能量 |

**耦合強度 = γ₁ · κ · λ_sync = 0.0939**

---

## 2. V-band 零點閉合 🟢

### 2.1 結構公式

```
β_V = -2.5 · log₁₀(λ_sync · γ₁ · κ) - 4
```

| 分量 | 數值 |
|:----|:----:|
| λ_sync · γ₁ · κ | 294.88 × 0.005096 × 0.0625 = 0.0939 |
| -2.5·log(0.0939) | +2.5682 |
| **β_V = 2.5682 - 4** | **-1.4318** |

### 2.2 驗證

| 量 | 值 |
|:--|:--:|
| IDCM 預測 β_V | -1.432 |
| 觀測 β_V (Freedman+2010, LMC) | -1.43 |
| 偏差 | **0.13%** ✅ |

### 2.3 物理意義

**-4 = -(φ³-φ⁻³) = -4** 係 MERA 分支因子，代表 Cepheid 基本模式耦合到 sync node 時嘅**維度壓縮** (2D 光球 → 4D 時空)。

```
β_V = sync_node_coupling - MERA_branching
```

## 3. I-band 零點 🟡

### 3.1 嘗試公式

I-band 投影更深 (S=7=φ⁴+φ⁻⁴)，但零點公式唔係簡單加入 S 因子：

```
β_I (嘗試) = -2.5·log(λ_sync·γ₁·κ·7) - 4 = -3.545
觀測 β_I = -1.61
偏差: 120% ❌
```

### 3.2 正確公式

I-band 零點 = V-band 零點減去固有顏色：

```
β_I = β_V - (V-I)₀
```

| 量 | 值 |
|:--|:--:|
| β_V (預測) | -1.4318 |
| (V-I)₀ (預測) | 0.1766 |
| β_I = -1.4318 - 0.1766 | **-1.6084** |
| 觀測 β_I | -1.61 |
| 偏差 | **0.01%** ✅ |

### 3.3 顏色 (V-I)₀ 嘅結構公式

```
(V-I)₀ = 2·φ⁻¹ / (φ⁴+φ⁻⁴) = 2 × 0.618 / 7 = 0.1766
```

| 量 | 值 |
|:--|:--:|
| 預測 (V-I)₀ | 0.1766 |
| 觀測 (V-I)₀ (= β_V - β_I) | 0.178 |
| 偏差 | **0.8%** ✅ |

**物理：** 固有顏色 (V-I)₀ 由 φ⁻¹ 同 L₄=7 嘅比值決定 — 同消光系數 R_H = κ·L₄ 共享 L₄ 結構數。

## 4. 波段零點統一公式

### 4.1 通用結構

```
β(λ) = -2.5 · log₁₀(λ_sync · γ₁ · κ) - 4 + Δ(λ)
```

Δ(λ) 係波段依賴修正，滿足 Δ(V) = 0。

| 波段 | Δ(λ) | β 預測 | β 觀測 | 偏差 | 狀態 |
|:----:|:----:|:------:|:------:|:----:|:----:|
| V | 0 | -1.432 | -1.43 | 0.13% | 🟢 |
| I | -(V-I)_0 | -1.608 | -1.61 | 0.01% | 🟢 |

### 4.2 對距離階梯嘅影響

零點 β(λ) 直接決定距離模數：

```
μ = m - M = m - [α(λ)·log P + β(λ)]
```

如果 β_V 有 0.13% 嘅誤差，對應距離模數誤差 ~0.006 mag，即 ~0.3% 距離誤差 — 遠細過 SH0ES 嘅 1.4% 系統誤差。
