## 一、篩選: 三面型 Archimedean 得 3 個候選

用三種正多邊形鑲嵌球面嘅均勻多面體只有 3 個（Archimedean 分類）:

| 面型 | 多面體 | 頂點數 | 含 Δ |
|:--|:--|:--|:--|
| (4,6,8) | Truncated cuboctahedron | 48 | ❌ |
| **(3,4,5)** | **Rhombicosidodecahedron** | **60** | ✅ |
| (4,6,10) | Truncated icosidodecahedron | 120 | ❌ |

**篩選條件: 60 頂點（譜逼出 60 = Σγ·μ²/N_gen = 90×2/3）→ 唯一 (3,4,5)** ✓

（60 頂點 Archimedean 有 3 個：足球 (5,6)、Snub (3,5)、Rhombicosidodecahedron (3,4,5) — 但三面型得 1 個）

## 二、「冇缺項」嘅幾何層證明

```
(3,4,5)  連續整數    = 冇缺項 ✓
(4,6,8)  跳咗 5,7    = 有缺項
(4,6,10) 跳咗 5,7,8,9 = 有缺項
```

**三面型之中唯一連續 = (3,4,5)** — 「3 種基本多邊形由細到大冇跳過」。
呢個係「冇缺項」嘅幾何版本，同 κ 閘極嘅譜層證明（e⁻² > κ > e⁻³ 唯一夾層）雙重交叉。

## 三、(3,4,5) 嘅三重身份（面型選擇嘅理由）

1. **唯一連續整數** = 冇缺項（幾何）
2. **唯一連續畢氏三元組**：3²+4² = 5² → N_gen²+B² = F₅²（代數）
3. **It-From-Beat 音程比**：3:4 = 純四度、4:5 = 大三度 — 和諧音程（音樂/節奏身份）

## 四、完整第一性鏈（o163 最終版）

```
60 = Σγ·μ²/N_gen = 90×2/3                [譜逼出預算分母]
+ 三面型 (3 = N_gen 世代結構)
→ 60 頂點 + 三面型 → 唯一 Rhombicosidodecahedron   [Archimedean 分類]
→ 面型 (3,4,5,4): 唯一連續 = 冇缺項               [幾何層冇缺項]
→ (3,4,5) 唯一畢氏三元組 → N_gen²+B² = F₅²
→ 份額 = (a, b², b²+c²) = (3, 16, 41)             [面型二次結構]
→ χ = 2 → 100% 封閉                                [拓撲層 100%]
→ κ⁻¹ = B² = 16 (DM = 閘極倒數)                   [譜層交叉]
→ 觀測: ratio 16/3 (−0.57%), CMB χ² = 0.87, BBN ✓
```
