## 三、份額嘅幾何生成 (核心新結果)

```
(3, 16, 41) = (a, b², b²+c²)   for (a,b,c) = (3,4,5)
```

- **3 = a**：三角面邊數 → 重子
- **16 = b²**：正方面邊數平方 → DM（同時 = κ⁻¹ 閘極倒數）
- **41 = b²+c²**：正方+五邊平方和 → 真空（同時 = N_d−N_gen）
- 和 = a + 2b² + c² = 3+32+25 = **60 = V**（球面頂點數）

即係話：**宇宙三份額 = 球面面型 (3,4,5) 嘅邊數二次結構** — 唔係砌數, 係面型嘅自然代數。
