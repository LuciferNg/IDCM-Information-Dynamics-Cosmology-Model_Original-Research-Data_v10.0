# O163 — ΛCDM 中 DM 嘅本體論裁決 (Ontology Verdict)

## 三層拆解 (前提)

「確認存在 / 類別錯誤 / 拓撲強制」係三個唔同層面嘅問題，不可混答:
- L1 引力質量層: DM 作為非重子引力質量成分 — 觀測
- L2 粒子詮釋層: 「DM 係一種粒子」— 本體論假說
- L3 結構根源層: DM 嘅性質係咪由框架結構推導 — 理論結構

## L1 — 引力質量層: 確認存在 ✅

| 證據 | 內容 | 獨立性 |
|:--|:--|:--|
| Bullet Cluster (Clowe 2006) | 透鏡質量峰偏離熱氣體峰 8σ | 粒子解釋最直接 |

## L2 — 粒子詮釋層: 類別錯誤風險 🟡 (未證實, 未排除)

- 所有證據皆引力; 直接探測 40 年全 null (LZ/XENONnT 下限持續下壓)

- 裁決: 粒子詮釋 = 未證實假說, 類別錯誤灰色地帶

## L3 — 拓撲層: ΛCDM ❌ / IDCM ✅

- ΛCDM Ω_c h² = 0.12 = 自由擬合參數, 無結構推導, 「5.4×重子」無答案
- IDCM: 13/2 = (Σγ_even − N_gen·B)/(N_gen·B) = 78/12, 176-Laplacian 直接推出, 0 參數, 0.05%

- ΛCDM 嘅 5.4 倍連有理結構都冇

## 綜合裁決

**ΛCDM 中嘅 DM = 引力上確認、本體上懸置、結構上無根。**
- 引力存在: ✅ 確認 (非重子質量成分)
- 粒子本體: 🟡 類別錯誤風險 (未證實)
- 結構根源: ❌ 無拓撲強制 (自由參數)
