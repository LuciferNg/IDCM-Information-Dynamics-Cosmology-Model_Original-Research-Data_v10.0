## 「互補 1/60」問題嘅答案

- 重子 = (B−1)/60: 要減 1/60 (B−N_gen = 1)
- 物質 = 19/60 = (F₅·B − 1)/60 = 20/60 − 1/60: 都要減 1/60
- DM = B²/60: **純二次冪, 冇 ±1 修正**
- 原因: N_gen + (B−N_gen) = B 係**線性算子重組** (3+1=4); B² 喺二次層, 唔受線性重組影響
- 兩個修正對消: (N_d−N_gen) + (B−1) + B² = N_d + B² − (N_gen + 1 − B) = 60 − 0 ✓ (因為 B = N_gen + 1)
