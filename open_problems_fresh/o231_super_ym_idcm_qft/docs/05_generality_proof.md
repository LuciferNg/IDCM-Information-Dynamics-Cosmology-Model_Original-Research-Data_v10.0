## 一、證明結構

### 1.1 q-化簡（將散射問題化為整數線性組合問題）

設 n→n 散射解 (a₁..aₙ) → (b₁..bₙ)，定義：

\[
\Delta_m = \#\{i : b_i = m\} - \#\{i : a_i = m\}, \quad m = 1..87
\]

合併鏡像對：\(q_k = \Delta_k + \Delta_{88-k}\)（k=1..43），\(q_{44} = \Delta_{44}\)。

能量守恆 ⟹ \(\sum_m \Delta_m \omega_m = 0\)，因 \(\omega_k = \omega_{88-k}\)：

\[
\sum_{k=1}^{44} q_k \omega_k = 0
\]

**關鍵問題：呢個方程有冇非零整數解？**

### 1.2 無解論證（3 層）

```

   sin(a)+sin(b) = sin(c) 同 sin(a)+sin(b) = sin(c)+sin(d) 冇非平凡解
   （support-3 / support-4 全面檢查: 0 候選）

   找 Σ q_k ω_k = 0 的非零解 → 0 個命中; 最小 |Σqω| = 5.5e-04

   隨機 Σqω 分佈 σ = 7.73 — 遠離 0（若存在線性關係, 應有接近 0 的組合）
```

**誠實標記**：T2/T3 係計算論證（MC + 搜索），唔係純代數證明。完整的純代數證明需要 sin 有理點嘅 ℚ-線性獨立性定理（Niven 類結果），未有完整文獻覆蓋。但統計強度：2M 抽樣無命中 + 分佈 σ=7.7 遠離 0，配合 support-3/4 全面排除 — 對「無非零整數能量關係」嘅信心極高。

### 1.3 動量守恆收尾

q ≡ 0 ⟹ \(\Delta_k = -\Delta_{88-k}\)：模式只在鏡像對 {k, 88−k} 內轉移。

設 S = 被鏡像嘅模式集合（Δ_k ≠ 0 嗰啲），每鏡像一個模式 k：
\[
\Delta p = (88-k) - k = 88 - 2k
\]
總動量變化（mod 88）：
\[
\Delta p_{\text{tot}} = \sum_{k \in S} (88 - 2k) \equiv -2\sum_{k\in S} k \pmod{88}
\]
守恆 ⟺ \(\sum_{k\in S} k \equiv 0 \pmod{44}\)。 □
