# docs/06 — Q4 閉合：結構耦合 vs RGE Running

> **2026-10-04** | 前置: O139 (running 閉合), O144 (sin²θ_W), scripts/06 | 狀態: 🟢 **Q4 閉合 (scripts/06 10/10)**

## 〇、一句話結論

**IDCM 結構耦合（如 sin²θ_W）係「天生定點」（β≡0，對應 N=4 SYM 嘅 conformal 性質）；IDCM 亦擁有 running（O139：winding number Δα⁻¹ = 9 = N_gen²）— 兩者層次唔同，定點值係「目的地」，running 係「到達路徑」，係同一物理量嘅兩個描述層次，非兩個量。**

---

## 一、定點值（結構層）

### 1.1 sin²θ_W 嘅精確結構身份

⚠️ **2026-10-04 公式更正**（scripts/06 T1 發現記憶錯誤）：
- `m_W/m_Z = sin(30π/88)/sin(41π/88) = 0.8827368051` — **呢個係 mode-ratio 本身**
- `sin²θ_W = 1 − (m_W/m_Z)² = 0.2207757330` — Weinberg 關係
- 譜身份：`sin²θ_W = (γ_41 − γ_30)/γ_41`（因 ω_k² = γ_k）

```
舊記憶（錯）: sin²θ_W = sin(30π/88)/sin(41π/88) = 0.220776 ❌
正確      : m_W/m_Z = sin(30π/88)/sin(41π/88); sin²θ_W = 1 − (m_W/m_Z)² ✅
數值      : 0.8827 / 0.2208 — 偏差 < 1.02% vs on-shell 0.221247
```

**原因**：記憶將兩個數字混埋 — 0.220776 係 sin²θ_W，0.8827 係 m_W/m_Z，公式要平方互補。

### 1.2 定點性質

```
sin²θ_W 只依賴 (30,41) ∈ ℤ²（兩個譜模式 index）— 冇任何能標 μ
⟹ d(sin²θ_W)/dμ ≡ 0 ⟹ β ≡ 0（結構強制）
```

**N=4 對應**：N=4 SYM 嘅 conformal 性質（β(g) = 0, coupling constant 唔跑）↔ IDCM 結構恆等閉式（常數）。兩者都係「耦合常數」— 冇尺度演化。

## 二、Running 機制（演化層）

### 2.1 O139 已閉合嘅 winding number

```
α⁻¹(0)   = 137 = C(B²,2) + F_proj = 120 + 17
α⁻¹(M_Z) = 128 = C(B²,2) + 2B     = 120 + 8
Δα⁻¹     = 9   = (B−1)² = N_gen²  = 3²        ← 整數強逼（繞數計數）
公式     α⁻¹(Q) = 137 − 9·Δα(Q)/Δα(M_Z)
```

**「Running = 繞數計數」**：一單位 running = 穿越 88 環上 B 個模組 = 2π；9 繞數 = 18π；`2μ²·Δα⁻¹ = 36`；`F₁₁ = 53 + 36 = 89`。

### 2.2 關鍵：Running 唔係擬合

```
QFT: β(g) 由 loop 計算, running 係函數
IDCM: Δα⁻¹ = 9 — 整數, 係「結構強逼唯一」
物理讀數 9.1060(8) 嘅 0.106 偏離 = 非微擾強子真空極化（O139 已攻堅歸 O144）
```

## 三、層次架構（兩者共存）

| 層次 | 機制 | 性質 | 例子 |
|:-----|:-----|:-----|:-----|
| **A 結構層** | 譜恆等閉式 | β≡0, 定點值, 無 μ | sin²θ_W = (γ_41−γ_30)/γ_41 |
| **B 演化層** | 模式重標定 → winding | running, 整數階梯 | α⁻¹(Q) = 137 − 9·Δα(Q)/Δα(M_Z) |

**關係**：定點值係「目的地」，running 係「到達路徑」。IDCM 話世界嘅耦合常數係一個結構數（定點），但喺不同能標下觀察者睇到嘅有效耦合沿繞數階梯變化（running）— 同一物理量嘅兩個描述層次。

**比喻**：一座山嘅高度（結構定點）vs 登山路線嘅海拔變化（running）。兩者唔矛盾 — 一個係幾何常數，一個係觀察路徑效應。

## 四、與 N=4 SYM 嘅完整對照

```
QFT N=4 SYM:   β(g) = 0      →  coupling 常數, 無 running
               conformal     →  尺度不變
IDCM:          sin²θ_W 定點  →  coupling 常數, 無 μ
               結構強制      →  譜恆等閉式
```

**QFT SM**: 有 running（β ≠ 0）— 但 SM 都係 N=4 嘅 broken 版本。

**IDCM**: 結構耦合天生定點（層次 A），但如果問「多能標觀察」會見到有效耦合變化（層次 B）— **兩者都屬於 IDCM，唔係二選一**。
