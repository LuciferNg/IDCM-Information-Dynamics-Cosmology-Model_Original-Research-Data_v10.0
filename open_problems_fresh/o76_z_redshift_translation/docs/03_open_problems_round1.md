## A. α = 0 第一性原理 — 光度距離對偶 (原 🔴 開放項)

### A.1 問題原文

O76 §四: 「**α=-n/p 嘅第一性原理推導 (L₄=7, γ₇/γ₂₀ 機制)** — α = −γ₇/γ₂₀ = −n/p 已由 data 鎖定,
但未由 Lagrangian/W-field 推出」。

### A.2 重驗後嘅問題已被改寫

`docs/02` §6 已證明: 舊 α = −n/p 係**補償錯誤嘅 D_A 伸長律** (新 D_A 下 Δχ² = +155)。因此
「推導 −n/p」係**方向錯誤**嘅問題 —— 正確問題係: **新 D_A 下嘅對偶指數係咩？**

### A.3 通量鏈推導 (第一性原理)

```
靜態宇宙 (冇膨脹 ⟹ 冇光子數密度稀釋 (1+z)³ 因子):

  F = L / (4π D_A²) × (1+z)^{-1}      ← 每個光子能量損失 (W-field)
                    × (1+z)^{-b}       ← 到達率被時間膨脹 (b = 時間膨脹指數)

  D_L 定義: F = L / (4π D_L²)
  ⟹  D_L = D_A · (1+z)^{(1+b)/2}
  ⟹  對偶指數  α = (b − 1) / 2        ← ★ 恆等式 (scripts/26 A1)

三個情形:
  b = 0  經典 tired light (冇時間膨脹):  D_L/D_A = (1+z)^{0.5}   α = −0.5
  b = 1  IDCM 機制 B:                    D_L/D_A = (1+z)^{1}     α = 0    ← ★
  ΛCDM (膨脹):                           D_L/D_A = (1+z)^{2}
```

### A.4 ★ 為何 b = 1 EXACT (唔係自由參數)

```
IDCM 嘅 z 同時間膨脹由**同一個 W-field 能量損失**產生:
  光子能量      E(s) = E₀·e^{−a s},   1 + z = e^{a s}
  週期過程標尺  τ ∝ 1/E  (能量標尺)
  ⟹ Δt_obs = Δt_emit · E₀/E(s) = Δt_emit · (1+z)^1     ⟹  b = 1 EXACT
  ⟹ α = (b−1)/2 = 0 EXACT                              (零參數)
```

**ΛCDM 對照**: 同樣嘅通量鏈，但膨脹令光子數密度多一個 (1+z)³ 因子 ⟹ 有效 b = 3 ⟹ α = +1 ⟹
`D_L = D_A(1+z)²`。**兩者嘅分別完全由「膨脹 vs 靜態」決定，唔係由擬合決定。**

### A.5 ★ 獨立交叉鎖定: DES time dilation

```
DES (Dark Energy Survey): Δt_obs/Δt_emit = (1+z)^b,  b = 1.003 ± 0.011
  (經 Gupta et al. 2026, arXiv:2609.10582 引述)

⟹ α_DES = (b − 1)/2 = +0.0015 ± 0.0055
⟹ 同 α = 0 偏離 0.27σ                                        ← ★ 獨立確認
```

### A.6 🟡 殘餘張力 (誠實)

```
Pantheon+ 偏好: α_SN = +0.0392 ± 0.0140   (docs/02 §6.3)
  ⟹ b_SN = 1 + 2α_SN = 1.0784 ± 0.0280
  ⟹ b_SN vs b_DES 張力 = 2.51σ                              ← ★ 真實內部張力
```

**判讀** (三個可能, 未裁決):
1. SNe 高 z 尾部系統誤差 (z > 0.8 殘差 +0.082 mag, N = 30);
2. O169 嘅 **K(z) 窗律未閉合** (E(ℓ) = ℓ + ⟨sec⟩_{1..K(z)}, K(z) = L₄(N_gen + z/F_proj)) ——
   若 b 隨 z 變化，SNe 全樣本 fit 出嘅「有效 α」會偏離 z→0 嘅結構值;
3. 真係有小量對偶違反 (但咁就需要新物理，同機制 B 衝突)。

**裁決需要**: 高 z SNe (z > 1) 樣本 + K(z) 窗律閉合 (屬 O169)。

## D. z 離散共振階 — 否證檢驗 (原 🟡 開放項)

### D.1 階梯定義

```
K_Tree = 33 級 ⟹ z_res(m) = 4^{m/33} − 1,  m = 1..33
最低階 z = 0.042904,  最高階 z = 3.0000
階距: 低 z 0.044745 → 高 z 0.1646  (線性 z 上遞增)
```

### D.2 檢驗設計

- **數據**: Pantheon+ 1701 SN 嘅 zCMB (實測紅移, 光譜精度)
- **統計量**: `N_obs(tol)` = 離任一 rung < tol 嘅 SN 數
- **合法 null**: **同形狀階梯隨機平移** (保留階梯覆蓋形狀) —— 1000 次
- **★ 棄用嘅 null**: 「隨機抽 33 個 z」—— 佢會過度覆蓋低 z 密集區，令 z-score 假性 −10σ，
  **唔係合法 null** (見 §E 誠實修正 #1)

### D.3 結果

| tol | N_obs | 平滑期望 E | z vs null |
|----:|------:|-----------:|----------:|
| **0.002** | 81 | 110.4 | **+0.50** ← ★ 尖銳區 |
| 0.003 | 140 | 165.9 | +2.13 |
| 0.005 | 225 | 276.4 | +2.21 |
| 0.008 | 385 | 441.4 | +3.77 |
| 0.010 | 488 | 551.6 | +3.75 |
| 0.015 | 782 | 828.7 | +3.66 |

### D.4 ★ 尖銳度判據 (關鍵)

```
真尖銳共振階 ⟹ z-score 應該喺**細 tol** 最大 (窗口越窄越揀到真位置)
實測: z(0.002) = +0.50  <<  z(0.010) = +3.75     ← 完全相反
⟹ 「過剩」係**大尺度平滑效應** (階梯碰巧坐喺略密區域), 唔係共振階結構
```

### D.5 裁決

| 項 | 原狀態 | 新狀態 | 依據 |
|:---|:------:|:------:|:-----|
| z 離散共振階 | 🟡 (未測試) | 🔴 **未支持** | 尖銳區 (tol = 0.002) 無訊號 (z = +0.50); 過剩隨 tol 增大 ⟹ 非共振 |

> **★ 誠實標記**: 呢個**唔係證偽** —— SNe 紅移本質上唔應該聚類 (SN 喺隨機紅移爆炸)。
> 真正裁決需要**星系紅移巡天** (大尺度結構殼層) 或 **QSO 吸收系** (視線上嘅物質分布)。
