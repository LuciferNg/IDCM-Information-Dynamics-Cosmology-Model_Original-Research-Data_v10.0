## 2. ★★★ 核心閉合: 143 = dim(SU(12)) = Λ²(12) + L₄L₅

```
77 + 66 = 143 = 12² − 1 = dim(SU(12))
```

SU(12) 生成元總數 = 階梯第 6 級 (66 = Λ²(12) = 正根數) + 階梯第 7 級 (77 = L₄×L₅)!

根結構分解:

```
143 = 66 (正根) + 11 (Cartan) + 66 (負根)
77  = 66 (正根) + 11 (Cartan) = dim(Borel(SU(12)))  ← 77 嘅真正代數身份
```

**77 = dim(Borel(SU(12)))** — Borel 子代數 = Cartan + 正根空間 = 11 + 66 = 77。呢個先係 77 唔係「啱啱好 7×11」嘅原因: L₄ = rank−B = 11−4 (O74), L₅ = rank = 11, 乘埋 = (正根/6)×rank 嘅結構乘積。
