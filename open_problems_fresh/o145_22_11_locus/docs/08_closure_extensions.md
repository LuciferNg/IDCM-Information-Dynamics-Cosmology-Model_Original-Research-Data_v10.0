## 2. ★★★ 閉式 #1: Z(φ=6) = iⁿ + 2·(−1)ⁿ (零新參數)

**推導** (G6 = {22, 44}, v₂(22) = 1, v₂(44) = 2):

```
Z(φ=6, n) = v₂(22)·exp(2πi·n·22/88) + v₂(44)·exp(2πi·n·44/88)
           = 1·exp(iπn/2) + 2·exp(iπn)
           = iⁿ + 2·(−1)ⁿ
```

**實部分解** (2 = v₂(44) = B/2):

```
Re(Z) = cos(nπ/2) + 2·(−1)ⁿ

n≡0 (mod 4): cos(0) + 2·(+1) = 1+2 = +3   = rank單位 + v₂(44)
n≡2 (mod 4): cos(π) + 2·(+1) = −1+2 = +1   = v₂(44) − 1
n≡1 (mod 4): cos(π/2) + 2·(−1) = 0−2 = −2  = −v₂(44)
n≡3 (mod 4): cos(3π/2) + 2·(−1) = 0−2 = −2 = −v₂(44)
```

**結構意義**: {+3, +1, −2} 唔係獨立標籤 — 全部由單一常數 v₂(44) = 2 = B/2 決定, 加單位根實部 cos(nπ/2)。零新參數, 完整閉式。

- +3 = rank 單位 (1) + v₂(44) (2) — n≡0 類 (玻色子類)
- +1 = v₂(44) − 1 — n≡2 類 (v₂=1, L=22 子環)
- −2 = −v₂(44) — n≡1/3 類 (奇數, L=44), 虛部 ±i = Z₂ 對偶
