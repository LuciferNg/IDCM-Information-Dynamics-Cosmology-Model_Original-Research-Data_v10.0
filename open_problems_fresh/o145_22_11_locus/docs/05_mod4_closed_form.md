## 1. 問題 (docs/03 §4 開放項)

考慮 88-site 對偶鏈 (n = 1..88)，γ_n = 4sin²(nπ/176)：

```
奇 sector (觀察者, 44 modes, Σ = 88):
  n≡1 mod 4 (22 modes): Σγ = 42.999362...
  n≡3 mod 4 (22 modes): Σγ = 45.000638...
```

docs/03 記錄為「**接近 43/45 但唔精確, 唔算閉合**」。本 doc 閉合呢個偏差 — 佢有**精確閉式**。

## 2. ★★★ 精確閉式: 44 ± sec(π/88)

```
Σγ(n≡1 mod 4) = 44 − sec(π/88) ≈ 42.9993624194
Σγ(n≡3 mod 4) = 44 + sec(π/88) ≈ 45.0006375806
```

**推導** (等差角度求和):

```
Σ_{k=0}^{N-1} cos(a+kd) = [sin(Nd/2)/sin(d/2)]·cos(a + (N−1)d/2)

n≡1: a = π/88, d = 4π/176 = π/44, N = 22
  Σcos = [sin(π/2)/sin(π/44)]·cos(π/88 + 21π/44)
       = cos(43π/88)/sin(π/44)
       = sin(π/88)/sin(π/44)          [cos(43π/88) = sin(π/88)]
       = 1/(2cos(π/88))               [sin(2θ) = 2sinθcosθ]

Σγ = 4·[22 − Σcos]/2 = 44 − 2·sin(π/88)/sin(π/44)
   = 44 − 1/cos(π/88) = 44 − sec(π/88)
```

**完整性**: 和 = 88 (觀察者預算), 差 = 2sec(π/88) = 2.0012751612。

## 3. ★★ 世界側係精確整數恆等式

```
even sector (世界, 44 modes, Σ = 90):
  n≡2 mod 4 (22 modes): Σγ = 44  (恆等式!)
  n≡0 mod 4 (22 modes): Σγ = 46  (恆等式!)
```

**符號證明** (sympy 驗證, 非浮點):

```
n≡2: 角度 (2k+1)π/88 = 44-site m 奇數
  Σ_{m奇=1}^{43} cos(mπ/44) = [sin(π/2)/sin(π/44)]·cos(π/2) = 0
  → Σγ = 44 − 2×0 = 44          ✅ 純恆等式

n≡0: 角度 2jπ/88 = 44-site m 偶數, j=1..22
  Σ_{j=1}^{22} cos(jπ/22) = −1
  → Σγ = 44 − 2×(−1) = 46       ✅ 純恆等式
```

**同一結構亦見於 44-site 鏈** (γ_m = 4sin²(mπ/88)):

```
m 奇 (22 modes): Σγ = 44   ← 階梯第 4 級 = N_d
m 偶 (22 modes): Σγ = 46   ← N_d + 2 = L₃L₅ + L₀
```

## 4. ★ 結構根源: 配對對稱破缺

Z₂ 鏡像 (n, 88−n) 每對 γ 和 = 4 (因 γ_n + γ_{88−n} = 4sin²θ + 4cos²θ = 4):

| 類 | 配對行為 | Σ |
|:---|:---------|:--|
| n≡2 | **自配對** (88−n ≡ 2): 11 對 × 4 | **44 精確** |
| n≡0 | **自配對** 但含端點: 10 對 × 4 + γ₄₄(=2, 自對偶) + γ₈₈(=4, Nyquist) | **46 精確** |
| n≡1 | **交叉配對** (88−n ≡ 3): 22 對分佈不均 | 44 − sec(π/88) |
| n≡3 | **交叉配對** 對偶側 | 44 + sec(π/88) |

**關鍵機制**: 自配對類嘅 Σcos 和中心角 = π/2 → cos 項消失 → 精確整數。交叉配對類嘅中心角 = 43π/88 → cos(43π/88) = sin(π/88) ≠ 0 → 剩低 sec(π/88) 偏移。

## 5. ★★★ 偏移量 sec(π/88) 嘅結構身份

```
sec(π/88) = 1/cos(π/88),  cos(π/88) = cos(2π/176) = cos(θ/2) 其中 θ = 2π/176 = π/88 半格角
sec(π/88) − 1 ≈ (π/88)²/2 = 6.3724e-4  (二階展開, 誤差 5e-7)
```

- π/88 = O74 θ_site = π/44 嘅一半 — 半格角度
- 偏移係 Nyquist 格點 (n=88, γ=4) 嘅曲率效應, 純幾何, 無自由參數
