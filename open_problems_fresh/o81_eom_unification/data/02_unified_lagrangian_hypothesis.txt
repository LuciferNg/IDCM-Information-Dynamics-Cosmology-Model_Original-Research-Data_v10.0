  V(W) = −μ²|W|² + λ|W|⁴,  μ²=2, λ=2/123
  ⟨W⟩² = μ²/(2λ) = 61.500000 = 61.5
  ⟨W⟩ = √(μ²/(2λ)) = 7.842194

  極座標分解: W = ρ·e^{iθ}, 其中:
    ρ = |W| (徑向模式, 振幅)
    θ = arg(W) (相位模式, Goldstone)

  SSB 後: ρ = ⟨W⟩ + δρ,  δρ 係 massive radial mode
    V(ρ,θ) = −μ²ρ² + λρ⁴
    = V(⟨W⟩) + (1/2)V''(⟨W⟩)·δρ² + O(δρ³)

  ★ 徑向模式質量: m_δρ = 2√(μ²) = 2.828427  (O39 無量綱制)
    → 物理質量: M₀·m_δρ/√61.5 = 10.0630 MeV

  ★ 相位模式: θ = Goldstone boson (連續極限質量零)
    離散圖上: 相位模式有阻挫 → 有效質量

  三、從 L_W 到 L_sG: 相位有效作用量推導
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Step 1: W = (⟨W⟩ + δρ)·e^{iθ} 代入 L_W

  L_W = (∂_μρ)²/2 + ρ²(∂_μθ)²/2 − μ²ρ² + λρ⁴

  Step 2: SSB 後 ρ = ⟨W⟩ + δρ, 展開到二次:
  L_W ≈ (∂_μδρ)²/2 − m_ρ²·δρ²/2 + ⟨W⟩²(∂_μθ)²/2
  + 交叉項: 2⟨W⟩δρ(∂_μθ)²/2 + ...

  Step 3: 積分掉 δρ (徑向模式, 重質量 m_ρ):
  有效相位 Lagrangian:
  L_θ_eff = (f_θ²/2)(∂_μθ)² + O((∂θ)⁴)
  f_θ² = ⟨W⟩² = 61.5 (相位衰減常數)

  ★ 相位衰減常數 f_θ = √⟨W⟩² = √61.500000 = 7.842194

  Step 4: 離散化到 A5 圖 (60 節點):
  (∂_μθ)² → 最近鄰差 (θ_i−θ_j)²/a²
  L_θ_eff = Σ_i [½θ̇_i²] − (J_eff/2)Σ_{⟨ij⟩}(θ_i−θ_j)²
  J_eff = f_θ²/a² = ⟨W⟩²/a²

  J_eff = ⟨W⟩²/a² = 61.500000  (歸一化 a=1)

  Step 5: 加入 cosine 勢 (阻挫 → α_ij):
  ∑_{⟨ij⟩} J_eff·cos(θ_i−θ_j−α_ij)  ← 有效 sine-Gordon!
  → 小角度: cos(Δ−α) ≈ cos(Δ)cos(α) + sin(Δ)sin(α)
  → α=0: cos(Δ)  (正常邊)
  → α=π: −cos(Δ)  (阻挫邊, 反鐵磁)
