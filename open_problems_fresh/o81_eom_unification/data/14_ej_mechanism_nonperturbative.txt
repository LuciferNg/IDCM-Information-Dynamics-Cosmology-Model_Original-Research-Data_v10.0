  A. #1 E_J 機制 — 容量均分 vs 剛度均分 (釐清 2 倍差)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


  模型二次型:
    H_quad = (E_J/2)·|θ|²  +  (J_eff/2)·θ^T Lap θ
    能量範圍 (range):
      on-site 每節點: −E_J cos θ_i 之範圍 = 2E_J        (θ_i: 0 → π)
      bond   每邊:    J_eff cos(Δθ−α) 之範圍 = 2J_eff   (Δθ−α: 0 → π)

  ─── 路線 A1: 容量均分 (energy-range equipartition) ───
    無通道偏好 ⟹ 總容量相等:
      V·(2E_J) = E·(2J_eff)
      ⟹ E_J = (E/V)·J_eff = (d/2)·J_eff

      = (120/60)·61.49999999999999 = 123.000000
  ✅ 路線 A1 (容量均分) 給 E_J = (E/V)J_eff = 2J_eff = 123
     123.000000

  ─── 路線 A2: 剛度均分 (variance-based stiffness) ───
    取無序相位場 ⟨θ_i²⟩ = σ², 獨立 ⟹ ⟨(Δθ)²⟩ = 2σ²
      總 on-site 剛度 = (E_J/2)·V·σ²
      總 bond  剛度 = (J_eff/2)·E·2σ² = J_eff·E·σ²
      均分 ⟹ (E_J/2)·V = J_eff·E ⟹ E_J = 2(E/V)J_eff = 4J_eff

      = 2·(120/60)·61.49999999999999 = 246.000000
  ⚠️  [否定/警示] 路線 A2 (剛度均分) 給 4J_eff = 246, 非 123
     差 2 倍來源: ⟨(Δθ)²⟩ = 2σ² 之獨立假設 → bond 項被**雙重計數**

  ─── 2 倍差之診斷 ───
  A1 比較「能量範圍」(capacity): 每邊 2J_eff, 每點 2E_J — 純量計數, 無方差假設
  A2 比較「二階剛度」: bond 項含 (Δθ)² = (θ_i−θ_j)², 對獨立場 = 2σ²
      但二階展開係喺**同一場**上: 對 uniform mode θ_i = θ, (Δθ)² = 0
      對最高模 (λ_max), bond 剛度 = (J_eff/2)·λ_max·|θ|²
      ⟹ A2 之 2σ² 假設把「兩點獨立」誤當成「同一場之漲落」
  ★ 判定: A1 (容量均分) 為正確比較; A2 之 2 倍係方差計數錯誤

  ✅ 2 倍差之來源已診斷 (A2 之 ⟨Δθ²⟩=2σ² 雙重計數)
     A1 無方差假設, 為正確比較

  ── 交叉檢驗: 若用最高模剛度比 (λ_max = 6.618034):
     E_J = λ_max·J_eff = 407.009090  ≠ 123  ❌ (已於 scripts/12 §4.4 否定)
  ── 若用平均模剛度比 (⟨λ⟩ = 4.000000):
     E_J = ⟨λ⟩·J_eff = 246.000000  ≠ 123  ❌
  ⚠️  [否定/警示] 譜比路線 (λ_max / ⟨λ⟩) 兩者皆 ≠ 2
     已於 scripts/12 否定, 此處交叉確認

  C. 相位滑移能量 2J_eff 與 E_J 之關係
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ─── 三種「單元能量」對照 ───
  (α) 單邊相位滑移 (Δθ: 0 → π, 無阻挫): ΔE = J_eff·[cos0 − cos(π)] = 2J_eff = 123
  (β) 阻挫邊懲罰 (α=π 但同色):         ΔE = J_eff·[cos0 − cos(−π)] = 2J_eff = 123
  (γ) 單節點相位翻轉 (θ_i: 0 → π):     ΔE = E_J·[cos0 − cos π] = 2E_J = 246

  (α) = (β) = 2J_eff = 123.0000 = E_J = 123.0000  ★ 三者相等!
  ✅ 單邊相位滑移能量 = 阻挫懲罰 = E_J = 123
     2J_eff = 122.99999999999999, E_J = 122.99999999999999

  ★ 物理讀法: **E_J = 單一 bond 之最大能量交換 (相位滑移 / 阻挫懲罰)**
     即 on-site 釘扎能量 = 單邊可承載之最大能量

  ⚠️ 但此讀法與 §A 之「容量均分」係**同一等式之兩種表述**:
     §A: V·E_J = E·J_eff  (總容量相等)
     §C: E_J = 2J_eff      (單邊滑移 = 單點釘扎)
     §C 只在「每點分擔 d/2 = 2 條邊」時與 §A 一致 (d = 4)
     → 兩者皆導向 E_J = (E/V)J_eff = (d/2)J_eff
  ⚠️  [否定/警示] §C 之「E_J = 單邊滑移能量」單獨睇係**定義**而非推導
     真正約束來自 §A 之容量均分 (V·E_J = E·J_eff); §C 係其 d=4 之特例讀法
