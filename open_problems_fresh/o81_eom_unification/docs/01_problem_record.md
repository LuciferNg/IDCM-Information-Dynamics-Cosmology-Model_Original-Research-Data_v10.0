## 二、答案 (2026-08-25/26 推導)

**兩個框架係同一四層次 Lagrangian 嘅不同極限:**

```
L_unified = L_chain + L_SSB + L_int + L_phase_eff + L_cos

UV:  L_chain = Σ_{n=1}^{88} [½φ̇_n² − ½(φ_{n+1}−φ_n)²/a²]       (自由晶格, 諧振子模式)
     ↓ 傅立葉對角化 → ω_k = 2sin(πk/88), k=1..44
     ↓ 奇偶分解 → μ² = Σγ_even − Σγ_odd = 90 − 88 = 2  (O34 慣例, 見 §七 註記 1)
SSB: L_SSB = (∂_μρ)²/2 + ρ²(∂_μθ)²/2 − μ²ρ² + λρ⁴            (μ²=2, λ=2/123)
     ↓ ⟨W⟩² = μ²/(2λ) = 61.5
耦合: L_int = Σ_n κ·ω_n·ρ·cos(θ−θ_n)·φ_n²                      (κ² = M₀ = 27.9009 MeV)
IR:  L_phase_eff = Σ_{i∈A5} [½θ̇_i² − (J_eff/2)Σ_{j∈N(i)}(θ_i−θ_j)²]   (J_eff = 61.5)
     L_cos = Σ_i [−E_J·cosθ_i − h_i·cosθ_i]
           + Σ_{⟨ij⟩} J_eff·[cos(θ_i−θ_j−α_ij) − (θ_i−θ_j)²/2]
```

**自由參數: 0** (全部係數由結構閉合)。

**關鍵係數**:
- `μ² = 2`, `λ = 2/123 = 2/[3(N_d−dim_ℂ)]`
- `⟨W⟩² = 61.5 = μ²/(2λ)`
- `J_eff = ⟨W⟩² = 61.5`
- `E_J = 2⟨W⟩² = 123 = L₁₀` (身份按 O204 裁決; 見 §七 註記 4)
- `h_i = A·cosθ_i`; `α_ij ∈ {0,π}`: 32 阻挫邊 = 20Δ + 12⬠

   → 兩者係兩個數, 不應以等號連接。

   該式係**恆等式**: 先設每阻挫邊能量 = 2J_eff = 123, 再乘 32 後除 32 → 必然回到 123。
   不構成 E_J 之獨立推導。E_J = 2⟨W⟩² 之實質依據為 (i) 模擬 E_J/J = 2, (ii) 123 = L₁₀ = 3(N_d−3)。

4. **docs/01 §2.3/§3.3 之 `E_J = 4μ²⟨W⟩² = 492` vs §6/§7 之 `E_J = 2⟨W⟩² = 123`**

   → 身份混淆而非數值錯誤; 本輪按時序鐵律以 dated 註記處理, 不回溯改寫 §2/§3 原文。
