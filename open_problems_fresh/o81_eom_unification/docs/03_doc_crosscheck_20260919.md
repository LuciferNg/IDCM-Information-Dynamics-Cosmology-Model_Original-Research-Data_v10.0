### ⚠️ 1. Σγ_even / Σγ_odd 標籤慣例不一致

| 位置 | 陳述 | 慣例 |

| `docs/01 §1.1` | Σγ = 90.0, Σγ_even = 46, Σγ_odd = 44 → 奇偶分裂: 世界/觀察者 | 44-site n-奇偶 |
| `docs/02 §層次2` | μ² = Σγ_even − Σγ_odd = 90 − 88 = 2 | 88-site k-奇偶 (**O34 權威**) |
| `scripts/05` | Σγ_even = 46 (世界), Σγ_odd = 44 (觀察者) | 44-site n-奇偶 |

獨立重算:
- 44-site (n=1..44): even = 46, odd = 44
- 88-site (γ_k = 4sin²(πk/176), k=1..88): even = **90** (= 世界), odd = **88** (= 觀察者)

**影響評估**: 兩者差值皆 = 2 = μ², 故下游 (λ = 2/123, ⟨W⟩² = 61.5, E_J = 123) **不受影響**。
**裁定建議**: 「世界/觀察者」身份按 **O34** 統一為 88-site (90/88); 44-site 之 46/44 應只稱「n-奇偶和」。
**歸屬**: 慣例統一屬 **O34** 範圍 → 交回上游 (本輪未修改任何文檔之該行)。
