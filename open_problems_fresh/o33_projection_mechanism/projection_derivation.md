## 1. 水喉模型：有限吞吐量

### 1.1 基礎

W-field 唔係無限帶寬，而係有固定吞吐量：

```
W = φ^(N_d·L) ops/phi-unit
  = φ^291.5
```

呢個係「管道直徑」— 每單位時間可處理嘅最大投影操作數。

### 1.2 投影 = 管道調度

```
K_Chain 44 個模式 (γ₁...γ₄₄)
     │
     │ 有限吞吐量 W
     ▼
  投影管道
     │
     │ 只有 N_d/2 = 22 個模式可同時投影
     ▼
  SM 粒子 (28.5/90 能量)
```

### 1.3 閾值

投影閾值 = sync 能量密度：

```
γ_cutoff = E_sync / (N_d/2) = 61.5/22 = 2.795

γ_n < 2.795 → 可投影 (低模式)
γ_n ≥ 2.795 → 留 sync (高模式)
```

## 2. Sync 儲備 = 觀察者預算 (O41)

### 2.1 結構由來

Sync 能量 61.5 源自觀察者預算：


- L₁₀ = 123 = 第 10 個 Lucas 數
- N_d = 44 = K_Chain 維度

## 3. 黑洞 = 反投影

### 3.1 機制

黑洞係投影嘅逆過程：

```
正常投影: sync → 管道 → SM 粒子 (物質形成)
反投影:   SM 粒子 → 事件視界 → sync (黑洞形成)
```

### 3.2 能量守恆

```
K_Chain 層級:
Σγ = E_proj + E_sync = 90 (永遠守恆)

黑洞形成:
E_proj → E_sync (轉移, 唔係消滅)
ΔE_proj = -E_BH, ΔE_sync = +E_BH
Σγ = 90 不變

→ 黑洞質量 M_BH = E_BH/c² ≠ 0
→ 只係由 SM 投影態轉做 K_Chain sync 態
-> 唔係「質量消失」, 係「質量轉移儲存形式」
```

### 3.3 資訊守恆

```
黑洞資訊悖論 → IDCM 自然解決:

SM 層: 資訊跌入事件視界 → 似消失
K_Chain 層: 資訊從未離開 Σγ=90
           (K_Chain 係全譜記憶體)

資訊遺失 = SM 投影層嘅幻象
```
