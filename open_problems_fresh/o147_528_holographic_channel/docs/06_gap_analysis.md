## 1. gap 0.73% 源頭定位

兩層都聲稱 m_s/m_d ≈ 20，但裸比差 0.73%：

```
譜比層: sin22/sin1 = 19.811167
公式層: (γ₁₄/γ₁)×(3.6/33) = 19.668040
gap = 0.73%
```

**代數源頭**：兩層一致需要 P_f(s)/P_f(d) = sin22·sin1/sin²14 = **0.10989**，而 O143 grid 鎖定 3.6/33 = **0.10909**——差 0.73%，冇細結構數。

即 gap 係 **P_f 比 3.6/33 同 sin² 幾何要求之間嘅張力**，唔係計算錯誤。

## 2. ★ 兩層各有 φ 修正路徑命中 20（新發現）

| 層次 | 裸比 | φ 修正 | 命中 | 分子 |
|:-----|:-----|:-------|:-----|:-----|
| 譜比層 | sin22/sin1 = 19.811 | φ^(10/528) | 19.9925（0.037%） | 10 = n_u = n₀(1)−L₄ |
| 公式層 | (γ₁₄/γ₁)(3.6/33) = 19.668 | **φ^(18/528)** | **19.9934（0.033%）** | **18 = L₆** 🆕 |

**公式層加 φ^(18/528) 修正後同樣命中 20（0.033%）**——O143 grid 原設計冇修正，但修正路徑存在，且分子 18 = L₆ = Tr(T̂⁶) 係轉移矩陣譜跡（O142）。

## 3. ★★ 18/528 = 3/88 = N_gen/Σγ_odd（兩層修正統一）

```
10/528 = 5/264 = n_u/528            （譜比層, 528 = Σγ_odd×2N_gen）
18/528 = 3/88  = L₂/(2N_d) = N_gen/Σγ_odd   （公式層簡化!）
```

**關鍵**：18/528 簡化 = 3/88——即公式層修正 = **世代數 ÷ 觀察者預算**（3/88）！兩層修正都有**觀察者預算**參與：
- 譜比層：n_u 攤分到 528 = Σγ_odd×2N_gen
- 公式層：N_gen 攤分到 88 = Σγ_odd

呢個係「528 觀察者側容量」角色嘅第二個獨立證據。

## 4. n_s 整數化內在偏差

公式層命中 20 需要連續 n_s = **14.129**，O143 用整數 14 → 引入 0.92% 內在偏差（grid 1.66% 偏差嘅 55% 來自整數化，45% 來自 P_f 比）。
