## 1. 核心發現：k(A/B) = κ(A) − κ(B)

docs/07 發現 8 個質量比需要 φ^(k/528) 修正，k ∈ {0, ±2, ±6, ±16, ±18}，但「點解 k = f(分母粒子)」開放。
docs/08 排除 7 個單變量模型，判定「數據點唔夠」。

**本 session 新假說：k 唔係 f(分母)，而係每粒子固有修正 κ 嘅差。**

```
k(A/B) = κ(A) − κ(B)
```

即每個費米子有一個固有 φ 修正指數 κ_f，質量比嘅修正 = 分子 κ 減分母 κ。**比嘅修正係「差」而唔係「分母」** — 呢個係 docs/08 排除唔到嘅結構。

### 3.1 行結構：κ(U) − κ(D) = −B²（常數！）

```

⚠️ **2026-09-08 修正（docs/11）**：κ(t) 由 O64 實證 = **0**（唔係 −14）！gen3 例外因為 t 唔喺 O143 grid（O64 用 γ₄₄×37×42 Z_topology），κ 修正被 Z_topology 吸收。κ(U) = κ(D) − B² 係 grid 內規則（gen1/2）。t/b 嘅 κ 修正 = 0−2 = −2（scripts/11 驗證 0.026%）。

### 3.2 列結構：代間增量（U/D 行相同！）

```

⚠️ **2026-09-08 cross-reference（docs/11）**：上表 U 行 gen3 用 κ(t) = −14（當時預測）計出 κ(t)−κ(c) = −16。docs/11 實證 κ(t) = **0**（O64 Z_topology 42），所以 U 行 gen3 實際增量 = 0−2 = **−2**（唔係 −16）——行規則 κ(U) = κ(D) − B² 只對 gen1/2 成立（grid 內），gen3 例外有結構原因。原記錄保留做時序歷史，數值以 docs/11 為準。

## 4. 對 docs/07 §2.4「分母粒子規律」嘅取代

## 6. 意義

- **k 先驗規則閉合**：修正分子 k = κ(分子) − κ(分母)，κ 係每粒子固有 φ 相位指數（全結構數）
- 528 分母嘅角色統一：**每粒子有 φ^(κ_f/528) 修正**，比嘅修正自動 = 差 → 528 係「粒子固有相位」嘅共同歸一化
- 同 O143 P_f grid 互補：P_f 控制絕對質量（M₀γ_nP_f），κ 控制比層 φ 修正 — 兩層分工（docs/05）而家兩邊都有結構
- docs/07「公式層修正必要性」升級：唔止 s/d（18/528），**全部 21 個比**嘅修正都由同一個 κ 表生成 — 系統性, 唔係逐個擬合
