## 1. 優先級二：κ 種子起源推導（🔴 → 🟢 部分）

docs/09 判定「κ 表『點解』🔴 — 5 個結構數種子嘅指派規則未推導」。本 session 推導出**種子生成公式**：

### 1.1 ★ 種子生成公式（全部由基本結構數直接生成）

```
κ(e) = κ(μ) = (L₅ − B)/2 = (11−4)/2 = 3.5 = L₄/2   ← 輕子 gen1/2
κ(τ) = L₅ − Z₂ = 11−2 = 9 = N_gen²                  ← 輕子 gen3
κ(s) = 2N_gen² = 2×9 = 18 = L₆                       ← D gen2
κ(b) = Z₂ = B/2 = 2                                  ← D gen3
κ(u) = κ(d) − B² = −16                               ← 行規則 (gen1)
κ(c) = κ(s) − B² = 2                                 ← 行規則 (gen2)
κ(t) = 0                                             ← O64 實證 (docs/11)
```

**4 個種子（e/τ/s/b）全部由 {L₅, B, Z₂, N_gen} 生成** — 唔再係「指派」，係「生成」。零新常數。

### 1.2 ★ 用戶問題答案：½L₅ vs L₆−B²

用戶建議檢查 ½L₅（輕子 gen2→3 增量）同 L₆−B² = 2（夸克 gen3 值）之間嘅表示論/CY₃ 對應。

**發現**：

```
½L₅ − (L₆−B²) = 5.5 − 2 = 3.5 = L₄/2 = κ(e)  ✅
```

即：**輕子 gen2→3 增量（½L₅ = rank(SU(12))/2）減去夸克 gen3 值（Z₂ = B/2）＝ 輕子 gen1 值（L₄/2）**。三條獨立生成規則喺 κ(e) 收斂。

- ½L₅ = 5.5 = **rank(SU(12))/2**（rank(SU(12)) = 11 = L₅, O59: 1+11 = Cartan+Rank）
- L₆−B² = 2 = Z₂ = B/2 = γ₄₄/2（O159/O160: γ₄₄ = B = 4）
- 冇直接 CY₃ 交點數身份（χ(CY₃) = −124, |χ|/2 = 62 — 唔係種子）— 誠實標記

## 2. 優先級三：階梯三點生成算子（🟡 → 🟢 閉合）

### 2.1 ★ 乘法生成算子 m(a,b) = N_d × Z₂^a × N_gen^b

用戶建議 Interaction 形式 f(a,b) = N_d(aZ₂ + bN_gen + ab·I)。測試後發現更簡潔嘅**乘法形式**：

```
m(a,b) = N_d × Z₂^a × N_gen^b

rung1 (μ/e): m(1,0) = 44 × 2¹ × 3⁰ = 88   ✅
rung2 (t/b): m(0,1) = 44 × 2⁰ × 3¹ = 132  ✅
rung3 (s/d): m(2,1) = 44 × 2² × 3¹ = 528  ✅
```

**三點全中** — 階梯由指數 (a,b) 生成，乘數 = Z₂ 冪次 × N_gen 冪次。

### 2.2 ★ (2,1) = 2(1,0) + (0,1) 指數線性組合 = 物理張量積

```
(2,1) = 2(1,0) + (0,1)  喺指數空間（線性組合）
→ m = Z₂² × N_gen = 4 × 3 = 12 = B × N_gen
→ 528 = N_d × B × N_gen = 44 × 4 × 3
```

**物理語意**（同用戶建議一致）：第三階梯 = **兩倍對偶（2×Z₂）與世代（N_gen）嘅張量積** = 世界維度(B) × 世代(N_gen)。用户嘅「2×Z₂ 與 N_gen 的張量積」直覺正確，但正確算子係乘法（指數加法）而唔係線性+Interaction。

### 2.3 對比用戶 Interaction 形式

```
f(2,1) = 44×(2·2 + 1·3 + 2·1·I) = 528 → 7+2I = 12 → I = 2.5 = F₅/Z₂ = 5/2
```

用戶形式 I = 2.5 = F₅/Z₂ 都係結構數，但需要 Interaction 項。**乘法形式 m = N_d·Z₂^a·N_gen^b 更簡潔**：冇 Interaction 項、三點全中、指數加法 = 物理張量積。乘法形式勝出。

### 2.4 階梯 rung 對應嘅 κ 分子一致性

```
μ/e: κ(μ)−κ(e) = 3.5−3.5 = 0    (唔需要修正 ✓, docs/07 k≈0)
s/d: κ(s)−κ(d) = 18−0 = 18 = L₆ (公式層修正分子 ✓, docs/07 k=18)
t/b: κ(t)−κ(b) = 0−2 = −2       (新! scripts/11 驗證 0.026%)
```
