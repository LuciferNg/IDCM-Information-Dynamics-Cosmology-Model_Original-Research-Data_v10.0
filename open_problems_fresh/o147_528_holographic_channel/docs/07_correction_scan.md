## 2. ★ 三大發現

### 2.1 修正分子全部結構數（或零）

非零 k 集合：**{6, 18, −16}** = {2N_gen, L₆, −B²}——全部係 IDCM 基本常數。冇出現任意數。

### 2.2 ★★ 修正分子加法一致（對數域系統性）

```
k(b/s) = k(b/d) − k(s/d) = 2 − 18 = −16  ✅
k(c/s) = k(c/u) − k(s/u)... = −16         ✅ (獨立計算一致)
```

修正唔係逐個擬合——佢哋喺對數域遵守加法，證明係**系統性偏差**，唔係隨機。

### 2.3 ★ -16 = -B²（新結構身份）

-16 = −B² = −4² = −2F₆。B² 之前出現喺 **528 = B²×M = 16×33**（docs/02 交叉確認）——-B² 修正令 528 嘅 B² 因子多一個用途。

### 2.4 修正分子跟「分母粒子」有規律跡象

| 分母粒子 | k |
|:---------|:--:|
| u, d（第一代夸克, n=1） | +18 = L₆ |
| s（第二代夸克, n=14） | −16 = −B² |
| e（第一代輕子, n=1） | +6 = 2N_gen |
| μ（第二代輕子, n=7） | 0 |

🟡 數據點太少（4 個分母粒子），只係跡象唔係規律。

## 3. 判定：公式層隱含 φ 修正

- ✅ **8/8 比可以通過 k/528 修正閉合**（k ∈ {0, ±2, ±6, ±16, ±18}，全結構數或零）
- ✅ 加法一致 → 系統性（唔係每個比獨立擬合）
- ✅ 修正後全部 Δ ≤ 0.08%（s/d 0.033%, c/u 0.076%, b/s 0.02%, c/s 0.02%）
- 🟡 **後驗標記**：k 值由 PDG 反推，唔係先驗推導——「結構數匹配」有選擇自由度（但 k 集中喺少數值，唔係散佈）
- 🟡 「點解 u/d 要 +18, s 要 −16, e 要 +6」嘅規律未推導

**同 O146 教訓對照**：O146 證明「密佈集合搵匹配 = 假象」（946 拍頻 vs 質量比 p=0.91）。今次唔同——k 值集中喺 {6, 18, −16} 三個結構數（8 個比得 3 個 k 值 + 3 個零），而且加法一致——呢個係「k 有結構」嘅證據，但力度有限（8 個數據點）。
