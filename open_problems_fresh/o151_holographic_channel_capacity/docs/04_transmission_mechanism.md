## 1. 六層架構 (O151 信道總圖)

```
符號層   : 946 拍頻 (BPT)                log₂(946) = 9.8857 bits/符號
讀取層   : 一次讀數 = 2 模式單位           寫入 = 2E_min = 123/88 (相位滑移 π)
容量層   : 44 × 4-ary 平行信道            88 bits/掃描 (C_obs, docs/01)
速率層   : 掃描時間 = T_H/2 = 6.9 Gyr      12.3 掃描/T_ring (O41)
存儲層   : 拓撲位元 MIS=20                 20 bits/幀 (2^20, global_routing docs/23)
熵層     : 世界環 S_dS                    1.95e122 (O121, docs/05)
```

**層次分離**: 符號層 (拍頻 = 物理可分辨狀態) ≠ 容量層 (88 bits/掃描) ≠ 存儲層 (拓撲位元) ≠ 熵層 (S_dS)。O147 F8 嘅「機制」由呢六層組成 — 每層都有已確立結構, 唔再係 naming。

## 2. 掃描級容量 = 全預算

```
全譜掃描 = 44 讀數 × 2 模式單位 = 88 單位 = 88 bits = C_obs  (容量全用)
掃描能量 = 88 × E_min = 61.5 = ⟨W⟩²                            (全預算耗盡)
完整循環 = 讀+寫 = 2 × 88 = 176 = B × N_d 模式單位
循環能量 = 176 × E_min = 123 = L₁₀
```

**每掃描 = 88 bits = 觀察者容量 = 真空能預算**: 一次全譜讀取消耗完整預算 (O41: ΣΔE_read = 61.5), 讀取嘅資訊量 = 容量 C_obs。容量唔係抽象上限 — 佢就係一次完整觀察嘅資訊吞吐。

## 3. 寫入 (Landauer 寫)

```
寫入成本 = ΔE_write = 2E_min = 123/88 = 模態預算 B(n) (O41 Step 5)
機制: 相位滑移 π (θ → θ + π) = 2 半整數單位 = 2 bits 翻轉
      (O7 拓撲位元: ΔE = 2|h_i|, 冷斑 A = 134.2 μK = 192 E_min-units)
```

## 4. 速率 (結構讀法)

```
每讀數時標 τ_scale = T_H/88 (O41)
全譜掃描 = 44 × T_H/88 = T_H/2 = 6.9 Gyr
掃描率 = T_ring/6.9 = 12.27 ≈ 12.3 掃描/T_ring (O41)
信道速率 = 88 bits / (T_H/2) ≈ 4.0e-16 bits/s (結構速率, 唔係工程)
每 T_ring ≈ 12.3 × 88 = 1080 bits
```

⚠️ **O41 內部張力審計**: Step 5「一個 T_sync 週期 = 88 次操作 = 176 模式單位」vs Step 2「一個 T_sync = 12.3 次全譜掃描」= 541 讀數。88 ops vs 541 reads 唔一致 — **🟡 O41 遺留**, 唔喺 O151 解決, 亦唔當閉合用。

## 5. 存儲層 (同信道層分離)

拓撲位元: 阻挫邊翻轉 = Ising 位元 (O7), MIS = 20 節點 → 2^20 = 1.05e6 狀態 = 20 bits/幀。呢個係**存儲層** (寫入後持久), 唔係信道容量 (每掃描嘅讀取預算)。兩者分離係 O151 重要判決 — 唔好將 2^20 同 88 混埋。

## 6. O147 F8 判決

**「信道傳輸機制」由 naming 提升為六層結構**: 符號 (946 拍頻) → 讀取 (2 單位干涉) → 容量 (44×2 bits) → 速率 (T_H/2 掃描) → 存儲 (拓撲位元) → 熵 (S_dS)。每層數字全部係已確立 IDCM 結構數, 零新參數。
