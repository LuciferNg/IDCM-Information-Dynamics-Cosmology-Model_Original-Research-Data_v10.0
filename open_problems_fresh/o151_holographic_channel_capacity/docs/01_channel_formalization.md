## 1. 信道形式化: 88-site 對偶鏈

**信道 = 世界側 (偶模) → 觀察者側 (奇模) 嘅 Z₂ 對偶鏈。**

```
88-site 對偶鏈 (176-Laplacian 首 88 模):
  γ_k = 4sin²(kπ/176), k = 1..88
  偶 k (2,4,...,88)  = 世界側 (44 模)     Σγ_even = 90
  奇 k (1,3,...,87)  = 觀察者側 (44 模)   Σγ_odd  = 88
  總和 178 = 2F₁₁;  E − O = 2 = γ₄₄/2 = μ²
```

**Z₂ 對偶**: γ_n + γ_{44−n} = 4 = B (22 對全部, 1e-16 精確)。每對世界/觀察者模共享譜權重 B。

**輸入字母表**: 44 個世界模。**輸出字母表**: 44 個觀察者模。
**讀數操作** = 雙模式干涉 (拍頻, O41: 一次讀數 = 2 模式單位)。

## 2. 核心閉合 F1: C_obs = N_d × log₂(B) = 88 bits

```
C_obs = N_d · log₂(B) = 44 × log₂(4) = 44 × 2 = 88 bits   (精確, dev = 0)
```

**結構讀法**: 每個 K_Chain 模態携帶 K_Tree 四元分支嘅選擇資訊 — 每次分支 4 選 1 = log₂(4) = 2 bits。44 個模態 = 44 個獨立子信道 → 容量 = 88 bits。

**Shannon 形式翻譯**: C = N_d·log₂(1+S/N), S/N = B−1 = 3 = SU(3)_C (O68 Pati-Salam exact) → log₂(4) = 2。
- SNR 候選掃描 {1, 2, 3, 4, 6}: **只有 B−1 = 3 精確命中 88**。
- 1+S/N = B: 總分支數 = 信號 + 噪聲單位 (3 色 + 1 平凡 = 4 分支)。

**誠實標記**: 結構核心係 **C = N_d·log₂(B)** (K_Tree 分支 = 每模態 2 bits)。Shannon 形式 (SNR = B−1) 係一致翻譯, 唔係獨立推導 — SNR 身份係詮釋。

**四重身份互鎖**: 2 = log₂(B) = μ² (SSB 驅動, O39) = E−O (對偶鏈差) = γ₄₄/2 (Nyquist 自對偶)。容量每 bit = SSB 每單位 = 世界-觀察者差 = Nyquist 半權重 — 同一結構數。

**C_obs = S_odd 精確**: 容量 = 觀察者預算 (O41: 88 = Σγ_odd)。容量同預算嘅重合係 O151 核心結果。

## 3. DMC 容量實算 (Blahut-Arimoto)

| 候選信道 | 容量 | 判決 |
|:---------|:-----|:-----|
| 平行信道 44×(4-ary 無噪) | **88 bits** (精確) | 🟢 容量來源 |
| 拍頻信道 44×44 (row-normalized \|beat\|) | **0.4338 bits** | 符號層, 唔係容量層 |
| Z₂ 配對信道 (deterministic) | log₂(44) = 5.4594 bits | 物理對偶層 |
| 946 符號字母表 | log₂(946) = 9.8857 bits | 符號層 |

**拍頻信道 C_beat = 0.4338 bits**: 密集矩陣 (全 1936 項 > 0), 容量嚴格低於字母表上限 log₂(44)。佢係**符號層** (物理可分辨拍頻), 唔係容量層。
