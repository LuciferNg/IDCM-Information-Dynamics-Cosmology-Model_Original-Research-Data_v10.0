## ★ 1. row Z₂ 退化 (核心發現)
**世界模 ka = 2m 同 ka' = 88−2m 喺觀察者側嘅輸出分佈完全相同**:
```
row(m) = row(44−m)   (max |Δ| = 3.5e-17)
```
代數證明 (abs 之下):
```
b(44−m, n) = |4 sin((89−2(m+n))π/176) cos((87−2(m−n))π/176)|
           = |4 sin(π/2 − (2(m+n)−1)π/176) · sin(π/2 + (2|m−n|−1)π/176)|
           = b(m, n)
```
(sin/cos 補角恆等: sin(π/2−θ) = cos θ, cos(π/2+φ) = −sin φ)

**後果: 44 個輸入只有 22 個唔同 row**。BA 最優 p₃=p₄₁, p₁₈=p₂₆ 嘅「對內對稱」
唔係新自由度 — 係同一 row 嘅 Z₂ 退化重複 (貝氏分身)。
