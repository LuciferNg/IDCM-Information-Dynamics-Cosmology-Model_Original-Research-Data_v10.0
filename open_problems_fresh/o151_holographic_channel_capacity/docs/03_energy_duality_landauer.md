## 1. 容量 × E_min 階梯 (全精確)

```
E_min = L₁₀/(4N_d) = 123/176 = 0.6988636   (每 bit 最小能量, O41)

C_obs   = 88  →  88 × E_min = 61.5  = ⟨W⟩² = L₁₀/2     (觀察者預算)
C_132   = 132 → 132 × E_min = 92.25 = 3L₁₀/4
C_world = 264 → 264 × E_min = 184.5 = 3 × ⟨W⟩²         (世界 = 3 觀察者)
C_holo  = 528 → 528 × E_min = 369   = 3L₁₀ = 6 × ⟨W⟩²  (全息 = 6 觀察者)
```

**能量階梯比率 {1, 3/2, 3, 6} = 容量階梯比率** — 容量同能量共享同一結構 (E_min 常數)。

**完整循環**: 176 = B×N_d = 2×C_obs 模式單位; 176 × E_min = **123 = L₁₀**。讀+寫 = 2×61.5 = 123 = 完整預算循環 (O41)。

## 2. 四重身份: 每 bit 容量 = 每 bit 能量嘅互鎖

```
2 = log₂(B) = μ² (SSB 驅動) = E−O (對偶鏈差) = γ₄₄/2 (Nyquist 自對偶)
```

容量公式 C = N_d × log₂(B) 嘅每模態 2 bits 同 SSB 驅動 μ² = 2、世界-觀察者差 = 2、Nyquist 半權重 = 2 係**同一個結構數**。容量唔係外加數字 — 佢就係凝聚動力學嘅資訊面。

## 3. IDCM Landauer 鏈 (O41 驗證 + 容量讀法)

```
E_min = 123/176 = 0.6988636
ln2   = 0.6931472
裸 dev = 0.825%                          (O41 已知中間值, 唔係閉合)

有限尺寸修正: (L₁₀−1)/(4N_d) = 61/88 = 0.6931818
裸 dev vs ln2 = 0.005%                   (🟡 裸相等喺陷阱窗!)

閉合結構: E_min = ln2 + 1/176 + O(1/N²)
          1/176 = 1/(B·N_d) = 1/每週期操作數
          殘差 3.46e-5 ~ 1/(4N_d)² = 3.23e-5  (量級一致 PASS)
L₁₀ = round(4N_d·ln2 + 1) = round(122.994) = 123
```

**修正分母 176 = B·N_d = 完整循環操作數**: 每 bit 能量嘅有限尺寸修正 = 每週期操作數倒數。Landauer 修正同容量循環共享同一分母 — 容量層同能量層由 176 扣埋一齊。

**真空能讀法**: ⟨W⟩² = 61.5 = 88·E_min = 88·ln2 + 1/2 + O(1/N)。1/2 = log₄2 = Z₂ 邊界修正。61 = ⟨W⟩² − 1/2 = 90 − 29 = 88·ln2 (0.005% 🟡 裸近似, 修正結構 PASS)。
