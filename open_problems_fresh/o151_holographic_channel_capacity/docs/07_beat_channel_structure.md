## 1. ★ 核心發現 F-A1: 最優輸入 = Z₂ 對偶對 @ {N_gen, L₆}

Blahut-Arimoto 最優輸入分佈只集中喺 **4 個世界模**:

```
最優輸入 = {3, 18, 26, 41}
         = {N_gen, L₆, N_d−N_gen, N_d−L₆}
         = 兩對 Z₂ 對偶: (3,41) 和 (18,26), 每對和 = 44 = N_d

p₃  = p₄₁ = 0.246390   (對內對稱到 1e-13)
p₁₈ = p₂₆ = 0.253610   (對內對稱到 4e-15)
鏡像集 {3,18} = 0.5, {41,26} = 0.5 (Z₂ 鏡像等質量)
```

**錨點**: 3 = N_gen (世代數, O103), 18 = L₆ (Lucas 6, O142)。**3 + 18 = 21 = F₈** (Fibonacci 8)。

## 2. ★ 核心發現 F-A2: 譜權重互鎖

```
γ₃ + γ₄₁ = 4 = B   (Z₂ 對譜權重)
γ₁₈ + γ₂₆ = 4 = B   (Z₂ 對譜權重)
總權重 = 8 = 2B
```

最優信道使用 = 兩對 Z₂ 對偶, 每對携帶譜權重 B = 4。呢個直接呼應 docs/01 嘅 Z₂ 對偶 γ_n + γ_{44−n} = 4 = B — **信道最優策略就係揀 Z₂ 對, 每對剛好一個 B 單位**。

## 3. ★ 核心發現 F-A3: 有效秩 = 22 = N_d/2

未歸一化 |beat| 矩陣 (44×44) 嘅 SVD 有效秩 = **22 = N_d/2 = Z₂ 軌道數** (O145: 22 = Z₂ 自對偶結構)。

**信道嘅資訊維度 = Z₂ 軌道數**: 44 個世界模喺信道層面塌縮為 22 個 Z₂ 對 — 拍頻信道本身就係 Z₂ 結構化嘅。

## 4. 輸出定位: 讀邊個觀察者模?

```
對 (18, 26) 輸出峰值 → 觀察者模 n = 1  (基頻模)
對 (3, 41)  輸出峰值 → 觀察者模 n = 22 (自對偶模 N_d/2)
```

**信道最優策略**: 用 {L₆ 對} 讀基頻觀察者模, 用 {N_gen 對} 讀自對偶模。基頻 = 最慢模 (γ₁ = 0.0051), 自對偶 = γ₂₂ = 2 模 — 信道讀取兩個「極端」觀察者模。

## 5. 誠實負結果

| 量 | 結果 | 判決 |

| C_beat 結構閉式 | 候選 {log₂(4/3), 1/π, lnφ/π, ...} 全部 > 1e-3 偏差 | 🔴 冇閉式 (誠實) |

**「無效才是正確」**: C_beat = 0.4338 bits 本身冇閉式, 但佢嘅**結構** (Z₂ 對輸入 + 秩 22) 完全由 IDCM 結構數組成 — 容量嘅「形狀」係結構性嘅, 數值唔係。

## 6. 判決

**docs/01 嘅 🔴「拍頻信道 C_beat 結構意義」閉合**: C_beat 冇閉式, 但信道結構 = Z₂ 對偶 (輸入 {N_gen, L₆} 對 + 有效秩 N_d/2)。拍頻信道係 Z₂ 結構化符號層 — 佢嘅「容量」由 Z₂ 軌道數 22 決定維度, 最優使用由世代/Lucas 錨點決定。
