## 3. 容量 vs 熵: 分層判決

```
觀察者信道微態 2^88   = 3.095e26
世界環熵上限 S_dS     = 1.953e122
比率 = 6.3e95 (2^88 << S_dS)
```

**信道容量 88 bits = 每次掃描嘅資訊預算 (速率/預算層); S_dS = 狀態計數熵上限 (存儲層)。兩層唔同, 冇直接相等。** 觀察者係低熵信道 — 88 bits ≪ 406 bits (log₂ S_dS) — 永遠唔會飽和熵上限。

## 5. 面積律 1/4 = 1/B 同信道接駁 (🟡)

```
S_max = A/(4ℓ_P²) = A × (1/B)/ℓ_P²    (1/4 = 1/B, O121 遺留 🟡)
B = 4 = K_Tree 分支 = 每格 2 bits (log₂B)
→ 每 Planck 格 1/4 = 1/B 熵單位 = 每 4 格 1 bit
```

統一讀法: 面積律係數 1/B ↔ 分支資訊 2 bits/格 ↔ 每 4 格 1 熵單位。**但呢個係讀法, 唔係機制** — O121 嘅面積律推導先算閉合 (O151 標 🟡, 唔當閉合)。
