## 0. 目的

R11 發現 IDCM 半頻模定理（M≡2 mod 3 ⟹ ω̃=1/2 EXACT）。R13 問：呢個離散結構有冇對應到**已存在嘅 DCE 實驗幾何**？

## 1. Wilson 2011（Nature 479, 376）實驗幾何

| 參數 | 值 |
|:---|:---|
| 邊界調變（SQUID 泵）| f_d = **10.22 GHz** |

## 2. IDCM 半頻模映射

```
DCE 共振條件:    ω_d = ω_a + ω_b
半頻模自對:      ω_a = ω_b = ω̃_m = 1/2  ⟹  ω_d = 2·ω_m = ω̃_max
實驗幾何:        f_pair/f_d = 1/2  ⟺  產出模 = 泵/2  ⟺  半頻模自對
```

## 3. 判決

> **Wilson 2011 嘅實驗幾何 = IDCM 半頻模自對嘅連續實現**：
> 「泵頻 = 2 × 模頻」即「模頻 = 半泵頻」，正正就係半頻模 ω̃=1/2 嘅條件。IDCM 離散譜（M≡2 mod3 板段）自動鎖定呢個 2:1 比例 —— 唔使調任何參數。
>
> **可證偽預言**：喺 M≡2 mod3 板段（離散格點邊界, e.g. SQUID 陣列），泵頻鎖定 f_d = 2f_mode 時產出對必然存在（結構確定）；**M≢2 mod3 配置冇半頻自對** → 相同條件下產出幾何唔同（可測差異）。呢個係 R11-C4 定理嘅實驗後果。

**誠實限制**：
- Wilson 用連續傳輸線（非離散 88-site）；半頻模喺本框架係離散格點物件 —— 對照係「幾何比例同構」唔係「同一台實驗」
- 尺度映射（模頻以 a_site 錨, 宇宙尺度）未做 —— 零參數只保 2:1 比例，唔保絕對 GHz
- IDCM 預言係比例結構（2:1），唔係對 Wilson 絕對頻率嘅預言重新 fit
