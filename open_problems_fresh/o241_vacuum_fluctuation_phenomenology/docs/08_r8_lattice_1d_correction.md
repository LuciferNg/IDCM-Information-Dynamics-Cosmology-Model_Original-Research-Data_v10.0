## 1. scripts/02 錯誤記錄（誠實修正）

**錯誤**：scripts/02 C4 用 `E_cas_shape(N)×N → −π/24?` 檢查 —— 但 E_cas_shape(N) 包含**常數項 2/π−1/2**，乘 N 後發散到 +∞（683 @N=5000），錯誤判定「裸便有限譜唔出係數」。

**正確 EM 漸近**（2026-10-08 重新手推）：
```
S_seg(N) = Σ_{m=1}^N sin(πm/(2(N+1)))
         = 2(N+1)/π − 1/2 − π/(24(N+1)) + O(1/N²)
E_cas(N)/J = S_seg(N) − 2N/π = 2/π − 1/2 − π/(24(N+1)) + O(1/N²)
⇒ 常數項 2/π−1/2（正規化偏移）＋ Casimir 項 −π/(24(N+1))
⇒ F = −dE/dd = −πħv/(24d²)     [d=Na, v=Ja/ħ]
```

**修正**：**1D 格點 Dirichlet 兩板喺長距離極限確實給出標準 1D Casimir 係數 −π/24**（v2 嘅「負發現」唔成立）。
