## 1. ★ Winding 定理 (環閉合 ⟺ 整數圈)

88 鏈 = 偶環 (88 步, 每步相位 kπ/176):
```
winding(a,b) = 88·(a−b)π/176 ÷ 2π = (a−b)/4 圈
環閉合 ⟺ winding ∈ ℤ ⟺ a−b ≡ 0 (mod 4)
```
55 塔 = 奇環 (55 步, 每步相位 kπ/55):
```
winding(a,b) = 55·(a−b)π/55 ÷ 2π = (a−b)/2 圈
環閉合 ⟺ a−b 偶
```

## 2. ★ δ_CKM: 世代整數圈 (winding = N_gen)

```
δ modes (21, 9): d = 12 = N_gen·B → winding = 12/4 = 3 = N_gen 圈!
CP 相位繞 3 個完整圈 = 三世代 — 相移整數化, 世代格閉合
θ₂₃ modes (7, 6): d = 1 → 88 鏈 winding = 1/4 ∉ ℤ, 55 塔 winding = 1/2 ∉ ℤ
→ (7,6) 兩邊都破 — 相移唔整數化 (用戶反證法成立)
```

## 3. 域不相容 (cyclotomic 實子域)

```
δ(88) = atan(sin(21π/176)/sin(9π/176)) = 66.399960°  ∈ Q(ζ₈₈)⁺
δ(55) = atan(sin(21π/55)/sin(9π/55))   = 62.18°       ∈ Q(ζ₅₅)⁺
相等 ⟹ 有理數 (實子域交集, gcd(88,55) = 11)
tan δ(88) = 2.288905... — 連分數 15 項唔終止 → ∉ Q
→ 兩個域值冇可能相等 — 代數不相容
```

## 4. 反證鏈 (δ 唔可以放 55 塔)

```
假設: δ_CKM 置於 55 塔 → 需要 (a,b) ∈ 55 塔 modes
① 環閉合: winding = (a−b)/2 需整數 → d 偶
② 世代格: d = N_gen·B = 12 — 但 55 = 5×11 冇 3 因子 → 先天冇世代格閉合
③ 就算揀 d 偶 (如 (21,9)): δ(55) = 62.18° ≠ 66.399960° — 域值矛盾
⇒ 假設矛盾 — δ 唔可以放 55 塔
```

## 5. ★ 分工定理: 偶環 = 相位閉合域, 奇環 = 混合域

```
88 鏈 (偶, 2N_d):  winding 整數圈 → CP 相位/全域量 (δ_CKM)
55 塔 (奇, home):  winding 半圈 → 混合角/局域量 (θ₂₃)
θ₂₃ 係角度 (49°) 唔係相位 — 唔使環閉合, 相鄰 modes 做最大混合
```
