## A. ★ 通道分配規則 (R5 🔴 → 候選 🟡)

**問題**: 點解 θ₁₂ ↔ odds-angle (角度相加), θ₁₃ ↔ measure (振幅相乘)?

```
θ₁₂ = atan(1/φ) + atan(1/33) = 31.7175° + 1.7357° = 33.4532°  (主角 + 細角修正)
sinθ₁₃ = ε·32/33 = 0.149826 → θ₁₃ = 8.6169°                    (直接幅度, 冇主角)
```

**候選規則**: 
1. **有角基底 → 角度合成 (SO(2) 群律)**; **冇角基底 → 幅度直接 (asin)**。
   θ₁₂ 有主角 atan(1/φ) = 31.72°,細修正 atan(1/33) 以角度相加自然合成;
   θ₁₃ 冇角基底,sinθ₁₃ 直接係投影幅度。
2. **細概率 → odds,大概率 → measure**: θ₁₂ 用 p_B = 1/33 (細, atan 級數收斂);
   θ₁₃ 用 p_I = 32/33 (大, 1−p = 1/33 細量, ε·p_I 造細幅度)。
   兩通道嘅「細修正」對稱: atan(1/33) ≈ 0.0303 rad ↔ ε·32/33 ≈ 0.1498。

## B. ★ Sector 分配規則 (R7 🔴 → 候選 🟡)

**問題**: 點解 δ_CKM 留 88, θ₂₃ 去 55?

```
δ_CKM = atan(ω₂₁/ω₉) = 66.399960° EXACT   (176 慣例)
       modes (21, 9) = N_gen×{L₄, N_gen} = 3×{7, 3}  ← 全部世代倍數

       modes (7, 6) = {L₄, 2N_gen}                    ← Lucas + 世代雙倍
```

**候選規則**:

## D. ★ INDEX vs ENERGY (🟡 → 候選 🟡)

**問題**: mode 選擇用 uniform level INDEX (k) 定 φ-hierarchy ENERGY (γ_k)?

```
γ_k = 4sin²(kπ/176) 非線性: γ₁ = 0.0013, γ₄₄ = 2, γ₈₈ = 4 (0→2→4 階梯)
```

**候選規則**: **INDEX 同 ENERGY 唔係競爭 — 分工**:
1. **邊界 (mode 選擇) 用 INDEX 對稱**: 邊界對 (43, 45) 以 k=44 對稱括住;

3. **喺 k=44 兩者重合**: k=44 同時係 INDEX 中心 (88/2) 同 ENERGY 特殊值
   (γ₄₄ = 2 = μ²) — 自對偶 mode = 稅/hold 規則嘅基礎。
