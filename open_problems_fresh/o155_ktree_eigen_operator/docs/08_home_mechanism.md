## §3 ★ 兩規則等價 ⟺ leg ratio 4:3 (結構強制)

```
(2N_d − K_tree)² = K_tree² + N_d²
⟺ 4N_d² − 4N_dK_tree + K_tree² = K_tree² + N_d²
⟺ 3N_d² = 4N_dK_tree
⟺ 3N_d = 4K_tree
⟺ N_d/K_tree = 4/3 = B/N_gen
```

**一般定理**: 對 Pythagorean triple (a,b,c): chain-complement `2b−a = c` ⟺ b/a = 4/3
⟺ (a,b,c) = (3,4,5)·k。反例 (5,12,13): 2·12−5 = 19 ≠ 13;正例 (3,4,5): 2·4−3 = 5 ✓。

⇒ home 嘅兩讀法 (加法閉合 / 乘法閉合) 重合, 係 **(3,4,5) 腿比 3:4** 嘅特殊性質 —
維度比身份 (ktree_structure S1: 4M = 3N_d) 已閉合 ⇒ **home 由結構強制, 唔係後驗**。
