> **狀態**: 🟢 形式化 (兩通道 = 同一 datum 兩種表示) / 🔴 通道↔表示分配規則 /

## §1 問題

點解角度通道 `atan(β)+atan(1/33)` 相加、振幅通道 `ε·32/33` 相乘?

## §2 形式化: 同一 co-closure datum 嘅兩種表示

P_B+P_I = I₃₃ 產生 (p_B, p_I) = (1/33, 32/33) (⟨ψ₀|·|ψ₀⟩ 零模機率, R2)。

密度 p ∈ (0,1) 有兩種自然表示, 各自閉合於一個對合 (involution):

| 表示 | 映射 | 閉合 | 對合 |
|:-----|:-----|:-----|:-----|
| **odds-angle** | θ(p) = atan(p) | `atan(p)+atan(1/p) = π/2` | inversion p ↔ 1/p |
| **measure** | a(p) = p | `p + (1−p) = 1` | complement p ↔ 1−p |

⇒ **角度通道用 odds-angle (SO(2) 群律: 角度相加 = 矩陣相乘);
振幅通道用 measure (概率律: 互補相乘)**。

## §3 驗證

| 檢查 | 結果 |
|:-----|:-----|
| p_B = 1/33, p_I = 32/33, p_B+p_I = 1 | 🟢 (R2) |
| atan(p)+atan(1/p) = 90° (p ∈ {1/33,1/44,1/11}) | 🟢 |
| tan(atanβ+atan p_B) = (K_tree+φ)/(K_tree·φ−1) | 🟢 (1e-40) |
| R(atanβ+atan p_B) = R(atanβ)·R(atan p_B) 矩陣精確 | 🟢 (1e-16) |
| sinθ₁₃ = ε·(1−p_B) = ε·32/33 = 0.14982642 | 🟢 |
| 兩通道只用 (p_B, p_I, ε, β) — 零新參數 | 🟢 |

## §4 ★ n=33 雙通道唯一性 — 降級 (blind-test 失敗)

**原聲稱** (R5 doc): 「null: n=33 雙通道唯一」。

**問題**: 唯一性嘅 target (θ₁₂ = 33.4602°, sinθ₁₃ = 0.14982642) **本身由 n=33 定義** —
循環論證。

**Blind-test** (對觀測 NuFIT5.2 target: θ₁₂ = 33.41°±0.72, θ₁₃ = 8.54° → sinθ₁₃ = 0.1485):

```
聯合偏差排名: n=34 最優 (輕微), n=33 次優 — 簡併度 1.01× (冇唯一性)
```

⇒ **33/34 對觀測數據完全簡併** — 「n=33 雙通道唯一」**降級 🔴**。
θ₁₂(33) = 33.4532° 同 θ₁₂(34) = 33.40° 都喺 NuFIT 1σ 內 (33.41±0.72), 無法區分。
