# O155 docs/05 — R5: channel 對偶算子表述 (scripts/07, 9/9 PASS)

> **日期**: 2026-09-07
> **問題**: θ₁₂ = atan(β)+atan(Tr(P_B)/K_tree) (角度通道, 相加) / sinθ₁₃ = ε·Tr(P_I)/K_tree (振幅通道, 相乘); channel 對偶 🔴

## §1 角度通道 (相加) — 精確

```
θ₁₂ = atan(β) + atan(1/33) = atan(β) + atan(⟨ψ₀|P_B|ψ₀⟩)
    = atan((K_tree+φ)/(K_tree·φ−1))          (1e-40 精確)
```

tan 加法精確形式:
```
tanθ₁₂ = (β + 1/33)/(1 − β/33) = (K_tree+φ)/(K_tree·φ−1) = 0.660711014930763
```
β = 1/φ, p_B = 1/33: tan(atanβ + atan p_B) = (β+p_B)/(1−β·p_B)。

旋轉算子合成 (C5): R(atanβ + atan p_B) = R(atanβ)·R(atan p_B) — SO(2) 矩陣精確。
**角度通道 = 兩次旋轉合成**: tree 基本角 atan(β) 再轉邊界角 atan(1/33)。

## §2 振幅通道 (相乘) — 精確

```
sinθ₁₃ = ε·Tr(P_I)/K_tree = ε·32/33 = ε·⟨ψ₀|P_I|ψ₀⟩ = 0.149826
NuFIT sinθ₁₃ = 0.14900 → Δ = 0.55%
裸 ε = 0.154508 (3.70% off) → 32/33 修正改善 6.6×
```

## §3 ★ Co-closure 同源 (統一算子陳述)

兩個通道都係**同一個零模 ψ₀ 嘅 projector 期望值** (docs/02):

```
角度通道:  修正 = atan(⟨ψ₀|P_B|ψ₀⟩) = atan(1/33)     邊界密度, 相加
振幅通道:  sinθ₁₃ = ε·⟨ψ₀|P_I|ψ₀⟩ = ε·32/33          內部密度, 相乘
同源:      p_B + p_I = 1   ← P_B + P_I = I₃₃ 嘅 resolution of identity
```

即: **同一組 projector (P_B, P_I) 喺同一態 (ψ₀) 嘅期望值, 一個進入角度通道 (atan 加法),
一個進入振幅通道 (乘法)** — co-closure 嘅算子機制 = resolution of identity
將 unity 分成 p_B + p_I = 1, 兩邊各自進入一個 channel。

## §4 Null 對照 (雙通道共同匹配)

n=30..36 掃描: 雙通道總殘差最細 = n=33 (Δθ₁₂=0.0070°, Δsinθ₁₃=0.55%),
次佳 n=32 — 1/33 喺雙通道同時唯一 (C7)。
