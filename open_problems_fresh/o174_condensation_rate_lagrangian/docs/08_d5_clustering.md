## 1. 場論鏈 (用戶鐵律: L → 路徑積分 → 相關子)

```
S_ℓ = Σ_{n=1}^{N_ℓ} (γ_n + μ²)|Φ_n|²          (O174 docs/03 層級作用量)
G(n) = 1/(γ_n + μ²)                            (模態空間傳播子)
ξ(r) = Σ_n G(n)·e^{ik_n r}                     (實空間 2-點函數)
ξ ~ 1/γ_1                                      (n=1 低能模長距離主導)
```

## 2. 結果

- **傳播子次序**: G(n=1) ≈ 0.4987 > G(中心) = 1/4 > G(Nyquist) = 1/6
  — 低能模 (n=1) 長距離主導; 中心模 (n=N_ℓ/2) 係**凝聚模** (A=0 零成本,
  O174 docs/03), 唔係最大 G
- **相關長度 ξ(ℓ) = 1/γ_1(ℓ)**: 196.2 → 3138.6 → 5.02e4 → 8.03e5 → ... (格單位)
  **單調增長** — 層級越高 (z 越大), 相關長度越大
- **可證偽預言 (C6)**: ξ 隨 z 增長 (1+z = 4^ℓ), ξ(ℓ=3)/ξ(ℓ=0) = 4094 —
  vs ΛCDM z 演化弱 (LRD r0 = 3.4-4.5 h⁻¹Mpc, Zhang+26 冇強 z 趨勢)
