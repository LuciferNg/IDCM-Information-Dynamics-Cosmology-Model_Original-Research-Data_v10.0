## 2. BHMF 鏈

```
Φ_BH(M, z) = Σ_ℓ 4^{−ℓ} · P(M; ℓ)          (事件率 4^{−ℓ}, O174 閉合)
P(M; ℓ) = P(δ̂) · |dδ̂/dM|                  (質量變換)
M(δ̂) = M_base·(1+δ̂)^{3/2} = 1.914e6·(1+δ̂)^{3/2}   (O173 docs/06)
```

**種子質量範圍**: δ̂ ∈ [−1,1] ⟹ M ∈ [0, 2^{3/2}·M_base] = [0, 5.41e6] M☉。
高端 (M > 1.5·M_base) 佔比 36/88 = 40.9%。

**★ 高端形狀預言 (C5)**: 
```
P(M) ∝ (1 − (M/M_base)^{2/3})^{−1/2}    (arcsine 奇異尾, 冪律)
```
**冇 Schechter 指數截斷** — 對比 ΛCDM BHMF (Schechter-like), 可證偽。
**層級權重**: 4^{−ℓ} = 1, 1/4, 1/16, 1/64 — 低 ℓ 主導 (z 低端種子多)。
