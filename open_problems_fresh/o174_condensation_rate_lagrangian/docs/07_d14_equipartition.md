## 1. 問題

## 2. 攻堅結果 — 三重獨立路徑

### 路徑 A: 熱均分 (Gaussian 積分, 經典極限)
自由場作用量 S = Σ(γ_n+μ²)|Φ_n|² 對角化後模態獨立, 配分函數
Z = Π_n π/(γ_n+μ²), 每個模態 ⟨|Φ_n|²⟩ = 1/(γ_n+μ²) (經典 Gaussian 均分)。
求和 Σ_n 1/(γ_n+μ²): l=0 → 12.535, l=1 → 50.640, l=2 → 203.061。

### 路徑 B: 最大熵分配 (Jaynes)
電荷 Q = 44 分配到 N_l 模態, 最大熵分配 = 均分:
```
S_assign = -Σ(q_n/Q)·ln(q_n/Q)  最大化 ⟹ q_n = Q/N_l (等份)
S_max = ln(N_l):  l=0 → 3.784, l=1 → 5.170, l=2 → 6.557
```
守恆核對: Σ q_n = Q = 44 (全 l 精確)。對照集中分配 (q_n = Qδ_n0): S = 0 < ln(N_l)。

### 路徑 C: 譜對稱 ⟹ 均分唯一
γ_n = 4sin²(πn/(2N_l)) 滿足 **γ_n = γ_{2N_l−n}** (sin²(π−x) = sin²x),
全層級 l=0..3 精確 (10^-25 內)。鏡像對稱 ⟹ 冇偏好模 ⟹ 唯一「無偏好」分配 = 均分。

## 3. 誠實審計 — 公設降級, 未完全量子化

| 路徑 | 帶入嘅公設 | 狀態 |
|:-----|:-----------|:----:|
| A 熱均分 | 經典極限 + 模態獨立 (已喺 S_ℓ) | ✅ 無新公設 |
| B 最大熵 | **Jaynes 等先驗 (indifference principle)** | ⚠️ 仍係公設 (但係資訊論最小公設) |
| C 譜對稱 | 鏈反射對稱 (數學恆等) | ✅ 無新公設 |

**結論**: 「D-D 腔物理均勻性」公設 → 降級為「Jaynes 等先驗」(indifference),
即由**物理公設**收窄到**資訊論最小公設**。均分喺「無偏好」假設下係唯一分配,
但「點解大自然冇偏好」仍然係一層假設。

**剩餘 (🔴 完全量子化)**: 由 O161 譜流通量 J_k 微觀定義出發,
證 Q = Σ_k J_k 嘅模態分解本身均勻 — 需要 J_k 嘅微觀動力學 (未有)。
