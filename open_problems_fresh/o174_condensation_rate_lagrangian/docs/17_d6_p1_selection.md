**結果** (ln Ψ vs ln(1+z) 斜率):

| logM | 斜率 | R² |

**判定**:
- ★ 高端 (logM 9.2+9.6 平均): b = **−0.72**, 命中 P1′ 預言 −1.00 ± 0.2 ✅
- ★ 冇反彈 (b < 0, 數密度隨 z 降) ✅
- ⚠️ 誠實: logM 9.6/10.0 正斜率係 **LBQS 光度選擇假象** (高 z 只睇到亮源 → 假高端上升, 標準 cosmic downsizing 效應)
- ⚠️ 誠實: LBQS 係光度限制樣本 (非 O173 P1′ 定義嘅 mass-complete), Ψ 係空間密度 (非後代/事件數)
  → **P1 初步 PASS (冇反彈), 正式判定等 mass-complete 樣本** (O173 P1′ 操作定義)

## 項 2: 選擇函數相容性 (D6-F1)

**關鍵結果**:
- 種子譜 P(>8) = 7.85% vs 觀測 5/69 = 7.25%: 差 0.6pp = **0.19σ (Poisson)** — 完全統計內 ✅
- 固定增長核 23.4% 已證偽 (docs/15) — 種子譜本身 (未增長) 直接命中觀測高端
- **選擇效應方向**: AGN 光度 ∝ M_BH → 高端易見 → 觀測應 > 種子譜; 但實測 7.25% < 7.85% (0.19σ, 統計內) → **選擇效應弱 或 樣本細未能分辨**
- ★ **s 結構值受壓檢驗**: 要 P(>8)=7.25% 需 s = 1.219 vs 結構值 s = 1.1874 → **dev 2.7%** — 結構 s 與觀測高端密度相容

**誠實詮釋**: 「種子譜 = 未增長種子」模型直接命中觀測高端密度 (0.2σ), 而「固定增長核」被證偽 (5σ+) → **觀測更似反映種子譜本身**, 支持 LRD = 早期種子 (docs/15 可證偽判別嘅種子側)。
