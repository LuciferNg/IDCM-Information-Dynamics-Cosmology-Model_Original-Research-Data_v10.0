## 三、方法論：為何呢個判決唔係「事後貶低」

1. **對照源係 v10.0 已閉合 O** (O37/O39/O148/O166/O204/O211), 唔係本 O 自己重算 — 非循環。
2. **ε / Ω_Λ 用 EXACT 恆等式證明** (scripts/03): v9.0 φ 形 = 精確式嘅 Lucas 尾截斷,
   dev < 1e-47 — 呢個係結構關係, 唔係數值巧合。

   符合用戶鐵律「φ-陷阱窗內一律唔閉合」。
4. **O208 密度基準**: 本判決唔做「數值匹配」聲稱, 只做「已知精確式 vs 舊近似」對照,
   故唔需 N_search/q_obs (純對照); ε/Ω_Λ 尾截斷係 EXACT 恆等式 (N_search=1, 唯一候選)。
