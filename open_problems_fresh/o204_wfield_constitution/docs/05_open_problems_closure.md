## 一、U1 — 舊 v7.0 `wfield_equation` 身份識別

### 1.1 舊方程原文（IDCM-v7.0 `data/wfield_equation.en-US.md`）

```
離散方程:  Φ_i(t+1) − 2Φ_i(t) + Φ_i(t−1) = Σ_j K_ij Φ_j(t) − φΦ_i(t)
作用量:    S = Σ_i Σ_t [ Φ_i(t)Φ_i(t−1) − ½Σ_j Φ_i(t)K_ijΦ_j(t) + (φ/2)Φ_i(t)² ]
本徵方程:  Σ_j K_ij ψ_j = (φ − 4sin²(ω/2)) ψ_i
鏈譜:      γ_n = 4sin²(πn/(2N_d)),  n = 1..N_d/2
樹譜:      μ_m = φ^(N_d·L − m),     m = 0..N_d·L
連續極限:  S = ∫d⁴x √−g [ −½∂_μΦ∂^μΦ − (φ/2)Φ² − (ε/4)Φ⁴ ]
度規提議:  g_μν = ∂_μθ·∂_νθ      (θ = 場相位)
```

### 1.2 逐項比對

| 項 | 舊 v7.0 | 現代 O204/O34 | 判定 |
|---|---|---|---|
| 鏈譜公式 | `4sin²(πn/(2N_d))` | `4sin²(πn/88)` | **完全相同**（n=1..22，max dev = 0.0） |
| 模數 | `N_d/2 = 22` | `N_d = 44` | 比 = **μ² = 2 EXACT** |
| 二次項 | `+φ/2 = +0.80902 > 0` | `−μ² = −2 < 0` | **符號相反** ⟹ 舊無 SSB |
| 四次項 | `λ_old = ε/4 = 0.0386271` | `λ = 2/123 = 0.0162602` | 比 2.3756（非結構） |
| 樹譜 | `φ^(291.5−m)`，μ₀ = φ^291.5 ≈ 8.3e60 | K_tree = 33 節點，Σμ_tree = 66 | **不相容** |
| 場身份 | 單實純量，無 U(1)_W | 複純量，有 U(1)_W | **不同** |

### 1.3 不可重標度定理（U1-d）

設 `W = aΦ`，則舊勢 `+(φ/2)Φ² + (ε/4)Φ⁴` 與現代 `−μ²|W|² + λ|W|⁴` 相等要求

```
−μ² a² = +φ/2   ⟹   a² = (φ/2)/(−μ²) = −0.4045084972 < 0
```

**不存在實 `a`** ⟹ 舊、現代勢**不可能**由任何實場重標度相連。這是一個乾淨的代數否證，不是數值比較。

### 1.4 U1 裁決 🟡

> **舊方程 = 現代 W-field 嘅「對稱相（⟨W⟩ = 0）極限」，但樹扇區參數化已廢。**
>
> - **可識別**：鏈譜公式完全相同；模數差恰好 μ² 倍。
> - **唔可識別**：(i) 二次項符號相反（舊無 SSB，正是 2026-08-12 paradigm break 改掉嘅嘢）；
>   (ii) 樹譜不相容；(iii) 場身份唔同（實 vs 複）。
> - **副產物**：舊 §5.2 之 `g_μν = ∂_μθ∂_νθ` 秩 1 退化（det(g) = −8.35e-53 ⟹ 不可逆），數學上唔成立；但係 U5 之結構線索（見第三節）。
> - **陷阱記錄**：`ε = φ⁻¹/4 = 0.1545085` vs `19/123 = 0.1544715`，rel = 2.392e-4 **落陷阱窗** — 標為陷阱，唔宣稱。


### 2.3 變體 (d)：四階完備性反證（★ 核心論證）

⟹ **loop 必然破壞四階完備**。若 μ²/λ 係 loop 生成，則 η 應該 = 0 — 但 loop 必然給 η ≠ 0。

## 三、U3 — λ 機制：收緊為「λ = μ²/E_J」

### 3.1 非獨立性發現

```
λ = 1/⟨W⟩²  ⟺  μ² = 2λ⟨W⟩² = 2
```

**「λ = 凝聚倒數」唔係獨立機制** — 佢等價於 `μ² = 2`（P3 已答）。此為 U3 原始陳述之邏輯冗餘。

### 3.2 真正獨立內容

```
λ = μ² / L₁₀,   L₁₀ = N_gen(N_d − N_gen) = 3 × 41 = 123
```

`123` 四條等價身份（全 EXACT）：

- `N_gen(N_d − N_gen) = 3 × 41 = 123`
- `2N_d + K_tree + μ² = 88 + 33 + 2 = 123`
- `Σγ + K_tree = 90 + 33 = 123`
- Lucas `L₁₀ = 123`

### 3.3 ★ 新機制讀法

G7 裁決值 `E_J = 2⟨W⟩² = 123`（sine-Gordon 相位剛度），而 `Σγ + K_tree = 123`。兩者獨立表達式相符 ⟹

```
λ = μ² / E_J = (徑向質量²) / (相位剛度)
```

> **U3 由「λ = 凝聚倒數」收緊為「λ = μ²/E_J」** — 即四次自耦合 = 徑向（振幅）扇區之質量² 除以相位（Goldstone）扇區之剛度。這是一個**跨扇區關係**，比原始陳述有內容。
>
> **剩 🔴**：為何 `E_J = Σγ + K_tree`（為何相位剛度 = 鏈譜和 + 樹節點數）。

## 五、U5 — U(1)_W 起源 = 88-site 環之平移（旋轉）對稱

### 5.1 結構識別

```
平移算子本徵值 = e^{i2πk/88}（88 個）⟹ 生成群 = U(1)
均勻模 (k=0) 平移不變（本徵值 = 1）⟹ 對應 T1 零模
相位旋轉 α = 0.7 rad  ⟺  環平移 Δj = α·88/2π = 9.803944 格
```

**場相位 θ 與環座標 θ 係同一個 θ**（O86 環度規 `ds² = R_world²dθ² − dt²` 之 θ）。因此：

- `U(1)_W`（場相位旋轉）≅ `U(1)_translation`（環平移）
- Goldstone 常數模 ≅ 環零模（T1）
- `c = R_world·ω_ring` = **環自身速度**

### 5.2 U5 裁決 🟢

> **U(1)_W = 88-site 環嘅平移（旋轉）對稱 S¹。**
> 呢個係 O204 之前未導出嘅項（P1 只**假設** U(1)_W 存在）。現在有結構出處。
> **副產物**：舊 v7 `g_μν = ∂_μθ∂_νθ` 秩 1 退化唔可直接用，但**動機正確** — 相位 θ 確實係定義時空嘅座標。正確形式 = O86 環度規（`R_world²dθ² − dt²`），非相位梯度張量積。
