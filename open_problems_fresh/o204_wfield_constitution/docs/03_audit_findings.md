### 矛盾

| 出處 | 陳述 | 日期 |

| O122 `docs/03_derivation.md` §1 | 「m_h = m_δW = M₀/2 = 13.9505 MeV」 | 2026-09-03 |

### 代數裁決 (scripts/03 §B5, 4/4 PASS)

```
V(W) = −μ²|W|² + λ|W|⁴
V'(W)  = −2μ²W + 4λW³ = 0   ⟹  W₀² = μ²/(2λ) = 61.5
V''(W) = −2μ² + 12λW²
V''(W₀) = −2μ² + 12λ·(μ²/2λ) = −2μ² + 6μ² = 4μ² = 8     ★ EXACT
數值二階差分獨立確認 = 8.0

反證 2μ² = 4:
  需要 12λW² = 4μ² ⟹ W² = μ²/(3λ) = 41.0
  但 V' = 0 要求 W² = μ²/(2λ) = 61.5
  41.0 ≠ 61.5 ⟹ 同極小條件矛盾 ⟹ m_ρ² = 2μ² = 4 唔可能成立
```

### ★ 裁決

```
🟢 正確: V''(W₀) = 4μ² = 8  (O37/O80/O122 一致)
🔴 錯誤: O73 docs/15 §1 表之「m_ρ² = 2μ² = 4」
```

### 結構讀法 (本 O 新增)

```
m_ρ² = 4μ² = 2·γ_44 = 2·γ_max        (L2 無量綱制)
m_δW = M₀·γ_22/γ_44 = M₀/2           (L3 MeV 制, O37 一致)
⟹ 徑向質量 = 鏈譜嘅 Nyquist/自對偶值組合, 零新常數
```
