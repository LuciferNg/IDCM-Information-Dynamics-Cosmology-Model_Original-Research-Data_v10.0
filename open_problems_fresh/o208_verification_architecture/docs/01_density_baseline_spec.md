# O208 docs/01 — 密度基準規則 (Density Baseline Rule)

> **日期**: 2026-09-22
> **性質**: 驗證架構標準 — Phase 0 交付物 1
> **狀態**: 🟢 已定案（本 O 閉合後成為 v10/v11 通用標準）
> **來源**: O115 docs/02 §三 缺陷 3 + O136 docs/13（密度效應實測）

---

## 一、問題

IDCM 任何「數值匹配」都面對同一個統計學問題：

> **搜尋空間越大，隨機抽樣越容易命中任意目標值。**
> 匹配偏差 0.146% 睇落好靚，但若隨機中位偏差都係 0.176%，
> 呢個「閉合」統計上同隨機冇分別 —— 唔係結構，係密度效應。

實測證據（O136 docs/13）：

| 案例 | 觀測偏差 | 隨機中位偏差 | 分位數 | 判定 |
|:-----|:--------|:------------|:------|:-----|
| O34/O35 模式分配 | 0.146% | 0.176% | ~50% | 🔴 統計唔顯著 |
| O136 模式分配 | 0.015%+ | 0.000339% | 差於隨機 | 🔴 比隨機更差 |
| 組合空間（可匹配任意目標） | — | 0.0003% | — | 🔴 無判別力 |

**結論**: 冇密度基準嘅「閉合」= 未閉合。分位數係入場券。

---

## 二、規則（強制）

任何數值匹配（閉合聲稱 / 預言 / 公式推導 vs 觀測）**必須同時報告**：

1. **隨機搜尋空間大小** `N_search`
   - 定義: 該匹配允許嘅候選數（模式數 × 算子家族數 × 指數範圍 × 常數組合數）。
   - 目的: 量化「呢個數字有幾容易隨機撞中」。
   - 報法: `N_search = 2.4e5`（附構成式，例 `44×12×120×4`）。

2. **隨機中位偏差** `d_med`
   - 定義: 喺搜尋空間內隨機抽 `N_mc ≥ 10⁵` 個候選，計算匹配偏差，取中位數。
   - 目的: 提供「隨機撞中嘅典型偏差」基準線。
   - 報法: `d_med = 0.176%`（`N_mc = 1e6`）。

3. **觀測偏差分位數** `q_obs`
   - 定義: 觀測偏差喺隨機偏差分佈中嘅百分位。
   - 判定:
     - `q_obs ≤ 1%` → 🟢 統計顯著（超越 99% 隨機）
     - `1% < q_obs ≤ 5%` → 🟡 候選（需加強證據）
     - `q_obs > 5%` → 🔴 唔顯著（密度效應，唔准入帳）
   - 報法: `q_obs = 0.4%`（`d_obs = 0.146%` vs `d_med = 0.176%`）。

4. **MC 樣本數** `N_mc` + 種子 `seed`
   - 可重現性要求: 每個 MC 報告必須附種子，重跑結果一致。

---

## 三、報告格式（新 O 強制 — 寫入標準報告模板）

每個閉合聲稱（`final_result.md` / 閉合 doc / 驗證 script 輸出）必須包含以下區塊：

```
## 密度基準
- N_search = {值}（{構成式}）
- N_mc = {值}，seed = {值}
- d_obs = {值}（觀測偏差）
- d_med = {值}（隨機中位偏差）
- q_obs = {值} → 🟢/🟡/🔴
```

**冇分位數 = 未閉合。** 即使公式係純代數推導（冇搜尋），都要聲明 `N_search = 1`（唯一候選）先可以跳過 MC —— 但必須講明點解係唯一候選。

---

## 四、例外

| 情況 | 處理 |
|:-----|:-----|
| 純代數恆等式（`γ_n = 4sin²(πn/88)`） | `N_search = 1`，唔使 MC，但必須聲明 |
| 觀測量測量誤差內（`|obs−pred| < σ_obs`） | 報誤差 σ 替代分位數 |
| 盲測預言（預先註冊，未見目標） | 盲測本身係最強密度控制；仍需報 N_search |
| 因果鏈推導（每一步唯一） | `N_search = 1` per step，報步驟數 |
