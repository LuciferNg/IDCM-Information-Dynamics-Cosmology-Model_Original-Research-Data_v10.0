### 2. 本徵尺度 fit + 去卷積 (量綱修正)

**fit**: 高斯 dip 模型 (A=134.2 固定, 只 fit σ) → **σ_fit = 4.08°** (χ²=0.4)
**⚠️ σ_fit 係「4.17° 平滑核 + 冷斑本徵」嘅卷積結果, 唔係本徵!**

**去卷積** (高斯卷積: σ_fit² = σ_int² + σ_kernel²):
```
σ_kernel = 4.17/2.355 = 1.771°  (R8 平滑核)
σ_intrinsic = √(4.08² − 1.771²) = 3.676°
FWHM_intrinsic = 3.676 × 2.355 = 8.66°
```

### 3. 尺度閉合 (正確量綱)

| 來源 | 冷斑尺度 | 值 |
|:-----|:--------|:---|
| **本工作** | 本徵 FWHM (去卷積) | **8.66°** |
| **IDCM 2×R8** | 2 × 4.17° | **8.34°** |
| Planck 2013 | 直徑 | ~10° |
| Vielva 2004 | angular radius ~5° | 直徑 ~10° |

→ **冷斑本徵 FWHM 8.66° ≈ 2×R8 (8.34°), 偏差 3.7%**
→ vs Planck 2013 直徑 ~10°: 偏差 13% (文獻值誤差內)

### ⚠️ v1 量綱錯誤修正記錄 (2026-08-25)
v1 寫「σ=4.08° = R8 4.17° 偏差 2%」— **錯誤**:
- R8 = 4.17° 係 **FWHM** (O5 定義), 唔係 σ
- σ=4.08° (FWHM 9.61°) 同 R8 FWHM 4.17° 差 2.3 倍, 唔可以直接比
- 正確: 去卷積後本徵 FWHM 8.66° ≈ 2×R8 8.34° (偏差 3.7%)

## 物理詮釋

1. **冷斑本徵直徑 ≈ 8.7° ≈ 2×R8** — R8=4.17° 係冷斑半徑尺度嘅量度核
   (平滑核 σ 1.77° < 冷斑本徵 σ 3.68°, 核比物體細 → 平滑冇抹平結構)
2. 4.17° 平滑核捕捉到冷斑核心 (rank 1-2/60), 但本徵結構更闊
3. A₅ 節點間距 26.17° ≫ 冷斑直徑 8.7° — 冷斑係單節點結構 (節點 0)
4. SMHW 係數幅度 (31 μK) vs pixel 幅度 (134 μK) = filter 響應差異, 互補

## 方法論

- 超額譜 (減 60 節點 median) 係乾淨嘅冷斑 SMHW 響應
- 高斯 dip 模型 (A 固定) fit σ_fit=4.08°, 唔係 free fit (A 有 O41 閉合值)
- **必須去卷積先攞到本徵尺度** — 平滑核貢獻唔可以忽略
- 比率 0.76-0.85 (R=1-7) 穩定, R=10 邊界效應 1.32
