## 0. 問題

docs/01 §10 開放項: E₂ = μ²·(Δθ/σ)² 入面 σ = 觀測不確定度 (NuFIT σ_θ, PDG σ_δ)。
σ 有冇 176-Laplacian 譜 / 環拓撲身份?

## 1. 判決 (一句話)

**σ 冇譜身份 — Category-error 封頂 (O153 先例)**。σ 嘅量嘅類別 = 觀測統計量
(誤差傳播, 由實驗擬合精度決定), 唔係譜量 (γ_k 類)。要求實驗誤差有理論譜身份 =
要求理論決定實驗測量精度 — 類別唔同, 橋樑唔需要閉合。泛函嘅譜內容全喺 μ² (已閉合)。

## 2. 證據鏈 (19/19 PASS)

### S1. σ 係統計量: 誤差傳播, 上/下側唔對稱

```
NuFIT sin²θ₂₃ = 0.573 +0.016/−0.020 → σ_θ(up) = 0.016215 rad = 0.9290°
                                        σ_θ(dn) = 0.020162 rad = 1.1552°   (差 24%!)
PDG δ_CKM = 1.144 ± 0.027 rad        → σ_δ = 0.027000 rad = 1.5470°
```

σ_θ 上/下側差 24% — 誤差傳播嘅非線性 (dθ/d(sin²θ) = 1/(2sinθcosθ) 隨 θ 變)。
**譜量會對稱; 統計量唔對稱** — 呢個係 σ 非譜嘅第一特徵。

### S2. 結構候選掃描 (dev < 10% 窗, 74 候選族)

| target | 最佳候選 | dev | 家族 |
|:-------|:---------|:---:|:-----|
| σ_θ(up) = 0.016215 | 2/L₁₀ = 2/123 = 0.016260 | 0.28% | Lucas |
| σ_θ(dn) = 0.020162 | π/F₁₂ (8.2%) | — | 冇靚命中 |
| σ_δ = 0.027000 | 1/37 (0.10%), 2π/F₁₃ (0.12%) | 0.1% | 質數 / Fibonacci |

**上/下側唔一致**: σ_θ(up) 撞 2/L₁₀ (0.28%),σ_θ(dn) 完全冇靚命中 (8.2% 起)。
如果 σ 有譜身份,上/下側應該同時命中同一結構值 — 冇。

### S3. null-control: 密度假象 (致命)

隨機 σ ∈ [0.005, 0.05] rad (2000 trials, 每 trial 一 target),10% 容差內命中結構候選率
= **98.1%**。即係話: 任何 σ 值都幾乎必中 — 候選命中 (0.1-0.3%) 喺純密度背景內,
**冇鑑別力, 唔可以當結構證據**。 (O157 threshold-family null-control 同款: count 撞靚
factor 唔可以宣稱閉合。)

### S4. 鑑別力: σ 自身誤差窗

σ(sin²θ₂₃) 本身係統計量, 有自身不確定度 (~30-50%, NuFIT 誤差唔對稱 ±0.016/−0.020)。
保守取 10% 窗: 候選 dev (0.1-0.3%) << 10% — 任何 10% 內候選都「命中」,
要求理論閉合到 <0.1% 對統計量冇意義。

### S5. Category-error 封頂 (O153 先例)

O153 先例: kT ln2 vs E_min — 冇系綜 ⇒ T 未定義, 橋樑唔需要閉合。同類:
σ 係量測誤差 (統計量), 唔係譜量; E₂ 嘅譜內容全喺 μ² (λ₂ = γ₄₄ = 2, docs/01 已閉合)
— **E₂ 譜結構完整, 唔缺 σ**。

### S6. σ 嘅操作定義 (泛函內生角色) + 譜化替代品檢驗

- **操作定義**: Δθ = σ ⟺ E₂ = μ² = 2 — 1σ 偏差嘅能量成本 = 一個自對偶質量單位。
  泛函分工: μ² 定能量單位 (譜, 已閉合), σ 定角度刻度 (觀測) — 兩者結合先有意義。
- **譜化替代檢驗** (σ → π/N 環分辨率): δ 鑑別力從觀測 σ 版 15× **跌到 0.7×** —
  對調懲罰定理被破壞! θ₂₃ 鑑別力仍高 (15153×) 但 δ 死。
  ⇒ **σ 唔可以被任何單一譜尺度取代** — 佢嘅角色本質上係觀測刻度。
