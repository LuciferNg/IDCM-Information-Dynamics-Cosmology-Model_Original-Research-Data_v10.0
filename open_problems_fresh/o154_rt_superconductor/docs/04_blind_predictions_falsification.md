# O154 docs/04 — 盲測預言 + 證偽條件 (Blind Predictions & Falsification) 🔮

> 2026-09-06 | 狀態: 🔮 已註冊待驗 (2026-2028 實驗窗口)

## 核心原則

44-cell 匹配 LaH₁₀ 係 post-diction。真正嘅考驗係 blind test:
「無效才是正確」— 若盲測失敗, 證明 44-cell 係結構巧合, 框架冇弱。

## P1: YH₁₀ — 文獻已預測未合成嘅 Fm-3m 44-cell 氫化物

- 文獻 (Nature Comm 2021): YH₁₀ 預測 Tc = **305-326 K** (DFT + Eliashberg)
- IDCM 結構規則: YH₁₀ 必須係 Fm-3m Y₄H₄₀ (44-cell) 先符合 — 若合成出嚟係其他結構而 Tc > 200 K → 規則死
- IDCM Tc 定律: Tc = 0.2605 × Ω_log(YH₁₀)
  - Ω_log = 1300 K → Tc = **339 K** [315-358]
  - Ω_log = 1400 K → Tc = **365 K** [339-385]
  - 若文獻 305-326 K 屬實 → 反推 Ω_log(YH₁₀) = 1171-1251 K
- **盲測陳述**: 當 YH₁₀ 合成, 量度 Tc 必須滿足 Tc = 0.2605×Ω_log (Ω_log 由 DFT/非彈性散射獨立量度); λ ≈ 2.7 (±10%)

## P2: 44-cell 類擴展 — ThH₁₀, AcH₁₀, HfH₁₀

- 2025 review 已預測 XH₁₀ (X = Th, Ac, Hf, ...) 存在
- IDCM: 任何穩定 Fm-3m X₄H₄₀ (32f+8c H, H₃₂ 籠) 都係高溫超導, Tc = 0.2605×Ω_log
- (La,Y)H₁₀ 固溶體: Tc 由 ω_log 內插 — 調律者機制: 用固溶體「調律」Ω_log 到 300 K 目標
- **證偽條件**: 存在 Fm-3m X₄H₄₀ 而 Tc < 150 K → 44-cell 規則死

## P3: 同位素效應

- 鏈 = 諧波 → α = −dlnTc/dlnM = **0.5** (BCS 值), 非諧波修正小
- LaD₁₀ 預言: Tc ≈ 250/√2 ≈ **177 K**
- 可證偽: 若 α << 0.5 (強非諧波/電子機制) → 聲子介導假設死

## P4: 間隙比 2Δ/kTc = 4.86 (±0.04, μ* 穩健)

- 對比: BCS 3.53, MgB₂ ~4, 氫化物量度 4.9-5.6, cuprates (d-wave) 5-8
- 可證偽: 若 YH₁₀ 量度 2Δ/kTc < 4.5 → R3 死 (比 BCS 差距細於 1σ 都死)

## P5: s-wave 對稱性

- Z₂ parity → s-wave singlet (docs/01)
- 可證偽: 節線/節點間隙 (d-wave, p-wave) → 配對扇區定理死

## P6: 結構穩定壓力

- IDCM N_crit = 150 (無量綱數值 = Σγ_even×F₅/N_gen = 90×5/3, O153 R5 候選) 同 Fm-3m 穩定化壓力 130-170 GPa 量級一致 (🟡 觀察, 非推導)
- 預言: 其他 44-cell 氫化物 (YH₁₀, ThH₁₀) 穩定化壓力 ≈ 130-170 GPa 區間

## 誠實負面清單 (🔴)

1. 🔴 IDCM 唔預測 Ω_log (需要 DFT/實驗材料輸入) — Tc 定律係比例律
2. 🔴 λ = 8/3 推導鏈未閉合 (C_obs/M 係候選閱讀)
3. 🔴 44-cell 規則冇解釋點解 X 要係三價稀土/錒系 (電子結構角色 — fcc 4a + H 電荷轉移)
4. 🔴 μ* 自由參數 (0.10-0.16)
5. 🟡 Tc(LaH₁₀) 高估 16% — 非諧波/雙間隙修正未建模
6. 🟡 壓力「150 GPa」只係量級觀察, 唔係推導
