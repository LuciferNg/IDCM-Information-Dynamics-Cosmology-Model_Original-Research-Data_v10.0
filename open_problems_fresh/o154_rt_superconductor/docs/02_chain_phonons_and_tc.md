## 4. Eliashberg 求解 (S03)

方程 (Marsiglio 摺疊形式, m∈ℤ → m≥0, renormalized ω̂/Δ̂):
```
ω̂_n = ω_n + πT Σ_m (ω̂_m/D_m)[λ(n−m) − λ(n+m+1)]
Δ̂_n = πT Σ_m (Δ̂_m/D_m)[λ(n−m) + λ(n+m+1) − 2μ*]
D_m = √(ω̂_m² + Δ̂_m²),  λ(k) = 2Σ_i α²F_i Ω_i/(Ω_i² + (2πTk)²)
```
⚠️ 重要 pitfall (本 session 捉到): 用錯未 renormalized 形式 + 冇 sgn 摺疊 → Z₀ ≈ 32 (錯) vs 正確 Z₀ = 1+λ = 3.67。sgn 加權令 Σλ(n−m)sgn(ω_m) = λ(0) 精確。
