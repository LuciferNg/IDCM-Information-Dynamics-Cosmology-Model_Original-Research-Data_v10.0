Abstract
Projective two-weight linear codes are closely related to finite projective spaces and strongly regular graphs. In this
paper, a family of q-ary projective two-weight linear codes is presented, where q is a power of 2. The parameters of
both the codes and their duals are excellent. As applications, the codes are used to derive strongly regular graphs with
new parameters and secret sharing schemes with interesting access structures.
Keywords: Linear code, strongly regular graph, secret sharing schemes
2000 MSC: 94B05, 05E30, 15A03

1. Introduction
An [n, k, d] linear code C of length n over Fq is a k-dimensional linear subspace of Fnq with minimal Hamming
distance d, where Fq denotes the finite field with q elements for a prime power q. There exist some bounds on the
parameters n, k, d [13]. An [n, k, d] code is called (distance) optimal if no [n, k, d + 1] codes exists. An [n, k, d − 1]
code iscalled almost (distance) optimal if [n, k, d] code is optimal. The dual code C ⊥ of a linear code C is defined as
C ⊥ = c⊥ ∈ Fnq : hc⊥ , ci = 0 ∀ c ∈ C . Clearly, the dimension of C ⊥ is n − k if C has dimension k. A linear code C is
said to be projective if the minimal distance of its dual is at least 3.
Let Ai denote the number of codewords with weight i in a code C of length n. The sequence (1, A1 , A2 , · · · , An ) is
called the weight distribution of C and the polynomial 1 + A1 z + A2 z2 + · · · + An zn is called the weight enumerator of
C . Denote by t = ♯{Ai : Ai > 0, 1 ≤ i ≤ n}. Then a code with weight distribution (1, A1 , A2 , · · · , An ) is called a t-weight
code. Weight distribution is an interesting research subject in coding theory as it not only contains the information
of the capabilities of error detection and correction, but also allows the computation of the error probability of error
detection and correction of a given code. Many linear codes with only a few weights were reported in the literature
[1, 3, 4, 5, 6, 8, 14, 15, 16, 17, 18, 19, 20]. In particular, projective two-weight codes are very precious as they
are closely related to finite projective spaces, strongly regular graphs and combinatorial designs [1, 2, 5]. However,
projective two-weight codes are rare and only a few families are known [1, 3, 9].

two-weight codes. As another application, all codes obtained in this paper can be used to construct secret sharing

4. Strongly regular graphs with new parameters
A connected graph of N vertices is called strongly regular with parameters (N, K, λ, µ) if it is regular with valency
K and if the number of vertices joined to two given vertices is λ or µ according as the two given vertices are adjacent
or non-adjacent.
Let G = [y1 , y2 , · · · , yn ] be the generator matrix of a [n, k] linear code C over Fq , where yi ∈ Fkq . Let V = Fkq ,
O = {hyi i : i = 1, 2, · · · , n} and Ω = {v ∈ V : hvi ∈ O}. Define a graph G(Ω) with vertices the vectors of V and where
two vertices are joint if and only if their difference is in Ω. In [1, Th. 3.2], it was proved that G(Ω) is strongly regular
if and only if C is a projective two-weight code. Assume that the nonzero weights of C are w1 and w2 . By [1, Coro.
3.7], the parameters of G(Ω) are
N = qk , K = n(q − 1), λ = K 2 + 3K − q(w1 + w2 ) − Kq(w1 + w2 ) + q2w1 w2 , µ = K 2 + K − Kq(w1 + w2 ) + q2w1 w2 .

5. Summary and concluding remarks

The contributions of this paper are summarized as follows:
• If m = 2s, the weight distribution of CD was determined in Theorem 7 for any prime power q and any c ∈ Fq ;
• The parameters of the dual of CD was also determined in Theorem 8;
• By Theorems 7 and 8, CD is a projective two-weight code if q is even and c ∈ F∗q . This class of projective
two-weight codes yield strongly regular graphs with new parameters in Section 4.
It is easy to prove that CD in Theorem 7 is minimal for s ≥ 3 as wmin /wmax > q−1
q [18, Lemma 3], where wmin , wmax
denote the maximum and minimum weights of CD , respectively. Hence the code CD in Theorem 7 can also be used
to construct secret sharing schemes with interesting access structures [18]. As another application, the projective
two-weight code CD for even q and c ∈ F∗q holds 1-design by the well-known Assmus-Mattson theorem [2].
