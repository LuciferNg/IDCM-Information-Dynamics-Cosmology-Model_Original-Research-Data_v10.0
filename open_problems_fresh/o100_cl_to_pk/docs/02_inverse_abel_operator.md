## 2. 算符定義 (ℳ)

```
輸入:  C_ℓ(ℓ_m) = D₁·A_m·2π/[ℓ_m(ℓ_m+1)]     (D₁ = 5750 μK², Planck TT 峰1)
       A_m = 母函數 (O83 閉合, 零自由參數):
             偶峰 m=2k: A = ((k+1)/(4k−1))²
             奇峰:      A₃=4/9, A₅=3/14, A₇=1/7 (m≥9: 地板 1/16, 延伸標記)
轉換:  ⟨(δT/T)²⟩_m = C_ℓ(ℓ_m)·(2ℓ_m+1)/(4π·T_cmb²)
       δ/(δT/T) = 2(k/k_H)² = 2ℓ_m²      ← SW: δT/T=−Φ/3; Poisson: δ=−(2/3)(k/aH)²Φ
                                              IDCM: a≡1, H≡H₀ (靜態無膨脹) → aH = H₀ = 1/R_world
                                              χ*=R_world ⇒ k/k_H = ℓ_m (docs/01, dev=0)
輸出:  Δ²(k_m) = [2ℓ_m²]²·⟨(δT/T)²⟩_m      (線譜每模方差)
       P(k_m) = 2π²·Δ²(k_m)/k_m³           [Mpc³]
       k_m     = ℓ_m/R_world               [Mpc⁻¹]
```

## 4. 結構解讀

- **Δ²(k) 峰值 ~1.2 喺 k~0.5 h/Mpc** — IDCM 物質功率譜線譜在 σ_8 窗 (k 0.1–0.4) 內有 4 條強線 (m=2..5), 呢個先係 σ_8 能閉合嘅原因
- **逐線對照 BOSS**: 只有 m=1 (k=0.079) 落入 BOSS 範圍 [0.016, 0.145], Δ²_ID = 0.033 vs Δ²_BOSS = 0.457 (比 0.072) — BOSS 星系 P 含 bias b²~4-14, 唔可以直接比; 平滑形狀比受邊緣效應污染 (詳見 docs/03 §4)
- **χ=πR_world 變體**: σ² 係 R_world 嘅 π⁻⁴ = 0.0103 倍 (純幾何敏感度, 已記錄)
