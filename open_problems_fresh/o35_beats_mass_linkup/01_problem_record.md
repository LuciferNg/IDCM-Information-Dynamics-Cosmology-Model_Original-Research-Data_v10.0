## 推導鏈 link-up 三步

### Step 1：拍頻公式（K_Chain 內稟結構）

兩個模態 n, m 嘅拍頻：

```
ω_n − ω_m = 2sin(nπ/88) − 2sin(mπ/88)
          = 4·cos((n+m)π/176)·sin((n−m)π/176)   ← 和差化積
```

**關鍵：** 拍頻係 cos×sin 形式 — 三角函數唔係人為選擇，而係正弦模態相減嘅和差化積必然結果。

### Step 2：振幅比 = sin 比值（link-up 核心）

質量譜 m_n ∝ sin(nπ/88)（O34 已閉合）⇒ 質量比：

```
m_{n1}/m_{n2} = sin(n1π/88) / sin(n2π/88)
```

**Link-up 假設（本 session 驗證）：** 質量比 = 模態振幅比 = sin 比值，
而模態振幅由拍頻結構決定（共振響應 ∝ 模態正弦）。

### Step 3：tan/cos 形式（本 session 新推導）

由 sin 比值經三角恆等式可得等價 tan/cos 形式：

```
sin(A)/sin(B) = 1/[sin(B)/sin(A)]  (倒數對稱)
             = cos(B/2)·tan(...)...   (恆等式變換)
```

驗證目標：確認 tan/cos 形式係 sin 比值嘅**恆等變換**（唔係新自由參數），
並檢查有冇任何質量比需要真正獨立嘅 tan/cos 表達（O34 未覆蓋）。
