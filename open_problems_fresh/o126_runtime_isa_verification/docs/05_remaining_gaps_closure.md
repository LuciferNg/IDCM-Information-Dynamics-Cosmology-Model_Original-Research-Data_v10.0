## 二、§A — Gap 4: CIP 4×2 分解唯一性: 🟡 → **🟢**

### 問題 (docs/04 §五)
v9.0 CIP 8 = 4×2 (4 相 × 2 模); v10.0 只證到 8 = 2B, 但「4×2 分解唔唯一」(≥3 個獨立來源)。

### 攻堅: 分清「值歧義」vs「名歧義」

| 候選 | 值 | 備註 |
|:-----|:--:|:-----|
| 「4」= B (φ³−φ⁻³) | 4 | K_tree 分支 (代數) |
| 「4」= L₃ | 4 | Lucas (φ-Lucas 對偶 n=3) |
| 「4」= mod-4 扇區 | 4 | 巢狀 (見下) |
| 「2」= μ² | 2 | SYNC 成本 |
| 「2」= L₀ | 2 | Lucas |
| 「2」= op types | 2 | read/write |

**關鍵**: 三個「4」候選**全部 = 4**; 三個「2」候選**全部 = 2**。
⟹ 「≥3 個獨立來源」係**名多值一** (label multiplicity), **唔係值歧義**。

### 由循環強迫「2」⟹ 4 = B 被迫
1. 循環 = 88 ops = 44 reads + 44 writes ⟹ 恰好 **2 種 op 類型** (docs/04 §十, 強迫);
2. 每 op = 2 模式單位 (176 = B·N_d) ⟹ 「2」= μ² 被循環定死;
3. 8 = 2B ⟹ **4 = 8/2 = B 被迫** (唯一分解, 非選擇)。

### 獨立交叉身份 (非數值)
- **8 = #{gcd(|44−n|, 176)}** = 44 模態譜嘅**相異 gcd 類數** = {1,2,4,8,11,16,22,176} (8 類);
- 伴隨: **相異代數次數 = 7 = L₄** (8 類中 g=8,16 同 deg=5) — `kchain_number_field/16`;
- 兩獨立身份一致: 8 = 2B = 譜 gcd 類數。

### 排除 mod-4
mod-4 扇區 {0,1,2,3} **細化**宇稱 ({0,2}/{1,3}), 即巢狀 — **唔係獨立因子** (docs/04 §十已記)。

### 裁決
🟢 **8 = B·μ² 係唯一結構分解**。8 = 2B 成立, 「2」由循環強迫 ⟹ 「4」= B 被迫;
