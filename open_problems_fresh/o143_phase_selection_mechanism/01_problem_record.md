## 問題陳述

O52 否定咗「全部 60 節點有異常」假說，只剩下 node0/node9 同 ΔE=0 12 節點子集有異常。O52 NN_results.md 記錄咗一個現象學描述：

> δT_i = A·cos(θ_i)，大部分節點 θ_i ≈ π/2 正交 → δT ≈ 0

**但呢個係現象描述，唔係結構推導。** θ_i 目前係自由參數，可以擬合任何數據。

### 結構推導目標

將 θ_i 從自由擬合參數升格為**88-site 雙鏈環幾何嘅拓撲鎖定相位**：

```
θ_i^ind = f( n_i, Topology_88 )
```

其中 n_i 係第 i 個 CMB 採樣節點嘅天球座標，Topology_88 係 88-site 對偶鏈嘅拓撲結構。

## 4 步算子化推導框架

### 步驟 1：建立雙鏈環到 2D 天球嘅拓撲映射算子 𝒫

**目標**: 構造投影算子 𝒫: ℋ₈₈ → L²(S²)，將 88-site 1D 離散環嘅相位場映射到 2D 天球 CMB 觀察面。

**88-site 環座標**:
- site k: x_k = 2πk/88, k = 0, 1, ..., 87
- 偶數 k = 2n: 世界模式 (γ_{2n} = γ_n^(44))
- 奇數 k = 2n-1: 觀察者模式 (γ_{2n-1} = γ_{n+0.5})

**60 節點天球座標**:
- n_i = (θ_i^sky, φ_i^sky), i = 0, 1, ..., 59
- 由 A₅ 二十面體頂點+面心決定 (Rhombicosidodecahedron)

**幾何約束 (O34)**:
- 未投影弧長比例: 41/60
- 投影弧長比例: 19/60
- 總弧長: 41 + 19 = 60 = 60 節點數

### 步驟 2：求解 T_pipe 算子嘅本徵相位態

**目標**: T_pipe 係 88-site 管道轉移算子，其本徵態展開決定相位場：

```
T_pipe |ψ_m⟩ = λ_m |ψ_m⟩
Φ_m(x_k) = A_m cos(k·ω_m + θ_0^(m))
```

**週期性邊界條件**: Φ_m(x_k + 88) = Φ_m(x_k) → ω_m = 2πm/88 = πm/44

**拓撲相角 θ_0^(m)**: 由 88-site 雙鏈嘅奇偶不對稱性決定：
- 偶數鏈 Σγ_even = 90 (世界)
- 奇數鏈 Σγ_odd = 88 (觀察者)
- 差 = 2 = B/2 (B = 4 = K_Tree 分支)

### 步驟 3：計算 60 節點嘅誘導相因子 θ_i^ind

**目標**: 將 T_pipe 嘅基態投影到 60 個採樣點：

```
δT(n_i) = ⟨n_i|𝒫|ψ_vac⟩ = A·cos(θ_i^ind)
```

其中 θ_i^ind = 𝒫(Φ_base(x_k)) 由節點 i 喺 88-site 環上嘅相對位置決定。

### 步驟 4：導出節點分化嘅結構判據

**目標**: 解析 θ_i^ind 分佈，解開 node0/node9 之謎：

| 節點類型 | 預測 θ_i^ind | cos(θ_i^ind) | CMB 表現 |
|:--------:|:------------:|:------------:|:---------:|
| 普通節點 (48/60) | ≈ π/2 或 3π/2 | → 0 | |z| < 0.4σ |
| Node0 (冷斑) | ≈ π | → -1 | −134.2 μK |
| Node9 (第二冷) | ≈ π | → -1 | −107 μK |
| ΔE=0 節點 (12) | ≈ π/2 (正交) | → 0 | mean|T| ≈ 19 μK |
