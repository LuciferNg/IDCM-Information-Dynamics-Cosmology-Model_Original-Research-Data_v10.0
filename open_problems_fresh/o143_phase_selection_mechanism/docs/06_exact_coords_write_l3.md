## 4. 🟢 k 分層身份 — 結構鏈由面數強制 (`scripts/22` §D)

```
幾何事實: 20 三角形 + 30 正方形 + 12 五邊形 (Rhombicosidodecahedron)
  → 每奇面 1 條阻挫邊 ⟹ #ST (Δ-□) = 20, #PS (⬠-□) = 12
  → k=2 = PS端點 ∩ ST端點 = 12; k=1 = 對稱差 = 40; k=0 = 補集 = 8
```

**判定**: 8/40/12 由**面數 (20Δ, 12⬠)** 唯一強制, 唔係數值巧合。
數值身份 (8 = F₆ = 2B = dim SU(3); 12 = B·N_gen = L₅+1) 係**候選**, 非推導。
