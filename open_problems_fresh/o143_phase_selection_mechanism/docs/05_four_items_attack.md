## 4. k 分層數值身份 — 🟢 結構鏈精確 (數值身份候選)

**結構鏈 (非 numerological, 30/30 著色成立, docs/04 §2)**:
```
32 阻挫邊 = 20 (Δ-□) + 12 (⬠-□)      [每奇面啱啱 1 條]
  → 端點 (k=1) = 2 × 20 = 40
  → 連接器 (k=2) = PS端點 ∩ ST端點 = 12
  → 自由 (k=0) = 60 − 52 = 8
20 縫 = 10 單邊 + 8 雙邊 + 2 三邊     [O7 結構]
```

**數值身份 (候選, 標明未證)**:
| 量 | 值 | 候選 |
|:--:|:--:|:-----|
| k=0 | 8 | F₆ = 2B = B·μ² = dim(SU(3)) = N_d−h¹¹ |
| k=1 | 40 | 2B·F₅ = N_d−B = 2×20Δ |
| k=2 | 12 | B·N_gen = L₅+1 = #⬠ = #PS 邊 |
| 總 | 60 | B(L₅+B) = 4×15; 15 = 2(1+F₅)+N_gen |

**判定**: 結構鏈 = 精確推導 (可當閉合); 數值身份 = 候選 (多個候選並存 = 未定, 需獨立推導篩選)。
