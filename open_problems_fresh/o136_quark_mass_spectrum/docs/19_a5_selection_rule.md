### 1.3 ★★★ 完整解釋 (修正 O81)

```
Σ_i T_n(cos β_i) = Σ_{l ≤ n, l ≡ n (mod 2)} c_l · Σ_i P_l(v_i·c)
                    ↑ T_n 只含同奇偶的 l
```

**推論**:
- 奇 n: 只含奇 l ≤ n。首個非零奇動差 = **15** → Σ T_n = 0 for 奇 n ≤ 14
- 偶 n: 只含偶 l ≤ n。首個非零偶動差 = **6** → Σ T_n = 60a₀(n) for 偶 n ≤ 4

### 1.4 🔴 O81 §7.3 的論證係錯的

```
O81 聲稱: 「A5 orbit 係中心對稱 (V → −V 封閉) ⟹ Σ_i T_n = 0 對所有奇 n」

實測: 每個 −v_i 距最近 v_j 精確 5.3401° (系統性, 非雜訊)
      → A₅ 旋轉群 (階 60) 唔含反演 → 軌道唔係中心對稱 🔴

正確原因: 動差結構 (5-design + 額外零動差), 唔係中心對稱
後果: Σ T_n = 0 只對 奇 n ≤ 14 成立, 唔係「所有奇 n」
```
