## 二、⚠️ 自我修正：`score()` 度量 bug

**舊版**（scripts/56 首跑）：
```
res = ys − (xs − mean(xs))/std(xs) · std(ys) − mean(ys)
    ↑ 用【固定斜率】std(y)/std(x)，非 OLS 斜率
⟹ 對低相關候選系統性膨脹
   實測: sin 得 1.1300，但已知值 0.8028 (誤 +40.7%)
```

**修正版**：
```
RMS = std(y) · sqrt(1 − r²)      (等價於 OLS 殘差 RMS)
```

**★ 驗證**：修正後 `absdm` = **0.5873** — 與 docs/25 已知值**精確吻合** ✅

## 六、★★★ 置換 null 退化定理（第二個方法論修正）

### 6.1 現象

```
        模型     觀測 RMS     null 中位   null min     P(≤觀測)
      2 因子     0.5180      0.5180     0.5180     0.0000
      3 因子     0.4970      0.4970     0.4970     0.0000
                  ↑ 三者【完全相同】⟹ 明顯退化
```

### 6.2 根本原因

```
① `perm = LM.copy(); rng.shuffle(perm.tolist())`
   —— `tolist()` 產生【副本】⟹ shuffle 作用於副本，perm 從未改變 (程式 bug)

② 更根本: `score()` 用【重排配對】= 排序後配對
   ⟹ 統計量對【任何】向量置換不變
   ⟹ 所有 permutation null 在此方法下【恆為退化】
```

### 6.3 定理

```
★★★ 置換 null 退化定理:
   若配對規則由重排不等式 (排序) 決定，
   則統計量對質量向量之任何置換不變 ⟹ 置換 null 恆無判別力。

⟹ 對重排配對法，唯一有效嘅 null 必須隨機化【因子結構】或
   使用【固定配對】(identity pairing) 再置換配對。
⟹ docs/29 §4.3 之 null (單調候選+單調配對) 與本輪同屬此類退化。
```

**★ 對既有結果之影響**：
- scripts/47（扇區標度 null test，P=0.34）**不受影響** — 該測試用 **9! 搜索**配對，
  置換質量會改變最佳配對 ⟹ 有效 ✅
- docs/29 §4.3、scripts/54、本輪 (D) **受影響** — 屬退化類型 🔴
