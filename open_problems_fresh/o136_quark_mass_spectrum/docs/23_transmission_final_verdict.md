## 零、⚠️ 必須更正的錯誤

### 0.1 錯誤的度量

docs/21-22 用 σ(α) = std(α_ij) 作為「單一冪律」的判據。

**缺陷**: 當 α → 0 時, σ(α) → 0 假性變小。
例: `sumM10` 給 σ(α) = 0.000166 (看似完美), 但 α_med = 0.000079 ≈ 0
→ 實際係「質量與該量無關」的退化情況, 唔係「完美冪律」

### 0.2 正確的度量

```
ln m = a + α·ln f   的最小二乘 RMS 殘差
對照基準: ln(m) 本身的標準差 = 3.8588 (完全無解釋)
```
