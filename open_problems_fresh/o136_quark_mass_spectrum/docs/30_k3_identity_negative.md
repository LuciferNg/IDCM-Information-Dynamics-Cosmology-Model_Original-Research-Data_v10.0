## 三、(B) 代數身份（唯一正面結果）

```
c_{i,n} = cos²(nβ_i/2) = (1 + cos(nβ_i))/2
⟹ c_{i,n}^{−1} = 2/(1 + cos(nβ_i)) = 1/cos²(nβ_i/2) = sec²(nβ_i/2)

⟹ Σ_i c_{i,n}^{−k} = Σ_i sec^{2k}(nβ_i/2)
```

**★ 物理讀法**：`sec = ω/k` = **折射率** ⟹ `Σ sec²` = 折射率平方和 = **光程²**。

**★ 與 O203 之關係**：O203 排除 sec 族作【漂移】（因 Nyquist `n=44` 發散），
但此處用於【質量】— 發散點 `n = 44` 唔喺 9 選模式 `{1,2,3,4,5,7,9,11,13}` 內，故不衝突。

## 五、★★ 方法論定理：範圍永遠唔係證據

```
docs/27 §一 已證: 任何【無界函數 + 冪次】可達任意範圍
  |Δm|^α: α=1 → 1.1e2;  α=φ² → 2.2e5;  α=3 → 1.3e6
  Σ c^{−k}: k=1 → 65;  k=3 → 3.1e5;  k=10 → 3.9e17

★★★ 推論 (本輪確立):
   「候選 X 命中所需範圍」【永遠唔可以】作為證據
   ⟹ 唯一有效比較 = 形狀 (RMS)
   ⟹ 若某族嘅 RMS 對其參數平坦, 則該參數【唔可能】由數據決定
```

**本輪即為此定理之實例**：docs/29 §4.2 曾以「k=3 命中範圍」為 k=3 之支持，
本輪證明該支持無效（RMS 平坦 ⟹ k 唔由形狀定；範圍可由 k 自由 tune ⟹ 範圍命中係擬合）。
