## 三、關鍵對比: sin 比框架 vs γ 比 × P_f 框架

### 3.1 兩套框架

### 3.3 核心觀察

**框架 A 勝**: u/d (0.026%), c/b (0.368%), μ/τ (0.10%)
**框架 B 勝**: b/c (0.015%), μ/e (0.030%)

**框架 A 的致命限制**: `m_c/m_s = 13.6559` **無法**寫成 sin(n)/sin(m) 的整數形式
```
證明: sin(n)/sin(m) = 13.6559, sin(n) ≤ 1 → sin(m) ≤ 0.073228 → m ∈ {1,2}
  m=1: sin(n) = 0.48720 → n = 14.246 (非整數)
  m=2: sin(n) = 0.97427 → n = 37.633 (非整數)
  → 無解 🔴
```

**框架 B 的致命限制**: 需要 P_f 字典, 且 P_f(τ), P_f(u) 未閉合 (見 docs/06)

## 七、關鍵結論與下一步

### 7.1 結論

1. **IDCM 工具有效** — 拍頻周期表給出方案無關的質量比公式, 部分優於 O136 P_f 框架
2. **兩套框架各有勝場** — 這說明**兩者都不完整**, 需要統一
3. **框架 A 的 u/d 同 A_f = 6.18 MeV** 是真結構發現
4. **框架 A 無法表達 c/s** — 這是硬約束, 證明純 sin 比框架不完整

### 7.2 統一提案

```
m_f = A_gen · sin(n_f π/88) · D_f

其中:
  A_gen = 世代標度 (1 : 375 : 22641 — 需推導)
  sin(n_f π/88) = K_Chain 拍頻 (拍頻表座標)
  D_f = 粒子內修正 (色荷/同位旋 — 取代 P_f)
```
