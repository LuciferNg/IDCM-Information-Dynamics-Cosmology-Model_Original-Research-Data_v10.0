## 1. 質量譜公式的結構價值

### 1.1 質量譜的定義

K_Chain 的質量譜是：

```
m_n = M₀ × √γ_n = M₀ × 2sin(nπ/88),  n = 1, 2, ..., 44
```

| n | 0 | 1 | 2 | 3 | 4 | 7 | 14 | 20 | 33 | 34 | 44 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| √γ_n | 0 | 0.0714 | 0.1427 | 0.2138 | 0.2846 | 0.4946 | 0.9586 | 1.3098 | 1.8481 | 1.8739 | 2.0 |
| m_n (MeV) | 0 | 1.99 | 3.98 | 5.96 | 7.94 | 13.80 | 26.74 | 36.54 | 51.56 | 52.28 | 55.80 |

### 1.2 質量譜不是粒子質量 — 而是投影基底

質量譜是 K_Chain 的**固有能量階梯**。粒子質量是這個譜經 CY₃ 投影後的結果。

```
粒子質量 = 譜能量 × 投影因子
```

用類比：質量譜是鋼琴的琴弦（決定泛音列），粒子質量是按下的琴鍵（決定具體音符）。兩者有不同的幾何來源。

### 1.3 質量譜的結構價值

**價值一：隔離拍頻比**

質量譜的**比值**是純幾何結構，與 M₀ 無關：

```
m_n₁/m_n₂ = sin(n₁π/88)/sin(n₂π/88)
```

這稱為**拍頻比** (beat frequency ratio)。它完全由 K_Chain 的 88-site 週期結構決定，是精確的、無自由參數的恆等式。

**價值二：分離投影比**

一旦確定了粒子對應的 K_Chain 模式 n，觀測質量比可分解為：

```
m_f₁/m_f₂ = [sin(n₁π/88)/sin(n₂π/88)] × [P_f₁/P_f₂]
              ↑                           ↑
           拍頻比 (已知)              投影比 (待推導)
```

投影比 P_f₁/P_f₂ 是純 CY₃ 幾何量，不依賴於 K_Chain。

**價值三：給出質量比例的上界**

質量譜本身給出的質量比就是拍頻比。實際粒子質量比可能大於或小於這個比值，偏離的大小由投影比決定，這本身就是物理信息。

## 2. 投影比的幾何來源

### 2.1 CY₃ Hodge 結構

CY₃(36, 98) 的兩個 Hodge 數：
- h¹¹ = 36 = Kähler moduli（控制內部空間的「大小」）
- h²¹ = 98 = Complex structure moduli（控制內部空間的「形狀」）

### 2.2 投影的物理意義

當 K_Chain 模式 n 投影到物理時空時，它經過 CY₃ 的內部空間：
- **Kähler 投影**：決定模式的「大小」放大倍數
- **複結構投影**：決定模式的「形狀」扭曲

### 2.3 投影因子的特例

### 2.4 色荷修正 D_quark

夸克有額外的色荷修正：

```
D_quark = 1 + h¹¹/h²¹ × ε × (1+ε) = 1.065528
```

這來自 CY₃ 的 Hodge 比 h¹¹/h²¹ = 36/98，乘以自能展開 ε×(1+ε)。

## 3. 完整 SM 費米子質量推導框架

### 3.1 推導方法

不是數值匹配，而是**三步結構推導**：

**第一步：模式分配**
每個 SM 費米子對應一個 K_Chain 模式 n。分配依據：
- 世代結構（1st/2nd/3rd）
- 色荷狀態（色單態/色三重態）
- 弱同位旋（上型/下型）

**第二步：拍頻比隔離**
從質量譜計算拍頻比，分離出投影比。

**第三步：投影比推導**
從 CY₃ 幾何推導投影比的結構公式。

### 3.2 候選模式分配（基於結構意義）

| 世代 | 輕子 (色單態) | 上型夸克 (色三重態) | 下型夸克 (色三重態) |
|:----:|:-------------:|:-------------------:|:-------------------:|
| 1st | e⁻ (n=1) | u (n=?) | d (n=?) |
| 2nd | μ⁻ (n=7) | c (n=?) | s (n=?) |
| 3rd | τ⁻ (n=20) | t (n=?) | b (n=?) |

模式分配的結構性候選：
- n=1 — 最低非零模式（基態）
- n=7 — DM 模式（m₇=13.8 MeV）
- n=20 — τ 模式
- n=33 — M = K_tree 深度
- n=34 — F₉ = Fibonacci 9

### 3.3 投影因子的結構候選

從已知的 CY₃ 和 Lucas 結構：

```
F_proj 候選庫:
  L₆/F₅ = 18/5 = 3.6        (電子)
  Nd−E_proj = 44−28.5 = 15.5 (μ 子)
  Nd−L₄ = 44−7 = 37          (τ 子)
  Nd−L₅ = 44−11 = 33         (下夸克?)
  Nd = 44                    (底夸克?)
  F₇ = 13                    (粲夸克?)
  L₅ = 11                    (粲夸克+D_q?)
```

### 3.4 驗證流程

1. 對每個費米子，指定 n 和 F_proj 的結構形式
2. 計算 m_pred = M₀ × γ_n × F_proj (× D_quark 如適用)
3. 對比 PDG，要求偏差 < 1% 或給出結構性修正項
4. 交叉比對：同一 F_proj 用於不同粒子時必須一致（如 L₆/F₅ 用於 e⁻ 和 s）

## 4. 開放問題

1. **模式分配的正當性**：為什麼某粒子對應某個 n？需要從 K_Chain 的 Z₂ 分級或色荷狀態推導。
2. **投影因子的結構推導**：F_proj = Nd−L₄ 等不是推導，只是數值巧合的標籤。
3. **D_quark 的適用範圍**：適用於所有夸克還是僅下型？需要從 CY₃ 投影的色荷分解推導。
4. **中微子質量**：沒有 α 衰減的推導，不能只看 M₀×γ_n×F_proj。
5. **CKM/PMNS 混合**：不在質量公式範圍內，需要單獨的混合角推導。
