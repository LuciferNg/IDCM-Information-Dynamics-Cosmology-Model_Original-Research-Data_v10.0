### 1.2 c/s 條目錯誤

`physics_mapping.json` 的 "c/s 夸克質量比, pair (8,22), sin8/sin22, O34 ✅ 0.368%" 條目:

- sin22/sin8 = 2.50985 vs 13.65591 → −81.62%
- φ^8.5379·sin8/sin22 = 24.247 vs 13.65591 → +77.56%

**數學證明**: m_c/m_s = 13.65591 **無法**寫成 sin(n)/sin(m) 整數形式:
```
sin(n)/sin(m) = 13.65591, sin(n) ≤ 1 → sin(m) ≤ 0.073228 → m ∈ {1,2}
  m=1: sin(n) = 0.48720 → n = 14.246 (非整數) 🔴
  m=2: sin(n) = 0.97427 → n = 37.633 (非整數) 🔴
→ 無解
```

**判定**: 該條目的 "0.368%" 與 c/b 條目相同 → **疑似複製錯誤**。需標記為 🔴。
