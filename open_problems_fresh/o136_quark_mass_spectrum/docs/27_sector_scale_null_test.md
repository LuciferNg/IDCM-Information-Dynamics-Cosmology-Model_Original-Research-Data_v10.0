## 一、★★ 框架修正：「範圍/比值分離」係錯嘅表述

docs/26 §二 寫「範圍正確者 = Gap 本徵向量 (2.175e5×)；比值正確者 = 二階自能 (0.5873)；
⟹ 兩個獨立環節」。**本輪證明呢個分離係假象。**

```
|Δm| 範圍 = 110.5×
  取 α = 1 → 1.105e+02   (觀測 3.379e+05, 比 0.00×)
  取 α = φ² = 2.618 → 2.237e+05   (比 0.66×)  ← 已達正確量級
  取 α = 2.0 → 1.221e+04   (比 0.04×)
  取 α = 3.0 → 1.349e+06   (比 3.99×)

★ 任何【無界函數 + 冪次】都可以達到任意範圍
★ 範圍只對【有界譜】(sin ∈ [0,1], 上限 1/sin(π/88) = 28.0172) 構成硬約束
```

**修正後嘅正確表述**：

| 譜類型 | 範圍 | 是否障礙 |
|:-------|:-----|:--------:|
| 有界 (sin(nπ/88)) | ≤ 28.0172× | 🟢 **真障礙**（唔可能達 3.379e5×） |
| 無界 + 冪次 (\|Δm\|^α) | 任意 | 🔴 **唔係障礙**（α 一調即到） |

**⟹ 質量問題只有【一個】障礙：形狀（比值），唔係兩個。**

## 二、扇區標度擬合（看似突破）

**動機**：A₅ 選擇律預言 9 模式 = 3 輕子 + 6 夸克（結構預言，非後驗）。
若三個扇區有獨立標度，則 9 個質量只需 1 個指數 + 3 個標度。

```
模型: ln m_p = ln C_{sector(p)} + α·ln f(n_p)
扇區: {L, U, D} (3) 或 {L, Q} (2) 或 {全部} (1)
搜尋: 所有扇區指派 (允許非連續) × α 網格; 扇區內採單調配對 (rearrangement 最優)
```

| 候選 | 扇區 | RMS | α |
|:-----|:----:|:---:|:---:|
| **sin(nπ/88)** | **3 (L/U/D)** | **0.3549** | 4.90 |
| \|Δm\| | 3 (L/U/D) | 0.3885 | 2.80 |
| \|Δm\| | 2 (L/Q) | 0.4567 | 2.75 |
| \|Δm\| | 1 (全部) | 0.5878 | 2.65 |
| G (Gap) | 3 (L/U/D) | 0.5927 | 0.85 |

**表面改善：sin 由 1.1178 → 0.3549（3.1×）。**

## 三、★★★ null test — 排除（決定性）

⚠️ 3 個自由標度 = 4 參數對 9 點 → **必須排除過擬合**。

### Null test 1：隨機扇區標籤（尺寸固定 3/3/3，N = 300）

```
sin(nπ/88): 觀測 RMS = 0.3549 | null 中位 = 0.4332, min = 0.1283 | P(null ≤ 觀測) = 0.3400  🔴 唔顯著
|Δm|:       觀測 RMS = 0.3885 | null 中位 = 0.3213, min = 0.1468 | P(null ≤ 觀測) = 0.7333  🔴 唔顯著
```

### Null test 2：隨機質量（扇區固定 3/3/3，N = 300）

```
sin(nπ/88): 觀測 RMS = 0.3549 | null 中位 = 0.4317, min = 0.1283 | P(null ≤ 觀測) = 0.3133  🔴 唔顯著
|Δm|:       觀測 RMS = 0.3885 | null 中位 = 0.3366, min = 0.1468 | P(null ≤ 觀測) = 0.6567  🔴 唔顯著
```

### ★ 裁決

```
★★★ 隨機扇區標籤（同尺寸）做得到一樣好甚至更好 (中位 0.4332 vs 觀測 0.3549; |Δm| 中位 0.3213 < 觀測 0.3885)
★★★ null 嘅最小值 (0.1283) 遠優於觀測
⟹ 3 個自由標度嘅改善【全部來自參數膨脹】
⟹ L/U/D 扇區結構本身【零信息】
⟹ U/D = 75.19 ≈ L₄L₅−μ² 係 post-hoc 巧合, 唔可以當結構身份 (禁後驗湊算子)
```

**AIC/BIC 註**：4 參數模型之 AIC/BIC 確比 2 參數好（−10.64/−9.85 vs −5.57/−5.17），
但 null test 顯示改善**唔依賴**具體扇區結構 ⟹ 資訊準則支持嘅係「多 3 個自由度」，
唔係「L/U/D 有意義」。
