## 一、極性規則 (核心發現)

### 1.1 規則

```
δ_g = (−1)^g · L_{5(g−1)}
n₀(g) = n₀(1) + Σ_{j=1}^{g−1} δ_j = 17 + Σ_{j=1}^{g−1} (−1)^j L_{5(j−1)}
```

### 1.2 驗證

| g | δ | Λ_g | n₀(g) | 目標 | 驗證 |
|:-:|:-:|:---:|:-----:|:----:|:----:|
| 1 | — | — | 17 | 17 | ✅ |
| 2 | **−2 = −L₀** | L₀ = 2 | 15 | 15 | ✅ |
| 3 | **+11 = +L₅** | L₅ = 11 | 26 | 26 | ✅ |

**極性交替**: g=2 為奇 → 負; g=3 為偶 → 正

### 1.3 ★★ 可檢驗預言: 第 4 代自動排除

```
δ₃ = (−1)³ · L₁₀ = −123
n₀(4) = n₀(3) + δ₃ = 26 − 123 = −97 < 0
→ 無效模式 → 第 4 代自動排除 ✅
```

**這是結構性預言: 恰好 3 代 (與觀測一致)**

排除機制:
```
L₁₀ = 123 > 2N_d = 88
→ 任何模式位移超過鏈長 → 無效
```

## 三、★ 輕子 Δn = 14 + dimC = 17 (新發現)

### 3.1 對比

```
夸克對 (色三重態):  Δn = B² − 2 = 14
```

**色單態的 Δn = 色三重態的 Δn + dimC**

```

17 = L₅ + C(4,2) = 11 + 6 = n₀(1)
→ 兩個獨立表達同時成立 ✅

```
