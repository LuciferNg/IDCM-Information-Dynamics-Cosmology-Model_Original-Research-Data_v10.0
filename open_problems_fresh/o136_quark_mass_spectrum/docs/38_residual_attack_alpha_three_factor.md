## 二、R8 — α = 79/30 盲測升格（scripts/68）

### 2.1 36 比零參數盲測（樣本外本體）

```
方法: m_i/m_j = (|dm_i|/|dm_j|)^α — 唔 fit 任何嘢 (零參數), 全 36 對
79/30:  |dev| 中位 0.4239  RMSE 0.8808
α_OLS:  |dev| 中位 0.4239  RMSE 0.8808   (兩者只差 3e-5, 不可辨識 — 預期)
MC null (α~U[0,5], N=20000): median 2.218, min 0.423
P(79/30 ≤ null) = 0.0008 ✅   P(α_OLS ≤ null) = 0.0008 ✅
成對: 79/30 優於 OLS 15/36 (bootstrap P=0.199 — 兩者差 3e-5 無意義)
```

**解讀**: 零參數 36 比預言係樣本外檢驗 — 唔用 M₀、唔用 α fit。任何冪律 α 值只有極少數能喺 36 比上攞到 |dev| 中位 < 0.43（null 密度極低）。79/30 = (88−N_gen²)/(2·N_gen·F₅) 結構值**本身**（唔係 fit 出嚟）達此水平 ⟹ 結構 α 假說有樣本外支持。

### 2.2 真正樣本外 t 預言（8pt fit → 預言 m_t）

```
fit 8 點（除 t）→ 用 α 預言 m_t:
  79/30 (零額外參數): log-dev = −0.0708 (7.3%)
  α_OLS_8 (1 參數):   log-dev = −0.1225 (13.0%)
  ⟹ 79/30 更準 1.8 倍, 且節省 1 個自由度 (方法論: 零參數 > 擬合參數)
  (對應 O209 docs/11: 9pt dev 0.003% vs 8pt dev 0.655%)
```
