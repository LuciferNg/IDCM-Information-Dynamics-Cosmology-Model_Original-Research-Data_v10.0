## 一、★★★ 結構障礙定理（決定性負結果）

### 定理

```
若 m(n) = C·γ(n)^α 對所有模式 n 成立
則 ln(m(n_{i+1})/m(n_i)) = α·ln(γ(n_{i+1})/γ(n_i))  ∀i
⟹ α_i ≡ ln(質量比)/ln(γ比) 必須為常數
```

### 實測

| i | n_i→n_j | γ 比值 | 質量比值 | **α_i** |
|:-:|:------:|:------:|:--------:|:-------:|
| 1 | 1→2 | 3.9949 | 4.2270 | **1.0408** |
| 2 | 2→3 | 2.2452 | 2.1620 | **0.9533** |
| 3 | 3→4 | 1.7725 | 20.0000 | **5.2338** |
| 4 | 4→5 | 1.5565 | 1.1312 | **0.2787** |
| 5 | 5→7 | 1.9401 | 12.0199 | **3.7521** |
| 6 | 7→9 | 1.6306 | 1.3991 | **0.6868** |
| 7 | 9→11 | 1.4684 | 2.3525 | **2.2266** |
| 8 | 11→13 | 1.3682 | 41.3134 | **11.8713** |

```
α_i ∈ [0.2787, 11.8713]
標準差 = 3.6248
跨度 = 42.6×

★★★ 定理: 【純冪律 m ∝ γ^α 不可能】 (對單調配對)
```

### ★★ 負相關（強烈線索）

```
corr(γ 比值, 質量比值)       = −0.2901
corr(ln γ 比值, ln 質量比值) = −0.1109

⟹ 質量比值與 γ 比值【反向】
⟹ γ 跳得大處 (n=1→2, 比值 3.99) 質量跳得小 (4.23)
⟹ γ 跳得小處 (n=11→13, 比值 1.37) 質量跳得大 (41.31)
```

**★ 呢個負相關排除任何「γ 的單調函數」解釋。**

### ★★★ 結構性結論

```
【範圍】正確者: Gap 方程主本徵向量 (2.175e5× ≈ 觀測 3.379e5×)
【比值】正確者: 二階自能 (RMS 0.5873, 最佳)

⟹ 質量譜問題分解為【兩個獨立環節】:
   (i)  範圍 (量級) — 需乘積/冪次結構
   (ii) 比值 (形狀) — 需正確的模式依賴
   冇任何單一候選同時滿足兩者
```

### Gap 方程的 g-無關性（診斷）

```
Gap 方程: m_n = g·Σ_m |V_nm|²·m_m/(E_m²+m_m²)
冪法迭代收斂後: 比值範圍 4.797e4×, 與 g 完全無關

★ 原因: 迭代落入【線性區】 (m ≪ E)
   m/(E²+m²) ≈ m/E²  ⟹ m_new = g·K·m,  K_nm = V_nm²/E_m²
   ⟹ 不動點 = K 的主本徵向量, g 只做整體縮放 (被歸一化消除)
   ⟹ 所以「Gap 方程」實際係【線性本徵值問題】
```
