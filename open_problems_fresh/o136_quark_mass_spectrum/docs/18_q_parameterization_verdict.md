## 一、★★ 確立: q-參數化 (精確恆等式)

### 1.1 推導

```
L = N_d/gcd(n, N_d)                      (子環長度)
n·L = n·N_d/gcd(n, N_d) = N_d · (n/gcd(n, N_d)) = N_d · q

其中 q := n/gcd(n, N_d)                  (winding number)

反週期條件:
  n·L ≡ N_d (mod 2N_d)
  ⟺ N_d(q − 1) ≡ 0 (mod 2N_d)
  ⟺ q − 1 為偶數
  ⟺ ★ q 為奇數 ★
```

### 1.2 驗證 (44/44)

```
✅ n·L = N_d·q           對所有 n ∈ [1,44] 成立
✅ 反週期條件 ⟺ q 奇數   對所有 n 成立
✅ v₂(n) ≤ 2 ⟺ q 奇數    兩個表徵等價
```

### 1.3 完整參數化

```
★ n = N_d · q / L,   q 奇數,  L | N_d
```

**這是 O137 Phase 1+2 的反週期律的最乾淨形式。**
