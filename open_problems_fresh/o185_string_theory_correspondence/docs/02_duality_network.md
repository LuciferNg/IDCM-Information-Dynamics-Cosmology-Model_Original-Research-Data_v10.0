## 5. 判定（scripts/02 §3）

- **S1-1 唯一「同構」= 站-模對偶 (D5)**: Ŝ = S²² 移位生成 ℤ₄，同時對角化 DFT，支撐
  {0,22,44,66} — 呢個係「位置表示↔動量表示」嘅離散版，同弦論 IIA↔IIB T-duality
  「位置↔動量/繞數互換」**同構**。但 IDCM 版零連續自由參數。
- **S1-2 其餘為「特例/無對應」**: S-duality 需要耦合常數 g（IDCM 冇）；T-duality 需要
  動量/繞數譜（IDCM 只有有限 44 模）；Mirror 需要 CY moduli 空間（IDCM CY₃ 係零輸入
  固定 (36,98)）。層次不同。
- **S1-3 可證偽判準**: 若 D5 同 IIA↔IIB 成立，IDCM 必須重現 τ = B + i/g 模參數結構
  （SL(2,Z) 作用）— 目前冇 ⟹ S1 全網以特例/無對應為主，唔宣稱對偶網同構。
