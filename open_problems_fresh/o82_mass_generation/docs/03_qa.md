## 二、特別問題 Q_s1: 1-loop 同實驗 mass 有冇 finite correction?

**場論學家:** 「你嘅 mass formula 係 leading order。完整 1-loop 自能會有 finite correction (next-to-leading order)。呢啲 correction 會唔會破壞你嘅 0.16% 閉合精度?」

**IDCM 答案:**

1. **IDCM 嘅 1-loop 自能係 exact (因為有限譜)**
   - 88-site lattice → 只有 44 個正頻模式
   - 1-loop 積分變為有限和: Σ_n = Σ_{k=1}^{44} (mode sum)
   - 冇 continuum limit → 冇 higher-order 積分誤差

2. **耦合結構 g_n = κ·ω_n 保證 leading order = exact**
   - g_n ∝ ω_n → ΔE_n = −g_n²/ω_n = −κ²·ω_n (exact, 唔係近似!)
   - 即使計算更高階 (2-loop), 譜形仍然 ∝ ω_n

3. **0.16% 偏差來自投影路徑 (F_proj), 唔係 loop 積分**
   - m_e = M₀γ₁·L₆/F₅ = 0.5118 MeV (dev 0.16%)
   - 1-loop finite correction 會改變 M₀ 嘅整體標度, 唔改譜形

**判決:**
- 🟢 Leading order: ΔE_n = −κ²·ω_n (exact, 譜形 scheme independent)
- 🟢 譜形 sin(nπ/88): 冇 finite correction
- 🟡 整體標度 M₀: 會有 finite correction (但吸收到 κ_R)

## 三、特別問題 Q_s2: 冇 Higgs particle 點 guarantee unitarity?

**場論學家:** 「SM 入面 Higgs 粒子保證 W_LW_L → W_LW_L 散射嘅 unitarity。你冇 Higgs 粒子, 點保證 unitarity?」

**IDCM 答案:**

1. **IDCM 冇 Higgs particle, 但有天然 cutoff**
   - IDCM 質量 = W-field 凝聚 + 1-loop 自能
   - W 係凝聚場, 唔係 propagation scalar
   - 天然 cutoff ω_max = 2 (Nyquist) → ~55.8 MeV

3. **延伸到 TeV 尺度需要 Higgs 或新結構**

- 🟢 IDCM 喺本身能量範圍 (≤55.8 MeV) 冇 unitarity 問題
