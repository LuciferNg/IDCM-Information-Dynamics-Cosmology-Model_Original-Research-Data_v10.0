## 四、moduli 機制（R5，O56 對接）

$$\boxed{\;h^{11} + h^{21} = \mathrm{Tr}\,\mathbf{G} = N_d + \sum\gamma = 134\;}$$

**機制**：moduli 總數 = 生成算子 $\mathbf{G} = \mathbb{1} + \hat\gamma$ 嘅**跡**（graded dimension）。
$2B$ 耦合只**重新分配** site 維數 ↔ 譜維數，總數不變（$2B$ 相消）：

```
site sector  N_d = 44  ──(−2B)──┐
                                ├─→ h¹¹ = 36  (Kähler)
energy sector Σγ = 90  ──(+2B)──┘
                                └─→ h²¹ = 98  (CPX)
                        總和 = Tr G = 134
```

呢個係 O56 「分支耦合」機制嘅**算子化版本**：O56 用「K_Tree 分支創造 2B 耦合」講，
本 O 用 $\hat\Pi_{2B}$ 投影講，兩者一致。
