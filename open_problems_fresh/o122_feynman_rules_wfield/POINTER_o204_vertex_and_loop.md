# POINTER → O122：頂點 `g_n = κω_n` 確認；one-loop 反證排除

## 一、O122 頂點形式獲 O204 支持

O122 §3 導出 `g_n = κ·ω_n`，`ω_n = 2sin(nπ/88)` ⟹ `g_n = κ√γ_n`（因 `ω_n² = γ_n`）。
O204 §U2 變體 (a) 即採此形式（`κ = 1/B² = 1/16`）。**形式一致，無衝突。**

## 二、★ U2 反證：μ²/λ 唔係 one-loop 生成

O204 `07_open_problems_attack.py` §U2 枚舉四個變體，全部失敗：

| 變體 | 耦合 | 需 κ²(μ²) | 需 κ²(λ) | 比 |
|---|---|---|---|---|
| (a) | `g_n = κ√γ_n`（O122 頂點） | 31.64534 | 1.01495 | **31.179×** |
| (b) | `g_n = κ`（均勻） | 0.30934 | 0.05520 | **5.604×** |
| (c) | Coleman–Weinberg（log 版） | — | — | 符號錯（見下） |
| (d) | 四階完備 η 之 loop 修正 | — | — | 反證（見下） |

### (c) CW 與 √-減除版本符號相反

```
√-減除版本 w² 係數 = −0.06320045569  (< 0, 生成 SSB)
CW (log) 版本 w² 係數 = +0.01116971552 (> 0, 唔生成 SSB)
```

**「SSB 由 loop 自動生成」依賴 scheme** — 對 O204 docs/04 §P5 符號定理之重要限定：
符號定理只在 √-減除 scheme 成立，**唔係 scheme-independent**。

### (d) ★ 四階完備性反證（核心）

O204 P1 導出 **η_tree = 0**（勢中無 w⁶ 項）。但 one-loop 修正必然給 `c6 = −1.391947756 ≠ 0`
⟹ **loop 必然破壞四階完備**。若 μ²/λ 係 loop 生成，則 η 應該 = 0 — 但 loop 必然給 η ≠ 0。

> **反證：`μ² = 2` 與 `λ = 2/123` 唔係 one-loop 生成。**
> 佢哋係樹階譜身份；loop 只提供 SSB 之**符號**（且 scheme-dependent）。

## 三、對 O122 之建議

`g_n = κω_n` 之 `κ` 若原意為「由 loop 決定」，需注意上述反證。
若 κ 係獨立輸入參數，則無影響。
