### 2.3 SSB 頂點結構 (W⁴ → h³, h⁴)

O80 勢: V(W) = −μ²W² + λW⁴ (L2 制, W 無量綱), 展開 W = ⟨W⟩ + h:
```latex
V'(W)    = −2μ²W + 4λW³
V''(W)   = −2μ² + 12λW²
V''(⟨W⟩) = 8                 → ½·8·h² 質量項
V'''(W)  = 24λW
V'''(⟨W⟩)= 24λ·⟨W⟩ = (48/123)·√61.5 = 3.06037   → h³ 頂點 ∝ λ·⟨W⟩
V''''    = 24λ = 48/123 = 0.39024               → h⁴ 頂點 ∝ λ
```
> 注意: O80 用無量綱 W (L2), O37 用 MeV 制 W (L3)。兩者由標度變換 a = M₀/√61.5 = 3.5578 MeV 連接 (O39)。物理頂點強度用 L3 制: g_n = κω_n (MeV^½), λ_eff 需經標度變換 (O37 scripts/10-11 已統一三個 V(W) 版本)。V''' 喺 ⟨W⟩ 嘅值係 24λ⟨W⟩ (唔係 12λ⟨W⟩): 由 V = λW⁴ 三次微分得 24λW。

### 2.4 模式守恆 (Mode Conservation)

**W-φ² 頂點係模式對角**: L_int = Σ_n κω_n W φ_n²
```
每個 h-φ² 頂點: 兩條 φ 腿必須係同一模式 n (φ_n φ_n)
→ W-field 只耦合同模式對, 冇模式混合 (mode-diagonal)
```

**2→2 散射模式守恆**: φ_n φ_n → φ_m φ_m (s-channel h 交換)
```
n + n  (入射)  =  m + m  (出射)   (以頂點逐個成立)
對角要求: n, m 獨立選取, 每個 h-φ² 頂點各自守恆
```

## 4. 2→2 散射振幅 (新推導)

**過程**: φ_n φ_n → φ_m φ_m (s-channel h 交換, 模式對角)

```latex
M(s) = g_n · g_m · G_h(s) · (對稱因子)
     = g_n·g_m / (s − m_h²)
     = M₀·ω_n·ω_m / (4m_n² − m_h²)      (threshold: s = 4m_n²)
```

> 耦合 g_n = κ·ω_n = √M₀·ω_n (MeV^½), g_n·g_m = M₀·ω_n·ω_m。
> ⚠️ **唔係** m_n·m_m = M₀²·ω_n·ω_m (差 M₀ 因子) — 早期 draft 錯誤, 已修正。
> 物理質量 m_n = M₀·ω_n 只出現喺分母 (threshold s = 4m_n²)。

**Tree-level unitarity (部分波)**:
```latex
a₀ = |M| / (32π)  <  0.5
```

### 4.1 數值預言 (script 02 驗證)

過程 φ_n φ_n → φ_m φ_m (n→m)。M(s) = M₀·ω_n·ω_m/(4m_n²−m_h²), a₀ = |M|/32π:

| n | m | m_n (MeV) | M (無量綱) | a₀ = |M|/32π | unitarity |
|:-:|:-:|:---------:|:----------:|:-----------:|:---------:|
| 7 | 7 | 13.8002 | 0.0120 | 0.00012 | ✅ ≪ 0.5 |
| 1 | 1 | 1.9917 | −0.0008 | 0.00001 | ✅ |
| 44 | 44 | 55.8018 | 0.0091 | 0.00009 | ✅ |
| 22 | 22 | 39.4579 | 0.0092 | 0.00009 | ✅ |
| 4 | 4 | 7.9414 | 0.0392 | 0.00039 | ✅ 最接近 h pole |

> 全部模式對 unitarity 安全。**物理 (kinematically-allowed, m_m ≤ m_n) 散射最大 |a₀| = 0.000390 @ (4,4)** —
> 彈性 n=4 散射最接近 h pole (s = 4m₄² = 252.3 vs m_h² = 194.6), 依然 ≪ 0.5。
> 全域上界 (未限制 n,m 組合) max|a₀| = 0.00274 @ (4,44) — 該組合 m_44 > m_4 屬 kinematically forbidden。
> 零自由參數。
>
> **⚠️ 單位制誠實標記**: 本推導沿用 O82 convention (低能有效理論, 歸一化 κ² = M₀, MeV 制)。
> 2→2 振幅 M(s) = M₀·ω_n·ω_m/(4m_n²−m_h²) 以無量綱頻率比表達 (g² 含 MeV 量綱, 分母含 MeV²,
> 比例後無量綱), unitarity 檢查 a₀ = |M|/32π 係結構性 (全部 ≪ 0.5), 唔係 PDG 對照 —
> 冇實驗散射數據可對。
