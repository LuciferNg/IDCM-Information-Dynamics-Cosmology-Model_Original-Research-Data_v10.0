## 二、發現嘅錯誤 (4 處) 及修正

### 🔴 錯誤 1: V''' 係數 (script 02 + docs/03 §2.2/§2.3)

**問題**: V(W) = −μ²W² + λW⁴, 三階導數 V'''(W) = **24λW** (唔係 12λW)
```
d/dW λW⁴  = 4λW³
d²/dW²    = 12λW²
d³/dW³    = 24λW   ← 正確
```
script 02 同 docs 都寫 `V''' = 12λ⟨W⟩ = 1.5302` — 錯。

**修正**: `V'''(⟨W⟩) = 24λ·⟨W⟩ = (48/123)·√61.5 = 3.06037`
- script 02 [E] 部分: 改為 Vppp = 24*lam*w_vev, 新增 check
- docs/03 §2.3: 完整列出 V', V'', V''', V'''' 導數鏈, 修正數值
- PASS 數由 21 → 22 (新增 V''' check)

### 🔴 錯誤 2: M(s) 散射公式符號 (docs/03 §4 + docs/01)

**問題**: docs 寫 `M(s) = m_n·m_m/(4m_n² − m_h²)` — 單位錯誤
```
耦合:    g_n = κ·ω_n = √M₀·ω_n (MeV^½)
g_n·g_m = M₀·ω_n·ω_m   (唔係 m_n·m_m = M₀²·ω_n·ω_m!)
正確:    M(s) = g_n·g_m/(s−m_h²) = M₀·ω_n·ω_m/(4m_n²−m_h²)
```
script 02 嘅**數值計算本身係啱** (`(κω_n)(κω_m) = M₀ω_nω_m`), 但 docs 符號寫錯差 M₀ 因子。

**修正**: docs/03 §4 + docs/01 改為 `M(s) = M₀·ω_n·ω_m/(4m_n²−m_h²)`。

### 🟡 錯誤 3: 自能公式表述 (docs/03 §3)

**問題**: docs 寫 `Σ_n(p) = g_n²·G_h(p≈0) = (κω_n)²/m_h²` — 呢個唔係 O82 推導
```
O82 正確鏈:
  O36 二階微擾:  ΔE_n = −(g_n)²/ω_n = −κ²ω_n     (教科書: ΔE = −g²/ħω)
  O82 QFT 翻譯:  Σ_n(p) ≈ −(g²/m_W²)·ω_n = −κ²ω_n  (低能極限, g²/m_W² 重整化)
  O38 抵消定理:  κ² = g²/m_W² = M₀
```
`(κω_n)²/m_h²` 有量綱錯誤 (MeV³/MeV² = MeV, 唔係 MeV) 且唔係 O36/O82 推導。

**修正**: docs/03 §3 改用 O36→O82→O38 正確推導鏈, 加單位註。

### 🟡 錯誤 4: docs/03 §2.2 h³/h⁴ 頂點因子表達

**問題**: 原寫 `h³: −i·(3!)·λ′_eff, h⁴: −i·(4!)·λ` — 用組合因子遮蔽咗真正嘅導數值, 且 λ′_eff 未定義。

**修正**: 直接寫勢導數
```
h³ 頂點: −i·V'''(⟨W⟩) = −i·24λ⟨W⟩
h⁴ 頂點: −i·V''''      = −i·24λ
```
