## 執行摘要

**核心問題**: IDCM 預測 60 個 A₅ 節點全部係「拓撲縫合節點」，應該有溫度異常。除咗已確認嘅大冷斑 = 節點 0，其他節點有冇對應公開冷斑目錄？

**答案**: 🟡 **部分命中 — 只有節點 0 (大冷斑) 係跨尺度唯一一致命中，其他節點冇對應目錄冷斑/熱斑。**

## 重大發現 1: 文獻根本冇「10+ 冷斑目錄」

SESSION_START.md 假設 Cruz 2005 (astro-ph/0505341) 有 ~10-15 個冷斑目錄，**係錯嘅**：

| 論文 | 實際內容 |
|:-----|:---------|
| astro-ph/**0505341** | ❌ 唔係 Cruz 冷斑論文！係 Saviane et al. dwarf galaxy 論文 |
| astro-ph/**0405341** | ✅ Cruz 2005 正確 ID — 只確認**大冷斑** (209°,-57°) + Table 4 四個子斑 |
| Cruz 2007 (0603859) | 同一大冷斑，冇目錄 |
| Cruz 2006 (0601427) | 同一大冷斑 morphology，冇目錄 |
| Hou 2009 (0903.4446) | 熱/冷斑統計，冇座標目錄 |
| Planck 2013 (1303.5083) | 大冷斑 + **第二冷斑 (32°,-8°)** (gp10 區，部分被銀河面遮擋) |
| Gurzadyan 2014 | 同一大冷斑重新分析，冇目錄 |
| Vielva 2010 overview | 同一大冷斑回顧，冇目錄 |

**結論**: 文獻目錄只提供 2 個確認冷斑 (大冷斑 + Planck gp10)，冇 ~10 個嘅完整目錄。

## 重大發現 2: SMICA 自建目錄（5.0° 平滑，2σ flood-fill）

由於文獻無完整目錄，用 Planck SMICA 自行提取（方法同 O2 一致）：
- **15 個冷斑 + 14 個熱斑**（|b|≥25° mask，面積≥2°²，組件合併 5° 內）

關鍵位置:
- 冷斑 #2 = **大冷斑** (-126.6 μK @ 208.40°,-56.33°) → 節點 0 距離 0.75° ✅
- 其餘冷斑離最近節點 5.9°-14.1° — **全部唔命中**

## 顯著性檢驗（1000 次隨機旋轉，保留網絡結構）

| 統計量 | 觀測 | 隨機分佈 | p-value |

## 尺度匹配

- 節點間距 26.09°，Voronoi cell 半徑 ≈ 13.05°
- 冷斑 FWHM 4.17° (R8) → 完全 fit 一個 cell ✅
- SMICA 大組件 (100+°²) = 跨多個 cell 嘅大尺度漲落，唔係節點結構
- **O2 熱斑 F₆ (157.8°,-70.3°)** → 最近節點 55 距離 **9.03°** — 唔命中
- **O2 熱斑 F₇ (0.2°,-37.9°)** → 最近節點 51 距離 **8.25°** — 唔命中

→ **熱斑唔喺節點上**（呢個係重要嘅誠實負面結果：IDCM 節點係「冷/熱異常」模型，但熱斑並唔對應節點位置）

## 結論

1. 🟢 **節點 0 (大冷斑) 係真結構** — 文獻 + SMICA 三尺度全部確認，距離 0.00°
2. 🔴 **其他 59 個節點冇對應目錄冷斑/熱斑** — 命中率同隨機冇分別
3. 🟡 全局 mean-nearest 微弱信號 (p=0.042) 由大冷斑驅動，唔係全網結構
4. 📝 文獻「10+ 冷斑目錄」係誤記 — 實際只有 2 個確認冷斑
5. 🔴 熱斑 (F₆/F₇) 距離節點 8-9° — 同節點模型唔一致，需要重新考慮熱斑嘅幾何歸屬
