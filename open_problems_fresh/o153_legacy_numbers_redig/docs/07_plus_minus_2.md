## 1. ±2 嘅譜幾何本質：γ₄₄ 自對偶 mode — 🟢

88-site 對偶鏈（176-Laplacian）有 Z₂ 對偶：γ_k + γ_{88−k} = B = 4。88 個 mode 分成：

```
43 對偶對 (k, 88−k), k=1..43      → 43×B = 172
k=44 自對偶 (44, 44)               → γ₄₄ = 4sin²(44π/176) = 4sin²(π/4) = 2 = μ²
k=88 Nyquist (對偶 = k=0 唔喺譜)   → γ₈₈ = 4 = B
─────────────────────────────────────────────
Σ = 178 = 2F₁₁                      （43×4 + 2 + 4 EXACT）
```

**k=44 係唯一自對偶 mode**：佢同 88−44 = 44 自己配對，γ₄₄ + γ₄₄ = B = 4。而 γ₄₄ = 2 = μ² — **±2 就係 ±γ₄₄，自對偶 mode 嘅能量**。

同時：γ₄₄(88-Laplacian) = 4sin²(π/2) = 4 = B（Nyquist）。**同一個 mode index 44 喺兩層 Laplacian 分別 = μ² 同 B** — 44 = N_d 就係自對偶位置。
