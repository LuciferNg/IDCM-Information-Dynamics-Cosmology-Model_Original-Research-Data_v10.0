## 1. 方法

### 1.1 化約（承 R7a/R7f）

固定 `(a, a′, b, b′)` 後，8 項 Mermin 多項式精確拆為 `M4 = F(d) + G(d′)`，其中

```
F(d)  = X[a,b,c,d]  − X[a′,b′,c,d]  − X[a′,b,c′,d]  − X[a,b′,c′,d]
G(d′) = X[a′,b′,c′,d′] − X[a′,b,c,d′] − X[a,b′,c,d′] − X[a,b,c′,d′]
```

（`X = E4`，單位 1/120）。寫成 A/R/U/V 形式（本輪實作所用；`(c,d)` 等表索引維度）：

```
A(c,d)   = X[a,b,c,d]      − X[a′,b′,c,d]
R(c′,d)  = X[a′,b,c′,d]    + X[a,b′,c′,d]
U(c′,d′) = X[a′,b′,c′,d′]  − X[a,b,c′,d′]
V(c,d′)  = X[a′,b,c,d′]    + X[a,b′,c,d′]
F[c,c′,d] = A(c,d) − R(c′,d)        G[c,c′,d′] = U(c′,d′) − V(c,d′)
```

於是有恆等 `max_(d,d′) M4 = max_d F + max_d′ G`（原始窗無任何 d/d′ 約束），故

```
全域 M4 最大 = max_(c,c′) [ max_d (A − R) + max_d′ (U − V) ]
```

即兩個 **max-plus 積**（`(62,62,62)` 廣播 + 沿 d 軸化約），每組 `(a,a′,b,b′)` 成本 ~1 ms。

### 1.2 不變式自檢（G6）

- A/R/U/V **分解恆等**：對 4 個聲明 6-tuple，`A[c,:] − R[c′,:]` 必須逐位元等於第三輪
  `fg_vectors` 的直接索引式（`F_dir`、`G_dir`）——本輪一切所繫之恆等，故獨立列出。
- 每分片自檢 `max|E4| = 120/120`、加速器對聲明 tuple 精確覆核 0 不符。

### 1.3 獨立驗證路徑（G1）

| 路徑 | 內容 | 為何獨立 |
|:--|:--|:--|
| ① 8 項直接枚舉 | 在達成 8-tuple 上以凍結 s-index 規則、精確 Python 整數重算 | 不經 A/R/U/V、不經分離 |
| ② 全 4-D 枚舉 | 對達成組 `(a,a′,b,b′)` 直接建 `(c,c′,d,d′)` = 62⁴ 陣列取極值 | 不經可分離恆等 |
| ③ 5 組恆等核對 | 5 個聲明組別：4-D 枚舉值 vs 可分離值 | 兩算法對打 |
| ④ 第三輪交叉 | 池值、放鬆憑證、達成值之不等式關係 | 跨輪、凍結 artefact |

## 4. 方法學新增（編號續第三輪，25–29）

25. **「池」可以是遮蔽物**：第三輪之「6 軸頂點池」把 n = 4 的超越完全遮住（池內 480 = 界，貌似
    飽和無超越）；全 62 軸空間一開，最大值 = 512 > 界。教訓：任何以「聲明池」為界的結論都必須
    標明池外未測，且池之選擇理由要寫成可審條件（本輪即為該義務之履行）。
26. **子集 + 達成者 → 等式夾**：若全域（弱約束）最大值在某配置達成，而該配置恰滿足較強窗之約束，
    則「較強窗之全域最大」= 全域最大，**毋須**重跑該窗的搜索（本輪 party 窗即如此取得 512）。
    此為昂貴搜索的省法，但必須**逐項精確驗證達成者之成員資格**（P1）。
27. **分片搜索的覆蓋即證據**：把外層空間按「首方有序對」分片，聚合時斷言「每對恰一次 + 外層計數
    = 62⁶」，比抽樣或計時更強——覆蓋是**可算**的，不是估的。
28. **多視窗耦合之精確 top-K 論證**：對極/相異約束下，最佳對必落在兩側之 top-K（K = 排除數 + 1），
    故毋須建 (c,c′,d,d′) 全 4-D 陣列；以全 4-D 枚舉在聲明組別覆核（本輪 5 組）即可入帳。
29. **同一輪內「跑出數字前」的實作修訂要留痕**：分片產物由修訂前原始碼產生、聚合由修訂後產生時，
    必須①說明修訂範圍（僅聚合/普查段）②以決定性重跑（D3）證明分片路徑逐位元穩定，而非僅口頭保證。
30. **★ 判決相關之計數必須寫成「存在式」**：任何「*嗰個*達成者具性質 X」之計數都係 tie-break 慣例之
    產物；退化極值下同一現象可有 392 / 880 / 1734 / 1794 四個「正確」值。正解 = 改問「**是否存在**達成
    者具性質 X」（本輪存在計數 11,318/46,080 = 24.56%，為四個慣例值之 12.9 倍），並以**兩個不同算法**
    重算該存在計數以證其慣例無關。
31. **★ 解釋另一支碼之計數差異要「逐字重現其慣例」**，唔止算法層：排序 tie 次序（`argsort(g)[::-1]`
    ≠ `argsort(-g)`）與 topk 實作（`argpartition` vs 全排序）都足以令同一計數由 880 變 1,734。做法 =
    把對方嘅 helper 逐字重抄一次，驗證能否**精確重現**其數字（本輪 `scripts/15` T1：880／392 兩者皆
    逐字重現 ⟹ 差異純屬慣例）。
32. **★ 預註冊預測之 FAIL 可以係發現本身**：`scripts/14` Q3 預測「兩種重建規則會重現 880／392」——
    如實 FAIL（1,734／1,794），而該 FAIL 正是 tie 退化之證據；隨即以新一支預註冊**判別性測試**
    （`scripts/15`）收口。**禁**把 Q3 事後改寫成會過嘅版本。

### 7.1 算法（零簡化）

每個外層組 `(a,a′,b,b′)` 建 `AB/RB/UB`（62×62 精確整數），用第四輪已獨立驗證之恆等式
`M4 = F(c,c′,d) + G(c,c′,d′)`（`F = AB[c,d] − RB[c′,d]`、`G = UB[c′,d′] − RB[c,d′]`），逐窗掃
`(c,c′,d)` 並以 **top-K 擴展論證**（K = 該窗 pair 約束數 + 1；`anti_str` 用 K = 3 附交換論證）取候選，
再列舉 top-K × top-K 組合施加窗約束；**每個得勝組另以完整 62⁴ 材化枚舉覆核**。
判決算術**全整數**（分母 120）；無 float、無 `fastmath`、無近似、無 tensor-core。
五窗語意：`raw_full`（無約束，d = d′ 合法）／`party`（每對內相異）／`eight`（八者兩兩相異）／
`anti_v3`（八者相異 ∧ 無對極對；= 第三輪 `eight_anti` 語意）／`anti_str`（最嚴：八者相異 ∧ 八者兩兩非對極）。
