## 二、(a) 相位層 🔴 — 無複相位自由度

**論證鏈**（`scripts/02_phase.py`：A1–A9；`scripts/06_escape.py`：N1/N4）

1. 階譜（A1）：{1:1, 2:1, 3:20, 4:30, 5:24, 6:20, 10:24}，|2I| = 120。**唯一** 2 階元素 = −1（中心）。
2. [2I, 2I] = 2I（完全群 ／ 完美群）⟹ Hom(2I, U(1)) 平凡 ⟹ **無**非平凡 1 維（相位）表（A3）。
3. 每一元素與其逆共軛（全 120 逐元素驗證，`scripts/06` N1：無共軛子之元素 = 0/120）⟹ 所有不可約特徵標**實值** ⟹ **無**真正複表（A5）。
4. 忠實 2 維表（純四元數）之 Frobenius–Schur 指標 ν = (1/120)Σχ(g²) = **−1**（四元數型，非複型），以 ν₂ = (Σχ² − 2|G|)/|G| 交叉核對（A5）；Σχ² = 120 = |G|、Σχ = 0。
5. 讀出 K[s][a] = sgn⟨u_a, R_s n₀⟩ ∈ {±1}：**實值符號**。−1 元素給出 2:1 旋量坍縮 2I → A5（階 60），係**旋量符號**而非 U(1) 角（A6b）。
6. ⟹ 凍結庫存內**不存在**複相位自由度；F1 之 (a) 條款（complex-phase dof）**不成立**（`scripts/06` N1）。

**IDCM 確實有連續相位扇區，但在凍結協定之外**：W-field Goldstone 相位模 θ，m_θ = 0、精確 U(1) 不變（O73 `docs/15_c_first_principles.md`；O144 `docs/17_photon_phase_mode.md`）。以 ±1 符號核**讀唔到**；把它加入讀出即「門 (C)」，見 §六。
