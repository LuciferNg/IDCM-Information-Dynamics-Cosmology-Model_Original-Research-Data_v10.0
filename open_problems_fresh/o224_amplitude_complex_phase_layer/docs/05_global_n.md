## 3. R7a — 第四方精確分離（定理級，池內外皆用）

8 項 Mermin 多項式對 n = 4 的精確分解：

```
F(d)  = +E4(a,b,c,d)  - E4(a',b',c,d)  - E4(a',b,c',d)  - E4(a,b',c',d)
G(d') = +E4(a',b',c',d') - E4(a',b,c,d') - E4(a,b',c,d') - E4(a,b,c',d')
M4    = F(d) + G(d')
```

⟹ `max_(d,d') M4 = max_d F + max_d' G`，`min_(d,d') M4 = min_d F + min_d' G`，故
`max_(d,d') |M4| = max( |max F + max G| , |min F + min G| )`（**必須取兩極值**，單側會漏）。
驗證：項表重組 ✓；對修正索引後的 brute force（全 62² = 3844 對）**10/10** ✓。
**推論**：全域問題化約為 **62⁶ 外層 + 兩條 62 向量極值**。

## 7. R7f — 無條件全域放鬆憑證

把 M4 = A(c,d) − B(c′,d) + C(c′,d′) − D(c,d′) 的每一括號以其自身極值放鬆：

```
A(c,d)  = E4(a,b,c,d)   - E4(a',b',c,d)        B(c',d)  = E4(a',b,c',d) + E4(a,b',c',d)
C(c',d')= E4(a',b',c',d') - E4(a,b,c',d')      D(c,d')  = E4(a',b,c,d')  + E4(a,b',c,d')

sup M4 ≤ max_c[Amax(c) − Dmin(c)] + max_c'[Cmax(c') − Bmin(c')]
inf M4 ≥ min_c[Amin(c) − Dmax(c)] + min_c'[Cmin(c') − Bmax(c')]
```

對**全部 62⁴ 外層 tuple** 精確計算（456 s）：

| 量 | 值 |
|---|---|
| U = sup M4 上界 | **768/120 = 6.4000**，於 (V00, E11, V00, F18) |
| L = inf M4 下界 | **−768/120 = −6.4000** |
| ⟹ \|M4\| ≤ | **768/120 = 6.4**（全 62⁸ 設定 tuple，無條件） |
| 已達成值（R7b/R7d） | 480/120 = 4.0 |
| **全域最大值區間** | **[4.0, 6.4]** |

驗證：支配性（U ≥ exact max 且 L ≤ exact min）4/4 樣本 ✓；`exact_inner`（(c,c′,d,d′) 全 4-D 暴力）與 T-構造一致 ✓；池外層版本 **640/120** 重現獨立 probe 值 ✓。
**未閉合**：6.4 > 4 ⟹ 憑證**不足**（負面結果照錄）。但相對平凡代數界 8 改進 20%，且把全域最大值**夾進有限區間**。

## 11. 方法學新增（編號接續第二輪，16–21）

16. **索引映射陷阱**：party *p* 的設定索引 = `2*(p-1)+bit`。兩個函數若共用同一錯誤映射，會互相「驗證」出假 PASS ⟹ 分離定理必須用**顯式索引**重建，並以獨立 brute force 核。
17. **兩極值鐵律**：`max|F+G| = max(|max F + max G|, |min F + min G|)` —— 只追蹤正極值會漏掉負向違反。
18. **raw 窗退化識別**：先檢查 argmax 是否由**重合設定**取得；是則該窗陳述無資訊（n = 4 即如此）。
19. **遮罩極值**：任何「界 + 窗口」路線都必須測遮罩版本（distinct / no-antipodal），否則會誤判界可用（R7c）。
20. **放鬆憑證 + 支配性驗證**：任何放鬆界必須 (i) 對精確 brute force **支配**（U ≥ max、L ≤ min），(ii) 以獨立 probe 校準小空間值，(iii) 明示是否足以閉合。
21. **精確化約 vs 放鬆**：固定 (a,a′,b,b′) 後 (c,c′,d,d′) 的極值可精確化約為 (d,d′) 上的兩項和；本輪放鬆之所以鬆 1.33 單位正是丟棄了 (d,d′) 的共享。這確立了 62⁶ 路線的成本結構。

### 13.5 方法學新增（續，22–24）

22. **並行 session 環境**：同一 open-problems 樹可能有多個 session 同時寫入各自目錄與共享 README ⟹ 任何「跨目錄唯讀」證明都必須用**內容雜湊 + 足跡歸因 + 原始碼掃描**，不可單靠 mtime 相等。
23. **決定性檢定必須宣告正規化**：含 wall-clock 的產物不可能逐位元相同；正確做法是宣告剔除哪些欄位，並對**決策投影**（claim 清單、ok 旗標、數值欄位）作逐位元比較。
24. **放鬆界的自我驗證三件套**：支配性（對精確 brute force）、獨立 probe 校準、一致性交叉檢查（兩條獨立構造路徑）；缺一即不可信。
