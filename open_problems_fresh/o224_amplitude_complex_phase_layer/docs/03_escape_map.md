## 二、門 (C)/(T) 之形式陳述

設凍結協定為 P₀ =（態空間 2I 左正則 120 態；讀出 {K_a}ₐ，K_a(s) = sgn⟨u_a, R_s n₀⟩；pair-local 因式表 ＋ memo；資源窗 all4）。
任何 P ⊇ P₀ 若滿足下列任一，即**唔再**係 P₀ 之讀出：

- P 之可觀測代數**非交換**（門 T）；或
- P 之讀出取值於 U(1)（非 {±1}），或於 ℝ 之連續集（門 C）。

**定理（本輪內容之重述）**：P₀ 之任何可觀測關聯皆古典（Bell-local）且**構造性**（λ = 初始態 ＋ 帳本歷史）；\max|S| 之精確全域最大 = 22/15 < 2；故越界**必然**要求 P ≠ P₀。此即 S3（零新參數/零新物件）與越界之不相容。

## 三、驗收條件（後繼協定若宣稱越界，須逐項通過）

1. **F1 檢查表**（本輪已操作化，`scripts/06` N6）
   - (a) 讀出代數非交換？**若非** ⟹ 立即古典封頂（複相位自由度不存在）。
   - (b) 存在二分（兩側互相交換、各非交換、態非乘積）？**若非** ⟹ 立即古典封頂（無張量因式）。
   - 校準要求：必須在 {2-qubit singlet, 3-qubit GHZ, 凍結機器, 古典乘積, 交換對} 上**精確重現** (T,T)/(T,T)/(F,F)/(F,F)/(F,F)，否則判準本身未校準。
2. **F2 檢查表**：任何宣稱之 max|S| > 2，須把「由該構造引入之複相位／張量結構」**定位回凍結域內**；定位唔到 ⟹ 按 F2 自身措辭為**偽**（本輪兩例：memo 對角短路、預算不可行 174.73×）。
3. **深度檢查**：λ 分解之深度 = 條件獨立片段數。決定性機器 ⟹ 深度 = 1（本輪已證）；宣稱深度 > 1 須顯式給出第二個**獨立**片段。
4. **四道硬測試**：① 零新參數成本明列 ② MC null（≥ 10⁷ 樣本／5σ，或**窮舉**替代）③ 樣本外盲測（先寫後跑）④ 結構剛性（h 洗牌／重標／泛用軸抽樣等電池）。

## 四、逃生後**保留**之結構（唔會失去）

- **值集量化**：±1 符號讀出之 1/15 量子係結構必然（V2/V7/V8）——後繼加入相位讀出後，量化**唔會**自動消失；此為「離散干涉存在、只係唔連續」之正面內容。
- **計數層**：44 = N_d 次讀取／輪、123/88 = 2·E_min、123/2 預算——純計數關係，與相位層無關，應保留為資源層之陳述。
- **60 行為類／log₂60 = 5.9069 bits**：中心 Z₂ 之 2:1 坍縮（憲章 B5）；此係**現協定**之隨機性上限，後繼擴張後需重新計算。
- **構造性 LHVM**：λ = 初始態（120 值、均勻）在 n = 2 **精確**重構全部非對角相關（3782/3782）——後繼協定若仍為確定性機器，此陳述形式上仍成立，但**唔再**是邊界（因為引入了新物件）。

## 五、最小越界構造（僅為規格示例，非本輪主張）

1. **門 C 單獨**：以內積值（或 Goldstone θ）作讀出 → CHSH 族**連續**存在 ⟹ 可調至 2√2。代價：+1 可觀測映射；需檢查是否仍守零參數（θ 之範圍、正規化是否為自由參數）。
2. **門 T 單獨**：兩個 2I 核、聯合讀出 K_{ab}(s,t) → 代數非交換 ⟹ 可承載 ℋ_A ⊗ ℋ_B。代價：+1 核；須聲明兩核之耦合（否則即為兩個獨立機器，無關聯通道）。
3. **C + T**：最小量子物件（2 qubit singlet ＋ 相位敏感設定）→ Tsirelson 2√2；此即憲章 §4 所排除之「唔屬域」物件。

★ 三項皆屬 O224 之 (a)/(b) 判決所界定之**域外**；本檔僅作**規格**，唔係本輪之構造主張。
