# O8 — 尺度半徑之謎 (節點影響範圍 vs 間距)

## 狀態: 🟢 已閉合

## 結論
節點影響半徑 = 節點間距/2π = 約化波長 λ̸ = 4.1526°。
冷斑 FWHM 4.17° (R8) = λ̸ + 平滑誤差 (0.4%); 去平滑後真實結構半徑 = 4.152° (0.01% 閉合, 三重獨立驗證 7/7 + 23/23 + 46/46 PASS)。
星系團真空 4.5-5° 係同一尺度嘅物質排除表現 (1.08-1.20× 緩衝)。

## 關鍵公式
- λ = 26.0913° (節點間距, A₅ 軌道, o1 群論閉合)
- λ̸ = λ/2π = 4.1526° (影響半徑 = 相位 1 rad 距離)
- ℓ = 180/λ̸ = 43.3 ≈ 44 = 2N_d (K_Chain 基本模式, -1.5%)
- HWHM_true = √(HWHM² − σ_smooth²·2ln2) → 4.152° (去平滑外推)
- 排除: 180/44 = 4.09° (1.5%), 26.09×ε = 4.03° (3.3%)
