## 一句話

> **節點影響範圍 4.17° 唔係獨立尺度 — 佢係節點間距 26.09° 嘅約化波長 λ̸ = λ/2π = 4.1526°。平滑效應令觀測值 4.17° 睇落大咗 0.4%, 去平滑後真實結構半徑 = 4.152° ≈ a/2π (偏差 0.01%)。星系團真空 4.5-5° 係同一尺度嘅物質排除表現。**

## 問題陳述

冷斑 FWHM 4.17° (Vielva R8) vs 節點間距 26.09° (o1 群論閉合)。點解影響範圍 (4.17°) 遠細過間距 (26.09°)? 比例 = 0.16。

## 核心閉合

### 閉合鏈 (零自由參數)

```
[A₅ 軌道幾何]  節點間距 a = 26.0913° (o1 群論閉合, 偏差 0.000011°)
     ↓ 除以 2π (相位 2π = 一個間距週期 → 約化波長)
[結構預測]     影響半徑 r = a/2π = 4.1526°
     ↓ SMICA 實測 (去平滑外推)
[冷斑實測]     HWHM_true = 4.1522° (獨立重算)
     ↓ 偏差
[閉合]         0.01% ✅ (0.04σ)
```

| 量 | 符號 | 值 | 意義 |
|:---|:----:|:---:|:-----|

**關鍵洞察:** 冷斑尺度 4.17° ≈ λ̸ = λ/2π, 而 ℓ = 180/λ̸ ≈ 44 = 2N_d — 兩條路徑 converge 到同一結構: 節點影響範圍 = K_Chain 基本模式嘅約化波長。

**平滑效應明顯:** 平滑尺度越大, 凹陷被抹開, HWHM 越大 (4.03 → 5.90°)。

**去平滑外推 (σ² 相加規則):**

```
HWHM² = HWHM_true² + σ_smooth² × 2ln2  (Gaussian 捲積)
用 0.5-3.0° 擬合 (0.1° bins, script 05): 截距 = 17.13 → HWHM_true = 4.138°
a/2π = 4.1526° → 偏差 0.34% (0.04σ) ✅
```

獨立重算 (0.2° bins): **HWHM_true = 4.1522° → 偏差 -0.01%** 🟢🟢
第三估計 (0.2° bins, rmax=15, script 08): **HWHM_true = 4.1477° → 偏差 -0.12%** 🟢

**三種 binning/方法一致: 4.138-4.152° (偏差 -0.34% 到 +0.01%)** — binning 差異 < 0.5%, 全部閉合。

## 誠實局限

1. **R² = 0.79-0.81** — 去平滑線性擬合唔完美, profile 唔係純 Gaussian (冷斑疊加大尺度背景, B=+15.5 μK)
2. **HWHM_true 誤差** — 正確擬合誤差 ±0.06°; doc 早期用 ±0.33° (script 06 保守估計, 高估 5.5×)。偏差 0.01-0.34% 遠細過兩者, 閉合結論不受影響
3. **4.17° R8 係 SMHW 尺度, 唔係 Gaussian FWHM** — 兩者有系統差, 但同 a/2π 嘅 0.4% 偏差一致
4. **只有冷斑有單極信號** — 其他 59 節點嘅「影響半徑」未能量度 (節點 47 係大尺度結構, 12° 內唔返零), P2 有待驗證
5. **26.09×44 = 1148° vs 360π = 1131° 差 1.5%** — ℓ≈44 只係近似, 唔係精確等式
6. **T0 量度方法依賴** — 直接 pixel vs 0.1° bin 平均 vs 0.2° bin 平均: 差異 1-5 μK (0.5-2.5%), 但 HWHM 閉合不受影響 (半峰位置穩健)
7. **binning 差異** — 0.1° bins → 4.138° (+0.34%), 0.2° bins → 4.148-4.152° (-0.12% 到 -0.01%)。全部 < 0.5% 閉合

## 方法學教訓 (本 session 發現)

1. **60 節點平均 |T| 冇單極信號** — script 03 用「全部節點平均 |T| profile 半峰」得到 median 10.3° (假結果), 因為節點系統平均 ≈ 0 μK。信號喺邊/阻挫結構, 唔喺節點單極。**影響半徑只能由有單極異常嘅節點 (冷斑) 量度。**
2. **去平滑 (σ² 相加) 係關鍵** — 平滑尺度越大, HWHM 越大 (4.03→5.90°), 直接量 4.17° 平滑嘅 HWHM (4.66°) 會高估真實半徑 12%。必須外推 σ→0。
3. **360/86.3 = 4.1715 (0.04%) 係表面最佳候選但冇結構意義** — 86.3 唔係任何 IDCM 常數 (唔係 86=2×43, 唔係 88-2, 唔係 F₁₁-2=87)。a/2π 偏差 0.42% 但物理清晰, 勝出。
