## 1. 路線 2 — 176-Laplacian (88-site half-site D-D 鏈) 譜密度

### 1.1 慣例核對 (O159 慣例坑: 分母 176 vs 178 唔好混)

```
矩陣: diag(3, 2, ..., 2, 3), off-diag −1, N = 88 sites   (half-site D-D)
數值對角化 (numpy eigvalsh) vs 解析 4sin²(kπ/176), k = 1..88:  max|Δ| = 2.22e-15
Σ譜 = 178.0000000000 = 2F₁₁ = 2·89                        (O159 BC 跡, 重現)
譜 ≡ 88-環相異譜 {2 − 2cos(kπ/88)}                         (同一集合, max|Δ| < 1e-12)
```

### 1.2 冪和 (O192 定理 N = 88 分支)

```
Σ_{k=1}^{88} λ_k^m = 88·C(2m,m) + 2^{2m−1}     (m = 1..20 全部 ✓)
```

### 1.3 ★ 連續極限譜密度 ≡ arcsine (第一原理導出)

```
λ(k) = 2 − 2cos(πk/88)   ⟹  k(λ) = (88/π)·arccos(1 − λ/2)
歸一化態密度:  ρ(γ) = (1/88)·|dk/dγ| = 1/(π√(γ(4−γ)))      (arcsine on [0,4])
```

## 2. 路線 3 — 投影核 (O180)

### 2.1 身份重現

```
θ_k = kπ/176;  r_k = 2πR_world·cos²θ_k;  v_k = c·cosθ_k;  a₀ = c²/(2πR_world)
max_k |v_k²/(a₀ r_k) − 1| = 5.35e-51        (O180 身份重現 ✓)
```

### 2.2 ★ 重量盲 (O180 §2.2 自己嘅結果, 本 O 用作路線 3 之判決)

```
Σ w_k·v_k / Σ w_k·√(a₀ r_k) = 1.000000000000
   w = uniform  → 1.0
   w = γ-weight → 1.0
   w = γ²-weight → 1.0
```

**核只固定映射 k ↦ (r, v); 密度係自由輸入** (O180: 「權重只決定面密度 Σ(r)」)。

> ⟹ 路線 3 **結構上唔可以提供測度** — 佢提供嘅係幾何映射, 唔係 ℓ-軸密度。
> 呢個係路線 3 最重要嘅結果, 而且係 O180 自己已經記錄嘅性質。

### 2.3 冇 ℓ_m-內容

投影核輸出係 (r_k, v_k) 空間量 (盤半徑 / 速度), 完全冇 CMB 多極矩 ℓ_m。
O180 文檔中出現嘅 ℓ 係 **FSR 精化層數** (R_world/44^ℓ 級聯), 唔係多極矩。

