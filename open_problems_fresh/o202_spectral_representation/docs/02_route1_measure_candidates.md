## 1. 方法

### 1.1 IDCM 離散譜 (O9 公式, 零手調)

```
ℓ_m = 44·(33 − C(9−m,2)) + ((m−1)·9 mod 25)      m = 1..7,  ℓ_5 = 1121 (O9 結構修正)
   → 220 / 537 / 810 / 1014 / 1121 / 1340 / 1412
峰高母函數 (O9/O10 零參數):
  偶峰 A_{2k}/A_1 = ((k+1)/(4k−1))²  → 4/9, 9/49, 16/121
  奇峰 A_3 = (2/3)², A_5 = 3/14, A_7 = 1/7
錨定: A_1 = TGT = (ε_φ⁵/8 · T_CMB)² = 899.973474 μK²
```

### 1.2 兩個錨定約定 (必須分開報, 唔可以只報靚嘅一個)

| 約定 | 定義 | 物理讀法 |
|:--|:--|:--|
| **peak** | A_m = TGT·ρ_m | 錨定**第一峰**高度 (ε⁵/8 係峰高) |
| **plateau** | A_m = TGT | 錨定**平台**高度 (ε⁵/8 係背景平台) |

### 1.3 測度作用

```
Var_M = Σ_m w_m · (2ℓ_m+1)/(2ℓ_m(ℓ_m+1)) · A_m          [μK²]
判準: |Var_M / Σ_obs − 1| < 5%   (Σ_obs = 12271.55091 μK², Planck PR3 TT full ℓ=2..2508)
```

### 1.4 候選族 (11 個, 全部由結構導出, 冇手調)

| # | 測度候選 | 定義 | 來源 |
|:--|:--|:--|:--|
| M1 | counting | w = 1 | 每峰 1 個 ℓ-mode |
| M2 | ring-Nyquist | w = N_d = 44 | 88-環角 Nyquist |
| M3 | rung spacing | w = 44(8−m) | O9 Δ_m |
| M4 | sky modes | w = 2ℓ_m+1 | 天球簡併數 |
| M5 | proj kernel | w = cos²θ_m | O180 r_m = 2πR cos²θ |
| M6 | spectral weight | w = γ_m | 88-環譜 |
| M7 | FSR cascade | w = 4^(m−1) | O140 N_ℓ = N·4^ℓ |
| M8 | log-ℓ uniform | w = ln(ℓ_m/ℓ_{m−1}) | 標度不變測度 |
| M9 | half-Nyquist | w = N_d/2 = 22 | Z₂ pair |
| M10 | Z₂ multiplicity | w = μ² = 2 | Z₂ 簡併 |
| M11 | Voronoi partition | w = 相鄰峰中點間距 | 合法 ℓ-軸分拆 |

## 3. 可容性篩 (admissibility screen) — 為何必要

一個「ℓ-軸測度」= ℓ-軸上嘅一個分佈 ⇒ 必須滿足:

```
(i)   w_m ≥ 0
(ii)  頻帶 [ℓ_m − w/2, ℓ_m + w/2] 唔可以重疊 (每個 ℓ-mode 只可計一次)
(iii) 總覆蓋 ≤ 可用 mode 數
```

★ **M4 係呢個篩嘅關鍵案例**: 佢係唯一通過 5% 判準嘅組合 (plateau 錨, +2.674%),
但 w = 2ℓ_m+1 = 441..2825 而峰間距只有 176..308 ⇒ 頻帶重疊 4.57×
(Σw = 12915 vs 覆蓋跨度 ~2825) ⇒ **唔係一個測度, 係雙重計數**。

> **方法論教訓 (可推廣)**: 「命中」必須先過可容性。一個唔可容嘅候選命中, 唔係證據,
> 係一個 warning — 佢通常代表公式用錯咗物件 (呢度: 簡併數 ≠ 頻寬)。

## 5. ★ 新發現 — 「總圖方差」唔係良定義觀測量 (M1 ill-posed)

flat / Harrison-Zel'dovich 讀法: 若 ε⁵/8 係**平台高度** D_ℓ = TGT = 900 μK², 則

```
Var_flat(ℓ_max) = TGT · Σ_{ℓ=2}^{ℓ_max} (1/ℓ + 1/(ℓ+1))        (對數發散)
```

| ℓ_max | Σ w_ℓ | Var_flat (μK²) | dev vs 觀測 |
|--:|--:|--:|--:|
| 500 | 11.0876 | 9978.58 | −18.685% |
| 1000 | 12.4719 | 11224.42 | −8.533% |
| 1500 | 13.2822 | 11953.63 | −2.591% |
| 2000 | 13.8572 | 12471.14 | +1.626% |
| **2508** | 14.3097 | 12878.36 | **+4.945%** |
| 3000 | 14.6678 | 13200.66 | +7.571% |
| 4000 | 15.2430 | 13718.32 | +11.790% |

**三個結論**:

1. 唯一「邊緣命中」(ℓ_max = 2508, +4.95%) 係 flat/HZ 讀法 — 但呢個讀法**唔係** IDCM 離散譜
   (係額外假設「有平坦包絡」= R6 缺失嘅物件)
2. dev 喺 ℓ_max = **1790** 過零 (精確二分: var(1789) = −0.008%, var(1790) = +0.0002%)
   ⇒ 「命中」純粹係 ℓ_max 選擇 artifact
   (O202 初報 ~1750 係粗插值; O171 獨立細掃 + O202 二分重算一致得 1790)
3. **最重要**: 總圖方差隨 ℓ_max 對數發散 ⇒ 佢**唔係**一個物理觀測量 (取決於實驗上截)。
   ⇒ O171 M1 嘅「全譜 rms vs ε⁵/8 = 3.69262×」係一個唔良定義嘅比較, 唔可以作為
   「錨唔對應」嘅證據 —— 應該改用**頻帶限制**或**峰高**比較 (見 docs/05)。

### 5.1 退化性 — 命中總方差唔構成測度證據

隨機可容分拆 (7 個連續頻帶, 隨機指派給 7 個峰, 錨定約定) 400 trial:
命中 (|dev| < 5%) **1 次 = 0.2%**。⇒ 總方差係一個超平面, 有無限多測度可以精確命中,
命中本身唔係測度結構嘅證據。
