## 1. 頻帶選擇審計 (M2/M3 之精確化)

### 1.1 全掃描

```
|dev| < 1% 之頻帶: L = [6]      (唯一)
|dev| < 5% 之頻帶: L = [6]      (唯一)
最佳: L = 6, dev = −0.8491%
結構截斷 (29 個結構數): 命中 0 個
```

### 1.2 檢定力 (為何「0.85% 吻合」無意義)

```
L = 6 頻帶: N = Σ_{ℓ=2}^{6}(2ℓ+1) = 45 個模態
總功率自由度 = N = 45 ⇒ CV(功率) = √(2/N) = 21.08%
⇒ CV(rms) = √(2/N)/2 = 10.5409%
⇒ 一致性 = 0.8491 / 10.5409 = 0.081σ
```

⚠️ **交回 O171 M2**: O171 docs/24 §1 引「一致性 = 0.040σ」— 本 O 由零重算得 **0.081σ**
(CV 慣例差: 功率層 21.08% vs rms 層 10.54%; 兩者都 ≪ 1σ, 結論不變, 但數字應更新)。

### 1.3 結論

> 唯一命中嘅頻帶 (ℓ ≤ 6) **唔係結構截斷**, 佢係「低四極偏低」呢個數據特徵嘅產物;
> 而且 45 個模態嘅宇宙變異 = 10.5% ⇒ 任何落在 ±10% 內嘅預言都會「吻合」。
> ⇒ 該吻合**唔可以作為 ε⁵/8 嘅驗證**。

## 2. Look-elsewhere — ε-家族審計

```

```

| 目標 | target | 命中 | 成員 | enrichment | p |
|:--|--:|--:|:--|--:|--:|
| 低ℓ頻帶 rms (ℓ=2..6) | 1.091361e-5 | 1 | (ε_φ, k=5, d=8) | 2.9× | 0.32 |

| 全圖 rms | 4.064496e-5 | 0 | — | 0 | — |
| SW 平台 √D̄(2..20) | 1.037432e-5 | 0 | — | 0 | — |

null control: 400 隨機 target U(3e-6, 3e-5) → 平均命中 0.345 個組合;
P(≥1) = 0.320, P(≥2) = 0.025。

**誠實讀法**:
- 指數 k **唔係**自由度 (ε^(k+1)/ε^k = 6.47 ⇒ 只有一個 k 接近任何 target)
- 但除數 d 有 18 個候選 (跨 44 倍) ⇒ look-elsewhere 自由度 = 18
- 冷斑 p = 0.025 名義 2.2σ, 但 (a) 4 個 target 校正後 ≈ 0.10; (b) 家族自身含框架常數
  ⇒ 唔係乾淨 null ⇒ **唔可以宣稱冷斑吻合係證據**
- ★ 冷斑同時被 **兩個** 成員命中 (ε_φ⁵/9 同 ε_ring⁵/8) ⇒ 多身份問題 (「密度背景」之另一面)

## 3. ε-成員指派審計 (零參數宣稱之致命點)

| 觀測量 | ε_φ 預言 | dev | ε_ring 預言 | dev | 選中 |
|:--|--:|--:|--:|--:|:--:|
| 低ℓ頻帶 (29.7448 μK) | 30.000 | **−0.849%** | 26.889 | +10.620% | ε_φ |
| 冷斑 (134.2 μK) | 149.998 | −10.532% | 134.446 | **−0.183%** | ε_ring |

```
ε-家族 = {ε_φ = (√5−1)/8, ε_ring = 13/86},  相差 11.57%
兩觀測量各自揀**唔同**成員 ⇒ 成員指派係**數據驅動** ⇒ 2 bits 自由度
⇒ 「零參數」宣稱失效, 除非有獨立選擇規則 (R7 🔴)
```

### 3.1 數域分離 (證明兩成員唔可以互相取代)

```
ε_φ = (√5−1)/8 ∈ Q(√5)   (次數 2)
ε_ring = 13/86 ∈ Q        (次數 1)
ε_φ⁵/ε_ring⁵ = 1.115674063...  (無理 ⇒ 冇有理關係)
ε_φ⁵/8 = 2^(−13)·φ^(−5)   ⇒ 指數對 (13, 5) = (F₇, F₅) 係**包裝**, 唔係推導
```

### 3.2 指數 5 之不可鑑別性

```
「指數 = 5」喺常數庫內有 ≥ 6 個身份: F₅ / B+1 / N_gen+μ² / L₄−μ² / 5 / ...
⇒ 即使將來導出「指數 = X」, 都唔可以鑑別 (X = 5 有太多身份)
⇒ R7 嘅可驗證性本身有問題 (唔止未導出)
```
