## 1. ★ 新結果 A — 精確仿射橋 (投影核 ↔ 譜變數)

```
γ_k = 4sin²(θ_k),  θ_k = kπ/176
⟹ cos²(θ_k) = 1 − γ_k/4
O180 投影核: r_k = 2πR_world·cos²(θ_k)
⟹ ★ r_k = 2πR_world·(1 − γ_k/4)                     (EXACT, k = 1..88)
   驗證: max_k |cos²θ_k − (1 − γ_k/4)| < 1e-35
```

**意義**: 投影半徑**唔係獨立幾何量**, 佢係 Laplacian 特徵值之**仿射函數**。
即 O180 之 cos²-核與 88-環譜之間冇額外自由度 — 兩者係同一個物件之兩種寫法。

## 2. ★ 新結果 B — 核係「測度保持」(arcsine → arcsine)

```
ρ_γ(γ) = 1/(π√(γ(4−γ)))         on [0,4]
r = 2πR(1 − γ/4)  ⟹  γ = 4(1 − u),  u = r/(2πR)
ρ_r(r) = ρ_γ(γ(r))·|dγ/dr| = 1/(2π²R·√(u(1−u)))     → 仍係 arcsine on [0, 2πR]
```

**推論 (雙面)**:

- 🔴 **負面**: 核係測度保持 ⇒ **唔提供新信息**; 標度仍自由 ⇒ 核本身**唔可以提供 ℓ-軸密度**
