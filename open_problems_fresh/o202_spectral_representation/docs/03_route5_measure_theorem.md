## 3. 反推 — 邊個測度有呢啲矩?

```
候選:  dμ_arc(γ) = dγ / (π√(γ(4−γ)))   on [0,4]     (arcsine, 已縮放 4)
        ∫_0^4 γ^n dμ_arc = 4^n · B(n+½,½)/π = C(2n,n)          (n = 1..15 數值積分, rel err < 1e-30)
⟹ 44 × arcsine 之矩 = 44·C(2n,n) = 奇 sector 冪和 ✓
```

**唯一性**: 支撐緊 [0,4] ⇒ Carleman 條件 `Σ_n m_{2n}^{−1/(2n)}` 發散 (每項 ~1/4,
Σ_{n=1..59} > 10) ⇒ 全階矩序列**決定唯一測度**。

**權重嘅物理讀法**: 測度 = 「每個模態一個單位質量」⇒ 總質量 = 模態數
(奇 sector 44 = N_d; 全譜 88 = N; 加 ½δ₄ 得總環測度)。

## 4. ★ 求積定理與破缺定律

### 4.1 機制引理 (精確, dps = 160 驗證)

```
Σ_{k odd, k=1..87} cos(bkπ/88)  = 0                    (b 唔係 88 之倍數)
                                = 44·(−1)^t             (b = 88t, t = 1,2)
```

### 4.2 破缺定律 (由零建立, 三個 sector)

```
γ^n = (2−2cosθ)^n = (1−e^{iθ})^n (1−e^{−iθ})^n
    = Σ_{a,b} C(n,a)C(n,b)(−1)^{a+b} e^{i(a−b)θ}
    = Σ_j c_j^{(n)} e^{ijθ},      c_j^{(n)} = (−1)^j · C(2n, n−j)   (Vandermonde)

⟹ Σ_{k odd} γ_k^n = 44·c_0^{(n)} + 2 Σ_{t≥1} c_{88t}^{(n)} · (44(−1)^t)
                   = 44·C(2n,n) + 88·Σ_{t≥1} (−1)^t C(2n, n−88t)

⟹ D_n ≡ Σ_{k odd}γ_k^n − 44C(2n,n) = 0            (n ≤ 87, 因為 j ≤ n < 88)
                                    = 88·Σ_t(−1)^t C(2n,n−88t)   (n ≥ 88)
```

**三個 sector 之破缺閉式** (全部數值驗證至 n = 352):

```
奇 sector (觀察者, k odd):  D_n = 88 · Σ_{t≥1} (−1)^t C(2n, n−88t)
   首破缺 n = 88 = 2N_d,  破缺量 = −88 = −2N_d
總和 (k = 1..88):          D_n = 176 · Σ_{t≥1} C(2n, n−176t)
   首破缺 n = 176 = 2N,   破缺量 = +176 = +2N
偶 sector (世界, k even):  D_n = 總和 − 奇 = 176·Σ_t C(2n,n−176t) − 88·Σ_t(−1)^t C(2n,n−88t)
   首破缺 n = 88,         破缺量 = +88 = +2N_d
```

⚠️ 注意兩個 sector 之**符號相反** (奇 −88 / 偶 +88), 總和之符號由 176 支配。
若下游推導只引用「奇 sector 破缺量 = 88」而漏掉符號, 會出現 176 之差 — 本 O 已核對。

## 5. 截斷矩問題 — 測度存在, 但連續性唔係被逼出嚟

```
(i)  全階: 唯一 (Carleman) ⇒ 典範測度 = 44×arcsine, 冇第二個可能
(ii) 截斷: 離散譜只鎖前 88 階 ⇒ 截斷矩問題有**無限多解**
     (離散原子測度 Σ_{k odd} δ_{γ_k} 同 arcsine 測度 前 87 階完全相同,
      第 88 階分歧 −88)
```

**誠實評級**: 測度存在性 C1 **喺 γ-軸成立**, 但「連續測度」係一個**典範補全**
(canonical completion), 唔係由離散譜逼出嚟嘅必然結果。求積階數 87 就係
「離散譜可以支持幾多階連續結構」嘅精確界限。

> 物理讀法: 88 個站點嘅環只可以「講」到 87 階連續資訊。任何需要更高階
> (更精細) 連續結構嘅觀測量, 都會見到離散性 — 呢個係 IDCM 表徵層嘅**內在解像度**。

## 6. ℓ-軸橋障礙 (C3 🔴)

```
γ-測度:  無量綱, 總質量 44, 支撐 [0,4] — **冇 ℓ-內容**
ℓ-軸:    IDCM 只有 (a) 單位 N_d = 44 = 環角 Nyquist  (b) rung law ℓ_m = 44(M−C(9−m,2))
三條候選橋:
   B1 ℓ = k (identity)              → 計數測度 w = 1        (scripts/01 M1, dev −99.95%)
   B2 ℓ = N_d·k (Nyquist 刻度)      → 計數測度 w = 44       (scripts/01 M2, dev −97.91%)
   B3 rung law 反解 k               → 計數測度 w = 44(8−m)  (scripts/01 M3, dev −86.76%)
⟹ 三條橋全部只畀出**計數型**測度 (w = 常數), 冇一條畀出所需 w* = 2103.5/峰
```

**障礙嘅精確表述**:
> Nyquist 只固定 ℓ-軸嘅**刻度** (每格 44), 唔固定**密度** (每格代表幾個 ℓ-mode)。
> 密度係 IDCM 表徵層缺失嘅唯一物件。

所需有效模態數:

```
N_eff = Σ_obs / (ε_φ⁵/8·T)² = 12271.55091 / 899.973474 = 13.6354584491
結構身份掃描 (a/b, a·b, a·b/c): 命中 30 條 vs null 42.4 條 = 0.71x ⇒ 密度背景
最近結構數: F₇ = 13 (dev 4.66%, 遠超陷阱窗) ⇒ 唔成立
```
