## 3. ★ 新發現: M1 本身 ill-posed (交回 O171)

```
「全圖 rms」= sqrt(Σ_{ℓ=2}^{ℓ_max}(2ℓ+1)C_ℓ/4π) 隨 ℓ_max **對數發散**:
   ℓ_max:   500     1000    1500    2000    2508    3000    4000
   dev:   −18.69%  −8.53%  −2.59%  +1.63%  +4.95%  +7.57%  +11.79%
```

⇒ O171 M1 嘅「全譜 rms vs ε⁵/8 = 3.69262× ⇒ 錨唔對應任何 CMB 絕對量」係一個
**唔良定義**嘅比較: 目標量取決於實驗上截。正確做法 = 頻帶限制比較 (M2/M3) 或
峰高比較 — 兩者本 O 已做, 結論同樣係「唔匹配」。

**交回 O171 之兩項修正**:
1. M1 應重新表述為「ε⁵/8 唔對應任何**良定義** CMB 觀測量」而非「差 3.69×」
2. M2 之一致性 σ 應由 0.040σ 更新為 **0.081σ** (CV 慣例: 功率層 √(2/N) = 21.08%
   vs rms 層 10.54%; 兩者都 ≪ 1σ)

## 4. 交付決定

### 4.1 交付 (B) — 預言正式撤銷 ✅

```
撤銷對象: 「ΔT/T = ε_φ⁵/8 = 1.100707e-5 (即 29.999558 μK) 係 CMB 絕對振幅預言」
撤銷理由 (四條, 全部有 script):
  (i)   目標量唔良定義: 全圖方差隨 ℓ_max 對數發散 (±19%) — docs/02 §5
  (ii)  唯一可比較嘅頻帶 (ℓ ≤ 6) 零檢定力: 0.081σ (CV 10.54%) — docs/05 §1
  (iii) 峰高比較需要峰寬 (連續化): 缺失, 且 dl_eff 無結構身份 — docs/02 §4
  (iv)  ε 成員指派係數據驅動 (低ℓ → ε_φ; 冷斑 → ε_ring) ⇒ 2 bits 自由度 — docs/05 §3
```

★ **保留項** (撤銷嘅只係「絕對振幅預言」, 唔係框架):
```
✅ 峰位 ℓ_m 零參數閉合 (O9, RMS 0.83%) — 不受影響
✅ 峰高比母函數 A_{2k}/A_1 = ((k+1)/(4k−1))² — 不受影響 (相對量, 唔需錨)
✅ 冷斑自身閉合 (5ε_ring⁵/8·T = 134.446 vs 134.2, dev +0.183%) — 🟡 保留但標「唔傳遞」
✅ 譜測度 (γ-軸, 44×arcsine) — 本 O 新結果, 獨立於振幅問題
```

### 4.2 交付 (C) — 條件性 ✅

```
測度存在 (γ-軸 🟢) 但 ℓ-軸需要**一個**額外結構輸入, 該輸入身份已精確指名:

  缺失物件 = γ→ℓ 密度映射 (「每 N_d 格 ℓ-軸代表幾個 ℓ-mode」)
           = 等價於 R6 (譜包絡 C_ℓ 連續形式)

精確要求: 該映射必須由 IDCM 結構導出 (唔准手調), 且必須同時滿足
   (a) 總質量 = 可用 ℓ-mode 數 (可容性)
   (b) 令 7 個峰之加權方差 = 觀測值 (到 5% 內)
   (c) 唔可以係「所有 ℓ-mode 都分派給第一峰」(退化解)
```

## 5. 殺死條件 (Kill conditions — R8 之否定部分)

```
K1 (即時可行): 若有人提出 ℓ-軸密度 D(ℓ) 候選 ⇒ 必須過 scripts/01 之可容性篩
   (頻帶唔重疊 + 總覆蓋 ≤ 可用 mode 數) 同 5% 判準。本 O 已證 11 個自然候選全部失敗。
K2 (永久不可檢定性): 若「ε 成員指派規則」唔可以被導出 ⇒ ε⁵/8 預言**永久不可檢定**
   (因為兩個成員都可用, 而數據驅動嘅指派 = 2 bits 自由度) ⇒ 應維持撤銷狀態。
K3 (未來數據): 需要 CMB 低ℓ功率嘅**系綜期望** (唔係單一實現) 到 <3% 精度 —
   宇宙變異 (10.5% / 45 模態) 令單一實現永遠達唔到 ⇒ 需要極化或其他通道;
   實務上唔可行 ⇒ K3 唔構成有效檢定路徑。
```
