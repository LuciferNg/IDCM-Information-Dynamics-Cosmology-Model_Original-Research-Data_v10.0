## 三、T2 — κ_{2m} Rayleigh 分母 11-adic 側 (🔴→🟢 閉合: 兩定理)

即: **κ_{2m} ≢ 0 (mod 11) ⟺ 11-free(m) ∈ {1,2,3,5}**。

```

             = {1,2,3,5}·11^j (j=0,1,2,...) — Fibonacci 基底 × 11 冪
```

**機制**: κ_{2m} = C(2m,m) − Σ C(2m−1,2k−1)·C(2m−2k,m−k)·κ_{2k} 遞迴
(O195 Thm 2) 喺 mod-11 嘅封閉性。κ_{2·11k} ≡ κ_{2k} (mod 11) 收縮
(m≤1000 全 PASS) — 11 冪只係「複製」κ_{2k} 嘅 mod-11 值。

## 五、T4 — α=0 嚴格證明 (🔴→🟢 閉合: Darboux 級)

### 定理 T4: 兩根干涉吸收 log 分支 1/n

**sin(δ) = Re(r₁)/R 精確** (δ = arcsin ε, ε = Re/R = 0.0061148)。

Darboux 論證鏈:
1. artanh(δ) 最近奇異點 = δ=±1 根 r₁, r₂ (log 分支點, O195/O196)
2. r₁ = Re + i·Im, r₂ = −Re + i·Im = −r̄₁ (實部鏡像對) ⟹ θ₁ = π/2 − δ
3. log 分支 ⟹ 單根貢獻 a_n^(r) ~ c·r^{−n}/n
4. 奇 n 兩根干涉: a_n ~ (c/2n)R^{−n}(e^{−inθ₁} + e^{inθ₁}) = (c/n)R^{−n}·cos(nθ₁)
5. **cos(nθ₁) = cos(nπ/2 − nδ) = ±sin(nδ)** (精確恆等, n 奇)
6. **sin(nδ)/n = δ·sinc(nδ) → δ (nδ→0)** — log 分支 1/n 因子被 δ 吸收!
7. ⟹ **a_n ~ ±c·δ·R^{−n} — α=0 主導**, 唔係 log 奇異點嘅 α=1

**O196 scripts/06 觀察機制化**: a_n·Rⁿ·n 線性上升 (0.134@11 → 0.929@79)
= c·sin(nδ) 嘅線性區 (nδ 細) — 唔係「log 奇異點收斂」, 係 sin 干涉。
