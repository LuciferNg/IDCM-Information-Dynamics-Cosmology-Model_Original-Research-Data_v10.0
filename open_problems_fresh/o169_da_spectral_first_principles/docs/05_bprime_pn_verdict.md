## 1. 判定準則 (三問)

### Q1 結構角色: P_n 嘅 `n` 同伸長嘅 `ℓ` 係咪同一個「層索引」?

```
伸長 (O76/O51):  ℓ = log₄(1+z)           — 距離/尺度投影嘅層索引 (連續, ℓ ≥ 0)
P_n  (v9.0 65):  n = K_Chain mode 索引   — 質量分配嘅層索引     (離散, n ∈ [1, 44])
```

**索引定義唔同** (連續尺度 vs 離散 mode)。

**但**文檔明確宣稱兩者共用**同一個每層因子**:

| 出處 | 原文 |
|:-----|:-----|
| `o116/docs/02_verification_report.md:58` | 「v9.0 的 CY₃ 投影算子 P_n 與 v10.0 的 K_Chain 質量分配 P_n 為**同一結構**」 |
| `o116/docs/02_verification_report.md:59` | 「**2φ⁻¹** 作為**跨尺度幾何不變量**, 在兩框架中一致」 |
| `o116/docs/02_verification_report.md:20` | 檔名 `65_projection_jacobian_micro.md` = 「P_n 推導」→ 自稱 **projection jacobian** |
| 同上 | 「✅ **跨尺度自相似**」(cross-scale self-similarity) |

→ **Q1 判定**: 索引唔同, 但**宣稱嘅「每層因子」係同一個 2φ⁻¹** ⇒ 角色層面同一結構對象。

### Q2 導數身份: `2φ⁻¹` 係咪「每層增益」呢個被證偽嘅對象?

```
舊宣稱「每層增益」  = 2φ⁻¹ = 1.2360679775
O169 自由擬合       = a = 0.994278 ± 0.04951   →  距 2φ⁻¹ = 4.88σ  ← 排除
新結構身份          = ⟨γ⟩_odd/2 = Σγ_odd/N_d = 44/44 = 1  EXACT
```

`P_n` 嘅線性係數**數值上就係 2φ⁻¹**, 而文檔明言其語義 = 「跨尺度自相似嘅投影 jacobian」,
即**同一個「每層增益」**。

→ **Q2 判定**: 🔴 同受證偽。

### Q3 承載性: `P_n` 嘅數值輸出喺現行 v10.0 鏈仲有冇承載?

## 2. ★ B′ 判定

> **`P_n = 1 + 2φ⁻¹n + K₂n²` 屬 A 類 (受證偽), 唔係 B 類。**

理由:
1. 文檔明確自稱 **"projection jacobian"** + **"跨尺度自相似"** —— 即宣稱質量層與距離層共用同一每層因子;
2. 線性係數**數值** = `2φ⁻¹` = 被證偽嘅「每層增益」;
3. O169 新結構喺**同一個 K_Chain 譜機制**上給出斜率 `⟨γ⟩_odd/2 = Σγ_odd/N_d = 1` ——
   即兩層共用嘅每層增益係 **1**, 唔係 `2φ⁻¹`。

> **但 P_n 嘅數值後果已被 v10.0 隔離。**
> 清理工作 = 移除 `P_n` 作為「推導來源」嘅**語言** + 清走 `6.5030` 殘留, **唔係改任何結構比率**。
