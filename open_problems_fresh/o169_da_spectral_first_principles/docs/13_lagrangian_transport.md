## 一、結果: 鏈模態 = 質量標量模 (單一 Lagrangian)

**★ 識別**: 鏈嘅 44 個模態係一個**共同頻率**嘅質量標量場模態:

```
omega_n = mu^2 = 2                     (頻率, 全部 n 相同 — 單一 Lagrangian)
k_n     = mu^2 * cos(theta_n)          (動量)
m_n     = mu^2 * sin(theta_n)          (質量)
theta_n = pi*n/88 = pi*n/(2*N_d)       (譜角, n = 1..44)

=>  omega^2 = k^2 + m^2   EXACT         (max dev = 9.18e-41, n = 1..44)
=>  m_n^2   = mu^4 sin^2(theta_n) = gamma_n   (Laplacian 譜) EXACT
```

**Lagrangian**:

```
L_n = (1/2)(d_t phi)^2 - (1/2)(d_x phi)^2 - (1/2) gamma_n phi^2
EOM: d_t^2 phi - d_x^2 phi + gamma_n phi = 0   =>   omega^2 = k^2 + gamma_n   (逐 n 驗證)
```

即: **一個質量標量場 Lagrangian，質量譜由 88-環 Laplacian 嘅譜 γ_n 給出**，
頻率 ω = μ² = 2 係**共同常數**（唔係逐模自由參數）。

## 二、群速度與延遲權重 (場論身份)

```
v_g(n) = domega/dk = k/omega = cos(theta_n)          ← 標準相對論群速度
sec(θ_n) = 1/v_g = omega/k = 折射率 n_refr           ← 「群延遲權重」嘅場論身份
```

★ 關鍵: **sec(πn/88) 唔係擬合出來嘅權重，佢就係質量模介質嘅折射率** ω/k。
呢個係 Lagrangian 級識別 — 之前 docs/07/12 只知 sec 係「譜權重」。

端點:
- `n = 44`: θ = π/2, k = 0 ⟹ **無質量極限** m² = γ₄₄ = 4 = ω²
- `n = 22`: θ = π/4, k = m = μ²/√2 ⟹ m² = γ₂₂ = 2 = ω²/2 (**自對偶**)

## 三、★ 增益身份 a = 1

```
a = <m^2>_odd / m^2_selfdual = <gamma>_odd / gamma_22 = mu^2/mu^2 = 1   EXACT
```

**讀法**: 每層增益 = **觀察者（奇）扇區嘅平均質量平方 ÷ 對面（自對偶）模嘅質量平方**。
因 Σγ_odd = N_d = 44（Z₂ 和律, docs/07/12）⟹ ⟨γ⟩_odd = 2 = μ² = γ₂₂ ⟹ a = 1。

即: 「觀察者扇區嘅平均質量平方 = 對面模嘅質量平方」— 呢個等式就係 a = 1 嘅物理內容。
