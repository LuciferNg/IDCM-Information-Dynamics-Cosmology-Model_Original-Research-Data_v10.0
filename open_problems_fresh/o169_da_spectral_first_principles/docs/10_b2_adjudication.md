## 一、裁決工具: 環幾何對面 (πR) + Nyquist 截止

```
結構輸入: L₆ = 18 = 1 + z_max,  F_proj = 17 = L₆ − 1,  ℓ_Nyq = log₄(L₆) = 2.08496250072

對面條件:  D_A(ℓ_Nyq) = πR
       ⟺  R(1 − 4^{−ℓ_Nyq})·E(ℓ_Nyq) = πR
       ⟺  (F_proj/L₆)·(ℓ_Nyq + b_eff) = π
       ⟹  所需有效截距  need = πL₆/(L₆−1) − ℓ_Nyq = 1.241429720727
```

★ 呢個條件**唔用 DESI 擬合** — 只用到幾何 (視線到對面) 同結構截止 (z_max = F_proj)。所以可以做獨立裁決器。

## 五、T4: φ 錨點嘅地位 — 恆等式 + 建基於已證偽式

```
φ 讀法嘅「E(1/2) = φ」:
   b = √5/2 = φ − 1/2   ⇒   E(1/2) = 1/2 + b = 1/2 + φ − 1/2 = φ     ← **恆等式**
   即係呢個「證據」係參數化嘅同義反覆, 唔係獨立約束。
```

該錨點嘅**來源**係: 舊律 `E_old(ℓ) = 1 + 2φ⁻¹ℓ` 於 ℓ = 1/2 嘅值 = `1 + φ⁻¹` = φ。
但**舊律已被 DESI D_M ×6 排除 4.88σ** ⇒ 要求新律同已證偽式喺一點重合，基礎薄弱。
★ 而且新律喺 ℓ = 1/2 嘅真值係 `1/2 + ⟨sec⟩_{1..21}` = 1.61835681 — 同 φ 只差 **0.0200%**，
屬**湧現**近簡併 (唔係構造出來嘅)，DESI 嘅 σ_b ≈ 0.6% 完全容納。
