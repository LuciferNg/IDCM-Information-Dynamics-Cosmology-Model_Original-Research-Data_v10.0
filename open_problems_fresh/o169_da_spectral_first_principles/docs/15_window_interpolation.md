## 三、★★ 結構重述: 窗口 = L₄ × 活躍世代數

```
K(z) = L₄ · N_eff(z),      N_eff(z) = N_gen + z/F_proj ∈ [N_gen, B] = [3, 4]
```

- z = 0 ⟹ N_eff = N_gen = 3（K = 21，DESI 窗，且已由門檻律導出 — docs/14 §三）
- z = z_max = F_proj ⟹ N_eff = B = 4（K = 28，πR/Nyquist 要求）
- 記憶已註冊: **N_gen + B = 7 = L₄** ⟹ 端點 = L₄ × {N_gen, B} 兩端結構數

★ 即: **窗 = L₄ × （活躍世代數）**，活躍世代數由 N_gen = 3 **線性於 z** 升到 B = 4。
③ 嘅問題由「z-線性 vs z-二次」**收窄**為「**點解活躍世代數線性於 z**」。
