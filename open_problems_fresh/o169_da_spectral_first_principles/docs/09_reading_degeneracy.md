## 二、U1 數域分離 — **兩讀法證明唔相等**

```
譜 b_spec = 1/⟨v_g⟩_{1..22} = 1.119113982034844
φ  b_phi  = √5/2            = 1.118033988749895
差 = 0.0010799933  (相對 0.0965%)
```

`mp.identify` 用 4 組基底（`√5` / `√5,√2,√3` / `π` / `√5,π`）全部 **miss** ⟹
`b_spec` 唔係 φ-代數亦唔係 π-代數。

**解析理由**：
```
⟨v_g⟩_{1..22} = sin(π/8)·cos(23π/176) / (22·sin(π/176))
```
⟹ `b_spec ∈ Q(ζ₁₇₆)`，`176 = 16·11`（`φ(176) = 80`，代數次數 80）；
而 `√5/2 ∈ Q(√5)`（次數 2）。

**兩個唔同次數嘅代數數唔可能相等** ⟹ 0.0965% 嘅一致純屬數值巧合，
**唔係同一個結構常數嘅兩種寫法**。
