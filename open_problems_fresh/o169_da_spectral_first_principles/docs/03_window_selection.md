# O169 docs/03 — Z₂ 自對偶窗口 K = 22 由數據唯一選出

> 日期: 2026-09-15 | 腳本: scripts/09_window_selection.py

---

## 一、問題

截距 b = 1/⟨v_g⟩_{1..K} 嘅窗口 K 係咪任意? 若 K 由數據揀 → 唔算結構 (overfitting)。

## 二、掃描 (K = 1..43, a = 1 固定)

```
1/⟨v_g⟩_{1..K} 通過 |σ|max ≤ 1.0 嘅 K: [22]      ← 唯一
⟨w⟩_{1..K}     通過 |σ|max ≤ 1.0 嘅 K: [21]
```

最佳: 1/⟨v_g⟩ → K = 22, χ² = 2.4528, |σ|max = 0.96
最佳: ⟨w⟩     → K = 21, χ² = 2.4563, |σ|max = 0.977

## 三、結構窗口對照 (全部不合格, 除 K = 22)

| K | 結構身份 | 1/⟨v_g⟩_{1..K} | χ²/5 |
|--:|:--|--:|--:|
| 11 | L₅ | 1.02993842 | 159.56 |
| **22** | **N_d/2 = Z₂ 自對偶模** | **1.11911398** | **2.4528** |
| 27 | F_proj 截斷 (O54) | 1.18463883 | 88.47 |
| 33 | K_tree | 1.29069441 | 589.34 |

## 四、結構理由

```
n = 22 = N_d/2 = 44/2      (Z₂ 自對偶模)
γ₂₂ = 4sin²(π/2 · 1/2)… = 4sin²(π/4) = 2 = μ²
v_g(22) = cos(π/4) = 1/√2
```

即窗口啱好停喺 **Z₂ 自對偶點** — 同 O167 scripts/12 (O1 深限, n=22, v_g = 1/√2, sec = √2) 同一個模。

## 五、結論

- K = 22 唔係 tune 出嚟: 43 個候選窗口中**只有**佢過 1σ, 而且佢係 Z₂ 自對偶點。
- ⟨w⟩ (算術平均) 嘅最佳窗口係 K = 21 (即**唔包**自對偶模) — 兩個讀法 (調和 vs 算術平均) 停喺相鄰窗口, 數值差 0.07% (1.119114 vs 1.118357)。
- → 譜分解 (harmonic mean of v_g over the self-dual half-chain) 由數據選出, **支持「譜分解 = 宇宙語言」命題** (charter 判準 ④), 但兩讀法簡併, 未達唯一 🔴。
