## 一、T1: Z₂ 分裂 — 譜 = 常數部分 + 反對稱波動

```
γ_n = 4sin²(πn/88) = 2 − 2cos(πn/44)          (43/43 驗證)

γ_n = μ²  −  2cos(πn/44)
      └┬┘    └────┬────┘
   Z₂-偶常數     Z₂-奇波動
   (μ² = 2)    (γ_{44−n} − 2 = −(γ_n − 2), 43/43 對)
```

★ 譜分成兩塊：**均勻部分 μ² = 2** (Z₂-偶) 同 **波動部分 −2cos(πn/44)** (Z₂-奇，反對稱)。

## 二、T2: 奇扇區內波動部分精確相消

```
Σ_{n odd} (γ_n − μ²) = 0        EXACT (精確 0, 唔係近似)
⟹ Σγ_odd = N_odd·μ² = 22·2 = 44 = N_d        EXACT
⟹ ⟨γ⟩_odd = μ² = 2                            EXACT
```

**結構理由**: 波動部分係 Z₂-奇 (反對稱) ⇒ 喺奇扇區內每一對 (n, 44−n) 相消；
N_d = 44 係**偶數** ⇒ 奇數集**冇不動點** ⇒ **零殘餘**。

## 三、T3: ★ 算子身份

```
L_odd ≡ Z₂-奇扇區嘅 88-環 Laplacian (22 個模態)

a = Tr(L_odd)/N_d = 44/44 = 1                EXACT
a = ⟨γ⟩_odd/μ²    = 2/2  = 1                 EXACT
Tr(T̂) = φ + (−φ⁻¹) = 1,   det(T̂) = −1        EXACT
```

★★ **a = 1 = 奇扇區平均譜重 / Z₂ 不動點權重** — 呢個係算子級身份，唔再係「算術後果」。
每層增益 = 「奇扇區每模態嘅譜重」相對「均勻譜重 μ²」嘅比值 = 1。

## 四、T4: ★ 整數性/保護 — 為何**必須**用奇扇區

```
偶扇區: Σγ_even/N_d = 46/44 = 1.0454545...   (非整數, 含 Z₂ 不動點 γ_22 = μ²)
奇扇區: Σγ_odd /N_d = 44/44 = 1              (精確整數)
```

**結構理由**:
- N_d = 44 偶 ⇒ 反射 n → 44−n 喺**奇數集冇不動點** ⇒ 反對稱相消零殘餘 ⇒ 增益**精確整數 1**;
- **偶數集含不動點 n = 22** (γ_22 = μ² = 2) ⇒ 殘餘 2/44 = 0.0455 ⇒ 非整數。

★ 即係話: **輸運量要「量子化」為整數，就必須取冇不動點嘅扇區**。
呢個係「點解係奇 (反週期) 扇區」嘅答案: 反週期扇區係唯一**無不動點**嘅 Z₂ 扇區，
所以只有佢嘅增益係拓撲保護嘅整數 (唔會有分數殘餘)。
