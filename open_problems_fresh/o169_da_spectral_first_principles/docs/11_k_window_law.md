## 三、T3: ★ 兩個結構端點

```
K(z = 0)     = L₄·N_gen = 7·3 = 21      ← DESI 唯一選出嘅窗 (docs/09 §U2)
K(z = z_max) = L₄·B     = 7·4 = 28      ← πR/Nyquist 要求嘅窗 (docs/08 §T3)
```

| 錨點 | 要求 | 窗律給出 | dev |
|:--|--:|--:|--:|
| Nyquist 對面 `E(ℓ_Nyq) = πL₆/(L₆−1)` | 3.326392221 | 3.326380611 | **0.000349%** 🟢 |
| Z₂ 自對偶點 `E(1/2) = φ` | 1.618033989 | 1.618356810 | 0.0200% 🟡 |

★ 窗嘅兩個端點係 **L₄ 乘「活躍分支數」**: 由 `N_gen = 3` (z = 0) 長到 `B = 4` (z = z_max)。
`B = N_gen + 1` ⇒ 等價寫法 `K = L₄·N_gen·(1 + (z/z_max)/N_gen)`，即窗口按「已覆蓋深度比例」增長。

## 四、T4: ★ 不可能性 — 常數 transit-time 門檻律

候選族: 「模式 n 活躍 ⟺ 其 transit time `τ_n = sec(πn/88) ≤ c·ℓ`」(c 常數)。

```
DESI 上限 ℓ = 0.8678:  K = 21 ⇒ τ₂₁ = 1.366317 ≤ 0.8678c 且 τ₂₂ = 1.414214 > 0.8678c
                       ⇒ c ∈ [1.574531, 1.629727]
Nyquist  ℓ = 2.084963: K = 28 ⇒ τ₂₈ = 1.849657 ≤ 2.084963c 且 τ₂₉ = 1.959747 > 2.084963c
                       ⇒ c ∈ [0.887142, 0.939943]

兩區間不相交  ⇒  常數 c 律不存在
```

★ 呢個係**負結果**: 排除一整族「按 transit time 開窗」嘅候選律。窗口唔可能係「速度門檻」，
只可能係「深度比例」型。
