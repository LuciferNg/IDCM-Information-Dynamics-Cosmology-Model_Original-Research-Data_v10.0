## 二、★ 推導 (解析, 全部 EXACT)

### S1. Z₂ 對偶律

```
γ_n = 4 sin²(πn/88),   γ_n + γ_{44−n} = 4 = B        (n = 1..43, 43/43 對)
γ_22 = 2 = B/2                                        (不動點 n = 22)
```

### S2. 反對稱 (推導嘅關鍵)

```
cos(π(44−n)/44) = cos(π − πn/44) = −cos(πn/44)        (43/43, dev < 3.5e-41)
```

### S3. ⟹ 奇數和 = 0

```
Σ_{odd n = 1..43} cos(πn/44) = 0   EXACT
```

**解析理由 (唔靠數值)**：
- 44 係**偶數** ⟹ 對每個奇 n，`44 − n` 亦係奇 ⟹ pair (n, 44−n) 完全落在奇數集內；
- 每對 cos 值相反 (S2) ⟹ 兩兩相消；
- 不動點 `44 − n = n` 要 `n = 22`（**偶數**）⟹ 奇數集**冇**不動點 ⟹ **冇殘項**。

### S4. ⟹ Σγ_odd = N_d

```
Σγ_odd  = Σ_{odd} 2(1 − cos(πn/44)) = 2·22 − 2·(S3) = 44 = N_d     EXACT
Σγ_even = Σ_{even} 2(1 − cos(πn/44)) = 2·22 − 2·(−1) = 46 = N_d + μ²  EXACT
Σγ      = 90 = 2N_d + μ²                                            EXACT
```

偶數集嘅 `Σ_even cos(πn/44) = −1`（不動點 n = 22 貢獻 cos(π/2) = 0；n = 44 貢獻 cos(π) = −1）。

### S5. ⟹ a = 1

```
a = Σγ_odd / N_d = 44 / 44 = 1   EXACT
```

### S6. ★ 附帶結構：μ² = 不動點權重

```
Σγ_even − Σγ_odd = γ_22 = 2 = μ²     EXACT
```

**結構讀法**：奇數集冇不動點 → 純反對稱相消 → 和係「整數飽和」`N_d`；
偶數集含不動點 n = 22 → 多出 `γ_22 = 2 = μ²`。呢個就係 μ² = γ₂₂ = 2 嘅譜來源。
