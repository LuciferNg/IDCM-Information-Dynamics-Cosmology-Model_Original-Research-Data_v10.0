## 3. §A ★★ 定理 T1：Adjoint 143 **唔可能**實現 `SU(12) → SU(4)×SU(3)`

### 3.1 第一步（精確、代數）

```
End(12) = End(4⊗3) = End(4) ⊗ End(3) = (1⊕15) ⊗ (1⊕8)
        = (1,1) ⊕ (1,8) ⊕ (15,1) ⊕ (15,8)                dim = 1 + 8 + 15 + 120 = 144
143 = Adj(12) = End(12) − 1
        = (1,8) ⊕ (15,1) ⊕ (15,8)                        dim = 8 + 15 + 120 = 143
```

⟹ **Adjoint 143 喺 `SU(4)×SU(3)` 之下完全冇 `(1,1)` 分量。**
（與 O88 `docs/02` §四記載一致 ✓ —— 即該分解本身正確，問題喺**物理判讀**。）

### 3.2 第二步（Schur / commutant —— 決定性）

設 `H = SU(4)×SU(3)_tensor ⊂ SU(12)`。若 `H ⊆ Stab(D)`（`D ∈ su(12)` 為 adjoint VEV），
則必須 `[X, D] = 0  ∀X ∈ H`，即 `D ∈ centralizer(H)`。

**基本表示 `12 = (4,3)` 為 H 之不可約表示**（張量積之不可約性）。
由 **Schur 引理**，`centralizer(H) ⊆ End(ℂ^12)` 為純量：

```
centralizer_{End(C^12)}(SU(4)×SU(3)_tensor) = C·1_12
⟹ centralizer_{su(12)}(H) = C·1_12 ∩ su(12) = {0}      (因 su(12) 取 traceless)
```

**腳本 S14 實測**：對 `{E_ij⊗I_3} ∪ {I_4⊗E_kl}` 全生成元解 `[g,M] = 0`（精確有理數 Gaussian 消去），
nullity **= 1** ⟹ commutant = `ℂ·1` ✓

> ★★ **定理 T1**：`H = SU(4)×SU(3)_tensor` **唔包含喺任何非零 adjoint VEV 之 stabilizer 內**。
> 故 unbroken group **唔可能**係（或包含）`SU(4)×SU(3)`。
> ⟹ 記錄之鏈第一步「`SU(12) → SU(4)×SU(3)`，Higgs = Adjoint 143」**結構上不可能**。

### 3.3 第三步（rank —— 獨立第二判據）

Adjoint VEV 必可對角化於 Cartan：`⟨Φ⟩ = diag(d_1..d_12)`，
stabilizer `= S(∏_i U(m_i))`（`m_i` = 相同特徵值之重數），故

```
rank(stabilizer) = Σ m_i − 1 = 12 − 1 = 11   （**任何** partition 皆然 —— adjoint VEV 保秩）
rank(SU(4)×SU(3)) = 3 + 2 = 5
```

`rank(SU(12)) = 11`，`rank(SU(4)×SU(3)) = 5`，差 **6 個 U(1)**。
`SU(4)×SU(3)×U(1)^6` 之 rank 雖為 11，但由 §3.2 之 commutant = {0}，
**加 U(1)^6 亦救唔到**（`u(1)^6` 之一部分必喺 `su(4)⊕su(3)` 內；任何包含 `su(4)⊕su(3)` 之
unbroken algebra 都要求 VEV 與 `su(4)⊕su(3)` 交換 ⟹ VEV = 0）。**兩條獨立判據同時收口。**

### 3.4 陽性對照（證明機器唔係「一味話唔可能」）

| 嵌入 | 基本表示分解 | commutant 維數 | traceless 非零 VEV | 結論 |
|:--|:--|:-:|:-:|:--|
| `SU(5) ⊃ SU(3)×SU(2)×U(1)` | `5 = (3,1) ⊕ (1,2)` —— **2 個分量** | **2** | `diag(2,2,2,−3,−3)` ✓ | **可以** ✓（教科書案例） |
| `SU(12) ⊃ SU(4)×SU(3)` | `12 = (4,3)` —— **單一不可約分量** | **1** | 無 | **唔可以** ✗ |

★ 關鍵分別：`SU(5)` 之 VEV `diag(2,2,2,−3,−3)` **保秩**（rank 4 → 4，`3+2−1 = 4` ✓），
而 `SU(12)` 之 `12 = (4,3)` 為單一不可約分量 ⟹ commutant 塌縮為純量 ⟹ adjoint 冇可用方向。

## 5. §C ΔB=1 標量 leptoquark 之判據

**判據推導**（B−L 記賬 + colour 收縮）：

標量 `φ` 耦合兩費米子 ⟹ `B−L(φ)` 必等於該配對之 `B−L`。

```
(q q)      : 1/3 + 1/3 = 2/3           (qbar lbar) : −1/3 + 1 = 2/3      <- 同值！
(qbar qbar): −1/3 − 1/3 = −2/3         (q l)       : 1/3 − 1 = −2/3      <- 同值！
(qbar l)   : −1/3 − 1 = −4/3           (q lbar)    : 1/3 + 1 = 4/3
```

`|ΔB| = 1` 需 `φ` **同時**耦合 `{(qq) 或 (q̄q̄)}` ∧ `{(q̄l̄) 或 (ql)}`。
兩類配對之 `B−L` 同值（**±2/3**），colour 需 (反)三重態（`3×3 → 3̄`、`3̄×3̄ → 3`）：

> ★ **判據**：**colour (反)三重態 ∧ `|B−L| = 2/3`**

### SU(4)_PS irrep 普查（權重法，精確有理數）

| SU(4) irrep | B−L 分解 | ΔB=1 資格 |
|:--|:--|:-:|
| `4` | `3_{1/3} ⊕ 1_{−1}` | ✗（無色三重態） |
| `4̄` | `3̄_{−1/3} ⊕ 1_{1}` | ✗ |
| **`6 = Λ²(4)`** | **`3̄_{2/3} ⊕ 3_{−2/3}`** | **✓** |
| **`10 = Sym²(4)`** | **`6_{2/3} ⊕ 3_{−2/3} ⊕ 1_{−2}`** | **✓**（`3_{−2/3}`） |
| `15 = Adj(4)` | `8_0 ⊕ 3_{4/3} ⊕ 3̄_{−4/3} ⊕ 1_0` | **✗（三重態 \|B−L\| = 4/3 ≠ 2/3）** |
| `20 = Sym³(4)` | `10_1 ⊕ 6_{−1/3} ⊕ 3_{−5/3} ⊕ 1_{−3}` | ✗（`|B−L| = 5/3`） |

★★ 注意 `15 = Adj(4)` 之三重態 `|B−L| = 4/3` —— 與 PD #1 獨立算出之
「gauge coset boson `B−L = ±4/3`」**完全一致** ✓（PD #1 之 `[Q_{B−L}, T^A] = q_A T^A` 核對）。
