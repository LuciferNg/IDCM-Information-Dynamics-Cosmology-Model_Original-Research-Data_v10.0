## 3. ★★★ (B) 封閉代數普查 —— **否證首輪「封閉」斷言**

### 3.1 獨立算法 ①（SU(3)⊗U(1) 直接分裂，唔靠 Pieri）

由 `4 = 3_{1/3} ⊕ 1_{−1}`：

```
Λ²(4)   = Λ²(3_{1/3}) ⊕ [3_{1/3} ⊗ 1_{−1}]                        = 3̄_{2/3} ⊕ 3_{−2/3}     (3+3 = 6 = C(4,2) ✓)
Sym²(4) = Sym²(3_{1/3}) ⊕ [3_{1/3} ⊗ 1_{−1}] ⊕ Sym²(1_{−1})       = 6_{2/3} ⊕ 3_{−2/3} ⊕ 1_{−2}  (6+3+1 = 10 = 4·5/2 ✓)
```

而 `Λ²(4) = 6`、`Sym²(4) = 10`（由維數與對稱性唯一）⟹

> **`4 ⊗ 4 = Λ²(4) ⊕ Sym²(4) = 6 ⊕ 10`**，且 `6`、`10` **皆為合格 SU(4) irrep**。

**底層 colour 級直述**（本修正之根因）：
```
3_{1/3} ⊗ 3_{1/3} = 3̄_{2/3} ⊕ 6_{2/3}        (9 = 3 + 6 ✓)
```
⟹ 兩個色三重態（各 `B−L = 1/3`）之乘積**含** `3̄_{2/3}` = 判據所要求之量子數 ✓
