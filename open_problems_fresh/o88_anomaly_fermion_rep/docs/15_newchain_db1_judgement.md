## 四、B 數方向審查（S5）—— ΔB 判據之結構前提

`U(1)⁸` 之基 = `H = (2,−3,0⁷)` + `E_i`（7 單態對角）⟹ **任何方向之色:弱 分量比 = 2:−3**。

`B ∝ diag(1/3·I₃, 0, …)`：弱分量 = 0 ⟹ `α = 0`；色分量 = 1/3 ⟹ `α = 1/6`（**矛盾**）。

> 🔴 **B 數唔喺 `U(1)⁸` 空間** ⟹ B 唔係 `SU(12)` 內部 U(1) 生成元 ⟹ **B 係外部／全域量子數**。

（舊鏈由 `SU(4)_PS` 之 `4 = 3⊕1` 提供 `B−L` ⟹ 有內部來源；新鏈**冇**此來源。）

**X/Y 之 ΔB**：色-弱交叉生成元 `B(E_ij) = B_i − B_j = 1/3 − 0` ⟹ 單個 `ΔB = 1/3`；3 種色合成 `ΔB = 1` ✓
