### 2.1 方法（精確、無擬合）

SU(N) 之三階異常定義：`Tr_R(T^a {T^b, T^c}) = A(R)·d^{abc}`，正規化 `A(fund) = 1`。
取 `a, b, c` 全為 **Cartan 指標**（`H_a = E_aa − E_{a+1,a+1}`，traceless 對角）：

```
T^a{T^b,T^c} = 2 H_a H_b H_c                        (Cartan 元素互換)
Tr_R(H_a H_b H_c) = Σ_μ m_μ · t^μ_a t^μ_b t^μ_c      (μ = 權重, m_μ = 重數)
d^{abc}           = 2 Σ_{ν∈fund} t^ν_a t^ν_b t^ν_c
其中 t^μ_a := μ_a − μ_{a+1}  為權重 μ 喺 H_a 上之特徵值

⟹  ★ A(R) = [Σ_μ m_μ t^μ_a t^μ_b t^μ_c] / [Σ_{ν∈fund} t^ν_a t^ν_b t^ν_c]
```

★ **關鍵簡化（令計算全整數、精確、快）**：
基本權重 `ν_i = e_i − (1/N)·1` ⟹ `t^{ν_i}_a = δ_{ia} − δ_{i,a+1} ∈ {−1, 0, 1}`。
`Λ^k`／`Sym^k` 之權重為基本權重之和 ⟹ `t^μ_a ∈ {−1,0,1}`（**整數**）；
`Adj` 之權重 `ν_i − ν_j` ⟹ `t^μ_a ∈ {−2,…,2}`（**整數**）。
⟹ 無需高分數運算（v1 版用 `Fraction` 需 >7 分鐘；v2 全整數 **0.15 秒**，快 ~10³ 倍）。

### 2.2 權重（純組合，唔用任何 rep 理論表）

| rep | 權重多重集 | dim |
|:--|:--|:--|
| `Λ^k(N)` | `k`-子集之和，重數 1 | `C(N,k)` |
| `Sym^k(N)` | `k`-可重組合之和，重數 1 | `C(N+k−1,k)` |
| `Adj(N)` | `{ν_i − ν_j}` ∪ `{0 之重數 N−1}` | `N²−1` |
