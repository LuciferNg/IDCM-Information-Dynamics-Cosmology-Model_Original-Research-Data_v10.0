# RESULT.md Template — IDCM O-series 結論摘要

---

## 格式

每條 O-series 一個 RESULT.md，放在該目錄 root，**極簡**（≤20 行），
只記錄最終結論、關鍵公式、依賴關係。

---

## Template

```markdown
# O{XXX} — {標題}

## 狀態: 🟢 已閉合 | 🟡 部分閉合 | 🔴 開放

## 結論
{一句話結論}

## 關鍵公式
- {公式 1}
- {公式 2}
- {公式 3}

## 依賴
{OXXX} → {OYYY} → {OZZZ}

## 密度基準
- N_search = {值}（{構成式}，或 `1` = 唯一候選）
- N_mc = {值}，seed = {值}
- d_obs = {值}（觀測偏差）
- d_med = {值}（隨機中位偏差）
- q_obs = {值}% → 🟢/🟡/🔴

> ⚠️ O208 規則: 冇分位數 = 未閉合（docs/01_density_baseline_spec.md）。
> 純代數恆等式: `N_search = 1` + 聲明唯一候選即可跳過 MC。
```

## 範例

### 🟢 已閉合

```markdown
# O95 — 44 唯一性

## 狀態: 🟢 已閉合

## 結論
N_d=44 是唯一滿足所有結構約束的自然數（6 層證明，N=1..200 窮舉）。

## 關鍵公式
- N_d = B × R = 4 × 11
- 88 = 2 × N_d（雙鏈結構）

## 依賴
O56 → O59 → O95
```

### 🟡 部分閉合

```markdown
# O120 — 輕夸克質量

## 狀態: 🟡 部分閉合（u/d 18-50%）

## 結論
下夸克質量閉合（d 18%），上夸克仍未達 <1% 精度。

## 關鍵公式
- m_d = M₀ · γ₃ · F_proj = {值}
- m_u = {公式} — 🔴 未閉合

## 依賴
O54 → O36 → O120
```

### 🔴 開放

```markdown
# O96 — SU(12) 根源

## 狀態: 🔴 開放

## 問題
為甚麼是 SU(12) 而不是其他 Lie 群？12 = B×N_gen = 4×3，但 N_gen 的根源在 O103。

## 依賴
O95 → O103 → O96
```

## 規則

1. **結論先行** — 第一句就講結論，唔好 preamble
2. **只寫最終結論，不寫推導過程** — 公式可以直接列，但唔好解釋點嚟
3. **公式用純文字或 LaTeX** — `γ_n = 4sin²(πn/88)` 或 $E = mc^2$
4. **狀態 emoji 統一** — 🟢 已閉合 / 🟡 部分閉合 / 🔴 開放
5. **依賴箭頭** — `→` 表示「依賴於」
6. **長短不拘** — 一個純公式可以用 1 行，一個綜合性 O（如 O72 場論審計）可以上百行，按需要分段
