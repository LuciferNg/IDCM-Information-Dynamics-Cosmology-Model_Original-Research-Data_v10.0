## 二、預備知識

### 2.1 Rayleigh-Ritz 變分原理 (矩陣形式)

對於 Hermitian 矩陣 A，Rayleigh 商：
```
R(x) = (x† A x) / (x† x)
```
滿足：
- max R(x) = λ_max(A)（沿對應特徵向量方向）
- min R(x) = λ_min(A)

**變分解讀**: 若 V(x) = −x† A x + O(x⁴)，則在臨界點附近，V 沿 λ_max 方向下降最快。

### 2.2 張量 Rayleigh 商 (張量形式)

對於 3-階張量 d ∈ ℂ^{n×n×n}，定義張量 Rayleigh 商：
```
R_d(x) = (d ×₁ x ×₂ x ×₃ x) / (x·x)^{3/2}
```
其中 d ×₁ x ×₂ x ×₃ x = Σ_{i,j,k} d_{ijk} x_i x_j x_k。

**Z-H 特徵值** (Qi, 2005): λ 係 d 嘅 Z-特徵值，若存在 x ≠ 0 使得：
```
d ×₂ x ×₃ x = λ x    (sum over j,k: d_{ijk} x_j x_k = λ x_i)
```
或等價地：
```
Σ_{j,k} d_{ijk} x_j x_k = λ x_i,    ∀i
```

### 2.3 有效勢能 V(Φ) 的張量展開

在 SU(12) 規範理論中，含純量場 Φ ∈ 12 嘅有效勢能可展開為：
```
V(Φ) = −μ² · (Φ†Φ) + κ · d_{ijk} Φ_i Φ_j Φ_k + λ · (Φ†Φ)² + ...
```
其中：
- μ² 項：質量項（SSB 觸發條件 μ² > 0）
- κ 項：三階不變量（由 d_tensor 定義）
- λ 項：四階自耦合

## 三、引理 1: d_tensor 嘅 Z-特徵值問題

**命題**: d_tensor 嘅最大 Z-特徵值 λ_max 對應嘅特徵向量 v_max 係 V(Φ) 在 SSB 勢能景觀中嘅最速下降方向。

**證明**:

考慮 V(Φ) 嘅三階部分 V₃(Φ) = κ · d_{ijk} Φ_i Φ_j Φ_k。

在單位球面 ‖Φ‖ = 1 上，V₃ 被 d_tensor 嘅 Z-特徵值譜 bound：
```
max_{‖Φ‖=1} |V₃(Φ)| = κ · λ_max(d)
```

由 Rayleigh-Ritz 變分原理嘅張量推廣 (Qi, 2005 Theorem 3.3)：
- 局部極值點 (Φ*) 滿足 d ×₂ Φ* ×₃ Φ* = λ Φ*
- 即 Φ* 係 d_tensor 嘅 Z-特徵向量
- 對應極值 V₃(Φ*) = κ · λ · ‖Φ*‖³

**關鍵**: λ_max 對應嘅特徵向量 v_max 係 V₃(Φ) 嘅全局最大值方向。在 SSB 中 μ² > 0 觸發 Φ 獲得 VEV，V(Φ) 嘅主導項 −μ²Φ†Φ + κ·dΦ³ 會沿 v_max 方向最快降低能量。

**物理**: 唔係人為揀選 (1,1)_0 方向，而係 d_tensor 嘅譜拓撲強制 SSB 沿 λ_max 方向發生。□

## 四、引理 2: 12D 張量 Z-特徵值譜分解

**命題**: 在 SU(12) 嘅 Cartan 分解 12 → 1⊕11 下，d_tensor 嘅 Z-特徵值譜自然呈現 1+11 結構，且 λ_max 對應嘅特徵向量正正係 Cartan 零權重方向 (1)。

**證明**:

設 {e_1, ..., e_12} 為 SU(12) Cartan 權重基底。在呢個基底中：
- e_1 = 零權重向量 (Cartan zero-weight)
- {e_2, ..., e_12} = 11 個非零權重向量

由 SU(12) 不變性，d_tensor 在 Cartan 權重下嘅分量滿足：
- d_{1jk} = 0 除非 j=k=1（零權重方向嘅選擇規則）
- 僅 d_{111} 及跨權重分量非零

Z-特徵值方程：
```
Σ_{j,k} d_{ijk} x_j x_k = λ x_i
```

對於 i=1（零權重方向）：
```
d_{111} x₁² + Σ_{j,k≠1} d_{1jk} x_j x_k = λ x₁
```

但 d_{1jk} = 0 for j,k ≠ 1（由 SU(12) 不變性 + 權重守恆）：
```
d_{111} x₁² = λ x₁
```
→ 解 x₁ = λ/d_{111} 或 x₁ = 0

對於 i≠1（非零權重方向）：
```
Σ_{j,k} d_{ijk} x_j x_k = λ x_i
```
呢個系統有 11 個獨立解，對應 λ_{2..12}。

**譜結構**: 12 個 Z-特徵值自然分為：
- 1 個主模：λ_max = d_{111}（沿零權重方向）
- 11 個次模：λ_{2..12}（沿非零權重方向）

且因為 d_{111} >> cross-terms（由 CY₃ 相交數分層），λ_max >> mean|rest|。□

## 五、主定理: Spectral Extremization → SSB 方向鎖定

**定理**: 在 SU(12) 規範理論中，若有效勢能 V(Φ) 包含 d_tensor 定義嘅三階不變量，則 SSB 凝結方向被 d_tensor 嘅譜拓撲強制鎖定喺 λ_max 對應嘅主模 1 方向。

**證明**:

**Step 1: V(Φ) 的張量展開**
```
V(Φ) = −μ² · Φ†Φ + κ · d_{ijk} Φ_i Φ_j Φ_k + λ · (Φ†Φ)² + higher order
```
其中 μ² > 0 觸發 SSB。

**Step 2: 變分分析**
在臨界點附近，Φ = ⟨Φ⟩ + δΦ。VEV ⟨Φ⟩ 滿足：
```
∂V/∂Φ_i |_{⟨Φ⟩} = 0
```
即：
```
−μ² ⟨Φ⟩_i + κ · Σ_{j,k} d_{ijk} ⟨Φ⟩_j ⟨Φ⟩_k + 2λ · (⟨Φ⟩†⟨Φ⟩) ⟨Φ⟩_i = 0
```

**Step 3: Z-特徵值對應**
令 v = ⟨Φ⟩/‖⟨Φ⟩‖ 為單位方向。上式重整為：
```
κ · Σ_{j,k} d_{ijk} v_j v_k = (μ² − 2λ‖⟨Φ⟩‖²) · v_i
```
即：
```
Σ_{j,k} d_{ijk} v_j v_k = λ_eff · v_i
```
其中 λ_eff = (μ² − 2λ‖⟨Φ⟩‖²)/κ。

**呢正正係 d_tensor 嘅 Z-特徵值方程！** 所以 v 必須係 d_tensor 嘅 Z-特徵向量。

**Step 4: 能量極小化**
SSB 選擇最低能量嘅真空。V(⟨Φ⟩) 沿 v 方向嘅值：
```
V(⟨Φ⟩) = −μ²‖⟨Φ⟩‖² + κ·λ_eff·‖⟨Φ⟩‖³ + λ‖⟨Φ⟩‖⁴
```

固定 ‖⟨Φ⟩‖，V 沿著 λ_eff 最大嘅方向最低。而 λ_eff 由 d_tensor 嘅 Z-特徵值譜決定：
```
max λ_eff = λ_max(d_tensor) / κ · (相對應方向)
```

**Step 5: 鎖定結論**
由引理 2，λ_max 對應嘅 Z-特徵向量正正係 Cartan 零權重方向 (1)。因此：
```
⟨Φ⟩ ∝ v_max = e_1 (零權重方向)
```

**即 SSB 凝結方向被 d_tensor 嘅譜拓撲強制鎖定喺主模 1，非人工指定。** □
