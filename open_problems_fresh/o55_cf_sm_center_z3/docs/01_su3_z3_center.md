## 三、Z_3 中心機制

### 3.1 SU(3)_c 嘅 Z_3 中心

SU(3) 嘅中心係 Z_3 = {1, ω, ω²}，其中 ω = e^{2πi/3}。

SU(3) 表示嘅 triality:
- **3** (fundamental): triality 1 → ω
- **3̄** (anti-fundamental): triality 2 → ω²
- **1** (singlet): triality 0 → 1
- **8** (adjoint): triality 0 → 1

### 3.2 1/3 量子化嘅起源

c_f = n/3 嘅「3」= |Z_3| = SU(3)_c 中心嘅階。

**呢個唔係對稱機制，係量子化機制** — O53 已經排除 Z_3 循環對稱 (d_tensor 唔協變)，但 **n/3 嘅分母 3 仍然來自 Z_3 嘅階**。

### 3.3 3c 值嘅 Z_3 × Z_2 結構

6 個不同值: {−2, −1, 0, 1, 2, 3} = 2 × 3 = |Z_2| × |Z_3|

**Z_2 結構**: mod 2 = {0, 1} ✅
- 偶數: 0, -2, 2
- 奇數: 1, -1, 3

**Z_3 結構**: mod 3 = {0, 1, 2} ✅
- ≡0 (mod 3): 0, 3
- ≡1 (mod 3): 1, -2
- ≡2 (mod 3): 2, -1

### 3.4 3c = 3q + r 分解

所有 3c 值可以寫成 3q + r，其中:
- **q ∈ {−1, 0, 1}** = Z_3 世代量子數
- **r ∈ {0, 1, 2}** = Z_3 電荷型殘餘

| 3c | q | r | 分解 |
|:--:|:-:|:-:|:-----|
| -2 | -1 | 1 | 3×(-1) + 1 |
| -1 | -1 | 2 | 3×(-1) + 2 |
| 0 | 0 | 0 | 3×0 + 0 |
| 1 | 0 | 1 | 3×0 + 1 |
| 2 | 0 | 2 | 3×0 + 2 |
| 3 | 1 | 0 | 3×1 + 0 |

呢個分解嘅物理意義:
- **q**: 世代相關嘅 Z_3 電荷 (gen1→gen3 各有不同)
- **r**: 電荷型相關嘅 Z_3 殘餘 (U/D/L 各有不同)
