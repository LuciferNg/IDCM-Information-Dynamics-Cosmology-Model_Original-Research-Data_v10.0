## 一、問題

36×36 矩陣有 3 個 12×12 full-rank blocks，但無 Z₃ 離散對稱分塊。
12 維機制嘅幾何身份係乜？

## 二、發現

### 1. Y = 3 × 12D 精確直和（決定性）

```
Schur 分解 Y = QTQ*:
T 下三角 ||·|| = 0.00e+00 (數值零!)
→ Y 喺 Schur 基下 = 3 個 12×12 塊嘅精確直和
→ 唔係「近似 block」— 係 exact direct sum!
```

### 2. 3×12 block 結構

```
Inter-block 主奇異值:
[[1.02  0.057 0.118]
 [0.057 0.142 0.077]
 [0.118 0.077 0.509]]
對角/非對角 = 6.64 (Frobenius ratio)
```

Block 譜相關：c01=0.893, c02=0.957, c12=0.855（>0.7，結構相關）

### 3. Block 譜正負結構

```
Block 0: +4/−8  rank 12
Block 1: +7/−5  rank 12
Block 2: +12/−0  rank 12
→ 三個 block 有唔同正負分佈（唔係複製）
```

### 4. K_Chain 起源

```
h11 = 36 = Nd − 2B = 44 − 8
12  = (Nd−2B)/3 = 36/3
→ 12 維有 K_Chain 結構起源!
```

### 5. 66 = su(12) 正根（身份統一）

```
su(12) 正根 = N(N−1)/2 = 66 = C(12,2)
66 = 2×33 (K_tree)
66 = 3×22 (3 代 × 2×L₅)
→ 66 嘅真正身份: su(12) 正根空間!
→ 3×su(12) dim = 429, E8×E8 − 429 = 67 = 66+1
```

## 三、閉合鏈

```
36 = Nd − 2B = 44 − 8
36 = 3 × 12
12 = (Nd−2B)/3
66 = C(12,2) = su(12) 正根
Y = 3 × 12D 精確直和
→ 12 維機制 = 3 個 su(12) sector
→ 3 代 = 3 個 su(12) 對稱破缺分支 (K_Chain 分支!)
```
