## 一、問題

真實幾何 Y = κ_ijk·J*^k 嘅 tr(Y²) = 4.9474，誤差 1.05% vs 5。

## 二、發現

### 1. tr(Y²) = 5 嘅身份

```

5 = φ³ − φ⁻³ + 1 = B + 1     (B = 4 = K_Chain 分支數)
```

```
1/λ₁ = 0.851869 vs φ^(-1/3) = 0.851800
誤差: 0.008%  (λ₁ 規範下)
```

→ 只有 λ₁ 精確，其餘大致沿 φ^(-k/3) 衰減（非微擾修正層級）。

| 量 | 值 | 身份 | 狀態 |
