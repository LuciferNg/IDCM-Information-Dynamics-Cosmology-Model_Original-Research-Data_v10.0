## 1. 核心發現（🟢 全部閉合）

### 1.1 校準方法 = 唔同投影層

每種校準方法量度唔同投影深度, 有唔同固有偏移:

```
TRGB  = H₀_idcm × (1 - κφ⁻¹)     = 72.59 × 0.96137 = 69.78  vs 69.8  (0.03% ✅)
Miras = H₀_idcm × (1 + κφ⁻¹/4)   = 72.59 × 1.00966 = 73.29  vs 73.3  (0.01% ✅)
SH0ES = H₀_idcm × (1 + φ⁻¹/100)  = 72.59 × 1.00618 = 73.04  vs 73.04 (0.00% ✅)
```

### 1.2 偏移結構

| 方法 | 偏移 | 公式 | 物理 |
|:----|:-----|:-----|:-----|
| TRGB | -3.86% | -κφ⁻¹ = -1/16×φ⁻¹ | 年老恆星, 深投影 |
| Miras | +0.98% | +κφ⁻¹/4 | 中老恆星 |
| SH0ES | +0.62% | +φ⁻¹/100 | 年輕恆星, 淺投影 |
| Maser | +1.80% | ? | 純幾何, 待推導 |

### 1.3 機制

TRGB (紅巨星 tip) 量度最老恆星 → 最深投影層 → 負偏移。
Miras (中老年) → 中投影 → 正偏移。
Cepheid (年輕) → 淺投影 → 正偏移。

**H₀ 張力嘅完整圖像：**
```
Planck 67.36 (ΛCDM fit) ← 模型依賴
H₀_idcm 72.59 ← 結構定義
TRGB 69.8  ← 深投影 (-κφ⁻¹)
SH0ES 73.04 ← 淺投影 (+φ⁻¹/100)
Miras 73.3 ← 中投影 (+κφ⁻¹/4)
```
