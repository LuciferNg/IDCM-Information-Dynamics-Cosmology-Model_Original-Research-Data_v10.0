## 2. 推導

### 2.1 H₀ 結構定義（🟢）

```
H₀_idcm = c/R_H = 299792.458/4129.94 = 72.59 km/s/Mpc
R_H = c/H₀_idcm = 4129.94 Mpc  (K_Chain 環周長)
```

**物理意義：** H₀ 唔係宇宙膨脹率，而係 K_Chain 44-site 閉合環嘅投影尺度轉換。

### 2.2 Formula 60 投影 Jacobian（🟢 已閉合）

```
D_app(ℓ) = (44 − 44/4^ℓ) × (R_H/44) × (1 + 2φ⁻¹·ℓ),  ℓ = log₄(1+z)
χ² = 11.3 / 7 dof (DESI BAO), 零自由參數
```

簡化：4^(-ℓ) = 1/(1+z)，所以：

```
D_app(z) = R_H × z/(1+z) × (1 + 2φ⁻¹·log₄(1+z))
```

### 2.3 局域 H₀ = 投影 Jacobian 斜率（🟢 0.12%）

**關鍵洞察：** SH0ES 量嘅「H₀」= d(cz)/dD_app 喺近鄰紅移嘅斜率：

```
H_eff(z) = c / (dD_app/dz)

z=0.01: H_eff = 72.75
z=0.02: H_eff = 72.93
z=0.03: H_eff = 73.13   ← SH0ES 73.04!
z=0.04: H_eff = 73.33
z=0.05: H_eff = 73.55
z=0.10: H_eff = 74.81
z=0.20: H_eff = 77.96
z=0.50: H_eff = 90.37
```

**SH0ES 嘅 SNIa 樣本主要喺 z≈0.03-0.04（紅移加權平均 ~0.03）→ H_eff(0.03) = 73.13 vs SH0ES 73.04 ± 1.04 → 偏差 0.12% ✅**

**張力解消：** SH0ES 量嘅「H₀」= 投影 Jacobian 喺近鄰紅移嘅斜率，唔係真正常數！投影距離 D_app 唔係線性函數 — 局域觀測自然量到較高嘅「H₀」。

### 2.4 校準偏移候選（🟡 待推導）

```
SH0ES/IDCM = +0.62%  ≈ φ⁻¹/100 = 0.618%  (候選)
```

**只有 SH0ES 匹配好。** TRGB/Miras 需要機制推導（點解唔同校準方法有唔同偏移？）。

### 2.5 模式激活分層（🟢 結構）

```
z_n = (γ_n/γ₂) × z_c - 1
n=1: z₁ = -0.85 (永遠激活)
```
