⇒ E_needed  = D_L/(R·z/(1+z))      = 1.02365

## 3. ★ 根因: O169 線性律違反非膨脹極限 E(0) = 1

非膨脹模型鐵律: ℓ→0 時投影必須回收結構率 `H₀_idcm = c/R_world = 72.59` ⇒ **E(0) = 1**。

```
舊律:  E(0) = 1                → H_eff(0) = c/R = 72.59 = H₀_idcm ✓
新律:  E(0) = b = 1.119 ≠ 1    → H_eff(0) = c/(R·b) = 64.87 ✗  (−10.6%)
```

O169 律 `E(ℓ) = ℓ + b` 係**高 ℓ 漸近** (DESI D_M×6 校準); 其截距 b = 1.11911398
(= 1/⟨v_g⟩₁..₂₂) 唔滿足 E(0) = 1 ⇒ **線性形式喺低 ℓ 唔成立**。

## 5. ★ 判決: −9.3% 係翻譯層/外推假象, 唔係物理差距

```
−9.3% = O169 線性律 E = ℓ + b 喺校準範圍 (高 ℓ) 以外嘅低 ℓ 外推誤差
        + 截距 b ≠ 1 違反非膨脹邊界 E(0) = 1
```

**N4 收窄為可解結構問題**: 推導 E(ℓ) 低 ℓ 形式, 滿足三個邊界條件:

```
(1) E(0) = 1                    ← 非膨脹極限 (H_eff(0) = H₀_idcm = 72.59)
(2) E(ℓ) ≈ ℓ + 1.119  (高 ℓ)    ← DESI D_M×6 (O169)
(3) E(0.0213) ≈ 1.0236          ← SH0ES 局域 (b_eff ≈ 1.002 ≈ 1)
```

線性律 `ℓ + b` 只係高 ℓ 漸近, 唔係全域形式。例如形式 `E(ℓ) = 1 + ℓ + (b−1)·f(ℓ)`
(f(0) = 0, f(∞) → 1) 可同時滿足 — **但 f 嘅推導係結構問題, 唔係 fit** (禁 post-hoc)。
