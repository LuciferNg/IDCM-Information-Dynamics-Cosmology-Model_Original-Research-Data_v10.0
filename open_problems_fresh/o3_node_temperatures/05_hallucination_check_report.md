## 驗證方法說明

幻覺檢查採用**獨立重算** (唔係重跑相同 script):

1. **重新讀原始地圖** (`/tmp/smica2.fits`, `/tmp/nilc.fits`, `/tmp/commander.fits`)
2. **重新平滑**: `hp.smoothing` + `remove_dipole`, sigma=4.17°/(2√(2ln2)) — 唔用任何 cache
3. **重新抽值**: astropy ICRS→Galactic → `hp.ang2pix` → 抽 60 節點
4. **重建圖**: 28° 閾值 → 120 邊 → BFS hop → 著色 → k 計數 → 對徑對
5. **重新統計**: mean/std/min/max, Welch t, 比例, 百分位

NILC/Commander 用 `read_map(nest=True)` + `reorder(n2r=True)` (NESTED→RING 坑)。
