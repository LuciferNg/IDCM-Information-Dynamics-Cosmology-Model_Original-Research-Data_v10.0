# O3: 60 節點實際溫度統計

> **狀態**: ✅ 完成 (2026-08-17)
> **方法**: Planck SMICA 4.17° FWHM 平滑 → remove_dipole → 60 節點抽值
> **核心問題**: A₅ 60 節點網絡喺真實 CMB 嘅溫度統計有冇結構?

## 速覽

| 結果 | 值 |
|:-----|:---|
| 冷斑 (節點 0) | **-134.19 μK** — 98.2% 極端百分位 🟢 |
| 冷熱分離 | -22.31 μK (p=0.06 邊緣) 🟡 |
| 溫度 vs BFS ladder | ρ=-0.05, p=0.71 — **冇 ladder** 🔴 |
| ΔE=0 節點 | mean\|T\| 比例 0.526, permutation **p=0.038** 🟢🟢 |
| 節點 57 謎題 | 已解釋: 著色 = BFS parity, 唔係溫度預測 ✅ |

## 最重要的 3 個發現

1. **冷斑係唯一真正極端節點** — 60 節點中只有節點 0 顯著偏離隨機場 (98.2 百分位, z=-1.98σ)。其他 59 個節點嘅溫度分佈符合高斯。

2. **「冷色/熱色」著色其實係圖論 BFS parity** — `color = 1 - (hop % 2)`, 純粹係二色性嘅必然, 唔係溫度預測器。呢個解決咗節點 57 謎題 (對徑點 +8.21 μK 但被標「冷色」): 佢只係 hop=8 偶數, 唔係預期冷。38% 節點 (23/60) 符號唔匹配, 匹配率 61.7% (p=0.09)。

3. **ΔE=0 零能量節點信號部分確認, 但有紅燈** — 12 個 k=2 節點 mean|T| = 19.05 μK vs 其他 48 個 36.18 μK (比例 0.526), permutation p=0.038。**🚨 但 8/12 節點 (67%) 位於銀河盤 (|b|<20°)**, 隨機期望只有 37% (p=0.038)。剔除銀河盤後高緯度 4 節點仍然顯著 (12.45 vs 33.21, p=0.0074), 所以信號唔係純銀河效應, 但 node 45 (+1.57 μK) 喺銀河盤內不可靠。詳細: `03_red_flag_galactic_plane.md`

## 誠實負結果

- **Fibonacci ladder 模型唔被支持** 🔴 — |T| vs hop 冇顯著相關 (ρ=0.20, p=0.12), BFS 層平均喺 ±25 μK 內隨機震盪
- **冷熱分離只係邊緣** 🟡 — 方向正確 (-22.3 μK) 但 p≈0.06, 剔除銀河盤後 p=0.24 消失
- **無「60 節點整體更極端」效應** — 除咗冷斑外, 節點 std 只係 91.8% 百分位
