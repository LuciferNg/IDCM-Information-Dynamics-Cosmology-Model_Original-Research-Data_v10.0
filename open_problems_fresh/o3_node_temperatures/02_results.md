## 核心結果

### 1. 60 節點溫度分佈

| 量 | 值 |
|:---|:---|
| mean | **-1.25 μK** |
| std | **46.19 μK** |
| min | **-134.19 μK** (節點 0 = 冷斑) |
| max | **+112.00 μK** (節點 53) |
| median | +1.44 μK |
| K-S vs 高斯 | D=0.1035, p=0.509 (✅ 符合高斯) |
| K-S vs 高斯(全圖σ) | D=0.0857, p=0.738 (✅ 符合高斯) |
| A-D | 0.875 (5% crit=0.74, 🟡 邊緣) |
| skewness | -0.468 (偏冷) |
| kurtosis | +1.216 (肥尾) |

**結論: 分佈整體符合高斯** (K-S p=0.51-0.74), 但 A-D 邊緣、略偏負 + 肥尾 — 個別節點有結構。

### 2. 冷色 vs 熱色分離

| 檢驗 | 結果 |
|:---|:---|
| 冷色 mean | -12.41 μK |
| 熱色 mean | +9.91 μK |
| **冷-熱差** | **-22.31 μK** |
| Welch t-test | t=-1.91, p=0.061 🟡 邊緣 |
| Mann-Whitney U | p=0.066 🟡 邊緣 |
| Bootstrap 95% CI | [-23.2, +23.3] (含 0) |
| 排列檢驗 (20000×) | **p=0.061** 🟡 |
| 剔除銀河盤後 | 差=-17.3 μK, p=0.239 (🔴 消失) |

**結論: 冷熱分離方向正確 (-22.3 μK) 但只係邊緣顯著 (p≈0.06)**。剔除銀河盤後 p 升到 0.24 — 信號唔穩健。呢個係誠實嘅 🟡 結果, 唔係 5σ。

### 3. 節點 vs 隨機天空位置 (2000 組)

| 量 | 節點觀測 | 隨機 60 點 | 顯著性 |
|:---|:---|:---|:---|
| 最冷 | **-134.2 μK** (節點0) | mean=-100.4±17.1 | **98.2% 更冷, z=-1.98σ** 🟢 |
| 最熱 | +112.0 μK (節點53) | mean=+89.2±18.1 | 90.2% 更熱, z=+1.27σ 🟡 |
| std | 46.2 μK | 40.9±3.8 | 91.8% 更大, z=1.42σ 🟡 |
| 冷熱差 | -22.3 μK | 隨機 0.0±10.4 | **|差|≥觀測: 3.4%** 🟢 |
| 雙極端聯合 | — | 88.8% 同時更極端 | 🔴 冇聯合效應 |

**結論: 冷斑 (節點 0) 係真正極端 (-134.2 μK, 98.2 百分位), 冷熱差排列 p=3.4% 🟢**。但冇「60 節點整體更極端」效應 — 除咗冷斑外其他節點接近隨機。

### 4. 溫度 vs BFS 距離

| 檢驗 | 結果 |
|:---|:---|
| Spearman (T vs hop) | ρ=-0.050, p=0.71 🔴 冇相關 |
| Spearman (\|T\| vs hop) | ρ=-0.224, p=0.085 🟡 弱 |
| Fibonacci ladder 模型 | ρ=0.202, p=0.122 🔴 |
| 連續模型 F₅φ^(-d/2) | ρ=0.224, p=0.085 🟡 |

**BFS 層平均**: d0=-134.2, d1=-10.4, d2=-3.8, d3=+24.1, d4=-14.2, d5=-1.9, d6=-5.7, d7=+23.7, d8=+8.2

**結論: 冇明顯 ladder 趨勢**。只有冷斑本身極端, 其他層平均喺 ±25 μK 內震盪 — **Fibonacci ladder 模型唔被支持** 🔴。

### 5. 節點 57 謎題 (對徑點 +8.21 μK 但冷色)

**解釋: 著色 = 圖論 BFS parity, 唔係溫度預測器!**

- 著色規則: `color[i] == 1 - (hop[i] % 2)` — 純粹係偶數 hop → 冷, 奇數 → 熱
- 節點 57 (hop=8 偶數) 被自動標為冷色 — 呢個係**二色性嘅必然**, 唔係溫度預測
- 節點 57 唔係孤例: **12 個冷色正溫 + 11 個熱色負溫** (共 23/60 = 38% 唔匹配)
- 匹配率 61.7% (p=0.09) — 弱相關, 但統計上冷色集體偏冷 (mean -12.4 vs +9.9)

**🔑 關鍵洞察: 「冷色」呢個 label 誤導 — 佢係圖論 parity 標籤 (BFS 奇偶), 物理意義係「同一 BFS 層嘅節點共享同色」, 唔係「預期冷溫度」。** 真正嘅冷斑信號係節點 0 本身嘅極端性, 而唔係整個冷色 subset。

### 6. ΔE=0 零能量節點檢驗 (交叉驗證 §21) — 🚨 有紅燈

| 量 | 值 | 預言 | 狀態 |
|:---|:---|:---|:---|
| ΔE=0 mean\|T\| | **19.05 μK** | <0.85× | ✅ 比例 0.526 |
| 其他 48 mean\|T\| | 36.18 μK | — | — |
| Permutation p | **0.038** | <0.05 | ✅ |
| t-test vs 0 | p=0.395 | — | ✅ (一致於零) |
| Bootstrap z | -1.64σ | — | 🟡 |
| node 45 | **+1.57 μK** | ≈0 | 🔴 喺銀河盤! |
| \|T\|<15 | 7/12 | — | ✅ |

**🚨 紅燈 (2026-08-17): ΔE=0 節點 8/12 (67%) 位於銀河盤 (|b|<20°)**, 隨機期望只有 37% (binomial p=0.038)。節點 45 (最靚零點 +1.57μK) 本身喺 b=-8.4° 銀河盤內 — 前景殘餘可能造成假象。

**但高緯度剔除後信號仍然存在**: 4 個高緯度 ΔE=0 節點 mean|T|=12.45 vs 其他 34 個 33.21 (比例 0.375, Welch p=0.0074) 🟢。銀河盤內 8 個 vs 14 個 (比例 0.515, p=0.105) 🟡 邊緣。

**結論降級**: 🟢🟢 → 🟡 部分確認。信號唔係純銀河盤效應 (高緯度獨立支持), 但 2/3 節點受污染, node 45 不可靠。詳細: `03_red_flag_galactic_plane.md`
