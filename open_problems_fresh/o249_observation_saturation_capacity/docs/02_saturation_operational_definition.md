## 一、問題

調律者原始觀察：多台望遠鏡同拍同一位置 → 「數據抖動」；全息投影容量可能同 528 相關。

拍頻信道實際容量 C_beat = 0.4338 bits；row Z₂ 退化 row(r)=row(44−r)；有效秩 22。

**Q2 問：微觀「投影通道飽和」= IDCM 邊個結構量？「抖動」喺 IDCM 入面係咩嘅操作後果？**

## 二、飽和嘅三層結構（操作定義）

### L1 — 容量層（儲存預算）
```
C_obs = N_d·log₂(B) = 44·log₂(4) = 88 bits = Σγ_odd   （F7a: dev=0）
階梯 {88, 132, 264, 528} = N_d×{2,3,6,12}             （F7b/c）
```
88 bits = 觀察者側嘅儲存預算（Σγ_odd over 44 觀察者模）。

### L2 — 自由度層（信息 DOF）
```
SVD 有效秩(σ > 1e-6·σ₁) = 22 = N_d/2 = Z₂ 軌道數      （F1）
row(r) = row(44−r), max|Δ| = 3.47e-17                 （F4）
```
44 個輸入喺信道層塌縮為 22 個信息 DOF。**補充精確化（本輪新實測）**：
row 1..43 組成 21 條精確 Z₂ 對（3.47e-17）；row 22 自對偶；row 44（Nyquist, γ₄₄=4=B）
向量 distinct 但信息近零（BA 最優支撐永遠唔含佢；F6 平台覆蓋佢嘅邊際增益 < 1e-13）。
O151「22 獨立 row」= SVD 有效秩（信息層），唔係逐 row 向量計數（計數 = 23）——
本定義以有效秩為準（信息層），與 O151 判決一致。

### L3 — 飽和層（本 O 操作定義）
**「飽和」= 當讀取方案假設嘅獨立通道數超過信道實際信息 DOF 時，新增讀取嘅邊際互信息結構性歸零，而試圖將簡併通道當獨立資訊處理 ⟹ 觀測不一致（抖動）。**

三個結構性指紋（全部由 scripts/01 實測）：
```
S1  鏡像對信息為空: I(X∈{r,44−r}; Y) = 3.6e-15 bits ≈ 0  ∀r=1..21   （F5）
    —— Z₂ 對偶輸入傳輸 0 位元：輸出分佈逐元素相等 ⟹ 讀者冇辦法分辨
       輸入係對中邊個 ⟹ 對內信息 = 0（精確, 唔係「少」）
S2  飽和曲線平台: C(S₁)=0, C(S₂)=0.43381827 = C_beat, k≥2 全部
    |C(S_k) − C_beat| ≤ 4.24e-13                              （F6）
    —— 信道喺第 2 個獨立 row 已達全容量；之後任意加 row 邊際增益 < 1e-13
S3  超容量解碼必然出錯: Shannon 定理 —— 每符號要求 > 0.4338 bits 嘅解碼錯誤率 → 1
```
操作後果（「抖動」嘅 IDCM 定義）：若觀測程序假定 44 個獨立輸入（忽略 Z₂ 簡併），
21 對精確相等 row 嘅讀數差異冇任何物理來源 —— 演算法將佢哋歸因於「噪聲/抖動」。
**呢個「抖動」係簡併結構嘅投影，唔係額外自由度。**

## 四、「飽和」嘅宏觀翻譯（Q3 承接）

操作層內容（宏觀可證偽形式）：

```
IDCM 主張（微觀）: 簡併通道對返回零新信息（S1: 精確 0; S2: 平台 4e-13）
宏觀可證偽對應 : 「對稱配置通道對嘅信息冗余 = 1（精確）」
                  ⟹ 宏觀兩通道同讀一源嘅邊際增益 G = 0
```

⚠️ 命名≠解釋鐵律：呢度嘅宏觀翻譯**唔係**「宏觀抖動 = 飽和」命名 ——
宏觀抖動有明確物理成因（大氣/時鐘/儀器噪聲, docs/01 A1/A3/A6）。
**IDCM 結構同宏觀抖動嘅統計結構一致與否 = Q3 盲測嘅對象，唔係本例定義嘅預設。**

## 五、對 Q4 嘅預註冊（承接 docs/03）

528 嘅「飽和容量」身份：528 = C(33,2) = B²·33（O147 五重身份之一）。
宏觀候選讀法唯一 = 「33 元素陣列嘅基線數」；但 N=33 冇宏觀獨立錨（天文冇 33 元素 magic
number）⟹ 池閘 + 判決規則預註冊見 docs/03 §七。
