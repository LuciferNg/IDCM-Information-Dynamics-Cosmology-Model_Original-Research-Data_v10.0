## 四、預註冊測試（T1-T3 — threshold 零放寬）

### T1 — Z₂ 對稱通道嘅邊際增益 G（宏觀 vs 微觀核心對照）
- **IDCM 預言（F5/F6）**：Z₂ 對偶通道返回零新信息 ⟹ 第二通道邊際增益
  G = [I(pair) − I(single)] / I(pair) = **0**（精確, 3.6e-15 bits）
- **宏觀操作化**：兩台望遠鏡喺對稱配置（同源同拍）：
  G_macro = [I(兩台) − I(單台)] / I(兩台)，其中 I 由實測強度互相關 r² 經
  高斯場公式 I = −½log₂(1−r⁴) 計（D1: r²(0)=0.84±0.07）
- **判決規則（預註冊）**：
  - G_macro ≤ 1e-3 → T1 支持（宏觀兩通道零增益 → 同構候選成立）
  - 1e-3 < G_macro ≤ 5σ 帶 → T1 部分（未定；需儀器校正模型：bandwidth/偏振/損耗）
  - G_macro > 5σ → T1 否決（宏觀兩通道有獨立噪聲平均增益 ⟹ 非 IDCM 型精確簡併）
- **Ex-ante 聲明（凍結時已寫低）**：實測 G_macro > 0 幾乎必然（獨立噪聲 → √2 SNR 增益），
  T1 預期「否決」——即「宏觀兩台望遠鏡同拍 = IDCM Z₂ 簡併」**機制層唔成立**。
  呢個否定本身係結構發現：精確簡併只存在於無噪聲極限。

### T2 — 信息 DOF 比例（有效秩 = 通道數/2 ?）
- **IDCM 預言（F1）**：N=44 信道有效秩 = N/2 = 22。
- **宏觀操作化**：N 元素陣列嘅 frame/相關算子 SVD 有效秩 r_eff（D4: B1 natural modes /
  D5: B2 模型）；判據：|r_eff/N − ½| ≤ 0.1 → 支持；否則否決。
- **Ex-ante 聲明**：天文陣列 rank 語義 = min(N, q_sources)（B2）≠ N/2 ⟹ 預期否決
  （**秩語義類別錯誤**風險高）；若 D4 對稱陣列模型顯示本徵值成對簡併（parity ± 對）
  ＝ 數學形式對齊（🟡），升唔到機制層 🟢。

### T3 — 飽和點位置（平台喺第 2 個獨立通道）
- **IDCM 預言（F6）**：信息平台喺 k=2（C(S₂)=C_beat, 之後 ΔI ≤ 4e-13）。
- **宏觀操作化**：D1 HBT I(d) 曲線 —— 兩檢測器信息隨基線 d 變化；「第 2 通道增益」
  喺 d→0 極限應為 0（若同構）。判決：|ΔI(d→0)| ≤ 1e-3 → 支持; 否則否決。
- **Ex-ante 聲明**：HBT r²(0)=0.84±0.07 → I(0) = 0.88 bits > 0 → T3 預期否決
  （宏觀 d→0 兩通道唔係零增益）。

### T1-T3 決策表（合併判決）
```
全部支持 (T1-T3 ✅ + MC null 過)  → 🟢 宏觀↔微觀同構成立（機制層）; Q4 528 有資格

```

## 五、MC null 計劃（每個支持判決必過）

- **N1 隨機信道對照**：同維度（44×44）隨機 row-stochastic 矩陣 10⁷ 個：
  計「有效秩 22」「鏡像對信息 < 1e-12」「k=2 平台」三指紋同時出現概率 ——
  必須 < 1e-7（5σ 級）先有資格講「IDCM 指紋唔係任何信道都有」。
- **N2 宏觀置換 null**：D1/D2/D3 數據嘅採樣/時間置換 10⁵ 次，量測 G_macro /
  秩比在置換下的分佈 —— 判決用實測值 vs 置換分佈嘅 z-score。
