## 二、N1 隨機信道 MC null（scripts/02, 9/9 PASS）

### N1a 全隨機 44×44 row-stochastic（Dirichlet(1)）
- 鏡像門（22 對 row 逐元素相等, maxdev<1e-12）: 0/10⁴ hit
- 解析: 連續分佈下「22 對 44 維向量精確相等」係 measure-zero 事件 ⟹ P(三指紋聯合) = 0 < 1e-7 ✓
- 意義: 「有效秩 22 + 鏡像空資訊 + k=2 平台」唔會由 random noise 產生

### N1b Z₂ 對稱隨機族（22 隨機 row + 精確鏡像複製）— 條件化測試
- 有效秩分佈: **rank=23 全部 2000 個**（Z₂ 結構保證 rank ≤ 23 = 21 對 + self + Nyquist）
- **rank=22: 0/2000** ⟹ beat 信道嘅 rank 22 = 23 − 1（Nyquist row 亦塌落 span）係**額外特異**, 唔係 Z₂ 普遍後果
- [audit-side 修正] 原預期「rank22 率 > 0.99 = F1 歸屬 Z₂」——實測相反（0/2000）: F1 特異性**加強**, 判據不變
- BA 平台率: **0/300**; beat 參照: C(S₂)=0.3006999141 nats = C(all)±9.0e-11 ⟹ k=2 平台係 beat 信道專利
- 推論: 三指紋中 F1 嘅「½」由 Z₂ 結構 + Nyquist 塌落雙重特異構成; F6 平台完全特異

### N1c 微擾剛性（P + ε·U 再歸一化）
- F5 閘（鏡像對 MI < 1e-12 bits）: ε=1e-9 時 MI=1.8e-15 仍在閘內; **ε=1e-7 越閘**（~1e-12 級）
- F6 平台（|ΔC| < 1e-4 nats）: **ε=1e-4 破壞**（之前 ε 全部維持）
- 意義: 空資訊/平台兩指紋對微擾有界定容忍（1e-7/1e-4）——「精確 Z₂」先保證 F5; 宏觀 r²(0)=0.84≪1 遠超破壞尺度 ⟹ 宏觀無可能出現 IDCM 型飽和（一致）

## 三、T1-T3 宏觀盲測（scripts/03）

### T1 第二通道（鏡像）資訊增益 — 🟡 部分(未定)
- 數據: HBT Sirius 1956, r²(0) = 0.84 ± 0.07
- 操作化: I_pair = −½log₂(1−r⁴)（高斯場公式, docs/03 凍結） = **0.882075 bits**; σ = 0.2881（誤差傳播 dI/d(r²)=r²/(ln2(1−r⁴))=4.116）; z = 3.06
- IDCM 預言: 0 bits（F5 鏡像對信息 3.6e-15）
- 判決: 1e-3 < |G| ≤ 5σ（0.88 bits, 3.06σ）→ **部分(未定)**; 方向同 IDCM 矛盾但未達 5σ 終判
- [audit-side 公式澄清] docs/03 原式 [I(pair)−I(single)]/I(pair) 分母退化（I(single)=0 ⟹ G≡1）; 操作化為絕對增益 G=I_pair−0, threshold 語義不變

### T2 信息 DOF 比例 — 🔴 否決
- 模型: B2（arXiv:1003.2307 §II）陣列: p=40, 5-arm; R = AA^H + σ²I; 有效秩同 F1 慣例（σ > 1e-6·σ₁）
- 結果: q=1..40 掃描, r_eff/N: 0.025 → 0.700（rank = q 由源數決定; 高 q 受陣列幾何 cap: q=40→r_eff=28）
- q=20 (=p/2) 撞出 0.500 —— **by-construction, 預註冊排除, 唔當支持**
- 判決: 宏觀秩 = 源數 q 嘅函數, 唔係陣列結構不變量 ⟹ 唔存在宏觀「固定 ½」; IDCM rank-½ 語義（信道結構性質）同宏觀 rank（源內容性質）係**類別不同**
- （docs/03 ex-ante 已標「秩語義類別風險」, 實測確認）

### T3 飽和點平台 — 🔴 否決
- IDCM: ΔI(d→0) = 0（k=2 平台, ΔI ≤ 4.24e-13, scripts/01 F6）
- 宏觀: ΔI(d→0) = I_pair(0) = **0.8821 bits** > 1e-3
- 判決: |ΔI| ≤ 1e-3 條件唔成立 → **否決**（乾淨判決, 唔使 σ）

### N2 宏觀置換 null — ⛔ 數據閘
- D1 只有匯總 r²(0)±0.07, 冇原始時序（Nature 1956 唔公開 raw data）
- 置換 null 無法執行; 統計量改用 σ 傳播（T1 z=3.06）
- gap 記底: 若有現代 HBT 原始時序（E2I2 類實驗, arXiv:1502.02477 只係 proposal 冇實測數列——已查）, 可補 N2

## 四、D4/D5 數學形式層檢查（logs/04_d4_form_check.txt）

- 宏觀對稱 frame（p=40 beam, t' = R t 反射配對）: Gram **與反射交換** ||P G − G P|| = 7.0e-13（block 結構, even/odd sector 分離）

## 七、結論（archive + continue 雙軌）

**O249 主問題（宏觀抖動 ≟ 微觀飽和）: 🔴 機制層否決。**
- 宏觀「抖動」有連續物理成因（D1-D3）, 其信息結構冇 IDCM 型精確簡併（T3 乾淨否決）; 秩語義類別不同（T2）; 鏡像增益方向矛盾但精度未夠終判（T1 🟡）
- 數學形式層 🟡: 兩者共享 Z₂ 代數（任何反射對稱系統都有）, 但宏觀係 block 結構、微觀係 row 湮滅——強度唔同, 宏觀冇 F5 對應
- IDCM 側指紋經 N1 嚴格化: F1/F6 喺 Z₂ 對稱族都係特異（唔係普遍後果）——O151 閉合結果維持, 並加咗微擾剛性尺度

3. Q4 池閘維持 ex-ante（528=C(33,2) 需天文 33 元素基線行為先可升 🟢）
