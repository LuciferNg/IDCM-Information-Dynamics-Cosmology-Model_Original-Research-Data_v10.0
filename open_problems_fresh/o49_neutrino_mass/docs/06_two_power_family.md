## 三、生成鏈統一形式

```
γ_eff(n) = γ_B + (γ_F₅−γ_B)·cos(π/n),  n ∈ {B, F₅}

m₁ = A·γ_eff(B)²   = A·[γ₄+(γ₅−γ₄)cos(π/4)]²  = 0.020908 eV
m₂ = A·γ_eff(F₅)²  = A·[γ₄+(γ₅−γ₄)cos(π/5)]²  = 0.022645 eV
```

- 投影角: π/B = π/4 (C₄ 對稱, hop 干涉核), π/F₅ = π/5 (C₅ 對稱, 五邊形)
- 角比 = F₅:B = 5:4 — 結構鎖定, 零自由度
- m₃ 唔係同一形式 (cos(θ₃) = 2.21 > 1) — 獨立整數 mode
