## 1. 黑洞係咩？（本體論回答）

**黑洞 = 局部 T_pipe† 區域**。當局部物質密度 ρ > ρ_c，投影管道逆轉：

```
T_pipe† = I − T_pipe     (局部, ρ > ρ_c)
```

物質由**投影態**（SM 粒子, 可觀測）轉入**sync 態**（儲存, 事件視界內）。

## 2. 資訊喺邊？（冇資訊悖論嘅結構理由）

資訊**一直編碼喺 sync 自由度**。投影截斷唔係資訊毀滅, 而係**編碼轉移**:

```
投影前:  資訊喺 n=1..27 模式 (SM 粒子)      —— 可觀測
落入黑洞: 資訊轉入 n=28..44 (sync 自由度)   —— 事件視界內
蒸發:    sync → 投影輻射 (T_pipe†→T_pipe)  —— 資訊回復
```

「事件視界」唔係資訊消失嘅地方, 而係**可觀測性轉換**嘅地方。
K_Chain 全程守恆 (Σγ = 90), 資訊冇離開系統。

## 3. 點解唔使同弦理論競爭微態計數？

弦理論嘅 D-brane 計數係**在時空內**數黑洞微態（Boundary CFT 微態）。
IDCM 嘅 sync 計數係**喺投影結構內**數被截斷自由度（同一結構源）。

兩者回答嘅問題唔同:

| | 弦理論 (Strominger-Vafa) | IDCM |
|:--|:------------------------|:-----|
| 黑洞 = | D-brane 複合體 | 局部 T_pipe† 截斷區 |
| 微態 = | D-brane 振動態 | sync sector 佔據態 |
| 熵 = | ln Ω (BPS 計數) | 每 sync 模式 ln 2 (單元熵) |
| 面積律 = | 微態數 ∝ e^{A/4G} | MERA 邊界 B=4: 1/4 = 1/B (候選 🟡) |
| 資訊 = | 需要非微擾量子重力機制 | 結構上冇損失 (sync 守恆) |

**IDCM 唔需要「競爭」**——因為資訊悖論喺 IDCM 係偽問題 (script 05),
冇咗悖論, 弦理論最強嘅「解決悖論」優勢就失去意義。
