## 2. 為何必須做（下游阻塞，三條）

### 2.1 星系殘骸問題**不可證偽**
```
τ_rec / t_true(11,100.9 Gyr) = 6.42×10³ 倍
τ_rec / T_ring(84.637 Gyr)   = 8.42×10⁵ 圈
```
任何可觀測窗口內，殘骸**準永久停留** ⟹ IDCM 與 ΛCDM 嘅觀測預言**相同**。
分辨唯一途徑 = `τ_rec` 獨立推導。

### 2.2 質子衰變 / 返池邊界不可定
```
τ_p (O88/PD, 10-02) = 2.891×10³⁸ – 1.388×10⁴⁰ yr
τ_p / T_ring        = 3.42×10²⁷ – 1.64×10²⁹ 圈
t_true / τ_p        = 3.84×10⁻²⁶            ← 質子衰變從未啟動
```
要講「質子衰變 vs 返池」邊界，需 `τ_rec` 定值。

### 2.3 ★ O173 P10/P11 有**循環論證**風險
P10（冇「回收中」黑洞群）現時只由 `τ_rec ≫ 13.8 Gyr` 支撐，
而該 `τ_rec` 係由**觀測缺失**反推 ⟹ 用觀測缺失反推 `τ_rec`，再用 `τ_rec` 解釋觀測缺失。
`τ_rec` 一旦有結構推導，P10 即由「一致性敘述」升級為**真預言**。
