## 1. Strominger-Vafa 做咗啲乜（簡述）

Strominger-Vafa (1996) 數出 D1-D5-P 黑洞嘅 BPS 微態數:

```
Ω ~ exp(2π √(Q₁Q₅Q_p/2))     (微態數)
S = ln Ω = 2π √(N₁N₅N_p/2)   (熵)
⟹ 同宏觀 S_BH = A/4G 匹配 (零自由參數)
```

**成就**: 首次俾咗黑洞熵嘅微觀解釋 —— 熵唔係「填入公式」,
而係 D-brane 複合體嘅合法微態數。

## 3. 關鍵差異：IDCM 嘅「微態」係有限嘅

弦理論: 無限維弦 Fock 空間 → 微態數天文數字 → 匹配任意黑洞熵。
IDCM: 44-site 格點 → 17 sync 模式 → **有限**微態 (次指數)。

**呢個差異係結構性嘅**:

- IDCM 係**低能有效框架** (R_world/44 ~ 10²⁴ m 格點間距)
- 宏觀黑洞 (10⁷⁷ 位元) 嘅微態活喺**次格點尺度**
- IDCM 格點層只提供「單元熵」+ 面積律來源 (MERA 邊界)

**結論**: IDCM 唔會、亦唔需要做到 D-brane 式嘅大數微態計數。
IDCM 嘅「黑洞熵」回答係: **熵 = 投影截斷資訊量**, 唔係「內部狀態數」。

## 5. 直接回答 O121 問題 #5

> 「是否需要與弦理論競爭黑洞微態計數？」

**唔需要「競爭」——但需要「對應」**:

1. **競爭係冇意義嘅**: IDCM 冇時空奇點、冇量子重力非微擾問題,
   弦理論嘅黑洞微態計數係為咗解決嗰啲問題而存在。IDCM 冇嗰啲問題。

2. **對應係必須嘅**: IDCM 必須解釋「點解熵 ∝ A」——O121 已經
   建立 (MERA 邊界 1/4 = 1/B 候選) + 微觀自由度身份 (sync sector)。

3. **真係嘅競爭位**: 冇。兩者係唔同層次嘅理論, 各自回答各自嘅問題。
   弦理論由微觀 (弦) 往上, IDCM 由宏觀結構 (88-site) 往下。
