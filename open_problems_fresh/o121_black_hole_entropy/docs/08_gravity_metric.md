## 1. 關鍵區分：微觀資訊層 vs 宏觀引力層

這是 IDCM 一個重要的兩層結構，之前沒講清楚：

| 層次 | 對應 | 機制 |
|:-----|:-----|:-----|
| **微觀資訊層** (script 07) | sync 模式存在，觀察者讀唔到 | 接收端截斷 (V=σ·A=0) |
| **宏觀引力層** (本文件) | sync 能量集中 → 度規彎曲 | 相關函數 → 度規 |

**兩件事獨立**：接收端截斷解釋「資訊點樣儲存」，度規彎曲解釋「點解有時空曲率」。佢哋係**同一個 sync 能量集中**嘅兩個不同層面嘅表現。

## 2. 度規 = 相關函數（v9.0 已建立）

v9.0 `15_gravity_emergent.md` 已經給出 IDCM 的湧現度規：

```
g_μν(x) = ∂_μ∂_ν C(x,y)|_{x→y}      (度規 = 相關函數二階導數極限)
Ω(x)² = ⟨|W(x)|²⟩/⟨|W₀|²⟩           (共形因子，依賴局部 W-field 強度)
V(r) = −G·M/r + O(1/r³)             (牛頓極限)
G = 1/M_Pl²                           (引力常數)
```

**核心**: 黑洞質量 M = sync 能量集中 (O33: ΔE_sync = +E_BH)。
sync 能量集中 → 局部 W-field 強度 ⟨|W(x)|²⟩ 改變 → 共形因子 Ω(x) 改變
→ 度規 g_μν 改變 → 時空彎曲。

**傳播端（W-field 模式 A_n）不變，但度規（相關函數的幾何）變了。** 這就是發送端不變、時空仍然彎曲的原因——彎曲的不是波的個體，而是波聚集後改變的整體相關函數幾何。

## 3. 三個宏觀效應的 IDCM 對應

### 3.1 時間變慢 ✅
```
g_00 = 1 − 2GM/rc²  (Schwarzschild 度規弱場極限)
太陽表面: g_00 = 0.99999575,  時間膨脹 ≈ 2.123e-6 / 秒 (標準 2.12e-6)
```
度規 00 分量 < 1 → 時間變慢。sync 能量集中處，相關函數幾何使度規時分量收縮。

### 3.2 史瓦西半徑 ✅
```
R_s = 2GM/c² = 2954 m (太陽質量, 標準 ~2953 m)
事件視界: g_00(R_s) = 0
```
史瓦西半徑 = sync 能量集中的度規奇點位置，同時也是 T_pipe† 區域的半徑。
**兩個描述是同一半徑**——微觀上是接收端截斷，宏觀上是度規 g_00→0。

### 3.3 引力透鏡 ✅
```
偏折角 θ = 4GM/(c²b) = 1.7516 arcsec (太陽, 標準 ~1.75 arcsec)
```
光（W-field 激發）沿彎曲度規的測地線傳播 → 透鏡偏折。
**X 透鏡是度規層效應，跟接收端截斷無關。**
