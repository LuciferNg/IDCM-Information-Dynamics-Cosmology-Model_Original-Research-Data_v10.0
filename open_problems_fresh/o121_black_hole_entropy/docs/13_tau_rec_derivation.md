`τ_rec` = 黑洞 (`T_pipe†` 反投影區) 捕獲之物質返池嘅時標。
現值 `7.1247×10¹⁶ yr` 出自 O173 `docs/09`「**最寬鬆回收假設**」(

## 1. 主路線: Poincaré 構型復現

### 推導

```
P1  黑洞 = 局部 T_pipe† 區, 「凍結」阻挫扇區嘅一個特定構型      (本 O docs/07, 11/11)
P2  阻挫扇區構型空間 = 2^20 (MIS = 20 拓撲位元, 衝突圖 0 邊)     (O7, 133/133)
P3  每 T_ring 全扇區被重寫 (61.5/ln2 = 88.73 bits ≥ 20 bits)     (O175 docs/01, 19/19)
    ⟹ 重排頻寬冗餘 4.436× ⟹ 每圈完全混合
──────────────────────────────────────────────────────────
⟹ 返池 = 等待該特定構型復現 (Poincaré 回歸)
⟹  τ_rec = 2^{MIS} · T_ring = 2^20 · T_ring
```

### 數值

| 量 | 值 | 來源 |
|:---|:---|:-----|
| `T_ring` | **8.463654×10¹⁰ yr** | 2π/ω_ring, ω_ring = 72.59 (O73) |
| `MIS` | **20** | O7 (整數, 唔可調) |
| `2^20` | 1 048 576 | — |
| **`τ_rec`(結構)** | **8.8748×10¹⁶ yr** | 2²⁰·T_ring |
| `τ_ref` (觀測尺度) | 7.1247×10¹⁶ yr | O173 docs/09 |
| **偏差** | **+24.56%** | ratio 1.2456 |

### 為何唔係「後驗擬合」(null 測試)

- 連續解 `b = log₂(τ_ref/T_ring) = ` **19.6831**
- O7 嘅整數 **20** 落喺 **1.58%** 內 (指數空間)
- 指數 `b ∈ [1,44]` 中, 令 `2^b·T_ring` 落喺 `τ_ref ±25%` 者 **唯一 = 20**
- ⟹ 指數**唔係**為咗撞 τ_ref 而選; 佢由 O7 獨立給出, 而恰好落喺窗內

## 5. 剩餘缺口 (誠實)

1. 🔴 **+24.56% 未解釋**: 主路線 vs 觀測尺度之差。候選解釋:
   (a) 「最寬鬆假設」之高估 (P-G8a: 只有 80.3% UHECR 來自返池) —
   **可證偽**, 需 UHECR 成分分析;
   (b) `MIS=20` 需嚴格重導 (O7 之 20 位元基於 SMICA 飽和著色);
   (c) 缺一個 O(1) 結構因子 (未找到)。
2. 🟡 **R1b 與 R2b 之差 (2.70%)**: 兩路線是否深層同一, 未證 (`2^20` vs `N_d φ^{(N_d−μ²)/2}` 之代數關係未知)。
3. 🟡 **`η = φ⁻²¹` 之動力學來源** (handoff R2): 本檔只**用** η 做對照, 未由譜導出 —— 仍開放。
