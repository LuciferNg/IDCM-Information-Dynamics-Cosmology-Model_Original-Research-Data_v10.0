## 1. 微觀自由度身份

**黑洞微態 = sync sector 嘅佔據組態**。

sync sector 係投影算子 T_pipe 嘅 kernel：

```
ker(T_pipe) = {n = 28..44}        17 個模式 (n* = N_d−L₆+1 = 27)
瓶頸 n=27: 22.8% sync 分量        (1−f_proj) × γ₂₇ = 0.6155
E_sync = Σ(1−σ_n)γ_n = 61.5       (L₁₀/2, 精確)
```

⚠️ **能量量綱辨析** (2026-09-24, 回應 o210 待審計旗標): O121 出現三個相近量, **唔可混淆** —

| 量 | 值 | 定義 |
|:---|:---|:-----|
| E_proj (結構) | 28.5 | Σσ_n·γ_n = L₅+1/2 (精確有理數) |
| E_sync (結構) | 61.5 | Σ(1−σ_n)·γ_n = L₁₀/2 = 90 − 28.5 (精確) |
| 譜截斷 n≥28 | 60.8845 | Σ_{n=28}^{44} γ_n (嚴格指數區間) |
| 譜截斷 n≤27 | 29.1155 | Σ_{n=1}^{27} γ_n |
| Ω_Λ×Σγ (近似) | 61.4953 | 只係 0.008% 近似, **非精確** |

關係: `E_sync = 60.8845 + (1−f_proj)·γ₂₇ = 60.8845 + 0.6155 = 61.5`。
投影**唔係**尖譜截斷 (n=27 係部分模式 bottleneck) ⟹ 結構值 ≠ 譜區間和
(差 0.6155 ≈ 8/13)。o210 line 57 旗標確認: 兩者係**唔同量**, 非矛盾。

> ⚠️ **驗證修正附註 (2026-10-02, 回應 O222 審計 → register handoff)**: 上句「≈ 8/13」**撤回**。
> `E_bottleneck = 0.6154630941421971` 對 `8/13 = 0.6153846153846154` 之絕對偏差 **7.848×10⁻⁵**
> (相對 **1.28×10⁻⁴**) —— 屬小數級近似 (後驗擬合風險), **唔係結構等式**。
> 權威值 = `0.6154630941421971` (由 γ 譜 + f_proj 導出; 兩路重算一致至 1e-14)。

每個 sync 模式係玻色子（佔據數 n_k ≥ 0），微態 = 整數解
{n_k} 令 Σ n_k·γ_k = E。呢個就係 IDCM 嘅「D-brane 計數」對應物。

## 2. 格點層計數（可嚴格做）

動態規劃計算 Ω(E=61.5)（17 模式, 見 script 03）：

```
Ω(61.5) ~ 4×10⁵ (縮放尺度下)
S_lattice = ln Ω ~ 12.9 (次指數)
漸近: S ~ 17 ln E − ln Πγ_k − ln(16)! ~ 17.8
位元計數: 17 × ln 2 ≈ 11.78 (每模式一位元)
```

**結論**: 格點層（44-site 鏈）提供**單元熵**——每個 sync 模式
承載 ln 2 位元。17 個模式 = 17 位元 ≈ L₆−1 = F_proj。

## 3. 面積律放大（誠實標記 🟡）

宏觀黑洞熵 S = A/4G = 4πM²/M_P² 係**線性於面積**。
44-site 格點層嘅熵係**次指數** (ln E 階)。兩者點接通？

| 層次 | 自由度 | 熵階 | 狀態 |
|:-----|:-------|:-----|:----:|
| 格點層 (44-site) | 17 sync 模式 | ~17 ln 2 (單元) | ✅ 可計數 |
| 次格點 (Planck) | A/ℓ_P² 邊界單元 | A/4G (線性) | 🟡 需微結構 |
| MERA 邊界 | B=4 分支連結 | N_b ln 2, 1/4=1/B | 🟡 候選 |

**IDCM 結構貢獻**: 熵 = 投影截斷資訊量（冇毀滅, script 05）。
**面積律係張量網絡邊界嘅自然結果**（MERA B=4 分支）, 唔係額外假設。

⚠️ **誠實標記**: S_BH = A/4G 嘅「1/4」= 1/B (K_Tree 分支因子)
**係結構候選, 未嚴格證明**。44-site 格點層本身唔足以計數宏觀黑洞
(~10⁷⁷ 位元), 需要次格點微結構 —— 呢個係 O121 嘅 🟡 開放位,
