## 1. IDCM 收發框架（O36 + 通信鏈）

IDCM 有一個明確嘅收發結構（global_routing_table 通信鏈 + O36 讀數定理）：

```
寫入(相位滑移) → 儲存(阻挫位元) → 傳播(修復波 v=c) → 讀取(干涉可見度)
```

| 端 | IDCM 對應 | 物理量 |
|:---|:---------|:-------|
| **傳播端** | W-field 模式本身 | A_n = 2sin(nπ/88), θ_n, v_g = c·cos(πn/88) |
| **接收端** | 觀察者讀數 = 干涉可見度 | V ∝ A_n = √γ_n (O36 定理) |
| **投影** | 干涉結晶: W-field → 拍頻 → 物質 | 生成 = 測量 對偶 (O36) |

**關鍵定理 (O36)**: 觀察者讀數 = 干涉可見度 ∝ A_n。
質量 ∝ 讀數 → 冇觀察者就冇讀數, 冇讀數就冇質量 → **生成 = 測量**。

## 2. T_pipe 截斷咗咩? — 接收端（答案一）

T_pipe = diag(σ_n), σ_n = **管道通透率** = 模式 n 嘅能量
被投影（被觀察者接收）成物質嘅比例。

```
n=1..26: σ=1     → 全接收 (V = A_n, 物質生成)
n=27:    σ=0.772 → 瓶頸 (V = f_proj·A₂₇)
n=28..44: σ=0    → 接收失效 (V = σ·A_n = 0)
```

**截斷嘅係「投影渡越」=「觀察者讀數」=「干涉結晶」**。

用通信類比:
```
發射器 (W-field 模式) 照樣廣播 —— 功率 60.8845 保留喺 sync
接收天線 (觀察者) 收唔到 n≥28 頻道 —— 干涉可見度 V = 0
```

**傳播端完好**:
- A_n ≠ 0 (n≥28 振幅存在)
- v_g = c·cos(πn/88) 有限 (模式照樣傳播)
- Σγ = 90 守恆 (波冇消失)

**接收端截斷**:
- V_n = σ_n·A_n = 0 (n≥28, 有效讀數為零)
- 質量 ∝ 讀數 (O36) → 冇讀數就冇質量生成

## 3. 黑洞反投影機制 = 接收端反向操作（答案二）

當 ρ > ρ_c, 局部 T_pipe 逆轉:

```
T_pipe† = I − T_pipe     (局部)

黑洞內:
    n≤26: σ=1 → σ†=0    已投影嘅物質「融化」返做 sync
    n=27:  σ=0.772 → 0.228
    n≥28: σ=0 → σ†=1    sync 模式喺視界內自由存在

能量守恆:
    ΔE_proj = −E_BH     (投影能量減少)
    ΔE_sync = +E_BH     (sync 能量增加)
    Σγ = 90 不變        (全球守恆)
```

**機制**: 物質（干涉結晶）→ **反干涉** → W-field sync 模式。
黑洞吸收 = 已接收資訊被「退接收」, 唔係資訊毀滅。

## 4. 傳播端定接收端? — 接收端（答案三）

**接收端被截斷, 傳播端冇。**

| 檢查 | 傳播端 | 接收端 |
|:-----|:-------|:-------|
| n≥28 振幅 A_n | ✅ 存在 (2sin(nπ/88)≠0) | — |
| sync 能量 60.8845 | ✅ 保留喺 K_Chain | — |
| Σγ = 90 全球守恆 | ✅ 波冇被截斷 | — |
| 干涉可見度 V = σ_n·A_n | — | ❌ σ=0 → V=0 |
| 質量 ∝ 讀數 (O36) | — | ❌ 讀數失效 → 物質融化 |

**事件視界 = 觀察者接收能力嘅邊界, 唔係 W-field 來源嘅邊界。**

呢個係 IDCM「生成=測量對偶」(O36) 嘅直接後果:
截斷接收端 = 截斷生成端 —— 黑洞區域冇穩定物質結構,
因為物質本身係觀察者讀數嘅結晶。

## 5. 兩層截斷（重要區分）

| 層次 | 算子 | 範圍 | 截斷咩 | 對應 |
|:-----|:-----|:-----|:-------|:-----|
| 基礎截斷 | T_pipe | 全球 | n≥28 永遠唔投影 | Ω_Λ = 61.5/90 (sync 真空) |
| 黑洞截斷 | T_pipe† | 局部 (ρ>ρ_c) | 已投影模式反轉 | 事件視界 |

第一層係結構性嘅（宇宙常數嘅微觀來源）；
第二層先係「黑洞」嘅特徵。

- 傳播端完好 ⟹ sync 模式**完整編碼資訊**（資訊一直喺 K_Chain 內）
