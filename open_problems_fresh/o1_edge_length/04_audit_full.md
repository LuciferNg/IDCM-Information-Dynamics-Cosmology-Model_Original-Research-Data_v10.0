## 2. 公式等價性核對（獨立驗算）

```
θ = arccos[cos α + (1−cos α)(v·n)²],  α = 120°, v·n = cos δ      (06 腳本形式)
  = arccos[−1/2 + (3/2)cos²δ] = arccos[(3cos²δ−1)/2]

θ = arccos(cos²δ − sin²δ/2)                                      (07 / 文檔形式)
  = arccos(cos²δ − (1−cos²δ)/2) = arccos[(3/2)cos²δ − 1/2]      ← 完全相同

獨立重算: 兩式差 = 0.00e+00°，θ = 26.09135714°，偏差 0.00001114°
```

✅ 兩條公式嚴格等價，文檔採用之形式正確。
