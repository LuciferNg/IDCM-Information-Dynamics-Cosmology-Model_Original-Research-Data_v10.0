## 1. 問題

邊長閉合鏈: 冷斑位置 → δ → θ (26.0913°)
θ 公式已閉合 (0.000011°), 但 δ = 15.1085° 本身有冇公式?

## 2. 發現 (scripts/09_delta_formula.py, 10_delta_group_word.py)

### 2.1 冷斑喺頂點-面大圓上 (關鍵!)

```
δ3 (到頂點) = 15.108516°
δ5 (到面)   = 22.650938°
軸角 3-5    = 37.3774°
δ3 + δ5     = 37.7595° ≈ 軸角 ✅ (差 0.38° = 球面過剩/2)

→ v、最近頂點 n3、最近面中心 n5 三者共面 (大圓)!
```

### 2.2 δ 由冷斑位置決定

```
δ = 15.1085° = arccos(v·n3)
v = 冷斑向量 (209°, -57° 嘅 ICRS)
n3 = 最近 3-fold 軸 (頂點方向)
→ δ 係「觀測位置 × 固定幾何」嘅確定量
```

### 2.3 位置碼 → 幾何鏈

```
冷斑銀道 (l, b) = (209°, -57°)
  l = 180 + L₇ (Lucas 29)
  b = -(N_d + F₇) = -(44 + 13)
  → v (球面幾何確定)
  → v 喺頂點-面大圓 (幾何事實, 唔係擬合)
  → δ = 15.108516° (確定量)
  → θ = arccos(cos²δ − sin²δ/2) = 26.091357° (群論, 閉合 0.000011°)
```

## 3. 球面三角形細節

## 4. 結論

**δ 冇「獨立閉合公式」— 但唔需要!** 因為:

1. δ 由觀測鎖定嘅冷斑位置直接決定 (唔係自由參數)
2. 冷斑位置本身有結構碼 (l=180+L₇, b=-(N_d+F₇)) — 已閉合
3. **完整鏈: 位置碼 → v → δ → θ (邊長) → SMICA 檢驗** — 全鏈自洽
4. δ/15 = 1.0072 (15° + 0.72%) 冇簡單 φ 公式 — 因為 δ 係幾何輸入, 唔係結構輸出
