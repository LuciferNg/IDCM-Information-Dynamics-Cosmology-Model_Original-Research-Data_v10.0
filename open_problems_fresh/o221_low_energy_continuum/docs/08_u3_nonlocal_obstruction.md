## 一、精確恆等式與兩個閉式（本節核心）

**恆等式（任何圖 Laplacian）**：`a₂ = −Σλ = −Tr(L)` **精確** ⟹ 二導數譜係數係**局部跡**，唔需要對角化（Q6 以稠密 eigh 交叉核實）。

**(a) 密度形變 h = 1 + εδ（零均值）**：

    dev(a₂) = ε²·A + O(ε³),      A = 18·Σδ² − ½·G2,       G2 = Σ_bonds (δ_i − δ_j)²
    c₁ ≡ 0（線性響應恆等消失）

**(b) 曲率泛函（共形讀法 g = Ω²δ，Ω = h^{1/3}）**：

    ∫R√g = (2/9)·ε²·G2 + O(ε³)        ← **100% 梯度**
    線性階在環面上恆等為零（R⁽¹⁾ 係全散度）

⟹ **a₂ 的回應 = 超局部（密度方差 Σδ²）主導；曲率 = 純梯度（G2）**。兩者結構相反。

## 五、連續極限：兩者結構相反

q=1 匹配振幅，比值 [18Σδ²] / [½G2]：M = 8 → **61.46**、M = 16 → 236.47、M = 32 → **936.78**（×15.2）

- 曲率泛函**恆為 100% 梯度**（無 Σδ² 項）⟹ 兩者在連續極限分離得**更遠**
