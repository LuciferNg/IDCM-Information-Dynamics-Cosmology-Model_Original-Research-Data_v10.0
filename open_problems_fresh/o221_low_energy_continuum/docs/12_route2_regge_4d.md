## 四、連續端對照：graviton DoF = 2（關鍵結果）

線性化 EH 二次型（動量空間）：
```
Q(eps) = 1/4 [ k^2((tr eps)^2 - eps:eps) + 2((k.eps).(k.eps) - (k.eps.k)(tr eps)) ]
```
- **規範不變性**：Q(ε + k⊗ξ + ξ⊗k) = Q(ε)，|ΔQ| = **4.44e-16** ✓
- **rank(Q) = N − D**（N = D(D+1)/2）：D=3：6 → **3** ✓；D=4：10 → **6** ✓ ⟹ kernel 恰為 D 個規範方向
- **物理偏振數 = rank − D = D(D−3)/2**：**D=4 → 2 ✓✓（graviton）**；D=3 → 0 ✓（3D 無局部 dof，一致）

## 五、本輪修正嘅 7 個真錯（全部係我嘅建構/判據錯，唔係物理）

1. 用 **mod M 座標差**當邊長 ⟹ wrap 立方塌陷（首輪 χ=360、max|δ|=2π）→ 改 **lift 座標**；
2. 形變**非週期**（cos(πΣx/M) 在 M-平移下反號）⟹ 唔係 torus 上合法構形 ⟹ 假線性項 → 改 cos(2πΣx/M)；
3. M=2 **label 商複形退化**（不同 lift 撞標籤）⟹ χ 必須在 M≥3 檢；
4. χ **formula 項序錯**（2-面入 +、3-面入 −）：首輪印 1620，實際 χ = 81−1215+4050−4860+1944 = **0** ✓；
5. Hessian 取錯泛函（漏 2πΣA）→ 見 §三；
6. 連續二次型漏 `k²((tr)² − ε:ε)` 兩項（以為相消，實際唔同量）⟹ 首輪 rank = 5 而非 6；
7. 規範向量係數用非正交基（off-diagonal 帶 1/2）⟹ 要除 ⟨B,B⟩（首輪 |ΔQ| ~1e-2）。
