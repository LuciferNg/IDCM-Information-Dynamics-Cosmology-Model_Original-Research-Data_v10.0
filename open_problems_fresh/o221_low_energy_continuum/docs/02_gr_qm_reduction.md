### R3 判決（🟡 部分閉合 + no-go 清單）
**可還原**：
1. 譜作用量前兩階係數結構：a_0 = N（體積）、a_2 = −Σγ = −(2N+2)（曲率），比值 **a_2/a_0 = −(2 + 2/N) → −2 純數**（速率 2/N ∝ 4^(−ℓ)，見 docs/01）。
2. 1 個連續維度的出現與其窗口 (1/λ_max, 1/γ_1)。

**不可還原（no-go，帶數字）**：
1. 🔴 **4D 維度**：d_s(𝒯) ≈ 1（max 0.9938）；chain = 1、ladder = 0 ⟹ 3+1D 需額外結構。
2. 🔴 **曲率動力學**：a_2 無線性響應（|c₁|/c₂ = 0.0052）；1D 曲率拓撲化。
3. 🔴 **四導數區**：a_4 ∝ N² 發散。
4. 🔴 **單層連續統**：有限鏈兩端 gapped（d_s → 0）。
5. 🟡 **ladder 角色**：只擴展／甚至壓縮縮放窗口，不加維度。
