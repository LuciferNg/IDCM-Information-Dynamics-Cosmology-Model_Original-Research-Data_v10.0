## 二、U6 閘：兩個讀法，一個被排除

**Reading A（鏈 = 真實空間格點，間距 a₀ ≈ 294.88 Mpc）**
```
ω² = c²k²(1 − x²/3),  x = k a/2  ⟹  ω² = c²k²(1 − k²a²/12)
標準二次 LIV 參數化 ω² = c²k²(1 − k²/Λ₂²) ⟹ Λ₂ = √12 / a
```
- Λ₂ = √12/a₀ = 0.011747608 Mpc⁻¹ = **7.51252e-41 GeV**
- 觀測界（Vasileiou+ 2013，二次 LIV，95% CL）：Λ₂ > **1.3e11 GeV**
- **赤字 = 51.2 orders of magnitude** ⟹ **Reading A 被觀測直接排除**（唔係邊緣，係決定性）
- 反推容許間距：a < √12/Λ₂^min = 2.66469e-11 GeV⁻¹ = **5.25816e-27 m**（與擴散／LIV 文獻同級）
- λ_sync = 9.09896e24 m ⟹ λ_sync/a_max = **1.73e51**

**Reading B（鏈 = 內稟／緊緻因子，非傳播格點）**
- 對固定物理 k：x = k a_ℓ/2 ∝ 4^(−ℓ) ⟹ 偏離 ∝ 4^(−2ℓ)，**極限下精確為 0**
- 實測（k = 0.01 Mpc⁻¹）：ℓ = 4 → 5.53e-6；ℓ = 8 → 8.43e-11；ℓ = 12 → 1.29e-15
- ⟹ 連續極限**無殘留格距效應**（U6 閘通過）；sinc 結構只存活於**內部量**（模標籤、比值、計數、譜）

## 三、Reading B 的可證偽內容

1. **內部比值帶 sinc dressing**：m_n/m_m = sin(nπ/2N)/sin(mπ/2N)，而唔係整數 n/m

|---|---|---|---|---|

| 22:11 | 1.847759065 | 1.961570561 | 1.990369453 | 2 |
| 44:22 | 1.414213562 | 1.847759065 | 1.961570561 | 2 |

- 偏差 ∝ x² ⟹ 同一比值在不同 N 下**差距可達 29%**（44:22 @ N=44 vs N=176）
- ⟹ **可證偽形式**：觀測比值必須等於 sin(nπ/2N)/sin(mπ/2N)**對某一個固定的 N**（物理層 ℓ = 0 ⟹ N = 88 或 176）；若數據偏好未 dressing 的整數比，則格點 dressing 唔係物理
2. **有限模數 + arcsine DOS**：44 / 88 / 176 模（整數，flow-不變）；譜測度 γ 軸 arcsine（KS = 1/N_modes）
3. **Nyquist 端點**：x = π/2 模 v_g = 0、偏離 36.338% ⟹ 任何使用最高模的預言都必須聲明係格點端點效應
