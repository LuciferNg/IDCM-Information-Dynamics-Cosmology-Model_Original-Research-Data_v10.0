## 一、問題精確陳述

docs/14 §五 用**同一向量 convention**（唔正規化）比較：

```
ratio = min|ev(TT block)| / |q(conformal vw)|            vw = diag(0,1,1,1)
```

- 格點：**6.0e-5**（M=3）→ **4.1e-4**（M=8）（= `data/17` log 之 5 位小數值）
- 連續端控制：**0.25**（正規化後 |TT|/|trace| = 1/4；由 raw basis norm 差 2 vs 3 產生）
- ⟹ 曾報「受壓 150–1000×」🔴

## 二、方法：**精確三因子分解**（scripts/20）

格點二次型唔係度量擾動空間上嘅型，而係**拉回**：q_lat(h) = ⟨A h, W A h⟩，其中 A = 線性化度量→邊長映射（`dL_e = ½L_e ŝᵀHŝ·cos(k·x)`）、W = Regge 二階變分。因此

```
ratio_lat / ratio_cont  =  (A_TT / A_conf)  ×  (m_TT / m_vw)  ×  (κ_l / κ_c)
```

| 因子 | 定義 | 性質 |
|:-----|:-----|:-----|
| A_s | 扇區剛度異常：|q_s|/‖source_s‖²（單位 source norm），各扇區對**自己**嘅連續端 | **物理陳述**（約定無關） |
| m_s | 映射失真：邊長空間 norm² ÷ 度量空間 norm² | 幾何（映射）性質 |
| κ_s | 偏振形狀因子：min|ev| / mean|ev| | 格點偏振劈裂之形狀 |

恆等性由 scripts/20 Q4.4 驗證：殘餘 **< 1e-9**（M=3,4,6,8 全通過）。

## 四、機制（三條，全部有數）

1. **主因 = conformal（空間跡）扇區剛度異常**：A_conf = **40.8 / 49.8 / 52.1 / 50.8**（M=3/4/6/8）→ **M-穩定 ~50×**。即 4D Regge 作用量在平坦環面上對**空間跡形變**嘅二次響應比連續 EH 二次型大 ~50×。此即文獻上嘅 **Regge conformal-mode problem**（Regge 作用量對邊長係線性 ⟹ 跡扇區冇正常傳播模）。50× 唔隨 M 衰減 ⟹ **唔係有限 M 偽影，係格點作用量之結構性質**。
2. **TT 扇區自身收斂到連續端**：A_TT = **0.131 → 0.218 → 0.303 → 0.362**（單調趨向 1，即與自己嘅連續端一致）；偏振劈裂 **28.5 → 12.7 → 8.5 → 7.3**（趨向 4.0）。
3. **映射唔係主因**：R_map = 0.4015 → 0.3800（**M-穩定**，O(1)），對比連續端 0.6124；映射貢獻 m_TT/m_vw = 0.43（~2.3×）。
4. **已否證之替代假說（誠實記錄）**：曾檢驗「壓抑 = 面積項（2πΣ_t A_t）與虧角項之**扇區特異相消**」→ **不成立**：兩扇區相消程度同級（~85–95%），相消比 1.34（M=3）→ 0.39（M=8），遠低於假說要求之 10×。相消本身係**數值條件問題**（|q_full| 係兩大項之差，M=8 時 q_area ≈ +32.9、q_deficit ≈ −32.2、q_full ≈ 4.3e-3），已作計算注意事項記錄（見 §六）。
5. **M→∞ 外推**：ratio → 0.25 × (1/50.8) × 0.43 ≈ **2.1e-3**，即殘餘 ~120× 壓抑**全部**來自 conformal 異常（~50×）+ 映射（~2.3×）⟹ **原始比值唔可以當 TT 動力學嘅預言**。

## 六、計算注意事項（新，供後人）

1. **分解必須三因子**：只做「TT vs trace 之比」會把 map 失真（m）與偏振形狀（κ）混入；scripts/20 之 min|ev| 約定需 κ = min/mean 才閉合（否則殘餘 5.9×）。
2. **相消條件**：flat 環面上 Regge 二次型係兩大項（area ≃ +q_a、deficit ≃ −q_d）之殘餘，相消 85–95% ⟹ 任何「q_full 之恆等檢查」必須以**分項大小**為分母（用 q_full 為分母會得 1e-8 級偽殘餘；改為分項分母後 M=8 得 7.15e-11）。
3. **argv 陷阱**：scripts/20 由 `sys.argv[1]` 取 M（預設 3），canonical `data/20_*.txt` 係派生聚合檔（見 01_problem_record.md §二十一）。
