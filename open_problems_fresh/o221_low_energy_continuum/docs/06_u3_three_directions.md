## 一、問題（docs/03 留下的兩個洞）

docs/03 證明「EH 動力學需 D ≥ 3、傳播重力子需 D = 4」，但 𝒯 = K_chain ⊗ K_tree 本身只有 **1** 條鏈。於是：

- (U3-b) 若可以，**曲率動力學是否隨之出現**？（1D 的 no-go 係 |c₁|/c₂ = 0.0052）

## 二、Q1 維數：d_s(K_chain^⊗d) = d（1.73 decades 窗口）

- ⟹ **3 鏈 = 3 空間維度**：3 + 1（細化／RG 時間方向）= 3+1 ✓（docs/03 U3-4 的候選讀法）

## 四、Q2 ladder 唔係空間方向（反而打散 plateau）

在 3 鏈窗口內，加 φ-階梯後 d_s = **0.11973 … 0.18346**（純 3 鏈為 2.87…3.65）

- 原因：階梯的尺度跨度（φ^33 ≈ 7.9e6）令積譜 λ = γ·μ 的 λ_min 落在 1e-8 級，在該 t 區間主導了 Boltzmann 和
- ⟹ **K_tree 唔係空間方向**；3 個空間方向必須來自 **3 份 K_chain**（與 docs/02 Q7「ladder 不加維度、反而收窄窗口」一致）

## 五、Q4 關鍵：3D 下曲率響應**依然為零**（瓶頸唔在維數）

可分度量形變（x 方向體積密度 h_i = 1 + ε·cos(2πi/M)，總體積固定；確定性剖面，非 G1 的隨機剖面），3-環面譜 = {μ_a + ν_b + ν_c} 精確可算：

| ε | naive Σλ rel dev | 不變測度 Tr_g rel dev |
|---|---|---|
| 0.02 | 1.9942e-04 | 6.6347e-05 |
| 0.05 | 1.2497e-03 | 4.1532e-04 |
| 0.10 | 5.0458e-03 | 1.6707e-03 |
| 0.20 | 2.0974e-02 | 6.8375e-03 |

二參擬合 dev = c₁ε + c₂ε²：

- naive Σλ：c₁ = −2.889e-03、c₂ = 0.53856 ⟹ |c₁|/c₂ = **0.0054**
- 不變測度 Tr_g：c₁ = −5.664e-04、c₂ = 0.17372 ⟹ |c₁|/c₂ = **0.0033**（1D 同測：0.0052）

**判決**：
- 🔴 **維數唔係瓶頸**：3D 可分形變下線性（曲率）響應同樣被壓抑到 scheme 級（≤ 0.0054）
- 結構原因（精確表述）：**均勻格點是二導數譜作用量 a₂ 的臨界點**；體積守恆的權重形變對 a₂ 的一階響應為零（二階才出現）
- ⟹ U3 之殘餘由「維數不足」改判為「**缺少真正的動態度量結構**」：需要 **非可分**（真正場論）度量變形 + 擴散／規範結構（metric 必須是場而非常數權重）
