## 二、路線 ②：3 份鏈嘅來源 — 由公設改為結構恆等式

### 2.1 恆等式

    d_space = N_gen = L₄ − B = 7 − 4 = 3        d_spacetime = B = 4  (3 + 1)

| 部件 | 值 | 獨立來源 |
|---|---|---|
| L₄ | 7 | Lucas（L₀ = 2, L₁ = 1, Lₙ = Lₙ₋₁ + Lₙ₋₂）: 2, 1, 3, 4, **7** |
| B | 4 | γ_{44±j} = 4 + α⁻¹(0) = 137 ⟹ B² = 16（O124），亦即 44/88/176 = 4× 之重數 |
| N_gen | 3 | 9 = N_gen² 手性 I-60 軌道（O137）；亦即 L₄ − B |

冗餘核對（全 PASS）：44 = 4×11、88 = 4×22、176 = 4×44；Σγ = B(N_d+1)/2 = 90（O211）；176-L 分割 178 = 90 + 88；α⁻¹(0) = 137 = 4 + 133。

### 2.2 數字學閘（深度-2 有理 null，強制）

基底 22 個專案常數，深度-2 表達式命中數：{2: 19, **3: 9**, 4: 16, 5: 12, 6: 11, 7: 11, 8: 14}

⟹ **「3」冇特殊優勢**（比 2、4、5、8 都少）⟹ 恆等式嘅力量**唔在於 3 本身**，而在於三個部件（L₄、B、N_gen）**各自被獨立推出**：呢個係「結構恆等式」而非「湊數」。

### 2.3 誠實邊界

- **得到**：d_space = 3 唔係自由輸入（等於 N_gen = L₄ − B）；d_spacetime = 4 = B，與 U3 最小性定理（docs/03：EH 需 D ≥ 3；傳播重力子需 D = 4）一致。
- **得唔到**：為何連續極限用**三份獨立鏈方向**（複製），而非單鏈 3 重對稱耦合。複製仍係輸入，成本 = **1 個離散選擇（0 連續參數）**⟹ 錨 dof = 1（O212）不受影響。
- 評級：**🟡**（算術精確 + 部件獨立；複製本身未推出）。
