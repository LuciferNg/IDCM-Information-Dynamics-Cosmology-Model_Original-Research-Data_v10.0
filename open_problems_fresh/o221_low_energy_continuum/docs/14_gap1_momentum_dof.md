# O221 / docs/14 — 缺口 1：4D Regge 逐動量分解抽 DoF = 2（TT criterion）— 部分閉合

**腳本**：`scripts/17_momentum_dof.py`（**11/11 PASS**，於 M = 3, 4, 6, 8 ⟹ 44/44）、`scripts/18_gap1_summary.py`（**9/9 PASS**）；數據 `data/17_momentum_dof.txt`（canonical；逐 M 全量跑 = `logs/17_momentum_dof_M{3,4,6,8}.txt`）、`data/18_gap1_summary.txt`。
**動機**：docs/13 §六 嘅四項 TT criterion（(a) rank = N − D；(b) DoF = rank − D = 2；(c) 規範方向零響應；(d) 真 TT 投影）。

## 一、方法（可審計）

平坦 4-torus（Kuhn 三角化，**lift 座標**）；動量 k = 2πn/M；度量模 `h(x) = H cos(k·x)` 經線性化 Regge 關係 `dL_e = ½ L_e ŝᵀ H ŝ` 餵入邊長；二次型用極化 `b(v,w) = ½[q(v+w) − q(v) − q(w)]`，`q(v) = S_R(L+v) − S_R(L)`（平坦係 stationary，只須 S_R 求值）✓。對照用同變量嘅線性化 EH：`Q(e) = ¼[k²((tr e)² − e:e) + 2((k·e)·(k·e) − (k·e·k)(tr e))]` ✓。

**機械健康檢查**：平坦時每 hinge 虧角 = 0（max|δ| = 5.33e-15，S_R = 1.6e-12 至 7.7e-11）；**均勻（乘法）縮放精確盲**（dS_R ~ 1e-11，同 docs/10 R6 一致）；二次標度 q(2v)/q(v) = 3.998–3.997（殘餘 = 三次項）✓。

**本輪兩個新陷阱（血淚）**：
1. **虧角 = `2π − Σ(繞 hinge 嘅二面角)`，唔係 `2π·cnt − Σ`**——cnt 只係入射單形數（實測每個 hinge 4 或 6 個入射）。錯用會得 max|δ| = 502、S_R = 5.2e5 ✗（已修，flat 回 0）✓。
2. **hinge key 必須用 lift 座標**（用 mod-M label 會把所有 lift 副本合併 ⟹ 入射數膨脹）✓。

## 二、連續端對照（**精確**）

| 量 | 值 |
|---|---|
| rank(Q) | **6 = N − D = 10 − 4** ✓ |
| kernel | **4 維 = 規範方向 h = k⊗ξ + ξ⊗k（精確零，max\|q_cont(gauge)\| ≤ 1.3e-23）** ✓ |
| 簽名 | **(1 正, 5 負)** ✓ |

單一正方向 = 空間跡（conformal）模；五個負 = 空間無跡模 ⟹ **conformal-factor problem** ✓；即 TT 偏振住喺**負號扇區** ✓（同 docs/15 Q5 嘅 `rank − D = 2` 一致 ✓）。

## 三、criterion (c)：**Regge-native 形式下閉合** ✅✓

**精確頂點位移方向** `dL_e = ŝ_e·(ξ_b − ξ_a)`，ξ(x) = ξ̂cos(k·x)（週期 ⟹ 合法 torus 構形）⟹ 二次型值對同範數隨機擾動之比：

| M | 3 | 4 | 6 | 8 |
|---|---|---|---|---|
| disp residual | 4.40e-6 | 1.12e-5 | 1.12e-6 | **3.02e-7** |

⟹ **位移方向就係格點嘅 gauge kernel（數值上精確）**，而且**包絡衰減 14.6×（M=3→8；M=4 一個 bump，唔宣稱單調）** ✓✓。呢個係缺口 1 嘅**主要正面結果**：格點自己帶住微分同胚型規範扇區 ✓。

**但**：用**天真線性化度量→邊長映射**餵入嘅 gauge 向量（h = k⊗ξ+ξ⊗k）**唔**係精確 kernel：殘餘 0.0119 (M=3) → 0.0409 (M=8)，**唔收斂** ✗ ⟹ 弱環係度量映射本身（O(1) 相對誤差），**唔係**格點冇規範扇區 ✓。**結論：DoF 計數必須用精確位移商，唔可以用天真度量映射** ✓。

## 四、criterion (a)/(b)：計數在連續端精確，格點端只到 1.2–4.1%

格點譜一致呈 **6 個大（負，物理） + 4 個小（gauge-like）**：M=3,4,8 得 (4+,6−)、M=6 得 (3+,7−)（小模嘅符號有漲落，大模恒 6 個負）✓。4 個小模 = 連續端 4 個精確零嘅格點殘影，水平 ~3–6%（min4_rel：0.032/0.048/0.057/0.060）⟹ **計數連續端 ✅、格點端 🟡（受 1.2–4.1% gauge violation 限制）**。

## 五、criterion (d)：dim(TT) = 2 精確；幅度受壓 🟡

用**空間動量** k ∥ axis 3，TT = 2×2 橫向塊嘅無跡部分（`h11 = −h22`、`h12`）：
- **dim(TT) = 2** ✓（計數：空間 3×3 六分量 − 橫向性 3 − 無跡 1 = 2；D=3 則 6−2−1 = 0 作對照 ✓）
- 格點與連續端 **rank 2、非退化** ✓；**與 conformal 扇區符號相反** ✓（conformal-factor 結構重現 ✓）
- **與跡扇區解耦** ✓（相對交叉項 ≤ 1e-6，連續端 ~1e-16）
- ⚠️ **幅度受壓**：|TT|/|conformal| 格點 6.0e-5 → 4.1e-4（M=3→8）vs 連續端 **0.25** ⟹ 相差 **150–1000×** ✗（同一向量 convention 下比較）⟹ 精確定量嘅新缺口（未解）。
