## 0. 背景（兩條未閉合線之交叉點）

- **docs/14 (c)**：Regge 作用量對**精確頂點位移**一階盲，但**天真度量投影**規範向量（`h = k⊗ξ+ξ⊗k` 餵入線性化度量映射）之殘餘 1.2e-2 → 4.1e-2，**唔隨 M 收斂**。⟹ 缺口 ① 核心：DoF 計數必須在**正確規範固定**下重做。

## 1. 構造（同一套，格點/連續端並行）

1. **變量**：10 個對稱度量擾動，取**單位張量範基**（每個基向量 `‖H‖_F = 1`）⟹ 所有剛度都係「per unit strain」，無基歸一化偽影。固定格點動量 `k = (2π/M) n`（n ∥ 軸 3），調制 `cos(k·x)`。
2. **規範子空間**：`Vg = span{ k⊗ξ_i + ξ_i⊗k }`，i = 0..3（連續端 diffeo 軌道；**兩端用同四條向量**）。
3. **規範固定**：`Z` = `Vg` 之**歐氏正交補**（維數 10 − 4 = 6）。
   ⚠️ **q-正交補在此不可用**：規範子空間落在連續端二次型之 **kernel 內**（`Vg·Q = 0`），故 q-正交補退化為全空間，取到任意 6 維（第一版據此得 dim 4 假象——見 §6(b)）。
4. **物理二次型**：`Q_phys = Z Q Zᵀ`（兩端同一 `Z`）；報譜、rank、慣性。
5. **逐扇區剛度**：單位 source norm（格點 = 邊空間範 `‖dl‖`；連續端 = 每單位應變張量範），每扇區對**自己**嘅連續端對照。
   註：`stiff = |q|/src²` 對方向嘅整體縮放**不變** ⟹ 與 docs/15 之值**可直接比較**（同一物理定義），差別只在「方向有無投影入規範固定物理子空間」。

## 3. 裁定

### ① 缺口 ①（DoF 計數/精確位移商）→ 🟢 **閉合（主體）**

1. **精確頂點位移 = 一階 kernel 方向**：四條方向之 `dS_R(amp)/dS_R(amp/2) = 4.00`（**精確**），即線性項為零、殘餘純二階幾何項 ⟹ Regge-native 規範扇區成立（獨立重驗 docs/14 (c)）。
   ⚠️ 判據要點：位移之嚴格不變性係對**有限**位移；線性化邊長變化只到一階，故**必須**用 Richardson 比值（4，非 2）判定，唔可以要求 `|dS_R|/amp²` 絕對細（見 §6(c)）。
2. **規範固定 10 → 6**：`rank(Vg) = 4`、補空間維數 6、`Q_phys` **無 kernel**（兩端）⟹ DoF 計數 `rank = N − D = 6` 在正確規範固定下**得**到（docs/14 之 🔴 解除）。
3. **慣性收斂**：格點 gauged-fixed 慣性 (2+,4−)@M=3,4 → **(1+,5−)@M=6,8** = 連續端值 ⟹ 細化流把額外近零方向併回譜內，**結構性收斂**（額外方向 < 5% 最大本徵值，M=3 時 4.01%）。
4. **天真映射之規範破壞**：0.0119 → 0.0414（**隨 M 增大，唔收斂**）⟹ 天真度量→邊長映射在規範扇區**無收斂極限**；但**規範固定後物理量 O(1)** ⟹ 破壞屬**映射層**，唔屬物理層。

### ② 缺口 ②（TT 幅度受壓）→ 殘餘② **閉合**：conformal 異常 = 規範污染

- **崩潰因子 M-穩定 = 28–29×** ⟹ 原 ~50× 「conformal 異常」中，**~96.5% 係天真度量映射之規範污染**；規範固定後 conformal 扇區對連續端之殘差只 **1.74–1.83×**（M-穩定）。
- **兩扇區皆 O(1)**（A_TT = 0.32–0.78、A_conf = 1.41–1.83）⟹ docs/15 之結論「原始 `|TT|/|trace|` 唔可以當 TT 動力學預言」**仍然成立**，但其**機制**由「跡扇區結構異常」**修正**為「**規範固定不當**」。

## 4. 新殘餘（誠實記錄，🔴 新開，不開新 O）

- **③ TT 扇區之 M-漂移**：規範固定後 `A_TT = 0.7841 / 0.6658 / 0.4470 / 0.3217`（M=3/4/6/8）≈ **2.3/M**，即格點 TT 剛度（per unit 邊空間範）**隨 M 下降**，而 conformal 扇區穩定 1.8。**須辨明**：係 (a) 格點 **edge-space 測度** vs 連續端「每單位應變張量範」之**測度不匹配**（U5「譜↔測度交換性」母題之同一性），抑或 (b) 真 TT 動力學殘差。
  - 已知傾向 (a)：docs/15 已證 TT 扇區**自身**收斂（偏振劈裂 28.5→7.3 趨向 4.0；A_TT_raw 0.131→0.362 趨向 1），即 TT 動力學在**另一**歸一化下收斂；兩套歸一化之差 = 測度項。
- **④ 規範破壞不收斂**（0.0119→0.0414）：天真映射層之固有性質（真實存在、已量化）；若日後要用天真映射做定量預言，必須先做規範固定（本文件之程序）。

## 6. 本輪真錯（全部在**構造側/判據側**，物理零讓步；已入 skill 第 25 條）

- **(a) 每參數重新歸一化破壞 polarisation 雙線性**：`b(v,w) = ½[q(v+w) − q(v) − q(w)]` 要求 `q(v+w)` 用**真和**；若對每個參數先歸一化（第一版 `tensor_of` 所為），則 `q(unit_i + unit_j)` 實際係「單位範向量」之值 ⟹ 全部 off-diagonal 項污染。症狀：連續端譜只得 rank 5、慣性 (2+,3−)（真值 rank 6、(1+,5−)）。修：改為**線性**映射（單位範基下每基向量張量範已 =1）。
- **(b) q-正交補退化**：規範子空間 ⊂ kernel ⟹ `Vg·Q = 0` ⟹ q-正交補 = 全空間，SVD nullspace 取到任意 6 維（第一版得 dim 4、連續端 (2+,2−,2 zeros) 之假象）。修：改用**歐氏**正交補（規範固定之標準做法；因規範方向 ⊂ kernel，歐氏補上之限制形式即商空間形式）。
- **(c) 位移判據錯用絕對量**：要求 `|dS_R|/amp²` 絕對細 → 必然 FAIL（量級 = 二階幾何項，M=3 時 9.56）。修：改 Richardson 比值 4（一階項為零之正確檢定）。
- **(d) pinv 而非 solve**：天真 gauge 方向 q≈0 ⟹ `Vg Q Vgᵀ` 病態，plain solve 放大噪聲成 O(1) 擾動（觸發 Cholesky 失敗）。修：`np.linalg.pinv(rcond=1e-10)` + 方向歸一化。
