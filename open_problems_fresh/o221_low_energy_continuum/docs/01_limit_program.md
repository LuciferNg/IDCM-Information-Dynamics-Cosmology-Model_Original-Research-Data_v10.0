## 一、問題（U1 的解答方向）

O221 開題時，框架內「連續化」三個方向混用而未形式化：

| 代號 | 原本寫法 | 實際操作 |
|---|---|---|
| (a) | 4^ℓ 細化（O197/O213） | N → N·4，a → a/4，√J → 4√J |
| (b) | n → x 連續化 | 固定相對模指數 n/M，N → ∞ |
| (c) | γ-譜測度極限（O202） | 計數測度 → 連續測度 |

**結論：三者是同一個單參數極限程序 L 的三種讀法，控制變量唯一 = x ≡ πn/M = k a/2。**

## 二、L 的定義（顯式）

```
L  =  (細化流: M → M·4,  a → a/4,  √J → 4√J)  ∘  (共動重標定: n → 4^ℓ n)
     極限 ℓ → ∞ 取下，物理模指數 n 固定（即 x = πn/(M_ℓ) → 0）。
不變量 = 只依賴 x 的函數（等價：只依賴 k/k_cut）。
```

- 物理動量：k_n = 2πn/L_world = **n / R_world**（L_world = 2πR_world = 176 r_d）
- 精確色散恆等式：**ω_n^(ℓ) = c k_n · sin(x)/x**，x = πn/M_ℓ = k_n a_ℓ/2（mpmath 50 位：dev 4.7e-51）
- c 不動點：c = a_ℓ √J_ℓ = R_world·ω_ring（ℓ = 0..6 精確，dev = 0）

⚠️ **慣例註記（新）**：O213 用 L_world = R_world，本文用環周界 2πR_world = 176 r_d = 25 949.2 Mpc。
兩者差一個 2π 因子，但 c 不動點使它**在無量綱結果中完全抵銷**（x、sin(x)/x、收斂率均不變）。
λ_sync（ℓ = 0 間距）= 2πR_world/88 = **294.8772 Mpc** ✓ 同導航表一致。

### C5 不變量 vs 變量（IR 存活判準的骨幹）
- **不變**：n → 4^ℓ n 共動重標定下 γ 完全不變（dev = 0）
- **變**：固定整數 n 時 γ_n^(ℓ) ∝ M_ℓ^(−2)（指數 1.99971）
- **變**：格點質量比 sin(πn/2N)/sin(πm/2N) → n/m（脫 dressing）
  - ratio(5,1)：N=44 → 4.974547（dev 0.509%）→ N=704 → 4.99990（dev 2e-5）
  - ratio(44,22)：N=44 → 1.41421（dev 29.3%）→ N=704 → 1.99759（dev 0.12%）
  - ratio(13,7)：N=44 → 1.80997（dev 2.54%）→ N=704 → 1.85696（dev 1e-4）
  ⟹ **sin-lattice 質量比是格點 dressing（flow-variant），極限內容是整數階梯 n/m。**

## 四、IR 存活判準（R2 的形式化結果）

一個 IDCM 量 Q 係「物理」的，若且唯若滿足：
- **S1 尺度不變**：Q 只依賴 x（= 相對模指數 = ka/2），不依賴 ℓ、M 單獨；
- **S2 收斂 + 速率可知**：極限有限非零，且首階修正有冪次律（可由 sin 展開封閉寫出）；
- **S3 錨不變**：不得引入新量綱常數（dof = 1，O212）；
- **S4 逐層可檢**：物理量須在 ℓ = 0（觀測層）取值；跨層聲稱必須先證 flow-不變性。

**分類**（R2 交付）：

- ✅ **存活**：c（不動點）、k_n = n/R_world、x、整數計數（44/88/176/178/90/88/89）、sinc 律本身、Σγ = 2N+2、E[γ] = 2+2/N、arcsine 測度、正則括號（見 docs/02）。
- 🟡 **有條件**：sin-dressed 質量比（是格點預言，非極限結構；聲稱物理必須指明 ℓ）、v_g = c cos x（Nyquist 端點為偽影）、a_2/a_0（極限 −2 但含格點項）。
- 🔴 **偽影**：Nyquist 模（36.34%、v_g = 0）、固定整數 n 的 γ_n（∝M^(−2) 衰減）、a_4（∝N² 發散）、單層的「連續統」（有限鏈兩端 gapped，d_s → 0，見 docs/02）。

## 五、四硬測試自查

1. **dof 成本**：L 引入 0 個新常數；全部結果由 (R_world, ω_ring, c) 三者（O212 錨定理已綁定為 dof = 1）加純整數生成。無擬合 ✓
