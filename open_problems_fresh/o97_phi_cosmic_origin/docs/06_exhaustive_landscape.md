## 四、F4 由 F1 自動涵蓋 (新證明)

```
定理: F1 閉合 ∧ μ>1 ⟹ μ ∉ ℚ (無理)
證明: 若 μ=p/q∈ℚ (μ>1) → μ−1/μ=(p²−q²)/(pq).
gcd(pq, p²−q²)=gcd(q,p²)·gcd(p,q²)... 直證: gcd(p,p²−q²)=gcd(p,q²)=1,
gcd(q,p²−q²)=gcd(q,p²)=1 → gcd(pq, p²−q²)=1.
∴ pq | p²−q² ⟹ p²=q² ⟹ p=q ⟹ μ=1, 還反 μ>1. 矛盾. ∎
```
所以「無理性」唔係第四個獨立條件 — **F1 內建咗無理**。O51 嘅無分相譜
(946/946 無理比) 同 F1 係同一件事嘅兩面。
