## 二、核心定理: 自相似二分 ⟺ φ

### 定義 (自相似二分尺度)

一個實數尺度 μ>1 係「自相似二分」嘅, 如果佢嘅**兩層自相似切分**剛好坐滿
單位預算而無隙無疊:

```
τ(μ) = μ⁻¹ + μ⁻² = 1
```

物理涵義: 一個 self-similar 階層, 父層 = 單位 1; 子層 = μ⁻¹ (父/μ);
孫層 = μ⁻² (子/μ)。三者要**剛好合埋**成單位, 先至冇「欠 (gap)」或「疊 (overlap)」。
原子 axiom = 預算守恆 (O39 世界預算 Σγ 守恆 / water-pipe throughput)。

### 定理: τ(μ)=1 嘅唯一正解係 φ

```
τ(μ) = 1   ⟺   μ⁻¹ + μ⁻² = 1
       ×μ²  ⟺   μ + 1 = μ²
            ⟺   μ² − μ − 1 = 0
            ⟹   μ = (1+√5)/2 = φ   (唯一正根)
```

### 四等價刻劃 (全 ⟺ x²−x−1=0)

| 刻劃 | 形式 | 意義 |
|:-----|:-----|:-----|
| (a) | **x = 1 + 1/x** | 自反轉遞歸 (最簡自我複製規則) |
| (b) | **x⁻¹ + x⁻² = 1** | 兩層自相似預算閉合 (無隙無疊) |
| (b')| **G/(G+S) = S/G** | Euclid「極端與中項」(黃金分割) |
| (c) | **[1;1,1,1,…]** | 連分數全週期, 自動複製 |
| (d) | **φ·φ' = −1, φⁿ+φ'ⁿ=L_n∈ℤ** | 整數閉合 (Lucas 閉環) |

**四者同根**: sympy 逐項證明 `x=1+1/x`、`x⁻¹+x⁻²=1`、Euclid 條件三個方程
嘅唯一正根**全部等於 (1+√5)/2 = φ** (scripts/01, PASS)。

### 三條排除關卡

1. **超越數 (π, e)**: 唔係代數數 → 冇「根與係數」整數閉合 → 冇閉式組合階層。
   π 係「周長/直徑」嘅**長度比**, 係靜態測量; 唔係迭代/自相似重標規則。
   e 係「自然生長基數」 limit(1+1/n)ⁿ, 係**速率**, 同「空間自相似切分」無關。

2. **二次無理但唔喺閉合族 (√2, √3)**: 根積 r₁r₂ = ±2/±3 ≠ −1 →
   冇 φⁿ+φ'ⁿ∈ℤ 嘅整數閉合閉環 → 唔能喺離散階層產生離散可表達嘅層位。
   且 τ(√2)=1.207>1 (疊), τ(√3)=0.911<1 (欠) — 預算都唔似合。

3. **有理尺度 (2)**: τ(2)=0.75<1 (欠), 且有理 → 譜全相稱 (ω_i/ω_j∈ℚ) →
   直接違反 O51 Level-3 嘅 **946/946 無理拍頻比** (sympy 證明 sin(nπ/88)
   除 n=44 全無理)。宇宙要「無分相稱譜」就一定要**無理尺度**。

**∴ 喺「無理 + 自相似 + 整數閉合 + 預算守」四重 constraint 下, φ 係唯一 survivor。**

## 四、為什麼係「無理」: 同 O51 咬合

O97 Level-A 最深刻嘅一步: 宇宙**唔可以用有理尺度 2**。

原因就係 O51 Layer-3 已證 (經 sympy 精確代數): **946/946 對拍頻比 ω_i/ω_j
全部無理**。如果尺度係有理 (如 2), 譜會自相稱, 波峰永久重合, 冇「無分相」週期性
(唔啱 O51 既無理比特徵)。所以尺度**必須**係無理代數數 —— 而喺「無理 +
自相似二分 + 整數閉合」嘅候選入面, 唯一係 φ。

- 呢步係**可證偽**嘅: 若有人搵到另一個無理代數尺度 μ≠φ 同時滿足 τ(μ)=1 + 整數閉合,
  咁 O97 Level-A 就錯。目前無。
