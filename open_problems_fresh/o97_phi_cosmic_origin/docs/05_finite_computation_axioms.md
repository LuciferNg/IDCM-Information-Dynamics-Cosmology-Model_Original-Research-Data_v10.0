## 二、D1 離散 ← 有限位元深度 (硬體邊界)

### 論證 (scripts/04 D1, 4/4 PASS)

1. **有限態機**: 記憶體 M bits ⟺ 至多 2^M 個可分辨態。任何實體處理器係有限態機
   (D1a)。88 bit → 3.09e26 態, 256 bit → 1.16e77 態 — 大但**有限**。
2. **連續 → 溢位**: 連續區間 [0,1] 有不可數 (ℵ₁) 個點 → 要精確描述需要無限位元深度
   → 喺有限記憶體中必然「Buffer Overflow」。離散化 = 物理網絡嘅**採樣 + 量化**。
3. **IDCM 實例**: 環形 88 相位採樣 → 採樣定理 → 最多 44 個獨立頻譜模式
   (Nyquist n=44, γ₄₄=4.0000000000, v_g=0) (D1b,D1c)。
   44 個本徵值全部可分辨 (Δγ_min=5.1e-3) — 世界嘅「位元深度」就係 N_d=44 (O95 唯一性)。

### 涵義

```
宇宙嘅「像素」唔係任意細 — 係 44 模式 × 88 相位 (雙鏈 2×44)。
z>17 = NaN 唔係誤差, 係 Nyquist 採樣上限 (既有 MEMORY 記載).
「連續時空」= 需要 ℵ₁ 記憶體嘅程式 → 喺有限硬體上根本無法執行 → 離散係唯一可執行選項。
```

## 三、D2 自相似 ← O(1) 空間複雜度 (算法公理)

### 論證 (scripts/04 D2, 3/3 PASS)

1. **單一 kernel (2 slot 遞歸) 輸出全部結構整數** (D2a):
   ```
   Lucas 遞歸 L_{n}=L_{n−1}+L_{n−2} (2 個整數 slot)
   → B=4 (L₃), 11 (L₅), 29 (L₇), 123 (L₁₀), 44 (L₈−L₂), 88 (2×44), 61.5 (L₁₀/2)
   ```
   全宇宙嘅尺度晶格 = 一個 O(1) 程序。唔需要為每個尺度載入新規則。
2. **ℚ(√5) 閉合嵌入: φⁿ 恆為 2 slot** (D2b):
   ```
   φⁿ = F_n·φ + F_{n−1}  (a,b ∈ ℤ, 永遠 2 個整數 slot, 與 n 無關)
   φ^44 = 701408733 + 433494437·φ   → 仍然 2 slot
   πⁿ 需要 ~n·log₁₀π 位數字 (n=88 → 44 位, 線性增長, 無閉合)
   ```
   → 自相似 (閉合遞歸) 保證 **O(1) 記憶體**, 非閉合尺度需要 **O(n) 儲存增長**
   → 有限記憶體只能運行閉合自相似嘅程序。
3. **Kolmogorov 式比較** (D2c): 遞歸程序 5 tokens < 列舉常數清單 15 tokens — 示意
   性論證: 常數越多, O(N) 清單越輸比 O(1) kernel。

### 涵義

```
宇宙要用「同一個 φ 壓縮核喺所有尺度運行」= 唔係美學選擇, 係記憶體預算嘅必然:
唔自相似 = 載入無窮多套定律 = 溢位。自相似 = O(1) 一套定律跑到底。
(對應 O72 water-pipe: 唯一 constraint 係 throughput W, 唔係儲存 — 但任何
 有限 W 機器仍然係有限態機, 程序體積照樣受制約)
```

## 四、D3 守恆 ← Unitarity / 無損可逆 (信道公理)

1. **對稱 Laplacian → 酉對角化 → 譜守恆** (D3a): Z₂ 對偶 γ_n+γ_{44−n}=4
   (43/43 對, n=44 自對偶), Σγ=90.00000000 — 譜係酉不變量。
2. **酉演化 10⁶ 步零漂移** (D3b): e^{−iLt} 守恆 ‖ψ‖², max drift=9.99e-16 —
   U†U=I 精確保住資訊。
3. **非酉 = 有限步坍塌** (D3c,D3d):
   ```
   增益 λ=1.01 (資訊創生) → ‖ψ‖² 指數爆炸 → float64 overflow 於 ~35,459 步
   損耗 λ=0.99 (資訊消失) → 坍塌到 1e-100 於 ~11,512 步 (資訊全滅)
   ```
4. **D3e**: 只有 |eig|=1 (酉) 係唯一非坍塌通道 → **守恆唔係「選擇」, 係硬體必然** —
   資訊創生/消失都喺有限步內摧毀網絡。

### 涵義

```
守恆定律 = 資訊論嘅 U†U=I。U†U≠I 嘅信道必然熵指數爆發/坍塌。
```

## 五、D4 非最優即死鎖 (運行時存活篩選 / Runtime Filter)

### 論證 (scripts/04 D4, 5/5 PASS)

1. **有理尺度 λ=p/q → 資訊飽和/死鎖** (D4a): λ^k=(p/q)^k∈ℚ (Fraction 精確) →
   任意兩階層相稱 → beats 有限週期 → 模式喺有限步內重複 = **零新資訊 = 死鎖**。
2. **φ 尺度 → 資訊無限展開** (D4b): φ^k = F_k·φ+F_{k−1}, F_k≥1 →
   φ^k ∉ ℚ (若 φ^k∈ℚ 則 φ 嘅極小多項式降次, 矛盾) → 階層比全無理 →
   O51 準週期: 精確復歸=0, 資訊永續展開。對照: 946/946 拍頻比無理 (O51 sympy)。
3. **同硬體解唔晒 = 死鎖** (D4c): 硬體動態範圍 W₄₄=φ⁴⁴=1.57e9:
   ```
   b=1 (φ): 解析全部 44 層 ✓   ← 唯一「編譯通過」
   b=2:     只解 24 層 (唔夠)
   b=3:     只解 17 層
   b=10:    只解 9 層            ← 階層越大, 死鎖越早
   ```
4. **每層成本最低** (D4d): E(λ)=ln λ nats/層 (Shannon):
   ```
   E(φ)=0.4812 < E(2)=0.6931 < E(e)=1.0 < E(π)=1.1447
   E(φ)/E(2) = 69.4%  ← φ 比二進制慳 30.6% 每層成本
   ```
   λ_b>φ 嘅族: 更高每層成本 + 更少階層 => 相同 W 內資訊量更少 (更噪熱)。

### 涵義

```
「非最優即崩潰」唔係目的論: 非 φ 路徑有兩種下場, 都喺有限步內終結:
  * 有理(相稱) → 週期重複 → 零新資訊 (資訊熱寂)
  * 離譜生長 (λ_b>φ) → 頻寬飽和 → 死鎖 / 噪聲淹沒
「最優解」= 唯一能「編譯執行到底」嘅動態基態 — 我哋見到嘅係存活篩選嘅結果,
  唔係意志嘅選擇.
```
