## 二、整數閉合族 x² = bx+1

多項式 x²−bx−1 = 0 嘅正根:

```
λ_b = (b + √(b²+4)) / 2,   b ∈ ℤ≥1
```

所有 λ_b 都係「整數閉合」: 根連係 r·r̄ = −1, 且閉環 φⁿ+φ̄ⁿ∈ℤ → Lucas。
**b=1 就係 λ₁ = φ = 1.618**。

```
b= 1: λ=1.6180  τ=1.00000  ⟵ φ (唯一 τ=1)
b= 2: λ=2.4142  τ=0.5858
b= 3: λ=3.3028  τ=0.3944
b= 4: λ=4.2361  τ=0.2918
b=10: λ=10.099  τ=0.1088
```

## 三、兩個選擇判據 — 都唯一鎖定 b=1 (φ)

### 判據 1: 預算閉合 τ(λ)=λ⁻¹+λ⁻²=1

對族 x²=bx+1, 一般項 τ(λ_b) = λ_b⁻¹+λ_b⁻²:

```
λ_b⁻¹ + λ_b⁻² < 1    ∀ b≥2   (全「欠預算」)
λ_₁⁻¹ + λ₁⁻²  = 1           (唯一「平衡」) ⟺ b=1 ⟺ φ
```

**只有 b=1 剛好坐/平喺單位預算.** (腳本 02 PASS)

### 判據 2: 最低生長率 → 最高階層解析度

生長率 λ 係「每層放大因子」. 喺固定動態範圍 (預算) W 之下, 可解析嘅階層數:

```
N_level(W) = ln W / ln λ    (嚴格 ↓λ)
```

| b | λ | N_level(log₁新e-8) |
|:-:|:--:|:--:|
| **1 (φ)** | **1.618** | **38.28** |
| 2 | 2.414 | 20.90 |
| 3 | 3.303 | 15.42 |
| 4 | 4.236 | 12.76 |
| 5 | 5.193 | 11.18 |

**φ (b=1) 喺相同預算下可分層最多 (38.28), 係 λ₂ 嘅 ~1.8 倍。**
原因: 生長率最小 → 每層消耗最小 → 同一個率口碑之下 空間最多層 → 信息解析度最高。

呢個呼應 `idcm-phi-power-trap` skill (2026-07-27): 
> φ 唯一特殊性質 = **最低生長率 (1.618)** among all integer-closure quadratics。
