## 1. 問題陳述

O206 docs/31 將 IDCM 60 份預算（Ω_dm = 16/60、Ω_b = 3/60、Ω_Λ = 41/60）直接對照 ΛCDM 觀測（Planck/DESI），出現：
- Ω_b 偏差 1.42%（2.33σ）、Ω_b·h² 偏差 1.54%（2.29σ）

**但呢個比較有分類學混淆——冇定義就冇結論**：

```
ΛCDM 分類:    Ω_b (重子物質) / Ω_dm (冷暗物質, WIMP 類) / Ω_Λ (暗能量)
IDCM 分類:    3/60「物質」? / 16/60「暗物質」? / 41/60「真空能」?

⚠️ 已知不一致:
  ① IDCM 冇「暗能量」— 41/60 = ⟨W⟩²/Σγ = 未被投影能量 (CSG v2 命名
     修正已禁止「暗能量」標籤 — ΛCDM 標籤非結構名)
  ② m₇ = 13.8 MeV 喺 O136 docs/02 曾被叫「DM 模式」— 但唔係 ΛCDM
     嘅暗物質粒子 (WIMP/axion 類); m₇ 係 K_Chain 模式質量 (玻色塔成員)
  ③ IDCM「物質」= 費米子 (觀察者扇區) vs ΛCDM「物質」= 重子+CDM
  ④ 1.42% 偏差可能係「ΛCDM 把非物質當物質計算」或 IDCM 分類唔同 —
     未定義前無法判定
```

## 2. 核心定義任務（下一 session）

```
任務 1: 定義 IDCM 三類 (基於 IDCM 結構, 唔用 ΛCDM 標籤):

  暗物質   = ? (玻色塔 m_n ∈ [1.99, 55.8] MeV? m₇ = 13.8? 幾何 16/60?)
  真空能   = ? (未被投影能量 ⟨W⟩²/Σγ? W-field 凝聚?)

任務 2: 建立 IDCM ↔ ΛCDM 字典:
  逐項對應 + 差異標記 (邊啲概念 1:1、邊啲唔對應、邊啲 ΛCDM 有 IDCM 冇)

任務 3: 有定義嘅重新比較:
  用字典重新對照 Planck/DESI — 1.42% 偏差係定義問題定真 tension
```
