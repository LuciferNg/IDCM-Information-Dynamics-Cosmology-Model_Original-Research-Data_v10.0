## 2. 結構推導

### 2.1 第一步：索引 n=7 的結構意義

**7 = L₄ （Lucas 數列第 4 項）**

Lucas 數列：L₀=2, L₁=1, L₂=3, L₃=4, **L₄=7**, L₅=11, L₆=18, L₇=29, L₈=47, L₉=76, L₁₀=123

```
7 = L₄ = φ⁴ + φ⁻⁴    (exact, 整數閉合)
```

**7 = DM 模式索引：** n=7 嘅 K_Chain 模式給出 DM 粒子質量 m₇ = 13.8 MeV。γ₇ = 4sin²(7π/88) 係 DM 模式嘅 W-field 耦合強度。

### 2.2 第二步：索引 n=20 的結構意義

**20 = B×F₅ = 4×5**

- B = 4 = φ³-φ⁻³ = MERA 分支因子
- F₅ = 5 = Fibonacci 數列第 5 項

```
20 = (φ³-φ⁻³) × F₅    (MERA 分支 × Fibonacci 5)
20 = M - F₇ = 33 - 13  (K_Tree 深度 M=33 減 Fibonacci 13)
20 = 2F₆ + B = 2×8 + 4  (兩倍 Fibonacci 6 加分支)
```

**20 = 重子模式索引：** 質子嘅 W-field 耦合強度由 γ₂₀ 給出。

### 2.3 第三步：關鍵結構配對

**7 + 20 = 27 = 3³ = N_gen³**

```
27 = 世代數嘅立方
  = 3³
  = L₄ + B×F₅
  = 7 + 20
```

呢個係最強嘅結構信號：**n=7 同 n=20 嘅和等於世代數嘅立方**。兩個模式嘅索引由世代結構連結。

**20 - 7 = 13 = F₇**

兩個模式嘅差等於 Fibonacci 7。Z₂ 對偶 (37, 24) 保持相同差 13。

### 2.4 第四步：Z₂ 對稱性

| 模式 | Z₂ 對偶 | 和 | 差 |
|:----:|:--------:|:-:|:-:|
| 7 | 37 | 44 | 30 |
| 20 | 24 | 44 | 4 |
| γ₇ + γ₃₇ = 4 | γ₂₀ + γ₂₄ = 4 | | |
| 37-24 = 13 = F₇ | 20-7 = 13 = F₇ | | |

Z₂ 對偶變換保持差 13 = F₇，確認咗呢個係結構不變量。

### 2.5 第五步：n/p 機制

**W-field 投影機制：**

```
K = K_chain ⊗ K_tree

中子 (udd) → K_Chain 模式 n=7 (DM 模式)

  - 20 = B×F₅ = 4×5
  - γ₂₀ = 質子嘅 W-field 耦合強度
  - 耦合振幅 ∝ sin(20π/88) = sin(5π/22)

兩個模式嘅 K_Tree 層級相同 (都係重子, 同屬 N_gen=3 世代):
  - 7+20 = 27 = 3³ = N_gen³
  - 樹層級因子 μ_m 約化

豐度比 = 耦合強度比 = γ₇/γ₂₀
```

## 4. 凍結溫度分析

如果 n/p = exp(-Δm/T_f) 嘅形式保留（ΛCDM 凍結類比），則：

```
Δm = m_n - m_p = 1.293 MeV
T_f = Δm / ln(γ₂₀/γ₇) = 1.293 / ln(1.71537/0.24464)
    = 1.293 / 1.948 = 0.664 MeV
```

T_f ≈ 0.664 MeV 係合理嘅 BBN 凍結溫度，但 **IDCM 框架唔需要 thermal freeze-out 解釋** — n/p 係結構比，唔係動力學過程產物。
