## B1: κ≈6/100 近對偶（R2）— MC null 判定

**觀察**: SH0ES φ⁻¹/100 vs RR Lyrae κφ⁻¹/6 耦合強度相近 (0.6180% vs 0.6438%)，即 κ/6 ≈ 1/100。

**數值**:
```
(κ/6)/(1/100) = 100κ/6 = 100/(16·6) = 100/96 = 25/24 = 1.0416667 (4.17% 偏離)
```

**MC null（10⁷ 樣本, 結構整數池 1..150, 4% 容差）**: 命中率 **0.269%** — 低概率但未排除 (p≈2.7e-3, 唔夠 5σ)。

**結構分解**:
- 100 = 10² (SH0ES 鏈深度平方)
- 96 = 16×6 = κ⁻¹ × n_RR = B² × (L₄−1)
- 100/96 = 25/24 = F₅²/B! — 兩者皆結構數

**判定**: R2 🟡「結構對偶未證實」。MC null 0.269% 表明「隨機湊近」唔常見但唔排除；兩側 (100 同 96) 各自有結構身份，但「100≈96」呢個接近本身冇獨立機制。**唔升 🟢，亦唔否證** — 留待 SH0ES 或 RR Lyrae 精度改善後二分。

## B2: Cepheid 相移抵消（R3）— 數值化

**舊**: Q2 「Σ κφ⁻¹/n → 0 群體相移抵消」定性。

**數值實況**:
- 正數求和發散：Σ_{44} κφ⁻¹/n = 0.1689 = 4.373×κφ⁻¹（調和級數，無收斂）
- 交錯版本：Σ(−1)^{n+1}κφ⁻¹/n → κφ⁻¹·ln2 = 0.6819×κφ⁻¹
- 隨機相位模型：⟨cos φ_n⟩ → 0，殘差 ~ κφ⁻¹/√44 ≈ 0.0058 (0.58%)

**實質**: 「相消」唔係數學收斂，而係**統計相位干涉**（多模態相位平均消失）。Cepheid P-L 關係係群體統計量 → 局域相移被平均 → 有效修正項 ~ κφ⁻¹/√N。呢個係合理機制，但幅度不再是 0 而係 ~0.6% 殘差——同個體 Cepheid 全耦合 (3.86%) 相比已經細 6.6×。

**判定**: R3 🟡 機制成立但「→0」措辭要改為「→ κφ⁻¹/√N 統計殘差」。唔影響 SH0ES L2 修正（100 深度嘅 0.618% 係鏈級邊界，唔係恆星群體項）。
