# O186: TRGB/Miras 校準差異機制 — 結構推導

## 核心問題

TRGB = 69.78 = H₀_idcm × (1 − κφ⁻¹) ✅ (0.03%)
Miras = 73.29 = H₀_idcm × (1 + κφ⁻¹/4) ✅ (0.01%)

**兩個問題：**
1. 符號相反：TRGB 減、Miras 加
2. 幅度比 4:1：κφ⁻¹ vs κφ⁻¹/4

## Step 1: 物理差異

### TRGB (紅巨星分支頂端)
- **物理過程：** 核心氦閃 (He flash) — 簡併核心達到 ~0.45 M☉ 時點燃
- **能量方向：** **向內** — 核心塌縮 → 氦點燃 → 能量釋放在核心
- **時序：** 單一臨界事件 (single sync event)
- **投影深度：** 最深層 (核心 → 表面)

### Miras (長週期變星)
- **物理過程：** AGB 星熱脈衝 — 氦殼層燃燒 + 徑向脈動
- **能量方向：** **向外** — 星體膨脹收縮 → 表面光度變化
- **時序：** 週期性振盪 (periodic oscillation)
- **投影深度：** 表層 (表面脈動)

## Step 2: W-field 投影機制

### κφ⁻¹ 耦合強度

κφ⁻¹ = 1/16 × φ⁻¹ = 0.038627 (3.86%)

- κ = 1/16 = 4⁻²：MERA 分支量子 (QG 耦合單位)
- φ⁻¹ = 0.618：黃金比例倒數 (W-field 遞歸尺度)

### TRGB 機制：核心同步事件 → 收縮投影 → 負偏移

核心 He 閃是 W-field 的**結構同步事件** (structural sync event)：
- 核心達到臨界密度 → He 點燃 → 同步
- 同步事件是**收縮** (核心塌縮，能量向內)
- W-field 投影從核心到表面：單層全耦合 → **κφ⁻¹**
- 負號：收縮投影 → 觀察者看到的光度 **少於** 幾何距離預測
  → 視星等更暗 → 距離更大 → H₀ 更低

```
D_obs(TRGB) = D_true / (1 − κφ⁻¹) ≈ D_true × (1 + κφ⁻¹)
H₀_obs(TRGB) = H₀_idcm × (1 − κφ⁻¹)
```

### Miras 機制：表面脈動 → 膨脹投影 → 正偏移，4 分支耦合

Miras 脈動是 W-field 包層的**相干振盪** (coherent oscillation)：
- 脈動是**膨脹-收縮**循環 — 淨能量向外
- W-field 樹結構 (MERA) 有 **4 個分支** (B = φ³−φ⁻³ = 4)
- 脈動能量分布於 4 分支 → 耦合被 **B = 4 稀釋** → **κφ⁻¹/4**
- 正號：膨脹投影 → 觀察者看到的光度 **多於** 幾何距離預測
  → 視星等更亮 → 距離更小 → H₀ 更高

```
D_obs(Miras) = D_true / (1 + κφ⁻¹/4) ≈ D_true × (1 − κφ⁻¹/4)
H₀_obs(Miras) = H₀_idcm × (1 + κφ⁻¹/4)
```

## Step 3: 4:1 幅度比 = MERA 分支因子

4 = φ³−φ⁻³ = 4.236... − 0.236... = **4** = MERA 分支因子 B

| 方法 | 物理過程 | 投影層數 | 耦合強度 |
|:----|:--------|:--------:|:--------:|
| TRGB | 核心同步事件 (單層) | 1 | κφ⁻¹ |
| Miras | 表面脈動 (4 分支) | B = 4 | κφ⁻¹/4 |

**幅度比 = 4:1 = B:1**

TRGB 是**單點同步事件** → 耦合到 1 層 → 全 κφ⁻¹
Miras 是**4 分支樹振盪** → 耦合到 B = 4 層 → κφ⁻¹/4

## Step 4: 符號機制 = 能量流方向

| 方法 | 能量流 | W-field 投影 | 對距離的影響 | H₀ 修正 |
|:----|:------|:------------|:-----------:|:-------:|
| TRGB | **向內** (收縮) | 核心同步 → 表面接收較少光 | D 變大 | **−κφ⁻¹** |
