# docs/03 — 88/90 sampling kernel 正式計算 (P3, gate ③)

> 對應: scripts/03_sampling_kernel.py (6/6 PASS)
> 判準: φ^{−53} 殘餘 0.353% 係咪由 88/90 = 44/45 震鈴平滑化 (Lanczos/Fejér) 解釋?

## 問題

φ^{−53} 命中 0.353%。若加一個「邊界截斷震鈴修正」, 可否收窄到 < 0.1%? 定係殘餘同 kernel 無關?

## 結果

### [1] 需要嘅修正因子

- 目標: ln(kT/M₀) = **−25.500691**
- φ^{−53}: ln = −53·lnφ = **−25.504227**
- 需要嘅乘性修正 = e^{0.003536} = **1.003546** (即 +0.354%)

### [2] 邊界比

88/90 = 44/45 = 0.977778 精確 (觀察者 88 模 ↔ 世界 90 模; N_d/(N_d+1))。

### [3] 簡單指數修正掃描

| m | (44/45)^m | dev vs 目標 |
|:-:|:----------|:------------|
| −1 | 1.02273 | 1.91% |
| −½ | 1.01126 | 0.77% |
| −1/4 | 1.00560 | 0.21% |
| **−1/6** | 1.00375 | **0.021%** ← 最近 |
| −1/8 | 1.00281 | 0.073% |
| −2 | 1.04604 | 4.23% |

**O168-06 只測過 m ∈ {±1, ±½, ±2}** — 佢漏咗 m = −1/6 (dev 0.021%)。

### [4] Null control (關鍵)

隨機 m ∈ [−0.3, 0] 連續掃描, 命中率 = **9.1%** 落喺 < 0.1%。

→ m = −1/6 嘅 0.021% 命中係**密度背景** — 唔係結構信號。要升 🟡 需要機制 (點解係 1/6 = 1/(2N_gen)? 冇導出)。

### [5] 震鈴量級

- 本算 partial-sum overshoot = 0.1562 (連續級數)
- O162 R4 離散 DFT overshoot = 0.0743
- 兩者都係 **5–15% 量級** — 需要嘅修正係 **0.35%**, 即 **21–44 倍** 太大

## 判準結果

- **震鈴/kernel 唔係 0.353% 殘餘嘅來源 🔴** — 量級差 1.5 個數量級
- **(44/45)^{−1/6} = 0.021% 命中 = 密度背景 🟡** (null 9.1%; 機制缺席)
- 殘餘 0.353% 嘅來源**未解釋** 🔴
