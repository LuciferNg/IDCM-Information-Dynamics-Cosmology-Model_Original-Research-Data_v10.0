## 二、W1. 選擇偏置 — w_obs = 2/10 係唔係 w 嘅公平估計?

w_obs 係喺**通量限樣本** (JWST z~4-7 AGN) 度量; 通道 A 種子係 fresh (低 M),
要過 L ≥ L_min 需要高 λ ⟹ 選中樣本嘅通道 A 份額理論上 ≠ w。

```
輸入 w = 0.20;  前向 (z_f=13.43, 通道 A fresh + 通道 B 成長):
  L_min = 3.0e43 → 選中樣本通道 A 份額 = 0.194   (偏 2.9%)
  L_min = 1.0e44 → 選中樣本通道 A 份額 = 0.177   (偏 11.5%)
觀測 w_obs = 0.20 (2/10)
```

**★原因 (同選擇階梯一致)**: 低端 2 粒嘅實測 λ = **3.68 / 1.89** — 遠高於樣本幾何均值
0.702 ⟹ 佢哋**好容易過閘**。所以選擇偏置只有 ~3% (L_min = 3e43)。
觀測 0.20 同前向選中份額差 **0.05σ_binom** ⟹ **w_obs = 2/10 大致係 w 嘅公平估計**。

## 四、W3. form density — 「w = 1/F₅」係咪特別?

```
整數分數 a/b (結構整數池):  0.2 → 1 條 (1/5)
2 步運算 (a op b op c, 結構數池含 f_bar/ε/φ):
  0.2 → 237 條 | 1/8 → 171 | 1/4 → 196 | 1/3 → 181 | 1/10 → 453 | 1/2 → 276
```
**⟹ 0.2 唔係特別密命中, 亦唔係稀疏命中 — 同鄰近值同量級 (237 vs 171–453)。**

**★另一點更根本**: O197 `docs/09` §2.1 表列「★1/F₅ = 1/5」「1/(L₄−μ²) = 1/5 (同一)」
「1/(N_gen+μ²) = 1/5 (同一)」三行 — 佢自己都標「同一」。**呢三行係同一個數字 5 嘅三種寫法,
唔係三條獨立命中**。加上樣本值恰好 2/10 = 0.2, **「dev = 0.00%」係必然結果, 唔構成證據**。
