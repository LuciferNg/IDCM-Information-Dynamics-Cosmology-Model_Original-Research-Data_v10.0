## 一、問題原文與三個獨立缺陷

開放項 4 原文: 「種子 logN 尾全 PDF −4.23/dex @ 1e8 比觀測高 z BHMF (LBQS z=2.5: **−0.82/dex**,
演化後) 陡 — 機制候選 = λ 散射 (σ_lnλ=1.39) 成長卷積展平」。

攻堅後發現呢個陳述有**三個獨立缺陷**, 全部已量化更正:

| # | 缺陷 | 更正 |
|:-:|:---|:---|
| 1 | **−0.82/dex 唔係高端斜率** — 佢係 `scripts/04` V5 對 z=2.5 **全部 6 點** (logM 8.4–10.4, 跨越峰值) 做嘅**全局 OLS** | 論文自己嘅高端斜率 β = −2.6 (同 bin、同質量窗 ≥10.0 dex) — footnote 6 |
| 2 | **質量框架錯配** — 記錄將「種子質量 1e8 嘅斜率」直接同「觀測質量嘅 BHMF」比 | 統一喺**觀測質量框架**: 模型斜率喺 logM_obs ≥ 10.0 = **−4.24 ~ −4.91/dex** |
| 3 | **機制候選 (λ 散射卷積) 唔成立** | 證偽 (見 §三) |

## 二、修正後嘅 like-for-like 對照

```
z_f* = 13.43  ⟹  G(z_f*→2.5) = 98.63
模型局部斜率 (觀測質量框架, d lnΨ/dlog10M):

顯著性: σ_β = 1.4 → 1.41σ;  σ_β = 0.4 → 4.95σ
```

**自身數據交叉核對**: 同一表嘅 z=2.5 屋頂兩點直接斜率 = **−6.18 ± 0.76/dex** (誤差由 σ_Ψ 傳播)
→ 模型 −4.58 vs −6.18 = **2.10σ** (唔顯著)。**注意**: 論文自己嘅 β = −2.6 同佢自己表格嘅
2 點斜率 −6.18 唔一致 ⟹ β 對擬合窗/方法敏感 (系統不確定度大於 σ_β = 0.4–1.4 所報)。

**裁決**: 修正後張力 = **1.76×**, 顯著性 **1.4σ–5.0σ** (取決於未知嘅 σ_β)。**唔屬「確鑿證偽」
級**, 亦唔係記錄所講嘅 5.16×。

## 三、機制候選證偽 — λ 散射卷積 (T8g)

### 3.1 記錄候選 (docs/03 T8g + O197 docs/08 機制 2)

「λ 有散射 σ_lnλ = 1.39 ⟹ G = exp(Δt·λ/τ) 有散射 ⟹ 卷積 ⟹ 展平」

### 3.2 證偽一: 量級荒謬

```
Δt(z_f*→2.5) = 2.296e9 yr;  τ = t_S·ε/(1−ε) = 5.0e7 yr
λ = 0.06 → G = 1.6e+01   (最低實測 λ)
λ = 0.10 → G = 9.9e+01   (結構值 f_bar)
λ = 0.702 → G = 1.0e+14  (實測幾何均值!)
λ = 3.68 → G = 2.4e+73   (最高實測 λ)
```
⟹ 用**實測即時 λ** 做**持續**成長率, G 跨 **72 個數量級** — 完全唔物理。

### 3.3 證偽二: 結構內部矛盾

模型嘅 G 由 `(t_ef, Δt)` **定死** (t_ef = t_S·ε/(λ(1−ε)) 用 λ = f_bar = 0.1 結構值)。
若 λ 有散射 ⟹ t_ef 有散射 ⟹ **總成長都變**: λ = 0.05/0.1/0.2 → G = 10/99/9728 (×972)。
但成長閉合 (docs/03 T8h) **必須**用 λ = f_bar 先閉合 ⟹ 機制同閉合自相矛盾。

**⟹ 記錄候選機制 (λ 散射卷積) 證偽, 應由開放項 4 移除。**

## 四、★新證偽 — 單一 z_f 成長律喺低 z 崩塌

記錄只喺 **z = 5–10** 檢驗過成長律 (docs/03: G ∈ [2.5, 11.4])。本攻堅首次外推到低 z:

```
G(z_f*→z) = exp((t(z) − t(z_f*))/t_ef),   t_ef = 0.5 Gyr,  z_f* = 13.43
  z = 5.00: G = 5.5e+00  → 中位 M = 3.87e+07 M☉
  z = 2.50: G = 9.9e+01  → 中位 M = 6.88e+08 M☉
  z = 1.25: G = 1.1e+04  → 中位 M = 7.51e+10 M☉
  z = 0.35: G = 1.7e+08  → 中位 M = 1.20e+15 M☉   ← ★
觀測 (LBQS z=0.35 BHMF): logM 8.0–9.6, 量級 ~1e8 M☉
```
**⟹ 模型喺 z=0.35 預測典型 BH 質量 1.2e15 M☉ — 超出觀測 7.1 dex。**

**反推 (更強)**:
- 用 z_f* = 13.43 解釋 z=0.35 嘅 1e8 M☉ BH ⟹ seed 只需 **0.58 M☉** (次恆星) — 荒謬。
- 若要 seed ≥ 100 M☉ (恆星級下限) ⟹ Δt ≤ 6.91 Gyr ⟹ **z_f ≤ 2.26** (模型用 13.43)。

**⟹ 單一 z_f 成長律 (λ = f_bar 持續) 被低 z BHMF 決定性排除。**
物理讀法: 真實 AGN 吸積率密度喺 z~2 見頂、z=0 前跌 ~2 個數量級 ⟹ 成長律**必須有 z 依賴
duty cycle / 截止**。呢個係**新開放問題** (唔可以再當 λ = f_bar 係「持續」值)。

## 五、殘餘與候選機制

### 5.1 形成時間散佈 (所需寬度定量)

若尾斜率殘餘 (1.76×) 由**形成時間散佈**解釋 (而非 λ 散佈 — 見 §三):
```
需 σ_eff(lnM) = 4.93 (種子 σ = 1.781)  ⟹ σ_K(ln G) = 4.60  ⟹ σ_tf = 2.30 Gyr
可用窗口 t(2.5) = 2.610 Gyr  ⟹ σ_tf / t(2.5) = 0.88
```
⟹ 需要**近全域**形成時間分佈 (σ_tf ≈ 0.88 × 全部可用宇宙時)。呢個同凝聚圖像
(O174 condensation) 一致, 但**唔解決 §四** (單靠分佈, 低 z 巨大質量問題仍在)。

### 5.2 層級疊加 (4^-ℓ × 4^ℓ) — 候選, 依賴開放項 6

若 O174 docs/09 嘅層級 (Φ_BH = Σ_ℓ 4^-ℓ P(M;ℓ)) 帶 **4^ℓ 質量標度** (中位 ×4/層、權重 ÷4):
```
複合譜局部斜率: logM 9.0 → −0.05 | 10.0 → −1.34 | 10.4 → −1.72 | 11.0 → −2.12 [/dex]
β 窗口平均 = −1.53/dex
```
**β = −2.6 夾喺兩個模型之間**: 單 logN −4.58 (太陡) ↔ 4^ℓ 複合 −1.53 (太展平)。
差距 1.07/dex = 0.76σ (σ=1.4) 至 2.67σ (σ=0.4) — **唔決定性**。

⚠️ **依賴**: 4^ℓ 質量標度**未推導** (開放項 6: N_ℓ = 22·4^ℓ 第一原理來源)。若開放項 6 證偽,
5.2 亦即失效。
