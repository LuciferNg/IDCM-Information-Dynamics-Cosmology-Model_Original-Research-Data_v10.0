## 三、★發現

### F1 🔴 T9g 係同義反覆 / 定義唔一致（docs/04 T9g）

**宣稱**: 「γ(22·4^ℓ/2) = μ² = 2 ∀ℓ=0..4（N_ℓ = 22, 88, 352, 1408, 5632）」

**審計結果**:
- `scripts/07` 實作 `gamma = 4·sin²(nπ/(2N_ℓ))` — 用**層級相關**分母 2N_ℓ。此時
  `γ(N_ℓ/2) = 4sin²(π/4) = 2` 對**任何 N** 都成立 ⟹ **同義反覆（tautology）**，
  唔係「自我相似」發現。
- 用**權威 γ 定義** `γ_k = 4sin²(kπ/176)`（O39/O40, 176-Laplacian）:
  ℓ=0 → γ(11) = **0.15224** ≠ 2（差 92%）; ℓ=2 → γ(176) = 5.2e-122 ≈ 0。
  權威定義下 γ = 2 嘅模態只有 **k = 44** 同 **k = 132**。
- 只有 ℓ=1（N=88, n=44）啱好兩邊都中 — 所以首版睇落冇事。

**裁決**: T9g 現行陳述**唔成立**（權威定義下）或**空洞**（script 定義下）。
若「層級自我相似」係真結構，需要先**推導層級相關歸一化** γ^{(ℓ)}_n = 4sin²(nπ/(2N_ℓ))
嘅來源（現時係假設）；否則應撤回。→ 已就地修正 `docs/04` T9g + 標 🟡。
**O174 docs/03「層級 ℓ 中心模恆 γ = μ²」同一問題（未審計, 唔喺本 O 範圍）。**

### F2 🟡 L_Edd 常數唔一致（scripts 1.26e38 vs 論文隱含 ~1.30e38）

  而論文自己嘅 λ 值隱含 **~1.30e38**。
- ⚠️ **本行首版誤記（2026-09-16 獨立覆核更正）**: 原文寫「8/10 物件 dev < 1%（最大
  CEERS_00717 7.12%）」— **自相矛盾且數字錯**。獨立重算（逐物件 `L_bol/(λ·M)`）:
  | 用 L_Edd | dev < 1% 物件數 | 最大 dev |

  即係 1.3e38 冇「8/10 < 1%」; 正確講法係「1.3e38 令最大 dev 由 10.01% 降到 7.12%」。

  max 1.386e38, 幾何平均 1.296e38, spread **1.15×**。
  ⟹ 論文側常數 ≈ 1.30e38 **成立**（median/geo 都落 1.30e38）。
- **★但偏差主因唔係常數**: spread 1.15× ≫ 1.26 vs 1.30 嘅 3% 差 ⟹ 逐物件重建偏差由
  **L_bol / M_BH 嘅 2 有效數字 rounding**（±5%）主導, 3% 常數差**不可分辨**。
  驗證: 9/10 物件嘅 L_need（= λ·1.26e38·M）落喺 L_bol±5% 內; 唯一例外 CEERS_00397
  （L_need 2.545e45 vs L±5% = [2.660e45, 2.940e45]）本身就係 docs/02 §七 已記錄嘅
  「論文取捨值差異」。
- **影響評估**: 前向模型用 `L = λ·L_EDD·M`（λ 來自表值, 唔用重建值）, L_EDD 3% 差異令
  L-cut 位置差 3% ⟹ 對低端份額/中位影響 < 0.1 ln, **唔改變任何結論**。
- **裁決（與首版建議不同）**: **唔改常數**。1.26e38 係精確標準值, 1.30e38 係論文側

   同一批數字 ⟹ 唔係「複製輸出」造成嘅假一致。

   「抽樣誤差」— 審計獨立量度 Var[ln M] 估計量嘅離散度（12 次獨立 seed）: SD = 0.0246
   ⟹ 0.0437 差距 = **1.78 SD**，抽樣誤差解釋**成立**（但屬臨界, 唔算強證據）。
