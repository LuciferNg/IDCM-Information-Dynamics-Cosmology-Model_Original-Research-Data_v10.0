## 三、B. 結構時間候選 (問題重構後)

正確問法: 形成時間 t_f 係唔係結構量? (z_f = z(t_f); 或 Δt(z_f→0) = n·t_ef)

| 候選 | z_f | 落 [7.33, 30.00]? |
|:---|:---:|:---:|
| t_f = t_S (Salpeter) | 10.36 | ✓ |
| t_f = t_ef (成長 e-folding) | 9.59 | ✓ |
| **t_f = t_ef/φ** | **13.59** | ✓ |
| t_f = t_ef/φ² | 19.12 | ✓ |
| t_f = t_S·φ⁻¹ | 14.66 | ✓ |
| t_f = T_ring/364 (O197 docs/07) | 16.64 | ✓ |
| Δt(z_f→0) = 27·t_ef (N_gen³) | 14.05 | ✓ |
| t_f = t_ef·φ | 6.68 | ✗ |
| t_f = 2·t_ef | 5.67 | ✗ |
| t_f = t_S·ε | 51.72 | ✗ |

**7/10 落入** — 但因為範圍太闊 (spread 22.7), **判別力極低**。全部候選都係結構量嘅積/商
(**零加性湊數**), 冇一個可以宣稱「命中」。

**★最值得注意嘅兩個 (物理上最自然)**:
- **t_f = t_ef** (z_f = 9.59): 「種子喺宇宙年齡 = 自身成長 e-folding 時間時形成」— 自洽、零新常數。
  呢個同 O197 docs/07 §三「凝聚窗 = t_ef」(Δt = t_ef) 係**同一個時間尺度**嘅兩種用法。
- **t_f = t_S** (z_f = 10.36): 「宇宙年齡 = Salpeter 時間」。

兩者都喺 T8c 嘅再電離窗 [8, 15] 內 ✓ — **反而係記錄用嘅 13.43 之上嘅 22.68 唔喺窗內** (見 §四)。
