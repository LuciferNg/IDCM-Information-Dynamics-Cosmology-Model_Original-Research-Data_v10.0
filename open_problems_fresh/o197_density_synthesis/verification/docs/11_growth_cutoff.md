## 二、層級索引 — 任何 z 截止都係層級截止

```
1 + z = B^ℓ = 4^ℓ      (O76)      ⟹   ℓ(z) = log₄(1+z)
ℓ(z_f*) = log₄(14.43) = 1.9253      (唔係整數 — 已記錄 O197 docs/09)
```

**⟹ 因為 z 同層級 ℓ 一一對應，一個「z 截止」唔係外加參數，而係層級索引上嘅截止 ℓ_stop。**
呢個就係「成長律必須由結構推導」嘅第一步：成長事件由層級 ℓ 索引（`1+z = B^ℓ`），
所以 duty cycle 只能係 **ℓ 嘅函數**，唔可以係任意 z 函數。

## 三、★★z_stop 容許窗 + 窗內結構值

兩個獨立約束（觀測 = Vestergaard & Osmer 2009 本地 PDF 質量窗；docs/06 §一）：

| 約束 | 條件 | 結果 |
|:---|:---|:---|
| **A** z = 2.5 高端閉合保留 | G(2.5) = G_unif(min(z_stop, 2.5)) ≤ 3600 | z_stop ≥ 1.28（**弱，非約束性**） |
| **B** z = 0.35 觀測窗 | 預測須留喺窗 [8.0, 9.6] dex ⟹ G_cap ∈ [14.3, 570] | **1.87 ≤ z_stop ≤ 3.78** |

> **★自查修正（09-16）**：約束 A 首版被誤當成對 G_cap 嘅**下界**（G ≥ 36 ⟹ z_stop ≤ 3.05）。
> 正確：若 z_stop ≥ 2.5，z = 2.5 根本**未凍結** ⟹ G(2.5) = 98.63 固定；若 z_stop < 2.5，
> G(2.5) = G_unif(z_stop) > 98.63。兩種情況都 ≥ 36 ⟹ A 只給「唔可太大」之弱上界。
> **唯一有效約束 = B**。

```
G_cap = G_unif(z_stop) = exp((t(z_stop) − t(z_f*))/t_ef) ∈ [14.3, 570]
⟹ ★z_stop 容許窗 = [1.87, 3.78]   (spread 1.91)
⟹ ★層級寬度 Δℓ = ℓ_f − ℓ(z_stop) ∈ [0.798, 1.164]
```

**★★窗內結構值 z_stop = 2.50**:

```
1 + z_stop = 3.5 = L₄/μ² = 7/2          (Lucas 4 / μ²)
等價:  z_stop = F₅/μ² = 5/2 = 2.5        (用 L₄ = F₅ + μ²: 7 = 5 + 2)
Δℓ = 1.0218 ≈ 1  個層級                  (dev 2.2%)
```

**★關鍵性質**: z_stop = 2.5 令 **z = 2.5 嘅高端閉合「恰好不變」**（G = 均勻律值 98.63），
即已閉合嘅結果**零改動** — 截止只作用喺 z < 2.5。

## 五、可證偽 — 替代形式全部排除

| 候選 | 結果 |
|:---|:---|
| **純冪律** `G = A(1+z)^{−p}` | ❌ **排除** — 冪律喺 (1+z) 上單調，唔可以同時滿足 z=2.5（G = 98.6）同 z=0.35（G ≤ 570 但 ≥ 14）嘅「**先長後停**」形態 |
| **Δℓ ≥ 2**（兩個層級以上成長窗） | ❌ **排除** — Δℓ = 2 ⟹ 1+z_stop = 4^{−0.075} < 1，凍結點唔存在（即永遠唔凍結 ⟹ 崩塌） |
| **均勻律（Δℓ = ∞，無截止）** | ❌ **排除** — 超 z=0.35 窗頂 5.48 dex（docs/06 §四） |
| **Δℓ = 1（一個層級）** | ✅ **唯一倖存**，且落容許窗 [0.917, 1.164] 內 |

## 六、開放項 5 殘餘 — 成長模型由結構推導

原本嘅「均勻 vs channel-resolved 二選一」被取代為**單一層級律 + 截止**：

```
G(ℓ) = exp( min(ℓ_f − ℓ, Δℓ) · lnB · t_ℓ / t_ef ),    Δℓ = 1,  1+z = B^ℓ
通道 A (譜偏差, 內稟): 冇環境供應 ⟹ 成長窗 = 0  (fresh, G = 1)
通道 B (環境過密): 成長窗 = Δℓ = 1 個層級
```

- 兩通道**共用同一層級律**，只係成長窗長度唔同 ⟹ 唔再係二選一
- 零新常數：`B = L₃`（scripts/10）、`t_ef = t_S·ε/(λ(1−ε))`（docs/03）
- 物理讀法：**吸積活躍期 = 一個層級**；`1+z = B^ℓ` 令「高 z 成長、低 z 停」有層級意義
