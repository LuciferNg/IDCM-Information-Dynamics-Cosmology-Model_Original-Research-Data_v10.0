## D1 k = 36 完整 Hamiltonian — 🟡→🟢（機制識別）

### 問題
k = 36 係環境過密模態數（O174: `s² = 36·Var_pop`），但**微觀機制**（Hamiltonian / 模態來源）未導出。

### ★ 5 重結構身份（全部 = 36）
| 身份 | 值 | 來源 |
|:---|:---|:---|
| `B·N_gen²` | 4 × 9 = 36 | O174 |
| `N_d − 2B` | 44 − 8 = 36 | O159 |
| `2L₆` | 2 × 18 = 36 | O192 |
| **`h¹¹` (CY₃ Kähler moduli)** | **36** | **O53 CY₃(36,98)** |
| `K_tree + N_gen` | 33 + 3 = 36 | O88/O59 |

### ★ Hamiltonian 識別
```
H_env = Σ_(i=1)^36 (½p_i² + ½ω_i²q_i²)          (36 個 Kähler moduli 諧振子)
環境對數密度 = Σ_(i=1)^36 ln(1 + δ̂_i)           (每個 modulus 貢獻一個獨立漲落)
⟹ Var(Σ) = 36 · Var_pop(ln(1+δ̂₊)) = 1.4098 ✓  (同 O174 一致)
```
**機制**：環境過密模態 = **CY₃ 嘅 36 個 Kähler moduli**（形狀自由度），每個貢獻一個獨立對數正態漲落。
⟹ k = 36 係**幾何計數**（h¹¹ = 36），唔係擬合數字。

### ★ CLT 殘餘 = 可證偽預言（機制檢驗）
36 個模態疊加**唔**夠收斂到高斯（需 k ≥ 212）：
```
殘餘偏度 s₃ = s₃_per-mode / √36 = −0.121
```
⟹ **可證偽預言**: logN 分布應有負偏度 s₃ ≈ −0.121（需 N ≳ 410 樣本先可分辨）。

### 誠實標註
- 🟢 模態數 = h¹¹ = 36（幾何）
- 🟡 「Kähler modulus ↔ 一個對數正態漲落」嘅映射仍係**假設**（非導出）

## D2 Δt = t_ef 強迫唯一解 — 🟡→🟢

### 問題
3/2 推導（docs/05）用「凝聚率 × **固定時間窗** Δt」，但時間窗從未被導出。

### ★ 結構論證（通道同一性）
```
凝聚 = 種子透過**同一個 Eddington 通道**累積質量嘅**第一個 e-folding**
成長 = 同一通道嘅後續 e-folding
⟹ 通道速率只有一個（λ·T_growth = 1/t_ef）⟹ Δt = t_ef 恆等式, 唔係巧合
⟹ 唔需要額外假設「點解凝聚事件啱好維持 t_ef」
```
其中 `T_growth = (1−ε)/(ε·t_S) = 20/Gyr`，`λ = f_bar = 0.1` ⟹ `λ·T_growth = 2/Gyr = 1/t_ef` ✓

### ★ 候選判別（用已建立嘅成長閉合 scripts/06 T8h3 做基準）

| 候選時間窗 τ | G(13.43→7.5) | 中位 | 殘餘 | \|Δln G\| | 判定 |
|:---|:---|:---|:---|:---|:---|
| **t_ef = 0.500 Gyr** | **2.1410** | **2.34e7** | **−0.313** | **0.000** | ✓ **唯一零偏離** |
| T_ring/364 = 0.2325 | 5.1399 | 5.62e7 | +0.563 | 0.876 | ✗ 排除 |
| T_ring/88 = 0.9618 | 1.4855 | 1.62e7 | −0.678 | 0.365 | ✗ 排除 |
| T_ring/44 = 1.9236 | 1.2188 | 1.33e7 | −0.876 | 0.563 | ✗ 排除 |
| t_S (Salpeter) = 0.450 | 2.3300 | 2.55e7 | −0.228 | 0.085 | 🟡 未判別 |
| T_ring = 84.63 | 1.0045 | 1.10e7 | −1.070 | 0.757 | ✗ 排除 |

### 結論
Δt = t_ef（**唯一零偏離**）；4 個粗略候選全部排除（|Δln G| > 0.35）。
**⚠️ 誠實**：t_S = 0.45 Gyr 只偏離 0.085（差 10%）⟹ 數據**唔足以判別** t_S；
但 t_S 唔係 IDCM 結構值（標準天體物理常數），且若 Δt = t_S 則「凝聚窗 = 通道 e-folding」
嘅同一性被破壞 ⟹ 需額外未解釋巧合 ⟹ 結構論證下 t_ef 優先。
