## 一、#4  通道交界 M ≈ 5.41e6 精確形狀 — **🟢 閉合**

### 1.1 精確式推導

```
通道 A: δ̂ = −cos(kπ/88), k = 45..88 (44 個等權模態)
連續極限: k uniform ⟹ θ = kπ/176 uniform on [45π/176, π/2]
δ̂ = −cos(2θ),  dδ̂/dθ = 2sin(2θ) = 2√(1−δ̂²)
⟹ f(δ̂) ∝ 1/√(1−δ̂²)   — arcsine (O157/O174 已閉合)

歸一化: ∫_{δ̂_45}^{1} dδ̂/√(1−δ̂²) = π/2 − arcsin(δ̂_45) = 1.53509641
        δ̂_45 = sin(π/88) = 0.0356923

Jacobian: M = M_base(1+δ̂)^{3/2} ⟹ dM/dδ̂ = (3/2)M_base√(1+δ̂)

★★ P_A(M) = 2 / (3·M_base·√(1+δ̂)·norm·√(1−δ̂²)),   δ̂ = (M/M_base)^{2/3} − 1
```

### 1.2 ★交界特徵: M_turn 可積發散

M → M_turn (δ̂ → 1) 時 √(1−δ̂²) → 0 ⟹ **P_A 發散** (可積):

| M | P_A(M) |
|:---|:---:|
| 0.500·M_turn | 2.093e-7 |
| 0.950·M_turn | 4.527e-7 |
| 0.990·M_turn | 9.883e-7 |
| 0.999·M_turn | 3.109e-6 |

**∫ P_A(M) dM = 1.02326** (解析精確; = (π/2)/[π/2 − arcsin(δ̂_45)] = 1.0232577)

> **⚠️ 審計修正 (2026-09-16, `scripts/98` 獨立核對)**: 原文寫「0.99810 (數值積分, dev 0.19%)」— **錯**。
> 代入 δ̂ = (M/M_base)^{2/3}−1 後 P_A dM = dδ̂/(norm·√(1−δ̂²))，故
> ∫_{M_base}^{M_turn} P_A dM = (1/norm)[arcsin(1) − arcsin(0)] = **(π/2)/norm = 1.02326** (精確閉式)。
> 即通道 A 份額 **超歸一 2.33%** (唔係欠歸一 0.19%)。原文 0.99810 無閉式來源。
> 原文值保留於此行內文。M_turn 尖峰數值積分 (scipy, limit=300) 獨立複核得 1.0232558 ✓ 同閉式一致。

### 1.3 交界形狀總式

```
P(M) = w·P_A(M) + (1−w)·P_B(M)
P_A: arcsine-Jacobian (發散尖峰 @ M_turn, 硬上限)
P_B: logN (平滑, 中位 6.98e6, σ_lnM = 1.7811)
P_B(M < M_turn) = 0.4433  (通道 B 有 44% 低尾)
```

**★硬分界 (可證偽核心)**: M > M_turn ⟹ P_A = 0 ⟹ **100% 通道 B** (已驗證 8/8, docs/01 V3)。

**★過渡寬度**: 由 P_A 發散尖峰 (M_turn 附近) + P_B 平滑尾部疊加 — 交界**唔係**平滑過渡,
係「硬邊 + 尖峰」。O181 LRD 質量窗 (3e6–1e7) 正正覆蓋呢個交界區。
