## 一、#1/#12  展平機制 — **🟡 部分閉合 (機制識別完成 + 一項修正)**

### 1.1 問題

種子譜全 PDF 斜率 @1e8 = **−4.23/dex** (docs/04 約定: d lnP/d lnM × ln10)；
觀測 BHMF 高端 ≈ **−0.82/dex** (LBQS z=2.5, 演化後只作方向)。需要展平 5.2×。

### 1.2 機制 1: 純成長 (G = 常數) — **唔展平**

M_obs = M_seed·G，G 同 M 無關 ⟹ ln M **平移** ⟹ 斜率不變。docs/03 T8g 結論正確。

### 1.3 ★機制 2: 成長卷積 (G **唔係**常數) — **展平 (修正 T8g)**

**★修正 docs/03 T8g**: 「純成長唔改斜率」只對 G = 常數成立。實際上 G 依賴
**per-object z_obs** (G = exp((t(z_obs) − t(z_f))/t_ef)) ⟹ G **有分布** ⟹ 卷積
⟹ σ_eff 增大 ⟹ **展平**。

```
σ_lnM(種子) = 1.7811  ⟹ Var = 3.1723
Var(t_obs) = 0.023676 Gyr², sd = 0.1539 Gyr  (10 粒實測 z)
Var(ln G) = Var(t_obs)/t_ef² = 0.094704
σ_eff² = 3.1723 + 0.0947 = 3.2670 ⟹ σ_eff = 1.8075
```

| 譜 | 斜率 @1e8 |
|:---|:---:|
| 種子 (σ = 1.7811) | −4.23/dex |
| **卷積後 (σ_eff = 1.8075)** | **−4.12/dex** |
| MC (600k, 10 點離散 z) | −3.24/dex |

**展平幅度**: 解析 3%，MC 23% (離散 z ⟹ 混合非純高斯)。

### 1.4 機制 3: L-cut 選擇 (λ·L_Edd·M ≥ L_min)

低 M 要過閘必須高 λ ⟹ 觀測樣本偏向 (低 M, 高 λ) ⟹ 進一步展平。
掃描 L_min = 1e43…3e44 ⟹ 斜率穩定喺 −3.24/dex (@1e8 遠高於閘, 效應飽和)。

### 1.5 裁決

| 機制 | 展平效果 |
|:---|:---|
| 純成長 (G 常數) | 0% (平移) |
| **成長卷積 (G 分布)** | **3% (解析) / 23% (MC 離散 z)** |
| L-cut 選擇 | 飽和 (−3.24/dex @1e8) |

**剩餘**: 觀測 −0.82/dex 需**更強機制** — 候選 = 吸積/合併演化 (z=2.5 嘅 BHMF 係
演化後, 唔係種子譜; 需完整 forward-model 含 accretion/merger)。

**★機制識別完成**: 展平 = 成長卷積 (σ_eff) + 選擇效應；種子譜 −4.23 → 觀測 −0.82
嘅剩餘差距歸因於吸積/合併 (唔喺 O197 種子譜範圍)。
