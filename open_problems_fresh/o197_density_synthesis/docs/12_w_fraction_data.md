## 一. 問題定義 — w 為何被 data-gate

`w` = **通道 A 份額** (docs/09 §1.3):

- 通道 A: δ̂ 譜偏差 → arcsine 分布 → M_seed ∈ [2.017e6, **M_turn**], **fresh (冇成長)**
- 通道 B: δ_env 環境 → logN → M_seed 中位 6.98e6, **full-time 成長**
- M_turn = M_base·2^{3/2} = **5.41361e6 M☉** (logM_turn = **6.7335**)
- 結構候選: **w = 1/F₅ = 1/5 = 0.2** (F₅ = L₄ − μ² = N_gen + μ² = 5)

verification/docs/08 (W4) 嘅裁決: 原樣本 **n = 10** (Harikane+23) 嘅 Clopper-Pearson
95% CI = **[0.0252, 0.5561]** (闊 0.531) ⟹ **8/8 候選全落 CI, 判別力 = 0**,
「dev 0%」係必然。所需樣本量 **n ≈ 97**。

**本文件 = 履行「獲取 Data-gated 的數據」。**

## 五. ③ 完整度修正 BHMF — 欄位身份裁決 + 反演

### 5.1 ★欄位裁決 (重要)

Taylor Table 3 有 `Φ` 同 `N` 兩欄, **兩者唔成比例** (N/Φ = 0.025, 0.068, 0.176, 0.303, 0.390)。

論文 §VI.2 原文: 「we construct the BH mass function by dividing the **weighted object
count** in each bin by the bin width and the co-moving volume」

⟹ 驗證: **Φ/(N/comp_total) = 1.200, 1.326, 1.253, 1.255, 1.257** — 近常數 (~1.25 = 1/(0.5·V),
V ≈ 1.6e6 Mpc³, 合理) ⟹

- **N = 未修正加權計數** (後驗分布分攤, 未做完整度修正)
- **Φ = N/(comp·0.5·V) = 完整度修正密度** (Fig.12 藍點)

交叉檢查: N-based 未修正份額 0.2579 vs 直接數 Table 1 raw 0.2258 ✓ (同層一致)
