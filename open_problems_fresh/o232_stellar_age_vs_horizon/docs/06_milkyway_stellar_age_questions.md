## Q1 🟢 銀河系唔係「年輕星系」——但「恆星 ≤ 宇宙齡」同星系年齡無關

**銀河系（暈）係宇宙最老成員之一，唔係年輕星系**：
- 銀暈球狀星團／特低金屬暈星：**13.5–13.7 Gyr**（BPS CS 22876−32 等）
- 薄盤：8–10 Gyr（較年輕，但呢個係**星系組裝歷史**，唔係「銀河年輕」）
- Banik+2026 樣本（低金屬、α-rich 次巨星）= 暈/厚盤族群 = **銀河最老人口**；佢哋嘅 A_★ = 13.73 正是「銀河老過頭」嘅證據方向

**關鍵轉譯**（R4 翻譯層）：ΛCDM 中「恆星 ≤ 宇宙齡」係**普遍約束**（恆星形成喺 t=0 之後），
唔係由「銀河年輕」造成——即使銀河今日先形成，入面啲星都唔可以 > A_U。「年輕星系所以星齡不過」係**錯嘅因果敘述**。

## Q2 🟢 係——光譜（＋視差）推斷星齡係成熟技術，但係統計性嘅

論文方法（arXiv:2607.00764 §2，快取）：
1. **次巨星分支 = 恆星時鐘**：次巨星壽命短（<1 Gyr），turnoff 位置對質量（⇒年齡）極敏感
2. **YY isochrones（Yi+2001 / Demarque+2004）**：用 (Teff, logg, [Fe/H], [α/Fe]＋Gaia eDR3 視差→光度) 擬合，年齡格上至 **20 Gyr**
3. **MCMC latent 年齡分佈重建**（＋疊代重建作交叉）——用**群體統計**壓單星散佈
4. **FLAME（純 Gaia）交叉**：兩個獨立管道一致先收
5. 論文操作天花板：`A − 5σ_A > 13.705 Gyr`（t_f = 0.1 Gyr 最早期形成）——樣本內 228 星被列為 0.1% 量測偽影

**限制（誠實標記）**：單星年齡誤差 ±1–2 Gyr（質量–金屬量–年齡簡併）；A_★ = 13.73 係 **latent 分佈極端**，
唔係「搵到一粒 13.73 Gyr 星」。**統計性 + 主序星多於單星精確**。
獨立交叉確認技術存在：白矮星冷卻序列、球狀星團 turnoff、星震學（紅巨星）。

**紅矮星（M 矮星）**：主序壽命 10³–10⁴ Gyr ≫ 13.787——宇宙內所有紅矮星都「未死」，
但 **冇一粒可以 > 13.787**（t=0 令形成時間 ≥ 0）。佢哋係「長命」，唔係「老過宇宙」。
最老暈紅矮星 ≈ 13.5–13.7 Gyr。

**白矮星**：冷卻齡係**下界**（總齡 = 冷卻 + 前身主序壽命 ~0.5–1 Gyr）；全部 12–13.5 Gyr，低於天花板。
**唯一曾「名義超齡」**：HD 140283（2013 名義 14.46±0.8），全系統誤差後與 13.787 喺 **1σ 內**相容（+0.84σ），
Gaia 複審更低（+0.16σ）——**歷史咗嘅「星老過宇宙」爭議已解決，非超齡證據**。
