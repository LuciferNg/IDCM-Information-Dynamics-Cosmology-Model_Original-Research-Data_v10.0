## 2. ★ IDCM 自身兩條互斥讀法（真 finding）

```
(A) doc 35 + verify_young_galaxies:  τ = 環周長「有幾遠」⟹ 冇年齡天花板
(B) doc 04:  渲染深度固定 (13.8); z>17=NaN 絕對截斷 ⟹ 存在「最大可渲染 lookback」⟹ 實質天花板
```
兩者對「有無天花板」給出**唔同答案**。外部 A_★ = 13.73 近 13.47 亦近 13.8 ⇒ **唔能裁決**。
但 doc 04 明言截斷在**早端**（z=17 ↔ 216 Myr）⇒ 讀法 (B) 之下「最老可渲染」= **D − 0.216 Gyr**，唔係 D 本身。

| D 取值 | 最老可渲染 (D − 0.216) | vs A_★ = 13.73 | 判定 |
|:---|:---|:---|:---|
| D = 13.4701（IDCM 結構值） | 13.254 | +0.476 = 2.9σ | 🟡 張力 |
| D = 13.8（doc 04 之 ΛCDM 錨） | 13.584 | +0.146 = 0.9σ | ✅ 相容 |
⇒ **若採讀法 (B)，數據偏好 D = 13.8 而非 IDCM 結構值 13.47**（即 IDCM 需結構推導出 13.8，仍未解決）。

```
raw: N(> τ)     = 22,661 (7.08%)      N(> 13.8) = 19,108 (5.97%)
```

不能作 IDCM「無天花板」之正面證據。論文之 13.73 係**清洗後（MCMC latent）**值，與目錄 raw 值不可直接比。
