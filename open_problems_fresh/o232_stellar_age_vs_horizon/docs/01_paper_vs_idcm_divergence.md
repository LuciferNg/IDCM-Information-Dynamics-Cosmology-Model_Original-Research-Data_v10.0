## 三、分歧逐條裁決

### D1 —「宇宙年齡」的存有論（最大分歧，範疇不相容）
- **論文**：Big Bang t=0；A_U = 13.8 Gyr 係**任務普遍、客觀**的量；恆星年齡係其**下界**。
- **IDCM**：冇 t=0；「齡」有兩層 —— (a) observer-relative **因果視界 τ = R_world/c = 13.47 Gyr**，(b) 相位標籤 t_true = 11,100 Gyr（亦非「起始至今」）。
- **裁決**：🔴 **範疇不相容**，非數值分歧。論文的 age 量測**預設了 ΛCDM 的 age 概念**；IDCM 把它降為 observer-relative 投影量。兩者不能直接對減。

### D2 —「恆星比宇宙老」悖論的**鏡像**
- **論文**：ETS 把宇宙壓到 12.9 Gyr ⇒ 出現「星(13.73) > 宇宙(12.9)」悖論 ⇒ 排除 ETS。
- **IDCM 自身**：τ = 13.4701 < A_★ = 13.73 —— **IDCM 亦面對 0.26 Gyr 缺口（1.6σ）**。
  - 但 IDCM **無 t=0、t_true = 11100 Gyr** ⇒「存在」上無悖論；缺口只出現在「**可觀測視界**」層。
- **裁決**：🟡 **核心未決**。IDCM 要麼證明 τ 唔係「可觀測星齡」之硬天花板，要麼需為 0.26 Gyr 缺口提供**結構因數**（見 R2）。

### D3 — Hubble 張力的機制
- **論文**：二選一 —— 早期新物理（被星齡排除）vs 晚期/局域空洞（被支持）；全在 ΛCDM 框架內。
- **IDCM**：張力係**投影層 artifact**；冇單一 H₀；幾何量 H₀ = ω_ring = 72.590，CMB 層 = ω_ring(1−π/44) = 67.407。**無需空洞**。
- **裁決**：✅ **方向一致**（兩者皆否定早期新物理）；⚠️ **機制不同**（IDCM 走「投影」，論文走「空洞」）。

### D4 — H₀ 數值
- 論文局域量 H₀_local = 73.17 ± 0.86；IDCM ω_ring = 72.590 → **0.67σ**；vs SH0ES 73.04±1.04 → **0.43σ**。✅ **一致**。
- IDCM 可證偽預言：純幾何量度（視差 / 脈澤 / 重力波）應收斂於 **72.590**（唔到 73.x 以上）。

### D5 — 方法論不咬合
- 論文的 age argument 依賴 ΛCDM 的膨脹積分；**IDCM 無此積分** ⇒ 論文對 ETS 的排除屬 **ΛCDM 內部**，**不直接檢驗 IDCM**。
- 論文 caveat「常數隨時間改變」**不咬合 IDCM**：IDCM 常數係靜態比值，α running 係投影效應，非時間演化。

### D6 —「13.8」在 IDCM 的身份（🔴 密度前驗）
- 需要之比 = 13.8 / τ = **1.0244941**。
- **凍結結構池**（IDCM 結構原子 ≤ 88）枚舉 p/q (1<p/q≤1.10)：**N_search = 10，0 命中**（null 期望 0.2）。
- **post-hoc 寬池**：唯一命中 = `42/41`（dev 0.010%）、`43/42`（dev 0.067%）—— 皆為**連續整數比 k/(k−1)**，屬泛型巧合（null≈0.5，得 2 個不顯著）⇒ **(🔴 post-hoc，禁宣稱結構)**。
- **裁決**：🔴 **IDCM 未結構推導 13.8**；13.8 係外部錨。scripts/01 §Δ 已凍結此結論。
