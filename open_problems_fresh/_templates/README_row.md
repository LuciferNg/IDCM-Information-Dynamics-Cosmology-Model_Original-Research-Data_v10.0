## 一行範本

```markdown
| **O{NNN}** | **{名稱}** | {emoji} **{狀態一句}** | **{摘要}** |
```

### 欄位規則

| 欄 | 規則 |
|:---|:-----|
| `#` | `**O{NNN}**`，粗體。特例：`**BPT**` 等非 O 條目照舊 |
| `名稱` | `**{名}**`，粗體，≤20 字 |
| `狀態` | `{emoji} **{一句}**` — emoji 見 `FORMAT.md` §三；一句內含**驗證率**（例 `8/8 PASS`）同**閉合日期** |
| `摘要` | `**{內容}**` — **結論先行**；★ 標重要發現；⚠️ 標陷阱；含驗證率 |

### 鐵律

1. **摘要內唔准用 `|` 字元** — 會斷開表格。需要時用 `\|` 或改寫。
   ⚠️ 實錄：`l.split("|")` 再 `"|".join()` 改狀態欄，會令轉義 pipe 斷開、**該行內容被截斷**。
   改法 = **整行重建**。
2. **狀態 emoji 只用對映表內嘅** — 唔准自創。
3. **行保留，唔刪** — 已合併／已撤銷嘅 O 行要保留（`🔀` / `⬛`），唔准刪行。
4. **改完要掃殘留碎片** — 掃「含原摘要關鍵詞但唔屬該 O」嘅行，應 = 0。
5. **狀態權威** — 本表 emoji 係狀態權威；`register.py check` 用佢嚟對帳。
