# O112: 968 ↔ T_CMB 交叉驗證

## 狀態: 🔴 待攻堅

## 問題
O100 發現 Σ1/γ_odd = 968 = 44×22, 但 T_CMB = 2.7283 K 同 968 之間無直接數值關係。檢查:
- M₀/968 = 2.79e7/968 = 28822 eV = 3.34e8 K (太大)
- M₀/(968×44) = 655 eV = 7.6e6 K (仍大)
- M₀/(968×44²) = 14.9 eV = 1.73e5 K (仍大)
- M₀/(968×44³) = 0.338 eV = 3925 K (仍大 1440×)
- 2.7283 K × 968 = 2641 K (冇結構意義)
- 2.7283 × 44 = 120 K (冇)
- 2.7283 / 44 = 0.0620 K (冇)

## 已知
- Σ1/γ_odd = 968 = 44×22 = N_d × 2L₅
- ~~T_CMB = 2.7283 K (Planck 2018)~~ ⚠️ **更正 (O166, 09-10)**: 2.7283 唔係 Planck 2018 值; Fixsen 2009 = 2.72548 ± 0.00057 K. 2.7283 = cmb_cl exp(−74) 公式輸出 (O166 已降級, 投影閉合 2.7284 ± 0.5%)
- M₀ = 27.9 MeV (IDCM 質量單位)
- ω_sync = 2π/T_sync = 2π/(84.64 Gyr) = 2.35e-18 rad/s
- ħ·ω_sync/k_B = 1.80e-29 K → T_CMB 唔係直接來自 ω_sync

## 開放子問題
1. T_CMB 同 968 嘅結構關係?
2. T_CMB 係咪來自 partition function: ⟨E⟩ = −∂lnZ/∂β?
3. Σω_n = 88 (Σγ_odd) 同 T_CMB 嘅關係?
4. 高溫極限 ⟨E⟩ ≈ 44/β → k_B T_CMB = ⟨E⟩/44?
