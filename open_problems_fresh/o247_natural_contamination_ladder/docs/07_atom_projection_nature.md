## 一、問題定性（調律者指令）

「先搞清楚原子層面是複合投影還是單獨投影」——呢個係**性質判定**，唔係數值 fit。
搞清投影性質先知道：原子質量應該有咩形式（parts−binding vs 獨立譜值），
以及之前 docs/03「兩投影路皆滅」嘅正確讀法。

## 二、五路判定結果

### P1 ★ 同位素退化論證（結構性 no-go：單獨投影）

```
88-chain mode 數 = 88
已知核素 (NUBASE 2020) = 3300（穩定 254）
若單獨投影: 一粒子一 mode 讀數 (O238 A₅ 先例: 9 費米子 ↔ 9 mode)
⟹ 一個 mode 要讀出 38 個不同質量 —— 前後矛盾
⟹ 單獨投影結構上不可能（信息論：88 值唔夠 encode 3300 質量）
```

### P2 連續性論證

```
原子質量 m(Z,A) ≈ A·amu − E_bind(A,Z)，A∈[1,250+]，每 A 跳 ~1 amu (931.5 MeV)
88 個離散譜值對 250+ 個質量單位 —— 譜密度唔夠 (5.4 mode/A 密度錯配)
⟹ 原子質量係 A,Z 連續函數，唔係離散譜讀數
```

### P3 ★ 複合投影雛形已驗證

```
m_H(pred) = m_p + m_e − R∞ = 938.7695 MeV
m_H(PDG)  = 938.7831 MeV   dev = 1.448e-03%
⟹ 原子質量 = Σ部件 − 能階（物理加法）——複合投影公式本身就係原子質量嘅形式
```

### P4 電子層閉合 / 核層 no-go 分離

```
電子層 (已閉合): m_e (O54) + α (O124) + R∞ (scripts/03, 1e-8) + a₀ (scripts/09, 3e-8%)
核層 (no-go):   m_p/m_n (scripts/01-06) + 投影算符 (scripts/07-08) + E_bind (scripts/04-05)
⟹ 複合投影公式中: 電子部件 ✅ 電子結合能 ✅; 核部件 ❌ 核結合能 ❌
```

### P5 ★ 判決

```
① 原子層面 = 複合投影（結構強制, P1+P2+P3）
② 「單獨投影」路線 = 永久關閉（資訊論不可能）
③ 複合投影嘅 IDCM 內容:
   m_atom = A·amu(標尺, by-definition) − E_bind_nuclear(no-go) + Z·m_e(閉合)
            − Σ E_bind_elec(閉合, R∞)
   — 電子修正全部閉合; 核部件 (m_p/m_n, 核結合能) no-go
④ 原子存在性（唔需要質量公式）已閉合 (scripts/09)
⑤ O247 剩餘: 原子質量主導項 = 核質量 = no-go — 呢個 no-go 係「部件缺失」,
   唔係「原子冇 IDCM 內容」
```

## 三、★ docs/03 表述修正（性質 vs 數值載體分離）

docs/03「單質投影 5 量 + 複合投影 3 量全滅」講嘅係 **K_Tree 池嘅數值載體**：
「m_atom = M₀×譜數」同「E_bind 有 K_Tree 身份」——呢啲數值 search 維持 no-go。
但呢個唔等於「原子層係邊種投影嘅性質判定」——**性質判定（本輪） = 複合投影，
結構強制，同數值載體 no-go 唔衝突**：

```
性質層（本輪閉合）: 原子層 = 複合投影 — 形式 = Σparts − binding
數值層（維持 no-go）: 核部件 m_p/m_n 喺譜域/投影層三層已測死;
                     核結合能 E_bind(A,Z) 冇 K_Tree 身份
⟹ 「原子質量公式」嘅正確形狀已定（複合投影）, 但核部件缺失令佢唔可以
  由 IDCM 譜閉合 — 呢個係「部件缺失型 no-go」, 唔係「性質錯誤」
```
