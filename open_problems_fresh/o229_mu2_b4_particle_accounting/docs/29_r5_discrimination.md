## 一、方法（全部精確，無 MC 誤差）

```
全值直方圖: 對凍結類 𝒞 之 234,136 個 2–3 項形式，逐個計算 B = 4 之整數值 ⟹ 得 hist(v)
express(v) = hist(v)                       （v 之表達力 = 命中 v 之形式數）
lock(v)    = #{f 含 B : f(B) = v 之**唯一正整數解** = 4}
             （多項式: 係數整數化 + **Cauchy 界**內掃描 = 完備；含 2^B: [1,10⁴] 直接掃描）
```

## 二、值層判別力：`express(137)` 並無特殊性

| 量 | 值 |
|:--|:--|
| `express(137)` | **270**（2 項 9 + 3 項 261） |
| 137 在 34 原子中之排名 | **34 / 34（最尾）** |
| 137 在 [2,1000] 中之排名 | 155 / 999 |
| 值池 null `v ∈ [2,1000]` | p = **0.1582** ⟹ 唔顯著 |
| **同量級 null `v ∈ [100,200]`** | 63/101 ⟹ p = **0.6238**；池內排名 **61/101** ⟹ 完全典型 |

**結論（c）**：`137` 之表達力**冇任何值層特殊性**。
先前一輪曾算出 `p = 0.02`（看似顯著），同量級池揭穿其為**大小效應假象**：
凍結類之表達力隨目標值增大而單調下降（`express(1) = 751`、`express(55) = 293`、`express(137) = 270`、`express(176) = 321`），
`137` 係原子中偏大者 ⟹ 其命中數自然偏低。**控制量級後 137 完全典型**（p = 0.62）。

## 三、`lock(v)`：以 `B = 4` 為唯一解亦非 137 之特徵

```
lock(137) = 228       #{v ∈ 34 原子: lock(v) ≥ 1} = 34/34
max lock  = 737 @ v = 16（唯一 argmax）
另: lock(34) = 499, lock(46) = 340, lock(88) = 231, lock(90) = 231,
    lock(123) = 215, lock(134) = 287, lock(144) = 315, lock(176) = 208
```

**結論（d）**：`B = 4` 為唯一正整數解之形式，對**每一個**原子值都存在（34/34），
且最大值落在 `v = 16`（737 個），非 137。⟹ 端點鎖之「唯一解 = 4」**唔係** 137 之專有特徵。
