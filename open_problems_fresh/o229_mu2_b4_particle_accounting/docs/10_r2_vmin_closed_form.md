## §1 R2-③ `V_min` 閉式 — 解問題記錄之 `??`

`01_problem_record.md` §二 載 `V_min = −μ²/(4λ)??`（存疑未決）。本輪精確求解：

```
V(x) = −μ²·x + λ·x²,   x := |W|²
dV/dx = 2λx − μ² = 0   ⟹   x* = μ²/(2λ)
V_min = V(x*) = −μ²·(μ²/2λ) + λ·(μ²/2λ)² = −μ⁴/(2λ) + μ⁴/(4λ) = −μ⁴/(4λ)
```

代入合約原子 `μ² = 2`、`λ = μ²/123 = 2/123`：

```
x* = |W|²_min = μ²/(2λ) = 123/2 = 61.5        (Fraction 精確)
V_min         = −μ⁴/(4λ) = −123/2 = −61.5     (Fraction 精確)
```

### 兩條附帶恆等（精確）
| 恆等 | 條件 | 值 |
|:--|:--|:--|
| `V_min = −μ²·⟨W⟩²/2` | 一般 | −61.5 |
| `V_min = −⟨W⟩²` | **⟺ μ² = 2** | −61.5 |
| `E_J = 2⟨W⟩² = 123 = L₁₀` | 一般 | 123 |

★ 三量同源：`|W|²_min = 61.5`、`−V_min = 61.5`、`E_J = 123 = 2×61.5` ⟹ 真空期望、勢極小、Josephson 能標三者係**同一數**之三面。

### 記錄缺陷
- ⚠️ 問題記錄之 `−μ²/(4λ)` 係**記法缺陷**（`−μ²/(4λ) = −123/4 = −30.75 ≠ −61.5`）；正確為 **`−μ⁴/(4λ)`**。
- 依文檔歷史完整性規則，**唔改**已寫入之 `01_problem_record.md`，只在本新檔更正（時序索引見 §3）。

## §2 R2-⑤ 派生數 `8` 之逐項出處（禁引用，Fraction 重算）

R1 `docs/06` 之 R11 記「`Σ_f N_c Q_f² = 2B = 8`」但未逐項核。本輪：

| 場 | `N_c` | `Q²` | `N_c·Q²` |
|:--|--:|:--|--:|
| `u` | 3 | 4/9 | 4/3 |
| `d` | 3 | 1/9 | 1/3 |
| `e` | 1 | 1 | 1 |
| `ν` | 1 | 0 | 0 |
| **每代** | | | **8/3** |

```
(8/3) · N_gen = (8/3) · 3 = 8 = 2B  @ B = 4        (精確)
等價一維方程: (8/3)(B − 1) = 2B  ⟹ 唯一解 B = 4
```

### 結論
- ✅ `8 = Σ_f N_c Q_f² = 2B` 之 `(8/3)` 因子**逐項精確**（非引用）。
- ✅ 且此式**單獨即定 B = 4**（併入 R2-② 之路線集後仍係冗餘——因 (8/3) 因子本身含 `N_gen = B − 1`，屬**內部耦合式**，唔係外部錨）。
- ★ 注意：`8 = 2B` 唔係獨立鎖（它與 `K1/K2` 同族），已於 docs/09 §2 之成本分類中歸入「內部結構」組。

## §2b 〔`-c4` 校正〕約定敏感：標準 QED 約定給 `16/3`，三代和 = `16 = B²`

§2 之 `8/3` 係 **naive 約定**（只把 `u, d, e` 各計一次）。標準 QED 約定須計**全部 16 個左旋 Weyl 態**（SO(10) `16 = Q_L, u^c, d^c, L, e^c, ν^c`），即含 `u^c / d^c` 之共軛態：

| 表示 | 態 | 色重數 | `Q` | `N_c Q²` |
|:--|:--|--:|:--|--:|
| `Q_L` | `u_L` | 3 | 2/3 | 4/3 |
| `Q_L` | `d_L` | 3 | −1/3 | 1/3 |
| `u^c` | `u^c` | 3 | −2/3 | 4/3 |
| `d^c` | `d^c` | 3 | 1/3 | 1/3 |
| `L` | `ν_L` | 1 | 0 | 0 |
| `L` | `e_L` | 1 | −1 | 1 |
| `e^c` | `e^c` | 1 | 1 | 1 |
| `ν^c` | `ν^c` | 1 | 0 | 0 |
| **合計** | **16 態** | | | **16/3** |

```
標準約定: 每代 Σ_f N_c Q_f² = 16/3   ⟹   三代和 = 16 = **B² = 旋量維數**   (Fraction 精確)
naive 約定: 每代              = 8/3   ⟹   三代和 =  8 =  2B
```

- ✅ **兩約定皆給 `B = 4`** ⟹ R11 對約定**穩健**：standard `(16/3)(B−1) = B²` 之解 = `{4, 4/3}`（取正整數 = 4）；naive `(8/3)(B−1) = 2B` 之解 = `{4}`。
- ★ **標準約定之陳述更強**：`Σ_f N_c Q_f²` 三代和 **直接等於 `B²` = 旋量維數 16**（而非 `2B`）——即 QED 之電荷平方和 = 每代之旋量態數，係同一 `16` 之兩面。
- ★ 此項由**獨立核對器**（`scripts/12` B6/B7）促發：核對器唔 import `scripts/10`，獨立枚舉 16 態得同值。
