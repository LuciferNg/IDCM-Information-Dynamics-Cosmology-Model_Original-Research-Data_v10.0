**普遍定理（R4-①）**：`∀ M ∈ ℳ`，整數模恰 `{0, M/4, M/2, 3M/4}`、**值集恰 `{0, 2, 4} = {0, μ², B}`**、

## 二、`3 ∤ M` 係結構必然（本輪核心）

```
3 | M  ⟺  3 | 2^a · 11^b      （因 ℳ 之每個元素餘因子皆 1）
        ⟺  3 | 2^a  ∨  3 | 11
        ⟺  False                （2 與 11 皆非 3 之倍數）
```

等價陳述：**`N_gen = 3 ∤ N_site = 2B·L₅`**（因為 `3 ∤ 2B = 8` 且 `3 ∤ L₅ = 11`）。
⟹ R3-② 之 🟡 殘餘（「`3 | M` 之鏈在 IDCM 內有冇實例」）**閉合為 ✅**：
**冇，而且係結構上不可能** —— 乾淨性唔係巧合，係 `L₅ = 11`（質數、`≡ 2 (mod 3)`）之算術後果。

## 三、反面可證偽（A3）

把 `L₅` 換成任何值 `L₅'`，令 `M = 2B·L₅' = 8L₅'`：

```
L₅' ≡ 0 (mod 3)  ⟹  3 | M  ⟹  值集擴為 {0, 1, 2, 3, 4}（出現 γ = 1 與 γ = 3 = N_gen）
L₅' ≢ 0 (mod 3)  ⟹  值集恰 {0, 2, 4}
```

- 雙向掃描 `L₅' ∈ [2,30]`：**(值集恰 {0,2,4}) ⟺ (3 ∤ L₅')**，0 例外。
- 臨界例：`L₅' = 6 → M = 48`、`L₅' = 12 → M = 96`，值集皆 `{0, 1, 2, 3, 4}`（實測）。
- `L₅ = 11 ≡ 2 (mod 3)` 落於乾淨分支。

**可證偽預言（供其他 O 用）**：若 IDCM 任何子結構出現長度 `3 | M` 之鏈，該鏈之整數譜**必須**含 `γ = 3 = N_gen`；
反之，若實測之鏈出現 `γ = 3`，則其長度**必須**被 3 整除（與 `N_site = 2B·L₅` 相容性立即可判）。
