## 二、獨立支撐 = 2

`R-a/b/c/e` 四個「斷裂」其實**化歸同一方程** `μ² = A/2`：

```
自對模（n = M/4，兩鏈皆有）: γ_{M/4} = A·sin²(π/4) = A/2 = 2
Σγ⁽⁸⁸⁾ = 21 對 × A + γ_22 + γ_44 = 84 + 2 + 4 = 90   ⟹  Σγ − 2N_d = 90 − 88 = 2 = A/2
配對結構                                        ⟹  Σγ_even − Σγ_odd = 46 − 44 = 2 = A/2
```

⟹ **獨立支撐 = 2**：
1. **自對模事實** `μ² = A/2`（`R-a/b/c/e` 四種讀法，秩 1）；
2. **橋** `R-d`：`μ² = B/2`。

**外部可觀測支撐 = 0**（重驗：R1 之 8 條 `μ²` 路線中 `external_observable_RHS` 全 false）。
對照：`B` 有外部錨 `α⁻¹(0) = 137` ⟹ 方向 `B → μ²` **單向**，唔可以反推。

## 三、子發現：橋化歸 `A = B`（跨接 R2-④）

由自對模事實 `μ² = A/2` 代入橋 `μ² = B/2` ⟹ **`A = B`**（選單歸一化約定）。
即：`μ²` 之真正結構內容 = **「自對模 = A/2」**；
`B = 2μ²` 之「`= B`」面係**慣例相依**（與 R2-④ 之「`A := B` 選單、`K16 ↔ K17` 席位互換」同一機制）。

⟹ `μ²` 之**約束秩（固定 A）= 1**；橋所加者係 `A = B` 而唔係新嘅 `μ²` 信息。
`μ²` 結構支撐 = **1 條鏈事實 + 1 條歸一化約定**，**0 條外部觀測** —— 此即「`μ²` 標度 🔴」之精確量化形式。

## 四、對 O38（`M₀` 標度）之意義

`μ²` 無外部錨 ⟹ 任何以 `μ²` 為標度單位之質量式（如 `M₀`）都**唔會**因此得到外部固定，
必須另有獨立外部輸入。本項為 R1 之「`M₀` 標度 🔴」提供**結構理由**（而非僅「未找到」）：支撐秩 1、外部 0。
