## §A 四項

### R3-① 異常和：由「檢查」升級為「定理」（`Y` 之唯一性）
設單代 16 態之量子數固定（R1 `docs/05` 之 6 表示表，含 `T₃R`、`B−L`、`Y`），
令 `Y(α, β) := α·T₃R + β·(B−L)/2`，`(α, β)` 為實未知量。逐項計算 8 個異常泛函：
`A[SU(3)³]`、`A[SU(3)²U(1)]`、`A[SU(2)²U(1)]`、`A[U(1)³]`、`A[grav·U(1)]`、
`A[grav·(B−L)]`、`A[(B−L)³]`、`A[(B−L)²U(1)]`，全部視為 `(α, β)` 之**多項式**。

**預註冊預測（二值）**
- **A1**: `A[SU(3)²U(1)] ≡ 0` 且 `A[grav·U(1)] ≡ 0`（對**所有** `(α, β)` 恆零 ⟹ 零約束）。
  依據：`Σ_{coloured} T₃R = 0`、`Σ_all T₃R = 0`、`Σ B−L = 0`（單代精確）。
- **A2**: 8 條件全零之實解集 = **過原點直線之並**；預測**維數 = 1**，方向 ∝ `(1, 1/2)`，
  **唔存在第二條獨立線**（即 `Y` 被量子數內容唯一確定到標度）。
- **A3**: 加歸一化 `Y(e^c) = 1` ⟹ `(α, β) = (1, 1/2)` **唯一**（唔係數值擬合：由 4 條條件 + 1 歸一化）。
- **A4**: 由解得之 `Y` 重算 `Σ_f N_c Q_f² = 16/3`（每代）、三代和 `16 = B²`（與 R2-⑤ 之約定討論獨立）。
- ⚠️ **風險項**：若 A2 之解空間維數 ≥ 2（例如出現第二條線），**原樣保留 FAIL**。

### R3-② 鏈譜整數性：**家族定理**（由 M = 88/176 推廣到一般 M）
`γ_n(A) = A·sin²(πn/M)`，本項取 `A = 4 = B`（單位耦合 Laplacian 頻帶頂；上游歸一化固定）。

**預註冊預測（二值）**
- **B1**: `γ_n ∈ ℤ ⟺ 2cos(2πn/M) ∈ ℤ`（因 `γ_n = 2 − 2cos(2πn/M)`）⟹
  `γ_n ∈ ℤ ⟺ n/M ∈ {0, 1/6, 1/4, 1/3, 1/2}`（模 1）。
- **B2（主定理）**: `3 ∤ M` 且 `4 | M` ⟹ 整數模恰 `{0, M/4, M/2}`，值集恰 **`{0, 2, 4} = {0, μ², B}`**，
  且**非零整數值之個數 = 2 = μ²**。
- **B3**: `3 | M` ⟹ 額外整數模 `{M/6, M/3, 2M/3, 5M/6}` ⟹ 值集擴為 `{0, 1, 2, 3, 4}`
  （具體盲測：`M = 48` ⟹ 整數 `n = {0, 8, 12, 16, 24, 32, 36, 40}`）。
- **B4（結構解讀，可證偽）**: `88 = 8·11` 且 `3 ∤ 88` ⟹ 整數譜乾淨；等價陳述 **`N_gen ∤ N_site`**。
  反面：若鏈長為 3 之倍數，譜中會出現 `γ = 1` 與 `γ = 3 = N_gen`，即「整數譜 = {0, μ², B}」**唔再成立**。
- **B5**: `M = 176`（雙覆蓋鏈）獨立重算 ⟹ 整數 `n = {0, 44, 88}`，`γ_44 = 2 = μ²`（中心模）、`γ_88 = 4 = B`。
- **B6（盲測家族預測）**: `M = 44 ⟹ {0, 11, 22}`；`M = 16 ⟹ {0, 4, 8}`；`M = 33 ⟹ 值集擴（含 γ = 1）`。

### R3-④ 端點鎖：**密度誠實界**（原子池 vs 連續區間）
R1 定義 `q_endpoint = #{k ∈ [2,400] : C(k²,2)+k²+1 ≤ 400} / 399 = 5/399 ≈ 1.253%`（🟡）。

**預註冊預測（二值）**
- **D1**: 形式家族 `k ↦ C(k²,2) + k² + 1` 之小 `k` 值 = `k=1→2`、`k=2→11`、`k=3→46`、`k=4→137`、`k=5→326` ⟹
  **4/5 落於原子表**（`2, 11, 46, 137` = `μ², L₅, Σγ⁽⁸⁸⁾_even, α⁻¹(0)`），`k=5→326` 非原子。
- **D2**: 改以**原子池**為前驗（`k` 只可以係原子，因為 `B = 4` 本身係原子）⟹
  `q_atom = 4/|atoms ∩ [1,400]| ≈ 4/33 ≈ 12.1%` **≫** 1.253% ⟹
  **R1 之 1.25% 係對「`k` 均勻分布於連續整數區間」之前驗，屬過度有利；誠實界應上修至 ~12%**
  （即端點鎖之判別力**接近零**，唔係「邊緣顯著」）。
- **D3**: 端點鎖之**精確性**不受影響：`B⁴ + B² − 272 = 0` 正根唯一 = 4（R2 已證）；本項只改**量化**。
