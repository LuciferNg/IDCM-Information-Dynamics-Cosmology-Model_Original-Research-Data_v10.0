# R5-① — 端點鎖之三項解剖：`137 = 120 + 16 + 1`

> 腳本 `scripts/22_r5_endpoint_anatomy.py`（13/13）｜數據 `data/22_r5_endpoint_anatomy.json`
> 合約 `docs/26_r5_contract.md` §B R5-①

## 一、三項之結構身份

```
α⁻¹(0) = C(B²,2) + B² + 1 = C(16,2) + 16 + 1 = 120 + 16 + 1 = 137     （B = 4）
等價有理式: (B⁴ + B² + 2)/2 ；等價多項式方程: B⁴ + B² − 272 = 0（正根唯一 = 4）
```

| 項 | 值 | 結構指派 | 判定 |
|:--|--:|:--|:--|
| `C(B²,2)` | **120** | 16 個左旋 Weyl 態之**無序配對數** | ✅ 組合計數（**非**群階，見 §二） |
| `B²` | 16 | 每代態數 | ✅ 結構指派（R1 §C 已證） |
| `+1` | 1 | 單態 | ✅ 結構指派（無進一步內容） |

## 二、`120` 之群階讀法：可證範圍（A2）

`120` 恰等於三個獨立精確計數（全部**顯式枚舉**驗證）：

```
(i)   C(16,2)  = 120                        （組合）
(ii)  |S₅|     = 5!                    = 120 （對稱群；偶置換 |A₅| = 60 顯式枚舉）
(iii) |2I|     = 5·|2T|                = 120 （2T 顯式枚舉 24 個單位四元數並驗乘法封閉；
                                              [A₅ : A₄] = 60/12 = 5，|A₄| 顯式枚舉 = 12）
```
（另記：`|Aut| = 2·60 = 120`（O223）亦同值。）

**但**「`C(B²,2)` 之群階讀法」**唔可以**直接成立：

- **(i) 傳遞讀法被排除**：若要求 `2I`-作用與「16 態不可分」相容（即**傳遞**），需 index-16 子群
  ⟹ `|H| = 120/16 = 15/2 ∉ ℤ` ⟹ 不存在 ⟹ 冇由此誘導之等變雙射 `Pairs(16) → 2I`。
- **(ii) ⚠️ 限制明記**：若容許 16 態**分裂**為非傳遞軌道（如 `10 + 6`：index-12 與 index-6 子群階 10、20 皆整除 120），
  則同一計數等式**另有**讀法 ⟹ 本項**只**排除傳遞讀法，**唔**聲稱「群階讀法一般不可能」。

## 三、判決：**半結構**

三項之中 **2 項**有結構指派（`16 = B²`、`1 = 單態`），第 3 項 `120` 係**配對計數**本身；
其與 `|2I| = |S₅| = 120` 之相等在「16 態不可分」之下被排除為等變身份（A2(i)），否則另有讀法（A2(ii)）。

⟹ 端點鎖之形式既唔係「純組合恆等」，亦唔係「已證之群論必然」，而是 **半結構**：
**結構指派存在，但唯一性／必然性未建立**。此判定與 R5-②（形式非唯一）互相印證。
