## 三、兩面結論

1. **形式非唯一**：`#forms = 270 ≫ 1` ⟹「端點鎖」**唔係**一條式子之特權
   （R1 曾以未凍結之鬆散枚舉估 `R = 6`；凍結類給 **270**）。
2. **但收斂**：228 個含 B 之命中形式**全部**（228/228）以 `B = 4` 為唯一正整數解
   —— 即 `L₅² + B² = 137`、`2B³ + 2B = 136`、`(B(B−1))² = 144`、`2^B = 16` 等互不等價之約束
   同時把 B 釘在 4。

**兩面必須並報**：`270` 講「形式唔稀有」（判別力分母極大），`228/228` 講「任一含 B 形式都唯一鎖 B = 4」。

## 四、符號陷阱（本輪自捉，correction tag `-c1`）

`ℱ` 內部有 **8 組**同一函數之重複表示：

```
2·1 ≡ 1·μ²        −2·1 ≡ −1·μ²
2·B ≡ 1·2B        −2·B ≡ −1·2B
1·B(B−1) ≡ 2·C(B,2)   −1·B(B−1) ≡ −2·C(B,2)
2·N_d ≡ 1·N_site  −2·N_d ≡ −1·N_site
```

⟹ 字面 120／expand-正則 114（只捉到 6 組）／**函數正則 112**（8 組全捉）。
