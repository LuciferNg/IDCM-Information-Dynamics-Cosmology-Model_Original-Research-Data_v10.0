## §0 方法（本輪之新儀器）

對全部 22 條對賬關係，在兩個單參數反事實下**同時**重算：
```
(i)  B → B(1+ε)   (μ²、上游常數、鏈振幅固定)
(ii) μ² → μ²(1+ε)  (B、上游常數、鏈振幅固定)
ε ∈ {1e-3, 1e-1};  鏈振幅 A = 4 視為上游歸一化 (唔隨 B/μ² 移動)
```
**判讀**：
```
殘餘 ≠ 0  ⟹ 【約束】(constraint) — 該關係係真預測，擾動即斷
殘餘 = 0  ⟹ 【定義/命名】(naming) — 兩邊同步移動，恆真 ⟹ 零對賬內容
```
★ 呢個測試之價值唔只在「睇幾多條斷」，而在於**機械地分開「內容」與「命名」** —
呢個係缺口 ③ 之身份類型分類之**可執行判據**（唔靠判斷）。

## §2 三個關鍵結論

### (4-1) B 側全斷 ⟹ B 唔係可調參數
16/16 顯含 B 之關係在 B-擾動下斷裂 ⟹ **B 冇任何「自由度」**：
任意外移 B 都同時違反 16 條獨立關係。B = 4 係**被過定之數**，唔係擬合值。

### (4-2) 兩腿解耦，唯一橋樑恰好係 `B = 2μ²`
```
μ²-擾動下: 15 條純 B 關係**全部存活** ⟹ B 與 μ² 係獨立自由度
           K12 (B = 2μ²) **斷裂** (res = 4.0e-3)
           K17 (μ² = γ_(M/4)) **斷裂**
```
⟹ `B = 2μ²` 係**唯一**連接兩腿之關係 ⟹ 佢係**約束**而唔係命名
（若係命名則兩擾動下皆存活，如 K13–K15）。**呢個直接否證缺口 ② 之「定義」分支。**

### (4-3) 剛性成立
不存在 ε > 0 使全部關係同時存活（兩個 ε 值下皆有斷裂）⟹ 系統**無冗餘自由度**。

### (4-4) 可證偽之具體數字
```
B = 2 → α⁻¹(0) = 11 ;  B = 3 → 46 ;  B = 5 → 326 ;  B = 6 → 667
```
任何 B ≠ 4 之「替代宇宙」都會被端點鎖**獨立排除**（唔靠色數、唔靠鏈）。
即：**若 SM 之色數或世代數唔係 3，IDCM 之 B = 4（由 α⁻¹(0) 鎖定）即刻被證偽。**
呢個係本 O 之**樣本外可證偽預言**（合約 §E ③）。

## §3 慣例凍結之附註

鏈振幅 A = 4 在本測試中**固定**。若把 A 亦設為自由（A := B），
則 K16 (`B = γ_max`) 會變成【定義/命名】而存活 — 呢個係**選單式**陳述，**唔取**。
理由（見 `docs/03` §3）：A = 4 被 B 之 9 條振幅無關路線**釘死**，
故 A 唔係自由慣例 ⟹ 固定 A 之處理係正確之物理讀法（慣例被數據唯一確定）。
