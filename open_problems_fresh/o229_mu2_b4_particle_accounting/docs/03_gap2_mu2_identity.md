# docs/03 — 缺口 ②：`B = 2μ²` 之地位（定義／巧合／結構推導）

## §1 三分支之逐一排除

### (i) 定義／同義反覆？ ❌ 排除

```
T1 重言式測: 「B − 2μ²」對自由符號 B、μ² **唔**恆等 0 (scripts/04 §[1])
符號共同性: B 與 μ² 無共同自由符號
更強之獨立性證據: μ² 有 6 條刻畫，其中 5 條 (M1–M6) **式內不含 B** ⟹ μ² 唔係「以 B 定義」
```
★ 若 B := 鏈振幅 A 且 μ² := A/2，則 B − 2μ² ≡ A − A = 0 係**恆等** — 故必須檢驗
「μ² 係否以 B 定義」。實測 μ² 之 6 條刻畫（中心模 / 宇稱差 / 勢參數 / Z₂ 不動點 / BC 成本 / F₃）
**全部不含 B** ⟹ **唔屬定義分支**。

### (ii) 巧合？ ❌ 排除

```
族定理 (scripts/04 §[4]): γ_max = 2·γ_(M/4) 對 M ∈ {8,16,44,88,176,352,704} **全部精確**
                          (max dev = 6.2e-61, 即 mpmath dps=60 之地板)
μ² = γ_(M/4) = 2 對所有 M 精確;  B = γ_max = 4 對所有 M 精確
```
⟹ 該關係**唔係** M = 88 之偶然數值接近，而係**離散 Laplacian 譜族之恆等性質**
（源頭：`sin²x + cos²x = 1`）。巧合分支排除。

### (iii) 結構推導？ ✅

**兩鏈各證一次**（`scripts/04` §[2]）：

```
88 鏈 (M=88): 配對 (n, 44−n)，γ_n + γ_{44−n} = 4 = B  ∀n
              n = 22 = N_d/2 係**自對點** ⟹ γ₂₂ + γ₂₂ = γ₄₄ ⟹ 2μ² = B      [dev < 1e-45]
176 鏈 (M=176): 配對 (44−j, 44+j)，γ_{44−j} + γ_{44+j} = 4 = B  ∀j∈[0,43]
              j = 0 係**退化自對** ⟹ γ₄₄ + γ₄₄ = γ₈₈ ⟹ 2μ² = B            [dev < 1e-45]
```
兩者係同一三角恆等 `sin²(x) + sin²(π/2 − x) = 1` 之**同一個退化點**（`scripts/04` §[3] 符號化簡 = 0）。

## §2 ★ 新結構引理（本輪 finding）

```
M = 88 鏈之**整數本徵值**恰為 {0, 2, 4} = {0, μ², B} = {0, F₃, L₃}
   n = 0 → 0 ;  n = 22 = N_d/2 → μ² = 2 ;  n = 44 = N_d → B = 4
證明要點: γ_n = 4sin²(πn/88) ∈ ℤ ⟺ sin²(πn/88) ∈ {0, 1/4, 1/2, 3/4, 1}
          ⟹ πn/88 ∈ {0, π/6, π/4, π/3, π/2};  88/6、88/3 非整數
          ⟹ n ∈ {0, 22, 44}  (非零者唯一)
```
★★ **`γ_n = 2` 之解唯一（n = 22 = M/4）** ⟹ μ² **唔可能**係鏈之其他模；
μ² 若非 2，則根本唔係任何鏈本徵值。呢個係 μ² = 2 之**結構鎖**（唯一性）。

**配套**：`L_n = 2F_n` 之解**唯一** n = 3（`scripts/02` §[7]，掃 n ≤ 23）。
故 `B = L₃ = 4` 且 `μ² = F₃ = 2` **同索引 3**，而 `L_n = 2F_n` 只有 n = 3 一解
⟹ 兩者之比值 2 係「同索引 Lucas/Fibonacci 對」之唯一可能。
🟡 **此為本輪新候選身份**（上游未註冊 `μ² = F₃`）— 標 🟡，須獨立推導方算閉合。

## §3 兩項誠實限制（唔可以略）

### 限制 1：譜腿之「4」係鏈振幅（慣例）

```
鏈一般形式 γ_n = A·sin²(πn/M)  ⟹  鏡像和 = A,  γ_max = A,  γ_(M/4) = A/2
A = 5 時鏡像和 = 5 ≠ B = 4  (scripts/04 §[5])
```
⟹ 嚴格講，譜腿證明嘅係 **`γ_max = 2γ_(M/4)`**（族恆等），
要升為 **`B = 2μ²`** 需要**額外識別**：`B ≡ γ_max` 與 `μ² ≡ γ_(M/4)`。

**該識別係自由慣例抑或被釘死？** — 被釘死：
`B = 4` 由 9 條**振幅無關**之路線（尤其端點鎖 α⁻¹(0) = 137）獨立固定
（見 `docs/02` §2）⟹ 鏈振幅 A **必須等於 4**，否則「B = γ_max」識別失效。
⟹ 慣例被上游凍結關係唯一確定（同 O226 R5 之「慣例被數據釘死」同構，
**唔可以提供選單**）。

### 限制 2：μ² **冇外部可觀測鎖**（核心不對稱）

```
B  之路線: R1 之 RHS = α⁻¹(0) = 137  ← **外部可量測**
μ² 之路線: M1–M8 之 RHS **全部**係結構內量（鏈本徵值 / 勢參數 / Lucas 數）
           ⟹ 外部可觀測鎖 = 0 條 (scripts/02 §[8])
```
⟹ **確定性方向 = B → μ²**。故 `B = 2μ²` 之「觀測內容」**全部由 B 側承載**；
μ² 側唔提供獨立觀測驗證。呢點必須明寫，否則容易誤把兩側當作互相印證。

## §4 判定

```
❌ 定義／同義反覆 — 排除 (μ² 之 6 條刻畫全不含 B; T1 非重言)
❌ 巧合          — 排除 (族定理對所有 M 精確; 同一三角恆等)
✅ 結構推導      — B = 2μ² 係 88 鏈自對點 (n = N_d/2) 與 176 鏈退化鏡像 (j = 0) 之必然結果

性質定位: 「B = 2μ²」之**內容** = 「B = 鏈振幅 A」之識別 + 「μ² = 鏈四分之一模」之識別
          + 三角恆等。三者合起來，B = 2μ² 係恆等而非數值巧合。
方向:     B → μ² (單向; B 有外部鎖, μ² 冇)
🟡 新候選: μ² = F₃, B = L₃, 且 L_n = 2F_n 唯一解 n = 3
```
