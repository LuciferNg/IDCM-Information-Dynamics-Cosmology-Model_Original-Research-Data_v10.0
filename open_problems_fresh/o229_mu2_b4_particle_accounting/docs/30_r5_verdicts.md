## 一、R5-① 端點鎖三項解剖 ⟹ **半結構**

```
α⁻¹(0) = C(B²,2) + B² + 1 = 120 + 16 + 1 = 137     （B = 4；等價 B⁴ + B² − 272 = 0 正根唯一）
```
- `16 = B²`：每代左旋 Weyl 態數 ✔ 結構指派
- `+1`：單態 ✔ 結構指派（無進一步內容）
- `120 = C(16,2)`：**配對計數**本身 ✔；但「`= |2I| = |S₅|`」之群階讀法**只在「16 態不可分」（傳遞）下**被排除
  （`120/16 = 15/2 ∉ ℤ` ⟹ 無 index-16 子群）；容許 16 態分裂時有 **34 種**非傳遞分解（`10+6`、`8+8`…）皆給另一讀法。
  ⟹ 第三項**唔係**已證之群論必然 ⟹ 整體判為 **半結構**。

## 四、R5 總判決

1. **端點鎖唔可以作為結構證據**：形式層 270 條、值層同量級 p = 0.62 ⟹ 由「結構**唯一推導** α⁻¹(0)」
   降格為「**一條可用之結構式**」。
2. **但在固定形式之下，`B = 4` 被過定**：228 條互不等價之結構式全以 `B = 4` 為唯一解
   （`L₅²+B² = 137`、`2B³+2B = 136`、`(B(B−1))² = 144`、`2^B = 16` …）⟹ R1/R2 之條件結果不變。
3. **上游 gap**：端點鎖形式之**群論必然性**仍未建立（需由更深結構強制 16 態不可分）⟹ 交 `register`（見 `docs/31` R5-A）。
