# docs/02 — 缺口 ①：`N_c = B−1 ⟺ B = 4` 退化裁決

> **日期**: 2026-10-02 ｜ **腳本**: `scripts/03` (14/14)、`scripts/02` §[1][5] (34/34)
> **合約條款**: 1-1 … 1-5 ｜ **判決**: ①(a) ✅ **非退化**；①(b) **退化但係同一根**

## §1 問題之精確化（兩個獨立命題，唔可以一齊答）

```
①(a) 「B = 4」與「N_c = B−1」之間：係咪退化？
①(b) 「N_c = B−1」與「N_gen = B−1」之間：係咪退化？
```

★ 原題目把兩者混成一句（「B 扮演模組深度與顏色數+1」）。**必須分開**：
B 之「模組深度」與「顏色數+1」係 **B 之兩個角色**，
而「N_c 與 N_gen 同值」係 **兩個角色之值相等**。兩者係唔同層次之問題。

## §2 ①(a) — 判決：✅ **非退化**

**判準（合約 1-1/1-2）**：存在 ≥3 條**完全不使用 N_c 符號**之路線各得 B = 4。

實得 **9 條**（`scripts/02` §[2]，逐字元掃描無 `N_c`）：

| 路線 | 關係 | RHS 淵源 |
|:--|:--|:--|
| R1 | C(B²,2)+B²+1 = 137 | α⁻¹(0) |
| R2 | B·L₅ = N_d = 44 | N_d |
| R3 | B² = 16 | SO(10) 旋量 |
| R4 | B·2L₅ = 88 | N_site |
| R5 | (B−1)² = 9 | Δα⁻¹ |
| R6 | N_d − 2B = 36 | h¹¹ |
| R7 | B² + N_d = 60 | 預算 |
| R8 | B/(N_d−B) = 1/10 | λ_Edd |
| R12 | L_B = 7 | b₀ |

**移一測試**（`scripts/02` §[3]）：刪去任何一條，其餘 8 條仍將 B 釘死為 4 ⟹ **過定（over-determined）**。

**替代值排除**（合約 1-4）：

```
B = 2 → α⁻¹(0) = 11 ;  B = 3 → 46 ;  B = 5 → 326 ;  B = 6 → 667   (實測 137 ✗)
B ≠ 4 ⟹ B² ≠ 16 且 B·L₅ ≠ 44 ⟹ 三鎖同時命中者 = 0 個
```

**⟹ 結論**：`B = 4` **唔係**由 `N_c = B−1` 反推。反過來 —
由端點鎖 R1（**式內無 `N_c`**）導出 B = 4 ⟹ **`N_c = 3` 係樣本外預言**（SM 實測 3，命中）。
⟹ ①(a) 之「退化」**唔成立**。

## §3 ①(b) — 判決：**退化，但係「同一根」而唔係「巧合」**

`scripts/03` §[4] 之代數核實：

```
N_gen := K_tree/L₅ = (N_d − L₅)/L₅ = N_d/L₅ − 1
B     := N_d/L₅
N_c   := B − 1
⟹ N_gen − N_c ≡ 0   (符號恆等 — 同一個函數)
```

且 `N_c = N_gen` ⟺ `L₅ + 1 = B(B−1)` ⟺ `12 = 4·3`，正解**唯一** B = 4（負根 −3 被 B > 0 排除）。

★★ **結構解讀**：`12 = B(B−1)` 正是 `SU(12) ⊃ SU(4)_PS × SU(3)_gen` 之**同一個因子化**
（SU(12) 基本表示維數 12 = 4×3）。色扇區來自 `SU(4)_PS → SU(3)_C × U(1)`（4 = 3+1 = (B−1)+1），
世代扇區來自 `SU(3)_gen`（3 = B−1）。**兩個「3」係同一個根 `12 = B(B−1)` 之兩個扇區**，
唔係兩個獨立奇蹟。

**⟹ 結論**：①(b) 係**退化**（值層：一方程兩讀法），但退化之內容係
**「色數與世代數之統一是結構後果」** — IDCM 把 SM 之兩個獨立經驗事實
（N_c = 3、N_gen = 3）**歸約為一個結構數 B−1**。呢個係**成果而唔係缺陷**，
但必須誠實標：**唔可以當「兩個獨立確證」**。

## §4 兩角色能否分離？（原題之直接答案）

```
✅ 可以分離，而且係「單向」分離:
   B = 4   ← 9 條振幅無關之路線（8 條唔用 N_c/N_gen）
   N_c = 3 ← B − 1（預言）
   N_gen = 3 ← (L₅+1)/B = B − 1（預言）
   
   方向: B → {N_c, N_gen}    （反之唔成立: 由 N_c=3 只能得 B=4，但 B=4 唔需要 N_c）
```
