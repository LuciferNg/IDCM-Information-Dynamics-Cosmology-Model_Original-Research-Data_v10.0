## 三、鎖之間為**負相依**（預註冊 FAIL 原樣保留）

```
邊際 m₁（端點鎖）= 1/105 = 9.524e-03
邊際 m₂（算術鎖）= 4/143 = 2.797e-02        乘積 m₁·m₂ = 4/15015 = 2.664e-04
聯合 q_atom = 2/15015 = 1.332e-04           ⟹ 聯合 / 乘積 = **1/2**
```

**機制**：端點鎖**強制** `k = 4`（因只有 `E[4] = 137 ∈ [100,200]`），
殺死 `k = 2` 支（該支本可滿足算術鎖：`2·13 = 26`、`2·18 = 36`）。
⟹ 預註冊之「正相關」**被否證**（實為負相依），FAIL 原樣保留並加 `-c` 校正。
**方法論教訓**：多鎖聯合機率**唔可以**當成邊際積 —— 鎖之間會經共用變量（此例 `k`）互相篩選。
