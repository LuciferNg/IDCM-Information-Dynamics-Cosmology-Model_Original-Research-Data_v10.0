## §A 三項

### R4-① IDCM 鏈長族之普遍定理（閉合 R3-② 之 🟡 殘餘）
R3-② 已證（對 `A = 4`）：`γ_n ∈ ℤ ⟺ 階 M/gcd(n,M) ∈ {1,2,3,4,6}`，且 `4 | M ∧ 3 ∤ M ⟹ 值集恰 {0, 2, 4}`。
本項把**假設**由「一般 M」換成「IDCM 實際鏈長族」：

```
ℳ := { 2^k : k ∈ [3,4] } ∪ { 2^k · L₅ : k ∈ [2,6] }      （L₅ = 11）
   = { 8, 16, 44, 88, 176, 352, 704 }
```

**預註冊預測（二值）**
- **A1**: `∀ M ∈ ℳ`：`4 | M` 且 `3 ∤ M` ⟹ 整數譜恰 `{0, M/4, M/2, 3M/4}`、值集恰 `{0, 2, 4} = {0, μ², B}`。
- **A2（結構必然，可證偽）**: `3 ∤ M` **唔係巧合**：`ℳ` 之元素皆形如 `2^a · 11^b`，而 `3 ∤ 2^a`、`3 ∤ 11`
  ⟹ **`3 | M` 對 IDCM 鏈在結構上不可能**。等價：`N_gen = 3 ∤ N_site = 2B·L₅` 係**恆等**（因為 `L₅ = 11` 為質數且 `≠ 3`）。
- **A3（反面可證偽）**: 若把 `L₅` 換成任何 `3 | L₅'` 之值（例 `L₅' = 6`、`12`），則 `M = 2B·L₅'` 會被 3 整除 ⟹ 值集擴為 `{0,1,2,3,4}`。
  ⟹ 乾淨性**唯一依賴** `L₅ ≡ ±1 (mod 3)`。
- ⚠️ **風險**：若 `ℳ` 內有任何元素 `3 | M`（即 A2 反例），原樣保留 FAIL。

### R4-② `μ²` 之結構支撐度（精確化 R1「μ² 冇外部鎖」）
R1 只講「`μ²` 之 8 條刻畫式中 `external_observable_RHS` 全為 false」。本項**量化內部支撐**：
把全部含 `μ²` 之關係列出，逐條以「`μ²` 真值 vs 擾動值」判其是否為**約束**：

```
R-a  μ² = γ⁽⁸⁸⁾_22           （中心自對模）
R-b  μ² = γ⁽¹⁷⁶⁾_44          （176 鏈中心模）
R-c  μ² = Σγ_even − Σγ_odd = 46 − 44

R-e  μ² = Σγ⁽⁸⁸⁾ − 2N_d = 90 − 88

R-g  E_J = μ²/λ = 123
R-h  V_min = −μ⁴/(4λ) = −123μ²/4      （導出量）
```

**預註冊預測（二值）**

- **B2**: **零信息型**（`μ²` 相消、對任何 `μ²` 皆成立）= **2** 條：`R-f`、`R-g`
  （因 `λ = μ²/123` ⟹ `|W|²_min = 123/2`、`E_J = 123` **與 `μ²` 無關**）。
- **B3**: **導出量型**（隨 `μ²` 移動、非約束）= **1** 條：`R-h`。
- **B4**: **獨立**支撐 = **2**（`{中心模}` 与 `{橋 B = 2μ²}`）；`R-a/b/c/e` 係**同一鏈事實之 4 種讀法**（非 4 個獨立支撐）。
- **B5**: 外部可觀測支撐 = **0**（承 R1，本項**重驗**而非引用）。
- ⚠️ **風險**：若「同一鏈事實」之判定被否（即 `R-a/b/c/e` 之中有 ≥1 條真獨立），`-c` 校正。
