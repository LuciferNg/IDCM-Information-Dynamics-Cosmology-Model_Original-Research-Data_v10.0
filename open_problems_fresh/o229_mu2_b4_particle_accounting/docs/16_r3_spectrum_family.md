## §1 主定理（精確）

設 `γ_n = A·sin²(πn/M)`，`A = 4`（= `B`，單位耦合 Laplacian 頻帶頂，上游固定）。則

```
γ_n = 2 − 2cos(2πn/M) = 2 − (ζ + ζ⁻¹),   ζ = e^{2πin/M}
```

`ζ + ζ⁻¹ ∈ ℤ` ⟺ `ζ` 之**階**（order）∈ `{1, 2, 3, 4, 6}`。故

```
★ γ_n ∈ ℤ ⟺ M / gcd(n, M) ∈ {1, 2, 3, 4, 6}
   階 1 → γ = 0    階 2 → γ = 4 = B    階 3 → γ = 3 = N_gen
   階 4 → γ = 2 = μ²   階 6 → γ = 1
   （階 5、7、8… 之 ζ + ζ⁻¹ 為無理 ⟹ 非整數）
```

此判準已與**高精度直接掃描**（`mpmath` 60 dps，容差 `1e-45`）逐點核對 441 點，0 例外。
