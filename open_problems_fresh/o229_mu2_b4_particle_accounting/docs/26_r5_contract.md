- **A2（可證偽，且**限定**其可證範圍）** 「`120 = C(16,2)` 之**群階讀法**」：

### R5-③ 形式 × 值 判別力矩陣

對每個原子 `v ∈ 34 原子集`：

```
express(v) = #{f ∈ 𝒞 : f(4) = v}                       （表達力：以 B = 4 直接命中）
lock(v)    = #{f ∈ 𝒞 含 B : f(B) = v 之唯一正整數解 = 4}   （鎖定力：唯一解恰為 B = 4）
```

- **C1** 表達力覆蓋：`#{v : express(v) ≥ 1} ≥ 0.8 × 34`（形式類表達力高 ⟹ 值層吻合便宜）
- **C2** 鎖定力稀疏：`#{v : lock(v) ≥ 1} ≤ 12`，且 `lock(137) = max_v lock(v)`
- **C3（判別力）** `argmax_v lock(v)` 之值集合；若 `|argmax| ≥ 2`（並列）⟹ 端點鎖**唔係唯一被鎖定之值**
  ⟹ 判別力須下修（`-c`）
- ⚠️ **風險**：若 `#forms` 意外地 < 3（B1 否證），或 `lock(137)` 唔係最大（C2 否證），原樣保留 FAIL。
