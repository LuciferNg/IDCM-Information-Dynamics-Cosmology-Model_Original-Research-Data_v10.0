## 二、逐項審計

### e^{−44} (O53) 🟡
- 用途: m_f = M_Pl·e^{−44}·e^{δ+c·lnφ}, m₄₄ = 950.006 MeV ≈ 0.9493 GeV
- 判據: docs/08 「44 = Nd = K_Chain site 數」+ docs/03 啟發式「壓抑因子」
- 問題: **e 底數冇結構來源** — 點解 e^{−N_d} 而唔係 φ^{−91.4}/2^{−63.4}/16^{−15.7}?
- 層次: 唔係 O165 禁嘅樹層權重 (質量階梯唔係 visibility ladder) → **冇違規**, 但機制開放

### e^{33} (O160) 🟡
- 用途: M_GUT = M_Z·e^{K_tree} = 91.1876 × 2.1464e14 = 1.956e16 GeV
- 問題: e 底數無來源; 且 M_Z 係觀察輸入 → **M_GUT 係投影, 唔係純譜預言**
- 對偶: 44 − 33 = 11 = L₅ — e^{−44} 同 e^{33} 鏡像對稱, 值得留意 (冇機制)

### e^{−74}, e^{−25.5} ✅ 已死 → 🟡 重開 (O168-06)
