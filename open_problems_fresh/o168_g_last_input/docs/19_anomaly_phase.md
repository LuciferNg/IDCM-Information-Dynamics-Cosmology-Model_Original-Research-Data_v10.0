## 問題
docs/16 已證明 53 = 相位方程唯一解、世界相位 44.5π − 反常 18π = 通道 26.5π。
剩: 反常相位 18π 嘅動力學 — 點解係 18π, 而唔係其他值?

## ★★ 核心身份: 反常相位 = Δα⁻¹·μ²·π = 9×2×π = 18π

| 量 | 值 | 來源 |
|---|---|---|
| Δα⁻¹ = α⁻¹(0) − α⁻¹(M_Z) | 9 = N_gen² | O142/O160 |
| μ² = γ₄₄ = λ₁₇ | 2 | O160 中央模定理 |
| Δα⁻¹·μ²·π | 9×2×π = **18π** | 本 script |

**反常相位 = α-跑動 × 中央模 × π** — 18π 唔再係「補集相位巧合」,
而係跑動 (9) 與中央模 (μ² = 2) 嘅精確乘積。

## ★ 相位預算方程: F₁₁ = k + 2μ²·Δα⁻¹

```
F₁₁ = 89 (世界相位預算, O161: 44.5π = 89·(π/2))
k    = 53 (通道)
2μ²·Δα⁻¹ = 36 (反常, 半-π 單位)
89 = 53 + 36 ✓ (精確)
```

- 36 = 2μ²·Δα⁻¹ = 4×9; 亦 = B·Δα⁻¹ (B = 2μ² = 4, 等價因式)
- **預算方程強逼唯一 k = F₁₁ − 2μ²Δα⁻¹ = 53** — gate ② 由「掃描唯一」升級「方程唯一」
- e 形 51: 51 + 36 = 87 ≠ 89 — 相位預算唔夠 (缺 2 半-π)
- F₁₀ 55: 55 + 36 = 91 ≠ 89 — 超出預算 (多 2 半-π)

## 機制詮釋 (🟡 公設層)

每單位 α-跑動消耗 μ²π = 2π 相位 — **一個完整繞數**。
詮釋: RG 流喺 α⁻¹-空間嘅旋轉數 = Δα⁻¹ = 9 (0 → M_Z 繞 9 圈)。
2π 因子嘅出處: Wilson line 相位 44.5π 係「總繞數×π/2」結構 (O161) —
跑動每單位貢獻一個整圈, 與世界相位預算同構。
