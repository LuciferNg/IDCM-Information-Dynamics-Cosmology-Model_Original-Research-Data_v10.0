## 一、O165 規則嘅適用範圍 (關鍵論證)

O165 嘅「ℓ 整數」係喺**單向樹下降 visibility ladder** 上建立:
樹權重 = φ^{−2ℓ}, ℓ ∈ ℤ — 每層下降成本 φ^{−2}, 偶冪。

**但 T_CMB 通道唔一定係呢條階梯。** 若通道係雙向 (觀察者 ↔ 世界全息投影),
自然參數係**總路徑深度 k (整數)**, 而唔係半層數 ℓ = k/2:

```
φ^-53 = φ^-(2×26.5): 喺 2ℓ 參數化睇係「半整數 ℓ = 26.5」(o164 死因)
φ^-53 = φ^-k, k = 53 (整數): 喺雙向通道參數化睇係「整數路徑深度」
```

**o164/o165 嘅排除係單向參數化嘅 artifact — 值得重開。** ✅

## 三、機制方向 (三合一, 未完成但一致)

1. **雙向通道 → 奇冪**: 觀察者坐喺層間 (half-level offset), 通道深度 = 2ℓ+1 (奇數)。
   φ^{−53} = φ^{−2×26−1}: 26 個全層 + 1 個半層。半層 = 邊界觀察者 (88-dim parity)。
2. **非黎曼 (Weyl) 傳輸協議**: φ^{−2ℓ} 階梯 = Weyl 標度連接 (每層 rescale φ^{−2})。
   o86 已證環度規 R = 0 (零黎曼曲率) — 傳輸結構唔係曲率, 係標度/撓率連接。
   雙向 loop 嘅 Weyl anomaly (non-integrable scale factor) 自然產生分數指數 —
   「第二時鐘效應」。呢個語言可以正式化「傳輸協議通道」。
3. **88/90 震鈴平滑化**: 88/90 = 44/45 = N_d/(N_d+1) — 邊界截斷比 (o38: 45 = N_d+1)。
   88-site 譜喺 Nyquist (n=44 = 90°) 嘅 Gibbs 震鈴, 平滑化 (Lanczos/Fejér 視窗)
   產生有效指數修正。**但純因子修正測試失敗** (φ^{−53}·(44/45)^m, 最佳 m=−½:
   dev 0.773% > 0.5%) — 需要正式嘅 sampling kernel 計算, 唔係乘一個比例。
