## 問題
docs/19: 每單位 α-跑動消耗 μ²π = 2π 相位 (RG 繞數公設)。
「2π」嘅 2 係邊度嚟?

## ★★ 『2』嘅結構來源: B = 2μ² = ΣA

```
2π/單位 = B·(π/2) = 4·(π/2) = 2π
          ↑模維度 ↑四分之一圈
B = 4 (模維度, dimC = B² = 16 spinor)
μ² = 2 (中央模, γ₄₄ 特徵值, O160)
B = 2μ² ⟹ μ²·π = B·(π/2) — 兩個因式完全等價
```

## ★ 環分區結構: 88 = B·22

```
88 sites = B(4) × 22 sites
22 = 2L₅ = 2×11 — 每模組件 = 22 sites = 四分之一環 = π/2
穿越全部 B 組件 = 一整圈 = 2π
```

每單位跑動 = 穿越 B 模 (4 分區 × 22 sites = 88 環) = 一整圈。

## 環總曲率對接 (O157)

- O157 零偏差定理: Σ_all A = μ² = 2 (176-Laplacian, BC-cost)
- 相位/單位 = ΣA·π = **環總曲率 × π**
- 『2』唔係自由數: = γ₄₄ 特徵值 = 曲率和 = B/2

## 完整鏈

```
總反常相位 = Δα⁻¹·B·(π/2) = 9·4·(π/2) = 36 半-π = 18π
三個等價因式: 2μ²Δα⁻¹ = B·Δα⁻¹ = 36 (μ² = B/2)
F₁₁ = k + 2μ²Δα⁻¹ = 53 + 36 = 89 ✓
```

## 裁決
- ✅ 『2』嘅結構來源確立: μ² = B/2 = ΣA (O157) — 唔再係自由數
- ✅ 每單位跑動 = 穿越 B 模 (4×22 sites = 88 環) = 一整圈 2π
- ✅ 四分之一圈 = 22 sites = 2L₅ — 環分區結構
- 🟡 剩: 點解跑動每單位要穿越成個 B 模 (α-跑動嘅模幾何 — 最底層機制)
