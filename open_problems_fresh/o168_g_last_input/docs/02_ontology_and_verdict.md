## 二、本體裁決: G 係咩?

**G 係框架嘅「最後絕對尺度輸入」— 但唔係自由常數。**

1. **輸入身份 (🔴 純譜推導不存在)**: M_P = √(ħc/G) 係絕對尺度鏈頂端。
   O38 公式 (M₀ = √(E_P·ħH₀)·φ^{47+37/528}·(1891/2025)) 以 M_P 做輸入;
   沙漠掃描證實冇任何乾淨結構組合可以命中 M₀/M_Pl (最佳單冪 φ^{−99} = 10.6% off)。

2. **但 G 被兩條獨立路徑釘住 (🟢 投影閉合成立)**:
   - 路徑 A: O38 反轉 — G = f(M₀, ħ, ω_ring, CY₃, φ), dev ~1e-7 (O38 閉合 82/82)
   - 路徑 B: η_B 方程 — G = f(Ω_b, ω_ring, η_B, m_p, T_obs), dev 0.32%
   - 兩路徑互相獨立 (一個用質量錨, 一個用 CMB 温度錨), 交叉 0.32%
   → G 唔係可以隨便調嘅參數 — 質量譜同重子扇區各自獨立釘住佢。

3. **O166 升級條件冇滿足 (保持 🟡)**: 投影閉合嘅 G 輸入可以換成「O38 反轉值」
   (dev 0.003%), 但 O38 公式自身含分數冪 37/528 (fit 殘餘, 無第一性來源),
   而 M₀ = 27.900915 MeV 本身係 o54 質量 fit 錨 → 成條鏈仍以觀察做底。
   **T_CMB 投影維持 🟡 (0.107%), 唔升 🟢。**

## 三、三投影統一圖 (The One Equation)

```
              η_B = Ω_b·3ω_ring²/(8π·G·m_p·n_γ(T))
                     │          │          │
                     │          │          └── o166: 求 T → 2.7284 K (0.107%)
                     │          └───────────── o73: 求 ω_ring → 72.73 (0.19%)
```

**一個方程, 三張臉。** IDCM 嘅零參數閉合唔係三個獨立推導 — 係一條結構方程
(η_B ≡ n_b/n_γ, 全部量已閉合) 對三個觀測扇區嘅一致投影。三者 <0.5% 互相一致。
