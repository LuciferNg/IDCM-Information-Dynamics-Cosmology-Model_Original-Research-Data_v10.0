## 1. ★ 重構: RGE 喺 IDCM = 調焦定律, 唔係流, 唔係阻尼

θ₂₃(N) = atan(sin(7π/N)/sin(6π/N)) — **N 係三角函數入面嘅參數**:

- ω_n(N) = 2sin(nπ/N) = 投影嘅「鏡頭」(sine 度量)
- θ(N) = atan(ω₇/ω₆) = 影像 (模式對投影成角度)
- **N = 焦距 / 調焦旋鈕** — 連續參數
- 框架尺度塔 {11,22,33,44,55,88,176} = L₅×{1,2,3,4,5,8,16} = **量子化焦距 detent** (鏡頭得嗰幾個卡位)

**一次過解釋三個現象**:
1. 殘差唔係流 — 係**散焦**: θ(88) = 49.3202° (誤焦 0.25%) vs θ(55) = 49.1966° (銳利 0.003%)。
   88 係 chain 觀察量嘅 detent, θ₂₃ (投影觀察量) 用錯咗。唔係 θ 隨尺度「跑」,
   係影相嗰陣用錯焦距。
2. 點解「寄生阻尼」讀法死咗 — 冇修正 bolted on, 純粹 re-focus。
3. RGE 第一性原理問題變成: **調焦定律 — 每個觀察量嘅焦距由咩定?**

## 2. ★ 新候選: 焦點定律 = 投影結構自己定焦

O148 投影份額鏈: f_proj = 19, f_unproj = 41, 3ε = 19/41, f_unproj = 41/60。

```
19 + 41 = 60          (投影鏈 19:41:60 — 兩個份額分子之和 = 60 = f_unproj 分母)
55 = 60 − 5 = (f_proj + f_unproj) − F₅
   = 投影總份額 − 純玻色子數 (O137 v₂≥3 = {8,16,24,32,40}, 5 個)
88 = 2N_d             (chain 觀察量焦距)
```

- **θ₂₃ (投影觀察量) 焦距 = 60−5 = 55** — 投影結構自己定, 唔係外來輸入
- **質量比 (chain 觀察量) 焦距 = 2N_d = 88** — 用緊鏡頭全開
- Sector 分離 = **唔同焦距來源**: chain 量用 2N_d, 投影量用 (投影空間 − 玻色排除)
