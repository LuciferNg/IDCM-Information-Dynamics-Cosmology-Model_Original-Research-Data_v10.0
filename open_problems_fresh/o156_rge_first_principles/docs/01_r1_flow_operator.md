## 1. 流算子定義

觀察量 θ₂₃ 喺尺度 N 嘅值: **θ(N) = atan(sin(7π/N)/sin(6π/N))**
(176 慣例: ω_n = 2sin(nπ/N); θ₂₃ = atan(ω₇/ω₆) = atan(g₇/g₆) W-field 耦合比)

**流向量場 (精確導數)**:
```
u(N)     = sin(7π/N)/sin(6π/N)
u'(N)    = [−7π cos(7π/N) sin(6π/N) + 6π sin(7π/N) cos(6π/N)] / (N² sin²(6π/N))
R_top(μ) = dθ/dlnN = N·u'/(1+u²)
```
