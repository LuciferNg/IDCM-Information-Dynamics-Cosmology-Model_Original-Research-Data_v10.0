## 2. ★ N(a,b) = ab+a+b 係 θ₂₃ 獨有 — 唔係費米規則

O36 全部 8 個模式對 (費米質量比 + 玻色質量比 + θ₂₃) 套用 N=ab+a+b:

命中率 1/8 — **只有 θ₂₃**。全 [1,44]² 密度 0.85% (8/946)。

**結構原因**: ab+a+b ≤ 176 先有可能命中塔 (即 (a+1)(b+1) ≤ 177)。大索引對
(玻色 19-41, 費米質量 8-33) 嘅積+和必然超出 — 佢哋根本冇「家」可得,
直接住 chain 尺度 88。**θ₂₃ (6,7) 係唯一細索引混合角** — 6·7+6+7 = 55 落入塔內。

⇒ **N=ab+a+b 唔係費米 sector 規則, 係 θ₂₃ 獨有身份** (同 docs/04 §3 一致:
e-row (2,3)→11 已證偽)。

## 3. 玻色模式對結構 (T5) — 同費米混合對唔同層

```
m_W/m_Z (30,41):
  30 = K_tree − N_gen = 33−3
  41 = N_d    − N_gen = 44−3
  差 = 11 = L₅ = N_d − K_tree ✓
  和 = 71 (質數)

m_H/m_W (38,19):
  19 = N_d/2 − N_gen = 22−3
  38 = 2×19 = N_d − 2N_gen = 44−6
  比 = 2:1, 差 = 19

θ₂₃ (6,7) (對照):
  6 = 2N_gen, 7 = L₄
  和 = 13 = F₇, 積 = 42 = N_d⁻
```

- 玻色對: **N_d/K_tree/N_gen 層** (近世界維度嘅「減法」模式), 差 = L₅
- 費米混合對: **N_gen/L₄/F₇ 層** (小模式, 和 = F₇ 入 Fibonacci 層)
- 兩者都唔用 O137 純玻色子索引 {8,16,24,32,40} (v₂≥3) — 純玻色索引係
  「唔可以做費米」嘅排除集, 唔係質量比模式
