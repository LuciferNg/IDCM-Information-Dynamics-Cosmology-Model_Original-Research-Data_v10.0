## 2. 家族密度 null

**家族 1/n** (n = ≤3 框架常數乘積, [300,700]): 61 個候選, tol 1.5% 內命中 **2 個** (462, 468)
→ 1/462 嘅命中係家族密度級, 冇唯一性。

**家族 (γ_a−γ_b)/c** (a<b∈[1,44], c ∈ 框架常數): tol 2% 內命中 **16 個**
→ (γ₇−γ₆)/30 嘅 0.14% 喺家族內零選擇性 — 任何 (a,b,c) 組合都可以撞中, 密度零信息量。

→ **結構判準直接拒**: 精度唔補償身份 (docs/05 階梯: 精度 + 多重度 + 身份 三缺一即敗)。
