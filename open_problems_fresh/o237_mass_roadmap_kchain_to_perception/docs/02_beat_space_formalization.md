## 一、交付：beat space = 正 88-gon 嘅弦長代數

### 1.1 向量身份（几何層）

```
b_n = sqrt(gamma_n) = 2 sin(n pi/88) = |1 - U_n|,   U_n = e^{i n pi/44}   (n = 1..44)
```

- **44/44 驗證**：`|1−U_n| = 2sin(nπ/88)`（mpmath 1e-40）
- `U_n` 係 88 次單位根（iπ/44 = 2π/88 × n/2 嘅相位）→ **b_n 正正就係單位圓上點 1 與 U_n 之間嘅弦長**

- ✅ 對應 docs/01 §五之「偏差層 = 結構閉合（γ = |1−U|²）」，再落一級到 √γ = |1−U|（幅度，唔係能量）

### 1.2 共面/度量層（rank = 2）

- v_n = 1 − U_n 全部喺同一個複平面（單位圓切線弦）⟹ Gram（44×44）秩 **2**
- 意味弦空間係 2 維（圓），但譜點有 44 個、44 個 beats 互異且嚴格遞增（non-degenerate）
- ⟹ **一個 n 一維游標**完全標定全部譜層質量（S4 兩層分工嘅結構根源：譜層只有一個自由度，n）

### 1.3 乘法閉合（代數層）——1936/1936

```
b_m · b_n = 4 sin(mθ) sin(nθ) = 2cos((m−n)θ) − 2cos((m+n)θ)      (θ = π/88)
          = b_{44−|m−n|} − b_{44−(m+n)}        (m+n ≤ 44)
          = b_{44−|m−n|} + b_{m+n−44}          (m+n > 44)
```

- **弦 × 弦 = 差弦 − 和弦**（product-to-sum，兩項 signed-beat 閉合）
