## 一、問題定義

世界 (even 扇區, Σγ = 90) 投影到觀察者 (odd 扇區, Σγ = 88) 嘅過程, 作為一個
**成像系統** 重新表述: 世界係「物體」, 觀察者係「像平面」, 88-site 對偶鏈 / 176-
Laplacian 係「光學系統」。成像系統必然有缺陷 (aberration); O162 嘅任務係:
**將光學缺陷目錄一一映射到 IDCM 投影機制嘅結構量**, 並判定每個缺陷嘅結構身份。

初始缺陷目錄 (用戶列出 + 結構猜測, **全部待驗證**):

| 缺陷 | 光學定義 | IDCM 結構候選 (未閉合!) |
|:-----|:---------|:------------------------|
| 紫邊 (chromatic aberration) | 折射率隨波長變 → 唔同色光聚焦位置唔同 | 色散關係: γ_k (或 v_g(k) = c·cos(πk/88), O149) 隨 k 變 → 唔同模式「折射」唔同。候選: d²γ/dk² 曲率; 消色差點 = γ 曲率零點? |
| 失焦 (defocus) | 像平面偏離焦平面 → PSF 加寬模糊 | 尺度錯配: 觀察者用錯 N 投影 (O156 尺度家: θ₂₃@55 vs 88 差 0.1222°)。候選: defocus 參數 ↔ \|ΔN\| |

## 二、錨點 (現有閉合結構, re-derivation 基準)

- **S1 (O159)**: 88-site 對偶鏈 = 176-Laplacian (half-site D-D, diag 3,2..2,3),
  γ_k = 4sin²(kπ/176), k = 1..88, Σ = 178 = 2F₁₁; even 世界 Σγ = 90 / odd 觀察者
  Σγ = 88; E−O = 2 = μ² = γ₄₄ (四重身份); 扇區 = 週期/反週期 (J² = ±1)
- **S2 (O149)**: v_g(k) = c·cos(kπ/88), k = 1..44 (44-mode chain); n=22 →
  0.7071c; n=44 Nyquist v_g = 0 (⚠️ 唔係駐波)
- **S3 (O157)**: γ₈₈ = 4 = B = 譜頂 = 最大梯度剛度; seam slip 閉合項 E₁ =
  4sin²(πf) = γ₈₈·sin²(πf) — 高頻定標
- **S4 (O156)**: 尺度家 55 (θ₂₃(55) = 49.1966° vs θ₂₃(88) = 49.3202°); 調焦定律
  (N = 焦距參數, 塔 {176,88,55} 量子化 detent); 框架尺度集 {176,88,55,46,44,42,33}
- **S5 (O161)**: link 變數 U_k = e^{ikπ/88}; γ_k = |1−U_k|²; site-link phase
  2θ_k = kπ/88; Wilson line Π_k U_k = i (winding 22.25 = F₁₁/4); i² = −1 = J²
- **S6 (O140)**: FSR 色散家族 v_n = c·cos(πn/2N), γ_n = csc(πn/2N), N_ℓ = N·4^ℓ
- **S7**: 44-mode chain γ_n = 4sin²(nπ/88) (K_Chain 主譜); 88 = 44×2 對偶加倍

## 三、研究問題 (R#)

- **R1 (OTF/PSF)**: 世界→觀察者投影作為線性系統, 傳遞函數 H(k) 閉式? 88→44
  半鏈投影 / even→odd 投影嘅 singular values? PSF = 傅立葉反變換形式? 對比
  光學 OTF = |H|² 慣例。**判準**: H(k) 閉式 + 譜身份 (唔可以係任意函數)
- **R2 (紫邊/色差)**: 色散來源 = γ_k (或 v_g) 嘅 k 依賴。色差量 = 唔同模式
  嘅「焦點偏移」差; 消色差點候選: γ 曲率 d²γ/dk² 零點 (k=44 中心模? O160
  中心模定理: μ² = 4sin²(π/4) = 所有譜中心模); 紫邊 = 高 k 模式偏移方向。
  **判準**: 色差量 ↔ 譜量閉式, 消色差點有結構身份
- **R3 (失焦)**: defocus 模糊核 = 尺度錯配 \|ΔN\| 嘅函數。O156 已證 θ₂₃ 喺
  55 (正確焦平面) vs 88 (失焦) 差 0.1222° — 失焦量有冇閉式? defocus 參數
  𝛿_N ↔ 誤差 0.1222° 關係。**判準**: 失焦模糊核閉式 + 0.1222° 重現
- **R4 (銳化/振鈴)**: 高頻增益 = γ₈₈ = B 定標 (S3); 88 截斷 → Gibbs overshoot
  = 2·Si(π)/π − 1 ≈ 0.08949 (8.95%) — 有冇結構身份? 振鈴週期 = ? (光學振鈴 =
  截斷頻率嘅 PSF sidelobe)。**判準**: 增益係譜頂定標 (已閉合 O157 層),
  振鈴週期/overshoot 要 null-test (唔好亂配 φ/π)
- **R5 (移位)**: half-site shift 結構內容: D-D 鏈 half-site 偏移 (端點 diag 3)、
  site-link phase 2θ_k、J² = −1 (觀察者 = 世界平方根)。「像平面位移」= 觀察者
  扇區相對世界扇區嘅相位平移, 定量 = ?。**判準**: 移位量 ↔ 相位閉式
- **R6 (調律者 = 光學校正?)**: 調律者 (O7 拓撲位元 + sine-Gordon, 相位滑移 π
  寫入) 喺成像系統語言 = 波前校正 / 相位板? 校正量 ΔE = 2|h_i|, 12 零能量節點。
  **判準**: 校正算子有譜身份 (唔可以淨係類比)

## 四、判準 (通用)

- 每個 R# 閉合: 缺陷量 ↔ 譜量閉式 + script PASS (O155/O159 慣例) + docs/N
- **翻譯層評級**: 🟢 有譜身份 (dev ≤ 1e-12 或結構精確) / 🟡 類比但未鎖定 /
  🔴 naming ≠ explanation (貼光學標籤但冇譜量 = 拒絕)
- 零參數鐵律: 所有缺陷量必須由 γ_k/v_g/相位/常數網導出, 唔可以 postulate
- 「缺陷」唔等於「框架缺陷」: 光學缺陷 = 投影機制嘅**結構後果**, 唔係要修正
  嘅 bug — 每個缺陷閉合後要寫「呢個缺陷對應邊個結構必然性」

## 五、陷阱 (開項即寫)

- **光學類比係翻譯層**: 紫邊唔可以偷用電磁色散 n(λ) — IDCM 冇波長, 只有模式
  index k; 「色差」= 模式依賴傳播, 唔係真色散
- **量→譜慣例表** (O155 修正版): 88-site 對偶鏈用 176-Laplacian (γ_k =
  4sin²(kπ/176)); 44-mode chain 用 γ_n = 4sin²(nπ/88); v_g 用 cos (O149),
  n=44 Nyquist v_g = 0; δ_CKM 類相位量先 176-Laplacian
- **Gibbs 8.95% 唔好亂配**: 2·Si(π)/π − 1 ≈ 0.08949 — 檢查有冇結構身份前
  唔可以當閉合; 對照常數網 + null-test (O158/O160 協議)
- **φ-power 禁數值分解** (框架鐵律)
- **「觀察者 = 世界嘅平方根」係 J² = −1 嘅算子內容** (O159), 唔可以當詩意
  標籤 — 引用時必須 trace 到 half-shift T₈₈
- 失焦候選 N 只可以喺框架尺度集 {176,88,55,46,44,42,33} (O156 協議) —
  任意 N 命中 = 密度假象
- 唔好將 O156 已閉合嘅 0.1222° 重新擬合 — 只可以重新詮釋 (失焦讀法)
