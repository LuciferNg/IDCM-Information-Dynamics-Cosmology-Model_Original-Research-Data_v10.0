## 1. ★ R2: 消色差定理 (中心模定理嘅色散讀法) — 閉合

**消色差**: d²γ/dk² = (π²/3872)·cos(kπ/88) = 0 ⟺ **k = 44** (自對偶錨)。

- k=44: cos(π/2) = 0 EXACT — 消色差點 = 中心模 = 自對偶錨 = γ₄₄ = 2 = μ²
- 呢個係 O160 中心模定理 (μ² = 4sin²(π/4) = 所有譜中心模) 嘅**色散讀法**:
  譜喺中心模嘅二階導數為零 = 模式聚焦唔隨 k 變 = 消色差

## 2. ★ 色差閉式: γ(44+m) = 2 + 2sin(mπ/88) — 閉合

```
γ(44+m) = 4sin²((44+m)π/176) = 2 + 2sin(mπ/88)   (EXACT)
γ(44+m) − γ(44) = 2sin(mπ/88)                     (色差 = 奇函數)
```

- **冇 m² 項** (sin 展開 = mπ/88 − (mπ/88)³/6 + ...): 一階線性, 零二階
  → **二階消色差 EXACT** (唔只係 d²γ/dk² = 0 喺一點, 係整個錨區冇色差項)
- 色差量 = 2sin(mπ/88) = **44-mode chain 嘅 ω_m** (O161 慣例) — 176-Laplacian
  中心模附近色差 = 44-mode ω: **兩個譜慣例喺呢度統一**
- m=22: 色差 = 2sin(π/4) = √2 (22 = N_d/2 = 2L₅, O145)

## 3. 鏡像和 (O160 重驗) + 紫邊方向

- γ(44+m) + γ(44−m) = 4 = B ∀m (1,3,7,21,44 全驗) — **色差對稱消**:
  +m 同 −m 嘅偏移抵消, 錨點係色差平衡點
- 紫邊方向: m>0 (高 k, 短波長類比) γ 升 (Δ = +2sin(mπ/88) > 0) —
  高頻模式能量升 → 聚焦偏移。結構內容 = **模式依賴聚焦**, 唔係電磁色散
  (IDCM 冇波長, 只有模式 index k — 翻譯層鐵律)
