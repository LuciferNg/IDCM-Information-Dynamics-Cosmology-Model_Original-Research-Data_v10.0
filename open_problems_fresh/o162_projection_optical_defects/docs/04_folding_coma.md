## 1. ★ R7: Z₂ 摺疊 — 鏡像不可分辨 (重影嘅資訊內容) — 閉合

**定理**: PSF_obs(j|j0) ≡ PSF_obs(j|89−j0) ∀j0, ∀j (數值 88×88 全驗證)

→ 觀察者無法分辨點源 j0 同其鏡像 89−j0。重影唔只係「睇到兩個像」 —
**資訊內容 = 鏡像自由度 (Z₂ 摺疊)**: 88 site → **44 = N_d 等價類**。

- 等價類數 = 44 = N_d (88/2) — 觀察者讀數空間 = N_d 維
  (O159 呼應: 觀察者 = 世界嘅一半)
- 摺疊不變點 44.5 = F₁₁/2 = 89/2 (O152 半整數家族) — 但**唔係 site**:
  冇任何格點係自身鏡像 → 每點都重影, 最小分離 = 1 (j0=44/45 同一對)

**半鏈摺疊**: 世界 88 site 喺觀察者眼中只有 44 個「等效位置」= N_d。

## 2. ★ R8: 重影不可消除定理 — 閉合

**odd 光圈內冇奇函數模**: u_k(89−j) = +u_k(j) ∀ odd k (鏡像偶函數);
偶函數模嘅任何線性組合仍係偶函數 → **PSF_obs 必然鏡像對稱**。

**破缺器喺世界側**: ∀ even k: u_k(89−j) = −u_k(j) (鏡像奇函數)。
加 k=88 (Nyquist) 嘅效果: PSF(44): 22 → 23, PSF(45): 22 → 21
(破缺量 = 2c·u_88(j0)u_88(j) = ±2c, u_88 = ±1 交替)。

→ **校正重影必須引入 even k (世界資訊) = 觀察者變成世界 (O159 平方根對偶)**。
per-mode 相位 (單模反轉 φ(87)=π) 唔能破缺 — 偶函數模線性組合仍偶。

**代價 (trade-off)**: 破缺器 = Nyquist 模 = 振鈴載體 (u_88 ±1, 能量 2N_d,
R4) — 校正重影引入振鈴。

## 3. R9: 彗差 (離軸像差) — 雙像分離度 — 閉合

**分離度公式**: d(j0) = |j0 − (89−j0)| = |2j0 − 89| = 2|j0 − 44.5|

- 線性離軸 (彗差類比): d(44)=1, d(22)=45, d(2)=85 — 冇二次項 = 冇球差項
- 光軸 = 44.5 = F₁₁/2 (分離零點, 但唔係 site)
- **強度恆定 22 ∀j0 — 冇強度彗差**: 彗差只喺分離度 (位置), 強度完全對稱
  (結構兩分: 強度 = N_d/2 定標, 位置 = 離軸線性)
