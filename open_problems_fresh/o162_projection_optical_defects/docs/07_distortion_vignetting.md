## 1. ★ R10: 畸變 (distortion) — 正倒雙像放大率 — 閉合

觀察者投影有**兩個像** (R1 雙像), 喺放大率讀法:

- **正像**: j0 → j0, M₊ = +1 (恆等映射)
- **倒像**: j0 → 89−j0, M₋ = −1 (鏡像映射)

**★ 畸變量 = 放大率差 ΔM = M₊ − M₋ = 2 = μ² = γ₄₄ = E−O**
(自對偶錨, O159 四重身份 — 同色差錨/質量錨共享單位)

- M 恆定 (±1) ∀j0 → **冇桶形/枕形畸變**: 像位置 = ±j0 (冇 j0² 項)
  → 畸變 = Z₂ 摺疊 (R7) 嘅幾何讀法, 唔係徑向非線性
- 強度恆定 22 (R9 已證冇強度彗差) → 畸變只喺位置 (正倒), 唔喺強度

## 2. ★ R11: 暈影 (vignetting) — Nyquist 遮擋 — 閉合

觀察者光圈 = odd k ≤ 87, 遮 k=88 (Nyquist)。

**★ 暈影比例 = γ₈₈/Σγ = 4/178 = 2/89 = 1/44.5 = 1/(F₁₁/2) EXACT**

- 4/178 = 2/89 = 1/44.5 三重身份全驗 (mp 60 dps 精確)
- 44.5 = F₁₁/2 = 89/2 — **暈影比例由半鏈中心 encode** (O152 半整數家族)
- 觀察者光圈能量比例 = Σγ_odd/Σγ = 88/178 = **44/89 = N_d/F₁₁**;
  遮咗 45/89 (含 Nyquist)

**暈影側別** (docs/04 側別表延伸): k=88 ∈ even (世界側) — 觀察者光圈遮佢;
世界含 Nyquist → 世界冇暈影 (R4: u_88 = ±1 振鈴載體)。
→ **暈影同振鈴互補**: 世界有振鈴 (有 88), 觀察者有暈影 (遮 88)。

## 3. 翻譯層標記

- 暈影 = 高頻遮擋 (光圈截止), 唔係光線幾何 — IDCM 冇光線, 係譜截斷
- 畸變 = Z₂ 摺疊幾何 (M=±1 恆定 = 冇徑向非線性), 唔係透鏡映射
