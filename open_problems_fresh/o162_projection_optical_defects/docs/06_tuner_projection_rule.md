## 1. ★ 攻堅結果: cos 屏投影嘅奇偶選擇性 (定理)

調律者驅動 h_i = A·cos(θ_i), θ_i = (i−½)π/88 (half-site 相位) 對模空間嘅
投影 P_k = Σ_j cos((j−½)π/88)·u_k(j):

```
P_k = 0                                    (k odd  — 觀察者光圈零響應, EXACT)
P_k = ½[csc((k+1)π/176) + csc((k−1)π/176)] (k even — 世界側全譜響應, 閉式)
```

**∀odd k: P_k = 0 係數值 1e-40 以下 (EXACT)** — 88 個 odd k 全驗證。

→ **調律者 cos 屏天然係世界側 (even) 驅動**。觀察者光圈 (odd) 對佢
完全不可見 — 呢個唔係近似, 係**離散正交性嘅必然**:
cos((j−½)π/88) 係偶模嘅線性組合 (同 u_k 嘅 DST 正交關係), 對奇模零投影。

