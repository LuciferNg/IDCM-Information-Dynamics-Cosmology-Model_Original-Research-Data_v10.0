## 1. 成像系統設定

世界 (even 扇區, Σγ_even = 90) → 觀察者 (odd 扇區, Σγ_odd = 88) 投影,
88-site half-site D-D 鏈 (O159) 係「鏡筒」, 模 u_k(j) = sin((j−½)kπ/88)
係光瞳。奇偶扇區 = 觀察者/世界 (O159: 週期 J²=+1 世界 / 反週期 J²=−1 觀察者)。

## 2. ★ R1: 觀察者投影 = 雙像/重影 (ghosting) — 閉合

**奇模式重建 (觀察者讀數)**: PSF_obs(j) = Σ_{k odd} u_k(j0)·u_k(j)

對任何點源 j0, 觀察者睇到**兩個等強度像**:
```
j0=2  → (2, 87=89−2), 強度 22 每個
j0=22 → (22, 67=89−22), 強度 22
j0=44 → (44, 45=89−44), 強度 22
j0=87 → (2, 87=89−87), 強度 22
```

**結構閉式**:
- 像對 = (j0, 89−j0) — site 反射 j → 89−j
- 強度 = 22 = N_d/2 = Σγ_odd/4 = 2L₅ (O145: 22 = 2L₅ = N_d/2 自對偶)
- 質心 = 44.5 = F₁₁/2 = Σγ/4 = 178/4 (O152 半整數家族: 43.5/61.5/6.5/0.5 新成員)

**鏡像閉式 (算子根源)**:
```
u_k(89−j) = sin((89−j−½)kπ/88) = sin(kπ − (j−½)kπ/88)
           = (−1)^{k+1}·sin((j−½)kπ/88) = (−1)^{k+1}·u_k(j)
奇模式 (k odd): u_k(89−j) = +u_k(j)   ← 鏡像偶函數 (觀察者)
偶模式 (k even): u_k(89−j) = −u_k(j)  ← 鏡像奇函數 (世界)
```
→ **觀察者 PSF 自動鏡像對稱 = 重影嘅算子根源**: 奇扇區模係 site 反射嘅
偶函數, 點源無法被觀察者定位 — 只見到對稱雙像。**呢個係結構必然性,
唔係 filter 缺陷** — 觀察者「睇世界」天生有鏡像自由度。

## 3. OTF = 奇扇區截斷

H(k) = 1 (k odd), 0 (k even): 傳遞函數 = 半譜光圈 (88 截斷)。
Σγ_even = 90 (世界), Σγ_odd = 88 (觀察者), E−O = 2 = μ² = γ₄₄
(扇區隙 = 投影損失, O159 重驗)。

## 4. ★ R4: 銳化/振鈴 — 閉合 + 誠實負結果

**銳化增益**: γ₈₈/γ₄₄ = 4/2 = 2 = μ² — 譜頂 (最大梯度剛度, O157 seam slip
定標) / 自對偶錨。銳化係結構後果: 高頻增益載體 = 譜頂 γ₈₈ = B。

**Nyquist 振鈴載體**: u_88(j) = (−1)^{j+1} (交替 ±1), Σ_j u_88² = 88 = 2N_d
(**能量加倍** — 唔係 44)。Nyquist 模 = 完美振鈴模式: 交替 ±1 係最高頻
振盪, 能量 2N_d 係唯一「加倍」模。正交性: Σ_j u_k u_l = 0 (k≠l),
44 (k=l<88), **88 (k=l=88, Nyquist 加倍)**。

**⚠️ 誠實負結果 — Gibbs 8.95% 喺離散鏈冇身份**: 離散 88-site 截斷 (K=44)
overshoot = 0.0743, 唔等於連續 Fourier 嘅 2Si(π)/π − 1 = 0.08949 (差 17%)。
連續 Gibbs 常數唔係離散 88-site 鏈嘅常數 — **照印唔宣稱** (對照常數網:
0.08949 ≈ 1/11.17 冇 L/F/T̂ 身份, 🔴)。

## 5. ★ R5: 移位 — half-site shift — 閉合

- **Ghost 端點喺 j = 0.5 同 88.5** (half-site, 唔係 0/89!): u_k(0.5) = 0,
  u_k(88.5) = 0 — 端點 diag 3 = half-spacing 邊界修正 (O159)。觀察者取樣點
  = 半格 (j−½), 唔係 site 中心 — **移位嘅邊界內容**。
- **Site-link phase 2θ_k = kπ/88** (O161 重驗): 2θ₁ = π/88 (最小半格相位),
  2θ₈₈ = π (Nyquist 實翻轉 = 最大相位滑移)。
- **Wilson line** (O161 重驗): odd 總相位 22π ≡ 0 → Π = 1 (觀察者);
  even 總相位 22.5π ≡ π/2 → Π = i (世界)。世界 holonomy = i = 90° =
  相位落後 π/2。
- **雙像質心 44.5 = F₁₁/2** = 移位嘅「像平面」: 觀察者睇世界 = 雙像對稱
  軸喺半鏈中心 (半整數), 對應 half-site shift 嘅像平面內容。
