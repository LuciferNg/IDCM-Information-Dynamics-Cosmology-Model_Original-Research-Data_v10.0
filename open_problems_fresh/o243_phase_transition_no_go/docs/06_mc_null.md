## 1. 設計

Null 假說: 「存在結構池內嘅控制參數 g, 令 V(w;g) 出現第二局部極小 (fake vacuum), 或令 K_chain 譜出現簡併 (band crossing)」。

兩池:
- **結構池**: 由 88-lattice 結構數生成 (L_k, F_k, N_d, B, γ 和, 有理組合), 41200 對掃描;
- **隨機池**: uniform (μ²∈[0.5,5], λ∈[0.001,1]) 10⁷ 對; 譜縮放 (s∈[0.001,1000], t∈[-10,10]) 10⁷ 對。

5σ 閾值: p < 5.7e-7。

- **P5d**: 兩池命中 = 0 (代數強制) ⟹ 結構池冇相變驅動器

## 3. 誠實說明 (P5d 嘅性質)

呢度嘅 0 命中**唔係** MC 靠運氣跑出 0 — 係**代數強制**:

1. 二次勢 V = -m²w²+λw⁴ (m²>0, λ>0): V' = 2w(2λw²-m²) 只有一個正根 ⟹ **只能有一個極小** — 唔理係咩正參數;
2. γ_n = 4sin²(πn/88) 嚴格遞增: 任何 s>0 縮放 + 平移都保持 gap > 0 — **唔理係咩正縮放**。

所以 MC 唔係「統計排除」, 而係**確認閉式** — 呢個係比 5σ 更強嘅結構強制 (structural forcing)。所有「相變驅動器」(第二極小/簡併) 喺代數上都唔存在喺該族, 兩池皆然。
