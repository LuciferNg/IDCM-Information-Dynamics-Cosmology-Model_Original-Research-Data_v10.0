## 八、正結構結果 + 註冊預言

### 8.1 尺度不變性 = 結構自動（🟢）

論文嘅核心宣稱「accretion–outflow coupling 係 M_BH 無關（10–1e8 M_⊙）」，
喺 IDCM **唔需要額外假設**：所有 IDCM 閾值都係**結構整數嘅無量綱比**，而按維度定理
（O73 §7 + O201 ⑨ scale-blindness），無量綱量嘅結構上唔可能含 M_BH。

```
★ 尺度不變性唔係「巧合」亦唔係「Rees 1982 論證嘅推論」——
   佢係「閾值 = 無量綱譜比」呢個架構嘅自動後果。
   呢個係本 O 嘅正結構貢獻（論文用 20 個 TDE 去「證實一個猜想」；IDCM 直接令佢成為定理式陳述）。
```

### 8.2 註冊預言（🟡 可證偽）

```
★ 低硬態噴流臨界率應該係 C_energy = 1/(N_d+1) = 1/45 = 2.2222% (Z₂ 扇區容量不對稱),
   唔係 2.000% (1/50)。
   機制候選: 噴流 = 扇區不平衡嘅洩漏 (O173 P11「返池」/ O203 c/45 漂移) —— 只有當吸積流嘅
   譜不對稱超過扇區容量不對稱 1/45 時, 相干外流通道先開。
★ 判別: N ≈ 552 (s = 0.5) TDE 樣本可 3σ 分開 2.000% vs 2.273%; N ≈ 812 分開 2.000% vs 2.222%。
★ 證偽條件: 若大樣本收斂到 2.000% ± 2%, C_energy 作為閾值身份即被證偽 (本 O 唔會事後調參)。
★ 二級候選 (唔可分辨): 1/44 = 2.2727% (O7 寫入率) —— 同 1/45 差 2.25%, 需 N ≈ 1.8e4 先分得開。
```
