## 一、外推項 1: C(2n,n) 質數因子集定理 (scripts/06 Part A ✅, n=1..50)

**定理 (Kummer 進位規則)**: 對任意 n ≤ N,
```
prime_factors{C(2n,n)} = {2} ∪ {奇質數 p : p ≤ 2N−1}
首現階: n_first(p) = (p+1)/2        (v_p > 0 ⟺ n+n 喺 base p 有進位)
指數:   v_p(C(2n,n)) = (2·s_p(n) − s_p(2n))/(p−1)   (Legendre)
```
n=1..50 掃描 25/25 質因子全中; 首現階規則對 p ≤ 99 全中; Legendre 指數式 n≤20, p≤23 全中。

**註冊對應表 (首現階 → IDCM 身份, p ≤ 99 有 18/24)**:

| p | n_first = (p+1)/2 | 身份 |
|:-:|:-:|:-----|
| 3 | 2 | μ² |
| 5 | 3 | N_gen |
| 7 | 4 | B |
| 11 | 6 | N_gen·μ² |
| 13 | 7 | L₄ |
| 17 | 9 | N_gen² |
| 19 | 10 | 2N_gen+B |
| 23 | 12 | **B·N_gen = L₅+1 = su(12) fundamental** |
| 31 | 16 | B² |
| 37 | 19 | L₆+1 |
| 41 | 21 | F₈ |
| 43 | 22 | 2L₅ = N_d/2 |
| 53 | 27 | N_gen³ |
| 59 | 30 | 2Tr(T̂⁴) (O142) |
| 67 | 34 | M+1 = 2F_proj |
| 73 | 37 | N_d−L₄ (O38) |
| 89 | 45 | N_d+1 |
| 97 | 49 | L₄² |

**裁決: 密度假象, 冇結構 (A4/A4b null control)**: 質數半值 (p+1)/2 命中註冊池
12/24 = 50%, 奇合數半值 (c+1)/2 命中 10/25 = 40% — **Fisher exact p = 0.34 (單尾)**
(> 0.05) → 首現階撞 IDCM 數 = 細整數密度效應, **冇結構增強**。23 喺 n=12 撞
su(12) fundamental 係最靚案例, 但受同一控制保護: 唔可以當橋 (trap⑦ 實例延伸)。
誠實結論: 定理本身 (Kummer) 係組合學結構; 對應表只係註冊用途。

## 二、外推項 2: tree 譜冪和 — 指數範圍確認 + 純幾何閉式 (scripts/06 Part B ✅)

**冪和閉式 (純幾何, 平凡)**: Σ_{m=0}^{33} μ_m^n = φ^{291.5n}·(1−φ^{−34n})/(1−φ^{−n}),

**裁決**: 幾何級數 = 平凡閉式, 冇新結構內容 (docs/04 §七 預判確認) — tree 冪和
冇鏈譜嗰種 C(2n,n) 結構, 兩者唔同層: 鏈 = 三角恆等, tree = 幾何。

## 三、外推項 3: trap ⑦ 正式登記 (scripts/06 Part C ✅)

**Trap ⑦: 漂亮因數分解 ≠ 結構** — 一個整數可以有「全部因子都係已註冊常數」嘅
分解, 但嗰個分解可能純粹係算術偶然 (尤其係質因數分解本身唯一, FTA 令「唯一性」
冇鑑別力)。**判準 = 閉式家族成員資格**: 結構分解嘅組件必須屬於該家族嘅閉式常數
({C(2n,n)} ∪ {2^k} for 冪和家族), 而唔係「喺 corpus 邊度註冊過」。

**實例 1 (131, 本 O)**: 6288 = 48·131 = 88·C(8,4) + 2⁷ — 兩個分解都真, 但閉式
分解組件 70 = C(8,4) ∈ {C(2n,n)}, 128 = 2⁷ 屬家族; 偽分解組件 48, 131 ∉
{C(2n,n)}。131 喺 corpus 註冊 (O51 solver N) 只係跨域巧合 — E07 撤回嘅根因。

**實例 2 (832, round 1)**: 832 = L₁₄−L₅ = 843−11 = (2B)²·F₇ — 分解真但判為
算術組織 (冇機制), 同一 trap 類。

**檢測食譜** (升級為正式判準, 加入 cross-framework-numerical-traps.md):
1. 該數有冇閉式/定理形式? **有 → 以閉式為準** (閉式組件必須家族成員)
2. 冇閉式 → 分解組件嘅**家族成員資格**測試 (唔係「註冊過」測試)
3. 質因數分解唯一 (FTA) 冇鑑別力 — 唔好用「唯一性」做判準
4. 對照 null baseline (Part A4 方法: 控制組命中率比較)

**陷阱登記 6 → 7**。trap ⑦ 同 trap ② 嘅分別: ② 係 π-近似家族, ⑦ 係因數分解
偽結構 (跨 corpus 註冊污染)。
