## 二、解析證明 (scripts/05 Part C ✅, 引理逐項驗證)

**引理 1 (交錯餘弦和)**: 對偶數 N, Σ_{k=1}^{N} cos(bkπ/N) = N·δ[b≡0 (mod 2N)] − δ[b odd]。
證明: b≡0 → 全 1; b odd → 配對 k↔N−k 相消 + 尾項 −1; b even ∉ {0} → 幾何和 (1−e^{ibπ}) = 0。

**引理 2**: T_a = Σ_{k=1}^{N} (−1)^k cos(akπ/N) = ½[Σcos((N+a)kπ/N) + Σcos((N−a)kπ/N)]
(積化和差, (−1)^k = cos(Nkπ/N)) ⟹ T_a = N·δ[a=±N] − δ[a odd] (|a| < N)。

**證明**: γ_k^n = 2^n(1−cosθ_k)^n = 2^n Σ_j C(n,j)(−1)^j cos^j θ_k, θ_k = kπ/N。
S_j = Σ_k (−1)^k cos^j(kπ/N) = 2^{−j} Σ_m C(j,m) T_{j−2m} = **−δ[j odd]** (j < N):
odd j → 全部 m 嘅 a 都 odd → −2^j/2^j; even j → a even ∉ {0,±N} → 0。
所以 D_n = Σ_k (−1)^k γ_k^n = 2^n Σ_j C(n,j)(−1)^j S_j = 2^n Σ_{j odd} C(n,j)(−1)^{j+1}
= 2^n·2^{n−1} = **2^{2n−1}** (用 Σ_{j odd} C(n,j)(−1)^j = −2^{n−1})。

**總和**: Σγ^n = 4^n·Σsin^{2n} = 4^n·(N·C(2n,n)/4^n + ½) = N·C(2n,n) + 2^{2n−1},
其中正弦冪和閉式由 sin^{2m}θ 嘅 cos 展開 (同一個 T_a 引理) 直接得出。
∎

**結構意義**: 冪和 = 鏈長 N × 中心二項式 C(2n,n) + 2 嘅冪。中心二項式本身有 IDCM
結構 — C(2n,n) 計 {1,2}-步平衡路徑 (O10 K_Tree 路徑族語境), 且因數分解全落喺註冊
質數集 {2,3,5,7,11,13,17,19=L₆+1} (n≤10, scripts/05 Part D ✅):
C(2n,n) = 2, 6, 20, 70, 252, 924, 3432, 12870, 48620, 184756
= μ², N_gen·μ², B·F₅, μ²F₅L₄, 2²N_gen²L₄, 2²N_genL₄L₅, 2³N_gen(F₁₂−1),
2N_gen²F₅(F₁₂−1), 2²F₅L₅F₇F_proj, 2²L₅F₇F_proj(L₆+1) — 全註冊因子。

**預算量子定理升級**: Σγ^n_odd = μ²·(22·C(2n,n)) 對所有 n — 「譜和 = 結構×μ²」
由線性/二次/三次推廣到**全階**, 結構 = 22·C(2n,n) = 2·11·C(2n,n) (世界半鏈 ×
L₅ × 中心二項式)。
