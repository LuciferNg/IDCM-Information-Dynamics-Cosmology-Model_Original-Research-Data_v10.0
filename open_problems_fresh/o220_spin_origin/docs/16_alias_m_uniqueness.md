## 一、問題

scripts/13 導出：位點相位必為 `θ_k = kδ`，`δ ∈ (π/176)ℤ`，記 `δ = mπ/176`，最小正解 `m = 1`。
但「最小」二字係**約定**（選最小正解），唔係**結構強迫**。本輪問：**`m = 1` 能否由結構唯一決定？**

## 三、三重約束

### (i) 雙覆蓋 ⟹ `m = 1`（**定標**，非選擇）

176 步 = 圓環一週 ⟹ 每步幾何角 = `2π/176 = 0.03569992`。
雙覆蓋定義：**spinor 相位 = 幾何角之半** ⟹ `δ = π/176` ⟹ **`m = 1`**。
交叉（B3）：`88` 步 × 幾何角 = `π`；`44` 步 = `π/2`（幾何 90°）；`γ₄₄ = 4sin²(π/4) = 2 = μ²` ⟹ 與 scripts/07/10 之「`N_d` 步 = 90° = 中心模」一致 ✓。

### (ii) `W = i` ⟹ `m ≡ 1 (mod 4)`（**一致性**）

88 步 holonomy = `i^m`（scripts/01：`W = i`，階 4）⟹ `m ≡ 1 (mod 4)`；前 40 個解 = `{1, 5, 9, 13, 17, …}`。
註：176 步 holonomy = `e^{imπ} = (−1)^m` ⟹ `m` 奇 = 空間 360° 伴 spinor `−1`（雙覆蓋簽名）✓。

### (iii) 完備性 ⟹ `m` 奇（**非退化**）

階梯須為 176-環之**完整模式基**：`#distinct site phase = 176 ⟺ gcd(m, 176) = 1 ⟹ m 奇`。
但 `gcd(m,176) = 1` 對 `m = 1, 5, 9, 13, …` 皆成立 ⟹ **完備性單獨不足**。

### 交集

| 約束 | 內容 | 排除 |
|---|---|---|
| (i) 雙覆蓋定標 | `δ = π/176` | 全部 `m ≠ 1` |
| (ii) `W = i` | `m ≡ 1 (mod 4)` | `m = 2, 3, 4, 6, 7, 8` |
| (iii) 完備 | `m` 奇 | 偶 `m` |

三者交集之唯一最小解 = **1** ⟹ **`m = 1` 唯一**（G1）。且 `m` 標籤**鏈之基本步長**（離散），非連續參數 ⟹ 無連續自由度（G2）。

## 四、模式集 ↔ 階梯（含 O219 殘留）

模式集 `M = {even n < e = 6} ∪ {odd n < o = 15} = {1, 2, 3, 4, 5, 7, 9, 11, 13}`，`|M| = 9`（F1）。
- 最大索引 `13 = o − 2`；`13 ≪ 88` = 獨立 γ 值 ⟹ 唔會別名進模式集 ✓。
- 若 `m = 2`（88-鏈）：同一幾何相位對應索引 `2k` ⟹ 模式集相位 = `{2,4,…,26}π/176` ⟹ 索引 `26 > o = 15` ⟹ **超出二十面體截斷** ⟹ `m ≠ 2`（F3）。
- ⚠️ 殘留（O219 🔴）：「階梯索引 `k` = 二十面體調和度 `n`」之**識別**未推導。**本輪等結論唔依賴此識別**（B2/C1/D1 皆無需），但 F3 之「唔別名」論證隱含前提係它。

**故分兩層**：階梯定標 `m = 1` 🟢；模式集與階梯之**逐項對應** 🟡（需 O219 識別）。

## 五、方法論教訓

1. **「最小正解」唔等於「結構唯一」**：本輪把 scripts/13 之約定升級為三重約束交集 ⟹ 同一個數字，論證等級唔同。
2. **三者要獨立**：定標（雙覆蓋）、一致性（`W` 階）、完備性（gcd）係三個唔同來源；只有交集才係唯一。
3. **殘留要標明依賴關係**：O219 之識別係 🔴，但本輪主結論唔依賴它 ⟹ 必須分層陳述，唔可以「一齊算」。
4. **新恆等式要查已知身份**：`distinct γ = 89 = F₁₁` 可與 `Σγ = 178 = 2F₁₁` 互證 ✓（非孤立數值）。
