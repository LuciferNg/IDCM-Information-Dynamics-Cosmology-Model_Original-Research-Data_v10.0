# docs/17 —（戊）multiplicity = dimension：`|M| = (dim Γ₁)²` 之橋

> 輪次：第十五輪（scripts/15，30/30 PASS）
> 前置：O137 定律 `|M| = N_gen²`；第十一輪 `N_d = N_gen·|A2| − 1`；docs/16 之模式集 `|M| = 9`
> 定位：把「世代數 = 空間維數」（第十輪 🔴 函數不同一）由**數值巧合**改寫為**表示論恆等式**，並給出可證偽預言

---

## 一、問題

第十輪結論：`N_gen = 3` 與 `D = 3` **依賴集不相交** ⟹ 函數同一 🔴（解耦測試：`s = 1 ⟹ D = 8` 而 `N_gen` 不變）。
但兩者皆 `= 3`，而 `|M| = 9 = 3²`（O137 定律）。本輪問：**「數量 = 維數」有無精確版本？**

---

## 二、橋之內容

`Γ₁` = 二十面體旋轉群 `I` 之 3 維不可約表示（`dim Γ₁ = 3`）。

| 層次 | 陳述 | 狀態 |
|---|---|---|
| 整數層 | `\|M\| = N_gen²`（O137 定律） | ✅ 已知 |
| 表示論層 | `\|M\| = dim(Γ₁ ⊗ Γ₁) = (dim Γ₁)²` | 🟢 恆等式 |
| 連結 | `N_gen = dim Γ₁` | 🟡 若有第一行則第二行**強迫**它 |

故命題精確化為：**「世代數 = 空間維數」⟺ 「模式空間 ≅ `Γ₁ ⊗ Γ₁`」**（F1）。

### 分解（數值特徵標驗證，F2）

`Γ₁ ⊗ Γ₁ = 1 ⊕ Γ₁ ⊕ Γ₅`（`1 + 3 + 5 = 9` ✓）
- `Γ₁` 特徵標 `(3, −1, 0, φ, 1−φ)`（類 E/C2/C3/C5/C5²，類大小 1/15/20/12/12）
- `Γ₅ = (5, 1, −1, 0, 0)`
- 用 `⟨χ_Γ⊗Γ, χ_Γ'⟩` 投影，`Σ d² = 60 = |I|` ✓

`Γ₁ ⊗ Γ₁` 之 9 維分解 = `1 ⊕ 3 ⊕ 5` 係**精確恆等式** ✓。

## 三、可證偽預言

| 代號 | 內容 | 否證條件 |
|---|---|---|
| P-M1 | 9 模式空間之表示內容 = `1 ⊕ Γ₁ ⊕ Γ₅` | 若為其他 9 維組合 |
| P-M2 | **唔可以**係 `Γ₄ ⊕ Γ₅`（後者冇 3，世代無所依附） | 若實測如此 |
| P-M3 | 故 9 模式空間必含 **1 個 `I`-不變（singlet）方向** | 若無不變方向 |
| P-M4 | 若實測 `3⊕3⊕3` 或 `1⁹` ⟹ 本橋**被否證** | — |

⚠️ **判別力警告（D3）**：`9` 之部分分拆共 7 個 —— `(1,8), (2,7), (3,6), (4,5), (1,2,6), (1,3,5), (2,3,4)` ⟹ **單憑「9 = 1+3+5」冇判別力**；必須用**表示內容**（特徵標），唔可以用整數分拆。同理：
- `(e,o)` 分塊 = `2 + 7 = 9` ⟹ 唔匹配 ✓（D1）
- `mod 3` 分塊 = `[2, 4, 3]` ⟹ 唔係 `(1,3,5)` ✓（D2）

## 四、手性在此處有判別力

`Γ₁ ⊗ Γ₂ = Γ₄ ⊕ Γ₅` 亦 `dim 9`（`E3`）。故：
- 若模式空間 = `Γ₁ ⊗ Γ₁` ⟹ 含 `Γ₁`（3 維）✓
- 若 = `Γ₁ ⊗ Γ₂` ⟹ 唔含 3 維 ⟹ 與 `N_gen = 3` 之橋斷

⟹ **`Γ₁` vs `Γ₂` 之選擇在此處有物理後果** —— 與 docs/14 之定向問題相連（但見 docs/18：該連繫之機制已被否證，故本處之「手性判別力」係**獨立於** docs/14 之新陳述）。
