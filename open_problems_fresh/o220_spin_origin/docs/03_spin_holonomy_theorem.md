## 一、[A] link 變數係譜之導出量（唔可以假設）

`S3`（O161 C1）寫 `U_k = e^{i2θ_k}`。本輪**由譜反推**，唔假設：

```
|1 − U_k|² = γ_k = 4sin²θ_k
⟹ 2 − 2cos(arg U_k) = 4sin²θ_k
⟹ cos(arg U_k) = 1 − 2sin²θ_k = cos(2θ_k)
⟹ arg U_k = ±2θ_k   (mod 2π)      ← 唯一解（單位模）
```

## 二、[B] ★★ 自旋定理

### 2.1 推導

```
W = Π_{k=1..n} U_k = exp(i Σ_{k=1..n} 2θ_k)
θ_k = kπ/(2n)（模式指數 = 半角；176 = 2×88 ⟹ θ_k = kπ/176）
Σ_{k=1..n} 2θ_k = (π/n)·n(n+1)/2 = π(n+1)/2

⟹  W = e^{iπ(n+1)/2} = i^{n+1}
```

**定理（自旋定理）**:

> 對 n 站點鏈，mode-space Wilson line 之階
> `ord(W) = 4 ⟺ n 為偶`；`n 為奇 ⟹ W = ±1，ord ≤ 2`。
> ⟹ **偶鏈必然 spinorial（雙覆蓋），奇鏈冇 spinor 結構。**

### 2.2 驗證

| check | 內容 | 結果 |
|:-----:|:-----|:-----|
| B1 | Σ_{k=1..88} 2θ_k = 44.5π = (F₁₁/2)π = 89π/2 | PASS（44.5π 精確） |
| B2 | ★ W = e^{i·44.5π} = **i** | PASS（虛部偏差 8.2e-60） |
| B3 | 89 = n+1 = 2N_d+1 = F₁₁（奇） | PASS |
| B4 | 偶鏈 n = 2,4,…,16: W = i^{n+1} ∈ {±i}，**階恰 4** | PASS（8/8） |
| B5 | 奇鏈 n = 3,5,…,17: W = i^{n+1} ∈ {±1}，階 ≤ 2 | PASS（8/8） |
| B6 | ★★ 定理成立（全部偶鏈 ord 4 / 全部奇鏈 ord ≤ 2） | PASS |

★ **結構讀法**：`W = i^{n+1}` 之奇偶來自 `n+1` 之奇偶；而 `n = 88 = 2N_d` 為偶
⟹ **自旋之存在 ⟺ 鏈長為偶**。呢條鏈**唔依賴**譜之詳細形狀（只依賴 mode index 與半角成比例），
所以係**組合／拓撲**性質，唔係動力學性質。

### 2.3 定向約定無關（rigidity）

`arg U_k = ±2θ_k` 兩解 ⟹ `W± = i^{±89}` = **i 或 −i** —— 兩者皆 primitive 4th root。
| check B7 | 兩符號約定皆階 4 | PASS |

⟹ 「自旋存在」之結論**唔可以被定向約定（手性 sense）翻轉** —— 兩個約定都係 spinorial。
（**注意**：呢個係「唔被翻轉」，唔等於「有絕對定向」—— 絕對定向由 A₅ 手性提供，見 R5。）
⟹ 用 O213 之語言：**手性決定「邊個 sense」，唔決定「有冇自旋」**。

## 四、[D] 自旋值 s = 1/2 之唯一性（兩條獨立約束）

**約束 ①（排除整數自旋）**：double cover 之核 = Z₂ = ⟨T²⟩（T = 一圈 transport）
⟹ 「旋轉 2π」**就係** T² = W² = −1 ⟹ 對自旋 s：`e^{2πis} = −1` ⟹ `s ≡ 1/2 (mod 1)`。
