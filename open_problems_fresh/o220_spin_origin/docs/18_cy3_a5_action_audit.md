## 一、兩次自我否證（本輪最重要之內容）

### 否證 1：`Γ₁` 係**自共軛**（docs/14 A4 錯）

`A₅` 之 5-元素類係 `{g, g⁻¹}`（squaring 才換類）⟹ `χ(g⁻¹) = χ(g)` ⟹ `Γ₁` 自共軛，Frobenius–Schur 指標 `ν = +1`（實型，可由 `1/60·Σ χ(g²) = +1` 驗證）。
⟹ docs/14 A4「`Γ₁` 非自共軛 / `Γ₁* = Γ₂`」**撤回**。

### 否證 2：反射共軛係**內**自同構 ⟹ 唔交換 `Γ₁/Γ₂`（docs/14 之**機制與結論**）

- 任何 `O(3)` 共軛皆**保旋轉角** ⟹ 保 `{72°, 144°}` 兩類 ⟹ 誘導之自同構**保類**。
- 而 `Out(A₅) = ℤ₂` 之交換作用正是交換兩個 5-fold 類（由特徵標：交換類 `C5 ↔ C5²` ⟹ `χ_Γ₁ = (3,−1,0,φ,1−φ) ↦ (3,−1,0,1−φ,φ) = χ_Γ₂`）✓
- ⟹ 該外自同構**無正交共軛實現**。三個反射之共軛搜尋：改變類別之元素數 = **0/180** ✓

**後果**：docs/14 之「指派 `Γ₁` vs `Γ₂` = 定向/手性」**唔可以由任何幾何共軛（含反射/鏡像）產生** ⟹ 該指派**唔係**手性（U7 `det` 標籤）之表示論實現 ⟹ 標 🔴。
幾何實現若要存在，需**非正交**操作（例如二十面體 ↔ 十二面體對偶），唔係 `O(3)` 共軛。

### 否證 3：「無理特徵標 ⟹ 唔可能作用」過強

`A₅ ⊂ SL(4,ℤ)` **存在**（由 `ℤ⁵` permutation module 之 4 維標準子模：`A₅` 作用於 5 個座標之偶置換，`(1,1,1,1,1)` 張成 1 維不變子空間，正交補 = 4 維整數格子模）⟹ 「有 `A₅` 作用」本身**唔係障礙**。
障礙精確化為**算術域**：`Γ₁` 特徵標含 `φ = (1+√5)/2` ⟹ 需 `ℚ(√5)`；而 polytope 頂點座標全整數 ⟹ 數據 ∈ `ℤ` ⟹ 無 `√5` 痕跡。

## 六、方法論教訓

1. **從特徵標表讀出一個「操作」唔等於該操作幾何存在**：外自同構交換兩個 3 維係真（代數），但**無幾何共軛實現**（保角性擋住）⟹ 必須檢查操作之**存在性**，唔止代數作用。
2. **驗證集要含歪斜輸入**：正交輸入會掩蓋約定 bug（本輪 hypercube 通過而歪斜格唔通過）⟹ 這正是 `idcm-*` 盲測紀律在**方法層**之體現。
3. **檔案若係「家族」就要掃家族**：`all_36_98.poly` 內含 100 個成員；只查 1 個成員（首輪）之結論弱得多。
4. **必要條件 ≠ 充分條件**：結論措辭必須標「證據層面」。
5. **自我否證要計數落檔**：本輪兩次撤回（自共軛、內/外自同構）皆由數值 check 觸發（FS 指標、反射共軛交換計數 = 0）⟹ 唔靠印象。
