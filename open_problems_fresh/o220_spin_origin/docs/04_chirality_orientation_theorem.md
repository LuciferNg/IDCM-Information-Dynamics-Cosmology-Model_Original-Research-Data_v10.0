## 二、[B] δ 判別量（O137 docs/29 §2-3 之獨立重算）

`δ(x) ≡ ∏_{a∈A2} (a·x)`，A2 = 15 條 2-fold 軸（= 15 個鏡面之法向，雙向證明：a 為鏡面法向
⟺ −σ_a = π-旋轉 ∈ I ⟺ a ∈ A2）。

| check | 內容 | 結果 |
|:-----:|:-----|:-----|
| B1 | δ(I·s) = δ(s)（15 次不變量，I-不變） | PASS，dev **2.1e-20** |
| B2 | δ(−s) = (−1)¹⁵δ(s) = **−δ(s)**（奇次 ⟹ 偽標量） | PASS |
| B3 | 60 個一般位置種子：δ ≠ 0 且 −s ∉ I·s | PASS（60/60） |
| B4 | 60 個鏡面種子：δ = 0 且 −s ∈ I·s | PASS（60/60） |
| B5 | ★ **精確二分**: δ ≠ 0 ⟺ 手性（−s ∉ I·s）⟺ 種子唔落鏡面 | PASS |

★ **B2 之意義**：δ 係 **15 次**（奇）不變量 ⟹ 反演下 **變號** ⟹ 佢**就係** χ 之代數化身
（O213 docs/09 H3：χ = sign(x₀·â)·δ_m，反射下 χ → −χ）。
⟹ **手性 = δ ≠ 0；定向 sense = sign(δ)** —— 唔需要額外引 χ。

## 五、[E] ★★ 定理（T9）：sense 絕對化 ⟺ 手性

| check | 內容 | 結果 |
|:-----:|:-----|:-----|
| E1 | ★ 手性集：δ 之符號在全部 \|Sym\| = 60 元素下**不變**（sign 集 = {−1}，唔含 0） | PASS |
| E2 | ★ 非手性集（\|Sym\| = 120）：improper g 令 δ ↦ **−δ**（全部翻轉） | PASS |
| E3 | ★★ **定理**: 旋轉 sense 絕對化 ⟺ 幾何手性（\|Sym\| 冇 improper 元素） | PASS |

**證明骨架**：
```
設 V = 幾何結構, Sym(V) = 其保集正交群。
δ 係 15 次（奇）不變量 ⟹ 對任何 improper g: δ(g·x) = det(g)^15 · δ(x) = −δ(x)。
(⇐) 若 Sym(V) 含 improper g, 則 g·V = V 且 δ 變號
    ⟹ 「+ sense 之 V」同「− sense 之 V」係同一集（由對稱連繫）
    ⟹ sense 之符號無觀測意義（純約定）。
(⇒) 若 Sym(V) 全 proper, 則 ∀g ∈ Sym(V): δ(g·x) = +δ(x)
    ⟹ sign(δ|_V) 係 Sym(V)-不變量
    ⟹ 「邊個 sense」係幾何事實，唔可以被對稱操作翻轉。
```

★ **呢個就係「手性 → 旋轉」之完整結構內容**：唔係「手性令宇宙轉」，而係
**手性令「轉向」有絕對定義**。時間箭頭（定向）與自旋 sense（旋轉符號）係同一個
`δ` 符號之兩個面向。
