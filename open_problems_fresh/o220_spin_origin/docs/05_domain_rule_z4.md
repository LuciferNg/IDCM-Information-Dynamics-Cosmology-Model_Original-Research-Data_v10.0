## 〇、一句話結論

> **「域」= 令模式 holonomy 封閉之最小鏈。**
> 模式 k 經 88 site（世界鏈一圈）累積相位 `h(k) = i^k`：
> `k` 偶 ⟹ `h = ±1`（**實**）⟹ 世界鏈自身可容納 ⟹ **88 域**；
> `k` 奇 ⟹ `h = ±i`（**複**）⟹ 世界鏈唔封閉 ⟹ **只能 176 域**。
> 而 `γ_n^{(88)} = γ_{2n}^{(176)}` ⟹ 88 域 = 176 域之**偶子格**（精確恆等式）。
> ⟹ Z₄ = ⟨i⟩ 之**子群** {+1,−1} = 88 域；**陪集** {+i,−i} = 176 域專屬。

## 三、[C] ★ 域規則定理

**定理（域 hosting 規則）**：
```
① 標量態（2S+1 = 1）: 冇內部標籤 ⟹ 可取實（封閉）模式 ⟹ h 實 ⟹ k 偶 ⟹ 88 域。
② 多重態（2S+1 ≥ 2）: 極化／螺旋度對偶需要兩個唔同模式 ⟹ 至少一個非封閉（k 奇）
   ⟹ 該態整體唔可能住喺 88 域（A4: 奇模式無 88 域代表）⟹ 176 域。
```
| check | 內容 | 結果 |
|:-----:|:-----|:-----|
| C1 | 88 域 = 偶子格 = 實 holonomy 扇區（44 = N_d 模式） | PASS |
| C2 | 176 域 = 實 ⊕ 複（44 + 44 = 88 = 2N_d） | PASS |
| C3 | ★ 互補映射 `σ(k) = N_d+1−k = 45−k` **必反奇偶**（因 45 奇） | PASS |
| C4 | ★ 推論：任何互補對 `(a, 45−a)` **必**跨兩側 ⟹ **必**需 176 域（結構必然） | PASS |

★ **C3/C4 之價值**：即使唔假設「極化對 = 互補對」，C4 提供一條**充分條件**：
只要一對模式之和 = 45 = N_d+1（奇），該對**自動**跨子群／陪集 ⟹ **自動**需要 176 域。
⟹ 呢個係「Spin ≥ ½ ⟹ 176 域」之第二條獨立通道（第一條 = 極化對偶需要 ≥2 模式）。
