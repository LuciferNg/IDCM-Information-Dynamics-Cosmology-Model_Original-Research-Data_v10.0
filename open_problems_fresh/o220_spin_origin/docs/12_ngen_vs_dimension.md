## 一、[A] 三個 3 之依賴集與解耦測試

| 路線 | 表達 | 依賴集 |
|:-----|:-----|:-------|
| **D**（U9） | `D = (2S+1)² − 1 = 4S(S+1) = 3 ⟺ s = ½` | `{S; 自旋／雙覆蓋結構}` |
| **N_gen**（CY₃） | `(h²¹ − B·L₅)/L₆ = (98 − 44)/18 = 3` | `{h¹¹ = 36, h²¹ = 98, B, L₅, L₆, CY₃}` |
| **dimC** | `= 3`（CY₃ 定義） | `{CY₃ 定義}`（**輸入**） |

★ **解耦測試**：`D` 只依賴 `S`；`N_gen`（CY₃ 路線）只依賴 Hodge 資料 ⟹ 兩依賴集**不相交**
⟹ 可獨立變動（例：`s = 1 ⟹ D = 8`，而 `N_gen` 不變）
⟹ **「D = N_gen」唔係函數恆等式** ⟹ 只能係「數值重合」或「共同祖先」。
⟹ **「兩個 3 都係 3」本身唔構成同源證明**（禁 numerical matching）。

## 七、方法論教訓（本輪）

1. **「兩個數相等」要分三層**：(a) 數值重合、(b) 共同祖先、(c) 函數同一。只有 (c) 可稱「同源」，(b) 需附共同祖先之推導鏈，**(a) 唔算任何東西**。
2. **拆循環之標準手法**：把表達式中之「答案」換成**外部群資料**（此例：`e, o` 換成 H₃ 之 Coxeter 度數／反射數）⟹ 循環即消失。
3. **識別 vs 定律**：數值識別（`X = a + b`）必須先過密度檢查；定律（群族全中）唔需要。
4. **θ = π 之軸提取陷阱**：反稱部分 `M − Mᵀ = 0` ⟹ `0/0 = NaN` ⟹ NaN 鍵在 Python set 中**永不相等** ⟹ 造成假無限迴圈。改用 `M + I = 2nnᵀ` 取軸。
5. 掃群（12 個子群）係極有效之判別器：只有目標群給整數／獨特值 ⟹ 排除「係任何群都得」之可能。
