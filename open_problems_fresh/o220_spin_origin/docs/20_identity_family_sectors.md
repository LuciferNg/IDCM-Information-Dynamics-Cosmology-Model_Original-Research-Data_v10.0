# docs/20 —（壬）身份重推：±μ 家族 vs ±μ² 家族

> 輪次：第十八輪（scripts/18，31/31 PASS）
> 緣起：調律者指出「360° = 176、每相 = 44、自旋 720° = 352，家族變成 42/44/46、86/88/90、174/176/178」
> —— 並追問：**哪些身份係 `±μ`，哪些係 `±μ²`？**
> 定位：給出**唯一判別準則**（sector 判據），並把歷來以 44/88/176 出現之身份逐條歸位

---

## 一、兩個單位（先釘死）

| 量 | 定義 | 値 | 出現之處 |
|---|---|---|---|
| `μ²` | `γ_{N_d}^{(176)} = 4sin²(π/4)` | **2**（EXACT） | **譜值**（平方量） |
| `μ` | `√γ_{N_d} = √2` | **1.41421356…** | **振幅**（線性量）、以及**譜值之差** |

★★ 關鍵事實（MC 20000 反測）：**`μ` 從來唔作為單一模之譜值出現**（命中 0/20000）；而 `μ²` 係譜值（`k = 44, 132`）。
⟹ `μ` 只住兩處：**(i) 振幅 sector**（`a_k = √γ_k`，`a_{N_d} = μ`）；**(ii) 譜值之「差」**（見 §二）。

## 二、★★★ `±μ` 家族 = 譜值（平方量）家族

幾何 **45° / 90° / 135°** 三點（八分圓 octant 三元組）：

| [176-L] k | 幾何角 | γ 值 | 精確式 |
|---|---|---|---|
| 22 | 45° | 0.5857864… | `μ² − μ` = `2 − √2` |
| **44** | **90°** | **2** | **`μ²`** |
| 66 | 135° | 3.4142135… | `μ² + μ` = `2 + √2` |

- 代數來源：`sin²(π/8) = (2−√2)/4`、`sin²(3π/8) = (2+√2)/4` ⟹ **`√2` 來自 16 次單位根 `cos(π/8)`**，唔係擬合。
- 和：`γ₂₂ + γ₆₆ = 4 = γ₈₈ = B` EXACT；差：`γ₆₆ − γ₂₂ = 2√2 = 2μ` EXACT；比：`γ₆₆/γ₂₂ = 3 + 2√2 = (1+μ)²` EXACT。
- 步長：`γ₄₄ − γ₂₂ = μ`、`γ₈₈ − γ₄₄ = μ²` ⟹ **兩種步長並存**（同一條鏈上）。
- [88-L] 慣例：同三元組 = `{γ₁₁, γ₂₂, γ₃₃} = {2−√2, 2, 2+√2}`（★ 別名 `γ₁₁^{(88)} = γ₂₂^{(176)}` ✓ 兩慣例給**同一組譜值**，只係索引唔同）。
- ⚠️ **2-adic 門檻**：44-鏈之 45°/135° 落於 `k = 5.5 / 16.5`（**非整數**）⟹ **`±μ` 家族需要 ≥ 88-鏈**（與雙覆蓋／偶扇區結構相連）。

**舊記錄之對應**：O219 之「`γ₃₃/γ₁₁ = 2±√2`，和 = 4」**在此得到結構解釋** —— 它係 88-鏈慣例下之 `±μ` 三元組。

## 三、★★★ `±μ²` 家族 = 計數／鏈長／半鏈和家族

對 `2m`-鏈（`γ_k = 4sin²(kπ/2m)`）：

| 量 | 值 | 精確式 |
|---|---|---|
| `Σ_{k=1}^{m−1} γ_k` | `2m − 2` | `2m − μ²` |
| 鏈長 | `2m` | 中心 |
| `Σ_{k=1}^{m} γ_k` | `2m + 2` | `2m + μ²` |
| 端點模 `γ_m` | `4` | `2μ²` |

⟹ **家族 = `2m ± μ²`**；偏移來源 = **端點模之半** `γ_m/2 = μ²` ✓。

| 鏈 | 家族 | 成員身份 |
|---|---|---|
| 44-鏈（m = 22） | **42, 44, 46** | `S(22)`, `N_d`, `S'(22)`（`42 = 2F₈`） |
| 88-鏈（m = 44） | **86, 88, 90** | `S(44)`, `2N_d`, `S'(44)`（`90` = O211「`Σγ = B(N_d+1)/2`」之真身） |
| 176-鏈（m = 88） | **174, 176, 178** | `S(88)`, `4N_d`, `S'(88) = 2F₁₁`（docs/16 之 `Σγ`） |

**遞歸**：`S'(2m) = 2S'(m) − 2`、`S(2m) = 2S(m) + 2`（乘 2 = **一個 μ² 步**）⟹ 家族在 `x ↦ 2x ∓ 2` 下閉合。

## 四、★★★ 判別準則（本輪核心產出）

> **身份屬「計數／鏈長／索引和／γ 和」⟹ 家族間隔 = `μ²` = 2（整數偏移）。**
> **身份屬「γ 譜值／平方量／振幅平方」⟹ 家族間隔 = `μ` = `√2`（八分圓位移）。**

| sector | 中心身份 | `−` 成員 | `+` 成員 | 間隔 |
|---|---|---|---|---|
| 計數／長度 | `44`（步） | `42` = `S(22)` | `46` = `S'(22)` | `μ²` = 2 |
| 計數／長度 | `88` | `86` | `90` | `μ²` = 2 |
| 計數／長度 | `176` | `174` | `178` | `μ²` = 2 |
| **譜值** | `γ₄₄ = μ²` = 2 | `γ₂₂ = μ²−μ` = 0.5858 | `γ₆₆ = μ²+μ` = 3.4142 | **`μ` = √2** |

★ **同一個幾何 90° 有兩個唔同家族**：
- 作**步數**（44）⟹ 家族 `{42, 44, 46}`（±μ²）
- 作**譜值**（`γ₄₄ = μ²`）⟹ 家族 `{γ₂₂, γ₄₄, γ₆₆}`（±μ）

⟹ **凡陳述 44/88/176 家族，必須標 sector**，否則歧義。

## 六、調律者所提三條身份之歸位

| 身份 | 種類 | 家族 | 判定 |
|---|---|---|---|
| `360° = 176` | **計數**（鏈長 `2m`，`m = 88`） | `{174, 176, 178}` | **±μ²** |
| `每相 = 44`（= `N_d` 步 = 幾何 90°） | **計數** | `{42, 44, 46}` | **±μ²** |
| `自旋 720° = 352`（= `2 × 176 = 8N_d`） | **計數** | `{350, 352, 354}` | **±μ²** |

而**同一批幾何**之譜身份：`γ₄₄ = μ²`（90°）、`γ₈₈ = 2μ²`（180°）、`γ₂₂/γ₆₆ = μ² ∓ μ`（45°/135°）⟹ 家族 **±μ**。

**故答案**：調律者所列之 `42/44/46`、`86/88/90`、`174/176/178` **全部係 `±μ²` 家族**；
`±μ` 家族係**譜值**家族（`μ² ∓ μ`），出現於八分圓三元組，而它需要 ≥ 88-鏈（2-adic 門檻）。

## 七、方法論教訓

1. ★ **同一數字可以有兩個身份**（44 = 步數 = `N_d`；亦可對應譜量 `γ₄₄ = μ²`）—— 報數必標 sector，否則「家族」之單位無法定。
2. ★★ **「±μ」唔可以係譜值**（MC 0/20000）⟹ `μ` 之歸宿係振幅或**差**；此一事實本身係判別準則之根據。
3. ★ **精確式要追到單位根**：`2 ± √2` 之來源 = `sin²(π/8)`，即 16 次單位根 ⟹ 唔可以只寫「出現 √2」。
4. ★ **門檻要報**：`±μ` 家族在 44-鏈**不存在**（`k = 5.5`）⟹ 結構限制本身係資訊（連繫雙覆蓋）。
5. ★ **舊結論以新框架重新解釋唔等於推翻**：O219 之 `2±√2` 原本係孤立識別，現升級為八分圓 `±μ` 三元組（升級，非修補）。
