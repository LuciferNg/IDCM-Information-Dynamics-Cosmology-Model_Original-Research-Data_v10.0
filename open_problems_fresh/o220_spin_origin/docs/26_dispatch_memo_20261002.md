## H1 — 糾纏之機制判準（相干權重）→ **O227**（連接通道：對映表、無信號與糾纏熵）

**分流問題**：糾纏 = 非因子化關聯，到底「什麼和什麼」相關聯、機制係什麼；糾纏是否「共享 bit」。

**本案量化內容（已實算，QM 側）**
- 判準式：`max|S| = 2√2·p`，`p` = **相干項（off-diagonal coherence）權重**
- Horodecki 形式：`max|S| = 2√(t₁²+t₂²)`，`T_ij = tr(ρ σ_i⊗σ_j)`
- 實測校準：
  - singlet `|ψ⁻⟩`：`T` 奇異值 `[1,1,1]` ⟹ `max|S| = 2.828427 = 2√2`
  - 去相干混合 `½(|↑↓⟩⟨↑↓|+|↓↑⟩⟨↑↓|)`：`T` 奇異值 `[1,0,0]` ⟹ `max|S| = 2.000000`
  - Werner `p=0.75` → `2.121320`；`p = 1/√2` → **恰 2.000000**
- ⟹ **臨界相干分數 `p* = 1/√2 = 0.70711`**
- 關聯函數形式被對稱性強制：singlet 係 `J=0`（旋轉不變）＋ 雙線性 ⟹ 唯一 `E(a,b) = −a·b`（實測 50 對隨機方向 max dev < 1e−14）
- **三類產生相關之機制（窮盡）**：①shared randomness（`E = Σ_λ p(λ)A B`，機率平均 ⟹ ≤ 2）②shared amplitude（`|ψ⟩ = Σ c_i|i⟩_A|i⟩_B`，相干疊加 ⟹ ≤ 2√2）③PR-box（態唔存在，可到 4）
- **IDCM 側診斷**：`C(a,b) = (1/120)Σ_s K[s][a]K[s][b]` = **λ-中介**（可分解）⟹ 上限 2；`A_a = diag(K[:,a])` 同基對角 ⟹ **0/1891 非交換對** ⟹ 無張量因式

**狀態**：🔴 機制判準本身**未於 IDCM 內導出**（門 (C) 相位讀出、門 (T) 第二核皆缺席）

## H4 — 手性之本體結構 → **O213**（動力學層；手性絕對定向）＋指向 **O137 gap 5**

**分流問題**：手性只係一個標籤？底層是什麼。（本體論追問，唔係 O220 之自旋起源主題）

**本案量化內容（已實算）**
- 本體：`δ(x) = ∏_{a∈A2}(a·x)`，`A2` = 15 條 2-fold 軸，`deg δ = 15`（**奇** ⟹ 偽標量；`|A2|` 若為偶則根本無手性標籤）
- `δ(g·x) = δ(x)` ∀`g ∈ I`（60 個 proper 元素，worst rel dev **1.7e−13**）；`δ(−x) = −δ(x)`
- **零集 = 15 條鏡面 = achiral 牆**（測度零）；精確二分：`δ ≠ 0 ⟺ −s ∉ I·s`
- **底層機制 = 軌道分裂**：`I_h`-軌道（120）= `I`-軌道（60）⊔ `mirror(I`-軌道`)`（60），**交集 = 0**；`δ(s) = +1.1544292171e−06`、`δ(mirror(s)) = −1.1544292171e−06` ⟹ **兩側 `|δ|` 相同 ⟹ 標籤 = 恰好 1 bit，且係無損壓縮**
- 牆確實分隔：`s → mirror(s)` 直線**穿 `δ = 0` 至少一次**（實測 11 次）⟹ 兩對掌分量**不可連續形變**
- 四型 I-軌道：12／20／30 皆含 `−v`（非手性）且 `δ = 0`；**唯一手性 = 60-軌道**
- 幾何 chirality ↔ SM chirality **代數橋 = O137 gap 5**（仍未建）

**狀態**：🟡 本體結構已實算（本檔 H4 為唯一記錄處）；🔴 代數橋未建
