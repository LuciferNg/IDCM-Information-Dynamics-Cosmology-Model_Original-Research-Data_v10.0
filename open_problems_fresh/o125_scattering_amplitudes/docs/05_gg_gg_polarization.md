## 1. 極化 (helicity) 組態分類 (§A)

4 條外線膠子, 每條 2 個物理極化 (λ = ±1) ⟹ **2⁴ = 16** 個組態。

| 類型 | 數目 | 樹層振幅 |
|:-----|:----:|:--------|
| all-plus `++++` | 1 | **0** (SWI: 全同號 helicity 消失) |
| all-minus `−−−−` | 1 | **0** (parity 共軛) |
| one-minus / one-plus `3+1` | 8 | **0** (SWI) |
| **two-plus-two-minus `2+2`** | **6** | **非零 (MHV)** |

★ **只有 6 個組態存活** = `C(4,2)` = **`2·N_gen`**。

驗證: A1 (16 總數), A2 (10 消失), A3 (6 存活), A4 (2⁴)。

## 2. Spinor-helicity + 運動學恆等式 (§B)

外線動量 (massless, `p_i²=0`):

```
p₁ = (1, 0.6, 0, 0.8)      p₂ = (1, −0.6, 0, −0.8)
p₃ = (1, sθ, 0, cθ)        p₄ = (1, −sθ, 0, −cθ)      cosθ = 0.3
```

## 3. Color-ordered MHV 振幅 (§C)

**Parke–Taylor**: 對排序 σ, 負 helicity 腿 (i,j):

```
A(σ) = ⟨ij⟩⁴ / ( ⟨σ₁σ₂⟩⟨σ₂σ₃⟩⟨σ₃σ₄⟩⟨σ₄σ₁⟩ )
```

6 個排序 = S₃ (固定腿 1): `(1234),(1243),(1324),(1342),(1423),(1432)`。

| 檢查 | 內容 | 結果 |
|:--|:-----|:-----|
| C1 | 反射 `A(1,2,3,4) = A(4,3,2,1)` (n=4 偶 ⟹ `(−1)ⁿ=+1`) | PASS |
| C2 | **U(1) 解耦** `Σ_{σ∈S₃} A(σ) = 0` (Dixon eq.8) | PASS (max\|Σ\| = 7.8×10⁻¹⁵) |
| C3 | `Σ_σ Σ_λ \|A(σ)\|² = 2(s²+t²+u²)³/(s²t²u²)` | PASS |
| C4 | `B(s,t,u) = (s²+t²+u²)³/(8 s²t²u²)` | PASS |
| C5 | `Σ_σ Σ_λ \|A(σ)\|² = 16 B(s,t,u)` | PASS |

★ **運動學括號閉式**:

```
B(s,t,u) = 3 − ut/s² − us/t² − st/u² = (s²+t²+u²)³ / (8 s²t²u²)
```

(數值: `B = 105.982649`; `Σ_σΣ_λ|A|² = 16B = 1695.722382`。)

Per-config (single ordering `A(1234)`, `|A|²`) — parity 配對 `(++−−)=(−−++)`、`(+−+−)=(−+−+)`、`(+−−+)=(−++−)`:

| `+−+−` / `−+−+` | 0.000094 |

## 4. 色求和 (§D) — Dixon eq.(10)

Trace basis, 標準歸一化 `Tr(T^a T^b) = δ^{ab}`:

```
M^{a₁a₂a₃a₄} = g² Σ_{σ∈S₃} Tr(T^{a₁}T^{a_{σ₂}}T^{a_{σ₃}}T^{a_{σ₄}}) A(1,σ₂,σ₃,σ₄)
```

Dixon eq.(10):

```
Σ_{colours} |M|² = g⁴ · N_c²(N_c²−1) · Σ_{σ∈S₃} |A(σ)|²
```

| 檢查 | 內容 | 結果 |
|:--|:-----|:-----|
| D1 | `Σ_{σ,τ} C_{στ} A_σ A_τ* = N_c²(N_c²−1) Σ_σ\|A_σ\|²` | PASS (122092.0115 vs 122092.0115) |
| D2 | 色因子 `= N_c²(N_c²−1)` 對 N=2,3,4 | PASS (12, 72, 240) |

SU(3) C-矩陣對角 = 50.666667 (標準歸一化)。

> ⚠️ **歸一化陷阱 (本節自捉)**: 初版用 `Tr(T^aT^b)=δ^{ab}/2` (即 `T^a=λ^a/2`), 得色因子 **16× 偏小** (72 vs 1152)。
> 標準 color-ordered 慣例係 `Tr=δ` (Dixon §1); 4 個生成元 ⟹ 因子 `(√2)⁴ = 16`。**跨文獻引用數字必須先核歸一化** (USER 鐵律)。

## 5. ★完整極化求和 — 最終結果 (§E)

```
Σ_{colours,spins} |M(gg→gg)|²
   = g⁴ · N_c²(N_c²−1) · Σ_σ Σ_λ |A(σ)|²
   = g⁴ · N_c²(N_c²−1) · 2(s²+t²+u²)³/(s²t²u²)
   = g⁴ · 1152 · B(s,t,u)                                  [N_c = 3]
```

初態平均 (colour `(N_c²−1)²=64`, spin `2²=4`; 共 256):

```
⟨|M(gg→gg)|²⟩ = Σ/256 = (9/2) g⁴ B(s,t,u)        ✓ 標準文獻值
```

| 檢查 | 內容 | 結果 |

## 6. IDCM 離散替換 + 結構解讀 (§F)

膠子 = 88-ring 上嘅 link phase (O124 §B); 零模 `n=0` 無質量 ⟹ massless 膠子。
離散 Mandelstam (O124 §F.2 慣例, `ω_n = 2sin(nπ/88)`):

```
s = (ω_a+ω_b)² ,  t = (ω_a−ω_c)² ,  u = (ω_a−ω_d)² ,  chain-momentum:  n₁+n₂ ≡ n₃+n₄ (mod 88)
```

| 模式 (n₁,n₂)→(n₃,n₄) | chain-mom | s | t | u | B_disc |
|:--------------------|:---------:|:--|:--|:--|:-------|
| (1,3)→(2,2) | OK | 0.08132 | 0.00508 | 0.00508 | −29.00393 |
| (5,7)→(3,9) | OK | 0.72202 | 0.01997 | 0.07645 | −137.87500 |
| (3,5)→(1,7) | OK | 0.32364 | 0.02028 | 0.07886 | −60.13226 |
| (2,5)→(3,4) | OK | 0.24779 | 0.00506 | 0.02015 | −195.33884 |

> ⚠️ **誠實標記**: `B_disc` 繼承連續括號嘅 **collinear (t,u→0) 同 t-channel pole**; 88-ring 模譜有界 (`ω_n ≤ 2`), 所以可及模全部近 collinear ⟹ `B_disc` 大而負。此為**結構轉譯**, 只在 soft/massless 極限 `n≪88` 精確 (同 O124 §F 一致)。

**結構清單** (全部由 `N_c = N_gen = 3` 生成):

```
16    = 2⁴                          (4 膠子 × 2 極化)
6     = C(4,2) = 2·N_gen            (存活 MHV 組態)
72    = N_c²(N_c²−1) = C_A²(N_c²−1) = 8·9 = F₆·N_c²
3     in B(s,t,u) = N_c = C_A
1152  = 72 · 16
```

**極化 = Z₂**: 膠子 helicity `λ = ±1` 對應 Z₂ 分級 (同 IDCM 費米/玻色 Z₂ 同構); 完整極化求和 = 對 `Z₂⁴` 16 個組態求和, MHV 結構揀出 `6 = 2N_gen` 個。
