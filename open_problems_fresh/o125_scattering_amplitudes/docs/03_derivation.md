## 2. ★圖分類定理 (R1): 模式對角 ⟹ 只有 s-channel

**命題**: 對過程 `φ_n φ_n → φ_m φ_m`, 4 條外線只有 **s-channel** 一種樹圖拓撲; t/u-channel 同 box 圖全部唔存在。

**證明** (script R1, 窮舉):
- 唯一帶 φ 嘅頂點係 `A_k = h φ_k φ_k` — 兩條 φ 腿**必須同模式** k。
- 4 條外線 `(n, n, m, m)` 分成 2 個 A 頂點, 共 3 種配對 (s/t/u):

| 配對 | 腿分組 | 模式一致? |
|:----:|:------:|:---------:|
| **s** | (φ_nφ_n)(φ_mφ_m) | ✅ |
| t | (φ_n φ_m)(φ_n φ_m) | ❌ n≠m |
| u | (φ_n φ_m)(φ_n φ_m) | ❌ n≠m |

- t/u 需要頂點 `h φ_n φ_m` (n≠m) — 模式對角**禁止**。
- **box**: φ 腿守恆 ⟹ `#A 頂點 = 4/2 = 2` 固定; 2 條 h 腿 ⟹ 恰 1 條 h 傳播子 ⟹ tree s-channel。冇第二種拓撲。

**★ 結構後果**: 連續 QFT 有 s+t+u 三通道 + box; v10.0 只有 s-channel。呢個係**精確結構結果**, 唔係近似。

## 3. h 自能泡 Π_h(s) (R2-R4)

### 3.1 泡函數閉式 (R2)

`s-channel` 唯一 1-loop 修正 = 內部 h 線嘅自能泡 `h → φ_kφ_k → h`:

```
B_k(s) = (1/4π) ∫₀¹ dx / [m_k² − x(1−x)s] = (2θ_k / sin 2θ_k) / (4π m_k²)
         θ_k = arcsin(√s / (2m_k))
```

**驗證** (R2): 閉式 vs mpmath 50 dps Feynman 參數化數值積分, **max dev = 1.3×10⁻¹⁶**。

### 3.2 ★結構恆等式 (R3)

```
Σ_(k=1..44) ω_k² = 90   EXACT
```

**證明**: `Σ_(k=1..87) sin²(πk/88) = 44` (標準 `Σ_(k=1..N−1) sin²(πk/N) = N/2`); 對稱 `k ↔ 88−k` 加 `k=44` 項 (`sin²(π/2) = 1`) ⟹ `Σ_(k=1..44) sin² = (44+1)/2 = 22.5` ⟹ `Σω_k² = 4×22.5 = 90`。

> ★ **同 O211 C7 一致**: `Σγ = B(N_d+1)/2 = 4×45/2 = 90` — 同一個「世界自洽數」。呢個係 O125 同 O211 嘅**獨立交叉點**。

### 3.3 ★零動量泡 (R4): 每模式等貢獻

```
Π_h(s) = Σ_k g_k² B_k(s)
       = Σ_k (κ²ω_k²)·(2θ_k/sin2θ_k)/(4π m_k²)
       = (1/(4πM₀)) · Σ_k (2θ_k/sin2θ_k)        ← 因為 κ²ω_k²/m_k² = M₀ω_k²/(M₀²ω_k²) = 1/M₀
```

**★ 關鍵**: 前因子 `g_k²/(4πm_k²) = 1/(4πM₀)` **模式無關** — `g_k² ∝ ω_k²` 精確抵消 `B_k ∝ 1/m_k²`。模式依賴只留喺 `θ_k` 內。

```
Π_h(0) = N_d/(4πM₀) = 44/(4π·27.900915) = 0.125494405757721…
```

**驗證** (R4): 44 個模式貢獻全等 (`max−min < 10⁻¹⁵`); 閉式 vs 直接和 dev < 10⁻¹²。

## 7. ★零重整化定理 (R10)

**命題**: v10.0 有限離散 QFT 中, 質量/耦合/波函數反項**全部為零** — 物理參數 = 結構參數。

**證明**:
1. **δZ = 0** (精確): `Σ_n = −κ²ω_n` **動量無關** (O82 leading order) ⟹ `δZ = ∂Σ/∂p² = 0`。冇波函數重整化。
2. **δm = 0** (O94): 1-loop finite part = 0, `δm_n = 0` (88-site 天然 cutoff)。
3. **δλ = 0 / δκ = 0**: 圈和有限 (`Σ_k 1/m_k² = 0.4146`, `ω_1 = 0.0714 > 0`) ⟹ **冇 1/ε 極點**需吸收 ⟹ 冇 coupling/vertex counterterm。

**對照 v9.0**: v9.0 用 dim-reg 引入 3 個 counterterms (`δ_Z, δ_μ, δ_λ`) 去吸收 UV 極點; v10.0 冇極點 ⟹ **重整化程序整體 vacuous** (docs/02 §二 #6)。
