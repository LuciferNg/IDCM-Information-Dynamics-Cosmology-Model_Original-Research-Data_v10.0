## 4. ★ 結構強迫: λ² = 1 (§E)

```
設 ĥ|λ⟩ = λ|λ⟩。  ĥ² = 1  ⟹  λ² = 1  ⟹  λ ∈ {+1, −1}
```

**呢個係本檔嘅核心**: helicity 嘅**值域 {+1, −1}** 唔係輸入、唔係擬合 —
係 ĥ 係**對合**嘅直接後果。對照:

| ĥ 嘅群 | 譜方程 | helicity 數目 |
|:-------|:-------|:-------------:|
| **Z₂ (本檔)** | `λ² = 1` | **2** ✓ (無質量 spin-1) |
| Z₃ | `λ³ = 1` | 3 ✗ |
| Z₄ | `λ⁴ = 1` | 4 ✗ |

⟹ **「恰好兩個 helicity」⟺「ĥ 係 Z₂」**。維度: 88 = 44 ⊕ 44 (λ = +1 扇區 ⊕ λ = −1 扇區)。
