## 1. 連續 pole 結構 (§A)

```
B(s,t,u) = 3 − ut/s² − us/t² − st/u² = (s²+t²+u²)³/(8 s² t² u²)      (s+t+u = 0)
```

| chk | 內容 | 結果 |
|:----|:-----|:-----|
| A1 | 兩形式相等 (s+t+u=0) | PASS |
| A2 | `t ↓ ⟹ \|B\| ↑` (單調) | PASS |
| A3 ★ | 連續: `t → 0 ⟹ B → ∞` (**無界**) | PASS |

數值: `t = 10⁻¹,10⁻²,10⁻³,10⁻⁴` → `|B| = 1.6×10³, 1.6×10⁵, 1.6×10⁷, 1.6×10⁹`。

> `1/t²` 同 `1/u²` 項 = **collinear pole** (無質量膠子交換)。

## 2. 離散運動學: 最小動量轉移 (§B)

88-ring 動量**量子化**: `ω_n = 2sin(πn/88)`, `n = 0..87`。
動量轉移 `t = (ω_a − ω_c)²` 嘅**最小非零值** = 相鄰能階間距平方。

| chk | 內容 | 結果 |
|:----|:-----|:-----|
| B1 | 最小間距喺能帶頂 `n=44` 兩側 (`dw[43] = dw[44]`) | PASS |
| B2 ★ | **`Δω_min = 4sin²(π/176)`** = 1.274348686×10⁻³ | PASS |
| B3 | `t_min = Δω_min²` = 1.623965×10⁻⁶ | PASS |
| B4 | `176 = 2 × 88` | PASS |

```
Δω_min = ω_44 − ω_45 = 2 − 2cos(π/88) = 4 sin²(π/176)   EXACT
       ≈ (π/88)² = 1.2745×10⁻³   (dev −0.011%)
```

> ★ 最小間距出現喺**能帶頂** (`ω_44 = 2`, 色散最平) —— 同 `4sin²` 結構一致。

## 3. ★ 有限譜自動正則化 (§C)

掃描**全部允許運動學** (`n₁+n₂ ≡ n₃+n₄ mod 88`, `n ∈ 1..44`; 56804 個點):

| chk | 內容 | 結果 |
|:----|:-----|:-----|
| C1 | 允許運動學數 > 0 | PASS |
| C2 ★ | `min \|t\| = Δω_min²` — **冇任何運動學低於佢** | PASS |
| C3 ★ | `t = 0 ⟺ 退化模式` (`a = c` 或 `a = 88−c`) — **得 measure-zero** | PASS |
| C4 | 離散有正下界; 連續冇 | PASS |
| C5 ★ | **`B_disc^{reg}` 有界** (`max` 有限) | PASS |
| C6 | 正則化子 = **能階間距** (唔係 counterterm) | PASS |

```
max |B_disc^{reg}| = 6.4589×10¹²          (對照: 連續 → ∞)
argmax (a,b,c,d) = (43,2,1,44):  s = 4.5856, t = 3.7146, u = t_min
  三項:  ut/s² = 2.87×10⁻⁷   us/t² = 5.40×10⁻⁷   st/u² = 6.46×10¹²
  ⟹ 主導 = 1/u² pole, 但 u ≥ t_min ⟹ 有限 (唔係 ∞)
```

**★ 核心**: 連續理論嘅 `1/t²` 發散需要**動量可以任意接近共線** (連續動量譜)。
88-ring 動量量子化 ⟹ `|t| ≥ Δω_min² > 0` ⟹ **冇 collinear 極限** ⟹ **冇發散**。
正則化子**唔係** counterterm, 係**能階間距本身** (有限尺寸效應)。

## 5. 正確離散振幅 = V₄ 張量 (有限) (§E)


|:----|:-----|:-----|
| E1 | V₄ 支撐 = mod-88 守恆集 (O124 E5) | PASS |

**有限譜 (88 模) ⟹ 全部和有限 ⟹ 冇 UV/IR 極點 ⟹ 冇 counterterm**
