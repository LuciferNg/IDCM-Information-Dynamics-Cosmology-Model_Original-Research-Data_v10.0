# Magic Rows 生成規則 — 端點 deg 條件閉合 (2026-08-25)

> **問題:** magic rows (d=7,14,20,22,33) 嘅生成規則係咩?
> **答案:** ✅ 低次數成員 = 兩端點都喺「低次數端點集」; magic rows 4/5 係低次數端點
> **狀態:** ✅ 閉合

---

## 1. ★ 終極規則: 端點 deg 條件 (276/276 雙向驗證)

```
deg(beat(i,j)) = lcm(deg ω_i, deg ω_j)   [lcm 定理]

→ deg < 40  ⇔  i, j ∈ 低次數端點集 (24 個)
→ deg<40 拍頻數 = C(24,2) = 276 ✅ 完全閉合!
```

## 2. 低次數端點集 (24 個)

| deg | 端點 | 數量 |

**高次數端點 (20 個): 全奇數非 11/33** — {1,3,5,7,9,13,...,43}

## 3. ★ 奇偶對稱破缺

```
偶數端點 22 個 → 全部低次數 (deg ≤ 20)
奇數端點 22 個 → 20 個高次數 + 2 個低次數 (11, 33)
```

## 4. 4-adic 規則 = 終極規則嘅 corollary

```
d≡s (mod 4) 先有 deg<40 (24 個例外全係含 11/33)
→ 因為 11/33 係奇數低次數端點, 打破 mod 4 守恆
→ 4-adic 係近似, 端點 deg 條件先係真相
```

## 5. Magic rows 身份

