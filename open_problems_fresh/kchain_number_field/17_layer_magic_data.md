# 操作/數據分層 — Magic vs Data vs Filler (2026-08-25)

> **問題:** magic rows (操作) 同物理參數行 (數據) 有咩關係?
> **答案:** ✅ 兩層分離; d=14 係唯一「操作=數據」結合點
> **狀態:** ✅ 閉合 (分層結構)

---

## 1. 三層分類

| 層 | d 值 | 數量 | 角色 |
|:---|:---|:---:|:---|
| magic (操作) | 7, 14, 20, 22, 33 | 5 | 宏指令行 |
| data (物理) | 11, 13, 17, 19, 21, 25 | 6 | 物理參數行 |
| filler (填充) | 其餘 32 | 32 | 無 label |

## 2. ★ Magic rows = gcd 類別代表

```
gcd(|44−d|, 176):  1    2    8    11   22
                 ↓    ↓    ↓    ↓    ↓
magic:            7   14   20   33   22
                 ANCHOR GEN TRANSFER KTREE HALF

有 magic 嘅 gcd 類別: {1,2,8,11,22}  ← 5 個!
冇 magic 嘅 gcd 類別: {4,16}  ← v₂ 偶數階

176 = 2⁴×11
→ magic 覆蓋 2⁰,2¹,2³,11,2·11 — 缺 2²,2⁴
```

## 3. Data rows 物理身份 (9 格)

```
d=11: (30,41) m_W/m_Z    d=13: (7,20) n/p BBN
d=14: (8,22) c/s + (10,24) u/d + (19,33) t/b   ← 3 quark!
d=17: (1,18) m_μ/m_τ    d=19: (19,38) m_H/m_W
d=21: (1,22) m_s/m_d    d=25: (8,33) m_c/m_b
```

## 4. ★ d=14 雙重身份 — 操作 = 數據結合點

```
d=14 行 label: 'Row GEN d=14' (世代生成操作)
d=14 格 label: c/s, u/d, t/b (三代 quark 質量比!)

→ GEN 操作直接產出三代 quark 質量比!
→ d=14 = Δn = B²−2 = 世代規則
→ 呢個係「操作 = 數據」嘅唯一結合點
```

## 5. 物理參數嘅 deg 分佈

```
deg=40 (高次數): 6 個 (m_μ/τ, m_s/d, n/p, t/b, m_H/W, m_W/Z)
deg=20: 2 個 (u/d, m_c/b)
deg=10: 1 個 (c/s)
→ 6/9 坐高次數行 (gcd=1)
→ 物理參數唔跟 4-adic 規則 (s mod4 無規律)
```
