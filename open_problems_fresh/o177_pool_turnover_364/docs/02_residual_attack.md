## 1. 問題

唔宣稱更精」。**推殘餘** = 定量判定: 殘餘係純輸入雜訊, 定有結構身份?

## 2. 方法鏈 (17/17 PASS)

### Part A — 誤差傳播 (每輸入獨立 1σ)

```
池/圈 = N·M·T_ring/(t·η·E_strain)
σ(M 3-sf)   = 1.05   (0.29%)
σ(t 2-sf)   = 10.51  (2.89%)  ← 主導
σ(T_ring)   = 0.021  (6-sf)
σ(E_strain) = ~0     (閉合式)
σ(池/圈)合併 = 10.56  (±2.90%)
```

### Part B — 殘餘統計

```
δ = +0.0533 = 0.005σ   (1σ = 10.56)
```

**364 與觀測嘅差距 = 千分之五個 σ** — 統計上完全不可分辨。
殘餘方向 (+0.015%) 亦冇系統性證據: 遠細過 σ_rel = 2.9%。

### Part C — 殘餘來源分解 (若 364 精確, 邊個輸入要變幾多)

| 輸入 | 需變 | 結論 |
|:-----|:----:|:-----|
| M_med | −0.0146% (→ 6.96898e6) | 3-sf 表示內, 即係 6.97e6 捨入向上嘅自然後果 |
| t_active | +0.015% (→ 11.0016e9) | 遠細過 2-sf 半寬 5% |
| E_strain | +0.015% | 同閉合式 dev 0.0045% 差 3-4×, 唔需要改結構 |
| T_ring | −0.015% | 同上 |

→ **最小移動 = M 嘅 3-sf 捨入**。殘餘冇強逼任何結構改動。

### Part D — 結構候選掃描 (δ = 0.0533 = ?, 全已註冊組件, 禁新常數)

候選庫 = {B, L₄, F₇, F₁₁, μ², N_d, dimC, K_tree, L₅, 75, 91, 45, 88, 90, 178,
137, 123, 33, 12, 21, 14, 16, 44, 55, 364}, 掃描 c1/c2, dev < 2%:

```
★ 唯一候選: δ = B/75 = 4/75 = 0.0533333   (dev 0.035%)
  75 = L₄·L₅−μ² = 2N_d−F₇ = 88−13   ← E_strain 閉合式內建分母 (O173 C7)
  等價相對形式: δ/364 = 1/(75·91) = 1/6825   (dev 0.035%)
```

**關鍵**: 75 唔係外來常數 — 佢正正就係 E_strain = (π²/75)(M_Pl/M_sun)(R_H/L_P)44⁻⁶
嘅分母。殘餘結構候選 = 池/圈 = B·L₄·F₇ + B/75 = **364 + B/(L₄L₅−μ²)**,
零新常數。

⚠️ 誠實標記: dev 0.035% 細, 但 δ 嘅 1σ = 10.56 → **統計無顯著性**。
B/75 候選 = 「有趣觀察」級, 唔宣稱。

### Part E — 逆向鎖定 (兩個主張各自要求 M 幾多?)

| 主張 | 需 M_med | dev from 6.97e6 |
|:-----|:--------|:----------------|
| 池/圈 = 364 (O177 閉合) | 6.96898e6 | −0.0146% (需假設 3-sf 捨入向上) |
| 池/圈 = 364 + B/75 | **6.9700004e6** | **+0.000005% (7-sf 都係 6.97)** |

→ 主張 2 (含 B/75 修正) 對現有 3-sf 輸入嘅要求**比主張 1 更自然**:
6.97e6 唔使任何捨入假設。但兩者都喺 3-sf 範圍 [6.965e6, 6.975e6] 內 → 現數據不可分辨。

### Part F — 可分辨極限

```
候選分離度 = (B/75)/364 = 1/6825 = 0.0147%
3σ 分辨需要 σ_rel < 0.0049%
現況 σ_t(2-sf) = 2.9% ≫ 分離度 → 必須先釘死 t
路徑: M ≥ 5-sf (質譜升級) + t ≥ 4-sf (活動窗口釘死)
```
