# O177 docs/03 — ★ 巧合 vs 身份: 360±4 對稱側審計 (Coincidence vs Identity)

> **日期**: 2026-09-13 · **Script**: `scripts/03_coincidence_vs_identity.py` (14/14 PASS)
> **觸發**: 用戶挑戰 — 「364 距離 360 (自觀閉圓) 太近, 如果 364 具備身份,
>           356 (360−4) 都應該具備兩側對稱身份」→ 364 係計算巧合定真身份?

## 1. 問題重構

364 = 360+4 = 8(N_d+1)+B (O177 形式 4) — 離自觀閉圓 360 只差 4 = B。
用戶邏輯: 若 364 = 360+4 有身份, 對稱側 356 = 360−4 應該都有 →
**兩側對稱身份 = 家族巧合?** 定 364 真身份?

## 2. 方法

|:-:|:-----|:----:|

| B | 對稱側核心比較: 356 vs 360 vs 364 形式清單 | 26 / 34 / 39 |

## 3. ★ 誠實發現: 形式密度判準失效

```
家族四 352-368 身份形式密度 (同級運算池掃描):
352: 44 個   354: 15   356: 26   358: 14   360: 34   362: 15   364: 39
353: 10      355: 13   357: 17   359: 10   361: 12   363: 26   365: 13
366: 11      367: 10   368: 20
```

**352 (44 個) > 364 (39 個)** — 用夠大嘅結構常數池, 幾乎任何整數都有身份形式。
三因子直積都唔唯一: 352 (L₅·B·F₆), 356 (F₁₁·μ²·μ²), 360 (μ²·μ²·Σγ_even),
363 (L₅·dimC·L₅), 364 (B·L₄·F₇) 全部都有。

→ **用戶挑戰成立: 356 (26 形式) 確實具備對稱身份形式 (4F₁₁, 2Σγ,
K_tree·L₅−F₇, 8(N_d+1)−B...)。「有身份形式」唔係巧合 vs 身份嘅判準。**

O177 嘅 7 個形式註冊仍然有效 (佢哋係「已知身份」), 但**形式數目唔可以
證明身份** — 呢個係誠實審計嘅重要修正。

## 4. 真正判準: 點估計 + 零參數預言

形式判準失效後, 剩返兩個獨立判準:

### 判準 1 — 觀測強逼 (點估計距離)

```
池/圈 = N·M·T_ring/(t·η·E_strain) = 364.0533   ← 5 輸入乘除, 獨立算出
距 364 = 0.053 (0.015%)
距 356 = 8.05  (2.21%)
距 360 = 4.05  (1.11%)
距 368 = 3.95  (1.08%)
```

點估計**唯一最近 364** — 比其他家族成員好 70-150 倍。
三因子直積命中者中: 364 (0.015%) < 363 (0.29%) < 360 (1.11%) < 356 (2.21%) < 352 (3.31%)。

### 判準 2 — 零參數預言 (可證偽輸出)

```
R_rel(pred) = 364·E_strain/T_ring = 6,729.87  vs  觀測 6,730.86  → dev 0.015% (O177 C2)
若用 356: 6,579.5  → dev 2.2%  ❌
若用 360: 6,654.5  → dev 1.1%  ❌
```

**364 有獨立預言輸出, 356/360 冇** — 用佢哋做「身份」會直接證偽。

### 判準 3 — 巧合概率

池/圈 若均勻落喺家族 [352,368]: P(∈ 364±0.1) = 0.2/16 = **1.25%**。
加上「364 = B·L₄·F₇ 三因子全譜系」條件後更低。

## 6. ★ 結論: 364 具備身份, 356 對稱身份「數學存在, 物理未激活」

1. **用戶挑戰成立 (一半)**: 356 確實有對稱身份形式 (26 個), 360 有 34 個 —
   形式密度唔係判準, 家族全員身份密集
2. **但 364 身份由觀測強逼**: 池/圈 點估計 364.0533 (5 輸入乘除, 唔係揀出嚟)
   唯一最近 364 (0.015%), 356/360/368 距離 70-150 倍遠
3. **364 有零參數預言**: R_rel = 364·E/T (dev 0.015%) — 356/360 代入即 fail
4. **356 對稱身份未激活**: 數學上存在 (4F₁₁ = 2Σγ), 但池/圈 冇撞 356 (2.2% 遠)
   → 身份 = 形式 × 觀測強逼 × 預言, 唔係單靠形式
5. **360 閉圓**: 係 O158 級聯身份 (88→90→180→360, 唔同物理量) —
   「364 太近 360」唔構成威脅, 因為點估計 364.0533 距 360 有 1.11% (364 嘅 74 倍)

⚠️ **統計誠實**: 1σ = 10.56 (t 2-sf 主導), 356/360/364/368 **全部喺 1σ 內**
→ 現數據**統計上不可分辨** 364 vs 356/360 → 判決移交 **O181**
(M ≥ 5-sf + t ≥ 4-sf)。本 O 結論 = 點估計 + 預言支持 364 身份,
巧合概率 1.25% 受壓, 但唔係統計定案。
