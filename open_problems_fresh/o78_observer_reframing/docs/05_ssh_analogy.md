## 1. SSH 模型簡介 (場論學家一定識)

```
Su-Schrieffer-Heeger (1979): 一維鏈, 交替 hopping t₁/t₂
  H = Σ (t₁ a†_n b_n + t₂ b†_n a_{n+1} + h.c.)

二聚化 (dimerization): t₁ ≠ t₂
  → 打開能隙 Δ = 2|t₁−t₂| (電子質量類比)
  → Z₂ 拓撲不變量 ν = sgn(t₂−t₁) (繞數)
  → 手性對稱: σz H σz = −H (A/B 子晶格交換)
```

## 3. 結構類比 (唔係數值擬合)

```
兩者共享同一結構骨架:

  子晶格對稱破缺 → 能隙/質量項

  SSH:   Δ = 2|t₁−t₂|      (電子質量)
  IDCM:  μ² = Σγ_even−Σγ_odd = 2  (SSB 質量項)

→ 呢個係「結構類比」— t₁,t₂ 單位任意, 唔係 fit

→ IDCM 嘅奇偶分裂 = 同一結構 (手性對稱 + Z₂ 分級)
```

## 4. 二聚化極限 (物理直覺)

```
退二聚化 (t₂ → t₁):
  SSH: 能隙 → 0 (金屬)
  IDCM: μ² → 0 → 冇 SSB → 冇質量
  → 88-site 退化到 44-site: 奇數模式消失

二聚化 (t₂ ≠ t₁):
  SSH: 能隙打開 (絕緣體)
  IDCM: μ² = 2 → SSB → 質量生成
  → 88-site 分裂: 奇數 (觀察者側) + 偶數 (世界側)

→ 「世界/觀察者」分裂 = 二聚化相變嘅必然結果
→ 冇「觀察者」= 未二聚化嘅平凡鏈 (數學上一致)
```
