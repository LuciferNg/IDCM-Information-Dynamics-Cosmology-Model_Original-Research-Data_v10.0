## 4. Beat 耦合

### 層內 beat (同層)
```
beat_ℓ(i,j) = μ_ℓ × |ω_i − ω_j|  (chain beat × tree scale)
每層 946 個 beat, 比例 beat_ℓ(i,j)/beat_ℓ(k,l) 係層內不變量
```

### 跨層 beat (不同層)
```
|ω_{i,ℓ} − ω_{j,ℓ'}| = |ω_i·μ_ℓ − ω_j·μ_ℓ'|
父子 (ℓ'=ℓ+1): μ_ℓ·|ω_i − ω_j·φ⁻¹|
核心: μ_{ℓ+1}/μ_ℓ = φ⁻¹ (每層下降 φ 倍)
```

## 5. 層間連結方式 (MERA 幾何)

### A. Isometry (粗粒化): 4 子 → 1 父
```
U: ℂ^(4^ℓ) → ℂ^(4^ℓ⁻¹),  U†U = I
權重: (ε, 1−ε)² 張量, ε = φ⁻¹/4
```

### B. Mode 縮放: 44 mode 等比例
```
λ_{n,ℓ+1} = φ⁻¹·λ_{n,ℓ}  (與 n 無關, 純縮放)
P_{ℓ→ℓ+1} = φ⁻¹·I₄₄
```

### C. Disentangler (去纏結): 鄰居
```
V(θ=ε) = [[cos ε, sin ε], [−sin ε, cos ε]]
V†V = I₂ ✅,  2-qubit: V⊗V
```

### 層間耦合矩陣
```
C_{ℓ→ℓ+1} = U ⊗ (φ⁻¹·I₄₄)
C_{ℓ→ℓ+k} = U^k ⊗ (φ⁻ᵏ·I₄₄)
```

### 完整 Hamiltonian
```
H_ℓ = Σ_n [½(∂W_{n,ℓ})² − ½γ_n(W_{n,ℓ}−W_{n−1,ℓ})²]
    + B^{−ℓ}·(W_{n,ℓ} − U·W_{n,ℓ−1})²     ← 層間 isometry
    + g_sync·cos(θ_{n,ℓ} − θ_{m,ℓ} − 2π/88) ← 層內 SYNC
```
