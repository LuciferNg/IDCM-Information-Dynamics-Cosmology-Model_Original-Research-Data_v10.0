T_CMB = 2×T_Pl×exp(−74)×(CY₃/10²)×(1−φ⁻⁹) = 2.7283 K

## 三項違規 (O166 判準)

| 違規 | 詳情 |
|:-----|:-----|
| **① e 底數冪 (反秘數)** | exp(−74) = φ^{−74/lnφ} = φ^{−153.78} — 非整數 φ 冪, O165 線性階梯唯一容許 φ^{2ℓ} (ℓ ∈ ℤ) 不容 |
| **② 任意因子 (零新常數)** | CY₃/10² = 134/100 — 10² 係任意冪, 冇結構來源 |
| **③ 宣稱不符 (算術審計)** | doc 宣稱「2.7284 K (0.01%)」; 實算 2.728321 K, dev vs Fixsen 2.72548 = **0.1042%**; o83 check 用 1% 鬆容差先至「PASS」 |

## 附加問題

- **「0.01%」來源不明**: o73/bbn 引用「cmb_cl 已閉合, 0.01%」— 但公式本身 dev 0.104% (vs Fixsen)。
  0.01% 可能係 vs 自身 2.7284 嘅 round-off, 唔係 vs 觀測。
- **o112 值標記錯誤**: o112 寫「T_CMB = 2.7283 K (Planck 2018)」— 2.7283 唔係 Planck 2018 值,
  Fixsen 2009 = 2.72548 ± 0.00057 係標準參考。
- **「SYNC 底噪」機制空泛**: cmb_cl H2 宣稱 CMB = SYNC 操作底噪, 但 exp(−74) 冇從任何操作
  成本/位元數/週期推導 — 74 係後驗湊出 (ln 分解: 73.08 + ln 2.66 ≈ 74)。

## 判決

**🔴 降級: exp(−74) 公式唔係結構閉合 — 剔除出「T_CMB 結構推導」位置。**
舊值 2.7284 K 嘅唯一合法用法 = o166 docs/02 投影閉合嘅預言中心值 (2.7284 ± 0.5%, G 依賴),
或直接用 Fixsen 2.72548 (BBN 閉合穩健, dev 0.30% 更佳)。
