## 推導步驟

### Step 1: 有限維 Hilbert 空間形式化 (scripts/01, 11/11 PASS)

從 44-site K_Chain 建立有限維 Hilbert 空間 ℋ_44:

- **ℋ_44 = span{|n⟩ : n = 1,...,44}**, dim = 44
- 正交基: ⟨n|m⟩ = δ_nm, 完備性: Σ|n⟩⟨n| = I_44
- 88-site 對偶鏈擴展: ℋ_88 = ℋ_even ⊕ ℋ_odd
- 觀察者投影 P_obs = Σ|odd⟩⟨odd|, 世界投影 P_world = Σ|even⟩⟨even|
- P_obs² = P_obs, P_world² = P_world, P_obs·P_world = 0, P_obs + P_world = I_88

**關鍵定理**: 有限維 Hilbert 空間中, 所有 Hermitian 算符的譜都是純離散的 → 塌縮不是外加公設, 而是有限維投影的自然結果。

### Step 2: 測量 = 投影讀數 — 塌縮能量學 (scripts/02, 8/8 PASS)

從 O41 觀察者預算推導測量過程的能量消耗:

- **每模態預算**: B(n) = L₁₀/(2N_d) = 123/88

- **IDCM Landauer 下限**: E_min = L₁₀/(4N_d) = 123/176 (取代 kT ln 2)
- **頻率加權讀數**: ΔE_read(n) = B(n)·ω_n/⟨ω⟩, Σ = 61.5

**測量收斂定理** 🟡: 每次測量消耗預算 → 最多 44 次後預算耗盡 → 系統鎖定在最後測量結果 |n⟩。這個「鎖定」在標準 QM 中被稱為「塌縮」。
> ⚠️ 審計標記: 計數與 dim ℋ = 44 一致, 但「預算耗盡 → 鎖定」缺微觀動力學推導。
