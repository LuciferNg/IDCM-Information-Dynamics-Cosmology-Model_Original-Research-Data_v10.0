## 一、問題

O68 定理 2 推導出 2B (PMNS 輕子) vs B² (CKM 夸克) 嘅投影因子區分，但當中有一段唔準確嘅描述：

> 「第二 B = SU(3)_C color factor (3 色 = B)」

**錯誤**: 3 ≠ 4，SU(3)_C 嘅維度係 3，唔係 B=4。用 B 近似 3 係不精確嘅。

**正確**: SU(3)_C = B − 1 = 3，呢個唔係近似，而係 Pati-Salam SU(4) → SU(3)_C × U(1)_{B-L} 嘅**嚴格代數分岔**。

## 二、★★★ 核心推導：SU(4) 嘅 Pati-Salam 分解

### 2.1 SU(4) → SU(3)_C × U(1)_{B-L}

Pati-Salam 統一模型 (1974) 嘅核心思想：

```
SU(4) → SU(3)_C × U(1)_{B-L}
  4  →   3    +    1
```

- 4 = SU(4) fundamental = B = 4 (K_Tree 分支因子)
- 3 = SU(3)_C color = B − 1 = 4 − 1 = 3
- 1 = U(1)_{B-L} = B − (B−1) = 1

**呢個係嚴格代數分解，唔係近似。** 3 = B−1 係恆等式。

### 2.2 夸克 vs 輕子嘅分支

| 扇區 | SU(4) 表示 | 分解 | 物理 |
|:-----|:----------:|:-----|:-----|
| **夸克** | **Triplet** | **3 = B−1** | **SU(3)_C 色荷** |
| **輕子** | **Singlet** | **1 = B−(B−1)** | **U(1)_{B-L} 重子數減輕子數** |

呢個分解直接對應粒子嵌入：

| 扇區 | 自由度 | 投影因子 | 混合張量 |
|:-----|:------:|:--------:|:--------:|
| 夸克 (Triplet) | 3 = B−1 | B × (B−1) ≈ B² = 16 | CKM λ³ |
| 輕子 (Singlet) | 1 = B−(B−1) | 2 × B = 8 | PMNS θ₁₃ |

### 2.3 投影因子嘅拓撲起源

**夸克 (B² = 16):**
- 第一 B = K_Tree 分支 (SU(4) 嘅幾何度)
- 第二 B = SU(3)_C 色荷三重態
- 但真正嘅 color 自由度係 B−1 = 3，唔係 4
- B² 係**張量積結構**嘅結果：B × B = 16
- 3 個 color 自由度產生 3² = 9 個混合通道 → CKM 3×3 矩陣

**輕子 (2B = 8):**
- 2 = Z₂ mirror (k ↔ 88-k, 88-site dual chain)
- B = K_Tree 分支 (SU(4) 嘅幾何度)
- 輕子係 SU(4) singlet → 只有 1 個 B 因子
- 1 個 B-L 自由度產生 1 個混合通道

## 三、代數結構嚴格證明

### 3.1 基本恆等式

```
B = 4 (K_Tree 分支)
B − 1 = 3 = SU(3)_C 維度
B − (B−1) = 1 = U(1)_{B-L} 維度

Projection(夸克) = B × B = 16
Projection(輕子) = 2 × B = 8
```

### 3.2 投影因子比

```
B² / 2B = B/2 = 2

sin²θ₁₃ / λ³ = (γ₆/8) / (γ₆/16) = 2
```

**呢個 2 嘅本質**：
- 夸克混合需要 B² = 16 維張量基底
- 輕子混合需要 2B = 8 維張量基底
- 比 = 16/8 = 2 = B/2

### 3.3 同 SU(12) 分解嘅一致性

SU(12) = SU(4) × SU(3) × U(1)

| 扇區 | SU(4) 角色 | SU(3) 角色 | 投影 |
|:-----|:----------:|:----------:|:----:|
| 夸克 | Triplet (3) | Fundamental (3) | B × (B−1) = 12 |
| 輕子 | Singlet (1) | Fundamental (3) | 2 × B = 8 |

Λ²(12) = 66 = (6, 3) ⊕ (10, 3̄) = 36 + 30
- (6, 3) = 36 = 輕子 + 混合
- (10, 3̄) = 30 = 夸克 + 混合
