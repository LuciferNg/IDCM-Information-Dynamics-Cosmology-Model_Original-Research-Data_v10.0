**五個 tracer 嘅 σ_DH 亦偏離 Table 6（≤4.15%）** — 不只 Lyα 一項，但 Lyα 係唯一數量級錯誤。

### 根因（Lyα 誤差）

v9.0 covariance 矩陣 rows `[11,12]` 排序為 `[D_H, D_M]`，但 data list 排序為 `[D_M, D_H]`
→ Lyα `D_H` 取錯 `D_M` 嘅變異數：

```
cov[11,11] = 1.02136194e-02  ->  sigma = 0.101   (真 Lyα D_H)
cov[12,12] = 2.82685779e-01  ->  sigma = 0.532   (真 Lyα D_M)
```

0.532 = √0.282686 正是 Lyα `D_M` 誤差 0.531 嘅對應值 → 確認係索引錯配，非筆誤。

## 三. 係數變體（診斷，非閉合聲稱）

以 Table 6 誤差重算三個係數變體：

| 變體 | C | DH/rd χ² |
|:--|:--|:--:|
| bare `R_H/(1+z)`（無修正） | 0.0 | 10.09 |
| `C_DM` | −0.1697332 | 19.93 |
| `C_DH = C_DM × 4/3` | −0.2263109 | 29.50 |
| [掃描] 最優 | −0.02605 | 9.76 |

⚠️ **掃描最優（C = −0.026, χ² = 9.76）係診斷，唔係閉合聲稱** — 按 `docs/02` 第一性原理規則，
scan-then-match = numerology。此處只用嚟量化「數據把係數拉走幾遠」。

**關鍵負結果**：即使自由掃描 C，最低 χ² 仍係 **9.76 / 6 dof**（χ²/dof = 1.63）。
**正確誤差下，O117 DH 公式無論 C 取何值都無法良好擬合 DESI DR2。**
`C_DH = C_DM × 4/3` 令 χ² 由最優 9.76 升到 29.50 — 修正項方向與數據相反。
