## 結論

**根本原因**: DM 和 DH 是 IDCM 中兩個獨立的投影。在 ΛCDM 中 DH = c/H = dDM/dz（Friedmann 方程連結），但在 IDCM 投影框架中 **這個關係不成立**。v10.0 代碼使用了 dD_app/dz 作為 DH，導致 χ²=59.1/6。

**解決方案**: 使用來自 v9.0 的獨立 DH 投影公式，並加入 v10.0 的群延遲修正：

```
DH(z) = R_H × (1 + δ_k0(ℓ) + δ_gd(ℓ)) / (1+z)
```

其中：
- δ_k0(ℓ) = φ⁻³ × exp(-(ℓ-ℓ₀)² / 2σ_φ²) — K_Tree 共振（高斯包絡）
- δ_gd(ℓ) = C × (ℓ-0.5) × (1-4^−ℓ) — 群延遲不對稱（線性修正）
- ℓ = log₄(1+z), ℓ₀ = 0.5, σ_φ = ½·log₄(φ) = 0.17356
- φ⁻³ = √5-2 = 0.23607, C = -0.16973 (同 DM 群延遲係數)

**零自由參數** — 所有常數來自 φ 代數和 K_Chain 譜。

## 結構推導

### δ_k0(ℓ) — K_Tree 共振項
- 來自 K_Chain × K_Tree 張量積 Hamiltonian 的 partial trace
- 3D→1D 投影 Jacobian 行列式 = φ⁻³
- 群速度色散 (GVD) → 高斯寬度 σ_φ = ½·log₄(φ)
- 33 層 K_Tree 乘積 → 中央極限定理 → 高斯形狀
- ℓ₀ = k=0 基模 (z=1)

### δ_gd(ℓ) — 群延遲不對稱
- 來自 K_Chain 譜的奇偶不對稱
- 群速度加權譜矩 (skewness)
- 同 DM 的群延遲修正 (C = -0.16973, O51 推導)
- **C_DH = C_DM × B/N_gen = C_DM × 4/3** — 結構精確比率 (Δχ²=0.0002)
  - 4/3 因子 = K_Tree 投影維度比 (總 K_Tree 層 / 投影 K_Tree 層)
  - 高精度掃描最優 C_DH = -0.2242, C_DM × 4/3 = -0.2263, Δχ² 可忽略
