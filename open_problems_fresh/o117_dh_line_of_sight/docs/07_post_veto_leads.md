## 一、arch 核形狀全景（修正後）

```
M(0)     = sec(π·22/88) = √2           (z=0)
M(½)     = sec(π·26/88) = 1.6686756    (z=1)  ← 全域極大值
M(ℓ_t)   = sec(π·24.43/88) = 1.5546    (z=2, ℓ=ℓ_t)
M(ℓ>ℓ_t) = √2 flat                     (z≥2, 鎖定)
```

arch 參數範圍 [π·22/88, π·26/88] = [0.7854, 0.9282] rad，全 < π/2 ⇒
sec 對 sin(πℓ) 嚴格單調；sin 喺 [0, ½] 升、[½, ℓ_t] 降 ⇒ **apex 唯一喺 ℓ=½（z=1）**。

Ω 曲線形狀（apex 喺 z=1、高 z 鎖死 √2）。將來任何 z≈1 或 z≥2 嘅 D_H
測量都可以直接殺/救 arch 核。**呢個就係否決審計真正留低嘅嘢。**

z_apex=1 本身有結構意義：ℓ=½ ⟺ z=1（4^½−1），而 ℓ=½ 係
sin(πℓ) 最大點 = **半鏈中心**（O76 z_eff=1/ln4 係另一件事，唔好混）。
