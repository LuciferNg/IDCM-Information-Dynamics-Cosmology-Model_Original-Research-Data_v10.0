## 2. 定理 [NDT-1] A 類無差別 — 兩讀法對實驗檯量逐項相同

**陳述**: 所有「實驗檯可測」量（R1 A/A′ 類: Casimir/Lamb/g−2/Casimir-Polder）都係譜差分／譜比，
由模譜對邊界敏感度唯一決定 — 兩讀法對佢哋嘅預言**逐項相同**。

**證明**:
1. R1 判準 ref∧bnd∧gau ⟹ 量只經邊界譜 γ_n(d), ω_n(d) 進入
2. 實體論 vs DTO 之爭（「零點能存在與否」）唔影響邊界譜函數本身 — 譜係同一 K_Chain 譜
3. 實體論讀法多出嘅係**全局常數 offset E_off（d-無關）**；−∂E_off/∂d ≡ 0 ⟹ 任何差分可觀測量讀法不變
4. 蒙地卡羅確認: 2000 隨機 (d, offset ∈ [0, 1e9]) — 兩讀法力恒同（Decimal 50 位, rel dev max 1.3e-35）

## 3. 定理 [NDT-2] B 類判別 — 唯一可以判別兩讀法嘅量 = 絕對真空能 ρ_Λ

### 判別結論（NDT3）

**實驗檯（A 類）永遠分唔到兩讀法** — Casimir/Lamb/g−2 數字唔可以判別「真空實體 vs 結構」，
正正因為佢哋係譜差分量（Jaffe 2005 分層嘅 IDCM 版本）。

**唯一判別通道 = B 類宇宙學真空能（ρ_Λ）**:
- DTO 有唯一預言（283.0821 → 2.246 meV → Λ_eff = 4.2913e-84 GeV², O86 dev 1.37%）
- QFT 實體論冇可證偽預言（counterterm 任意 ⟹ 任何 ρ 都合法）

觀測已選 DTO 側 —— 唔係因為「真空有冇實體」嘅實驗，而係因為**只有結構讀法產生了一個可被宇宙學檢驗的唯一數字**。
