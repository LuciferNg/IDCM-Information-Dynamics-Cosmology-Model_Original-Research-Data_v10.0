## 1. 判準（三條，全部要過先算「可觀測」）

```
C-ref  差分性   : 存在參考系 R (另一邊界/另一能級/另一條件), 量可寫成
                  Δ = O(S; b) − O(S; b₀), 或本身係譜差 (能級差/異常差)
C-bnd  邊界敏感 : ∂Δ/∂b ≠ 0 (對條件微變有響應)   — Casimir F∝d⁻⁴ 即此
C-gau  gauge 不變: 無量綱化後 s_X = d ln X / d ln c = 0 (O213 判準)
```

三條全過 → A 類（實驗檯可測）；缺差分性但結構閉合＋gauge 不變 → B 類（結構檢驗量，宇宙學通道）；否則 → C 類（不可觀測／無對應）。

## 4. 與 O241 之分工

A′ 類四量（Casimir-Polder / Casimir / Lamb / g−2）被 R1 判入「實驗檯可測構型」，但**IDCM 側之力/頻移表達式**屬 O241 Q2/Q3 推導範圍 — 本 O 只喺可分層（可測 vs 不可測）層面裁決，唔代推數字。O241 完成時，其結果應自動落入 A′ → A 升格（結構閉合補齊），唔會改變判類。

## 5. 盲測現狀

判準本身係**形式判準**，唔係數值擬合（N_search=1，無 φ-power）。樣本外正例：Lamoreaux 1997 / Mohideen-Roy 1998 / Wilson 2011 / Lamb / g−2 全部係 A 類差分構型且被實驗證實；反例：QFT 絕對 E₀ 從未被測到（scheme 依賴，120 階失敗正係其不可觀測性之證據）。B 類之樣本外鎖 = Λ_eff 通道（O86 dev 1.37%）。
