## 1. ★★★ 雙角公式: m_H/m_W = 2cos(19π/88)

```
m_H/m_W = sin(38π/88)/sin(19π/88) = 2cos(19π/88)   (sin 2x/sin x = 2cos x, 1e-50)

19 = N_d/2 − N_gen = 22−3;  38 = 2×19 = N_d − 2N_gen
```

## 2. ★★★ 餘角公式: m_W/m_Z = cos(14π/88)/cos(3π/88)

```
sin(30π/88) = cos(7π/44) = cos(14π/88)   (30 = 44−14 互餘)
sin(41π/88) = cos(3π/88)                  (41 = 44−3 互餘)
```

**W/Z 比 = cos(2L₄·π/88)/cos(N_gen·π/88)**,分母嘅原身 sin(41π/88) 載 f_unproj。
