## 1. Gemini 假說 A: H/W 純世界 + Spin-Dependent Projection

**假說**: H (Spin-0) 冇極化對偶 ⇒ 唔需要 176 域混合, 純世界 88 域;
W/Z (Spin-1), τ/b (Spin-1/2) 有極化 ⇒ 必須 176 域觀察者對偶。

### 驗證結果:

| 檢查 | 結果 |
|:-----|:----:|
| ★ H/W = 1.558 > 1 ⇒ 45-家族 (sin 比全 <1) 自動排除 | 🟢 結構必然性 |
| 88 域單模式 √γ₂₅ = ω₂₅ 係唯一有算子身份解 (25 = N_d/2+N_gen = F₅²) | 🟢 |
| 176 域反轉 (86,39) = √(γ₈₆/γ₃₉) = 1.558419 dev 0.0011% | 🟡 罕見 (p=0.015) 但冇算子身份 |
| Spin 假說可證偽 (Spin-0 必須 88 域) | 🟢 框架成立 |

**誠實評估**: Spin 假說嘅「結構必然性」部分成立 (H/W>1 排除 45-家族,
所以 H 唔使混合唔係選擇)。但「88 域係唯一精確」被 (86,39) 反例挑戰 —
統計罕見 (p=0.015) 但 86/39 冇已命名算子身份, 按零新常數原則唔升級。
ω₂₅ 單模式保留為唯一結構解。

## 2. Gemini 假說 B: μ/e 雙步迭代 √(γ_k1)×√(γ_k2)

**假說**: m_μ/m_e = √(γ_k1)×√(γ_k2) 兩步相干乘積 (Z₂ 光圈二次摺疊)。

### 驗證結果:

| 檢查 | 結果 |
|:-----|:----:|
| 單步上限 28 (88 域) / 56 (176 域) < 206.8 | 🟢 超限確認 |
| 88 域最佳: √(γ₃₃/γ₁)×√(γ₁₇/γ₂) = 206.934 dev 0.081% | 指數無身份 |
| 176 域最佳: √(γ₇₇/γ₁)×√(γ₆₇/γ₁₄) = 206.762 dev 0.003% | 指數全無身份 |
| **null control**: 200 隨機目標, 176 域雙步 median best dev = 0.0056% | 🔴 p = 0.365 = 純背景 |

**🔴 裁定**: 雙步迭代假說 **被 null control 裁定為純背景** —
雙步配對自由度太大 (7744² 對), 0.003% 級命中係預期內。指數 (77,1,67,14)
全無算子身份。Gemini 嘅「L₅/B 選擇規則」冇命中。

## 3. 教訓

- 雙步/多步乘積 = 自由度爆炸 → 必須 null control 先算結構 (scripts/15 同款)
- Spin 假說結構必然性成立, 但冇證據支持「spin 決定投影域」— 目前只係
  H/W>1 排除 45-家族嘅必然結果
- μ/e 仍然 🔴: 單步超限, 雙步背景 — 需要第三種結構 (非 √γ 乘積)
