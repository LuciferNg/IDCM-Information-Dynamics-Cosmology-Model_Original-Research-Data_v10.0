## 1. 問題之形式化

橋之群層 iso 已 exhibition（`docs/10`）。要更進一步（升 🟢）須有**共同測度**：一個 canonical 歸一化，令兩側 ℤ₄ 分級測度可比。
形式化：存在（α, β, π）—— 純量 α、平移 β、類置換 π —— 使

> `α·s_c + β = d_{π(c)}`  ∀c ∈ ℤ₄

其中 `s` = 鏈側 ℤ₄ graded 測度、`d` = 算子側。本檔對 4 種歸一化層級（純量／仿射／置換／ℤ₄ 相位）逐一窮舉判定。

## 2. 算子側測度：**自共軛**（定理）

`V₁₂ = C¹²`，`z ∈ Z(SU(B))`；`Λ^j` 之中心荷 = `i^j` ⟹ 分級測度 `d_c = Σ_{j ≡ c (4)} dim Λ^j`。

| c | 合成 | `d_c` |
|:-:|:--|:--:|
| 0 | `Λ⁰+Λ⁴+Λ⁸+Λ¹²` = 1+495+495+1 | **992** = 2¹⁰ − 2⁵ |
| 1 | `Λ¹+Λ⁵+Λ⁹` = 12+792+220 | **1024** = 2¹⁰ |
| 2 | `Λ²+Λ⁶+Λ¹⁰` = 66+924+66 | **1056** = 2¹⁰ + 2⁵ |
| 3 | `Λ³+Λ⁷+Λ¹¹` = 220+792+12 | **1024** = 2¹⁰ |

**★ 自共軛定理**：Hodge 對合 `j ↔ 12−j` 給 `dim Λ^j = dim Λ^{12−j}`，而 `12−j ≡ −j (mod 4)`
⟹ 類映射 `c ↦ −c` ⟹ **`d₁ = d₃ = 2¹⁰` EXACT**（算子側測度對 `c ↦ −c` **對稱**）。
宇稱：`Σ_{c even} d = Σ_{c odd} d = 2¹¹ = 2048`（二項式定理）。

**★ 字符恆等**：`Σ_{j=0}^{12} dim Λ^j · i^j = (1+i)¹² = −64 = −B³`（精確高斯整數；`(1+i)⁴ = −4`）
⟹ **算子側 ℤ₄ 字符為純實數**（`Im = 0`，等價於 `d₁ = d₃`）✓

## 3. 鏈側測度：兩種憲章約定之行為**相反**

`γ_k = 4sin²(kπ/176)`（176-L，憲章 C1 標準 = **路徑**）；`γ_n = 4sin²(πn/88)`（88-L，legacy = **環**）。

| 約定 | `(s₀, s₁, s₂, s₃)` | 性質 |
|:--|:--|:--|
| **176-L（路徑）** | `(46, 44−sec(π/88), 44, 44+sec(π/88))` | **非**自共軛：`s₁ − s₃ = −2sec(π/88) = −2.0012751612` ≠ 0；**4 個類全部偏離均值**（`N_d + μ²/4 = 44.5`） |
| **88-L（環）** | `(44, 44, 44, 44)` | **完全均勻** = `N_d` ∀c ⟹ 缺陷支撐 = **0 類** |

**88-L 均勻性之證明**（一行）：`Σ_{j=0}^{N−1} sin²(πj/N + φ) = N/2`（**∀φ**，單位根濾子）
⟹ 四類各 `= 4·(22/2) = 44 = N_d` ✓（4 個不同 φ 全數真算驗證）。
⟹ 176-L 之差異**純由邊界產生**（路徑缺 `k=0`、含未配對之 `k=88`，及定點 `k=44`）。

## 4. ★ 對齊不可能性（四層窮舉，全數失敗）

| 層 | 檢定 | 176-L | 88-L |
|:-:|:--|:--|:--|
| **(a)** 缺陷支撐基數（相對類平均） | 純量（含置換）對齊 | **4 類** vs 算子 **2 類** ⟹ 失敗 | 0 類 vs 2 類 ⟹ 失敗 |
| **(b)** 仿射 × **24 置換窮舉** | `α·s_c + β = d_{π(c)}` | **0/24 成功** | **0/24 成功** |
| **(c)** ℤ₄ 相位（`α ∈ {1, i, −1, −i}`） | 命中實數 `−B³` | `\|Im(α·C_chain)\| ∈ {2.00128, 2.0, 2.00128, 2.0}` ⟹ **全部 ≠ 0** ⟹ 失敗 | 同（均勻 ⟹ 亦失敗） |
| **(d)** 混合測度（線性組合） | — | 可强行對齊，但引入 **1 個自由參數** ⟹ **手調** ⟹ 違反零參數絕對主義 ⟹ 唔可當結構 | 同 |

> **★ 判決**：**共同測度唔存在**（canonical 範疇）；且**兩種鏈約定都阻塞** ⟹ 裁定**非約定依賴** ✓
> 阻塞量級 = `μ² = 2`（相位層）／整數 32 = 2B²（仿射層）—— **非**數值精度問題。

## 5. 阻塞之結構原因（為何「唔同型」）

- **算子側**：由 **Hodge 對合**（`j ↔ 12−j`，存在因 `V₁₂` 度 = 12 且外代數封閉）**強制自共軛** ⟹ `d₁ = d₃`。
- **鏈側（路徑）**：ℤ₄ 測度攜帶**邊界／定點缺陷** —— 定點 `γ₄₄ = μ²`、邊界 `γ₈₈ = B`（未配對）⟹ 非自共軛。
- **鏈側（環）**：無邊界 ⟹ **完全均勻**（零缺陷），但算子側非均勻 ⟹ 另一種失敗模式。

⟹ 兩者作為「**帶對合 `c ↦ −c` 之 graded 向量**」**唔同型**（type mismatch），而非「尚未找到歸一化」。

## 6. 唯一正面結果：計數層零異常

鏈側**計數**測度（`Ŝ = S^{N_d/2}` 之 4 個 eigenspace）`= (22, 22, 22, 22) = (N_d/2)·(1,1,1,1)` —— **均勻**。
組合空間（對角 ℤ₄）之計數分級 = 卷積：

> `(22,22,22,22) ∗ (992,1024,1056,1024) = (90112, 90112, 90112, 90112)`，總 `= 360448 = 88 × 4096`

⟹ ★ **組合空間係 free ℤ₄-module**（rank 22528）⟹ **ℤ₄ 異常純粹係「譜測度」側現象**，唔存在於組合（計數）層 ✓
（亦解釋 §4 之阻塞來源：對齊失敗只可能來自譜測度，而譜測度之缺陷正是邊界效應。）
