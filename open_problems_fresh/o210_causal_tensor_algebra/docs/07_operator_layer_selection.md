## 2. ★ 定理 O210-T2（no-go, 代數層）

**敘述**：𝒯 = (`Op`,`Sc`,`Fn`,`Ix`; {`⊗`,`⊕`,`Tr`,`Spec`,`Proj`,`†`,`Contr`}) 中，**冇任何運算之 codomain 帶「禁止／排除」標記**；且 `⊗` 為全映射（`Op×Op → Op`）。
故 `Λ^k(12) = (Proj_antisym ∘ ⊗^{k−1})(12^{⊗k})` 為 **𝒯-可構造型**（對任意 `k`），`Sym^k` 同理。
⟹ **類型層零壓制**：冇辦法由 𝒯 之型別規則導出「複合算子不可構造／被壓制」。

**證明**（兩行）：`Proj ∈ 七運算`、`⊗ ∈ 七運算` 且 `⊗: Op×Op → Op` 全定義；`Λ^k`、`Sym^k` 為 `⊗^k` 之投影像 ⟹ 屬 `Op`。歸納完畢。∎

**驗證**：`scripts/05` §C（七運算簽名 codomain ∈ {`Op`,`Sc`,`Sc×Op`}；`Λ² = Proj_antisym ∘ ⊗` 之可構造性）。

**⟹ 直接判決 O88 §4 條件 ① 為假。** `τ_p = ∞` **不可能** 由「框架禁止」得出。
