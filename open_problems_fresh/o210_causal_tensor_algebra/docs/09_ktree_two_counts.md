## 2. 圖論：路徑 `P_N`（K_tree）之 Laplacian

- `N = 2(B²+1) = 34` 節點、`E = N−1 = 33` 邊。
- `Laplacian L = D − A` 譜 = `2 − 2cos(kπ/N) = 4sin²(kπ/2N) = 4sin²(kπ/68)`，`k = 0..N−1`。
- **★ 圖論定理**：`tr L = Σdeg = 2E` ⟹ `Σ(非零 λ) = 2E = 66` —— 對**任何**圖成立。

**真算驗證**（整數 Laplacian 矩陣 + 對角化）：
`tr L = 66` EXACT（整數）；`λ₀ ≈ −1.2e-16`；非零模數 = 33 = `N−1` ✓；`Σλ = 66.0000000000` ✓；
解析式對數值譜最大偏差 `1.78e-15` ✓；配對 `λ_k + λ_{N−k} = B = 4` ∀k ✓；不動點 `k = N/2 = 17`, `λ = B/2 = 2 = μ²` ✓。

## 4. ★ `66 = 2·K_tree` 裁定之修正（三層分解）
