## 2. ★ 定理 O210-T1（模 B 定則）

**設定**：`12 = B · N_gen = 4 × 3` ⟹ `SU(12) ⊃ SU(B) × SU(N_gen)`，`12 = (B, N_gen)`；
`SU(B) ⊃ SU(N_c) × U(1)_{B−L}`，`N_c = B − 1 = 3`（由 `12 = (B,3)` 逼出）。
單位跡條件：`N_c·(1/N_c) + 1·(−1) = 0` ⟹ `B = N_c + 1`。

**定理**：設 `S_λ(C^B)` 為 `SU(B)` irrep（`k = |λ|`）。若其 Cauchy 分量帶 `B−L = ±q`，則

> **`k ≡ ±q (mod B)`**

**證明**（Cauchy + 分支律，一步）：
`S_λ(C^{N_c} ⊕ C) = ⊕_{μ : λ/μ 為水平條} S_μ(C^{N_c}) ⊗ U(1)^{|λ|−|μ|}`。
`U(1)_{B−L}` 與 `SU(N_c)` 對易 ⟹ 對 `S_μ(C^{N_c})` 為**常數**電荷：
`q = |μ|/N_c − (k − |μ|) = (B|μ| − N_c·k)/N_c`，其中用咗 `n₄ = k − |μ|` 及 `B = N_c + 1`。
⟹ `N_c·q = B|μ| − N_c·k`。取 mod `B`（`gcd(N_c, B) = gcd(B−1, B) = 1` 可逆）：
`N_c·k ≡ −N_c·q (mod B)`。又 `N_c = B−1 ≡ −1` ⟹ `N_c⁻¹ ≡ −1` ⟹
`k ≡ +q (mod B)` 或 `k ≡ −q (mod B)`。∎

**推論（ΔB=1 通道）**：`q = 2/3 = 2/N_c` ⟹ `k ≡ ±2/3`。以 `N_c⁻¹ ≡ −1`：`2/3 ≡ −2 ≡ 2 (mod 4)` ⟹
**`k ≡ 2 (mod 4)`**，`k ≤ 12` 內恰 `{2,6,10}` ✓（與 O88 普查完全一致）。

**推論 2（最小性）**：最小正 `k` = 2 = `N_c·q` = qq pair 之 **fundamentals 數目** ⟹
ΔB=1 最小載體 = `Λ²(12) = 66` **由 pair 結構強逼**（唔係由維數巧合）。

**推論 3（週期身份升級）**：週期 = `B` = **IDCM 分支數**（`B = 4`，O229 九路線過定，其中 8 條不用 `N_c`），
而**唔只**係「SU(4) 行列式指紋」——`SU(4)` 就係 `12 = B·N_gen` 之 **B-因子**，故兩者係同一件事之兩層描述。

## 4. `66 = 2·K_tree` 之裁定

**66 出現於三條互不相通之結構**：

| 鏈 | 分解 | 維數 |
|:---|:---|:---|
| (i) `SU(4)×SU(3)_F`（`12 = (4,3)`） | `Λ²(12) = 10⊗3̄ ⊕ 6⊗6` | 30 + 36 = 66 |
| (ii) `SU(11)×U(1)`（`12 = 1⊕11`） | `Λ²(12) = Λ²(11) ⊕ 11 = 55 ⊕ 11` | 55 + 11 = 66 |
| (iii) 樹譜（`K_tree` 譜和） | `Σλ = B³ + B/2` | 64 + 2 = 66 |

- 鏈 (i) = **ΔB=1 判據所在鏈**（帶 colour 三重態）。
- 鏈 (ii) = **`K_tree` 身份所在鏈**（`55 = C(L₅,2) = F₁₀`）。
- 鏈 (iii) 係**譜和**（非維數）；其結構分解（`B`-一般）：
  鏈長 `sites = 4(B²+1) = 68`、模數 `= sites/2 − 1 = 2B²+1 = 33 = K_tree`、
  配對 `k ↔ half−k` 和 `= B`（`B² = 16` 對）、固定點 `k = half/2 = 17`、`λ = B/2 = μ² = 2`
  ⟹ `Σλ = B²·B + B/2 = B³ + B/2 = 66` ✓（只用 `B`）。

**★ B-擾動測試（結構剛性，4 Hard Tests #4）**：

```
R1 = 2·K_tree = 2·(B−1)·L₅      R2 = Σλ = B³ + B/2
B = 2:  22   vs    9.0 ;  B = 3:  44  vs  28.5 ;  B = 4:  66  vs  66.0 ★
B = 5:  88   vs  127.5 ;  B = 6: 110  vs 219.0 ;  B = 7: 132  vs 346.5
```

⟹ 兩表達式**只喺 `B = 4` 相交**，冇 `B`-一般恆等 ⟹ **冇結構機制**（真機制會畀出對所有 `B` 成立之恆等）。

**裁定**：
- `66 = 2·K_tree` = **單點算術巧合**（🔴 作為「強逼機制」）；
- 但 `66` 本身作為 `Λ²(12)` **仍係結構強逼** — 途徑 = `k = 2`（qq pair 之 fundamentals 數）+ 模 `B` 定則；
- 舊表述「結構巧合（非輸入、非貼標籤）」（O88 docs/07 L226）**不成立**（維度層巧合 ≠ 結構層身份）。
