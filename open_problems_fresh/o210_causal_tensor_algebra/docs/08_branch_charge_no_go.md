## 1. 定義：分支荷 = SU(B) 之中心荷（ℤ_B）

**群論事實**：`Z(SU(n)) = ℤ_n`（純量矩陣 `ω·I`, `ω = e^{2πi/n}`）。`ω·I` 作用於 irrep `S_λ` 為純量 `ω^{|λ|}`
⟹ **中心荷（n-ality）`χ(S_λ) := |λ| mod n`** — well-defined。

**IDCM**：`12 = B·N_gen` ⟹ 分支因子 `SU(B) = SU(4)`，`|Z(SU(B))| = B = 4`。故

> **★ 定義（分支荷）**：`χ(O) := |λ| mod B`，對任何由 fundamentals 生成之對象。

**型別相容性（三檢全過）**：

| 檢定 | 內容 | 結果 |
|:--|:--|:--|
| (a) well-defined | `λ ≅ λ + (1^B)` ⟹ `|λ|` 加 `B` ⟹ `χ` 不變 | ✓（`λ=(2,1,1,0)`: 4≡0；`+(1,1,1,1)`: 8≡0） |
| (b) 加法同態 | `⊗` 下 `χ` 相加 mod B | ✓ 三組真實分解全過（含維數守恆） |
| (c) 可算 | `χ` 為純組合函數 | ✓ 6 個標準 irrep 之維數與 `χ` 全對 |

**(b) 之實算證據**：

| 分解 | `χ` 相加 | 分量 `χ` | 維數守恆 |
|:--|:--:|:--:|:--:|
| `4 ⊗ 4̄ = 15 ⊕ 1` | `1+3 = 4 ≡ 0` | `0, 0` | `15+1 = 16 = 4×4` ✓ |
| `4 ⊗ 4 = 6 ⊕ 10` | `1+1 = 2` | `2, 2` | `6+10 = 16` ✓ |
| `4 ⊗ 6 = 4̄ ⊕ 20` | `1+2 = 3` | `3, 3` | `4+20 = 24 = 4×6` ✓ |

**(c) 之標準 irrep 表**：`4(χ=1)`、`6(χ=2)`、`10(χ=2)`、`15(χ=0)`、`20(χ=3)`、`4̄(χ=3)` ✓（維數 Weyl 公式實算）。

## 2. ★ 定理 O210-T3

> **`N_c·(B−L) ≡ |λ| (mod B)`** 對 `S_λ(C^B)` 之**每個** `SU(N_c)×U(1)_{B−L}` 分量成立。
> （即：**分支荷 = B−L 分子 mod B**；中心荷可由 B−L 讀出。）

**證明**（Cauchy + 水平條，一步）：對分量 `S_μ(C^{N_c}) ⊗ U(1)^{k−|μ|}`（`k = |λ|`）：
`Q := N_c·(B−L) = B|μ| − N_c·k`；取 mod `B`（`B|μ| ≡ 0`、`N_c = B−1 ≡ −1`）⟹ `Q ≡ k (mod B)`；
又 `χ(S_λ) = |λ| mod B = k mod B` ⟹ `Q ≡ χ (mod B)`。∎

**暴力驗證**：`k = 0..12` × {`Λ^k`, `Sym^k`} × 全部水平條分量 = **1507 個分量全部成立** ✓
（分 k 計數：k=2: 10/10、k=6: 69/69、k=10: 226/226 …）。

**推論**：ΔB=1 合格分量之 `Q = ±2`，且 `k ≡ ±Q (mod B)` ⟹ `k ∈ {2, 6, 10}` ✓（與 T1 一致）。

⟹ ★ **T1 之模數 `B` = `|Z(SU(B))|` = 分支群之中心階** — 週期身份由「數值相同」升級為**群論恆等**。
