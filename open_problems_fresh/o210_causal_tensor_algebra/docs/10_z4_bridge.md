## 2. ★ 鏈側 ℤ₄ 扇區定理（新，精確）

**設定**：`γ_k = 4sin²(kπ/176)`，`k = 1..88`（176-L 標準約定），按 `k mod 4` 分四扇區。

| 扇區 | `k mod 4` | `Σγ` | 閉式 | 項數 |
|:--|:--:|:--:|:--|:--|
| `s0` | 0 | **46.0** | `N_d + μ²` | 22（10 對 + 定點 `k=44` + 邊界 `k=88`） |
| `s1` | 1 | 42.9993624194… | `N_d − sec(π/88)` | 22（與 `s3` 構成 22 對） |
| `s2` | 2 | **44.0** | `N_d` | 22（**11 對，無定點**） |
| `s3` | 3 | 45.0006375806… | `N_d + sec(π/88)` | 22 |

> **★ 扇區定理**：`Σγ^{(c)} = N_d + δ_c`，`δ = (μ², −sec(π/88), 0, +sec(π/88))`，**`Σδ = μ² = 2` EXACT**。

**證明（初等，兩條）**：
1. **對合** `k ↔ 88−k`：`γ_k + γ_{88−k} = B = 4` ∀k。類映射 `c ↦ −c (mod 4)`：
   - `class 2 ↦ class 2`，定點 `k = 44 ∈ class 0` ⟹ class 2 = **11 個完整對** ⟹ `s2 = 11·B = 44 = N_d` ✓
   - `class 0 ↦ class 0`：10 對 ×B + `γ₄₄ = μ² = 2` + 未配對之 `γ₈₈ = B = 4` ⟹ `s0 = 46 = N_d + μ²` ✓
   - `class 1 ↔ class 3`：共 22 對 ⟹ `s1 + s3 = 22·B = 88 = 2N_d` ✓
2. **單位根濾子**（定 `s1`）：`Σ_{j=0}^{21} cos((4j+1)π/88) = cos(π/88) − cot(π/44)sin(π/88)`
   ⟹ `s1 = 44 − [2cos(π/88) − cos(π/44)/cos(π/88)]`
   ⟹ `2cos(π/88) − cos(π/44)/cos(π/88) = (2cos²(π/88) − cos(π/44))/cos(π/88) = 1/cos(π/88)`
   ⟹ **`s1 = N_d − sec(π/88)`，`s3 = N_d + sec(π/88)`** ✓（用 `2cos²x = 1 + cos2x`）

**對照憲章 C2**：World = 偶 k = `s0 + s2 = 2N_d + μ² = 90` ✓；Observer = 奇 k = `s1 + s3 = 2N_d = 88` ✓；總 `= 4N_d + μ² = 178 = 2(88+1)` ✓。
**★ 零缺陷扇區 = class 2**（唯一 `δ_c = 0`，且 = 唯一「全配對、無定點、無邊界」扇區）。

## 3. 生成元與站-模對偶（canonical，**零前提**）

**(a) 模-ℤ₄ 生成元**：`Ŝ := S^{N_d/2} = S²²`（`ℤ₈₈` 上移位 22 站）。
- 對 DFT 基：`Ŝ|k⟩ = e^{2πi·22k/88}|k⟩ = i^k|k⟩` ✓（真算，`dev = 0`）
- `Ŝ⁴ = S^{88} = 𝟙` ⟹ 階 4 ⟹ 生成 `ℤ₄ = ℤ₈₈/ℤ₂₂` ✓
- `Ŝ` 與環 Laplacian 交換（同一 DFT 基同時對角化）✓
- 扇區均勻：`88/4 = 22 = N_d/2` ✓

**(b) 站-模對偶（關鍵）**：4:1 decimation 陪集指標 `x_i^{(c)} = 1 ⟺ i ≡ c (mod 4)` 之 DFT：

> `X_k^{(c)} = Σ_{j=0}^{21} e^{−2πik(c+4j)/88} = 22·ω₄^{−cj}·[k ≡ 0 (mod 22)]`

⟹ **支撐恰為四個特殊模 `{0, 22, 44, 66} = (N_d/2)·{0,1,2,3}`，相位 = `22·ω₄^{−cj}`** ✓
（真算：支撐偏差 `1.8e-38`、相位偏差 `2.1e-38`，dps = 40。）

⟹ ★ **站側 ℤ₄（4:1 decimation 陪集 = O213 之 L7 流）與模側 ℤ₄（`k mod 4`）係同一 `ℤ₄` 之對偶兩面，同一生成元 `ω₄ = i`** —— 此為 **DFT 對偶定理之直接後果，無需任何額外前提**。

## 4. 算子側 ℤ₄

- `z = diag(i,i,i,i,1,…,1)`（4 個 `i`, 8 個 `1`）：`det = i⁴ = 1` ⟹ `z ∈ SU(4) = SU(B) ⊂ SU(12)` ✓
  （`Z(SU(B)) = ℤ_B`，`B = 4`。）
- `Λ^k(C¹²)` 上：本徵值 `= i^k` ⟹ `χ = k mod 4` ✓（**= 定理 O210-T3**）
- ℤ₄ 類維數和：`{0: 992, 1: 1024, 2: 1056, 3: 1024}`，總 `= 2¹² = 4096` EXACT
  ⟹ **缺陷 = `(−2B², 0, +2B², 0)`，`32 = 2B²`，總和 0**（對稱）

## 5. ★ 橋裁定（三層）

**(1) 群層 — 升級**：兩側 `ℤ₄` 皆有**區別生成元**（鏈：`Ŝ`；算子：`z`），皆對應「1 ↦ `i`」
⟹ 同構 `Φ: Ŝ ↦ z` **存在且唯一**（帶區別生成元之有限循環群同構是唯一的，**非任意選擇**）
⟹ **舊判「同模但無 map」→「map 存在」** ✓

**(2) 預註冊證偽測試 — 執行且通過**：`ΔB=1 ⟹ k ≡ ±|B−L| = 2 (mod 4)` ⟹ 鏈扇區 class 2
⟹ `Σγ = N_d = 44` EXACT；逐值 `{2, 6, 10}` **全部**落 class 2 ✓
**鑑別性**：替代情況 class 0 `= N_d + μ² = 46 ≠ 44` ⟹ 測試**有牙**（唔係恆真）。

**(3) ⚠️ 誠實界定 — 真正有內容之檢定係 ill-defined**：
(2) 之「通過」部分係**定義性**（兩側皆 `k mod 4` 之同一算術）。真正檢定 = **weight 對齊**：

| | 測度 | 缺陷向量 |
|:--|:--|:--|
| 鏈側 | `Σγ`（譜和，總 178） | `(μ², −sec(π/88), 0, +sec(π/88))`，總和 `μ²` |
| 算子側 | `dim`（維數，總 `2¹²`） | `(−2B², 0, +2B², 0)`，總和 `0` |

⟹ 兩測度**類型唔同**（譜和 vs 維數），**冇 canonical 共同歸一化** ⟹ 對齊比較 **ill-defined**，
既**唔能證實亦唔能證偽** ⟹ **殘餘命題 = 需 `𝒯` 型別規則外之共同測度**（例如 `𝒯` 上之 action / trace）。

> **★ 最終裁定**：**🟡⁺（較前 🟡 前進一格）** —— 由「無 map」→「**群層 iso 已 exhibition**（canonical + 唯一）**且預註冊測試通過**」；
> 殘餘收窄為**單一、精確、良定義性缺口**：共同測度之存在性。**唔可**當 🟢（未到「結構強逼」）。
