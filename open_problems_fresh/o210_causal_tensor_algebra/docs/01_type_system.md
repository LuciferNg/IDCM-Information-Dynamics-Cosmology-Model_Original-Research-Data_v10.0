## 一、定位與原則

𝒯 = K_chain ⊗ K_tree 作為**有型別、運算封閉**嘅代數對象。型別系統嘅作用：

1. **消滅 category error**：88-L/176-L 指數混淆、Σγ_odd = 88 vs 44、λ_max 公式 γ₂₀ vs γ₄₀ — 全部由「人腦記」變成**型別檢查**。
2. **令「禁 ad hoc 常數」成為定義**（T0 標量判準）：冇算子身份嘅數字根本唔係代數嘅標量。
3. **為生成層（Phase 3）提供語言**：生成算子要用型別語言寫（SESSION_START §五）。

## 二、四型定義

| 型 | 記號 | 定義 | 例 |
|:---|:----:|:-----|:---|
| **算子** | `Op` | 載體空間上嘅線性映射（自伴隨/么正/冪等） | T̂, K_chain, K_tree, Ω̂, v̂_g, U, γ̂, P_world, P_CY, T_pipe, J² |
| **標量** | `Sc` | 泛函作用喺算子嘅**像**（帶域標籤） | Lₙ, γ₄₄=2, Σγ_even=90, 5940, 41/60, λ_max |
| **泛函** | `Fn` | Opⁿ → Sc 嘅映射 | Tr, Σ(譜和), det, dim, ⟨W|·|W⟩, E[φ], beat, 𝒫 |
| **指標** | `Ix` | 帶**指標集**嘅索引對象 | k∈I₈₈, n∈I₄₄, (a,b)∈Λ²(I₄₄), parity/mod-4 子集 |

**核心結構關係**：`Sc := Im(Fn|Op)` — 標量 = 泛函嘅像。呢個直接實現「數字是譜嘅陰影，唔係結構本身」。

## 三、基本型別規則（typing judgments）

```
Γ ⊢ e : τ   （喺環境 Γ 下，表達式 e 有型別 τ）

生成元:   ⊢ T̂ : Op, ⊢ K_chain : Op, ⊢ K_tree : Op,
          ⊢ Ω̂ : Op, ⊢ v̂_g : Op, ⊢ U : Op, ⊢ J² : Op
投影元:   ⊢ P_world : Op, ⊢ P_obs : Op, ⊢ P_CY : Op, ⊢ P₄₄ : Op, ⊢ T_pipe : Op
泛函:     ⊢ Tr : Fn, ⊢ Σ : Fn, ⊢ det : Fn, ⊢ dim : Fn,
          ⊢ ⟨W|·|W⟩ : Fn, ⊢ E[φ] : Fn, ⊢ beat : Fn, ⊢ 𝒫 : Fn
指標集:   ⊢ I₄₄ = {1..44}, ⊢ I₈₈ = {1..88}, ⊢ I₃₃ = {1..33},
          ⊢ Λ²(I₄₄) = {(a,b): 1≤a<b≤44}
```

**指標映射**（Ix → Ix，全部顯式）：
- `t₂ : I₄₄ → I₈₈`, n ↦ 2n（88-L → 176-L 平移）
- `parity : I₈₈ → {even, odd}`（世界/觀察者）
- `mod4 : I₈₈ → {0,1,2,3}`（扇區）
- `dual : I₈₈ → I₈₈`, k ↦ 88−k（Z₂ 對偶）

## 四、型別規則表（操作 × 型別簽名）

| 操作 | 型別簽名 | 產物型 |
|:-----|:---------|:------:|
| ⊗ 張量積 | Op × Op → Op；Ix × Ix → Ix | Op / Ix |
| ⊕ 直和 | Op × Op → Op（不相交不變子空間） | Op |
| Tr 跡 | Op → Sc | Sc |
| Spec 譜分解 | Op → (Sc-list × Op-list) | Sc-set × Op |
| Proj 投影 | Op → Op（P² = P） | Op |
| † 伴隨 | Op → Op | Op |
| Contr 收縮 | Op⊗Op → Op（部分跡）；Ix 求和 → Sc | Op / Sc |

**成員取值**：對角算子 γ̂ : Op 嘅成員 γ_k : Sc 由指標應用得出（k : I₈₈ ⊢ γ_k : Sc）。

## 五、T0 標量判準（Sc = Im(Fn)）

> **T0**: `s : Sc ⟺ ∃ A : Op, f : Fn: s = f(A)`。

**證明要點**：Sc 定義為泛函層嘅像 — 由構造，任何 Sc 值必須有產生佢嘅 (f, A) 對。反之，任何 f(A) 都係 Sc。所以 T0 係定義性（definitional），唔係經驗性。

**推論（反 ad hoc 規則 = 定義）**：
- 任何公式嘅常數，若冇 (f, A) 產生證明，**唔係 𝒯 嘅標量** — 唔准入公式。
- 例外只有**有量綱錨**（M₀, R_world, V_EW…）：按 O204/O73 維度定理，任何無量綱結構理論自由度 ≥ 1 — 錨係結構必然，標 🟡（`Sc_anchor`）。

**實例應用**（docs/04 重寫報告逐條執行）：
- `λ_max = 36 − 1/γ₄₀` : Sc ← (Spec∘1/γ̂)∘(CY₃) — 有產生對 🟢
- `283.0821`（O107 尾巴）: 冇 (f, A) → **唔係標量** 🔴 排除
- `44.5 = F₁₁/2` : 縫外冇角色 → 🔴 排除（O152 R13 一致）
- `M* 斜率 −0.9` : 宿主質量投影假象 → 🔴 排除

## 六、T-FIELD 域定理（R12 提升為型別規則）

> **T-FIELD**: 每個 Sc 值帶**域標籤** ∈ {Q, Q(√5), Q(ζ₈₈)⁺, Q(ζ₅₅)⁺, ℂ, trans, composite}。
> **Q = Q(√5) ∩ Q(ζ₈₈)⁺**（O152 R12，5 ∤ 88，deg 20）— 兩域只共享有理數。

**推論**：
1. **精確閉合必須 ∈ Q**：核心分數（41/60, 19/60, 123/176, 2/123…）全 ∈ Q，所以 dev = 0（scripts/01 Fraction 精確）。
2. **跨域等式結構上不可能**：φ-form（Q(√5)）等於 K_chain 譜值（Q(ζ₈₈)⁺）⇒ 必然近似 ⇒ φ-陷阱窗。
3. **扇區分離**：質量比 ∈ Q ∪ Q(√5)，混合角 ∈ Q(ζ₈₈)⁺（O155 T31 分工定理）。
4. `μ/e = (γ₇/γ₁)(F_μ/F_e)` 係**複合域**（Q(ζ₈₈)⁺ · Q(√5)）— 域定理管交集，唔管乘積，註冊表標 `composite`。

## 七、指標類型 — 殺死指數漂移

**規則**: 指標對象必須攜帶**指標集 + 約定**；冇標明指標集嘅 γ 係型別錯誤。

| 對象 | 正確型別 | 常見錯誤 |
|:-----|:---------|:---------|
| γ : I₈₈ (176-L) | `γ_k = 4sin²(kπ/176)`, k=1..88 | 同 88-L γ_n 混淆 |
| γ' : I₄₄ (88-L) | `γ_n = 4sin²(πn/88)`, n=1..44 | 同上 |
| parity(γ) : I₈₈ | even k → world (Σ=90); odd k → obs (Σ=88) | 用 0-indexed slice 誤標 "even" |
| parity(γ') : I₄₄ | even n → 46; odd n → 44 | 44/46 互換（已捕獲, 見 docs/03 C2） |
| λ_max 公式 | `36 − 1/γ₄₀`（γ₄₀ : I₈₈） | 寫 γ₂₀（I₄₄ 標籤漂移, 已修正） |

**捕獲實例**（scripts/01 G4, G12 實測）：
1. 44-site "even" 和 = 46（1-indexed even-n = k≡0 mod 4 = s0）— 0-indexed `γ[::2]` 揀中 odd-n → 44 誤標 "even"。憲章 C2 裁定。
2. `λ_max = 36 − 1/γ₂₀` 中 γ₂₀ 係 88-L；數值不變但標籤漂移。憲章 C2 改為 `γ₄₀^(176-L)`。
