## 2. IDCM 框架下的問題重構

### 2.1 核心張力

IDCM (v10.0) 係**無膨脹、無 Big Bang、無宇宙年齡**框架：
- z = 結構座標 ℓ = log₄(1+z)，唔係 lookback time
- τ = R_H/c = **13.4701 Gyr** = 渲染深度 (光行時間, 固定距離度量)
- T_sync = 2πτ = **84.6349 Gyr** (SYNC 週期, O39/O51 已閉合)
- t_true = N·T_sync + τ = 11,100.64 Gyr (N=131, O51)

**問題**: 「12.3 Gyr 前嘅合併」呢個時間標記喺 IDCM 點解讀？

### 2.2 三個可能讀法

| 讀法 | 內容 | 狀態 |
|:----:|:-----|:----:|
| A | 恆星年齡係框架無關觀測 (isochrone 物理)，IDCM 只需解釋「點解宇宙有咁老嘅星」 | 🟡 部分可行 |
| B | 合併「時間」= K_Chain 相位，12.3/10.5/6.0 Gyr = 結構時標嘅特定相位 | 🔴 無結構機制 |
| C | 合併歷史本身係 ΛCDM 詮釋，IDCM 用質量階梯 (M_d) 解釋「點解有呢啲合併」 | 🟡 質量階梯可行 |

## 7. 結論 (初步)

**IDCM 需要一個「星系合併/恆星年齡」嘅結構解釋** — 呢個係中小尺度自洽性嘅核心。目前狀態：

1. **✅ 質量階梯合併規則 (新發現)**: LKH/GSE/Sgr 全部 d≈4.4 級, MW 當時 d=4.08, 合併質量比 0.24 吻合論文 0.2-0.3。IDCM 質量階梯 (O32) 解釋「點解銀河系歷史有 3 個同質量細合併而冇大合併」— d=4 星系只吸收 d≈4.5-5 級系統。可證偽預測: MW 型星系唔會吸收 d=3 團級。
2. **🟢 M31 RAR 內圈成立**: R≤20 kpc χ²/dof ≈ 1.0 (零參數, baryon-only) — O32 RAR 延伸到大質量星系。外圈「23% 下跌」可能係 Zhang+2024 Jeans 方法特有 (Sofue 2015 只跌 10%)，需獨立測量。
3. **🟢 M31-MW 軌道週期 43.5 Gyr ≈ 0.51 T_sync** — 半週期巧合 (待確認結構意義)。
4. **🟢 合併時鐘候選閉合 (Gemini 方案 C 突破)**: 合併事件時間匹配 K_Chain 模式週期 T_n: LKH→n=7 (DM 模式, 0.7%), GSE→n=8 (2.1%), Sgr→n=15 (1.3%), M31 盤→n=15 (1.3%), M31 合併→n=11 (1.3%)。**n=15 喺兩個獨立星系命中** + n=15=7+8 和頻 (O54) → 6 事件 4 強命中 p≈2.8e-4。合併 = K_Chain 模式共振。需精密星流年齡確認。
5. **🔴 衛星系平面 (VPOS)**: 垂直 M31 連線假說否證 (64.3°)，13.5°=27/2 弱跡象，需 O57 投影數學。

**最重要嘅方法論教訓**: 唔好將 ΛCDM 嘅「12.3 Gyr ago」直接翻譯成 IDCM 嘅「12.3 Gyr 相位」— 合併時間應該對應 K_Chain 模式週期 (共振時標)，而質量軸由質量階梯提供。時間軸同質量軸都有結構: 質量 → d 級, 時間 → n 模式。呢個係 O60 最重要嘅結構閉合方向。
