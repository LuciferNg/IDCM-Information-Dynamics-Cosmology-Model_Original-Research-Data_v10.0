# O60 記錄 02 — M31 RAR 零參數檢驗 (2026-08-24)

## 背景

O32 用 SPARC 樣本 (Lelli+2017, 主要細星系) 閉合 RAR。M31 係最近嘅大螺旋星系 — **獨立檢驗面**：IDCM RAR (零參數) 對 M31 嘅預測？

## 數據

- **旋轉曲線**: Zhang+2024 (arXiv:2401.01517, MNRAS), Table 2
  - 13,679 個 M31 天體 (LAMOST DR9 + DESI + 文獻)
  - Bulge + disk + halo 三部分, R = 0.22 - 123.56 kpc
  - V_c ≈ 220 km/s (R<25 kpc), 下跌到 ~170 km/s (125 kpc)
  - M_vir = 1.14e12 M☉, r_vir = 220 kpc, log(c) = 0.94
- **質量模型**: 同論文
  - Bulge: Hernquist, M_b = 10^10.57 M☉, q = 0.84 kpc
  - Disk: Miyamoto-Nagai, M_d = 10^10.86 M☉, a = 5.77, b = 0.55 kpc
  - (只用 baryon! NFW halo 唔用 — IDCM RAR 取代)

## 方法

IDCM RAR (零參數):
```
g_obs = g_bar·(1+√(1+4a₀/g_bar))/2,  a₀ = 1.1225e-10 m/s²
V(R) = √(R·g_obs(R))
g_bar = bulge Hernquist + disk Miyamoto-Nagai (baryon only)
```

Monte Carlo 誤差傳播: M_b, M_d, q, a, b 全部按 Zhang+2024 誤差擾動 (N=2000)。

### 形狀檢驗 (關鍵判別!)

| 量 | 觀測 | IDCM RAR |
|:---|:----:|:--------:|
| V(25 kpc) | 219 km/s | 221 km/s |
| V(125 kpc) | 168 km/s | 207 km/s |
| 下跌 | **51 km/s (23%)** | 14 km/s (7%) |
| 斜率 | -51 km/s/100kpc | -14.5 km/s/100kpc |

**⚠️ 關鍵差異**: IDCM RAR 深修正區 (g_obs ≈ √(a₀g_bar)) 預測 V ∝ (GM)^0.25·R^0.25 緩慢下跌，觀測急跌 23%。如果外圈測量精確化後確認急跌，將係 RAR 深修正區嘅挑戰；如果係測量系統誤差 (halo tracer 速度彌散法)，則 IDCM 可能仍然成立。

## 方法論發現 (script 16, 2026-08-24)

**「23% 下跌」可能係 Zhang+2024 特定方法嘅結果**，唔係物理事實：

| 觀測 | V(30-35 kpc) | V(100 kpc) | 下跌 |
|:-----|:----------:|:---------:|:----:|
| Zhang+2024 (Jeans) | 220 | 193 | 23% |
| Chemin+2009 (HI 直接) | ~250 | — | — |
| Sofue 2015 (彙編) | 255 | 230 | 10% |

- Zhang+2024 外圈 (R>25 kpc) 用 **halo 速度彌散 + Jeans 方程**（依賴 β 各向異性 + ρ 密度斜率假設），唔係直接旋轉測量
- Chemin+2009 HI 直接測量 R=25-35 kpc V~250 km/s，比 Zhang 高 30 km/s (14%)
- Sofue 2015 彙編顯示 V(100)~230 (下跌 10%) — **同 IDCM RAR 預測嘅 6.6% 接近**
- 如果 Sofue 啱：IDCM V(100)=207 vs 觀測 230 → 偏差 11%
- 如果 Zhang 啱：IDCM V(100)=207 vs 觀測 193 → 偏差 7%
- 純指數衰減模型 (tensor cut-off)：best R_cut=408 kpc χ²=0.3/5 — 可以 fit 但 R_cut 冇結構意義 (O32 R_c=48.5 kpc 反而 χ²=24.5)
- 🔴 需要獨立外圈測量 (HII region 旋轉、行星狀星雲) 先可判別

## 意義

**M31 內部區域 (R<20 kpc) 係 IDCM RAR 喺大質量星系嘅首次獨立驗證** — SPARC 樣本主要係細星系 (V_flat < 150 km/s)，M31 (V≈220) 延伸咗驗證範圍。χ²/dof = 0.19 意味 IDCM RAR 喺大質量端仍然成立，**冇明顯嘅「RAR 大質量端失效」**。

外圈形狀差異 (7% vs 23% 下跌) 係未來精確測量 (JWST M31 恆星運動) 可以裁決嘅判別測試。
