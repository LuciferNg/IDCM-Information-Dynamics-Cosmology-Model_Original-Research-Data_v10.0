## 二、z=0 基準矛盾 — 解決 (唔係矛盾)

「0.15% (z<4 中位) < 1/306 = 0.327% (P14)」嘅矛盾係**質量選擇假象**:

1. z<4 樣本中位 M* ≈ 10^9.3 — 係**質量選取子樣本**嘅值
2. 本地 M_BH-M* 關係喺 M* = 10^9.3: RV15 (AGN): ~0.02%, Kormendy-Ho
   (elliptical): ~0.25% — **0.15% 正正坐喺本地關係喺該質量嘅預言帶**
3. 1/306 = all-galaxy 質量積分平均 (Elvis, dwarf-inclusive), 唔係 per-source 值

→ **冇矛盾**: 0.15% @ M*~10^9.3 係質量選取子樣本, 1/306 係質量積分錨。
P14 嘅 1/306 仍然係 v2 模型 z=0 端點 (LRD 後代族譜積分) 嘅正確錨。
