## 3. 重尾候選: logN (ln(1+δ) 空間)

```

UHz1: ln(1+91.4) = 4.526 → 距中位 (4.526−0.862)/s σ
  s=1.0: 3.66σ → P(1e6 事件) ~ 124 個    s=1.5: 2.44σ → ~7e3 個
  s=2.0: 1.83σ → ~3.4e4 個
→ s ∈ [1.2, 2] 使 UHz1 成為 1e-6..1e-4 尾事件 (viable)
```

- 種子質量譜 (δ_env 部分): ln M_seed = ln M_base + 1.5·ln(1+δ)
  → log-normal, σ_lnM = 1.5s ∈ [1.8, 3] → **σ_dex ∈ [0.78, 1.3]**

  −0.5 至 −1.0 (種子譜層面; 觀測 BHMF 高端 −2~−3 由吸積/合併塑造, 唔係種子譜)
