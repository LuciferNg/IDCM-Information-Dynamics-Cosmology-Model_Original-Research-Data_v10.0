## 四、R4 arcsine[0,4] 整數序列閉式 (scripts/02 W06-W07 ✅)

```
κ_{2m} = (2m)!·2^{2m}·(−1)^{m+1}·σ_m/m,   σ_m = Σ_{k≥1} j_{0,k}^{−2m}  (Rayleigh sum)
生成函數: Σ_{m≥1} σ_m z^{2m−2} = J₁(z)/(2z·J₀(z))   (Bessel 比, W07 m=1..8 ✅)
```

- σ_m 有理數: 1/4, 1/32, 1/192, 11/12288, 19/122880, 473/17694720, 229/49545216, ...

## 五、R5 EFT 翻譯閉合 (scripts/02 W09-W10 ✅)

**邊界有效作用量 = 邊界自由能差 (β-domain 對偶, dev < 1e-51)**:

```
ΔK(−β) = ln[1 + δ(−β)] = ln[1 − sinh(2β)/(88·I₀(2β))] = ln(Z_N(β)/Z_arc(β))
```

- Z_N(β) = e^{−2β}[88·I₀(2β) − sinh(2β)] (O193 docs/02 E-M 修正閉式)
- Z_arc(β) = 88·e^{−2β}·I₀(2β) (觀察者 sector = arcsine MGF, O193 docs/02 §四)
- ⟹ ln Z_N = ln Z_arc + ΔK(−β): **全鏈自由能 = 觀察者自由能 + 邊界修正** —
  ΔK(t) 喺 β-domain 就係自由能差, 唔係新作用量, 係 partition function 比率嘅 log。
- 機制: δ(−t) = −δ(t) (sinh 奇, I₀ 偶) — t→−β 對偶係代數恆等 (W09 ✅)。
- 數值: β = 0.05..3, dev 0..1.4e-51 (W10 ✅)。
- 呢個閉合 SESSION_START 開放項 3 (ΔK EFT 翻譯 ↔ O193 β-domain 對偶):
  「邊界有效作用量」嘅正確理解 = ln(Z_N/Z_arc) — 唔係額外 Lagrangian,
