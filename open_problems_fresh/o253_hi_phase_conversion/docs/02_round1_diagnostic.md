## 五 ★ 今輪真結構結果：轉換效率嘅允許形式被量綱鎖死

```
ε_HI ≡ CSFRD/ρ_HI        [量綱 = 1/time]
IDCM 譜泛函（γ_n、N_d、B、L_k…）全部無量綱   [O201 ⑨ 維度論證]
⟹ 任何 IDCM 率量必須 = (無量綱結構係數) × (單一率錨)
⟹ ε_HI = n_struct × ω_ring ,  ω_ring = 2π/T_ring = 0.0742369 /Gyr
```

**形式 ✅ 鎖死**（零自由形狀參數）；**係數 🔴 未識別**：

```
n_struct = ε_HI/ω_ring = 3.1028     帶 [2.5856, 3.8785]（τ_dep ±20%）
帶內預註冊候選 8/20：3(=N_gen)、π、φ²、11/4、e、16/5、22/7、19/6
分開 N_gen=3 與 π=3.1416 需 τ_dep 精度 < 2.36%；現 ~20%（差 8.5×）
```

**★ 常數分支被觀測證偽**：若 n_struct 無 z 依賴，則 SFRD 跌幅 = Ω_HI 跌幅 = 1.35；
實測 **2.46** ⟹ 超出 **82%（raw）／120%（corr）**。所以：

```
缺口 = n_struct 為何隨宇宙時間跌 1.822 (raw) / 2.196 (corr)？
       若冪律形式 n ∝ (1+z)^k，k = 1.751 (raw) / 2.295 (corr)
```

呢個係**無量綱目標**——正正係 IDCM 嘅母語。文章嘅「效率瓶頸」翻譯成 IDCM 語言之後，
唔再係「氣體物理」，而係「**轉換算子係數嘅宇宙學演化**」。呢點係 round 2 嘅攻擊核心。
