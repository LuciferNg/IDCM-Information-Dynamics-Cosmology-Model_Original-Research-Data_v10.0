## 四 為何係 no-go（三條邏輯閘）

```
閘1  𝒯 譜泛函全部無量綱且 z-無關：譜只依 (B, N_d, 站數)，冇時間變量
     ⟹ 任何純譜泛函必然給出常數係數 ⟹ 已被 R1 D5 證偽（需要 1.82 演化）
閘2  任何 z 依賴只可能來自兩種結構物件：
     (i) 幾何 N(z) ∝ 4^-ℓ（P1）   (ii) 環相位 t/T_ring
     ⟹ 兩者都已枚舉（Z1–Z4），0/10 合格 ⟹ 此路封閉
閘3  ⟹ n_struct(z) 必須來自**第三種**物件：佔據數／相空間（放熱通道）
     而 𝒯 係譜代數，冇溫度、冇佔據、冇放熱 ⟹ 物件不存在
```

**所以 G1（相變算子缺席）由「斷言」升級為「已證」**：唔係未搵到，係代數內冇呢個自由度。
