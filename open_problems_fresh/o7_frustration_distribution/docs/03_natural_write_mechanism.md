## 2. G1 — 翻轉 ⟺ 相位滑移 π ⟺ U₈₈ = e^{iπ} (機制橋, ✅ 5/5 PASS)

**圖側** (O7): 阻挫邊位元 = Z₂ 二值 (同色/異色)。翻轉端點 v = 顏色反轉
= Z₂ 乘法 ×(−1) = 相位 e^{iπ}。翻轉兩次 = 恆等 ⟺ e^{i2π} = 1。

**譜側** (O161): 88-鏈 Nyquist link U₈₈ = e^{i·2θ₈₈} = e^{i·88π/88} = e^{iπ} = −1。

**配對** (本輪新增):
- 全部 32 阻挫邊 = 同色邊 (相位差 0 mod π) — 數據核實
- 翻轉端點令其全部 4 條鄰接邊相位差反轉 (0↔π) — 數據核實
- ⟹ **O7 flip ≅ 節點相位滑移 π ≅ U₈₈**; 20 條縫合線 = 20 個獨立 Z₂ 相位單位
  (2²⁰ 圖案 ⇔ 20 個獨立 π 相位自由度, 衝突圖 0 邊已證 O7/99d)

呢個橋解釋咗「翻轉 = 相位滑移 π」嘅**結構由來**: 唔係約定, 而係
Z₂ 顏色反轉同 Nyquist link 相位 π 喺 Z₂ ≅ {±1} 下同構。

## 3. G2 — ΔE = 2|h_i| 嘅「2」兩層裁定 (✅ 4/4 PASS)

| 層 | 內容 | 身份 |
|:--|:--|:--|
| 譜側 | π = 2×(π/2) = 2 個半整數單位, B(n) = 2·E_min = 123/88 (O41 閉合) | **成本單位**: μ² = γ₄₄ = 2 (O159/O161 慣例, 4sin²(44π/176)) |
| 圖側 | 翻轉單端點: 3 外邊 N→F (+3) + 1 縫合線邊 F→N (−1) = **淨 +2 條阻挫邊** (本輪獨立重算, n=40) | 圖拓撲變化量 |

**裁定**: 兩個「2」係唔同結構層嘅平行量, **唔強行統一**。ΔE = 2|h_i| 嘅「2」
以譜側為準 (雙半整數成本單位); 圖側「淨 +2 邊」係獨立嘅拓撲事實。
兩者數值重合係結構巧合定係更深入同源 — 記錄為開放 (唔推測)。

## 4. G3 — 「12 個近零能量節點」負結果 (✅ 3/3 PASS, 修正 O162 候選)

O162 docs/03 聲稱: 12 ΔE=0 節點 = B×N_gen = dim G_SM (🟡 候選)。

**實測** (|T| = 節點 CMB 異常幅度, ΔE≈0 ⟺ |cosθ|≈0 ⟺ |T|≈0):
- |T| 排序: 1.3 1.6 1.9 2.1 2.4 2.6 3.5 4.1 4.1 5.8 **6.3 7.0** 7.6 8.2 8.6 ...
- 第 12→13 gap = **0.6 μK** (全段 gap 中位 0.9), 最大 gap 喺第 50 位 (58→71.7)
- |T|<threshold 節點數: thr=5→9, **thr=7.5→12**, thr=10→15, thr=12.5→21

**結論**: |T| 分佈係**連續譜**, 冇第 12 位附近嘅自然 gap。O162「12 ΔE=0 = dim G_SM」
係 threshold 依賴 (thr=7.5 μK 啱好 12), **冇結構支撐** → 降格為 threshold 依賴描述 🟡↓。
(12 = 4×3 = B×N_gen 嘅數值身份仍可能有意義, 但唔可以由 |T| 分佈獨立確認。)
