## 二、第一原理推導

### 步驟 1: κ 閾值決定可見模式數

從 W-field Higgs portal 質量公式：

$$m_n = (\kappa - e^{-n}) \cdot v_{EW} \cdot e^{-n}$$

- $\kappa = 1/16 = B^{-2}$（結構常數）
- $e^{-n}$ 是模式振幅（K_Tree RG 流）

當 $e^{-n} > \kappa$ 時，$m_n^2 < 0$ → 模式在 Higgs portal 中呈**快子不穩定** → 與 Higgs 混合 → 耦合到 SM → **可見**。

當 $e^{-n} < \kappa$ 時，$m_n^2 > 0$ → 模式穩定 → **隱藏（DM）**。

閾值條件：$e^{-n} = \kappa = 1/16 \implies n = -\ln(1/16) = \ln(16) = 2.7726$

**∴ 可見模式：n = 0, 1, 2（3 個模式）**
**隱藏模式：n ≥ 3（所有高階模式）**

這 3 個可見模式對應 3 個世代。**不是「3 世代 = 3 對」，而是 κ 閾值自然給出 3 個可見模式。**

### 步驟 2: Coxeter 配對能量

K_Chain 的 Coxeter 對稱性：

$$\gamma_n + \gamma_{44-n} = 4\sin^2(\pi n/88) + 4\sin^2(\pi(44-n)/88) = 4 = B$$

每個互補配對 (n, 44-n) 有總能量 $B = 4$，這是數學定理，不是假設。

### 步驟 3: 可見能量 = 世代數 × 配對能量

每對 (n, 44-n) 對應一個 Dirac 世代（Doc 07）。3 個可見模式（n=0,1,2）形成 3 對 → 3 世代。

每對能量 = B = 4。可見能量 = 3 × 4 = 12。

**這裡的關鍵假設**：配對的總能量 B 全部用於可見物質。這基於 Coxeter 恆等式 $\gamma_n + \gamma_{44-n} = 4$ 是精確等式，不是上界。配對的能量要麼全部可見（如果該對耦合到 SM），要麼全部隱藏。

### 步驟 4: 總能量

K_Chain 44-site 的總能量：

$$\Sigma\gamma = \sum_{n=1}^{44} 4\sin^2(\pi n/88) = 90$$

這是三角恆等式，與 K_Chain 結構綁定。

### 步驟 5: 暗能量

$$\text{暗能量} = \Sigma\gamma - \text{可見能量} = 90 - 12 = 78$$

### 步驟 6: 比值

$$\frac{\Omega_{DM}}{\Omega_b} = \frac{78}{12} = 6.5$$

### 步驟 7: 轉移矩陣形式（純結構表達）

用轉移矩陣不變量表達：

- $\Sigma\gamma = 90 = 2N_d + L_0 = 2\cdot44 + 2$
- $N_{gen} \cdot B = 12 = L_5 + 1 = 11 + 1$

所以：

$$\frac{\Omega_{DM}}{\Omega_b} = \frac{2N_d + L_0}{L_5 + 1} - 1 = \frac{90}{12} - 1 = 6.5$$

**這是最終結構形式。** 所有數字（2, 44, 11, 1）都來自轉移矩陣 $\hat{T} = [[1,1],[1,0]]$ 的譜跡或矩陣元。

## 三、13 和 2 的真相

**13 和 2 沒有結構意義。**

6.5 = 78/12。78 和 12 的最大公因數是 6 = 2×3 = L₀ × N_gen。約分後得 13/2。

- 13 只是 (Σγ - N_gen·B)/6 = 78/6 = 13
- 2 只是 (N_gen·B)/6 = 12/6 = 2

**把 13 叫做 F₇、把 2 叫做 L₀ 是對真相的偽裝。** 這不是結構推導，這是把計算結果貼上預先存在的 Fibonacci/Lucas 標籤。

**真正結構的比值是：**

$$\frac{\Omega_{DM}}{\Omega_b} = \frac{\Sigma\gamma - N_{gen}\cdot B}{N_{gen}\cdot B} = \frac{90 - 12}{12} = 6.5$$

或者用轉移矩陣：

$$\frac{\Omega_{DM}}{\Omega_b} = \frac{2N_d + L_0}{L_5 + 1} - 1 = 6.5$$
