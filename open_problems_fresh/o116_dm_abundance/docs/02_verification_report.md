## 2. 核心發現

### 2.1 v9.0 推導路徑

```
K_Chain 44-site Σγ = 90
├── 3 配對 → SM (可見) → 12 單位
└── 18 配對 + Nyquist + 零模 → DM → 78 單位
→ R_DM = 78/12 = 6.5

CY₃ 投影精確化:
P_n = 1 + 2φ⁻¹ × n + K₂ × n²
K₂ = 2·(h²¹-h¹¹)/h²¹ - 2φ⁻¹ = 0.029238
```
