## 問題

群延遲修正 (C = −0.16973, 0.02%) 將 DESI DR2 χ² 從 42.23 降到 18.09/7，但 χ²/dof = 2.58 仍高於 1.0。
LRG1 (z=0.51, ℓ=0.30) 是最大離群點 (偏差 −4.8%)，靠近 SYNC 轉折點 (z_c = 0.6 = F₄/F₅)。
立方項修正 δ₃(ℓ) = C₃×(ℓ−0.5)³×(1−4^−ℓ) 已被測試並失敗。

**開放問題（原 4 項）**: ① SYNC 轉折點附近是否需局部阻抗修正？ ② LRG1 離群是否反映 K_Chain 模式 n=2 (SYNC) 激活？
③ 修正形式是否應分段？ ④ 是否需考慮每模式激活時的阻抗不匹配？

## 閉合結論 (2026-09-26)

**整個前提係假象。** 精確複現原值 `χ² = 18.092/7`（χ²/dof = 2.58）後，用**同一組 7 點**、只換上現行定律：

- **7 點**: `18.092/7` → **`1.7154/7` (0.245)** — 改善 **10.5×**，全部 pull ≤ 1σ
- **D_M/rd (6 bin)**: `27.164/6` → **`2.4528/6`**（O169 修正定律）
- **D_H/rd (6 bin)**: → **`3.4712/6`**（O170 arch 核 `M(ℓ) = sec(π·n_c/88)`, `n_c = N_d/2 + B·sin(πℓ)|N_d/2`）
- **12 點聯合（含 ρ）**: → **`6.8591/12` (0.572)**
- **LRG1**: −4.56% (−3.71σ) → **−1.15% (−0.93σ)** ⟹ 非離群，係證偽定律之假象
- **Lyα (z=2.33)**: +300.08σ → **−0.30σ**（6 bin 中第二好嘅點）
- **SYNC 局部修正**: 自由雙參數掃描 Δχ² = **0.639**（2 dof）⟹ **統計上唔被要求**

**三重污染**: (i) 伸長定律 `E = 1 + 2φ⁻¹ℓ` 已由 O169 證偽（DESI DR2 D_M×6 排除 **4.88σ**）；
(ii) 群延遲 `C₁ = −0.16973` 已由 O169 證偽；(iii) `D_H = dD_app/dz`（ΛCDM 關係）已由 O117 判定 IDCM 唔成立 —
前提嘅 2 個 D_V 點（BGS/QSO）正正用咗呢條錯式。

**立方項失敗之詮釋反轉**: 非「修正形式唔啱」，而係「冇殘差可修」（「無效才是正確」之又一例證）。
**§開放問題 1–4 全部自動消解。** 唔開新 O、唔做局部阻抗模型、唔搬遷 v9.0 SYNC 系列。
