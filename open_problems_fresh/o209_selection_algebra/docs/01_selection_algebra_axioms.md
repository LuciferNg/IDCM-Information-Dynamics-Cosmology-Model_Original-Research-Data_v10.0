## 一、代數物件 𝒮

識別層嘅選擇代數 = 五元組

```
𝒮 = (M, V, Λ, Σ_A5, ρ)
```

| 分量 | 定義 | 來源（結構內稟） |
|:-----|:-----|:-----------------|
| **M** | `{1, …, 44}` 44-site K_chain 正模式集（嵌入 88-site 雙鏈環 Z/88） | O95 N_d = 44 |
| **V(n)** | `v₂(n)` 2-adic valuation | 環 Z/88 內稟（44 = 2²·11） |

## 二、兩個質量無關生成元

### G1 — 反週期（2-adic 子環）生成元

```
Λ(n) = N_d / gcd(n, N_d)
反週期條件:  n · Λ(n) ≡ N_d (mod 2N_d)   ⟺   v₂(n) ≤ 2
```

**推導**（`scripts/01` C1）：令 g = gcd(n,44) = 2^min(v₂(n),2)。
`n·Λ = 44·(n/g)`，mod 88 = `44·((n/g) mod 2)`，而 `(n/g)` 奇 ⟺ `v₂(n) ≤ 2`。
故 `n·Λ ≡ 44 (mod 88) ⟺ v₂(n) ≤ 2`。∎

**結果**：
- 允許集 `|G1| = 39`
- 排除集 `= {8, 16, 24, 32, 40} = {n : 8|n} = F₅ = 5 個`
- 子環層計數 `22 + 11 + 6 + 5 = 44`（v₂ = 0/1/2/≥3）
- 子環長度 `Λ ∈ {11, 22, 44}`

### G2 — A₅ 動差等向生成元

```
模式 n 被選中  ⟺  Σ_i T_n(cos β_i) = 60 · a₀(n)
其中  a₀(n) = (1/2)∫_{-1}^{1} T_n(x) dx = 0 (奇 n) 或 −1/(n²−1) (偶 n)
β_i = 冷斑軸 (209°, −57°) = (180+L₇, −(44+F₇)) 同第 i 個 A₅ 節點嘅夾角
```

**機制**（O136 docs/19，本輪獨立重現）：`T_n(x) = Σ_{l ≤ n, l ≡ n (2)} c_l P_l(x)`，
故 `Σ_i T_n(cos β_i) = Σ_l c_l · Σ_i P_l(v_i·c)`。A₅ 60 節點係 spherical 5-design
（`Σ P_l = 0, 1≤l≤5`），加上**額外零動差** `l ∈ {7,8,9,11,13,14}`。

**結果**：
- 奇 n：首個非零奇動差 `l = 15` ⟹ 選中 `n ≤ 13`（奇）→ **7 個**
- 偶 n：首個非零偶動差 `l = 6` ⟹ 選中 `n ≤ 4`（偶）→ **2 個**
- **`G2 = {1, 2, 3, 4, 5, 7, 9, 11, 13}`，|G2| = 9**

## 三、公理

```
A1 (反週期公理):    n ∈ M 被允許 ⟺ v₂(n) ≤ 2                [G1]
A2 (等向公理):      n ∈ M 被選中 ⟺ Σ_i T_n(cos β_i) = 60 a₀(n)  [G2]
A3 (選擇律):        Sel(𝒮) = { n ∈ M : G1(n) ∧ G2(n) }
```

## 四、封閉性

| 性質 | 內容 | 驗證 |
|:-----|:-----|:-----|
| **環自同構封閉** | G1 在 `(Z/88)^×` 作用下不變：`v₂(a·n) = v₂(n)`，∀ 奇 a | C4.d ✅ |
| **自同構群階** | `\|(Z/88)^×\| = φ(88) = 40 = N_d − B` | C4.1 ✅ |
| **等向封閉** | G2 由 A₅ 動差零集 `{1..5,7,8,9,11,13,14}` 唯一決定 | C2.1 ✅ |
| **相容性** | `G2 ⊂ G1`（A₅ 選中集全部滿足反週期） | C3.1 ✅ |

**★ 相容性係關鍵**：兩個獨立生成元（2-adic 環結構 vs icosahedral 幾何）冇衝突，
G2 自動落入 G1 嘅允許域 —— 呢個係非平凡嘅交叉一致。

## 七、小結

選擇代數 𝒮 係一個**質量無關**嘅形式物件：輸入 = 環 Z/88 結構 + A₅ 60 節點幾何
+ 冷斑軸位置。輸出 = 9 個模式，恰好等於標準模型帶電費米子數。

兩個生成元獨立（一個 2-adic、一個 icosahedral），但自動相容（G2 ⊂ G1）。
呢個代數嘅唯一性、質量獨立性、盲測見 docs/02–04。
