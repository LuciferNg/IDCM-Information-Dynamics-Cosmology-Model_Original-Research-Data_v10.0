## 一、框架修正 — 中微子唔係「3 個鏈模式」

docs/04 §四 嘅缺口陳述有**框架錯配**。追查 repo 現狀（O57/O49 已閉合）：

```
O57 docs/09 §2.2:  m_ν = (γ₆ × v)²/M_comp,  γ₆ = 4sin²(6π/88) = 0.180736 (K_Chain n=6)
O49 docs/09 §一:   中微子 = W-field mode 6 凝聚 (dim-5 Weinberg, Majorana)
                   → 3 世代 = 1 個主凝聚 (mode 6) + 2 個能隙干涉束縛態
```

**★ 修正**：中微子扇區**唔係 3 個鏈模式**，而係
**1 個鏈模式（n = 6）+ 2 個能隙束縛態（連續內插值，唔對應整數 mode）**。

```
m₃ = γ₆²·A                                    ← mode 6 主凝聚 (整數)
m₁ = [γ₄ + Δ·cos(π/4)]²·A                     ← hop 干涉分裂態 (γ₄,γ₅ 之間內插)
m₂ = [γ₄ + Δ·cos(π/5)]²·A                     ← 五邊形分裂態
Δ = γ₅ − γ₄ = 4sin(9π/88)sin(π/88)  (9 = N_gen²)
```

所以「3 個模式未被 𝒮 選出」呢個講法本身唔成立 —— 𝒮 選**鏈模式**，
中微子扇區只有 **1 個鏈模式**。

## 二、★★ 結構分區定理

### 2.1 G2 嘅「閾值」結構

G2（A₅ 動差等向）嘅準則係 `Σ_i T_n(cos β_i) = 60·a₀(n)`。
用 Legendre 展開 `T_n = Σ_{l ≤ n, l ≡ n (2)} c_l P_l`：

```
模式 n 過 G2  ⟺  l ≤ n 嘅同奇偶 A₅ 動差全部係零 (或貢獻 a₀)
             ⟺  n < l_first(parity(n))

其中 (scripts/05 C1, C5):
  l_first(even) = 6     (首個非零偶動差)
  l_first(odd)  = 15    (首個非零奇動差)
```

### 2.2 ★ 三個等價刻劃（全部 = 6）

```
n_ν = min{ n ∈ M : ¬G2(n) }        (首個 A₅ 破缺模式)
    = l_first(even)                 (首個非零偶動差度數)
    = 6                             (scripts/05 C1.3)
```

### 2.3 分區

```
𝒮 分區 (scripts/05 C2.5):
  |G1| = 39
  ├─ G1 ∧ G2      = 9  → 帶電費米子 (A₅ 保護)   Sel(𝒮) = {1,2,3,4,5,7,9,11,13}
  └─ G1 ∧ ¬G2     = 30 → 非帶電扇區
       └─ 閾值     = 6  → 中微子 (A₅ 敏感 → seesaw 壓低)
```

**★ 物理讀法**：
- **帶電費米子** = A₅ 各向同性模式（受 icosahedral 對稱保護）
- **中微子** = A₅ **破缺閾值**模式（感受對稱破缺 → 質量被 seesaw 壓低至 ~0.05 eV）

呢個解釋咗**為何中微子質量咁細**：佢係唯一「睇到」A₅ 各向異性嘅鏈模式。

## 四、⚠️ 已證偽嘅候選（誠實記錄）

測試過一個候選刻劃：**「中微子 = A₅ 破缺強度最大嘅模式」**
（δ_n = |Σ T_n − 60 a₀(n)|）。

```
scripts/05 C4:
  δ₂ = 0.000009, δ₄ = 0.000005      (G2 通過 ⟹ 冇破缺) ✅
  δ₆ = 1.936684                      (閾值)
  δ₈ = 1.032894,  δ₁₀ = 0.493118
  δ₁₂ = 16.937205  ← 最大!          (> δ₆)
  δ₁₄ = 8.321652, δ₁₆ = 2.129713, ...

🔴 「最大破缺」假說證偽: argmax = 12 ≠ 6, 且 δ 非單調
```

**裁決**：選擇準則係 **【閾值】**（首個破缺）而**唔係【強度】**（最大破缺）。
呢個係重要區分 —— 避免將「第一個」誤讀成「最強」。
