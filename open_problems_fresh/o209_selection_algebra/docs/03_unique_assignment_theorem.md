## 四、分配唯一性（`scripts/03` §C2）

對唯一模式集，窮舉全部 `9! = 362,880` 個雙射。

**評分**：冪律 `ln m = α·ln|Δm| + β` 嘅 RMS。
**閉式**：對單調無關變量，`RMS = std(ln m)·√(1 − corr²)`
⟹ **最小化 RMS ⟺ 最大化 |corr|**（可完全向量化，唔需 362880 次 lstsq）。

**★ Δm 定義源頭**（O136 `scripts/63` 權威）：`|Δm_n| = Σ_{m=1}^{88}|V_nm|²/(E_n−E_m)`，
掃描**全部 88 個模式**（唔係 44）；退化對 `a+b=88`（`E_a=E_b`）以 `1/d → 0`
（`|d|<1e-12`）處理。此慣例下 `|dm_1| = 16862.478721`、`|dm_13| = 152.535542`
精確重現 docs/33 表（dev < 1e-6）。

| 量 | 值 |
|:---|:---|
| 雙射數 | 362,880 |
| 最小 RMS | **0.587228** |

| 單調配對 RMS | 0.587228 |
| corr(ln\|Δm\|, ln m) | 0.988353 |
