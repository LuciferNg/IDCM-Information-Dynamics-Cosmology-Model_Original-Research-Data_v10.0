### 2.3 密度基準（兩種 null 配對）

**⚠️ 關鍵方法論**：null test 必須用同觀測**同樣嘅自由度**（最優配對），
唔可以只用單調配對 —— 否則低估 null 能力、高估顯著性。

| null 型 | d_obs | d_med | q_obs | 判定 |
|:--------|:-----:|:-----:|:-----:|:----:|
| 單調配對（低估 null） | 0.5872 | 3.6590 | 0.00% | 🟢（**過度樂觀，唔採用**） |
| **最優配對（匈牙利法）** | 0.5872 | **1.2329** | **1.60%** | 🟡 **採用** |

```
N_search = 1   (選擇代數唯一選集，質量無關)
N_mc     = 2000,  seed = 20260924
d_obs    = 0.5872
d_med    = 1.2329  (最優配對 null 中位)
q_obs    = 1.60%   → 🟡
```

**★ 與 O136 docs/33 交叉**：docs/33 報最優配對 null `P = 0.0155`（1.55%）。
本輪 **1.60%**（MC 2000）—— 幾乎完全一致，兩條獨立路徑互相驗證。

**★ Δm 定義源頭核對**：`|Δm_n| = Σ_{m=1}^{88} |V_nm|²/(E_n−E_m)` 掃描**全部 88 個模式**
（O136 `scripts/63` 權威定義），唔係 44 個。退化對 `a+b=88`（`E_a = E_b`）用
`1/d → 0`（`|d| < 1e-12`）處理。此慣例下 `|Δm_1| = 16862.478721`、
`|Δm_13| = 152.535542` 精確重現 docs/33 表（dev < 1e-6）。
