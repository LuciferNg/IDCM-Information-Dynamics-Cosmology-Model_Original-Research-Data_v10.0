## 二. 主結果 — 閾值定理

**定理 (選擇閾值).** 設 A₅ 節點集 = 冷斑軸 (±(209°, −57°)) 對應之 60 個二十面體節點。
對模式 n ∈ [1, 44]，

```
G2(n)  ⟺  n < l_first(parity(n))
```

其中 `l_first(even) = 6`，`l_first(odd) = 15`。故

```
Sel(𝒮) = {odd n < 15} ∪ {even n < 6}
       = {1,3,5,7,9,11,13} ∪ {2,4}
       = {1,2,3,4,5,7,9,11,13}   (9 模式 = 3 輕子 + 6 夸克)
```

驗證：`scripts/07` C5 — 閾值預言 = G2 直算 = **EXACT**（400 條隨機軸全部一致）。

### 證明骨架

1. `T_n(cos β) = cos(nβ) = Σ_{l ≤ n, l ≡ n (2)} c_l P_l(cos β)`（Chebyshev 展成 Legendre）。
2. 故 `Σ_i T_n(u_i·c) = Σ_l c_l M_l(c)`，其中 `M_l(c) = Σ_i P_l(u_i·c)` 係 **A₅-不變諧和多項式**（degree l）。
3. `M_l ≡ 0` 除非 l 落入二十面體諧和度集 S（見第三節）。
4. 對奇 n：G2 要求 `Σ T_n = 0`。因 `{M_l : l ∈ S}` 係線性獨立多項式、且 `c_l ≠ 0`，
   `Σ = 0` ⟺ `S ∩ {1..n} 冇奇元素` ⟺ `n < 15`。
5. 對偶 n：G2 要求 `Σ T_n = 60·a₀(n)`。減去連續球面平均值後，條件等價於
   `Σ_{l 偶, 2 ≤ l ≤ n} c_l M_l(c) = 0` ⟺ `n < 6`。
   （關鍵：`(1/2)∫_{-1}^{1} P_l = δ_{l0}`，故連續平均值只留 l=0 項，而 `a₀(n) = (1/2)∫ T_n` 正好係球面平均。）

## 三. 群論基礎 — 二十面體不變量環（本 O 獨立重推）

`M_l(c)` 係 A₅-不變、degree-l 諧和多項式。**本節唔引用文獻，直接由 60 節點集反推**
（`scripts/09_a5_invariant_ring.py` → **21/21 PASS**）：

### (a) 對稱群由節點集反推

揀 3 個線性獨立節點做參考基，枚舉全部保集正交映射 ⟹

```
|G| = 60,  全部 det = +1 (G ⊂ SO(3)),  階分佈 (1, 15, 20, 24)
```

`(1,15,20,24)` = A₅ 之 id / order-2 / order-3 / order-5 特徵分佈 ⟹ **G ≅ A₅**（非 I_h）。
**冇 −I**（min tr = −1）⟹ 節點集非中心對稱 ⟹ 奇動差可以非零（同 §二 一致）。

> ⚠️ 座標檔四捨五入到 1e−4 度 ⟹ Gram 偏差 ~7e−6，枚舉容差必須 ≥ 1e−5（用 1e−9 會
> 只搵到 4 個元素，誤判群階）。

### (b) Molien 級數

對 rotation `g`（`tr g = a`）：`det(I − t g) = (1−t)(1−2t cosθ+t²) = 1 − a t + a t² − t³`
（3×3 之主 2×2 子式之和 `= tr(g^{-T}) = tr g`）。故

```
P(t) = (1/|G|) Σ_g 1/det(I − t g) = (1 + t¹⁵) / ((1−t²)(1−t⁶)(1−t¹⁰))
```

數值殘差 **4.3e−5**（座標捨入級）。⟹ **primary degrees {2, 6, 10}**、**skew degree 15**，
且 `2·6·10 = 120 = 2|A₅|`。

### (c) 諧和譜 = 自由模（修正 §〇 舊寫法）

諧和不變量之 Poincaré 級數 = `(1−t²)P(t) = (1+t¹⁵)/((1−t⁶)(1−t¹⁰))`
⟹ 諧和不變量 = **自由模** over `C[σ₆, σ₁₀]`，生成元 `{1, skew₁₅}`：

```
S = ⟨6,10⟩ ∪ (15 + ⟨6,10⟩)
```

**⚠️ 唔係單一半群 ⟨6,10,15⟩**（數值上同集，但 15 係 skew 生成元，唔係第三個 primary degree；
`⟨6,10,15⟩` 作為集合 = `⟨6,10⟩ ∪ (15+⟨6,10⟩)` 只因 `2·15 = 30 ∈ ⟨6,10⟩`）。

### (d) 三路徑一致（獨立交叉）

| 路徑 | S (l ≤ 30) |
|:-----|:-----------|
| Molien 級數 `(1−t²)P(t)` | 6,10,12,15,16,18,20,21,22,24,25,26,27,28,30 |
| 特徵標法 `(1/60)Σ_g sin((2l+1)θ_g/2)/sin(θ_g/2)` | 同上（全整數） |
| 實測 max-over-400-軸 Legendre 動差 | 同上 |

三路徑**逐項相同**（`scripts/09` C3.1 / C5.1；`scripts/04` section J）。

### (e) 數值驗證（`scripts/07` C2/C3，400 條隨機軸）

| 集合 | l 值 | max\|M_l\| |
|:-----|:-----|:----------:|
| 零集 Z | 1,2,3,4,5,7,8,9,11,13,14,17,19,23 | ≤ 3.78e−05（機器噪聲） |
| 諧和度集 S | 6,10,12,15,16,18,20,21,22,24,25,26 | ≥ 0.093 |

- **分離度 ≥ 2400×**（噪聲 vs 信號）⟹ 分類無歧義。
- **軸無關**：`M_l ≡ 0` 係群論事實（`M_l` 係 A₅-不變），實測 400 軸一致。
- **5-design**：`l ≤ 5` 全零 ⟺ `Σ_i u_i u_iᵀ = 20·I`（實測 dev **7.3e−6** = 捨入級）。

## 四. G1 冗餘定理

```
G2 ⊂ G1        (C6.2)
⟹  Sel = G1 ∩ G2 = G2   (C6.3)
```

`max v₂(n) over G2 = 2`（C6.4）⟹ G1 嘅條件（`v₂ ≤ 2`）對全部被選模式自動滿足。

**裁決**：對「帶電費米子選擇」，**G1 零貢獻** — 選擇律可簡化為**單一生成元 G2**（A₅ 動差等向）。
G1 並非完全無用：佢承載**費米/玻色 Z₂ 分級**（`v₂ ≤ 2` = 費米），係 docs/07 中微子分區
（`G1 ∧ ¬G2 = 30`）嘅必要工具。故 𝒮 嘅公理集可收緊為
**{G2 (選擇), G1 (分級)}** — 兩個角色分離，唔再係「兩個選擇生成元」。
