## 二. 結構部分 — 角色多重集被強制

```
Gen3 = {1,2,3}   -> (up,   down, lep)      [t, b, τ]
Gen2 = {4,5,7}   -> (up,   lep,  down)     [c, μ, s]
Gen1 = {9,11,13} -> (down, up,   lep)      [d, u, e]
```

**每塊角色多重集 = {up, down, lep}**（C2.1/C2.2）— 即每世代恰含 1 個 up-type、
1 個 down-type、1 個帶電輕子。

**結構來源（O88）**：Pati-Salam 分解

```
SU(4)_PS ⊃ SU(3)_c × U(1)_{B−L}:   4 = 3_{1/3} ⊕ 1_{−1}
```

`3_{1/3}` = 夸克（3 色）、`1_{−1}` = 帶電輕子（色單態）；`SU(2)_L` 再將夸克分 up/down。
故**「每世代 1 lepton + 2 quark，夸克再分 up/down」係 SM 內容計數嘅直接後果**
（+ 中微子 = SU(4) 單態之伴侶，見 docs/07）。

**判級**：多重集 🟢 結構；邊個模式配邊個角色 🟡 未定（見下）。

## 三. 非結構部分 — 角色置換 σ_g

定義 σ_g = 塊內 |Δm| 排名 (1,2,3) → 角色：

```
σ_3 = (up,   down, lep)      = id
σ_2 = (up,   lep,  down)     = (2 3) 換位
σ_1 = (down, up,   lep)      = (1 2) 換位
```

**三代 σ_g 相異**（C3.4）。

**證偽假說「角色 = f(塊內 |Δm| 排名)」**（C3.5）：若該假說成立，σ_g 應三代一致
（因為排名係塊內唯一結構序）。實測三代相異 ⟹ 假說**證偽 → PASS**（誠實記錄）。

## 四. 窮舉不變量搜索（三分類）

對 53 個結構候選不變量，分三類（`scripts/08` C4）：

| 類別 | 定義 | 集合 |
|:-----|:-----|:-----|
| **不相容** | 有碰撞且碰撞角色唔同 | `n mod 2,3,4,5,6,8,9,11,12`；`v₂(n)`；`L(n)`；`is_prime`；`is_square`；`ndiv`；**塊索引 g**；**塊內排名 r** |
| **空洞相容** | SEL 上 injective（無碰撞）→ 平凡 | `n mod 13..44`；`E_n`；`\|dm_n\|`；`SEL 位置` |
| **非空洞相容** | 有碰撞但仍相容 | **只有 `n mod 7`, `n mod 10`**（各 2 碰撞） |

**關鍵**：`E_n = 4sin²(nπ/88)` 同 `|dm_n|` 喺 SEL 上單調 ⟹ injective ⟹ 只係**空洞相容**
（等價「角色 = f(n)」，零信息）。

### Null test（C5）— 決定 k=7, 10 係咪信號

枚舉**全部 216 個**守塊多重集之角色分配（每塊 3! 個置換），逐個數「非空洞相容模數」數目：

```
mean = 1.14    median = 1    max = 2
P(count >= 2) = 0.250   (54/216 個分配達到 >=2)
```

觀測 = 2 個 ⟹ **唔超過 null max，且 25% 隨機分配同樣達到** ⟹ **巧合級，非結構信號**。
（`n mod 7` 雖然 7 = L₄ 係框架自然數，但 null 顯示「有 2 個非空洞命中」係隨機分配之常態。）

### 雙組合（C6）

1378 個雙組合 → 11 個非空洞相容；**冇一個係「全框架自然模數」組合**（C6.1）。
