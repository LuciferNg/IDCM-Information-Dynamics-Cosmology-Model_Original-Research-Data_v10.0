## 一、動機

O209 質量譜殘留（c/s 離群、RMS 0.58）一直卡喺「C_f = 咩算子」正推（O233 5 線負、O234 DOF=0、O212 dof=1、docs/14–18 全負）。

用戶提出逆推：**唔 fit 數值，用幾何連結本身推質量，質量 = 代價**。

RAG 確認先例：O136 docs/25（觀察↔被觀察交互 = 位置算子 Z₂-奇耦合；二階自能 |Δm| = 0.5877）+ docs/29（觀察代價族）。而 O209 嘅 |dm|（= V²G 對角）**就係**「位置算子二階效應」（docs/25 定理嘅 88-site 完整版）——|dm| 本身就係「幾何連結代價」：每個模式同其餘 87 個模式嘅耦合強度 × 能量倒數。質量譜任務 = 唔再問 C_f 係咩，而係問「幾何代價（|dm|） → 質量」嘅結構係咪直接得。

## 二、方法

1. **P1 幾何中心性候選**：88-site 正權連結矩陣 W = |V|²·|G| 上計 eigenvector/degree/betweenness/closeness/ablation（全部零參數「幾何連結」量），freeze 9 點 fit 對比 |dm|
2. **P2 φ² 候選統計檢定**：freeze OLS 斜率 vs φ² = 4cos²(π/5)（二十面體角）vs 79/30，σ_α 檢定 + 固定值 RMS 對比
3. **P3 C_f 算子身份測試**：m = M₀γC_f（IDCM 質量公式）＋ m = C·|dm|^{φ²}（代價公式）⟹ C_f ∝ |dm|^{φ²}/γ？——如果 slope=1 即 C_f 有算子身份（閉合 O233）
4. **P4 標度檢查**：C 有冇框架身份（vs M₀）

### P2. ★ freeze 下 OLS ≈ φ²（20面體角）— 新候選升格 🟢

- **freeze OLS α = 2.616977 ± 0.151（1σ）**
- **φ² = 2.618034 → −0.01σ**；79/30 = 2.633333 → **−0.11σ**
- 固定 φ² freeze RMS = **0.580174** vs 固定 79/30 = 0.580655 → **φ² 好 0.08%**
- **φ² = 4cos²(π/5) EXACT**——π/5 係正五邊形/二十面體角；IDCM 已有二十面體線（O223 |GeoAut|=60 手性 I、O137 I-60 軌道 = N_gen²）⟹ **φ² 有正當幾何身份，唔係新常數**
- 對照：PDG 下 OLS = 2.633254 ≈ 79/30（0.00σ）、φ² = +0.10σ——**scheme 揀候選**：PDG 捧 79/30、freeze 捧 φ²。O234 freeze 係「質量比 scheme」（FLAG Nf=4）有獨立理據 ⟹ **質量層默認 freeze ⟹ φ² 係新首選，79/30 降為次選**
- ⚠️ 統計上兩者都喺 1σ 內（σ_α = 0.15 好大）——**唔可以話「驗證 φ²」**，只可以話「freeze 下 φ² 係更自然嘅結構歸因」（dev 0.04% vs 0.63%）

### P3. C_f 反推 FAIL 🔴（O233 維持）

- log C_f ~ log(|dm|^{φ²}/γ)：**slope = 0.374（需 1）**，RMS = 0.555
- ⟹ **C_f ≠ K·|dm|^{φ²}/γ**——C_f 唔可以由 |dm|^{φ²}/γ 生成
- ⟹ O233「C_f 無算子身份」5 線負**維持**；「質量 = 代價」唔可以簡化為 IDCM 質量公式 m = M₀γC_f 嘅 C_f 項
- 兩個公式（m = C|dm|^α 冪律 vs m = M₀γC_f）係**唔同結構**——前者 9 點 2 參數，後者 8 值 C_f 反解——唔可直接換算

### P4. 標度 C 未閉合 🔴

- m_n ≈ C·|dm|_n^{φ²}（freeze）：C = **1.47e−6 MeV** ≠ M₀ = 27.9（差 1.9e7）
- docs/25 個 C = 5.39e−5 都係咁——**「質量 = 代價」公式嘅標度一直未接入框架常數**；呢個係閉合前必補（可能 C = M₀·|dm|_ref^{−φ²} 之類，未搵到）
