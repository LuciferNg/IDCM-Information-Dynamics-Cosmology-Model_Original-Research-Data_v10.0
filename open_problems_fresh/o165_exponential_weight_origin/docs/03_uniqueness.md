# O165 — 03: 唯一性裁決 (指數 vs 冪律 vs 高斯)

## 判準

可見模式數必須 = 3 = N_gen; 權重必須出自結構 (零新常數)。

## A. 高斯 e⁻ⁿ² — FAIL (2 個可見)

```
e⁻¹ = 0.3679 > κ ✓   e⁻⁴ = 0.0183 < κ ✗
→ 可見 = {0,1} = 2 個 ≠ 3
```

**結構註**: 鏈色散 γ_n = 4sin²(πn/88) ≈ (πn/44)² 係**二次** — 若用鏈譜做玻爾茲曼 e^(−γ_n) 就係高斯形。高斯 FAIL = 鏈自身譜 FAIL。

## B. 冪律 n⁻ᵖ — FAIL (連續譜 + n=0 發散)

- **n=0 發散**: 冇自然歸一, 可見性喺 n=0 無定義 — 結構性 FAIL
- **非唯一**: {1,2,3} 可見 iff p ∈ [2, 2.52372) — 連續譜, 任何 p 都得

| p | 可見 (n≥1) |
|:-:|:-----------|
| 1.5 | {1..6} |
| 2.0 | {1,2,3} |
| 2.3 | {1,2,3} |
| 2.524 | {1,2} |

## C. 幾何族 rⁿ — 樹強逼 r = φ⁻² (唯一)

3 可見 iff r ∈ (1/4, 16^(−1/3)] = **(0.25, 0.396850]**

| r | 值 | 可見 | 裁決 |
|:--|:---:|:----:|:-----|
| φ⁻¹ (樹比, 未平方) | 0.61803 | {0..5} 6 個 | FAIL — 證明權重必須係振幅平方 |
| **φ⁻² (樹比, 平方)** | **0.38197** | **{0,1,2} 3 個** | **PASS** |
| 1/4 (B⁻¹ 等權 isometry) | 0.25 | {0,1} | FAIL — 退化: 4⁻² = κ 精確 |
| 1/2 (√B⁻¹ 等權振幅) | 0.5 | {0..3} 4 個 | FAIL — 退化: 2⁻⁴ = κ |
| 1/7 (L₄⁻¹) | 0.14286 | {0,1} | FAIL — 出區間 |
| 1/3 | 0.33333 | {0,1,2} | 數值得, 但無樹結構出處 |
| 0.35 | 0.35 | {0,1,2} | 數值得, 但無樹結構出處 |
| e⁻¹ (舊標籤) | 0.36788 | {0,1,2} | 數值得, 但 e ∉ 樹結構 (超越數) |

**結構候選只有 φ⁻² 過: 非退化 + 恰好 3 + 零新常數 (φ⁻¹ 已文檔化)。**

## D. 玻爾茲曼/諧振子身份裁決

```
φ⁻²ˡ = e^(−2l·lnφ)  ⇒  玻爾茲曼形式 e^(−E_l/kT) 需要 E_l = 2l·lnφ·kT  ← 線性階梯 (等間距!)
```

- ✅ 幾何權重 ≡ 玻爾茲曼**線性**能階 (每層一個 RG 步, 衰減率 2lnφ 常數)
- ❌ 鏈模式色散二次 → 玻爾茲曼變高斯 (A 已排除)
- ❌ Poisson: P(n) = λⁿe^(−λ)/n! 係 λⁿ/n! 衰減 (超指數), 唔係幾何
- ❌ QHO 基態: 高斯 e^(−n²) (A 已排除)

**「諧振子身份」成立嘅係樹層階梯 — 每層 = 一個 RG 步 — 唔係鏈模式。**

## 結論

「點解指數?」— 因為**幾何 (RG 層階梯) 係唯一喺樹結構內、非退化、精確給 3 可見層**嘅權重族。
「點解 e 底?」— 唔係 e: 精確底係 **φ²** (φ⁻²ˡ = (φ²)⁻ˡ), e 係 φ² ≈ e 嘅 3.7% 近似。
「點解 n 一次冪?」— 因為每層乘一個常數因子 (RG 步線性複合), 指數係層索引一次方。
