# O228 / R6 — LP 對偶憑證：分數 packing 能否證明 `k_min = 7`（凍結合約）

- 合約名：**`o228-r6-lp-certificate-v1`**
- 動機：R5 收窄殘餘——排列界只給 `k_min(𝔐_edge) ≥ 6`、整數 packing 憑證只給 5。問：**集合覆蓋 LP 之
  對偶（分數 packing）**能否給出 ≥ 7 之憑證？（若 LP 最優 = 7 ⟹ 憑證成立；若 < 7 ⟹ **LP 路線已死**，亦係結果。）
- 判準凍結於此，**不得放寬**；被偽證者原樣留 FAIL ＋ 立 `-c` 校正 tag。【盲】= 本輪首次見值。

## §1 操作空間（封死）

**准**：①由 K 導出之 0/1 分離矩陣（435 行對 × 62 列）②**精確有理數（`Fraction`）單純形**（Bland 反循環規則）
③由最終表讀出對偶（原始）解 ④檢驗憑證對（primal/dual 目標相等）。
**禁**：①浮點門檻調參（LP 全程精確）②新參數或擬合 ③引入觀測數據 ④改 o222 任一檔 ⑤改 R1–R5 任一凍結產物。

## §2 形式化

對每部機器 𝔐（m 行、N 列、行對集 P，|P| = m(m−1)/2；`A[p][a] = 1` ⟺ 列 a 分開行對 p）：

```
原始（覆蓋）  min Σ_a x_a      s.t.  Σ_a A[p][a] x_a ≥ 1  ∀p ∈ P ,  x ≥ 0
對偶（packing）max Σ_p y_p      s.t.  Σ_p A[p][a] y_p ≤ 1  ∀a      ,  y ≥ 0
```

- **弱對偶**：`Σ_p y_p ≤ Σ_a x_a`；整數 packing `ν ≤ LP* ≤ k_min`（LP 鬆弛夾在兩者之間）。
- **憑證**：若同時給出可行 primal `x*` 與可行 dual `y*` 且 **目標值精確相等**，則 `LP*` **已證最優**，
  且 `k_min ≥ LP*`。

## §3 判定項（預註冊）

- **L1（定理核對，非盲）**：六部皆 `ν ≤ LP* ≤ k_min`（其中 `ν` = R5 之整數 packing 值
  `{2,3,5,1,2,1}`；`k_min = {4,5,7,2,3,1}`）。
- **L2（憑證對，非盲但精確）**：六部皆能以**有理數**給出可行 `x*`、`y*` 且 `Σx* = Σy*`（= LP\*），
  即 LP\* 最優性**經算術驗證**，非只信單純形。
- **L3（盲預測，主）**：**`LP*(𝔐_edge) < 7`**（我押 LP 鬆弛**唔緊**）⟹ 集合覆蓋 LP 路線**不足以**證明
  `k_min(𝔐_edge) = 7`。若實測 = 7，則**憑證成立**（因 `LP* ≤ k_min = 7`）。
- **L4（盲預測，輔）**：𝔐_edge 之**最難行對**被最少列分開之條數 `λ_min ∈ [8, 12]`
  （推論：均勻解上界 `62/λ_min ∈ [5.17, 7.75]`）。
- **L5（結構描述，非盲）**：報 `𝔐_edge` 最優解之**支撐**（`x_a > 0` 之列）與**緊行對**（`Σ_a A[p][a]x_a = 1`）
  之型態——若支撐含 ≤ 7 個列且緊行對成阻礙集，則另得可人手核對之組合憑證。
