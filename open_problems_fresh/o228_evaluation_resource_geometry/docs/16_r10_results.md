## 0 先驗清點：為何只餘非凸論證

覆蓋問題 `min Σ_a x_a s.t. Σ_{a∈S(p)} x_a ≥ 1`（62 列、435 對）。任何**加權／分數／計數**下界 =
某可行對偶向量 `y ≥ 0` 之值 `Σ y_p`；而子族限制之 LP 係全域 LP 之**鬆弛**（約束更少）⟹ 其值 `≤ LP* = 5`。
故**第①–⑥類（計數、packing、LP、局部化、行側見證、均勻權重）**全部 `≤ 5 < 7` ✓
⟹ 破 5 **必須**用非凸（整數可分性）資訊 —— R10 之標的。
