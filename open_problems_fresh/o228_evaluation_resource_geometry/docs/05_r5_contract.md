## §2 判定項（預註冊）

### K1 — **中心排列下界定理**（【非盲值；新公式】）

- 定義：`cap(k) ≡ min(2^k, k² − k + 2)`。其中 `k² − k + 2` = **ℝ³ 中 k 個大圓（中心平面）在一般位置之區域數**
  （k = 1：2；k = 2：4；k = 3：8；k = 4：14；k = 5：22；k = 6：32；k = 7：44）。
- **定理（本輪提出）**：機器之每列 = 某線性泛函之符號 ⟹ k 列所給之號樣式必落於某 k 個大圓之排列區域內
  ⟹ `k_min ≥ min{k : cap(k) ≥ m}`。**k ≥ 5 時 `k²−k+2 < 2^k` ⟹ 排列界嚴格強於資訊界。**
- **K1a（核對表）**：預測 `k_min^bound(m) = min{k : cap(k) ≥ m}` = m=2→1、4→2、6→3、12→4、20→5、**30→6**；
  與 R2 實測 `k_min` = 1,2,3,4,5,**7** 比較 ⟹ 預測 **6/6 滿足 ≥ 界**、**5/6 取等**、唯一超界者 = 𝔐_edge（6→7）。
- **K1b（過渡事實表）**：對六部機器逐一核 `F_k = 0 ⟺ k < 界`（用 R2 已登記之 F 值；11 條過渡事實）。
- **K1c（排列界之直接驗證）**：對每部機器、每個 `k ≤ 4`，**全枚舉**其 k-型子集並算「實現之相異號樣式數」
  `pat(T)`；預測 `max_T pat(T) ≤ cap(k)`（即界唔只係「區域數上界」，而係**實際實現數之上界**）。

### K2 — **𝔐_edge 於 k = 6 之破例憑證**（【部分盲】）

- 背景：`F_5 = F_6 = 0`、`F_7 = 8584`；界說 k = 6 可行（cap(6) = 32 ≥ 30）但實測不可分離 ⟹ 需憑證。
- **K2a（奇偶論證）**：機器之列集為**中心對稱軌道** ⟹ 排列中心（所有平面過原點）⟹ 號樣式集**對「取負」封閉**
  ⟹ 實現樣式數**必為偶數**。由 `F_6 = 0` 得 `pat ≤ 28`（偶數且 < 30）。
- **K2b（盲預測）**：於 𝔐_edge、k = 6 之隨機 2×10⁵ 個 6-子集（MT，宣告種子）中，**最大實現樣式數 = 28**。
- **K2c（盲預測）**：k = 5 之最大實現樣式數 **≤ 22**（= cap(5)，且偶數）。
- **K2d（碰撞幾何）**：對 K2b 之最佳子集，列出碰撞行對，並報其 `⟨r,r'⟩`（ℚ(√5) 精確）；**預測**碰撞對
  皆為「最近對」（`|⟨r,r'⟩|` 於 30 行中屬最大值層）。
