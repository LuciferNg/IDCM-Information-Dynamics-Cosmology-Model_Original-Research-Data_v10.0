## 1 ★ 主定理：非負係數割族**無條件**判死（唔再靠 8584 普查）

支撐 `S = [3,4,6,8,9,13,15,18,19,32]`（10 欄，`x* = ½·1_S`，`LP* = 5`，讀自 R13 持久化憑證）。

1. **`P13-1` ✅**：`S` 自身**就係 cover**（`∪_{a∈S} cme[a] = ALLP`，435/435）。
2. **`P13-2` ✅（無條件定理）**：分離 LP `[P] := max{Σ_{a∈S}c_a x*_a : Σ_{a∈C}c_a ≥ 1 ∀C ∈ 𝒞, c ≥ 0}` 之對偶
   `[D] = min{Σ_C μ_C : Σ_{C∋a}μ_C ≥ x*_a}` 有**顯式可行見證** `μ_S = max_a x*_a`（因 `S` 本身就係 cover）
   ⟹ `[P] = [D] ≤ max_a x*_a = ½ < 1` ⟹ **冇任何非負係數（含 0/1）割分離 `x*`**，且**與 8584 普查無關**。
3. **`P13-3` ✅（精確值）**：`M_all := min Σ_{C∈𝒞}μ_C s.t. Σ_{C∋a}μ_C ≥ 1 (∀a∈S)` **= 1 EXACT**
   （LB：`10 = Σ_{a∈S}1 = Σ_C μ_C|C∩S| ≤ 10·Σμ_C`，用 `|C∩S| ≤ |S| = 10` ⟹ `Σμ ≥ 1`；UB：`μ_S = 1`）
   ⟹ 分離 LP 值 `= ½·M_all = ½`（強對偶）。
4. **`P13-4` ✅（交叉驗證）**：把 `S` 併入 8584 幀族後，R13 之精確切平面值 **`9/5 → 1`**（16 迭代、子集 83）
   ⟹ 幀族之 `9/5` 係**族限制**之產物；`S` 一入族即跌至定理界。
