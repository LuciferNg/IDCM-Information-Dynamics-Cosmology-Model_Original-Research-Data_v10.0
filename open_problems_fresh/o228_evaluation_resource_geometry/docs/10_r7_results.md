### 1.2 理論（已證 ＋ 已核，非假設）

- **L1（奇碼映射）**：`code(−r) = complement(code(r))`，對**任意**列集成立（每列符號在 `r → −r` 下取負；tie 行由 τ 讀「行嘅首個非零分量」，同樣取負）⟹ **無任何類含反極對**、**類大小成孿生成對**。
- **L2**：`loss := m − pat = Σ(size−1) = 2` ⟺ **恰兩個 size-2 類，且互為孿生** ⟺ 未分離行對恰為一對孿生對 `{p, twin(p)}`（等價 `|U| = 2`）。3000 個隨機 6-子集核驗全中。
- **L3**：故 loss = 2 之 6-子集必須：**(a)** 只含**唔分離 `p`** 之列（62 列中僅 **50** 列）；**(b)** 分離其餘 **433** 對。
- 另核：**孿生對之分離列集完全相同**（`pcol[p] == pcol[twin(p)]` ∀p）⟹ (a) 之兩重條件一致。

## §2 ② `λ(p)` 幾何：每對行被幾多列分開

### 2.1 剖面（按精確 `⟨r,r'⟩ ∈ ℚ(√5)` 分殼；**無浮點**）

- **𝔐_edge**（435 對）：殼 → `λ` 集合 =
  `|dot|=1 → {62}`；`cos36°` 殼 → **{12, 14}**；`−cos36°` → {48, 50}；`±0.5` → {20,22}/{40,42}；
  `±|1/4−1/4√5|` → {36,38}/{24,26}；`dot=0` → {30,32}
- **𝔐_face**：{62}、{14,16}、{46,48}、{38}、{24}
- **𝔐_2I**：{62}、{38,40}、{22,24}
- `λ_min` = **edge 12／face 14／2I 22**（與 R6 一致 ✓）

### 2.2 新結構（本輪，合約外發現，已標）

- **`P2a-2` PASS（cross 互補律）**：`λ(r, −r') + λ(r, r') = N` 對**全部**無「雙垂直列」之對成立
  ⟹ 一對與其 **cross 像**之分離集**互補**（每列恰分給一方）。
  註：**反極像對** `(r,r') → (−r,−r')` 則保持 `λ` 不變（兩個唔同命題，原 `P2a-1` 曾誤讀）。
- **`P2a-3` PASS（tie 機制引理）**：對一條線之兩列 `u, −u`：若 `u` 只與該對之**一個**成員垂直，
  則**恰有一列**分離（τ 令兩個 tie 取值相同）；否則兩列一致。21421 次核驗 0 違例。
  ⟹ **`±` 律被 tie 破壞**，此即 `λ` 唔一定係「線數 ×2」之因。

### 2.3 被偽證之預測（原樣保留 ＋ 校正）

- **`P2a-1` FAIL**：我預註冊「`λ_min = 12 = 6 線 × 2`」⟹ 實測 **12 列跨 11 條線**
  （`E02,E10,E12,E13,E14,F00,F07,F08,F09,V03,V05`）⟹ 立 **`P2a-1-c`**：`λ_min = 12` 之**值**成立，線分解改變。
- **`P2b-1` FAIL**：預註冊「`λ` 隨靠近單調減 ∧ 最難對 6 線全 E 型」⟹ **兩者皆錯**：
  每個殼裂成**兩個軌道**且 `λ` 互補（唔存在單一「最難殼」）；最難對 11 線為 **V/F/E 混合**（非全 E）⟹ 立 **`P2b-1-c`**。
- **`P2c-1` PASS**（精確代數刻畫）：`⟨u,r⟩⟨u,r'⟩ = (⟨u,r+r'⟩² − ⟨u,r−r'⟩²)/4` 且
  **`u` 分離該對 ⟺ `⟨u,r+r'⟩² < ⟨u,r−r'⟩²`**（即 `u` 更近**差**方向而非**和/平分**方向）。
  30182 個（對, 列）組合 0 違例（12660 個 tie 項另計，由 τ 決定，非由 dot）。
