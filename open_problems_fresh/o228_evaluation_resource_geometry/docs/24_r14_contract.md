# O228 / R14 合約 — 覆蓋族之無條件分離判死與極小覆蓋族定量

合約名 `o228-r14-cover-family-v1`（**先寫合約、後寫 scripts，判準不得事後放寬**）

## 0 定義（全部承 R1–R13 之凍結定義）
- `𝔐_edge`：30 列 × 62 欄；`cme[a]` = 欄 a 之 435 對 pair-mask；`ALLP = 2^435 − 1`。
- `𝒞` = **覆蓋**（cover）族 = {C ⊆ 欄 : ∪_{a∈C} cme[a] = ALLP}；`ℱ` = R11 之 8584 個 size-7 幀；`ℳ` = inclusion-minimal 覆蓋。
- `S` = 根 LP 之 10 列支撐（`x* = ½·1_S`，`LP* = 5`；R12/R13 凍結值，由 `data/25` 持久化向量讀入）。
- 非負係數割 = 「`Σ_{a∈S} c_a x_a ≥ γ`，`c ≥ 0`」，**有效** ⟺ `Σ_{a∈C} c_a ≥ γ` 對所有 `C ∈ 𝒞`（`c ≥ 0` ⟹ 只需對極小覆蓋檢查）。

## 1 預註冊判定（P13-*）
- `P13-1`【非盲】`S ∈ 𝒞`（`∪_{a∈S} cme[a] = ALLP`）。
- `P13-2`【盲·**無條件定理**】分離 LP `[P] := max Σ_{a∈S} c_a x*_a  s.t. Σ_{a∈C}c_a ≥ 1 (∀C ∈ 𝒞), c ≥ 0`
  之最優值 **≤ m := max_{a∈S} x*_a**（對偶見證 `μ_S = m`）⟹ 對 `x* = ½·1_S`：`[P] ≤ ½ < 1` ⟹
  **不存在任何非負係數割分離 `x*`** —— 且此結論**與 8584 普查無關（無條件）**。
- `P13-3`【盲·精確值】`M_all := min Σ_{C∈𝒞} μ_C  s.t. Σ_{C∋a} μ_C ≥ 1 (∀a∈S)` **= 1 EXACT**
  （LB：`10 = Σ_{a∈S}1 = Σ_C μ_C|C∩S| ≤ 10 Σμ_C`（因 `|C∩S| ≤ |S| = 10`）⟹ `Σμ ≥ 1`；UB：`μ_S = 1`）
  ⟹ `[P] = ½·M_all = ½`（強對偶）。
- `P13-4`【非盲·交叉驗證】把 `S` 併入幀族後，R13 之切平面解由 `9/5` **跌至 `1`**（單調性 + 精確命中）。
- `P13-5`【盲】`max_{C∈ℱ} |C∩S| = 3`。
- `P13-6`【盲·一般定理精確性】對 200 個隨機 `x* ≥ 0`（支撐 ⊂ `S`），族 `𝒞' = ℱ ∪ {S}` 上之切平面值
  **恰等於** `max_{a∈S} x*_a`（0 違例）；且 `ℱ`-only 之值 `≥` 該值（族限制 = R13 `9/5` 之來源）。
- `P13-7`【盲】size-8 族密度：均勻隨機 8-集之覆蓋率 `p̂`（10⁵ 抽樣，5σ 帶）**≥ 0.05**，即 `A8 ≥ 1×10⁸`。
- `P13-8`【記錄·誠實分級】完整 size-8 極小覆蓋普查**不可行**（R11 同款 DFS 之死端比 `≈1.8×10⁴` ⟹ 節點量級 `≥10¹⁰`）；
  本輪只交 **MC 密度估計（附 σ）＋ witness 計數下界**，並**明報**不可行原因，不以估計冒充精確。
  另附**精確**結構事實（無需列舉）：任一 `C ∈ ℳ` 皆不含任何幀（含幀 ⟹ 非極小）；任 `C ∈ ℳ` 滿足 `|C∩S| ≤ 9`。

## 2 限制
唯讀（`o222` 4 件 sha256 不變）；零新參數；精確有理數（`Fraction`）；MC 只作密度/σ 帶並明示；
`f_8` 般之估計**不得**當精確值；若 MC 顯示 `p̂ < 0.05` 則 `P13-7` 原樣 FAIL 並立 `-c`，不得改門檻。
