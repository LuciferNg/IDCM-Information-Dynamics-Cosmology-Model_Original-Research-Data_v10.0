## §2 一般機器之定義

```
𝔐 = (G, u₀, 𝒜, τ)          K𝔐[g][a] = sgn_τ( ⟨u_a , g·u₀⟩ ) ,  g ∈ G / Stab(u₀)
```

- **列集** = orbit `O(u₀)` 之**相異點**（同 coset 之列完全相同，重數不增資訊 —— 與 R1 慣例一致）；
- **型（type）** = 列纖維分割 `π_a` 之等價類；「分離幀」= 分離**全部 C(m,2) 個行對**之列子集；
- **F_k** = 分離 k-子集數；**k_min** = min{k : F_k > 0}；**rank** = `dim_ℚ span(列向量)`。

**五部機器（本輪全測）**：

| 機器 | G | u₀ | 𝒜（列數 / 線數） | m 預期 |
|---|---|---|---|---|
| 𝔐_2I（= R1 機器，回歸） | 2I (120) | V00 | 62 / 31 | 12 |
| 𝔐_face（對偶讀法） | 2I (120) | F00 | 62 / 31 | **20** |
| 𝔐_edge | 2I (120) | E00 | 62 / 31 | **30** |
| 𝔐_T（四面體） | T (12) | (1,1,1) | **14 / 7** = ±4 body-diagonal ∪ ±3 coordinate | **4** |
| 𝔐_O（八面體） | O (24) | e₁ | **26 / 13** = ±3 vertex ∪ ±6 edge-midpoint ∪ ±4 body-diagonal | **6** |
| 𝔐_D4（退化極限） | D₄ (8) | e₃ | **10 / 5** = ±e₃ ∪ ±{e₁,e₂,(1,1,0),(1,−1,0)} | **2** |

- 𝔐_T 為**自對偶**（face 法向 ≡ vertex 方向）⟹ 只有 V、E 兩族；
- 𝔐_O 之**面族 ≡ body-diagonal 線**（八面體之對偶為立方體）；
- 𝔐_D4 為「m = 2」退化極限，用以測定理之邊界。

## §3 判定項（預註冊）

### (A) 一般定理項（機器無關）

- **T1**：`#相異行 = |O(u₀)| = [G : Stab(u₀)]`，於六部機器全中。
- **T2**（二分律）：`π_a` 為 (m/2, m/2) **二分割 ⟺ 該列零平手（tie-free）**；有平手者其形狀由 τ 決定
  （本輪全量報告形狀）。
- **T3**（閉式，機器無關形）：`F_k = Σ_{T : ⋁_{a∈T} π_a = 0̂} e_k(T)`
  ＝ `C(N,k) + Σ_{π ≠ 0̂} g(π)·C(β(π),k)`，`g(π) = ∏_B (−1)^{|B|−1}(|B|−1)!`
  —— 於**每部機器**以三路（type-set 形／Möbius 形／brute force DFS）互相對帳（k 上限：m ≤ 6 之機器到 4；
  𝔐_2I/face/edge 到 4）。
- **T4**：`F_k = 0 ⟺ k < k_min`，且 `k_min = min{|T| : T 分離}`（無例外）。
- **T5**（生成 vs 分離）：預測 **`k_min ≤ rank_ℚ K𝔐` 於六部機器全部成立**（R1 已見 4 < 6）。此為**猜測**，可被偽證。
- **T6**（null 相對讀法）：對每部機器，定義
  `rate_machine(k) = F_k / C(N,k)`、`rate_null(k) = F_k(all bisections of m points)/C(nbis(m),k)`
  （null 由 §T3 之 size-multiset 化簡精確計算；此化簡已於 R1 C17-c 以 pts = 4/6 反例 regression 鎖死）。
  預測：**六部機器全部 `rate_machine(k_min) < rate_null(k_min)`**（即：無任何機器在最小幀規模上「超額」）。

### (B) 盲測項（解析推導 → 直接對撞，逐條給出預測值）

**B1 — 𝔐_T（四面體）**
- m = 4 行 = 座標四面體 4 頂點 {v₁=(1,1,1), v₂=(1,−1,−1), v₃=(−1,1,−1), v₄=(−1,−1,1)}；**零平手**。
- census：**7 個相異分割** = 4 個形 (1,3)（各重數 **2**，來自 8 條 body-diagonal 列）＋ 3 個形 (2,2)（各重數 **2**，來自 6 條座標列）。
- **F₁ = 0、F₂ = 12、F₃ = 212、k_min = 2**。
  （導出：兩條 (2,2) 型必覆蓋全部 6 對 ⟹ 3 型配 × 2×2 = 12；三型組合逐一列舉得 F₃ = 12+8+32+96+64。）

**B2 — 𝔐_O（八面體）**
- m = 6 行 = {±e₁, ±e₂, ±e₃}。
- census：**只有 4 個相異分割**，全部形 (3,3)（經 τ 消平手後），重數 = **(8, 6, 6, 6)**，總 26。
  （導出：3 個 +e_i 頂點列、3 條 edge 列、2 條 body-diagonal 列 → 同一型；−e_i 各歸其餘三型。）
- **F₁ = F₂ = 0、F₃ = 1080、k_min = 3**（導出：4 型中任 3 型皆分離；Σ 三元型配之重數乘積 = 288×3 + 216 = 1080）。

**B3 — 𝔐_D4（退化極限）**
- m = 2 行 = {±e₃}；每列之平手（z-軸為 0 之 dot）由 τ 解成 {+1, −1} ⟹ **10 列全部分離**那唯一行對。
- **F_k = C(10,k) 於 k ≥ 1、k_min = 1、相異分割 = 1（重數 10）**。

**B4 — 𝔐_face（對偶讀法）**
- **m = 20**（一致性：與上游 O226 R2 之 20-類相符）；
- **平手律**：每條 **edge 列恰有 4 個平手行**（該 edge 所屬之兩面 f, f′ 及其對面 −f, −f′，即 ⟨u, ±f⟩ = ⟨u, ±f′⟩ = 0）；vertex/face 列 0 平手；
  故 𝔐_face 之 census **必含非二分割形**（τ 解平手後形狀 (8+p, 12−p)）；
- 預測：**vertex 列與 face 列（12 + 20 = 32 列，零平手）之 π_a 全為 (10,10) 二分割**；總平手 (列,行) 對數 = 15×2×4 = **120**。

**B5 — 𝔐_edge**
- **m = 30**（一致性：O226 R2 之 30-類）；平手律與 census 全量報告（不預測，列為測量項）。

### (C) 一致性／回歸項

- **C1**：𝔐_2I 於 R2 重建後**逐位重現 R1**：16 型、直方圖 {3:10, 5:5, 7:1}、F₁..F₄ = [0,0,0,12645]、k_min = 4、rank = 6。
- **C2**：𝔐_2I/face/edge 之平手 (列,行) 對數：2I = 120（R1 C8 之 12×10）；face = 120（B4）；edge = 全量報告。
- **C3**：null 之 size-multiset 化簡在 m = 4,6 上與 brute force 相符（R1 C17-c 之 regression 擴大至 m = 4,6,12）。

### (D) 協定級（成本律對接）

- **P1**：逐字重現上游 `run_pair` I/O 語義（唯讀 import），於 62-機器上量測：**每對 miss ∈ {2,3}**，並給出 62×62 全對總 miss 與 cache hit 數。
- **P2**：資源同一性檢核 —— **31 軸 ⟹ 31² = 961 對 ⟹ 8 × 961 = 7688 reads**（上游 A2 pass 讀數），
  與預算 `reads/pass = 88`、`reads/tick = 44 = N_d` 併置；本輪只**重算並對照**，不重推上游推導。
