我預註冊「剪枝 DFS 訪問 < 1% 之子集」——**錯**。實測（`F_6(𝔐_edge) = 0` 之同一支後綴聯集剪枝 DFS）：

「短憑證五類窮盡」之**量化**版本（唔係「剪枝巨大所以憑證好短」之直覺）。

## §3 第①類（計數）憑證之銳利度審計（`P7-4` PASS）

對六部 R2 機器**窮舉** `k ≤ 4` 之 `max pat(k)`，與 `cap(k) = min(2^k, k²−k+2)` 比較：

- **24 個 (機器, k) 組合中 16 個達到等號**（含 `M_edge`／`M_face` 之 `k ≤ 4` 全部，`M_2I` 之 `k ≤ 3`）
  ⟹ 在**資訊界主導區**，計數界不但成立而且**銳利**；
- 但在真正需要它之處（`𝔐_edge` 之 `k = 6`）：`cap(6) = 32 ≥ m = 30` ⟹ **空洞**，
  真值 `max pat(6) = 26`（R7）與界相差 **6** ⟹ 第①類憑證在此**失效**。

**判詞（`P7-5`）**：計數界在「`m` 接近 `2^k`」之小 `k` 域銳利、在「`m ≤ cap(k)` 但接近 `k_min`」之域空洞
—— 恰為 R8 §1 表第①行給出精確理由（tie 令幾何論證不可嚴謹化，見 R8 §3）。
