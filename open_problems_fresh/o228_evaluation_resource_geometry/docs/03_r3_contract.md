## §2 判定項（預註冊）

### H1（§五②：null 之 10⁷-樣本 5σ 帶）

- 程序：與 R1 C17-c 完全相同的 4×二分割抽樣（LCG，同一遮罩表），**draws = 10⁷**。
- **預測**：`|MC − p₀| < 5σ`，其中 `p₀ = 6240/180251 = 0.0346184`（精確值，已由 size-multiset 化簡給出）、
  `σ = sqrt(p₀(1−p₀)/10⁷) ≈ 5.78×10⁻⁵` ⟹ 5σ ≈ **2.89×10⁻⁴**。
- 附註：精確值優先於 MC（本項只作 §五② 之樣本帶履行；精確值為準）。

### H2（§五④：擾動／結構剛性）

對 𝔐_2I（m = 12、62 列、F_4 = 12645）：

- **H2a（單列刪除）**：62 個刪除變體之 F_4 **恰取 3 個相異值**，重數 **(12, 20, 30)**（對應 V/F/E 三條群軌道）
  —— 且每個值 **< 12645**（即無任何單列是多餘的）。
- **H2b（單線刪除）**：31 個刪除變體之 F_4 **恰取 3 個相異值**，重數 **(6, 10, 15)**，全部 < 12645。
- **H2c（單線隨機替換）**：把 31 條線之任一條換成 **隨機二分割**（自 462 個二分割均勻抽；宣告種子），
  200 次抽樣中 **≥ 190 次** 使 F_4 ≠ 12645。
- **H2d（慣例擾動，R1 C18 引用）**：等變平手規則使 F_4 由 12645 → 1000（差 12.6×）；本輪只引用、不重算。
- **剛性判決（預註冊方向）**：若 H2a–H2c 全中，則「資源計數」對刪除**敏感**、對替換**極敏感**，
  併合 R1 C17-c 之「低於 null」與 C18 之「慣例敏感」⟹ **F_4 = 12645 不具結構剛性**（判為 🟡／🔴 而非 ✅）。
