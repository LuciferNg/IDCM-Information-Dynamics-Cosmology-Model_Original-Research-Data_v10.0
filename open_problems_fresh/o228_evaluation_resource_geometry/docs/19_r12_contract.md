## 數學（先寫定，避免方向錯）

1. cover LP（`min Σx s.t. Mx ≥ 1`）之凸界 = packing LP 之值 = **5**（強對偶）⟹ 凸界封頂 5 ✓（R6）。
2. **packing 空間加割 = 加約束 ⟹ 只會壓低**（對 cover 下界無用）✗；**cover 空間加割 = 對偶空間加變數
   ⟹ 界可上升** ✓✓ —— 本輪只走後者。
3. **編碼**：割「`Σ_{a∈A₀} x_a ≥ 1`」（係數 0/1、右端 1）在對偶空間恰為**一個候選集 = A₀ 之「虛擬 pair」**
   （目標係數 1）⟹ 可直接餵入 `scripts/10` 之精確有理單純形（`solve_packing_lp`）✓ 零新求解器。
4. **有效性判準（可窮舉證明）**：該割對所有整數覆蓋有效 ⟺ **冇任何覆蓋完全落入 `A₀ᶜ`** ⟺（等價）`A₀ᶜ`
   之子集皆非覆蓋 ⟹ 當 `|A₀ᶜ|` 細（本輪之構造：`A₀ᶜ = S \ {a}`，`|S| = 10` ⟹ `|A₀ᶜ| = 9`）時可**窮舉 2⁹ 逐個核**✓
5. **切口選擇**：`S` = 當前 LP 最優解之支撐；對每個 `a ∈ S` 取 `A₀ = (ALL \ S) ∪ {a}` ⟹ 若有效，因
   `x*_a = 1/2 < 1` 而**必然割中**（violated）✓ 逐一嘗試、加割、重解、迭代。
