## §2 Census（C1–C11）

**分裂律（C7/C9）**：`π_a = π_{−a}`（同線兩列同分割）⟺ **非 edge 線**；
- 15 條 edge 線是 **split**（同線兩列給出**不同**分割）；
- 16 條非 edge 線（6 vertex + 10 face）= **16 個相異二分割之雙射**（C9）。
- ⟹ 16 = 6 + 10 之「幾何來源」與「分割來源」是**同一個 16**：vertex/face 線貢獻「自身」那一刀，edge 線只貢獻「加料」。

**零點律（C8）**：edge 列恰垂直 **4** 行（edge 中點軸落在大圓上 ⟹ 4 個頂點恰垂直），vertex/face 列 **0** 行；
總零點 = 120 = 12 × 10 ⟹ 平手（tie）**只發生在 edge 族**，且是「4/12」型的結構性平手。

**重數解剖（C10/C11）**：把 62 列按「同分割」歸類，每型重數 = 2（自身線之兩列）＋ edge 族加料：

| 型 | 幾何身份 | 自身 | edge 加料 | 重數 |
|---|---|---|---|---|
| V-type ×6 | **閉鄰域 N[v]**（icosahedron 圖，6/6 命中，C11） | 2 | 5,5,5,5,5,7（五個 5、一個 7） | 5×5, 1×7 |
| F-type ×10 | face 線 | 2 | 各 1 | 全部 3 |

合計 30 + 25 + 7 = 62 ✅；直方圖 `{3:10, 5:5, 7:1}` 完全對上（C6）。
**讀法**：`N[v]` 那一刀（=「與 v 同側的閉鄰域 vs 其補」）被 **5 條 edge** 額外複製，`N[v*]`（唯一的那個）被 **7** 條 edge 複製 ⟹ 資源幾何把 31 條軸壓成 16 種可分辨「切法」，而 edge 族是**冗餘的供給源**。

## §3 幀計數閉式（C12–C14）

**定義**：`F_k = #{ S ⊆ [62] : |S| = k, S 分離全部 C(12,2) = 66 個行對 }`（= k 個設定合起來即可唯一識別 12 狀態）。

三條獨立路線（**互相對帳**）：

1. **(A) brute force DFS**：bitmask over 66 行對，剪枝；
2. **(B) partition-lattice Möbius**：`β(π) = #{a : π ≤ π_a}`，`F_k = Σ_{T ⊆ 𝒯, ⋁T = 0̂} e_k(T)`；
3. **(C) type-set**：`F_k = Σ_T e_k(T)`，`T` 為 16 型之子集，分離 ⟺ join = 離散分割。

**結果（三路全中）**：

| k | F_k | 備註 |
|---|---|---|
| 1 | 0 | |
| 2 | 0 | |
| 3 | 0 | |
| 4 | **12 645** | 上游值重現（C3）✅ |
| 5 | **1 051 351** | 本輪新增 |
| 6 | **23 083 292** | 本輪新增 |
| 7 | 283 782 566 | 閉式（非 brute） |
| 8 | 2 471 290 760 | 閉式（非 brute） |

- `k_min = 4`（幀最小規模 = 4 個設定）；`C(62,4) = 557 845`，故 F_4 佔 **2.2668%**。
- **分離型集大小譜**（C13）：`{4:55, 5:1248, 6:5028, 7:9660, 8:12195, 9:11290, 10:7993, 11:4368, 12:1820, 13:560, 14:120, 15:16, 16:1}`；**型集大小 ≤ 3 者不存在**（k_min ≥ 4 之型集層證明）。
- **Möbius β-譜**（C12）：`{3:284550, 5:131515, 6:19305, 7:26303, 8:46900, 9:810, 10:13220, …, 62:1}`（唯一 β = 62 者即 0̂ 被排除）。
- **族混合分解（C16）**：F_4 = 12645 = 625 + 1980 + 920 + 1860 + 2480 + 460 + 800 + 1520 + 1040 + 80 + 480 + 240 + 160（按 V/F/E 組成逐項列出；**EEEE = 625 = 5⁴**）。

**閉式（本輪主定理，機器無關形式）**：

```
F_k = C(N,k) + Σ_{π ≠ 0̂} g(π) · C(β(π), k)          g(π) = ∏_{B ∈ π} (−1)^{|B|−1}(|B|−1)!
```

- `β(π) = #{a : π ≤ π_a}`（π 細於 π_a ⟺ 該列在所有 π 之塊內為常數）。
- 對照全 462 二分割之純組合 null：`p₀ = F_4(462)/C(462,4) = 6240/180251 = 0.0346184`（C17-c，精確；MC 交叉核對）。
- **非分離 -c 標記**：本定理對任何「(m/2,m/2) 二分割排列 + 平手規則」機器成立，本輪只在 icosahedral 機器與 pts = 4/6 小反例上驗證。
