## 1. §A (1) B = 4 嘅推導

### 1.1 ★★ 鏡像恆等（o160 docs/06 §4）

鏈譜 `γ_k = 4sin²(kπ/176)`，`k = 1..88`。以中心模 `k = 44` 為軸嘅**鏡像對**：

```
γ_{44+j} + γ_{44−j} = 4sin²(π/4 + x) + 4sin²(π/4 − x),   x = jπ/176
                    = 4[sin²(π/4+x) + sin²(π/4−x)]
                    = 4 · 1  =  4        ∀ j = 1..43
```

因為恆等式 `sin²(π/4+x) + sin²(π/4−x) = 1`（**代數恆等，唔係數值巧合**）。

**`j = 0` 退化**：`2γ₄₄ = 4 ⟹ γ₄₄ = 2 = μ²`（中心模定理）。

```
⟹ B = 鏡像對和 = 2γ₄₄ = 2μ²
```

## 2. §B (2) α⁻¹ = 繞數（唔係公設）

### 2.1 ★★ 端點結構 ⟹ Δα⁻¹ = (B−1)²

IDCM 兩個端點（o142/O160）：

```
α⁻¹(0)   = C(B²,2) + F_proj        (投影錨)
α⁻¹(M_Z) = C(B²,2) + 2B            (Z 極點)

```

```
Δα⁻¹ = F_proj − 2B = (B²+1) − 2B = B² − 2B + 1 = (B−1)²
```
