## 6. §E 離散 1-loop 顯式（確認 3g 貢獻 = 0）

| chk | 內容 | 結果 |
|:---:|:-----|:-----|
| E1 ★ | link propagator `V = 2(G₀₀ − G₀₁) = (N−1)/N = 87/88` 精確閉式 | ✅ `0.9886363636` |
| E2a ★ | Wick 收縮和：`S₁ = S₃ = C_F²N_c = 16/3`（planar）；`S₂ = −2/3`（crossed） | ✅ |
| E2b ★ | `⟨Tr[D⁴]⟩ = (S₁+S₂+S₃)V² = 10V²`，`10 = (N_c²−1)(2N_c²−3)/(4N_c)` EXACT | ✅ |
| E3 ★ | `⟨Tr[C²]⟩ = −12(G₀₀² − G₀₁²)`（顯式 Wick，`Σf² = 24`）—— 唯一 4g tadpole，**發散 ∝ log N** | ✅ |
| E4 ★ | 3g = 0 ⟹ **唯一 1-loop 自能圖 = 4g tadpole** | ✅ |
| E5 🟡 | 觀察：`10 = (10/3)C_A` —— **僅 N_c = 3 成立**（N_c = 4 時 27.19 vs 13.33）⟹ 巧合，非恆等 | ✅ |

### ★ E1 推導（解析）

環 Green 函數 `G_{ij} = (1/N)Σ_{n≠0} e^{2πin(i−j)/N}/λ_n`，`λ_n = |1−e^{2πin/N}|²`：

```
G₀₀ − G₀₁ = (1/N)Σ_{n≠0}(1−e^{2πin/N})/λ_n = (1/N)Σ_{n=1}^{N−1} 1/(1−e^{−2πin/N})
```

用單位根恆等式 `Σ_{n=1}^{N−1} 1/(1−w^n) = (N−1)/2`（w = 原根）：

```
G₀₀ − G₀₁ = (N−1)/(2N)  ⟹  V ≡ 2(G₀₀−G₀₁) = (N−1)/N = 87/88  EXACT
```

### 判決 (E)

> **🟢 3g = 0 下，唯一 1-loop 自能圖係 4g tadpole。**
> 4g tadpole 貢獻 `⟨Tr[D⁴]⟩ − ⟨Tr[C²]⟩`，其中 `⟨Tr[C²]⟩` **發散 ∝ log N**。
> 呢個發散係「質量型」（tadpole），**唔係耦合重整** ⟹ 1-loop **冇耦合 running**。

### ★★ 核心結論

> **3g = 0 唔會令 b₀ = 7 失效 —— 因為 b₀ = 7 從來唔係圈係數。**
> 3g = 0 令**圈推導**（O142 §1.1）崩潰，但 `b₀ = L₄ = 7` 係 **T̂ 不變量**，
> 零圈輸入，**存活**。
> 而且 3g = 0 同 O139（繞數 running，冇圈）**互相印證** ——
> 兩條獨立路徑（頂點代數 / 繞數計數）都指向：**IDCM 冇 1-loop β 函數**。
> ⟹ 「3g = 0 對 b₀ = 7 嘅 1-loop 一致性」係 **ill-posed**；正確講法係
> **「b₀ = 7 唔係 1-loop 量，而係 T̂ 結構不變量」**。
