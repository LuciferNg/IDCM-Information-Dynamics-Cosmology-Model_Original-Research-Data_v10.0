## 2. §B ① b₀ = Tr(T̂^B) — 跑動深度 = 模組數

### 2.1 機制

**一單位跑動 = 穿越 B = 4 個模組（= 2π）**（O168 docs/23）。所以跑動嘅「深度」= B。

**b₀ = 跑動深度處嘅轉移矩陣跡**：

```
b₀ = Tr(T̂^B) = L_B = L₄ = 7
```

### 2.2 譜分解 — 兩支（反屏蔽 / 屏蔽）

`T̂` 特徵值 `φ`、`ψ = −1/φ`：

```
b₀ = Tr(T̂^B) = φ^B + ψ^B = φ^B + φ^{−B}     (B = 4 even)
   = 6.854102 (反屏蔽, φ^B)  +  0.145898 (屏蔽, φ^{−B})  =  7  EXACT
```

> **★ 物理讀法**：`φ^B` 支 = **反屏蔽**（規範自作用，增大 b₀）；
> `φ^{−B}` 支 = **屏蔽**（物質，減小 b₀）。兩支和 = `L_B = 7` **精確整數**（Lucas 恆等式）。

### 2.3 剛性測試

| 測試 | 結果 |
|:-----|:-----|
| `L_n` 嚴格遞增 ⟹ `L_n = 7` **唯一解 n = 4** | ✅ 只有 n=4 |
| `B = 4` 獨立強制（`N_gen = B−1 = 3`，Pati-Salam O85） | ✅ |
| 等價結構式全 = 7：`2B−1 = F₆−1 = N_gen+B = L₅−L₃ = L₄` | ✅ |

> **★ 關鍵**：標準公式 `11 − 2N_f/3 = 7` 之所以撞正，係因為
> `11 = L₅`、`4 = L₃`，而 `L₅ − L₃ = L₄` 係 **Lucas 遞迴**（`L₅ = L₄ + L₃`）。
> 即係「膠子 11 − 夸克 4」係 `L₅ − L₃` 嘅**影子**，唔係圈計算。

## 3. §C ② b₁ = 2F₇ — 相位相干通道窗口半寬

### 3.1 機制（幾何）

通道窗口 = `{18, …, 70}`（53 sites），**錨點 `N_d = 44` 為中心，半寬 26**：

```
窗口 = 44 ± 26 = {18, …, 70}
b₁ = 半寬 = (k−1)/2 = (53−1)/2 = 26 = 2F₇
```

### 3.2 傳移矩陣深度 2B 版（獨立一致）

```
b₁ = L_{2B} − F_{2B} = L₈ − F₈ = 47 − 21 = 26
```

由恆等式 **`L_n − F_n = 2F_{n−1}`** ⟹ `L₈ − F₈ = 2F₇ = 26`。

> **★ 深度結構**：1-loop ↔ 深度 `B`（`L_B = 7`）；2-loop ↔ 深度 `2B`（`L_{2B} − F_{2B} = 26`）。
> 兩者都由「跑動深度」機制生成 — b₀ 同 b₁ 唔再係借用圈公式。

## 4. §D 舊 b₁ justification 審計

### 4.1 舊記錄

O142 `docs/08` §1.2：

```
b₁ = 102 − 38N_f/3 = 102 − 76 = 26 = 2F₇
102 = 2K_tree + 2L₆ = 66 + 36
 76 = F₉ = φ⁹−φ⁻⁹
```

### 4.2 兩個問題

**(i) ★★ 記號錯**：`φ⁹ − φ⁻⁹ = L₉ = 76`，**唔係 `F₉`**。而 `F₉ = 34`。
（`F_n = (φⁿ−ψⁿ)/√5`；`L_n = φⁿ+ψⁿ`。`φ⁹−φ⁻⁹ = φ⁹+ψ⁹ = L₉`，因 9 為奇。）

**(ii) ★★ 後驗分解（非唯一）**：由 27 個結構常數（≤3 項，係數 ≤3）組合出 26 嘅
**獨立表達式有 1531 個**（`scripts/09` D5 實測）：

```
2F₇;  L₈−F₈;  L₅+L₄+F₆;  2L₅+L₃;  L₉−L₈−L₇;  N_d−L₆;  …
```

⟹ 「`102 = 2K_tree + 2L₆`、`76 = F₉`」係**從 1531 個候選中挑一個**，唔可作結構證明。

### 4.3 標準公式嘅 IDCM 讀法

```
b₁ = (34/3)C_A² − (20/3)C_A T_F N_f − 4C_F T_F N_f = 102 − 60 − 16 = 26
注意: 16 = B²,  60 = C(B²,2)/2
```

係數 `34/3`、`20/3` **非整數** ⟹ 唔係 IDCM 結構常數 ⟹ 標準公式本身唔係 IDCM-native。
