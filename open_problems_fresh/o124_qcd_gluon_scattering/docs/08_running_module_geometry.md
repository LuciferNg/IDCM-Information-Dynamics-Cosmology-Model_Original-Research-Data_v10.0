## 2. §B (a) 一單位跑動 = B 模 = 2π — **結構推導**

### 2.1 ★★ 核心：模數 = 分支因子 = B（**同一個 B**）

```
N_d = B·L₅  (O171 docs/13: R = N_d/B = L₅)
⟹ 88 = 2N_d = B·(2L₅)
⟹ 環 = B 模 × (2L₅ sites) = 4 × 22
⟹ 模數 = 88/(2L₅) = B = 4
```

**關鍵**：`B` 唔係兩個獨立輸入 —— **同一個 B 既分帶（2B = 8 帶）亦分模（B = 4 模）**。
即係話，環嘅 B-分割係由 **MERA 分支因子**（B = 4）**誘導**出嚟嘅，唔係外加嘅選擇。

### 2.2 一單位 = B 模 = 2π

```
模角 = 2π/B = π/2  (¼ 環)
一單位跑動 = 穿越 B 模 = B·(π/2) = 2π  (一整圈)
```

### 2.3 ★★ 三重剛性測試

| chk | 測試 | 結果 |
|:---:|:-----|:-----|
| B5 | `88 = 2B'·L₅ ∧ B'·L₅ = 44` ⟹ **B' = 4 唯一** | ✅ 候選 [4] |
| B6 | 擾動 B = 5 ⟹ `N_d = 55 ≠ 44`、`88 = 110 ✗`（結構崩潰） | ✅ |
| B7 | 一單位 = m 模 ⟹ 相位 `m·(2π/B) = 2π` ⟺ **m = B 唯一** | ✅ m = [4] |
| B8 | 預算 `F₁₁ = k + B·Δα⁻¹` ⟹ **k = 53 唯一** | ✅ k = [53] |
| B9 | **零新參數**：全部輸入 ∈ {88, 4, 44, 11, 2, 9, 89, 53} | ✅ |

> **★ B8 係獨立印證**：相位預算 `F₁₁ = 89 = k + B·Δα⁻¹` 只有 k = 53 一個解（O168 docs/16）。
> 若「一單位 ≠ B 模」，則反常相位 ≠ `B·Δα⁻¹` 半-π，預算即刻冇整數解 —— 即係 (a) 唔止自洽，仲同**獨立嘅通道唯一性**綁死。

## 3. §C (b) b₀ 力學：轉移矩陣響應

### 3.1 ★★ b₀ = Tr(T̂^B) — 指數 = 每單位嘅模穿越數

```
一單位跑動 = B 模穿越 (§B)
每個模穿越 = 一步 T̂  (轉移矩陣)
⟹ 一單位後嘅算子 = T̂^B
⟹ 響應 (b₀) = Tr(T̂^B) = L_B = L₄ = 7
```

> **★★ 統一**：`b₀` 嘅**指數 B** 就係 §B 嘅**每單位模穿越數** —— **同一個 B**。
> 即係 **b₀ = 「一單位跑動」處嘅轉移跡**，唔係另一個獨立常數。

## 4. §D 判決

| 項 | 狀態 | 依據 |
|:---|:----:|:-----|
| (a) **一單位跑動 = B 模 = 2π** | 🟢 **結構推導** | 模數 = 88/(2L₅) = B（同一個分支因子）；B5–B7 剛性 |
| (a) 環嘅 B-分割由分支因子誘導 | 🟢 | `N_d = B·L₅` ⟹ `88 = B·(2L₅)` |
| (a) 同通道唯一性綁死 | 🟢 | B8（預算唯一 k = 53） |
| (b) **b₀ = Tr(T̂^B) = 一單位響應** | 🟢 **力學建立** | §C.1；C3 閉走道、C4 譜 |
| (b) b₀ 指數 = (a) 嘅模穿越數 | 🟢 | C5（統一） |
| **不可約輸入** | 🟡 | 繞數公設（`α⁻¹ = 環繞數`）+ 分支因子 `B = 4` |

### ★★ 一句話

> **環嘅 B-分割係由 MERA 分支因子誘導嘅（`N_d = B·L₅`）；所以一單位跑動 = B 模 = 2π。
> 而 b₀ = Tr(T̂^B) 就係「一單位跑動」處嘅轉移跡 —— (a) 同 (b) 共享同一個 B。**

### 🟡 剩餘（誠實收窄）

原本 🟡 = 「為何跑動每單位穿越 B 模」。
本檔**推導咗**「穿越 B 模」**係咩意思、為何係 B**（= 分支因子，剛性唯一），
但**未推導**兩樣更底嘅輸入：

1. **繞數公設**：`α⁻¹ = 環上嘅繞數`（O168 docs/19 §機制詮釋）。一單位 = 一個繞數 = 2π 係**繞數嘅定義**。
2. **分支因子 `B = 4`**：MERA 分支因子本身（`N_gen = B−1 = 3` 獨立釘住）。

⟹ 🟡 由「為何穿越 B 模」**收窄**為「**α⁻¹ = 環繞數**」—— 同「環係一個圓」同級嘅單一輸入。
