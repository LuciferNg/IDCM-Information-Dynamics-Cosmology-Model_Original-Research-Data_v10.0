## 六、判決 + 物理理由

### 判決

🔴 **channel-level em 讀數算子冇純群論形式** —— 三重獨立證據：
1. B1 差值族 21 候選 0 命中（最佳 22.33σ）
2. B2 絕對族 1800 候選 0 命中（最佳 7.54σ）
3. C 結構論證：同 Δ 量子數通道 spread 5.557 MeV（群論不可分辨）

### 物理理由（為何必然）

em 質量分裂 = QED 自能差：

```
ΔM_em ∝ ⟨ Σ_{i<j} q_i q_j / r_ij ⟩ + Σ_i q_i² Δm_i
           └── 群論（分子，電荷量子數）──┘   └── 動力學（分母，波函數重疊）──┘
```

群論只決定**電荷量子數**（分子）；`⟨1/r_ij⟩` 係**波函數重疊**（分母，動力學）。
同一組量子數、唔同 spectator 波函數 ⟹ 唔同 E。

**⟹ 呢個係範疇定理，唔係參數不足。** M4 docs/18 §五.4 嘅判斷（「operator 必須含
mode-level 資訊」）**方向正確**，但需再進一步：唔止 mode-level，「波函數重疊」
本質上係連續動力學量。
