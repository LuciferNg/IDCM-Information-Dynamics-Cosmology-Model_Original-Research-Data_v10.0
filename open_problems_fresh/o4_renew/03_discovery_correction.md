## 第二部分: 修正 (Corrections)

### 修正 1: C01 script 冷斑 reference 數字

- **錯誤**: 「已知冷斑 Galactic ≈ (263.86°, −48.74°)」
- **正確**: 冷斑 Galactic = (209.0°, −57.0°) (Cruz 2005)
- **修正方式**: C01_map_sampling.py line 64-66 改為 (209.0°, −57.0°)
- **影響**: 冇 (計算用 astropy 轉換, 唔靠 reference)

### 修正 2: A01 script 面遍歷 bug

- **錯誤**: `nxt[(v, nb)]` 用咗 v 嘅 order 而非 nb 嘅 order → KeyError (9, 20)
- **正確**: 預先計算所有頂點嘅有序鄰居 `all_order`, 再建 nxt mapping
- **修正方式**: A01_geometry_basics.py 重寫 nxt 建構部分
- **影響**: 修正後面遍歷成功 (62 面, 20Δ+30□+12⬠)

### 修正 3: D01 script 5lv/6lv generator bug

- **錯誤**: `np.array([...] for i in range(60))` generator → object array, TypeError
- **正確**: `np.array([...])[[min(dist[i], 5) for i in range(60)]]` fancy indexing
- **修正方式**: D01_stats_full.py line 73-78
- **影響**: 修正後 BIC 完整表成功輸出

### 修正 4: D03 script angdist format bug

- **錯誤**: `np.degrees(ang)` 係 array, `:.2f` format 失敗
- **正確**: `np.degrees(ang)[0]`
- **修正方式**: D03_coldspot_position.py line 37
- **影響**: 修正後冷斑定位輸出成功
