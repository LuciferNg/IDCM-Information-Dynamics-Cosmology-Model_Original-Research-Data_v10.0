## 零、問題

O177 殘餘攻堅結論: 池/圈 = 364 (dev 0.0146%) 同 364+B/75 (δ-dev 0.035%) 兩候選
**統計不可分辨** (δ = +0.0533 = 0.005σ), 因為輸入精度太低:

- M_med = 6.97e6 M☉ → 3-sf (±0.5%), λ_Edd = 10% 假設 (O173 record 11/12, ratio 0.9994)
- t_active = 11e9 yr → 2-sf (±5%), z≈9→0 渲染窗口 (O173 script 01 保守值)

分辨需要: **M ≥ 5-sf (σ_M < 0.0029%) + t ≥ 4-sf (σ_t < 0.029%)**, 3σ。

**問題**: 呢兩個精度天文上攞唔攞到? 攞到就判決候選; 攞唔到就明確 gate 邊個輸入卡死。

## 三、攻堅路徑 (已執行)

1. **文獻審計**: COSMOS-Web 目錄質量誤差 (散佈 0.428 dex, 每對象 ±0.35 dex);
   JWST 後續質譜 (Nature 2025 electron-scattering 展寬 → virial 高估數個數量級;
   arXiv:2609.09265 quasi-star 差 5 decades) → **天文 scatter 已封死 5-sf** ✅
2. **λ_Edd 傳播**: λ=10% 假設不確定度 ≥±0.5 dex (方法分歧) → M 系統誤差 216%,
   common-mode 不可平均 → M 5-sf 天文不可達 → 需 PDF 摺積替代 ✅
3. **窗口天文化**: Δt(9→0) = 13.256 Gyr (Planck 2018, σ=1.02%);
   N(z)∝1/(1+z) 加權 t_eff = 7.620 Gyr (−42.5%); Δt(9→2) = 2.729 Gyr (−79.4%)
   → t 4-sf 不可達 (宇宙學 35× + 定義依賴 20-79%) ✅
4. **判決輸出**: 🔴 gated (永久) — M_med 主卡 + t_active 次卡;
   PDF 摺積替代路徑量化 (6.1%→3.9%, 仍 792× 過粗) ✅

⚠️ 紀律: 判決由獨立文獻誤差預算得出, 冇調整 λ 或窗口湊候選。
