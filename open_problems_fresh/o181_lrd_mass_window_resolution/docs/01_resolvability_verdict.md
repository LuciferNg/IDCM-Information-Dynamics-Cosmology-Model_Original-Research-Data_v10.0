## 1. 問題重述

O177 docs/02 結論: 池/圈 = 364 (dev 0.0146%) 同 364+B/75 (δ-dev 0.035%)
**統計不可分辨** (δ = +0.0533 = 0.005σ), 因為輸入精度太低:
- M_med = 6.97e6 M☉ → 3-sf, λ_Edd = 10% 假設
- t_active = 11e9 yr → 2-sf (z≈9→0 渲染窗口)

可分辨路徑預言: **M ≥ 5-sf (σ_M < 0.0029%) + t ≥ 4-sf (σ_t < 0.029%)**, 3σ。
O181 問: 呢兩個精度天文上攞唔攞到?

### 2.2 λ_Edd 傳播 (判準 2)

M_obs ∝ Lbol/λ → **σ_logM = σ_logλ (common-mode, 全部 434 同一假設, 唔會 √n 平均)**。
文獻方法分歧 ≥ ±0.5 dex (保守下界) = **216% 相對系統誤差**。
即使採樣誤差歸零, λ 誤差都 ≫ 0.003% — M 5-sf 永久卡死。

## 4. ★ 附帶 errata: O177 docs/02 B/75 候選 = 3-sf 捨入假影

O177 殘餘攻堅用咗 **3-sf 捨入值** M = 6.97e6 (O173 C2 記錄格式)。
但 catalog 實際 median (little_red_dots/data/11_cosmosweb_tests.json) =
**6,973,199.696** (7-sf, λ=10% 假設, script 11 直接計算)。

```
池/圈 (3-sf M=6.97e6)  = 364.053314767   ← O177 記錄值
池/圈 (exact M)        = 364.220439585
δ(exact) = +0.2204  (dev 0.0606%)        ← 4.13× O177 記錄 δ = +0.0533
B/75 = 0.05333 只覆蓋 24.2% 殘餘          ← 唔再係「唯一候選」

統計判決不變: δ = 0.2204 / σ(採樣+宇宙學) = 0.0098σ ≪ 1σ → 364 身份站得住
```

**結論**:
- O177 Part C「最小移動 = M 3-sf 捨入向上」**方向錯** — catalog median 高過 6.97e6
  (6,973,199.696 > 6,970,000), 用真實值反而令殘餘加大 4.13×
- O177 Part D「唯一候選 δ = B/75 (dev 0.035%)」= **3-sf 捨入假影** — exact M 下
  B/75 覆蓋率只有 24%, 唔係殘餘嘅結構解釋
- O177 Part E「主張 2 零捨入假設」失效 — 真實 median 唔係 6.9700004e6
- **O177 閉合維持**: 殘餘 = 0.0098σ, 364 結構身份統計一致
- **B/75 候選降級**: 由「🟡 有趣觀察」→ 捨入假影 (唔宣稱結構, 唔當候選)
