## 推導鏈（全部 EXACT 有理算術）

```
sin(2Nθ) = sin^{2N}(θ)·P(cotθ),  P(u) = Σ_j (−1)^{N−1−j} C(2N,2j+1) u^{2j+1}
⟹ P 根 = {cot(πm/2N), m=1..2N−1} = {0} ∪ {±r_m}, r_m = cot(πm/2N)
⟹ Q(z) := P(u)/u|_{u²=z} = 2N·Π_{m=1}^{N−1}(z − r_m²),  [z^j]Q = (−1)^{N−1−j}C(2N,2j+1)
⟹ monic q = Q/2N ⟹ Newton 恆等式 ⟹ p_j := Σ_m cot^{2j}(πm/2N)  (Fraction 精確)
⟹ csc²θ = 1+cot²θ ⟹ Σ_n csc^{2k}(πn/2N) = Σ_j C(k,j) p_j   (p_0 := N)
⟹ ζ_N(−k) = (1/4^k)·Σ_n csc^{2k}    （負矩家族由係數表直接推出）
```
