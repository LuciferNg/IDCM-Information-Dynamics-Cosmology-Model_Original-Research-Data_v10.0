## 通用化公式（N 通用 4g 頂點）

O124 scripts/05 嘅模空間張量（N=88 site 特例）通用化到任意 FSR 鏈長 N：

```
環 = 2N 個 site（88-site 雙鏈 = 2·44）; 動量守恆 mod-2N
V₄(N; n₁n₂n₃n₄; a₁a₂a₃a₄) = −(1/24)(1/(2N)²) · site_{2N}(Σn) · Σ_{δ∈{0,1}⁴} e^{2πi Σδₖnₖ/(2N)} T_δ
site_{2N}(Σn) = Σ_{m=0}^{2N−1} e^{2πi mΣn/(2N)} = 2N·δ_{Σn≡0 (mod 2N)}
色張量 T_δ       = 極化抽取（Q4 = Tr[D⁴]−Tr[C²], 16 維嵌入）— N 無關
U(1) 閉式:      V₄^U1 = −δ_{Σn≡0}·Π_k(1 − e^{2πin_k/(2N)})/(2N)
```

- **色代數隨 N 唔變**: su(3) f/d、Tr[T⁴] 分解、G_ss=72 全部係內部結構 — FSR 只改變動量標籤 n↔2N（O137 [B] 移植原則實證）。
