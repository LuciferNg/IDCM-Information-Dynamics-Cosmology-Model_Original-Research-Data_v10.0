## ★ 新閉式（T3 產物）

### 1. ζ_N(−k) = N·C(2k,k) + 4^k/2  EXACT（k ≥ 1）
v1 曾宣稱 ζ_N(−k) = N·C(2k,k) — 被實測否證（24/24 偏差）: Σ_{n=1}^N cos(jπn/N) = 0
只喺 j 偶數; j 奇數 = **−1**（幾何和 2z/(1−z) 實部 −1 — 半格點邊界, cos(π)=−1 唔畀消）。
⟹ 正確閉式含邊界修正 4^k/2 = 2^{2k−1}:
```
ζ_N(−k) = Σ_{n=1}^N ε_n^k = N·C(2k,k) + 4^k/2
例 (N=44): 90, 272, 912, 3208, 11600, 42704  (k=1..6)
```
推導梗概: sin^{2k}θ 展開 + 奇諧波 cos 和 = −1 ⟹ 修正 = 2Σ_{j odd}C(2k,k−j) = 2·4^{k−1} = 4^k/2。
60 位精度 24/24 命中; 代數推導可閉（j 奇數 cos 和為幾何級數）。**誠實註記**: O137 已知
Σγ_even = 90 同本閉式 k=1 一致 — 現為任意 k,N 嘅完整閉式族。
