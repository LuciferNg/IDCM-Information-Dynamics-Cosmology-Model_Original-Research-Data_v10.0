sector 計數由 A₅ 表示論數據生成: **表層 = 個別 irrep 維數 × L₅** (33,44,55)；
**深層 = 全積 (=群階 60) × L₄** (420)。層數 L₄ = 7 被兩條獨立約束唯一鎖定。

   **33/34 觀測檢定失敗** (統一因子同 A_s 簡併 ⇒ 原理上不可檢定) ⇒ 只靠結構身份。

   ★★ **深層 sector 算子身份 = 高斯整數範數算子** —— z = 14+15i ⇒ z² = −L₇ + 420i

## 關鍵公式
- 主形式: X_obs = X_bare·(d−1)/d，d = sector 態數 (1 個真空態)
- **家族 (四成員)**: 33/34 (K_tree+1) · 44/45 (N_d+1 = 88/90) · 55/56 (F₁₀+1) · **420/421** ((L₇²+1)/2)
- **階層律**: 表層 33,44,55 = dim·L₅ (dim ∈ A₅ 非平凡 irrep 維數 {3,4,5})；深層 420 = L₄·|A₅| = 7·60
- **rung law (R1b)**: d = g·L_m，每個成員 (g, m) **唯一** — 表層 (3,L₅)(4,L₅)(5,L₅)，深層 (60,L₄)
- **rung 指數導出 (R1b-指數)**: R = 2N_d/(2B) = 88/8 = 11 = L₅ (鏈週期, 由帶數 2B 導出) ⇒ 表層 m = 5；L_m = 420/|A₅| = 7 = L₄ ⇒ 深層 m = 4；交叉排除 (33/60,44/60,55/60 ∉ Lucas；420/3,420/4,420/5 ∉ Lucas)
- **帶指數定律 (R1b)**: 選中帶指數 n ∈ {3,4,5} = A₅ 非平凡 irrep 維數；null test 隨機命中 1/C(8,3) = 1.79%
- **型別二分 (R8)**: 表層 d = #{γ_k ≤ γ_{nR}} = nR (帶計數)；深層 d = (L₇²−1)/2 = 420 (軌道計數)；兩型互斥
- ★★ **高斯範數算子 (R8-算子)**: z = 2L₄ + (N_gen F₅)i = 14+15i ⇒ z² = −L₇ + 420i
  · 421 = N(z) = |z|² (分母) · 420 = Im(z²) = 2ab (分子) · 29 = |Re(z²)| = L₇
  · 420/421 = sin 2θ = Im(z²)/N(z)，tan θ = 15/14 · 29² + 420² = 421² (畢氏 (29,420,421))
  · 420 = L₇² mod 421，421 = (L₇²+1)/2 ⟺ L₇² ≡ −1 (mod 421) (L₇ = √−1 mod 421, ord = 4)
  · 421 質數 ≡ 1 mod 4 ⇒ 兩平方和表示唯一 ⇒ 錨對 (14,15) 被鎖定
- **和/積對偶 (R1b)**: Σ dim_i = 3+3+4+5 = 12 = B·N_gen = L₅+1；Π dim_i = 60 = |A₅| = Σ_all dim²
- **階層律分派 = 導出 (第五輪)**: 每個 d 嘅 (g, L_m) 分解唯一 (g ∈ A₅ 不變量 ∩ 因數, L_m ∈ Lucas)
  ⇒ 表層自動得 g ∈ {3,4,5} (單一 irrep), 深層自動得 g = 60 (全積)；反例排除 (33/60,44/60,55/60 ∉ Lucas; 420/3,420/4,420/5 ∉ Lucas)
  · 統一形式 d = (Π_{i∈S} dim_i)·L_{m(S)}, S ⊆ {3,4,5} (|S|=1 ⇒ L₅; |S|=3 ⇒ L₄)
  · 型別判定 ⚠️ 唔對稱: d > 2N_d ⇒ 必為軌道型 (有效); d ≤ 2N_d ⇒ 只係候選 (≤ 88 候選 36 個 ⇒ 唔足夠)
