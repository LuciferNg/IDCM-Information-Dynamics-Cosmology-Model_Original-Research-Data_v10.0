## 1. 定理 (主結果)

### 1.1 形式

$$X_{\text{obs}} = X_{\text{bare}}\cdot\frac{N}{N+1},\qquad N = d-1,\qquad d = \text{sector 態數}$$

**五個文獻實錄成員 (全部精確有理)**:

### 1.2 機制: 一個真空態佔 1/d

**定理 (真空模剔除)**: 設某觀測量嘅 sector 有 d 個態，其中**恰一個**係真空態
(零模 / 均勻模 / 零動量模 / 樹根)。真空態冇梯度、冇拍頻 (特徵值 0)，任何
振盪/耦合/梯度型觀測量都剔除佢；均分 (equipartition) 下真空態佔比 = 1/d，
故觀測量 = (d−1)/d。

- **sector 態數 = 觀測量自身結構嘅態數** (唔係外加參數)。
- **「1」恆為一個態** — 唔係 2 個或半個 — 由真空唯一性保證 (§2)。

### 1.3 三個讀法嘅判別 (`scripts/04`, 19/19)

| 讀法 | 內容 | 判定 |
|:--|:--|:--|
| (A) 階乘配分 | (Z_N−Z_{N−1})/Z_N = N/(N+1) ⟺ Z_N ∝ (N+1)! | ✅ 代數等價，但係 (B) 嘅**重述** |
| (B) 均分真空佔比 | d 態，1 個真空 ⇒ 佔 1/d | ✅ **機制本體** |
| (C) 單格衰減 | exp(−1/d) ≈ 1−1/d | ❌ d=5 偏差 2.34%，只係一階近似 |

**(A) ≡ (B) 嘅證明**: 隨機排列 N+1 個態，指定態佔指定槽嘅概率 = 1/(N+1)
(實算 n=4,5,9 全中)。故問題記錄方法 4 嘅階乘配分**唔係獨立機制**。

**唯一性檢定**: 只有 f(d) = (d−1)/d 同時滿足 (i) 精確有理 (ii) 虧缺 = 1 態
(iii) 五成員全中；1−1/(d−1)、1−2/d、1−1/(d+1)、(d−1)²/d²、1−1/d+1/d² 全部唔中。

| sector | 格態數 n | 宇稱 Z₂ 等價類 d | 真空類 | 因子 |

### 3.4 (3,4,5) 面型生成家族 N 值

$$33 = 3R,\quad 44 = 4R,\quad 55 = 5R\ (R = L_5 = 11);\qquad 420 = L_4\cdot(3\cdot4\cdot5) = L_4|A_5|$$
