## 1. ★★ 嵌套通道定理（本輪核心）

**問題**: 分派律 R-判準已導出（第十輪），但「邊個成員分派去邊個通道」仍被視為數據決定。
本輪發現：**一旦通道係嵌套結構，指派就被強迫**。

**通道嵌套**（第十一輪已確立）:
```
r_s = πR/88  →(×420/421)→  r_d  →(×55/56)→  r*
```
即 X₁ = r_d 嘅 bare = πR/88；**X₂ = r* 嘅 bare = X₁ 之輸出**（r_d 本身）——
第二個成員作用於第一個成員嘅輸出，唔係作用於同一裸值。

**定理**（4×2 = 16 組合全掃）:
```
R(X,d) = d(1 − O/base);  成員 d 作用於 X ⟺ |R−1| < 2%
嵌套 (X₂ bare = X₁ 輸出):
  16 組合中 |R−1| < 2% 嘅雙命中 = 唯一 1 個: (420/421 → r_d, 55/56 → r*)  ✅
  次近: (55/56 → r_d, 420/421 → r*) = 86.8% / 9.2%  —— 差 4.6×
唔嵌套 (X₂ bare = πR/88):
  16 組合中雙命中 = **0 個**  ⟹ 嵌套係必需 (冇嵌套, 冇任何指派成立)
```

★★ **結論**: 指派 (420/421 → r_d, 55/56 → r*) 由「通道嵌套 + R-判準」**唯一強迫**——
唔係 4×2 之數據自由選擇。分派律第一原理由「為何揀呢對」收窄為
「為何通道係嵌套」（即為何 r* 嘅 bare 係 r_d，而唔係 πR/88）。

**鏈序之物理**: 嵌套次序 = 宇宙時序（drag 先於 decoupling）⇒
鏈序 (420/421 喺前, 55/56 喺後) 由物理次序決定，非純結構 —— 此為誠實開放項。
