## 3. ★★ 更正二: σ(r\*/r_d) 之 naive 傳播**高估 7.9×**

### 3.1 問題

第九輪 (scripts/36) 用:

```
σ(r*/r_d) = sqrt( (0.26/144.43)² + (0.26/147.09)² ) = 0.25229%     (naive)
```

★ 但 r_d 同 r\* 係由**同一個參數後驗**導出之量 ⇒ 佢哋**高度相關** ⇒
獨立傳播嚴重高估。

### 3.2 四條獨立估算

| 方法 | 結果 |
|:--|--:|
| 線性參數響應 (CAMB 逐參數) | **0.03403%** |
| CAMB Monte Carlo (400 樣本, Ω_b h²) | **0.03222%** |
| CAMB Monte Carlo (400 樣本, Ω_b h² + Ω_c h², ρ = −0.6) | **0.03209%** |
| 欄間散佈 (排除 c3 = EE, n = 5) | **0.03180%** |
| CAMB 7 點網格 (scripts/40 獨立) | **0.03418%** |

★★ **五條路徑一致於 0.032–0.034%** ⇒ 真值 = **0.032%**, naive 高估 **7.9×**。

### 3.3 物理內容

- r\*/r_d 對參數之依賴**幾乎只有 Ω_b h²**:
  `∂ln(r*/r_d)/∂(Ω_b h²) = +0.03402% / 1σ`;
  Ω_c h² 貢獻 +0.00103%; H₀ 貢獻 0.00000% (因 r_d 同 r\* 同步標度)。
- **反解相關係數**: `ρ(r_d, r*) = 0.98398` (由 σ_naive 同 σ_true 反解)
  ⇒ r_d 同 r\* 幾乎完全相關, 獨立傳播必然失效。
- 欄間散佈 (0.0318%) 同參數傳播 (0.0321%) 獨立吻合 ⇒ 交叉確認。
