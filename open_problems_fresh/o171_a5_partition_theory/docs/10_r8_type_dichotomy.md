## 1. 問題陳述

docs/04（R1）嘅階層律講：**表層 = 單因子·L₅ / 深層 = 全積(=|A₅|)·L₄**。
R8 問：表層／深層係咪對應「**鏈 sector**（chain）vs **樹 sector**（tree）」？

本節把「型別二分」講成**生成公式**層面嘅分別：

| 型 | 生成公式 | 計數對象 |
|---|---|---|
| **帶計數型**（表層） | `d = #{γ_k ≤ γ_{nR}} = nR` | 鏈譜**前綴**（鏈 sector） |
| **軌道計數型**（深層） | `d = (L² − 1)/2` | Z₂ 折疊**軌道**（格／樹 sector） |

---

## 2. 檢定（C3）

### (i) 帶計數型

| n | d = nR |
|---|---|
| 3 | 33 |
| 4 | 44 |
| 5 | 55 |

（R = L₅ = 11 = 88/8 = 鏈週期）

### (ii) 軌道計數型

$$L_7 = 29:\quad \frac{L_7^2 - 1}{2} = \frac{841-1}{2} = 420 \quad\text{(C3 PASS)}$$

### (iii) 互斥檢定

| 檢定 | 結果 |
|---|---|
| 表層 (33,44,55) 可否寫成 (L²−1)/2？ | **否** —— 無整數解（C3b PASS） |
| 深層 420 可否寫成 nR？ | **否** —— 420/11 = 38.18 ∉ ℤ（C3c PASS） |
| 420 是否超出鏈帶範圍？ | **是** —— 420 > 88 = 鏈全長（C3d PASS） |
| 鏈帶前綴和 {11,33,66,110,165,231,308,396} 含 420？ | **否**（C3e PASS） |

⇒ ★ **型別二分成立**：表層 = 帶計數型（鏈譜）；深層 = 軌道計數型（格軌道）。
⇒ 生成公式**唔同** ⇒ 兩層唔係同一條公式嘅不同參數。

## 3. 與 docs/04 錨定理嘅一致性

docs/04（R1）獨立證明：`N/(N+1) = 2ab/(a²+b²)` 有整數解 ⟺ |a−b| = 1，
⇒ 420/421 係家族**唯一「sin 2θ 型」**成員（14²+15²，|a−b| = 1）。

本節嘅型別二分**同一方向**：
- 表層 33/44/55 用**鏈譜**（無連續對表示）；
- 深層 420 用**格軌道**（有連續對 (14,15)）。

⇒ 兩條獨立路徑指向同一個二分 ⇒ 交叉確認（唔係同源重複，因為一條係**代數恆等**，一條係**計數幾何**）。
