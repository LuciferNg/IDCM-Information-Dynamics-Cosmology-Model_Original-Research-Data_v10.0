## 2. sector 90 之結構身份（三重）

```
Σγ_odd  = 88 = 2N_d          (EXACT)
Σγ_even = 90 = N_gen²(L₅−1) = 9·10 = F₁₁+1 = 89+1
Σγ_all  = 178 = 2F₁₁
```

解析基礎（60 dps 全驗，7 個 n）：`Σ_{k=1}^{n−1} sin²(πk/n) = n/2`；
`n = 176` 半和 = 44.5 = 89/2 ⇒ `Σγ_all = 4·44.5 = 178`。

⚠️ 譜比 `88/90 = 44/45`（家族成員 44/45 之譜身份）；`89/90 ≠ 88/90` ⇒ **冇譜身份**（與 `scripts/09` 降級一致）。

## 3. ★ 可檢定性分裂定理

> **定理**：設家族成員之 sector 態數為 `d`，修正因子 `U = (d−1)/d`。則
> - **偵測**（U ≠ 1 抑或 U = 1）需精度 `σ < 1/(2d)`
> - **識別**（邊個 d）需精度 `σ < 1/(2d(d−1))`
> ⇒ 識別門檻 / 偵測門檻 = **`d − 1` 倍**

| d | 成員 | 偵測需 σ < | 識別需 σ < | 識別/偵測 |
|:--|:--|:--|:--|:--|
| 34 | 33/34 | 1.4706% | 0.04456% | 33× |
| 45 | 44/45 | 1.1111% | 0.02525% | 44× |
| 56 | 55/56 | 0.8929% | 0.01623% | 55× |
| **90** | **89/90** | **0.5556%** | **0.00624%** | **89×** |
| 421 | 420/421 | 0.1188% | 0.000283% | 420× |
