## 2. 三分解定理

「33/34 可否檢定」其實係**三個精度需求唔同**嘅問題：

| 問題 | 內容 | 差距 gap | 需 σ < | 現時精度比 |
|:--|:--|:--|:--|:--|
| **Q1 偵測** | U ≠ 1 抑或 U = 1（有冇修正） | 1/d | 1/(2d) | d=34: **1.93×** |
| **Q2 識別** | U = 33/34 抑或 0.97（邊個有理值） | 0.0606% | 0.0303% | **93.9×** |
| **Q3 絕對錨定** | rms 能唔能鎖死峰幅標度 | — | 需 Δℓ_eff 橋樑 | **結構不相容** |

現時精度 σ(D₁)/D₁ = 2.844%。

### 關鍵：Q2/Q1 精度需求相差 d−1 倍

```
Q1 門檻 = 1/(2d)          Q2 門檻 = 1/(2d(d−1))      比值 = d − 1
d = 34: 1.4706%  vs  0.04456%   →  33×
```

⇒ `docs/12` 嘅「不可檢定」講 **Q2**（正確）；`docs/16` 嘅「可檢定」講 **Q1**（正確）。**兩者唔矛盾，但必須分開標示。**

## 3. Q3：歸一化鏈為何係「結構不相容」而非「未建立」

恆等式（橋樑）：

```
(ΔT/T)²_rms · T_CMB²  =  Σ_m Δℓ_m · w_m,    w_m ≡ (2ℓ_m+1)·D_{ℓ_m} / (2ℓ_m(ℓ_m+1))
```

左邊 = (ε_φ⁵/8 × 2.72548e6 μK)² = (29.9996 μK)² = **899.97 μK²**（IDCM 零參數預測）。

用 Planck 分箱譜（ℓ = 220/528/792/1012/1188）算 w：

| m | ℓ_m | D_ℓ (μK²) | w_m (μK²/Δℓ) |
|:--|:--|:--|:--|
| 1 | 220 | 5816.48 | 26.379 |
| 2 | 528 | 2579.22 | 4.880 |
| 3 | 792 | 2552.73 | 3.221 |
| 4 | 1012 | 1246.29 | 1.231 |
| 5 | 1188 | 822.19 | 0.692 |
| | | **Σw** | **36.403** |

反解均勻 Δℓ_eff = 899.97 / 36.403 = **24.7227**。

**三項障礙**：
1. Δℓ_eff 無唯一結構身份（<1% 命中 2 個：421/F_proj = 24.76、123/F₅ = 24.6）⇒ 唔可以當導出
2. 第一峰 m=1 佔 Σw 嘅 **72.5%** ⇒ 反解值唔穩健
3. 結構猜測 Δℓ_m = 峰距/L₅ = 4(8−m) 得 **939.7 μK²**（dev **+4.4%**）⇒ **唔閉合**

**根本原因**：
- 連續譜：(ΔT/T)² = ∫dℓ (2ℓ+1)/(4π) C_ℓ —— Δℓ 係測度，由 ℓ 連續性提供
- **IDCM 譜係離散**：只有峰位 {ℓ_m} + 峰高 {D_m}，**冇** Δℓ 測度

⇒ 橋樑所需之 Δℓ_eff **唔係 IDCM 導出量**。錨 (rms) 唔能自動鎖死峰幅標度。
⇒ **Q3 係結構不相容（唔係待辦工程項）**，`docs/16` §9 之「錨定令 33/34 可檢定」**降級**為只對 Q1 成立。

## 4. 附：峰距之組合恆等（新）

O9 峰位 `ℓ_m = 44(M − C(9−m,2))`，M = 33：

```
ℓ_m:  220, 528, 792, 1012, 1188
峰距 Δ_m = ℓ_{m+1} − ℓ_m = 44(8−m)  =  308, 264, 220, 176
```
