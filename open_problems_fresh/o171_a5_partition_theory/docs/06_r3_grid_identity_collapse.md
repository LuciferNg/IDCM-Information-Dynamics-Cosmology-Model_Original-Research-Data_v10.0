## 1. ★ 恆等坍縮定理 (Collapse Theorem)

**定理**: 設 $a, b$ 連續整數（$b = a+1$），$L = a+b$，$N = 2ab$。則

$$\frac{L^2+1}{2} = a^2 + b^2 = N+1$$

**證明**:
$$b = a+1 \;\Longrightarrow\; \begin{cases} a^2+b^2 = 2a^2+2a+1 \\ 2ab = 2a^2+2a \end{cases}
\;\Longrightarrow\; (a+b)^2 = 4a^2+4a+1 = 2(2a^2+2a)+1 = 2N+1$$
$$\therefore \frac{L^2+1}{2} = N+1 = a^2+b^2 \qquad\square$$

**檢定**: 對 $a = 1..499$ 全部成立（scripts/08；scripts/11 獨立重驗 $a = 1..1999$）。

## 3. Z₂ 折疊實算 (Burnside)

$Z_2$ 作用於 $\mathbb{Z}_{29}^2$：$(i,j) \mapsto (-i, -j)$。

$$n_{\text{orbits}} = \frac{n^2 + f}{2},\qquad f = \#\{\text{固定點}\}$$

$n = 29$（奇）⇒ $f = 1$（只有原點）⇒

$$n_{\text{orbits}} = \frac{841+1}{2} = 421,\qquad \text{非真空軌道} = 420$$

| 檢查 | 結果 |
|:--|:--|
| 軌道數 | **421** ✓ |
| 固定點 | **1** = (0,0) = 零動量 = **真空** ✓ |
| 非真空軌道 | **420** ✓ |

⇒ 與坍縮定理數值一致（$421 = 14^2+15^2$）。**兩條路徑同一內容。**
