## 1. 問題陳述

docs/04（R1）確立了家族成員嘅 sector 大小 d 有結構身份：

| 成員 | d | d 嘅結構身份 |
|---|---|---|
| 33/34 | 33 | K_tree（樹前綴和） |
| 44/45 | 44 | N_d（鏈格點數） |
| 55/56 | 55 | F₁₀（Fibonacci） |
| 420/421 | 420 | (L₇²−1)/2（Z₂ 折疊軌道數） |

但**為何 d 取呢個值**（即「算子類型 → sector 大小」嘅**定量律**）一直係 🔴。
本節提出並檢定 **rung law**：

$$d = g \cdot L_m, \qquad g \in \{\text{A}_5\ \text{表示論不變量}\},\ L_m \in \{\text{Lucas}\}$$

## 2. rung law 唯一性（C1）

**枚舉域**：g ∈ A₅ 表示論不變量 = irrep 維數 {1,3,3,4,5} ∪ Σdim=12 ∪ |A₅|=60
⇒ 去重後 {1,3,4,5,12,60}；L_m ∈ Lucas {1,2,3,4,7,11,18,29,47,76}。

| d | 觀測量 | 唯一分解 (g, L_m) |
|---|---|---|
| 33 | 質數峰幅度（O10） | (3, L₅ = 11) |
| 44 | 邊界截斷比 | (4, L₅ = 11) |
| 55 | r\*/r_d（O167） | (5, L₅ = 11) |
| 420 | r_d 修正（O167） | (60, L₄ = 7) |

⇒ **每個成員嘅 (群因子 g, rung 指數 m) 唯一**（C1 PASS ×4）。
⇒ 表層三成員**共享同一 rung m = 5**（C1e），深層用 m = 4（C1f）。
⇒ 表層 g = dim ρ_i ∈ {3,4,5}（單一 irrep 維數）；深層 g = |A₅| = 60（群階）（C1g）。

## 3. ★ 定律真內容：帶指數 = irrep 維數（C2）

88-site 鏈嘅帶結構（R = L₅ = 11，鏈週期）：

| 帶 n | 上界 γ_{nR} | 帶內態數 |
|---|---|---|
| 1 | γ₁₁ | 11 |
| 2 | γ₂₂ | 22 |
| 3 | γ₃₃ | 33 |
| 4 | γ₄₄ | 44 |
| 5 | γ₅₅ | 55 |
| 6–8 | γ₆₆ … γ₈₈ | 66/77/88 |

- 精確關係 `#{γ_k ≤ γ_{nR}} = nR`（C2b ×3 PASS）。
- 家族成員落喺**帶 3, 4, 5**。
- 而 {3,4,5} = A₅ 非平凡 irrep 維數（C2 PASS）。
- 未選中 = {1,2,6,7,8}，**含 trivial 維數 1**（對應真空模，與 docs/08 真空佔比定理一致）。

**Null test**：由 8 個帶隨機揀 3 個命中 {3,4,5} 嘅概率 = 1/C(8,3) = **1.79%**（C2c PASS）。

⚠️ **誠實標註**：「3,4,5 係 irrep 維數」係群論事實，而「帶指數 = 維數」係**識別**（identification），
唔係推導。null test 只排除「隨機」呢個替代假設，唔排除「其他選擇律」。

## 4. 和／積對偶（C6）

| 量 | 值 | 結構身份 |
|---|---|---|
| Σ dim_i（非平凡） | 3+3+4+5 = **12** | B·N_gen = L₅ + 1 |
| Π dim_i（非平凡） | 3·3·4·5 = **60** | \|A₅\| = Σ_all dim² |

★ **對偶**：維數之**和** = 乘積型量（B·N_gen = 12）；維數之**積** = 和型量（|A₅| = Σdim²）。

- 表層 rung：L₅ = Σdim − 1 = 11（C6c PASS）—— 表層用**單一 dim** 做 g，配「維數和 − 1」。
- 深層 rung：L₄ = 7 **≠** Πdim − 1 = 59（C6 末段）⇒ **對偶律唔統一解釋兩個 rung**。

⚠️ 此對偶**唔係**統一機制，只係表層嘅一條巧合性一致（已標註）。

## 5. rung 指數來源（C5）— 遺留 🔴

| m | 候選身份 | 命中 |
|---|---|---|
| 5 | \|Irr(A₅)\| = 5 | ✓ |
| 5 | F₅ = 5 | ✓ |
| 5 | N_gen + μ² = 5 | ✓ |
| 5 | B + 1 = 5 | ✓ |
| 4 | B = 4 | ✓ |
| 4 | L₃ = 4 | ✓ |
| 4 | dim ρ₄ = 4 | ✓ |
| 4 | \|Irr\| − 1 = 4 | ✓ |

⇒ 5 同 4 都係細數，**多身份密度高** ⇒ **無法由身份唯一決定 rung 指數**。
⇒ 「為何表層 m = 5、深層 m = 4」仍係 🔴（定律本身已唯一，但指數選擇律未閉合）。

**另有一條鏈根源線索（C4）**：

$$L_7 = \#\{\gamma_k < \mu^2/2 = 1\} = 29 \quad\text{(鏈譜閾值計數)}$$
$$L_7 = 2L_4 + N_{gen}F_5 = 14 + 15 \ \Rightarrow\ L_4 = (L_7 - N_{gen}F_5)/2 = 7$$

⇒ 深層 rung 7 **亦係鏈導出**（經 L₇）。
⇒ **表層同深層都係「鏈根源」**：表層用鏈**週期**（R = 88/8 = L₅ = 11），深層用鏈**計數**（L₇）。
