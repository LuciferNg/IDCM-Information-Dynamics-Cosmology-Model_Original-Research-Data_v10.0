## 2. 421 係咪被觀測逼出？（誠實檢定）

```
IDCM 裸值 πR/88 = 147.4385132 Mpc;   Planck r_d = 147.09 ± 0.26
需要修正比 = 0.9976362131;   420/421 = 0.9976247031
→ 中央值對應 d = 423.05;   1σ 帶 d ∈ [242.29, 1665.72]（帶闊 1423）
```

- ✅ 421 **落喺** 1σ 帶內（命中 0.0012%）。
- ❌ 但 1σ 帶**好闊**（1423 個整數 d 落喺帶內，共 4999 個）⇒ **觀測本身唔逼出 421**。

**裁決（誠實）**: 421 嘅結構性**唔係**嚟自觀測擬合，而係嚟自 (3,4,5) 面型／L₇ 群算術；
觀測只提供**一致性**（0.0012%）+ **未來可證偽窗口**。

**null test（關鍵）**: 喺 d ∈ [2, 5000] 中，1423 個整數落喺 1σ 帶；
但**結構候選**只有 {34, 45, 56, 90, 421}，其中**唯一**命中帶內嘅係 **421**。
⇒ 結構 + 觀測**聯合**先有選擇力（單靠任一方都唔夠）。
