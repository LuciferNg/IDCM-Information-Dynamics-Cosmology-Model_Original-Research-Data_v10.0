## 3. M2 —— 一致性 σ: 0.040σ → 0.081σ ✅ 確認

```

CV(功率) = √(2/45)      = 21.0800%
CV(rms)  = √(2/45)/2    = 10.5400%   (rms = √功率 ⇒ CV 減半)
```

實為**精確 2 倍**（因 rms = √功率 ⇒ CV(rms) = CV(功率)/2，唔係 /√2）。
