## 2. 分派律之陳述

設通道 X 之已註冊 bare 值 `B(X)`, 觀測 `O(X) ± σ(X)`, 已註冊鏈 `chain(X)`。
定義**邊際基準** (移除 d 之因子後之值):

```
base(X, d) = B(X) · Π{ (d'−1)/d' : d' ∈ chain(X), d' ≠ d }
```

定義**分派判準**:

```
R(X, d) ≡ d · [ 1 − O(X)/base(X, d) ]
```

> ★★ **通道分派律**: 成員 d 作用於通道 X ⟺ **R(X, d) = 1**。
>
> 亦即: **該通道之 bare 公式相對觀測之虧缺, 恰為 1/d。**

呢個係一條**結構陳述**, 唔涉及 σ: 修正因子 (d−1)/d 嘅作用就係造成 1/d 之虧缺,
所以「成員 d 作用於 X」同「X 之 bare 虧缺 = 1/d」係**同一件事**。

---

## 3. 代數定理

**定理 1**: `z_dev = z_det · (R − 1)`, 精確恆等。
其中 `z_det ≡ (B/d)/σ`, `z_dev ≡ (B(d−1)/d − O)/σ`。

*證明*: B(d−1)/d − O = B − B/d − O = (B − O) − B/d
= B(1 − O/B) − B/d = (B/d)(d(1−O/B) − 1) = (B/d)(R − 1) ⇒ 除以 σ 即得。 ∎

**推論 1**: 第九輪之判準「|z_dev| ≤ 1σ」⟺ **「|R − 1| ≤ 1/z_det」**。
⇒ 第九輪之 σ-判準**唔係**獨立判準, 佢係 R-判準加上一個由檢定力決定之容差。

**推論 2**: R ≠ 1 之偏離量, 就係「修正唔足以 / 過量解釋虧缺」之量度。

*驗證*: scripts/38 §B (sympy: 差值簡化為 0 且 free_symbols = ∅) +
scripts/40 §B (200 組隨機數值代入, 最大殘差 < 1e−40)。

## 7. 預言與否證出口

分派律係一條**可否證**之陳述:

1. **預言 P1**: 若某新通道之 bare 公式虧缺恰為 1/d (d 為家族成員), 則 d **必須**
   作用於該通道; 反之若 d 作用, 則該通道之 bare 虧缺**必須**恰為 1/d。
2. **否證出口 A**: 發現一條已註冊通道, 其 bare 虧缺 = 1/34 ⇒
   「33/34 不可檢定」被推翻。
3. **否證出口 B**: 發現某通道之修正後預測同觀測吻合, 但其 R ≠ 1
   ⇒ 分派律被推翻 (修正非該 d 所致)。
4. **否證出口 C**: 發現兩條不同通道需要同一 d ⇒ 一成員多通道 ⇒ 分派律需擴展。
5. **P3 (不可判定)**: 若通道之 bare 虧缺顯著性 < 1σ ⇒ 分派不可判定。
   *實例*: θ* 之虧缺顯著性 = **+0.476σ < 1σ** ⇒ 不可判定
   (同對消律 docs/25 §4 一致) ✓
6. **P2 (自足)**: 若虧缺唔等於任何 1/d 且唔顯著 ⇒ 該通道唔受家族修正,
   bare 公式必須自足。*實例*: θ* (d_req = 7056, 唔近任何成員)。

## 9. 遺留

- 🔴 **分派律之第一原理**: 本節導出「虧缺 = 1/d ⟺ 分派」, 但**未導出**
  「為何某通道之 bare 公式會恰好虧缺 1/d」—— 即為何 r_d 之 bare 係 πR/88 而
  佢嘅虧缺係 1/421。呢個仍屬基礎層。
- 🟡 **44/45 × r\* = −1.030σ 邊緣** (見 §5.3) ⇒ 需 σ 改善 1.03× 即可通過;
  但讀法 I 同讀法 II 衝突 ⇒ 需釐清鏈之次序規則。
- 🔴 **R ≠ 1 之殘餘** (r_d 0.4846%, r* 1.2079%) ⇒ 需第二機制或 R_world 精化。
