## 1. 問題陳述（docs/04 §6 遺留）

> 🔴 「sector 大小嘅定量律 — 為何係 $L_5$（表層）同 $L_4$（深層）而唔係其他 rung？」

docs/09 已證 rung law `d = g·L_m` 對四成員唯一，但當時嘅診斷係「m = 5 同 m = 4 各有 ≥3 條身份 ⇒ 多身份 ⇒ 🔴」。

## 2. 表層：rung = 鏈週期 R（C1）

| 量 | 值 | 來源 |
|---|---|---|
| 鏈長 | 2N_d = 88 | N_d = 44（O95） |
| 帶數 | 2B = 8 | B = 4（分支因子） |
| **鏈週期** | **R = 2N_d/(2B) = 88/8 = 11** | 帶均分 |
| 等價寫法 | R = N_d/B = 44/4 = 11 | — |
| Lucas | L₅ = 11 | — |

⇒ ★ **R = 11 = L₅**。故「表層 rung = L₅」**唔係選擇** —— 佢係鏈週期嘅值（C1h/C1i PASS）。

### ⚠️ 一條被排除嘅路線（誠實記錄）

本來想用「88 嘅因數中屬 Lucas 者」揀出 R：88 因數 = {1,2,4,8,11,22,44,88}，
其中 Lucas = **{1,2,4,11}** ⇒ 加約束 `B ≤ R < 88` 後候選仍係 **{4, 11}** ⇒ **唔唯一**（C1g PASS 記錄此負結果）。

⇒ **真約束係「帶數 = 2B」**，唔係 Lucas 性。Lucas 性（R = L₅）係**結果**，唔係輸入。
（此更正唔回溯改寫 docs/09，另立於此。）

## 3. 表層 m 由 R 反解（C2）

| d | 唯一分解 (g, m, L_m) | g 身份 |
|---|---|---|
| 33 | (3, **5**, 11) | dim ρ = 3 |
| 44 | (4, **5**, 11) | dim ρ = 4 |
| 55 | (5, **5**, 11) | dim ρ = 5 |

⇒ 三個成員共享 **m = 5**，而 `L₅ = R`（C2c PASS）⇒ 表層 m 由鏈週期決定。

## 4. 深層：rung = 商 420/|A₅|（C3）

- |A₅| = Σ dim² = 60（階層律固定 g = 60）
- 420 = (L₇²−1)/2（軌道折疊）
- ⇒ **L_m = 420/60 = 7 = L₄**

**唯一性**：令 420/g ∈ Lucas 嘅 g ∈ 不變量集 = **{60}**（C3e PASS）⇒ 唯一。

⇒ 「深層 rung = L₄」**亦唔係選擇** —— 佢係商。

## 5. 交叉排除（C4）

| 方向 | 檢定 | 結果 |
|---|---|---|
| 表層用 g = 60？ | 33/60 = 11/20、44/60 = 11/15、55/60 = 11/12 | 全部 ∉ Lucas（非整數） |
| 深層用 g ∈ {3,4,5}？ | 420/3 = 140、420/4 = 105、420/5 = 84 | 全部 ∉ Lucas |

⇒ 兩層嘅 g 分派**互斥**，唔可以互換。

## 6. 結論：rung 指數係導出鏈嘅末端

```
表層:  B = 4  ⇒  帶數 = 2B = 8  ⇒  R = 88/(2B) = 11 = L₅  ⇒  m = 5
深層:  階層律 ⇒  g = |A₅| = 60  ⇒  L_m = 420/60 = 7 = L₄  ⇒  m = 4
```

⇒ **rung 指數唔係自由參數**（C5a–C5c PASS）。
