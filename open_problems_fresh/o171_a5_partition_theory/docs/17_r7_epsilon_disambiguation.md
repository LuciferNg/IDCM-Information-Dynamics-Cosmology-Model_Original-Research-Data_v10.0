| 出處 | 定義 | 值 |

## 2. 結論：唔應該統一 —— 係兩個唔同幾何對象

| 參數 | 結構身份 | 幾何來源 |
|:--|:--|:--|
| **ε_φ** | φ⁻¹/B = (√5−1)/8 | **樹/黃金自相似**：φ = T̂ 主特徵值，B = 4 帶數 |
| **ε_ring** | F₇/(2N_d−2) = 13/86 | **環退化模佔比**：2N_d−2 = 88−2 = 86 個退化模 |

判別準則（零參數、可證偽）：**每個 ε 被自己嘅觀測量鎖定，並被另一個嘅觀測量排除。**

| 觀測量 | ε_ring | ε_φ | 判別比 |
|:--|:--|:--|:--|
| 冷斑 5ε⁵/8 × T_CMB（觀測 134.2 μK） | **134.4459 μK**（dev **0.183%**）✓ | 149.9978 μK（dev **11.77%**）✗ | **64.3×** |
| CMB 峰幅 A(p₁) = D₅₂₇/D₂₂₁（觀測 0.443433） | 0.434014（dev **2.124%**）✗ | **0.443620**（dev **0.042%**）✓ | **50.3×** |

⇒ 兩個 ε 各自被**唔同觀測量**以 50–64 倍判別力鎖定。2.17% 差距係**真結構差異**，唔係待修正誤差。

## 3. 兩者之間冇可導出關係

```
ε_φ / ε_ring = 43/(26φ) = 1.02213313524…      (無理數)
倒數 = 26φ/43 = 0.9783458…                     (無理數)
```

- `sympy.minimal_polynomial` 次數 = **2** ⇒ 冇任何有理結構形式可以精確等於
- 最近有理結構形式 = 45/N_d = 1.022727，dev **0.0581%** ⇒ 唔可以當結構身份
- 26 = 2F₇ 可寫，但 43 = N_d−1 **唔係** IDCM 不變量 ⇒ 形式無結構意義

⇒ **兩者不可互相導出**。

由 IDCM 不變量集生成 23 個候選 ε（結構整數比 + φ 冪形式，0.13 < ε < 0.18）：

| 關卡 | 通過者 |
|:--|:--|
| 冷斑（dev < 0.2%） | **只有 `F7/86`** |
| 峰幅（dev < 0.2%） | **只有 `phi^-1/4`** |
| 兩關同時 | **∅（空集）** |

兩個通過集係**互不相交嘅單元素集** ⇒ 統一**唔可能**，兩個參數係必須嘅。
