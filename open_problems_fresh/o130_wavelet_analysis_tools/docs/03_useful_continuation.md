## 0. 為何要繼續推？— v9.0 工具箱嘅真正缺陷

v9.0 `wavelet_toolbox/` 用**點態 S/N** 測試 K_Chain 階梯：喺 `s_n = λ_sync/n` 逐點計 S/N，數「有幾多個點過 3σ」。
呢個做法有三重結構性缺陷（本輪逐一形式化）：

| # | 缺陷 | v9.0 後果 | 本輪定量結果 |
|:-:|:-----|:----------|:-------------|
| 1 | **點態 S/N ≠ 全局檢定** | 報「17/19 諧波偵測」 | matched filter Δχ² 只有 +11.6（knots=5） |
| 2 | **斜坡 confound** | 單調殘餘令任何正偏移都「過 3σ」 | Spearman ρ=0.9979, 只 1 IMF（script 03） |
| 3 | **broadband 退化** | 移除方法一換，偵測數 4→3→17 | Δχ² 隨 broadband 自由度崩到 +0.4（script 04） |

**有用層嘅正確延續** = 用一個**統計上有效**嘅檢定重做同一條結構預言，得出誠實答案。以下三節。

## 1. 校準化偵測檢定（script 04）— matched filter + trial-corrected null

### 方法
K_Chain 階梯係一條**完整模板**，唔係一組獨立峰：

```
T(s) = Σ_{n∈S} γ_n · cos(2π n s / λ_sync) · exp(−½ (2πn/λ_sync)² Σ²)     Σ = 10 h⁻¹Mpc
```

- **只放 A 一個自由參數**（模板振幅）⟹ 模板**唔可以**透過自由 damping 去模仿 broadband。
- Broadband = 三次樣條（knots = 4/5/6），加模板後取 Δχ²（1 dof）。
- 窗口 **s ≥ 40 h⁻¹Mpc**：s<40 區相對誤差 ~0.5%，細 s 峰獨大，任何平滑 broadband 都過唔到檢定。
- **Trial-corrected statistic** `D = max_{knots × λ-shift} Δχ²`（3 × 9 = 27 trials）。
- **Null** = "數據 = 平滑 broadband + 噪聲，無階梯"（1000 realizations）。

### 結果

```
knots=4 : χ²_bb =  35.8 (χ²/dof 1.6)   Δχ² = +10.69   A = +3.28e-03
knots=5 : χ²_bb =  23.9 (χ²/dof 1.1)   Δχ² = +12.22   A = +4.52e-03
knots=6 : χ²_bb =  16.2 (χ²/dof 0.8)   Δχ² =  +7.23   A = +4.80e-03
knots=8 : χ²_bb =   4.0 (χ²/dof 0.2)   Δχ² =  +0.44   A = −3.33e-03   ← broadband 食晒
```

```
D_obs = +14.57 ;  null D: mean +15.50, std 7.08, max +51.75  →  p = 0.500
shifted-ladder profile (knots=5): peak at δ = −5%, δ=0 只係 +11.64  ← 唔係位置特異
```

### 判決
**🔴 唔顯著。** BOSS DR12 ξ(s) **冇**偵測到 K_Chain 階梯。而且：
- Δχ² 隨 broadband 自由度**崩潰**（+10.7 → +0.4）⟹ 階梯同 broadband **退化**。
- shifted-ladder profile **平/闊**，δ=0 唔突出 ⟹ 唔係階梯位置特異。

> **「無效才是正確」**：v9.0 嘅「17/19」係偽影；本輪用有效統計得到**零偵測**，
> 唔係框架弱，係舊聲稱本來就係方法偽影。遷移嘅**結構**（`s_n = λ_sync/n` 位置）仍然正確。

### 2.1 取樣定律（bin Nyquist）
```
Δs_n = λ_sync/[n(n+1)]  ≥  Δs_bin     ⟹   n_max(Δs_bin) = (−1 + √(1 + 4λ/Δs_bin)) / 2

| Δs_bin (h⁻¹Mpc) | 5 | 4 | 3 | 2 | 1 | 0.5 |
|:--|:--|:--|:--|:--|:--|:--|
| n_max | **8.53** | 9.59 | 11.15 | 13.76 | 19.66 | 28.01 |

### 2.2 窗口（Rayleigh）解析度
```
Δn_res = λ_sync / T          (T = 觀測窗口長度)
BOSS DR12 (T=175) → Δn_res = 2.32 > 1   ⟹ 相鄰模態在峰位**唔可分離**

⟹ 階梯**位置**冇被嚴重打亂；但 Rayleigh 極限 Δn_res=2.32 仍令相鄰模態峰位不可分。

### 2.3 三大障礙排序（本輪結論）
1. **Bin Nyquist** `n_max = 8.53` — 聲稱嘅 19 諧波中 **n=9..20 全部係 sub-bin**（硬切）。
2. **Broadband 退化** — script 04，p = 0.50。
