## 1. 錯在哪（算術）

1 h⁻¹Mpc ≡ 1/h Mpc（h⁻¹Mpc 係**大**單位），所以

    d[h⁻¹Mpc] = d[Mpc] × h_fid        （乘）

v9.0 寫成 `d / h`（除）⟹ 偏差剛好 1/h² = 1/0.6736² = **2.20**？—— 唔係：v9.0 除的是 **H = 0.7259**（IDCM 自身 h），所以 406.2227 / 198.63 = 2.045，而相對「本來應該用 0.7259 乘」的錯法是 1/0.7259² = 1.897×。

- 錯值來源（逐字）：`IDCM-v9.0--W-Field-Lattice/open_problems_fresh/kchain_cosmic_web/_core.py`
  - `LAMBDA_SYNC = 2*math.pi*R_H/88   # 294.88 Mpc` ← **物理 Mpc，正確**
  - `BAO_HINV = BAO_MPC / H            # 203.0 h⁻¹ Mpc (IDCM prediction)` ← 錯方向
  - 同檔其餘 36 個 v9.0 腳本一律 `LAMBDA_SYNC / H` / `LAM_HINV`
- O130 遷移腳本原封照抄：`LAM = math.pi * 4129.94 / 44 / 0.7259  # 406.2227 h^-1 Mpc`
