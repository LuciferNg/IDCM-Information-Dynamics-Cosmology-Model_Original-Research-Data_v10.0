## 二、推導鏈驗證

### 2.1 結構公式鏈

```

  ↓
m₃ = (γ₆·v)² / M_comp = 0.05357 eV
  ↓ (NH 反解: m₃² - Δm²₃₁ = m₁²)
m₁ = √(m₃² - 2.434e-3) = 0.02088 eV
m₂ = √(m₁² + 7.53e-5) = 0.02261 eV
  ↓

```

```

2B² = 2 × 4² = 32
誤差 = 1.01%
✅ 閉合
```
