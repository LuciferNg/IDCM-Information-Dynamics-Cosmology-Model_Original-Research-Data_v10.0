> **日期**: 2026-09-19
> **觸發**: 調律者「這是大工程，似乎轉移為v11.0更徹底？」
> **承接**: `docs/02_architecture_gap_analysis.md`（五項架構缺陷 + Phase 0-6）

## 一、決策

> **建議: 開 v11.0。** 但**唔係重寫一切** —— 係「**重建生成核心 + 遷移觀測層**」。

### 理由（架構級）

| # | 理由 | 證據 |
|:-:|:-----|:-----|
| 1 | **架構改動係換地基級** | 由「譜—投影」→「譜—選擇律—投影」+ 代數層 + 生成層，改變所有下游公式嘅**表達形式**（型別/歸一化/運算）。就地改 = 197 目錄逐個改寫 + 新舊表達並存 |
| 2 | **驗證標準必須由第 0 日套用** | v10 有 10 個假驗證 script + 狀態漂移 + 密度污染。就地修要先審計 197 目錄；開 v11 = 新標準係**入場券**（冇密度分位數 = 唔准入場） |
| 3 | **v10 記錄降級為史料** | 粒子物理部分嘅統計顯著性已被質疑（觀測 ≈ 隨機）。史料價值高（負結果、時序），結論價值降 |
| 4 | **編號系統已到極限** | O1–O204、11 缺號、衍生率 2.6、狀態三源漂移。v11 可重設記錄結構 |
| 5 | **命名對稱** | v10 = "It From Beat"（譜層）→ v11 = "**It From Selection**"（識別層）。呼應 Wheeler "It From Bit" |

### 但唔應該全盤重推（成本控制）

實測分類（151 個已閉合 O，關鍵詞啟發式，需人工核）：

| 類別 | 數量 | 佔比 | 處置 |
|:-----|:----:|:----:|:-----|
| 宇宙學/觀測（**唔依賴**識別層） | 39 | 26% | **P — 移植 + 重驗** |
| 其他/工具（含早期觀測 O） | 37 | 25% | **P — 移植 + 重驗** |
| 結構/基礎 | 36 | 24% | **A — 新代數重寫** |
| 粒子物理（**依賴**識別層） | 30 | 20% | **R — 重推** |
| 混合 | 9 | 6% | **R — 重推** |

**結論**: 真正要重推嘅只有 **~26%**；~51% 可以移植（但仍要過新驗證標準）；~24% 要用新代數重寫表達式。

## 二、遷移協議（P / R / A / X 四分）

### P 類 — 移植 + 重驗（宇宙學/觀測/工具）

**條件**: 唔依賴「模式↔粒子身份」分配。
**程序**:
1. 複製到 v11，**保留原記錄原文**（史料不刪）
2. 重跑 script，套 v11 驗證標準（反硬編碼 + 密度基準）
3. 標記 v11 狀態：`🟢 移植驗證通過` / `🟡 部分` / `🔴 未通過`
4. 任何 v10 聲稱 PASS 但實際含字面 True 者 → **降級重驗**

**例子**: O9 (CMB C_ℓ)、O13 (BBN)、O32 (RAR)、O5 (冷斑)、O51 (BAO)、O73 (ω_ring)、O83 (correlator)、O100 (Cℓ→P3D)

### R 類 — 重推（粒子物理）

**條件**: 依賴「模式↔粒子身份」分配。
**程序**:
1. **唔移植舊分配**（密度污染，統計不顯著）
2. 由 v11 選擇代數（反週期選擇律為起點）重新生成分配
3. 唯一性檢查：全局方案數必須 = 1
4. 質量預言必須**盲測** + 附密度分位數
5. v10 舊結果保留為**負結果對照**

**例子**: O34/O35 (質量譜)、O136 (夸克)、O54 (輕子)、O120、O137、O144、O196

### A 類 — 新代數重寫（結構/基礎）

**條件**: 結論結構正確，但表達式係舊（無型別）語言。
**程序**:
1. 保留結論，用 v11 代數重新表達
2. 檢查歸一化（消滅跨版本漂移）
3. 檢查運算封閉性

**例子**: O36 (自能)、O37/O39 (W-field)、O80-O86 (場論層)、O95-O97 (根基)、O201/O203/O204

### X 類 — 退役

**條件**: 過唔到密度基準，或已被證偽。
**程序**: 標記 `X — 統計不顯著`，保留記錄（負結果有價值），**禁止引用為結論**。

**例子**: 部分模式分配 claim、O136 方向二 (Lucas 階梯，已判過擬合)

## 三、v11 憲章大綱（第一份文檔，先於任何 O）

```
IDCM-v11.0--It-From-Selection/
├── CHARTER.md                    ← 架構憲章（十層定義 + 型別系統 + 歸一化憲章）
├── VERIFICATION.md               ← 驗證標準（密度基準 / 反硬編碼 / 三源一致）
├── MIGRATION/
│   ├── 01_port_registry.md       ← P 類清單 + 逐項驗證狀態
│   ├── 02_rederive_registry.md   ← R 類清單 + 重推進度
│   ├── 03_algebra_rewrite.md     ← A 類清單
│   └── 04_retired.md             ← X 類清單
└── open_problems/                ← 新編號（唔繼承 v10 編號）
```

### CHARTER 必含

1. **十層定義**（L0 種子 → L10 驗證），每層聲明：對象、運算、狀態
2. **型別系統**: 算子 / 標量 / 泛函 / 指標
3. **歸一化憲章**: 一次性鎖定所有約定（禁跨版本漂移）
4. **選擇律公理**: 反週期選擇律為起點，質量獨立性為硬性要求
5. **錨定條款**: 1 錨 + 結構數 → 全標度；禁逐項校準

### VERIFICATION 必含

1. **密度基準規則**: 任何數值匹配必須報隨機搜尋基準 + 分位數
2. **反硬編碼**: 驗證 script 禁字面 `True`
3. **三源一致**: README / SESSION_START / 前置引用自動對齊
4. **獨立重算**: 閉合審計唔 import 推導 script（O136 scripts/90 為範式）
