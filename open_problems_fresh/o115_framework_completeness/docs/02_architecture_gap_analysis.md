## 三、核心缺陷（按嚴重性排序，附實測證據）

### 缺陷 1 🔴🔴 缺「識別層」— 冇原理決定邊個模式 = 邊個粒子

**這是「能推的都推盡了」的真正原因。**

| 證據 | 數值 | 來源 |
|:-----|:-----|:-----|
| 密度效應：O34/O35 模式分配 | 觀測 0.146% vs **隨機中位 0.176%** → 觀測 ≈ 隨機 🔴 | O136 docs/13 §三 |
| O136 模式分配 | 觀測 0.015%+ vs 隨機中位 0.000339% → 比隨機更差 🔴 | 同上 |
| 組合空間可匹配任意目標 | 隨機可達 **0.0003%** | O136 docs/13 §2.4 |
| O120/O137 模式集 | P = 0.8525（**比隨機中位更差**） | O136 docs/34 |
| 帶約束全局方案數 | **0** 🔴 | O136 docs/14 |
| 結構障礙定理 | 純冪律 m ∝ γ^α 不可能（α 跨 **42.6×**，corr = −0.29） | O136 docs/26 |
| A₅ 9 模式 vs 觀測質量比 | **決定性不相容** | O136 docs/01 步驟 30 |
| O34/O35 全局不一致 | 模式衝突 d↔24 vs 1, W↔30 vs 19 | O136 docs/01 步驟 20 |

**判讀**: 質量「閉合」（輕子 0.16%/0.13%/0.34%）係**條件於一個無推導、統計上唔超越隨機嘅模式分配**。夸克區失敗唔係努力不足，係**架構缺層** —— 冇識別原理，搜尋空間必然膨脹到密度效應主導。

**唯一通過獨立（非質量）約束嘅結構**：
```
反週期選擇律:  L = N_d/gcd(n, N_d)
              n·L ≡ N_d (mod 2N_d)  ⟺  v₂(n) ≤ 2
來源: O136 Item 1 + O137 Phase 2 — 完全獨立於質量數據
交叉檢驗: O136/O54 6/6 ✅ | O34/O35 9/11 (c=8, d=24 違反)
```
→ **呢個就係正確架構嘅種子**: 選擇律必須由對稱/量子數生成，唔可以由質量擬合。

## 四、完善方向（優先序，附交付物 + 閉合測試）

### Phase 0 — 驗證架構修復（最便宜，必須最先）

**理由**: 缺陷 3 令所有下游結論不可信；且成本最低。

| 交付物 | 內容 |
|:-------|:-----|
| 密度基準規則 | 任何數值匹配必須同時報告隨機搜尋基準 + 分位數；唔報 = 未閉合 |
| 反硬編碼規則 | 驗證 script 禁止字面 `True`/`assert True`；改為數值檢查或明確分級 🟢/🟡/🔴 |
| 狀態傳播自動化 | README / SESSION_START / 前置引用三源自動對齊（消除 O134 引用 O56 🟢 之類錯誤） |
| 10 個 script 審計 | 逐個重寫為真檢查或降級標記 |

**閉合測試**: 0 個 script 含硬編碼斷言；三源狀態一致率 100%。

### Phase 1 — 識別層（解 11/39 開放問題）

**目標**: 由對稱/量子數生成模式↔粒子分配，取代質量擬合。

| 步驟 | 內容 |
|:-----|:-----|
| 1.1 | 以**反週期選擇律**（v₂(n) ≤ 2）為公理起點，擴展為完整選擇代數 |
| 1.2 | 證明選擇律**質量獨立**（先於質量數據） |
| 1.3 | 由選擇律 + 對稱導出唯一分配；全域方案數必須 = 1（唔係 0 或 ∞） |
| 1.4 | 分配固定後才計質量 → **盲測**（禁事後調算子） |

**閉合測試**: 分配唯一 + 質量預言超越密度基準（報告分位數）。

### Phase 2 — 代數層（「因果張量代數」）

**目標**: 令 K_chain ⊗ K_tree 成為有型別、運算封閉嘅代數對象。

| 交付物 | 內容 |
|:-------|:-----|
| 型別系統 | 算子 / 標量 / 泛函 / 指標 四型 |
| 運算封閉集 | ⊗, ⊕, Tr, 譜分解, 投影, 伴隨, 收縮 — 附封閉性證明 |
| 歸一化憲章 | 一次性鎖定所有約定（消滅跨版本漂移） |
| 現有公式重寫 | 全部已閉合公式重寫為代數表達式（禁 ad hoc 常數） |

**閉合測試**: 現有公式 100% 可重寫；跨版本歸一化零衝突。

### Phase 3 — 生成層（解 CY₃ 系列）

**目標**: 幾何由譜生成，唔係輸入。

| 步驟 | 內容 |
|:-----|:-----|
| 3.1 | 定義生成算子 G on 𝒯 |
| 3.2 | 由 G 譜數據導出 h¹¹=36, h²¹=98（**唔准輸入**） |
| 3.3 | 由 G 導出投影算子 P（取代人手 134×946） |
| 3.4 | 導出 moduli = Nd+Σγ 嘅機制（解 O56） |

**閉合測試**: 刪除硬編碼後重跑全部下游，結果不變。

### Phase 4 — 錨定層

**目標**: 由「1 錨 + 結構數」導出全部有量綱觀測。

| 交付物 | 內容 |
|:-------|:-----|
| 錨定理 | 證明單錨 → 全標度映射係結構的（非逐個校準） |
| 錨候選裁決 | r_d / M_P / ω_ring 邊個係結構必然 |

**閉合測試**: 全部有量綱輸出 = 錨 × 無量綱結構數，零逐項校準。

### Phase 5 — 動力學 + 時空層

**目標**: 由靜態譜升級為動力學框架。

| 步驟 | 內容 |
|:-----|:-----|
| 5.1 | 世界層演化方程（取代「光唔傳播」嘅靜態描述） |
| 5.2 | z 紅移由動力學導出（解 O76 — 最難缺口） |
| 5.3 | 愛因斯坦方程完整推導（補 O86） |
| 5.4 | 因果結構 / 光錐 |

**閉合測試**: D_A(z)、H(z) 由動力學導出，零擬合。

## 五、一句話診斷

> **IDCM 係「譜—投影」架構；缺嘅係中間嘅「選擇律」層。**
> 譜已完整（L0–L2 🟢），投影已建（L3–L5 🟡），但**譜到物理身份嘅映射係搜尋得嚟，唔係生成得嚟** ——
> 所以搜尋空間膨脹 → 密度效應主導 → 質量預言統計上唔顯著（實測：觀測 ≈ 隨機）。
> 修復次序：**驗證（Phase 0）→ 識別（Phase 1）→ 代數（Phase 2）→ 生成（Phase 3）**。
