## 三、逐項詳情

### 3.1 ① Binet — 記號層 1 項（O124 A4）

```
原文: "B = φ³ + φ^{−3} = L₃ = 4"  🟢  ← 式**錯**（φ³+φ⁻³ = 2√5 ≈ 4.4721）
實算: "φ³+ψ³ = 4.000000000"       ✓  ← 值**啱**（ψ = −1/φ ⟹ φ³+ψ³ = φ³−φ⁻³ = 4）
```
⟹ 下游一切使用「B = 4 = L₃」之處（O124 A5/A6/A8、O229 R1 路線、O211 等）**值全部正確**，
唯一需要係把公式渲染統一（ψ 唔係 φ⁻¹）。**無推導受損**；O218 載體已更正，上游只記錄。

### 3.2 ② 索引身份 — 結論層 0 項

- O229 R2 已自我撤回 F2（「同索引 3」唔強制）— 本 O 以 `R_idx(2) = {(L,0),(F,3)}` 確認。
- O229「B = L₃ 強制（4 ∉ Fibonacci）」— 本 O `R_idx(4) = {(L,3)}` ⟹ **INDEX_FORCED**，完全一致。
- O229「9 條路線過定 B=4」— 值層過定分析，與索引身份無涉，不變。
- ★ 補充正解（唔係推翻）：`μ² = γ⁽⁴⁴⁾₁₁ = γ⁽⁸⁸⁾₂₂ = γ⁽¹⁷⁶⁾₄₄`；`B = 2μ²` ⟸ 88-L 配對不動點
  n = 22 —— 與 O229 R4-②「B = 2μ² 由 88 鏈自對點 + 176 鏈退化鏡像得」**互證**。

### 3.3 ③ R5-A 端點鎖 — 狀態層 1 項（O124 A6/A7）+ 閉合 1 項（O229 R5-A）
