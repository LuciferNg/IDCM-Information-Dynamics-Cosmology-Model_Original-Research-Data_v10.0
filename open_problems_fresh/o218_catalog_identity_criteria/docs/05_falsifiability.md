## 三、形式不變性（等價改寫**唔可以**改變判級）

| # | 改寫 | 結果 |
|:--|:--|:--|
| N1 | `B*(N_d+1)/2` → `(N_d+1)*B/2 + 0` | 兩者皆 `IDENTITY_OK` 🟢 |
| N2 | `π(N_d−n)/88` → `π((43+1)−n)/88` | 兩者皆 `IDENTITY_OK` 🟢 |

⟹ 判準對**寫法**不變、對**內容**敏感（正確語義）。

## 四、敏感度（🟢 案例對目標擾動之反應）

| dev | 判級 | 解讀 |
|:--|:--|:--|
| 1e-12 | `FORMAL_OK` 🟡 | 形式滿足但**冇精確證書** ⟹ 未閉合（**唔可以白拿 🟢**） |
| 1e-6 | `FALSE` 🔴 | 超出 identity tol (1e-9) |
| 1e-3 | `FALSE` 🔴 | 同上 |

> ★ 設計決定（誠實記錄）: `identity` 類之 🟢 必須有**精確證書**（符號化簡 = 0 或 mpmath 60 位 < 1e-45）。
> 只有「數值上接近」而無證書 ⟹ 🟡 `FORMAL_OK`（未閉合）。呢個防止「用浮點巧合冒充恆等式」。

## 五、★ 限制（本輪發現, 誠實記錄）

```
🟡 整數字面值幾乎唔可被 G1 判死:
   由閉包退化定理 (docs/03 §二), 任意 n ≤ cap 都 ∈ P。
   故 24 之類「有深度 1 表示」之整數屬合法 DEPTH1 葉 (表示數 R ≈ 3)。
   ⟹ 判準唔可以靠「葉合法性」擋住任選整數; 資訊量工作必然落在:
        U (表示數 R) + G5 (密度) + class 分派 — 三者在 I9/I10 已驗證有牙。
   ⟹ 對 n > cap (如 401) 才落 BARELITERAL。
🟡 sympy 會即時化簡字面算式 (397 − 307 → 90) ⟹ 測試注入必須用
   `Add(..., evaluate=False)` 才能令「葉」真正存在於樹中。
   呢個係測試設計陷阱 (首次注入曾假 PASS — 已修)。
🟡 注入測驗係「判準能否判死」之充分條件, 唔係「判準冇假陽性」之證明 —
   假陽性由回歸組 (docs/04 放行 8/8) + 形式不變性 (N1/N2) 覆蓋。
```
