## 五、判準之可追溯性（每行 gate_fired）

判準唔只輸出判級, 亦輸出**邊個 gate 判死**。例:

```
A1 COINCIDENCE  ← T2_cross_framework (IDCM L₁₀ ↔ SM b₁, 無共同推導)
A2 TAUTOLOGY    ← T1 (等式對共有量 41 恆等, 代入其他註冊值後化簡 = 0)
A5 MULTIPLIER   ← T5 (主體偏差 10% ≫ 精度) + G5 Farey (N = 11.7 ≫ 1)
A6 TRAP         ← G4 (5.9e-4 ∈ (1e-5,1e-3), 精度 1e-4 優於窗寬)
```

⟹ 任何 🔴 判決都可回溯到一條**可執行規則**, 唔係「靠經驗判斷」。
