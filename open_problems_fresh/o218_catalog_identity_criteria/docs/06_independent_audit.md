## F. ★ γ 鏈標籤分離 — 同一符號兩個歸一化（本 O 主要新結果）

### F.1 兩個並存鏈

| | **88 鏈** | **176 鏈** |
|:--|:--|:--|
| 形式 | γ⁽⁸⁸⁾_n = 4sin²(πn/88), n = 1..44 | γ⁽¹⁷⁶⁾_k = 4sin²(πk/176), k = 1..88 |
| 出處 | o169 docs/02:21、o211 docs/01 C7 | o124 scripts/13 A1–A3 |
| 全部和 | Σ = **90** = B(N_d+1)/2 | Σ = **178** |
| 奇/偶 | Σ_odd = 44 = N_d, Σ_even = 46 | Σ_odd = 88, Σ_even = **90** |
| 奇模平均 | ⟨γ⟩_odd = **2 = μ²** (22 項) | ⟨γ⟩_odd = **2 = μ²** (44 項) |
| γ_44 | **4 = B** | **2 = μ²** |
| 配對恆等式 | **(n, 44−n)**: γ_n + γ_{44−n} = 4 = B ∀n | **(44−j, 44+j)**: γ_{44−j} + γ_{44+j} = 4 = B ∀j |

關係（實測）: **γ⁽⁸⁸⁾_n = γ⁽¹⁷⁶⁾_{2n}** ⟹ 88 鏈 = 176 鏈之**偶模子集**；
故 176 鏈 Σ_even = 88 鏈 Σ = 90 ✓ 自洽。

### F.2 可執行判定（`chain_pairing_check` / `wrong_pairing_check`）

```
88  鏈 用 (n, 44−n)   : max_dev = 0        ⟹ 恆等式 ✓
176 鏈 用 (44−j,44+j) : max_dev = 0        ⟹ 恆等式 ✓
176 鏈 用 (n, 44−n)   : 最近接 dev = 2.0701 ⟹ **無解** ✓（O124 A3 負結果復現）
88  鏈 用 (n, 44−n)   : 最近接 dev = 0     ⟹ **有解**（全部 n 皆解）
```

### F.3 裁決

```
O163 docs/07:33 之無標籤寫法「B = 4 = φ³−φ⁻³ = γ_n + γ_{44−n} [Z₂ 對偶和]」
  · 喺**88 鏈**: 真 ✓（本 O 可執行驗證, sympy 化簡差 = 0）
  · 喺**176 鏈**: 假 ✓（O124 A3 之負結果, 最近接偏差 2.07）
⟹ O124 A3 之「負結果」係【鏈條件性】— 唔係絕對 no-go;
   兩份記錄各自喺自己嘅鏈上正確, 只有【無標籤】令佢哋互相矛盾。
```

**O169 docs/02:25 之歸一化混用（精確記錄）**:
同檔 :21 已聲明 `γ_n = 4sin²(πn/88), n = 1..44`（88 鏈）；
:25 寫「Σγ_odd = 44 = N_d (22 個奇模, ⟨γ⟩_odd = 2 = μ² = **γ_44**)」。
實測: ⟨γ⟩_odd = 2 = μ² 喺**兩鏈皆真**（穩健）; 但 **γ_44 = 2 只在 176 鏈為真**
（88 鏈 γ⁽⁸⁸⁾_44 = 4 = B; 88 鏈中 = μ² 之模係 **γ⁽⁸⁸⁾_22**）。
⟹ 該句之「γ_44」係 176 鏈之量, 混入 88 鏈聲明之句內。
