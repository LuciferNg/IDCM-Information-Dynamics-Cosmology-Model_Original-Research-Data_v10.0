## 問題

4^{−ℓ} 數密度律 (O174: q_ℓ = Q/N_ℓ = 4^{−ℓ} 電荷稀釋) 係**時間層級律** —
但「每層邊啲位置有新凝聚」未答。層級模態預算 N_ℓ = 44·4^ℓ (O140)
點樣映射到物理位置 (節點/阻挫邊)?

## 核心結果

### 1. 正交分解 — 時間律 ⊗ 空間律

**O179 核心洞察**: 凝聚分佈係**正交分解**, 唔係單一機制:

```
完整凝聚分佈 dN/dℓ·dP(i) = 4^{−ℓ} · W(i)/ΣW
                          ─────   ──────────
                          時間律    空間律
                          (O174)   (O179 docs/01)
```

- **時間律** 4^{−ℓ}: 凝聚**事件率** (每層模態預算稀釋) — 同位置無關
- **空間律** W(i): 凝聚**位置權重** (晶格幾何 + 阻挫) — 同 ℓ 無關
- 兩者正交: W(i) 冇 ℓ 依賴, 4^{−ℓ} 冇位置依賴

### 2. 模態預算 ↔ 位置自由度

```
N_ℓ = 44·4^ℓ = B·L₅·4^ℓ      (模態預算 — 時間層級, O140)
60 節點 = B·(L₅+B)           (位置自由度 — 固定, docs/01)
92 = 60+32 = 2(N_d+μ²)       (總自由度 — 節點+阻挫邊)
44/60 = L₅/(L₅+B) = 11/15    (模態/位置比 — 譜身份)
```

- ℓ 層嘅「新凝聚」唔係新增節點 — 係**同 60 節點**上嘅新事件 (docs/14 重構)
- 4^ℓ 分支: 每層 ×4 模態 → 每層事件分散到 4^ℓ 倍嘅模態通道
- **位置集合固定, 事件率稀釋** — 「新節點出現」係誤導性問題 (docs/14)

### 3. 層級中心模 ↔ 位置

O174: 層級 ℓ 鏈中心模 n = 22·4^ℓ 恆滿足 γ = μ² = 2。
- 每層凝聚「方向」由中心模鎖定 (全層級自我相似)
- 位置由 W(i) 決定 (幾何), 方向由中心模決定 (譜) — 兩者正交

**層級映射閉合**: 4^{−ℓ} 係時間事件率 (O174 電荷稀釋), 位置分佈由
