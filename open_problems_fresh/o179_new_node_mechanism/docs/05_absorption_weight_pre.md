## 1. 測試對象

O252 視線遮蔽窗中心速度 μ_hat = 235.7 km/s（SE = 21.6, R10 fit）係咪可以由
O179 hop 階梯 + 幾何推嘅「吸收截面權重加權平均速度」命中。

## 2. 數據來源（全部已存在，O179 正典 / O252 已用）

- 節點: `cmb_cold_spot/data/a5_nodes.txt`（60 節點 RA/Dec）
- 阻挫邊: `cmb_cold_spot/data/frustration_edges.txt`（32 邊）
- hop 階梯: n(h) = [1,4,8,11,12,11,8,4,1]（Σ=60，O179 正典）
- 速度映射: **v(h) = Vmax·√(h/8), Vmax = 409.78 km/s**（O252 R13 已用，唔屬 O179 新假設）
- 比較框架: ⟨v⟩_w = Σ_h w(h)·v(h) / Σ_h w(h)（O252 R13 用同一形式做質量統計）

## 3. 候選權重（全零新常數，全部由譜量/幾何生成）

| # | 候選 | 定義 | 結構身份 |
|:-:|:-----|:-----|:---------|
| W1 | 阻挫端點密度 | w₁(h) = n_frust(h) = 層 h 內阻挫邊端點總數 | O7 阻挫 = 凝結應變庫存 |
| W2 | 干涉核 | w₂(h) = n(h)·[1 + (B/L₅)·cos(πh/4)] | O179 位置權重層和, C = B/L₅ = 4/11 |
| W3 | 層環截面 | w₃(h) = n(h)·h | 2D 遮蔽截面 ∝ hop（幾何） |

**固定形式**：每候選只有一種定義（唔准計算後調整）；權重係「每層總截面」。

## 4. 預先宣布決策規則

對照目標：μ_hat = 235.7，SE = 21.6 → 95% CI = [193.4, 278.1]

| 判定 | 條件 | 流向 |
|:-----|:-----|:-----|
| 🟢 命中 | \|⟨v⟩_w − 235.7\| ≤ 21.6（1 SE 內） | 候選成為窗中心結構身份候選 |
| 🟡 兼容 | 21.6 < \|⟨v⟩_w − 235.7\| ≤ 42.3（95% CI 內） | 候選保留，需更多源 |
| 🔴 排除 | \|⟨v⟩_w − 235.7\| > 42.3 | 候選淘汰 |
| ⚫ VOID | 候選權重幾何為零（結構崩壞） | 唔判 PASS/FAIL，記錄原因 |

**Baseline 對照**（唔屬於候選）: 質量權重 ⟨v⟩ = 280.03（O252 R13 已計，Δ=44.33 → 🔴）

## 5. MC null（沙漠檢查，10⁶）

- 對每候選：隨機層權重 r(h) ~ U(0,1)×n(h)，計 ⟨v⟩_r 分佈
- p_null = P(|⟨v⟩_r − 235.7| ≤ 42.3)（隨機權重命中 CI 概率）
- 若 p_null > 5% → 沙漠（任何權重都中，候選命中無信息量）→ 標記「低鑑別度」
- 若 p_null ≤ 5% 且候選命中 → 候選有鑑別度

### 7.3 判定 (按 §4/§5)

- 🟢 命中: 0　🟡 兼容: 1 (W2, 模糊)　🔴 排除: 2
- **W2 「兼容」無鑑別度**: p_null = 43.7% ⇒ 隨機權重命中 CI 機率 ≈ 44%,
  W2 佔位 39.9 percentile = 同隨機權重無法區分。即 W2 唔算結構出路。
- **結論 (誠實)**: 吸收截面權重三候選**冇一個命中 1SE**；唯一「兼容」係沙漠帶內嘅隨機
  佔位 ⇒ 窗中心身份維持開放，O252 R13「需要新幾何/機制或高解像樣本」結論 reinforced。
- **元問題**: 95% CI [193.4, 278.0] 覆蓋 85 km/s ⇒ 任何合理權重都幾乎走唔出帶,
  呢個測試鑑別度本身受限 (O252 R14 已指出)。分辨候選需要更多源收窄 CI。
- **結構限制**: 三候選全由譜量/幾何生成 (零新常數), 形式凍結於預註冊 —
  冇候選需要事後調整。保留 W2 作觀測層候選 (等更多源), 但唔升格為閉合。
