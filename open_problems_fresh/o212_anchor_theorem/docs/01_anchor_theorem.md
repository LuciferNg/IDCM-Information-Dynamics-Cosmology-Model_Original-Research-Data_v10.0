
## 五、★ 對 SESSION_START 命題嘅修正（誠實記錄）

SESSION_START §一 寫：

```
現狀：逐項自帶標度
| 量        | 標度          | 來源                        |
| M₀        | 27.9009 MeV   | E_kchain·φ^(47+37/528)      |
| A (冷斑)  | 134.2 μK      | 88×61/40 × T_CMB            |
| R_world   | 4129.94 Mpc   | r_d×88×421/(420π)           |
| a₀        | c²/2πR_H      | 幾何                        |
| ω_ring    | 72.73 km/s/Mpc| BBN 鎖定                    |
問題: 呢啲標度之間嘅關係係逐個推, 唔係由單一錨 + 結構數一次導出。
```

**本 O 修正**（三點）：

1. **「逐項自帶標度」係表象**。上表每一行都係 `錨 × 無量綱數`：
   - `R_world = r_d × 88×421/(420π)` → `r_d` 本身 = `N × l_Pl × 420π/(88×421)`
   - `M₀ = M_Pl × N^(−1/2) × (1891/2025)φ^e`（O38）
   - `a₀ = (l_Pl/t_Pl²) × N^(−1) × 1/(2π)`
   佢哋**已經**係同一個錨嘅投影；「逐個推」只係推導路徑嘅歷史順序，唔係標度來源嘅獨立性。

2. **「錨全觀測（r_d / M_P / ω_ring）」需要拆開**：
   - `c, h, k_B, e` **唔係觀測錨** — 佢哋係 SI 2019 精確定義（換算因子）。「錨全觀測」嘅講法對佢哋唔成立。
   - `r_d` 唔係錨 — 佢係 `R_world × 420π/(88×421)`（O171），而 `R_world = c/ω_ring`。
   - `ω_ring` 同 `G` **係同一自由度嘅兩張臉**（經 BBN 鏈 `ω_ring² = 8πGρ_c/3`, `ρ_c = η_B m_p n_γ/Ω_b`）。
     `scripts/02` C5 證實：由 `N` 反解 `G = 6.6743e−11`，**dev = 0.00000%**。
   - ⟹ 錨候選裁決（交付物 2）：**G ≡ ω_ring ≡ M_Pl**，三者同一個自由度；`r_d` 係導出。

3. **「單錨 → 全標度 結構映射未證」→ 本 O 已證**（§二）。且係**唔需要證**嘅 —— 因為佢係維度齊次性嘅必然，同 O200 §四 嘅化簡一致。
