## 問題回顧

IDCM 核心假說: **60 個 A₅ 節點全部有溫度異常**（拓撲縫合節點）。O5 目錄對比只發現 2 個強冷 (node0 + node9) — 其他 58 個冇對應目錄。O52 要測其餘節點有冇**系統性微冷/微熱**（低於目錄閾值, 但統計上可檢測）。

## 🚨 Frame Bug 修正 (2026-08-21)

初版 script 用 ICRS RA/Dec → theta/phi 直接採樣 SMICA 地圖 — **frame inversion trap** (SMICA + R3 mask 都係 Galactic frame)。錯誤結果: R3 mask 48/60 保留 (正確: 45/60), 溫度全部錯位。

**修正**: `SkyCoord(icrs).galactic` → `hp.ang2pix(nside, l, b, lonlat=True)`。修正後 R3 mask 45/60 同 O27 完全一致 ✅。**教訓: 任何新 sampling script 必須先 frame check (skill 反幻覺鐵律 §1)。**

## 方法

SMICA 平滑地圖 (0.5°-10°, O5 cache) × 每尺度:

1. **60 節點 mean vs 全天空** (|b|>25°): Welch z
2. **高緯度子集** (|b|≥30°, n=31): 避開銀河面
3. **R3 mask 分層** (O27 要求): unmasked 45 vs masked 15
4. **符號不對稱**: 冷/熱數量 + 2σ 極端
5. **隨機控制組**: 同緯度 60 點 × 2000 resample → z_ctrl
6. **剔除 node0/node9**: 排除已知異常後嘅敏感性
7. **堆疊 radial profile** (3.0°): 60 節點平均 (0-2°, 2-4°, ... 12-14°) vs 1000 random stacks

## 對 IDCM 嘅意義 (誠實評估)

1. **「全部節點有異常」假說 🔴 否證**: 60 節點 mean、高緯度子集、unmasked 45、堆疊 profile 全部零偏移。節點網絡唔係「60 個縫合點全部有溫度特徵」。

2. **真正嘅異常只有 node0 + node9** (O5 + O21 已確認):
   - node0 (大冷斑): -134.19 μK, rank 1/60, 三地圖一致
   - node9 (第二冷): -107 μK, rank 3/60, 三地圖一致, 但 O21 已證明只係高斯隨機極端值 (z=-1.46σ, p=8.2%)

3. **IDCM 觀測內容修正**: 唔係「60 節點全部有異常」, 而係:
   - **拓撲位元層** (阻挫邊 32 條, |ΔT| gap p=0.016): 有真實信號 (O7/O21 P2)
   - **節點溫度層**: 只有 node0 一個顯著極端值, node9 係隨機極端值
   - 兩層要分開表述, 唔可以混為「全部節點有異常」

4. **注意**: 呢個係**觀測層面**嘅否證 — 「節點有異常」係觀測預言。數學層面 (λ₂=φ⁻² 群論閉合, O4) 仍然成立, 但佢預言嘅係**網絡結構**, 唔係**節點溫度**。
