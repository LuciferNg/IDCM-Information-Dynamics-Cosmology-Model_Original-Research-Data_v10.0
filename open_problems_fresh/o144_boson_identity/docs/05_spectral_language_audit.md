## (i) 譜運動學: ✅ 有用

### 公理清晰
```
A0 有限譜: ε_n = 4sin²(πn/2N), n=1..N
A1 離散波方程: ∂²φ/∂t² = c²Δ_disc φ
A2 相對論原理: 色散關係與參照系無關
```

### 導出 (非擬合)
```
v_n = c·cos(πn/2N)          群速度 (離散色散直接微分)
γ_L(n) = csc(πn/2N) = 2/√ε_n  Lorentz 因子
η_n = ln cot(πn/4N)           快度格子
E_n = mc²csc, p_n = mc·cot   → E²−p²c² = m²c⁴ 精確 ✓
SR = K_Tree 尺度精化 ℓ→∞ 極限 (N_ℓ = N·4^ℓ)
```

### 獨立檢驗 (真實觀測)
| 測試 | 結果 |
|:-----|:-----|
| Pantheon+ 1701 SNe | FSR 零參數 χ²=2006.8 vs ΛCDM (3 參數) 2002.1; ΔAIC=−2.7 (ΛCDM 略優) |
| DESI BAO | 部分 tracer −3.05σ (張力) |
| 高 z (z>0.8, 30 點) | χ²=35.6 vs 26.7 — **可證偽張力**, JWST 可判 |

**評**: 這是真語言 — 公理先驗、預言可算、有獨立數據對比、有可證偽點。

### ⚠️ 但 FSR 沒有解決質量譜
FSR docs/02 line 79 自認: 「質量 (∝ γ_n^{44}) 和最大速度 (cos(πn/88)) 來自同一本徵值 — **同一階梯兩個讀數**」。
⟹ 「質量 ∝ 本徵值」是**讀數識別 (輸入)**, 不是三公理的後果。FSR 導出運動學; 質量譜是從 O54 繼承的。
⟹ **FSR 對質量譜問題是正交的** — 它描述「有質量 m 的粒子如何運動」, 不決定 m 的值。

## (ii) 譜語法: ❌ 無用 (作為預言語言)

### [A] 語法退化測試 — 144 個解

CSG v2 docs/03 宣稱: 網格由 6 個 T̂ 常數生成 `{N_d=44, L₄=7, L₅=11, F₇=13, F₉=34, L₆/F₅=3.6}`, 形式 `{x, N_d−x, (N_d−x)/2}`。

**嚴格語法池 (16 值) 掃描結果**:

| 粒子 | <1% 選項數 | 替代解 |
|:----:|:----------:|:-------|
| e | 1 | n=1, L₆/F₅ (唯一) |
| μ | 2 | n=7,(N_d−F₇)/2 ✓ **或** n=15, L₆/F₅ |
| τ | **6** | n=19/N_d−L₆F₅ (0.094%), n=20/N_d−L₄ (0.339%), n=39/(N_d−L₅)/2 ... |
| u | **0** | 無 (最佳 2.02% > 1% 門檻) |
| d | 1 | n=1, N_d−L₅ (唯一) |
| s | 2 | n=6,(N_d−L₄)/2 **或** n=14, L₆/F₅ |
| c | 3 | n=34,F₇ **或** n=15,N_d **或** n=29,(N_d−F₇)/2 |
| b | 2 | n=33,N_d **或** n=36, N_d−L₆F₅ |

**解空間上界 = 144** (放寬到 83 值池 → 7.2×10⁵)。

**代數視角**: 16 未知 (8n + 8P_f) − 8 質量方程 = **8 維連續解空間**。粗粒化 (1% 窗) 後仍有 144 個解。

⟹ CSG v2 的「16 約束 = 16 自由度 → 唯一解」**只在其 5 條後驗約束成立時為真**。若只用先驗約束 (質量方程 + 一代基本模), 解不唯一。

### [B] S₃ 對偶「單射」實為三種不同形式

| 家族 | 特徵常數 X | 兩個槽的實際形式 |
|:----:|:----------:|:-----------------|
| L | L₄=7 | n(μ) = **X** \| N_d−P_f(τ) = **N_d−X** |
| D | N_d−L₅=33 | P_f(d) = **X** \| n(b) = **X** |
| U | F₇=13 | P_f(c) = **X** \| P_f(u) = **(N_d−X)/2** |

三家族用**三種不同形式** → 「三個轉置各用一次 → 選擇定則閉合」不成立: 仍需選擇「哪個家族用哪種形式」。這與 O136 docs/03 判定的「公式形式不一致 🔴」同構。

### [C] 音樂 cross-domain 測試: 24 個單調性違反

CSG docs/04 宣稱「α = beat/κ 決定和諧/不和諧邊界」, 但該文檔**自己的表**違反此規則:

| 音程 | α | 和諧度 H | 音樂理論 |
|:----:|:--:|:--------:|:---------|
| 純四度 | 7.73 | 1 (最和諧) | 最和諧 |
| **三全音** | **9.80** | **4 (不和諧)** | **不和諧** |
| 純五度 | 11.73 | 1 (最和諧) | 最和諧 |
| 大七度 | 15.73 | 4 (不和諧) | 不和諧 |

tritone (α=9.80) 夾在兩個「最和諧」之間卻是「不和諧」; 大七度 α 最大卻不和諧。文檔聲稱「α>>1 → 和諧」被自己表格否證。且「和諧度」欄本質是音樂理論輸入的重標籤 (循環)。

### [D] 0 個 out-of-sample 預言

網格覆蓋 8 費米子 — 全部參與 16 約束建構。質子/膠球/中微子/ν 比值: 網格無機制, 預言不出。
⟹ LOOCV 8/8 是 **value-blind** (值盲測: 用其他粒子推此粒子的值), **非 form-blind** (形式盲測: 不用任何觀測值推導規則形式)。後者才是真盲測 — 而 [A][B] 顯示形式無法先驗固定。

## 核心診斷

```
譜語言有兩半:
  運動學半 (ε_n → v, γ_L, 質量殼)  = 公理導出, 有觀測檢驗  → 真語言 ✅
  語法半   (ε_n → 粒子質量)        = 後驗編碼, 144 個解     → 假語言 ❌

為何語法半失敗: 它把「已觀測的 8 個質量」用結構名詞重寫 (重新編碼),
              而不是產生新預言。144 個解 = 語法選不出正確的那個。

更深層: 運動學半說「質量是質量殼雙曲線參數 m²c⁴ = E²−p²c²」,
        語法半卻把質量當成「本徵值 × 投影」。兩者角色衝突 —
        而公理支持的是運動學那半。
```

## 對攻堅方向的含義

1. **譜語言對質量譜問題目前無用** — 它的價值在運動學/宇宙學 (有觀測檢驗那半)。
2. **要讓語法有用, 必須把 144 → 1** — 需要 ~7 條**先驗**約束 (從原理來, 不是從數據讀)。CSG v2 的 5 條是後驗, 所以不閉合。
3. **候選原理**: 變分原理 (極值化作用量) 或 作用在網格上的對稱群 — 這正是 O137 方向一, 但要求更嚴: 原理必須**刪掉 144 個解**, 不是描述它們。
4. **可驗收標準**: 任何新語法必須 (a) 零觀測輸入導出 (n,P_f) 規則形式, (b) 通過 form-blind 盲測, (c) 至少 1 個 out-of-sample 預言。
