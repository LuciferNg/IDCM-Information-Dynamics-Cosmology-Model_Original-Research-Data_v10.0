## 4. 三個描述性事實（下輪假說種子, 非結果）

1. **p/n/η′ R_h ≈ 33 M₀ = M_tree**（p 33.19, n 33.05, η′ 32.91）—— p/n 係 docs/10 `E_bind = M₀·M_tree` 嘅既有 0.92% 結果；η′ 接近 33 係新嘅描述性觀察。**但** η/Λ 同 modes (11,9,7) 卻係 18.2 同 38.6 ⟹ 同 modes 唔同 R_h ⟹ 純 multiset 函數被 η/η′/Λ 反例否證（三者 modes 相同: R_h = 18.2 / 32.9 / 38.6 三值！）—— **R_h 唔可能係 quark-multiset 嘅函數**，必含態量子數（自旋/混合/宇稱）——結構性結論 ✅
2. **strange 目標近似等差**: Λ−p ≈ 5.4, Σ+−Λ ≈ 2.8, Ξ0−Σ+ ≈ 3.5 (M₀) —— 描述；強子質量分裂尺度（~3-5 M₀ = 90-150 MeV）。
3. **重味節點堵塞**: 冪律 b-node = 7304 MeV > B 介子質量 5279 ⟹ B/ϒ 嘅 R_h 為負（−72.6/−184.5 M₀）⟹ **凍結 C 嘅冪律節點質量喺重味失效**（O238 已知 c/s、b/c 比 >3σ 離群，本輪確認佢令連結層 additive 模型結構性失敗）。
