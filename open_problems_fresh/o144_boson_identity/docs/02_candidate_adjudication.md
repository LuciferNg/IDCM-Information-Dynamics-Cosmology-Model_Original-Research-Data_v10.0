## 一、裁決結果: 候選 A 勝出, 候選 B 排除

### 候選 A: m_p = F_proj × M₀ × ω_max (948.63 MeV, 偏差 1.104%)

**C_p = 17 的雙重結構身份** (φ-group 幾何先驗推導 ✅):

| 身份 | 公式 | 來源 |
|:-----|:-----|:-----|
| L₆ − 1 | 18 − 1 = 17 | O121 修正 (F_proj = N_d − n*, n* = N_d − L₆ + 1 = 27) |
| Σφ8 (Gen1) | φ=8 扇區相交和 [1,10,2,2,2] = 17 | O137 3×44 扇區矩陣 (與 C_e 分子共用結構!) |

**γ 因子 = ω_max = 2 的身份**: ω_max = ω₄₄ = 2 = **γ₂₂** (4sin²(22π/88) = 2)。γ₂₂ 是 **φ=6 扇區對應的 Nyquist 模式** (φ=6 ↔ K_Chain modes {22, 44}, script 39)。

⟹ **候選 A 重寫為全 φ-group 語言**:
```
m_p = M₀ × γ₂₂ × Σφ8 = M₀ × 2 × 17 = M₀ × 34 = M₀ × F₉
      ↑ φ6 Nyquist 模式   ↑ φ8 Gen1 相交和
```

### 候選 B: m_p = M₀ × γ₂₀²γ₇ × 47 (943.98 MeV, 偏差 0.608%) — 排除

**C_p = 47 無 φ-group 算子身份** ❌:
- 47 = L₈ (Lucas 數, 純代數 — 非幾何算子)
- 47 = N_d + N_gen (計數)
- 47 = φ=9 點 label (索引, 非結構量)
- **47 ∉ Φ** (φ=9 相交矩陣值集: {1,2,4,5,6,7,8,10,16,21,28,31,36,37,55,64})

**γ 因子 γ₂₀²γ₇ = 0.719858**: 20/7 為輕子模式索引 (τ/μ), 非扇區算子。⚠️ 但發現 γ₂₀²γ₇ ≈ C_e/N_φ8 = 3.6/5 = 0.72 (偏差 **0.020%**) — 候選 B 的 γ 組合意外地是輕子結構比。此巧合無助於 C_p=47 的致命缺陷, 記錄備查。

## 二、新結構發現

### 1. ★ 節點閉合: 2P_u + P_d = 64 = Φ[3,6] ∈ φ=9 相交矩陣

O136 給 u: P_f = 15.5 (與 μ 共用), d: P_f = 33 (N_d − L₅)。
```
2P_u + P_d = 2×15.5 + 33 = 64 = Φ[3,6] = 1 + 9×7  (G1 x₃=9 × G2 x₃'=7)
```
64 直接是 φ=9 相交矩陣元素 (Φ 值集: ..., 55, 64)。u/d 投影因子和的 **φ9 幾何身份** — O136 P_f 結構閉合的一步。節點質量:
```
m_uud = M₀ × γ₁ × Φ[3,6] = 27.9009 × 0.005096 × 64 = 9.10 MeV (obs 8.99, 1.2%)
64 = B³ = 4³ (補充身份: K_Tree 分支的三次冪)
```

### 2. ★ 膠球閉合候選: X(2370) = M₀ × N_φ8 × Σφ8 = M₀ × 5 × 17 = M₀ × 85

**BESIII X(2370) 純連結凝聚 — 無夸克 — 直接檢驗「連結能量 = 質量」**:
```
m_glueball = M₀ × N_φ8 × Σφ8 = 27.9009 × 5 × 17 = 2371.58 MeV
```
- N_φ8 = 5 = φ=8 扇區點數 = **玻色子站點 {8,16,24,32,40}** (v₂ ≥ 3 純玻色子模式)
- Σφ8 = 17 = Gen 1 與 φ8 扇區相交和 [1,10,2,2,2]
- **零參數, 全 φ-group 語言** — 玻色子扇區的自相交 = 純連結凝聚
- 85 = 5×17 亦 = 2N_d − N_gen = 88 − 3 (計數身份, 次要)

**實證對照 (web 查證 2026-09-17)**:
| 目標 | 值 | 偏差 |
|:-----|:---|:----:|
| X(2370) 文獻命名 | 2370 MeV | 0.0665% |
| BESIII 精確中心值 (2011, π⁺π⁻η′) | **2376.3 ± 8.1(stat) +3.1/−4.3(syst)** MeV | 0.20% — **在 1σ (8.1 MeV) 內** ✓ |
| 格點 QCD 假標量膠球預言 | 2.1–2.7 GeV | 範圍內 ✓ |

**結構解讀**: 膠球 = 玻色子扇區的「總相交度」— 5 個玻色子站點 × 它們與 Gen 1 的相交和。這是 P2 (連結能量) 語言的**第一個零參數閉合候選**。

**⚠️ 誠實標記**: 
- 對精確中心值 2376.3 偏差 0.20%, 在統計誤差 8.1 MeV (0.34%) 內 — 閉合候選而非閉合
- X(2370) 非純膠球 (`arXiv:2605.01757`: 與 ηc 有 ~1° 混合) — 質量偏移來源之一
- 曾試 `M₀×85 + m_d` = 2376.27 (0.001%) — **拒絕**: 膠球無夸克, 加 m_d 無物理理由 (擬合陷阱)

### 3. 同源假說: 質子/膠球 = N_φ8/γ₂₂ = 5/2

```
質子 (候選 A) = Σφ8 × γ₂₂   = 17 × 2  = M₀×34
膠球          = Σφ8 × N_φ8  = 17 × 5  = M₀×85
比 = N_φ8/γ₂₂ = 5/2 = 2.5 (exact)
obs: 2370/938.272 = 2.5259 (1.04% 差 = 質子殘差的傳播)
```
兩者同源 (共同因子 Σφ8), 差別只是「玻色子點數 5」vs「φ6 Nyquist 模式 2」。docs/01 判準 4 (同源) 結構上成立。
