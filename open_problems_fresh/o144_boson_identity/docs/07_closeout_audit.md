### N1 ★ C5/C6 行和 screen 是「值盲」— 刪除力來自方程形式, 非目標值的身份

`docs/06` §2.2 列 C6 (L 行 n 和 = 28) 刪除率 95.45%。本輪掃描 L 行 n 和的**完整分佈**:

```
19 個可行值; 頻數 294 (15 個值) 或 588 ({46,47,49});
28 的頻數 = 294, 在 19 個值中並非最優 (max = 588)。
```

⟹ **任何**單一 n-和值都至少保留 294 個解; `= 28 = N_φ12` 的身份**沒有額外鑑別力**。
C6 的刪除力純粹來自「一條線性方程」這個**形式**。這比 docs/06 §4 的「挑哪個常數配哪個行和是自由選擇」更強:
**連目標值本身都不攜帶信息**。同理由 C5 (U 行 P_f 和 = E_proj = 28.5) 類推。
