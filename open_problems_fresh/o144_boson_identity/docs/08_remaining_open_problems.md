## 一、問題 12 — 對偶/共享的模式身份 (S₃ 家族對稱) 🟡

### 1.1 真網格模式 (本輪首次精確化)

| 關係 | 配對 | 家族 | 類型 |
|:-----|:-----|:-----|:-----|
| 對偶 1 | (τ, μ) | L ↔ L **同家族** | P_f(τ) = 37 = N_d − n(μ) = 44 − 7 |
| 對偶 2 | (b, d) | D ↔ D **同家族** | n(b) = 33 = P_f(d) |
| 共享 1 | (e, s) | L ↔ D **跨家族** | P_f = 3.6 |
| 共享 2 | (μ, u) | L ↔ U **跨家族** | P_f = 15.5 |

⚠️ 對偶有**兩種類型** (`P_f = N_d − n` 與 `n = P_f`) — scripts/20 初版只檢查第一類,
導致真網格被誤算成 1 條對偶 (已修正, 與 scripts/14 `dual_set` 一致)。

### 1.2 V10 原則 (預註冊): 「對偶全同家族 ∧ 共享全跨家族」

| 量 | 值 |
|:---|:---|
| 311 網格中符合者 | **5** |
| p (真網格碰巧符合的機率) | **0.0161** |
| Bonferroni (×10 條原則) | **0.161** → 校正後**不顯著** (未達 z ≥ 3) |
| 刪除力 | 311 → 5 (**62×** 壓縮) |
| 真網格 | ✅ 在 5 個之內 |

**14 條預註冊原則中唯一有刪除力者**。其餘 13 條 (含 6 條變分極值 + 3 條全域數論) 全部 ❌。

### 1.3 ★ 殘餘歧義定位 — 本輪最有價值結果

5 個存活者與真網格的差異**只在兩個粒子**:

| # | 差異 | c 的 n |
|:-:|:-----|:------:|
| 1 | s: (14, 3.6) → (6, 18.5); c: (34, 13) → (25, 18.5) | 25 |
| 2 | c: (34, 13) → (25, 18.5) | 25 |
| 3 | c: (34, 13) → (27, 16.5) | 27 |
| 4 | c: (34, 13) → (33, 13) | 33 |
| 5 | — (**真網格**) | **34** |

```
差異粒子頻率: c × 4, s × 1
⟹ 整個 O144 網格歧義已收縮到一個整數: n_charm ∈ {25, 27, 33, 34}
⟹ c 的 P_f = 13 = F₇ 已被 V10 固定; 只有 n 未定
```

**⚠️ 誠實標記**: tie-breaker T4 (「c 的 n ∈ Fibonacci」→ 選 34) **為後驗** — 在觀察到 §1.3
之後才提出, **不可計入盲測**。合併機率 (V10 × T4 局部 1/4) = 0.004 raw, Bonferroni ×14 = **0.056**
→ 🟡 邊緣不顯著。

**且 33 亦有結構身份**: 33 = N_d − L₅ = 3 × 11 = N_gen·L₅。所以「34 = F₉ 勝 33」**本身仍未推導** —
這是問題 12 的真正核心, 已精確化為單一整數的裁決。
