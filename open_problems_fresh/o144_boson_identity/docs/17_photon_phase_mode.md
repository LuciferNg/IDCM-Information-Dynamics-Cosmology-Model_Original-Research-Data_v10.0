## §1 ★ 徑向 vs 相位分解（張力之解）

作用量（o159 docs/02，由 176-Laplacian BVP + 扇區不對稱推出）：
```
S = Σ_j |φ_{j+1} − φ_j|² + μ² Σ_j |φ_j|²,   μ² = 2 (derived)
```

寫複場 `Φ = ρ e^{iθ}`（ρ 實振幅、θ 相位）：
```
|∂Φ|² = (∂ρ)² + ρ²(∂θ)²
μ²|Φ|² = μ² ρ²
⟹ S = (∂ρ)² + μ² ρ² + ρ²(∂θ)²
```

| 模 | 質量² | 來源 | 對應上游 |
|:--|:--|:--|:--|
| 徑向 ρ | `m_ρ² = μ² = 2` | `μ²\|Φ\|²` 項 | o159「零模獲得質量 ω₀ = √2」 |
| 相位 θ | `m_θ² = 0` | **無勢**（θ 只透過 ρ² 耦合） | o85「剩餘相位 = 光子」 |

**★ 張力之解**：o159 之 `ω₀ = √2` 係**徑向（振幅）模**；o85 之「n=0 零模 = 光子」係**相位模 θ**。
兩者係**同一 mode 之兩個自由度**，屬**不同扇區** ⟹ **無矛盾**。

**核實**（精確）：`ω₀ = √(γ₀+μ²) = √(0+2) = √2 = μ` ✓（γ₀ = 0 裸零模）。
