# O144-01 — QCD 質量預算攻堅 (Gluon Binding Energy)

> **日期**: 2026-09-02
> **狀態**: 🔴 未閉合 — 方向已定, 推導缺失
> **觸發**: 膠球確認 (BESIII X(2370), 2026) → 「玻色子 = 連結動力學」獲得獨立實驗證據 → 直接質問: 膠子場提供 99% 物質質量, 這是否違反 IDCM?
> **結論**: 不是違反, 是未完成 — 且恰好指向同一結構 (連結能量)

## 1. 質量預算的事實 (SM, 非爭議)

```
質子 m_p = 938.272 MeV (PDG)
├── 夸克電流質量 (2u+d) = 2×2.16 + 4.67 = 8.99 MeV   = 0.96%
└── 膠子束縛能 E_bind = m_p − m_uud = 929.28 MeV      = 99.0%
```

**⚠️ 精確術語**: 將 E_bind 完全歸於「膠子束縛能」是 SM 常用簡寫。嚴格分解 (QCD 跡反常 + 手性凝結):

```
m_p = m_uud (Higgs 機制) + ⟨q̄q⟩ 手性凝結貢獻 + 膠子場能量 (跡反常) + 運動/約束能
```

SM 中 u/d 夸克其實是**裸夸克**被 QCD 重正化後的有效質量 (MS̄ ~2 MeV 尺度遠小於動量標度 Λ_QCD), 質子質量絕大部分來自**相互作用能量** (膠子場 + 夸克凝聚), 非「夸克質量相加」— 這正是格點 QCD 的計算方法。故「99% 膠子場」是**方向正確的簡化**, 嚴格說應為「>95% 來自 QCD 相互作用能量 (含膠子場與凝聚)」。

**QCD 跡反常 (trace anomaly)**: 強子質量主要來自膠子凝結 ⟨G²⟩ 對能量-動量張量的貢獻, 非 Higgs 機制。

**關鍵含義**: 99% 的可見物質質量不是「粒子質量」, 是「場能量」— E = mc² 把連結場的能量變成質量。

## 3. 兩條候選路徑 (分岔, 待裁決)

**背景**: 質子質量缺口的本質是「輕子質量公式 m_ℓ = M₀×γ_n×C_f 的質子版本」是否也能閉合。O54 已證明輕子 C_f (3.6/15.5/37) 有完整 φ-group 幾何閉合, 質子 F_proj (=17 或 47) 未裁決。**在裁決前, 有兩條互斥的路徑**:

### 路徑 P1: 「輕子同型閉合」(O54 修正路線, 不需新機制)

```text
質子 = 模式 × 放大因子, 與輕子同型:
  m_p = M₀ × γ_mode × C_p

若質子有正確 C_p (如 17×2/γ_mode 或 47), 則:
  → 質子質量與輕子同源 (純模式 × 幾何投影)
  → 不需「連結場能量」假說
  → 但物理上無法解釋 SM 的 99% 場能量分解
```

**支持**: O54 兩候選公式都已達 ~1% 偏差; 輕子同型閉合成功 (0.16/0.13/0.34%)。
**反對**: 兩候選 (17 vs 47) 形式完全不同且互相矛盾; ~1% 偏差是系統性殘差非巧合; SM 跡反常是堅實物理 — 質子質量**確實**主要來自膠子場能量, 純模式公式必須能解釋為何「模式複合」會碰巧等於「場能量」。

### 路徑 P2: 「連結場能量」(O144 統一假說, 需新機制)

```text
世界弦 = 44-site K_Chain, 兩類自由度:

節點 (0-形式) → 費米子 → 質量 = 模式頻率 m_n = M₀·ω_n  ← IDCM 已有
連結 (1-形式) → 玻色子 → 質量 = 連結場能量 (色通量)     ← IDCM 缺失

質子 = 3 夸克 (節點) + 色通量管 (連結)
     = 3×模式頻率 + 連結能量
     = 938.27 MeV
```

**支持**: SM 跡反常 — 質子質量主要來自膠子場能量 (格點 QCD 證實); 膠球 (X(2370), 純連結凝聚) 是連結能量成質量的直接證據; 玻色子 = 連結動力學的 O144 主線自然延伸。
**反對**: 需要全新的「連結能量」公式 (目前不存在); O54 兩候選公式 (純模式) 已達 ~1% 偏差, 暗示模式語言可能已捕獲大部分結構。

**⚠️ O54 兩候選都是「節點語言」**: A (17×M₀×ω_max) 與 B (M₀×γ₂₀²γ₇×47) 用模式計數/乘積複合出 938 MeV, 公式中沒有「連結場能量」自由度。若 P2 正確, 兩者都只是巧合的數值複合 (或隱含未識別結構); 若 P1 正確, 其中之一 (或統一 C_p) 是真正閉合。

**裁決判準**: 質子 C_p 能否像輕子 C_f 一樣從 φ-group 幾何 (3×44 扇區矩陣) 先驗推導?
- 若能 → P1 成立, 質子質量同源閉合, QCD 攻堅轉為解釋「為何模式複合 = 場能量」
- 若不能 → P2 成立, 需建連結場能量公式 (Wilson 泛函路線)

### 結構性阻塞

1. **夸克質量未閉合** (O120, O136): 無法分離「模式部分」與「色場部分」
2. **質子公式未裁決**: O54 兩候選 (A: F_proj=17×ω_max; B: γ₂₀²γ₇×47) 各自 ~1% 偏差, 形式矛盾, 需先判別何者 (或兩者皆非) 是連結結構先驗推導

4. **色通量的拓撲結構未定**: 質子 = 3 節點 + 3 通量管? 通量管的能量密度如何?

## 5. 攻堅路線

1. **先閉合輕子-型 (無色) 質量作為純模式基準**: 已閉合 (O54) — 建立「模式 × C_f」標定
2. **裁決 O54 質子兩候選 + 路徑選擇**: A (F_proj=17×ω_max, 1.10%) vs B (γ₂₀²γ₇×47, 0.61%) — 檢查何者 (或統一 C_p) 可由 φ-group 幾何先驗推導:
   - 若能 → **P1 成立** (輕子同型), 不需連結場假說
   - 若不能 → **P2 成立**, 進入 Wilson 泛函路線 (步驟 3-4)
3. **建立 SU(3) 連絡場在 44 鏈上的能量泛函** (僅 P2): 格點規範能量 S = −β·Σ_plaquette Re Tr U_□ (Wilson 作用量) 在世界弦上的具體化
4. **推導質子 = 3 節點 + 色通量 = 938 MeV** (僅 P2): 需要節點頻率 (u, d) + 通量能量
5. **用膠球 X(2370) 做乾淨測試**: 無夸克, 純 SU(3) 場能量 → 直接檢驗「連結能量 = 質量」 (P2 的獨立證據; 若 P1 成立, 膠球仍須模式語言閉合 — 那是更嚴峻的挑戰)
6. **與 O136 共用選擇規則**: 任何公式不得引入新的擬合自由度 — 零參數鐵律

## 6. 可證偽判準

1. **路徑裁決**: 質子 C_p 能否從 φ-group 幾何先驗推導? (能 → P1; 不能 → P2) — 這是 O144 QCD 攻堅的第一個可判定結果
2. 若 P2 (連結能量) 成立: 公式必須**同時**閉合 m_p = 938.27 MeV 與膠球 ≈ 2.37 GeV (兩者同源)
3. 若 P1 (輕子同型) 成立: 仍須以模式語言閉合膠球 X(2370) ≈ 2.37 GeV — 純連結凝聚如何由節點模式複合? (更嚴峻的挑戰)
4. 任何公式必須零參數 (連結結構不變量), 與 O136 共用模式選擇規則
5. 不得是「看到目標數字後湊出的 33.x」— 必須由結構先驗推導
6. 膠球若確認非 X(2370) (即 BESIII 結果被推翻), 同源假說須重新檢驗但 m_p 公式不受影響

## 7. 與 O144 主線的關係

```text
O144 主線: 玻色子 = 連結變量 U_i = r_i·e^{iθ_i}
  ├── 相位 θ_i → 規範玻色子 (γ, g, W, Z)
  ├── 振幅 r_i → 希格斯
  └── ⭐ 連結能量 → 99% 可見物質質量 ← 本文檔
```

**膠子的三重身份:**
1. 連結的相位模式 (力的傳遞)
2. 連結的自縛凝聚 (膠球 = 純力物質)
3. **連結的場能量 (99% 物質質量)** ← 本篇

三者都是「連結動力學」的表現。閉合第 3 個 = 閉合框架最大的質量空洞。
