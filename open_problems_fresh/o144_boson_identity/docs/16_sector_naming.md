## §0 缺口之精確表述

docs/15 將淨缺口收窄為：

> 「為何該兩個 intrinsic 權重係 `(M_tree = 33, 2N_d = 88)`？」

即 `A_w = 88 + μ² = 90`、`B_w = 33 + μ² = 35` 之中，**為何「intrinsic」部分係 88 同 33**。

---

## §1 ★ 兩扇區權重之共同結構

| 扇區 | 權重 | 分解 | 來源 |
|:--|:--|:--|:--|
| 鏈（88-site 對偶） | `A_w = 90` | `= 2N_d + μ² = 88 + 2` | o159 §2 精確 |
| 樹（33-level） | `B_w = 35` | `= M_tree + μ² = 33 + 2` | O34 §4.4 🟢 |

**兩者同形**：`weight = (扇區自身不變量) + μ²`。

**每-site / 每-level 權重**（精確）：
```
Σγ_odd / (2N_d)  = 88/88 = 1        ← 鏈: 每 site 權重 1
Σλ / M_tree      = 66/33 = 2 = μ²   ← 樹: 每 level 權重 2
```

o159 §2 之精確分解（已載上游，本處只核實）：
```
Σγ_even = 90 = 21B + γ₄₄ + γ₈₈ = 84 + 2 + 4      (21 = F₈)
Σγ_odd  = 88 = 22B                                (22 = 2L₅ 完整 Z₂ 對)
μ² = Σγ_even − Σγ_odd = γ₄₄ = Tr(Dir) − Tr(Neu) = 2
```

## §2 ★ 為何鏈側基底係 `Σγ_odd`（觀察者）而唔係 `Σγ_even`（世界）

**o159 §3 之結構定理**（只讀引用）：
```
e^{i(j+176)kπ/176} = (−1)^k
  even k (世界): 週期 (period 176), J² = +1 → 實扇區
  odd  k (觀察者): 反週期 (period 352, double cover), J² = −1 → 虛扇區
```

**觀察者扇區自帶複結構**（`J = T₈₈`, `J² = −1` on odd sector）。

**推論**：標度橋之修正項 `(1 − 4/3150)` 係**複振幅相位效應**（`γ_k = |1−U_k|²`，
`U_k` 帶相位 `2θ_k = kπ/88`）⟹ 修正**自然住喺 odd（反週期/虛）扇區**
⟹ 鏈側 intrinsic 取 **觀察者子空間跡 `Σγ_odd = 88`**，唔係世界子空間跡 `Σγ_even = 90`。

**Z₂ 配對核實**（精確）：`γ_k + γ_{88−k} = 4 = B`（k = 1..43，畢氏 sin²+cos²=1）；
`k = 44` 自對偶（`88−44 = 44`），`γ₄₄ = B/2 = μ²`。

## §3 ★★ 「+μ²」被恆等式強制

```
μ² ≡ Σγ_even − Σγ_odd        (o159 §2, 精確, 定義性)
⟹ Σγ_even = Σγ_odd + μ²      (恆等式, 非額外結構)
```

**故「為何 90 唔係 88」之答**：90 係**世界扇區總和**；其自然分解 = 觀察者基底 (88) + 隙 (μ²)。
用 `Σγ_odd` 做 intrinsic，`μ²` 做「extra」，係**唯一唔重複計算**之分解
（若用 90 做 intrinsic 再加 μ²，就會 double-count 個隙）。

**同一 `μ²` 出現喺兩條鏈之 Dirichlet−Neumann 跡差**（o159 §2 fact 2，兩者皆精確）：
```
88 鏈: Tr(Dir) − Tr(Neu) = 178 − 176 = 2 = μ²
33 樹鏈: Tr(Dir) − Tr(Neu) =  66 −  64 = 2 = μ²
```
o159 明載「同值但不同機制，兩者都精確，唔好混埋」—— 本處只作**扇區權重之 extra 皆 = μ²** 之核實。

## §4 ★ 為何樹側 intrinsic 係 `M_tree` 而唔係 `Σλ` 或 `N_d − 1`

| 候選 | 值 | 判 |
|:--|:--|:--|
| `M_tree`（樹深度） | 33 | ✅ **基本量**：`= (χ−2)/4 = 3(φ⁵−φ⁻⁵)`（O34 §4.4 🟢） |
| `Σλ`（樹鏈跡） | 66 | 🔴 **派生量**：`= 2M_tree`（o155 docs/03 trace 定理）；且 `66−2 = 64 ≠ 33` |
| `N_d − 1` | 43 | 🔴 僅係 `44−1`，無獨立結構身份 |

**核實**（精確）：
```
M_tree = 3(φ⁵ − φ⁻⁵) = 33
Σλ = Tr(L_tree) = 33 × 2 = 66 = 2M_tree
A_w − 2N_d  = 90 − 88 = μ²   (鏈 extra)
B_w − M_tree = 35 − 33 = μ²  (樹 extra)
```

**為何唔係 `Σλ`**：若用 `Σλ = 66` 做 intrinsic，則 `B_w = 66 + 2 = 68`
⟹ `A_w·B_w = 90 × 68 = 6120` ⟹ 修正 `= 4/6120`，**唔等於**觀測值 `4/3150`（偏 48.6%）。
故 `Σλ` 已被**數值排除**，唔係選擇問題。

## §6 ⚠️ 誠實負面

1. **「已命名」本身係一條 restriction**：docs/15 §6 已標。若允許 `43 = N_d−1`、`68 = 2F₉`
   等派生組合入詞彙，則 `(43,68)` 亦得 `(45,70)` ⟹ 16 解並存。
   本輪之改進**唔係**消滅歧義，而係**為 restriction 提供動機**（見下）。
2. **動機（非證明）**：`intrinsic` 必須係**扇區自身之不變量**（鏈 = 觀察者子空間跡；
   樹 = 維度），唔可以係「另一扇區量之組合」。呢個係**原則性選擇**，仍未由更基本原理導出。
3. **`Σλ` 之排除係數值而非結構**：`Σλ` 被排除係因 `90×68 ≠ 3150`，唔係因「唔係不變量」。
   兩條理由並存，但只有前者係硬約束。
