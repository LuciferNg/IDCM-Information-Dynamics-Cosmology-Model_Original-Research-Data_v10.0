## §3 ★ 新子恆等式：`(N_d+1) = Σγ_even/μ²` 係定義性

**觀察**：`N_d + 1 = 45`；`Σγ_even/μ² = 90/2 = 45`。兩者相等。

**但唔係巧合** —— 係**定義性推論**：

```
μ² ≡ Σγ_even − Σγ_odd            (定義)
Σγ_odd = 2N_d                     (定理)
⟹ Σγ_even = 2N_d + μ²
⟹ Σγ_even/μ² = 2N_d/μ² + 1 = N_d + 1     (因 μ² = 2 ⟹ 2N_d/μ² = N_d)
```

⟹ `(N_d+1)` **唔係**額外假設；佢係「凝聚質量項 = 兩扇區能量差」之直接代數後果。

### 修正項之三個等價正則形

```
(i)   μ²/((N_d+1)(M_tree+μ²))        = 0.00126984126984
(ii)  μ⁴/(Σγ_even·(M_tree+μ²))       = 0.00126984126984
(iii) (μ²/Σγ_even)·(μ²/(M_tree+μ²))  = 0.00126984126984
```

**(iii) 係最有原理樣貌之讀法 —— 修正 = 兩個凝聚分數之乘積**：

| 因子 | 值 | 讀法 |

## §9 方法論產出

1. **「因子分解審計」**：面對一個「精確但無機制」之複合常數，**逐因子查其推導來源**，
   比整體密度測試更能定位缺口（本例：3 因子 → 2 個已閉合 → 缺口收窄到 1 項）。
2. **「定義性 vs 巧合」**：`(N_d+1) = Σγ_even/μ²` 看似數值巧合，實為定義之代數後果。
   檢查方法：由定義鏈 `μ² ≡ Σγ_even − Σγ_odd` + 定理 `Σγ_odd = 2N_d` 重推。
3. **φ-冪近命中須視為陷阱**（0.0043% 亦唔例外）。
4. **密度測試須用詞彙分層 + 同型模板枚舉**；單一 `dev ≈ 0` 係無效證據。
