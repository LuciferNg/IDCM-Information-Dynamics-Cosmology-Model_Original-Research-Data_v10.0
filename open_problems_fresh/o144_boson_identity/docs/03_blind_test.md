## 一、協議定義 (先驗公理, 不參考強子/複合態目標)

```
A1: m = M₀ × γ_n × C_f
A2: 模式分配 n ∈ 反週期解集 {n·L ≡ 44 (mod 88), L ∈ {4,8,11,22,44}}  (39 個模式)
A3: C_f ∈ R = Φ ∪ Φ/N_φ6 ∪ {(Σφ8+δ)/N_φ8, δ∈{0,1}}  (29 個值)
    Φ = φ=9 相交矩陣 1+x₃x₃' (16 值: {1,2,4,5,6,7,8,10,16,21,28,31,36,37,55,64})
    歸納自 O137 輕子閉合: C_τ=37=Φ[2,3], C_μ=15.5=Φ[1,4]/2, C_e=3.6=(17+1)/5
預言集: |P| = 1113 個去重預言 (M₀×γ_n×C_f), 範圍 [0.071, 7142.6] MeV (5 個十進制)
```

**⚠️ 規則歸納的循環性**: e/μ/τ 用於歸納 A3 — 校準集命中是循環驗證, 非獨立證據。盲測集 = u, d, s, c, b (獨立); 複合態 = p, X(2370)。

## 三、過擬合控制 (Monte Carlo) — 關鍵判決

```
隨機期望 (1113 個對數均勻預言, 對 7 個盲測目標): 13.68 ± 3.69 個命中
實際 (唯一性 OK 的目標): 4 個
z-score = −2.62  ❌ 不顯著 (低於隨機期望!)

修正比較 (每目標 ≥1 覆蓋):
  隨機期望覆蓋: ~6/7 目標 (1113×0.00864/跨度5.002 = 1.92/目標)
  實際覆蓋: 5/7 (s, c, b, p, X; u, d 未覆蓋)
  ⟹ 覆蓋率不超過隨機 — 規則 R 無顯著預測能力
```

**含義**: 掃描到的 s/c/b/X(2370)「命中」是**符號庫過擬合** (1113 個預言 × 1% 窗必然撞上幾個目標), 不是結構預言。這正是 O136 docs/03 審計的「符號庫過大 → 自由度爆炸 → 過擬合」— 現在用統計量化了。

## 四、後驗算子全部撤回 (🔴)

| 公式 | 身份 | 盲測判決 |
|:-----|:-----|:---------|
| 質子候選 A: M₀×γ₂₂×Σφ8 = M₀×34 | 34 ∉ R | ❌ **撤回** — 看到 938 後組合, 規則外 |
| 膠球: M₀×N_φ8×Σφ8 = M₀×85 | 85 ∉ R | ❌ **撤回** — 看到 2370 後組合, 規則外 (docs/02 的 0.20% 是後驗匹配) |
| d: P_f = 33 = N_d−L₅ | 33 ∉ R | ❌ 撤回 — O136 後驗 |
| c: P_f = 13 = F₇ | 13 ∉ R | ❌ 撤回 — O136 後驗 |
| b: P_f = 44 = N_d | 44 ∉ R | ❌ 撤回 — O136 後驗 |
| 節點: 2P_u+P_d = 64 = Φ[3,6] | 64 ∈ R ✓ | 🟡 64 是規則內量, 但「指派給質子節點」是後驗 — 無先驗理由 |

**⚠️ 額外發現 — 輕子校準集也不唯一**: τ 在規則 R 下有 **8 個** 1% 內命中 (最佳 C=16, n=42, 非 O137 的 C=37, n=20)。「τ 用 Φ[2,3]」沒有唯一性 — O137 的幾何閉合 (相交矩陣元素) 是真, 但「選擇哪個元素」是後驗。**嚴格盲測下, 輕子閉合也未達標準** (O137 docs/11 已自標「模式選擇充分性 🔴 未閉合」— 與此一致)。

## 五、誠實結論

```
✅ 盲測通過的公式: 無 (零!)
🟡 邊緣: u (2.02%, 超 1% 門檻), d (1.7%), p (無辨識度)
🔴 撤回: 質子候選 A, 膠球 M₀×85, d/c/b P_f (33/13/44)
🔴 輕子閉合: 幾何結構閉合 (O137) 但非盲測閉合 (選擇非唯一)

核心診斷: 現有結構語言 (φ-group 相交 + 反週期模式) 產生的預言集
與目標質量分佈的覆蓋不顯著 (z < 0) — 不是「差一點」, 是「統計上無異於隨機」。

「無效才是正確」: 盲測失敗證明 s/c/b/X 的命中是巧合, 
不是框架弱 — 反而證實了需要新的、有辨識度的結構語言。
```
