## 1. 問題

`docs/05` 結論: CSG v2 網格宣稱「16 約束 = 16 自由度 → rank 滿 → 唯一解」,
但用其宣稱的嚴格語法掃描得 **144 個解** (τ 有 6 個替代, c 有 3 個)。
「唯一」只在加上 5 條後驗約束時成立。

**本輪任務**: 找一個**先驗原理** (不是從數據讀) 把解空間刪到 1。

### 3.2 ★★★ 聯合被迫性 (script 14) — 核心否定結果

枚舉所有 (共享模式, 對偶集, 行和) 三元組, 數哪些能唯一決定解:

| 項 | 值 |
|---|---|
| 解空間 | 6,468 |

| R 候選 (家族 × 欄位 × 結構常數) | 96 |
| **能唯一決定解的三元組** | **362** |
| **被唯一選出的不同網格** | **311** |
| 真網格 | 1 / 311 |

**⟹ 同一套形式機制 (結構常數定靶) 能「唯一導出」311 個不同網格。
真網格只是其中之一。**
「唯一性」是**泛型**的, 不是真網格的專屬性質。

| 限制 | 桶 | 唯一三元組 | 不同網格 | 真網格在其中 |

## 4. 判決

```
解空間 6468
  → 3 條結構約束 (C2+C4+C5) → 1 (真網格)   ← LOOCV 8/8 ✅
  → 但同一機制在 439×96 = 42,144 個三元組中
    有 362 個能唯一選出解, 共 311 個不同網格
  → 真網格 = 1/311
```

**❌ 不被迫。** 「16 約束 = 16 自由度 → 唯一解」是**選擇效應**:
- 形式 (哪兩對共享、哪兩條對偶、哪個行和) 全部從真網格讀出
- 約束目標 (E_proj=28.5, N_φ12=28) 雖是衍生常數, 但「挑哪個行和配哪個常數」仍是自由選擇
- 有效自由度: 共享模式 ~6.6 bits (log₂100) + 對偶集 ~5.4 bits (log₂42) + R ~6.6 bits (log₂96) ≈ **18.6 bits 選擇**
  > ⚠️ **校正 (2026-09-17, docs/07 A3)**: 原文寫「R ~4.6 bits ≈ 16.6 bits」— 4.6 = log₂24 是 §3.3 **受限測試**的 R 候選數, 非 §3.2 的 96。正確 = log₂(100·42·96) = **18.62 bits**。
- 這 18.6 bits 的選擇把 6468 刪到 1 — **與盲測 (script 04) z = −2.62 同病**

## 5. 結論與下一步

**「先驗原理刪解空間」路線失敗** — 能刪到 1, 但刪法是後驗選擇的串聯,
不是原理強迫。要真正閉合, 需要:
1. 一個**從原理導出**「恰好 2 共享對 + 2 對偶 + 某行和 = E_proj」的定理
   (目前無)
2. 或一個**能刪掉 311 個競爭者**的變分/對稱原理
   (RMS 最小只刪到 1/3, 不顯著)

**與 docs/03 (盲測)、docs/04 (順序攻堅)、docs/05 (譜語言) 合併結論**:
現有全部質量結構語言 (φ-group、Lucas/Fib、反週期、CSG 網格、FSR 運動學)
在用戶的盲測 + 預測能力判準下**均未通過**。差別只在失效機制:
- 盲測: 預言集與隨機無異 (z = −2.62)
- 順序攻堅: 公理無法先驗預言 (三步全 ❌)
- 譜語法: 語法退化 (144–311 個同型解)
- 被迫性: 唯一性是泛型的 (311 個網格可被「唯一導出」)
