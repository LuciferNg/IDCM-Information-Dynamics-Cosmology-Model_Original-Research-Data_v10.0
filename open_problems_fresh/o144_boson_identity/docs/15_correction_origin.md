## §3 ★★ Gram / correlation 讀法

兩扇區權重矩陣：

```
G = [[A, μ²], [μ², B_w]] = [[90, 2], [2, 35]]
det G = A·B_w − μ⁴ = 3150 − 4 = 3146
```

**正規化重疊（相關係數）**：

```
ρ  = μ²/√(A·B_w) = 2/√3150 = 0.035634832255
ρ² = 0.00126984126984  =  修正 δ (4/3150)      ✓ 精確
```

**三個等價讀法**（皆精確）：

| 讀法 | 式 | 值 |
|:--|:--|:--|
| 相關係數平方 | `ρ²` | `4/3150` |
| 正規化 Gram 行列式 | `1 − det G/(A·B_w)` | `1 − 3146/3150` |
| Gram–Schmidt 正交化損失 | `1 − ‖ĉ⊥t̂‖²` | `1 − 0.99873015873` |

**幾何陳述**：設 `|ĉ⟩ = |c⟩/√A`、`|t̂⟩ = |t⟩/√B_w`，則 `⟨ĉ|t̂⟩ = ρ`；
鏈方向對樹方向正交化後之範數² = `1 − ρ²`。
⟹ **修正 = 「正交化損失」= 兩扇區正規化重疊之平方**（零新參數）。

**形式判別（數據可判別）**：

```
線性 (1 − ρ²)  → 88·71·(…) 相對偏差 = 0.0
平方根 √(1−ρ²) → 88·71·(…) 相對偏差 = 6.355×10⁻⁴
```

⟹ **線性形勝**（差 ~3 個數量級）⟹ `v ∝ (1 − ρ²)`，**唔係** `√(1−ρ²)`。
（若係 `√(1−ρ²)`，修正會係 `ρ²/2 = 2/3150`；觀測係 `4/3150` ⟹ 判別成立。）
