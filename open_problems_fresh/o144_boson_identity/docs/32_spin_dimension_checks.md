## 2. 結果: 三檢驗全證實 ✅✅✅

### P-A 容器因子（★ 結構性結論）

```
ΔS(ρ−π, (u,d) meson)  = 22.943 M₀
ΔS(Σ*/Λ, (u,d) baryon) =  9.606 M₀
同 pair 差 = 13.337 M₀ = 333σ  (σ ≈ PDG 0.04 M₀)
⟹ ΔS 唔可能只係 pair 函數 —— 容器維度必在 (結構性, 唔係機會)
容器因子 C = 2.388 (單點, 唔係算子)
```

### P-B 冪律排除

| α 來源 | pair | ΔS 比 | m-prod 比 | α |
|--------|------|-------|-----------|-----|
| α₁ | (u,d)→(d,s) | 1.609 | 42.89 | +0.127 |
| α₂ | (d,s)→(c,d) | 2.802 | 16.58 | +0.367 |
| α₃ | (c,d)→(b,d) | 3.117 | 3.05 | **+1.018** |

max|Δα| = 0.892 ≫ 0.05 ⟹ **冪律排除**（與 O136 結構障礙定理 m ∝ γ^α 不可能 呼應——同類禁制喺自旋分裂重現）

### P-C 加法族: 0/6 全排除

γ-sum、E′-sum、m-sum（正/倒序）—— dev 最大 789%, 最小都 4.9%（r2 γ-sum-pos 4.88% 唔達標）——**加族死**
