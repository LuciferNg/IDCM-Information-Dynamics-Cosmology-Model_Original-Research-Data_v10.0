## §1 精確結構：乘積形是否被迫

記 `Σγ_even = Σ_{n=1}^{44} γ_n = 90`、`Σγ_odd = 88`、`μ² = Σγ_even − Σγ_odd = 2`、
`M_tree = 33`。目標修正：

```

f₁ = μ²/Σγ_even = 1/45 = 1/(N_d+1)      (docs/13 §C: (N_d+1) = Σγ_even/μ² 係定義性)
f₂ = μ²/(M_tree+μ²) = 2/35
```

**單一比測試**（核心詞彙 `n = 35` 個整數）：`4/3150` 無法寫成 `p/q`（`p,q` ∈ 核心）。

- ⟹ 最少需 **3 個常數**（`4`, `90`, `35`）⟹ **乘積形係結構上被迫**，唔係可選讀法。

**⚠️ 歸屬聲明**：`λ_WH ≡ λ_self ≡ 1/⟨W⟩²` ⟹ `λ_WH·⟨W⟩² = μ²/2 = 1` **唔係本輪新發現** ——

## §2 ★ 二階結構：線性項缺席

以 `88·71·(形式)` vs 目標 `B*` 之相對偏差：

| 形式 | 值 | 相對偏差 |
|:-----|:--|:---------|

| `1 − f₂` | 5890.9714 | 5.594% |
| `(1−f₁)(1−f₂)` | 5760.0610 | 7.692% |
| `1/((1+f₁)(1+f₂))` | 5781.7861 | 7.344% |

| `exp(−f₁·f₂)` | 6240.0711 | 8.074×10⁻⁷ |

**讀法**：`f₁`、`f₂` 各自係 `O(10⁻²)`，但**單獨出現即偏 2–6%**；只有**乘積** `O(10⁻³)` 命中。

**形式判別**：三者（減法 / 加法 / 指數）之差 ~ `f² = 1.612×10⁻⁶`，而橋之精度 ~ `4.311×10⁻¹⁰`
⟹ **數據可判別**：減法形 `1 − f` 勝 ~3 個數量級（3741×）⟹ 修正係**減法式**。

**原理（階數）**：有效勢極小 ⟹ `∂V/∂v = 0` ⟹ 一階 (tadpole) 項**恆等為零**
⟹ 領頭修正**必為二階**。故 `f₁`、`f₂` 缺席唔係巧合，而係**極小條件之必然**。
