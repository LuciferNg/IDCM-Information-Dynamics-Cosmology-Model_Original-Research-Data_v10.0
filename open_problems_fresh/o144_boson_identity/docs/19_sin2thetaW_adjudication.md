## §4 ⚠️ α_s 之張力（誠實）

`α_s⁻¹ = F₆ + sin²θ_W + 1/B`：

| 用邊個 `sin²θ_W` | `α_s⁻¹` | 對 SM `8.4818` dev |

**⚠️ 誠實張力**：用候選 A 反而**更貼** α_s。

**兩種解讀**（誠實列出）：
- **(i)** α_s 公式係**三重和式擬合**（三個常數湊一個目標）⟹ 本身脆弱，
  用邊個 `sin²θ_W` 都可以「貼」；A 貼得更好係巧合
- **(ii)** 若 A 為真，則 B 錯 —— 但 B 有推導（譜閉式）且勝 `m_W/m_Z` ⟹ 矛盾

**判別權重**：`m_W/m_Z`（獨立觀測，3.40×）+ 推導鏈（B 有，A 冇）**≫** α_s（單一和式）。

**⟹ 附帶發現**：若要用 α_s 作判據，需先為 α_s 公式找**獨立推導**；
現時 `F₆ + sin²θ_W + 1/B` 只係**和式**，其「閉合」需重新審視。

## §5 譜閉式推導鏈（O142 v11，本輪核實）

```
ω_k ≡ sin(kπ/88)  (模式振幅)
ω₄₁ = sin(41π/88) = cos(3π/88)          EXACT   (因 41 = 44 − 3)
ω₃/ω₄₁ = tan(N_gen π/88)                EXACT
m_W/m_Z = cos((N_gen+L₅)π/88) / cos(N_gen π/88) = 0.882737
        = sin(30π/88) / sin(41π/88)     (30 = N_d − 2L₄, 41 = N_d − N_gen)
sin²θ_W = 1 − (m_W/m_Z)²
14 = 2L₄ = N_gen + L₅
```
⟹ **零自由參數**，全部來自 `K_chain` 譜 + 整數身份。

**⚠️ 候選 A 之推導鏈：冇**（`3/13` 係看到 PDG 值後湊出）。
