## §1 兩軸分類法（正式化）

| 軸 | 判準 | 通過 | 不通過 |
|:--|:--|:--|:--|
| **軸一 存在性** | 密度測試 / 虛無測試 | **存在** ✅ | **不存在** 🔴（巧合／密度產物） |
| **軸二 閉合性** | 能否由原理導出形式 | **閉合** 🟢 | **未閉合** 🔴 |

**四個象限**：

```
                        閉合 🟢              未閉合 🔴
   存在 ✅   先驗推導完成（最好）        後驗但通過測試（真，待導出）
   不存在 🔴  （空集）                  密度產物／巧合
```

**關鍵推論**：
- 一個宣稱可以「存在 ✅ + 未閉合 🔴」—— 呢個係**正面**狀態，唔係失敗。
- 只有「不存在 🔴」才係真否定。
- 密度／虛無測試**唔係**用來否定結構，而係用來**守住「存在」軸**（防止把密度產物誤認為結構）。

## §2 ★ 新精確恆等式（本輪新，已閉合為定理）

176-分母 88-site 對偶鏈：`γ_k = 4sin²(kπ/176)`, `k = 1..88`

```
Σγ_even (世界)   = 90        Σγ_odd (觀察者) = 88        Σγ_total = 178 = 2F₁₁

★ 頻譜行列式 (乘積) — 之前從未計算:
    ∏_{k even} γ_k = 176 = 4N_d
    ∏_{k odd}  γ_k = 2   = μ²
    ∏_all          = 352 = 8N_d
    比值           = 88  = 2N_d = Σγ_odd          ← 與 Σγ_odd 同一數!
    44-site 鏈 ∏_{n=1}^{44} γ_n = 176 (同 ∏γ_even)
```

**雙路核對**（`scripts/25` §A1–A7 全 PASS，dps=40）：
1. 直接乘積（mpmath）
2. sin 乘積閉式：`∏_{j=1}^{n−1} sin(jπ/n) = n/2^{n−1}` 及 `∏_{j=1}^{n} sin((2j−1)π/(2n)) = 2^{1−n}`
   → `∏γ_even = 4⁴⁴·88/2⁸⁷ = 176`；`∏γ_odd = 4⁴⁴·2⁻⁸⁷ = 2`

**結構意義**：`∏γ_odd = μ²`（觀察者子空間之頻譜行列式 = 凝聚驅動）、
`∏γ_even = 4N_d`（世界子空間 = 4 × 鏈長）。
「行列式 = 維度」型：`∏γ_even/∏γ_odd = 2N_d` 與 `Σγ_odd = 2N_d` 係兩個獨立物件卻同值。

```
修正 = 4/(90·35) = μ²/((N_d+1)(M_tree+μ²))
```

## §5 判決與閉合程序

### 5.1 O144 之正確定位

> **唔係「全部失敗」，而係：質量公式族不存在；標度橋存在但未閉合；頻譜恆等式已閉合。**

### 5.2 缺口重新表述（well-posed 逆問題）

```
舊表述: 「標度橋係唔係真?」           → 已答: 真 (存在 ✅)
新表述: 「如何由原理導出橋之形式?」    → 逆問題 (未解)
```

**閉合程序（下一步）**：

1. **P6 線索深化**：導出「修正 = 凝聚分數 ÷ (N_d+1)」中 `(N_d+1)` 之來源。
   候選：有限鏈正規化、Z₂ 對偶配對之約束計數、凝聚態之佔據數修正。
2. **原理先行**：由 ① 鏈凝聚之正規化條件 ② 44-site 對偶約束 ③ 世界/觀察者子空間投影
   分別導出形式，再比對 —— **唔可以**由數值反推原理（否則只係再一次枚舉）。
3. **P1 之近整數**（`p = 1.951773` vs 2）值得記錄：若某原理給出 `88^{μ²}·修正`，
   則 `p → 2 = μ²` 有原理基礎；現時 `88²` 偏離 24%，故未成立。
4. **存在軸之守門**：任何新橋宣稱必須先過密度／虛無測試（本輪已建立標準流程）。

### 5.3 方法論產出

- **兩軸分類法**：任何 O-series 宣稱之標準標籤（存在性 × 閉合性）。
- **局部虛無**：當目標值落在頻譜之非典型密度區，必須加局部虛無（本輪：全域 0.1779% vs 局部 0.0437%）。
- **「頻譜最優」≠「顯著」**：排名 0 之對仍可能只達 68.4 百分位。
