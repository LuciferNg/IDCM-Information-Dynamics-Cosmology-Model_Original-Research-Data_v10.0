## 一、P1：d 落 odd 流 = 輕子全奇＋質量次序補填（唔係獨立異常）

質量升序 rank 1..8 = e,u,d,s,μ,c,τ,b（觀測次序，無 assignment 輸入）：

```
輕子 rank = {1, 5, 7} —— 全奇數（P = C(4,3)/C(8,3) = 1/14 = 0.0714）
odd ranks {1,3,5,7} 用咗 3 個（輕子），剩返 rank3
rank3 粒子 = d（質量第三，觀測 e<u<d）
⟹ d 落 odd 流 = 質量次序嘅必然補填，唔係 docs/14 假設嘅「分層極限犧牲者」
```

**關鍵**：O233 冇 assignment 輸入去製造呢個——質量次序本身令輕子 rank 全奇（1,5,7），odd 流第 4 位自然由 d 攞。「d 係唯一落 odd 流嘅夸克」唔需要額外機制。

## 二、P2：★ m_d > m_u 嘅結構起源（C_f 層反轉 vs γ 層主導）

d 落 rank3（唔係 rank2）係因為 m_d > m_u。喺 A_γ 框架：

| 量 | 值 |
|:--|:--|
| C_f_u | 3.8029 |
| C_f_d | 3.6620 |
| **C_f 層** | **u > d（1.0385×）** |
| γ₃/γ₂ | 2.2452 |
| **m 層（γ×C_f）** | **d > u（2.1620×）** |

```
m_d/m_u = (γ₃·C_d)/(γ₂·C_u) = 2.1620  vs  觀測 = 2.1620  ✅ EXACT
```

**⟹ 結構**：C_f 層反轉（u>d）被 γ 階梯（γ₃/γ₂ = 2.245）壓過——**m 次序最終由 γ_n（鏈譜本徵值）主導，唔由 C_f**。d 落 odd 流係 γ 階梯主導嘅必然結果。

## 三、P3：t 槽機制（s1 四元素點解輕子用 3、t 用 1）

```
s1（≡1 mod 4）∩ A₅ = {1, 5, 9, 13} —— 4 元素
  輕子 {e, μ, τ} → modes {1, 5, 9}  B−L = −1 ∈ ℤ   T3 強制 ✅（3/3）
  t          → mode 13            B−L = +1/3 ∉ ℤ  T3 唔強制
⟹ t 係 s1 第 4 元素但 T3 唔鎖佢——VEV 機制（docs/01 §C: y_t ≈ 1, M₀γ₁₃Φ_max ≈ 1431 MeV ≪ m_t）可以移除佢
```

- 解釋咗「點解輕子啱好用 3 個 ≡1 槽而唔係 4 個」：B−L 整數性只強制輕子（−1），t（+1/3）唔喺 T3 荷定義域。
- 同 docs/13 L2 完全一致：d/b 命中只係湊中（B−L=±1/3 嘅 Q∈ℤ 冇 T3 定義域支持）。
