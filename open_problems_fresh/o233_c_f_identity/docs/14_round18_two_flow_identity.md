## 四、★ 統一結論：鋸齒 Z₂ × 輕子槽 ℤ₄ = 同一結構兩投影

```
鏈側（88-chain）:   mode n mod 4  ℤ₄ 扇區（O210 docs/10, 群層 iso 🔗）
                        │ Φ: Ŝ↦z（唯一同構）
算子側（SU(B)=SU(4)）:  χ = |λ| mod B  (O210-T3)
                        │ B−L 整數性（docs/13）
物理側:              輕子 B−L=−1 ∈ ℤ ⟹ χ≡1 ⟹ 落 ≡1 槽（{1,5,9}）
                      夸克 B−L=±1/3 ∉ ℤ ⟹ 無槽 ⟹ 避開 ≡1（5/5, 1/56）
                        │ 質量升序 rank（A_γ assignment, O137 授權）

```

- **docs/06 §四 一源假說**（鋸齒 Z₂ 同位置算子 X 嘅 Z₂-奇同源）首次獲定量支持——但係「源」唔係 X 算子本身，而係 **B−L 整數性（T3）× 群層 iso（O210 docs/10）× 質量升序 assignment**。
- 鋸齒 7/7 交替（p=0.0138）＋ 夸克全避 ≡1（p=1/56）＋ 輕子全 ≡1（p=1/56）**三個統計係同一結構嘅三個投影**，並唔係三個獨立發現——docs/08 已證鋸齒/階梯獨立（1.01×），但本輪顯示鋸齒/輕子槽**唔獨立**（同一 partition）。
