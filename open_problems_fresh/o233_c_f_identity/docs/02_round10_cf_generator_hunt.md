## 三、裁決

1. **無富集**：C_f 8 值命中池嘅次數**低於**隨機目標（84 < 127 / 10 < 12）⟹ 池嘅高密度
   （55049 值）令單一「漂亮命中」（如 u = 521/137 到 4.4e-6）**零統計意義**。
2. **單點命中唔構成證據**：u = L₁₃/137、τ = (F₂₀−60)/42、b = (h¹¹+F₁₆)/B 等最接近形式
   係 pool 密度之自然產物（任何隨機目標平均都搵到 >10 個 1e-3 命中）。
3. **最簡有理對照**（報告用, 非證據）: e 18/5 (0.164%, 已 pre-registered 錨) / u 19/5 (0.077%)
   / d 11/3 (0.126%) / s 124/3 (0.030%) / μ 30 (0.103%) / c 186 (0.033%) / τ 319/2 (0.090%)
   / b 256=B⁴ (0.097%) — 即使全 8 個都有「近似有理」，**池 null 顯示呢個近似程度喺 55049 值
   池內係期望發生** ⟹ 唔可以當生成器證據。
4. **Φ 目錄決斷**（docs/01_ §D 重申）：8 值 0/8 精確成員。
