### L2 算子側機制（O210-T3，`o210/docs/08`，✅ 已閉合）

**★ 機制**：
- **B−L ∈ ℤ（輕子 −1）⟹ Q ≡ 1 (mod 4) ⟹ χ ≡ 1 —— 強制落 ≡1 槽**

⟹ **「輕子有槽而夸克冇」唔係統計巧合，係 B−L 整數性嘅直接後果**（docs/12 Critical Context 嘅「統計→結構必然」而家由定理坐實）。

### L3 群層橋（O210 docs/10，🟡⁺ 已建立——docs/12 寫「映射未證」需更正，見 §五）

**O210 docs/10 §5(1)** 已證明：
- 鏈側 ℤ₄（站-模 DFT 對偶，生成元 Ŝ = S²²，`Ŝ|k⟩ = i^k|k⟩`，階 4）
- 算子側 ℤ₄（SU(4) 中心荷，生成元 z，`χ = k mod 4`）
- **同構 Φ: Ŝ ↦ z 存在且唯一**（帶區別生成元之有限循環群同構唯一，非任意選擇）

⟹ 鏈扇區 `k mod 4` ↔ 算子 `χ = |λ| mod 4` 係**同一 ℤ₄ 嘅兩面**。**T3 嘅 χ≡1 ⟹ 鏈側 s1（≡1 mod 4）**——即「輕子槽」嘅算子側身份（χ = 1）與鏈側身份（s1）對齊。

**鏈側 s1 閉式**（O210 docs/10 §2，精確初等證明）：`s1 = N_d − sec(π/88) = 44 − 1.000637581 = 42.999362419`，`s3 = 45.000637581`，`s1+s3 = 88 = 2N_d`。
