## 二、構成（以什麼構成）：三元商，無獨立元素

C_f = m_f / (M₀ · γ_n)，由三元素構成（`scripts/22` [1]）:

| 元素 | 角色 | 來源 | 量綱 |
|:--|:--|:--|:--|
| m_f | 觀察質量 | PDG/SM 輸入 | 有量綱（MeV）|
| M₀ | 世界質量量子 | O120（27.900915 MeV）| 有量綱（MeV）|
| γ_n = 4sin²(nπ/88) | 鏈譜本徵值 | K_chain（O120/O137）| 無量綱 |

**本體論陳述 1**：C_f **冇獨立構成元素**——佢係兩個有量綱量（m, M₀）與一個無量綱譜（γ）之間嘅**商關係**。喺本體論上 C_f 係「關係」而唔係「實體」：Reality = Relations + Distinctions（O206 本體論），位置 = Object − Reference Frame 關係——C_f 就係「質量（Object）相對鏈譜（Reference Frame）」嘅座標。

**本體論陳述 2**（呼應調律者裁決 docs/16 §八）：C_f 無量綱、冇資格做錨——因為錨必須係**有量綱單位源**（O212：G≡ω_ring≡M_Pl）；C_f 係**派生座標**，唔係**輸入單位**。

## 三、住處（住喺邊）：質量 ⊗ 鏈譜 商空間

**本體論陳述 3**：C_f 住喺 **M/Γ 商空間**——M = 質量譜 {m_f}，Γ = {M₀γ_n} 鏈格質量標度。每粒費米子 = 商空間一點，C_f 係該點嘅座標：**質量譜投影到鏈譜基嘅身份座標**。

## 四、原理（係乜 + 點解）：質量 = 結構 × 身份 雙因子分解

**本體論陳述 4（質量機制論述）**：IDCM 質量層 = 雙因子分解

```
m_f = M₀ · Γ(n) · Id(f)
        │      │       └── Id(f) = C_f: 粒子身份因子（商空間座標, 無量綱）
        │      └── Γ(n) = γ_n: 鏈譜結構因子（無量綱頻率, K_chain）
        └── M₀: 世界質量量子（有量綱刻度, 唯一錨）
```

- **結構因子 γ_n**：m 次序由 γ 主導——γ 升序 = m 升序 **EXACT 零反轉**（`scripts/22` [3]）；m_d/m_u = (γ₃C_d)/(γ₂C_u) = 2.1620 觀測 EXACT（docs/15）。γ 層**已閉合**。
- **身份因子 C_f**：測量「此費米子相對鏈格質量（M₀γ_n）偏離幾多」——塊參數結構 G1≈3.66（e,u,d）／G2≈30–41（s,μ）／G3≈160–256（c,τ,b）（docs/16）；內部再有 Z₂ 結構（鋸齒 = 輕子/夸克分離, docs/14）同槽限制（≡1 mod 4 = T3×O210 iso, docs/13+17）。
- **原理**：C_f 嘅原理 = **身份係關係產物**——C_f 唔係「啲咩嘢」，而係「質量譜喺鏈譜參考系嘅身份投影」。鋸齒/槽/塊全部係**呢個座標空間內部**嘅結構，唔需要 C_f 本身係「常數組合」。

## 六、結論（三問答案）
