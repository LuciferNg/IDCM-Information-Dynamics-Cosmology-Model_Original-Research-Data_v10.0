## 一、結論（先寫死）

🟢 **R-D 已回答——ε-CHL 半徑一般律（經 v1 否證修正後）**：

**律（v2，預註冊後確認）**：
```
r_ε(t) = 2t + C_eff(ε,t) · (ln 1/ε)^{2/3} · t^{1/3}（tail 區域，ε ≤ 1e-4）
C_eff = C₀ · [1 − (1/2)(ln t)/(ln 1/ε)]^{2/3},   C₀ = 2(3/(4√2))^{2/3} = 1.3106…
```
- Debye 尾 |J_d(2t)| ~ (2πd·tanh α)^{−1/2}·e^{d(tanh α−α)}，α = arccosh(d/2t)，tanh α−α = −(2/3)√2·δ^{3/2}（δ = d/2t−1）⟹ 主項 (4/3)√2·t·δ^{3/2} = ln(1/ε) − (1/2)ln t − (1/4)ln δ − (1/2)ln(4π√2) + …
- **收斂**：r_ε(t)/t → 2（速率 t^{−2/3}·(ln 1/ε)^{2/3}）——ε-光錐喺比值意義下收斂向 v_max = 2（R1 已量 2.27→2 而家講明機制）；
