## 2. 可辨識性 (identifiability, scripts/10 §1–2)

### 2.1 加權 MLE 重擬合

docs/01 引用嘅 γ = 0.258122 係 O54 嘅**無權重** fit。用 σ_f = 0.005 做權重重擬合:

| 量 | 加權 MLE | 聲稱結構值 | 相差 |
|:--|:--------:|:---------:|:----:|
| γ | 0.244703 ± 0.010712 (4.38%) | 8/31 = 0.258065 | **1.25 σ** |
| C | 0.042783 ± 0.002385 | 1/25 = 0.040000 | 1.17 σ |

⟹ 觀測對指數嘅約束只有 **±4.4%**; 8/31 落喺 MLE 1.25σ 內 = **唔可辨識**
(即係話一大堆值都同樣相容, 8/31 冇被數據「選中」)。

### 2.2 Δχ² 檢定 —「0 參數好過 2 參數」聲稱

| 模型 | χ² | dof |
|:----|:--:|:---:|
| 0 參數結構 (1/25, 8/31) | 10.9377 | 10 |
| 2 參數自由 | 9.2950 | 8 |

Δχ² = 1.64 (2 額外參數) → p = 0.44 ⟹ **2 參數 fit 冇顯著改善**。

⚠️ 呢個**唔係**「結構贏」—— 係「**數據根本唔約束指數**」(自由 fit 都只改善 1.64)。
配合 §1 嘅密度基準, 「0 參數 chi² 同 2 參數相當」係**空洞陳述**, 冇資訊量。

## 3. 根本因: 譜指數透明性定理 (scripts/11)

### 3.1 設定 (O54/O37)

```
CR 質子譜:        dN_p/dE_p = A·E_p^(−p)
W-field 模式 n:   權重 w_n ∝ γ_n = ω_n²,  靜止系 e⁺ 能量 u_n = E_n/2
Lorentz boost:    E_e = (E_p/m_p)·u_n
注入譜:           dN_e/dE_e = Σ_n w_n·|dE_p/dE_e|·(dN_p/dE_p)
```

### 3.2 定理

```
E_p = m_p·E_e/u_n  ⟹  dE_p/dE_e = m_p/u_n
dN_e/dE_e = Σ_n w_n·(m_p/u_n)·A·(m_p·E_e/u_n)^(−p)
          = A·m_p^(1−p)·E_e^(−p) · Σ_n w_n·u_n^(p−1)
                                └──── 同 E_e 無關 ────┘
⟹  dN_e/dE_e ∝ E_e^(−p)   EXACT
```

**數值驗證**: 4 種模式譜 (γ_n / ω_n / uniform / 任意) × 5 個 p 值, 反演對數斜率
= −p, 最大偏差 **2.2e−15** (機器精度)。**sympy 解析**: d log(contrib)/d log(E_e) = −p。

### 3.3 推論 — 層次錯配 (category error)

```
正電子分數:  f = N_W/(N_W + N_sec)
高能區:      f ≈ N_W/N_sec ∝ E^(p_sec − p_prim)
             p_prim ≡ p_CR   (W-field 通道透明, 本定理)
             p_sec  = 次級 (pp→π→e⁺) 譜指數 (CR 傳播/冷卻)
⟹ γ_obs = p_sec − p_CR 係「兩條 CR 譜指數之差」= CR 傳播物理
⟹ IDCM MeV 級模式譜 (ω_n, γ_n) 對 γ_obs 零作用
⟹ 將 γ_obs 認做結構數 8/31 = 層次錯配
```

**★ 呢個係本輪最重要嘅結果**: 唔止「8/31 唔可辨識」, 而係**佢喺原理上唔可能係
IDCM 結構數** —— W-field 轉換通道對譜指數透明, 佢只會**繼承** CR 質子譜指數,
唔會產生自己嘅指數。docs/01 §3「譜指數 2」亦係同類誤讀: 產生率 ∝ ω_n² 係
**MeV 級模式譜嘅內部指數**, 同 GeV 級觀測譜指數係兩個唔同層嘅量。

## 4. 本輪仍成立嘅結構內容

### 4.1 運動學窗口強化 (scripts/12) — ✅ 保留 (誠實標強度)

docs/01 §2 只證 m_δW = M₀/2 落喺 (2m_e, 2m_μ)。本輪強化到**整條模式塔**:

| 模式 | m_n (MeV) | > 2m_e | < 2m_μ | < 2m_p | < 2m_He4 |
|:----:|:---------:|:------:|:------:|:------:|:--------:|
| n=1 | 1.992 | ✅ | ✅ | ✅ | ✅ |
| n=7 (DM) | 13.800 | ✅ | ✅ | ✅ | ✅ |
| n=22 | 39.458 | ✅ | ✅ | ✅ | ✅ |
| n=44 | 55.802 | ✅ | ✅ | ✅ | ✅ |

**44/44 模式全部落喺 (2m_e, 2m_μ) = (1.022, 211.3) MeV** ⟹ 每個 W-field 模式都
e⁺e⁻ 專屬。三重 AMS-02 觀測 (正電子異常上升 / 反質子純次級 / 反氦 < 10⁻⁹) 一致。

**⚠️ 誠實標明預言強度**: 窗口條件對 M₀ 係**兩端封閉嘅中度約束**
(M₀ ∈ (14.317, 105.7) MeV, 跨 **7.4×**, 實際 M₀ = 27.9 落喺 33% 對數位置)。
唔算強 (唔係精確命中), 但唔係空洞 —— 太輕會令塔底低過 2m_e, 太重會開 μ⁺μ⁻ 通道。

### 4.2 產生率譜指數 2

γ_n = ω_n² 係精確恆等 (44 模式 dev = 0) ⟹ Γ_n ∝ ω_n² 嘅**內部**譜指數 = 2。
呢個係 MeV 級模式譜嘅性質, 正確, 但**唔可以**接到 GeV 級觀測譜形 (見 §3.3)。

### 4.3 衰變寬度 Γ(W→e⁺e⁻)

Γ = 9.26×10⁻⁵ MeV, τ = 7.1×10⁻¹⁸ s —— O37 Lagrangian 層嘅推導, 唔受本輪影響。

## 6. 要真正閉合需要咩 (開放方向)

1. **p_CR 結構化**: IDCM 要預言 CR 質子譜指數 (2.7)。現時係觀測輸入,
   池掃描 q_obs = 1.000 冇唯一解。屬**框架問題** (CR 加速/傳播唔在 IDCM 結構內)。
2. **p_sec 結構化**: 次級正電子譜指數 (傳播/冷卻)。同樣係 CR 物理。
3. **非透明通道**: 若某通道嘅注入譜**唔**繼承 CR 指數 (例如共振峰、閾值效應),
   先有可能產生結構性指數。W-field 二體衰變**唔屬**此類 (§3 定理)。
4. **40 MeV 拐點**: 需要 Voyager 1 / AMS-02 低能數據 (外部)。

⟹ 按分流裁決: 呢四項全部**唔屬**本 O 可用現有算子解決嘅範圍, 屬 CR 傳播物理
(框架外) 或待外部數據。本 O 可攻部分已推到底。
