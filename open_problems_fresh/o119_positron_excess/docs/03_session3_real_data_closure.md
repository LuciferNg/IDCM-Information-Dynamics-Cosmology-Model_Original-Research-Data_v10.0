## 1. 真實 AMS-02 全譜重擬合 (scripts/13) — 🔴 災難級

**問題**: docs/01 §4 嘅「χ²/dof = 1.094 (0 參數) 好過 O54 2 參數 1.376」係對
**10 個手打點 + 固定 σ = 0.005** 算出。本輪用真實 74 點 (誤差 = stat ⊕ syst) 重算。

| 模型 | 自由參數 | χ²/dof (真實 74 點) |
|:----|:-------:|:------------------:|
| O54 2-param (C, γ) | 2 | **6783** |
| O119 結構 0-param (1/25, 8/31) | 0 | **6781** |
| 純次級 (無 W-field) | 0 | 2589 |
| 自由 2-param (只喺上升區 10-300 GeV) | 2 | 2.29 |

**★ 真實數據形狀** (唔係單調冪律):
```
谷底 ~9 GeV (電荷相關太陽調制)
  → 峰 ~428 GeV (正電子超出, 起點 25.2±1.8 GeV)
  → 截斷 >284 GeV (源項指數截斷, E_s = 810+310/−180 GeV)
```
O54/O119 嘅單調冪律模型**冇峰冇截斷** ⟹ 對全譜 χ²/dof ~ 10³–10⁴。

**★ 更根本**: AMS-02 超出需要源項標度 **E_s ≈ 810 GeV**; IDCM W-field 標度 = 13.95 MeV,
差 **5.8×10⁴ 倍** ⟹ IDCM W-field **唔可能**係 AMS-02 超出嘅源 (量級層次錯配, 同 docs/02 §3 一致)。

**自由擬合 (上升區 10-300 GeV)**: C = 0.0055, γ = 0.6281 ± 0.0054, χ²/dof = 2.29。
docs/01 聲稱嘅 γ = 8/31 = 0.2581 同真實自由 fit 差 **69.0σ**。

⟹ 裁決: docs/01 §4「χ²/dof = 1.094」係**手打數據**產生嘅假象; 真實數據下模型完全失敗。

## 2. CR 譜指數 p_CR 結構化 (scripts/14) — 🔴 框架外

**真實 AMS-02 質子譜指數** (d ln Φ / d ln R):

| R 範圍 (GV) | 點數 | 指數 |
|:----------:|:---:|:----:|
| 1–1800 (全, 含太陽調制) | 72 | 2.494 ± 0.001 |
| **>10 (太陽調制以上, 物理值)** | 50 | **2.775 ± 0.002** |
| 30–1800 | 36 | 2.793 ± 0.003 |
| 100–1800 | 20 | 2.757 ± 0.007 |

**DSA 結構路線**: 擴散激波加速注入指數 p_inj = (r+2)/(r−1);
強激波 r = B = 4 ⟹ p_inj = 2 = μ² (IDCM 結構數)。
⚠️ 但 r = 4 係**任何強激波**嘅普適值 (γ = 5/3 Rankine-Hugoniot), 唔係 IDCM 獨有 → 🟡 弱結構。

**剩餘 δ = p_obs − p_inj = 2.775 − 2 = 0.775** (傳播修正) 密度基準:
- 池內最近 (F₈+L₄)/h11 = 0.7778 (dev 0.303%), **q_obs = 0.991** 🔴

⟹ p_CR = 2.7 **唔可以**從 IDCM 結構推導: = (普適 DSA 注入 2) + (傳播 δ)。
兩者皆屬 CR 加速/傳播物理 (框架外), 同 docs/02 §3 指數透明性定理一致。

## 4. 次級背景零參數化 (scripts/16) — 🔴 框架外

**問題**: docs/01 §6.2 自認 f_sec = 0.055·E^(−0.33) + 0.005 係 3 個 fit 參數。

**密度基準** (O208, 容忍度 = 0.1% = docs/01 用嘅匹配標準):

| 參數 | 值 | 池內 ≤0.1% 命中數 | d_med | q_obs | 判定 |
|:----|:--:|:---------------:|:-----:|:-----:|:----:|
| A | 0.055 | 27 | 0.0161% | 0.985 | 🔴 |
| δ | 0.33 | 19 | 0.0126% | 0.997 | 🔴 |
| c | 0.005 | 2 | 0.0415% | 0.768 | 🔴 |

⚠️ δ = 0.33 有池內**精確**命中 M/(μ²+h₂₁) = 33/100 (dev 0.0000%) —— 但呢個係
後驗構造 (100 = 2+98 特登砌出), 池內有 19 個式 ≤ 0.1% 命中, 恰恰證明**冇唯一性**。

**物理歸屬**: 次級正電子源項 q_sec ∝ n_H · σ_pp(E) · φ_p(E):
- n_H = 星際氫密度 (天體物理)
- σ_pp = 質子-質子非彈性截面 (QCD, ~30 mb) — IDCM 結構池冇 barn 級標度
- φ_p = CR 質子譜 (p_CR = 2.775, 框架外)

⟹ f_sec 嘅歸一 (A) 同斜率 (δ) 完全由散裂/傳播設定, 唔含 IDCM 結構。
