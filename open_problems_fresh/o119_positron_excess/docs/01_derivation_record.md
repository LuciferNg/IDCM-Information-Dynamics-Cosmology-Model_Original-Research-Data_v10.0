## 0. 問題定位

**AMS-02 觀測**: 正電子分數 e⁺/(e⁺+e⁻) 從 10 GeV 的 ~10% 上升到 300 GeV 的 ~20%, 與純次級模型 (宇宙線碰撞產生的正電子應隨能量下降) 相反。

**O54 已閉合**: 反物質 = 和頻通道 (差頻=物質, 和頻=反物質, docs/03)，但正電子 CR 通道用 2 參數冪律 fit (f_W = 0.04·E^0.258) 而非結構推導。

**O119 任務**: 從 O37 Lagrangian 推導 W → e⁺e⁻ 衰變寬度 Γ 和正電子能譜的零參數結構。

| script 36 | 模式疊加 ΣΓ_n·(E/E_n)^(-p) | χ²/dof = **1397** (O54 自報, f_W = ΣΓ_n·(E/E_n)^(-p)/ΣΓ × 0.5) | 有結構但完全失敗! |
| script 36 | 同上 (O119 獨立重算, 同模型) | χ²/dof ≈ **825** | 模型不同歸一 → 數值不同, 兩者皆災難級 |

**根源**: 正電子能量由 CR 譜決定, 非 W-field 模式譜。模式疊加用 E_n = M₀·ω_n (MeV 級) 無法匹配 GeV 級數據。docs/04「主峰 60-100 GeV」係 CR boost 後嘅 fit 產物, 非模式結構。

## 3. 閉合 2: 產生率譜形 (硬閉合 ✅)

K_Chain 結構:
- ω_n = 2sin(nπ/88) (頻率, 能量標度)
- γ_n = 4sin²(nπ/88) (能量本徵值)
- **γ_n = ω_n²** (精確恆等, 44 模式 dev=0)

W-field 產生率:
- Γ_n = M₀·γ_n = M₀·ω_n² (O54/O36)
- E_n = M₀·ω_n (模式能量)
- log Γ_n = log M₀ + 2·log E_n

**譜指數 = 2**: 產生率 ∝ 能量² → 高頻 (高能) 模式產生率高 → 正電子分數隨能量上升。

### 4.3 簡併性檢查 (誠實標記)

γ = 0.2581 有 **31 個** < 0.5% 的結構數組合 (script 04 全面搜尋), 包括:

- 48/178+... 等多個 0.118% 組合

**⚠️ 誠實標記**: 8/31 **唔係**數值上最精確嘅候選 ((F₈+γ₂₀)/88 dev 0.003% 更準)。8/31 被選中嘅理由係**結構乾淨度** (非純數值精度):
- 8 = F₆ (O67 8/5 分支因子)

⟹ 8/31 屬「結構識別」而非「數值最優」— 動力學推導仍 🔴 開放 (見 §8)。

**方法學註記**: script 02 最初搜尋 (a/b, a/(b+c), (a−b)/c) 格式, miss 8/31 (屬 a/(b−c) 格式); script 04 擴充到 (a±b)/c 先搵到。JSON 已更新註記。

## 5. 閉合 4: 衰變寬度 Γ(W→e⁺e⁻) (推導 ✅)

從 O37 Lagrangian:
- L_int = Σ κ·ω_n·W·φ_n², κ² = M₀
- m_δW = M₀/2 = 13.9505 MeV
- 電子質量: m_e = M₀·γ₁·(L₆/F₅) = 0.5118 MeV (0.16%)
- 有效 VEV: v_eff = M₀√2 = 39.46 MeV
- Yukawa: y_e = m_e/v_eff = 0.01297

**衰變寬度** (scalar → fermion pair):
```
Γ(W→e⁺e⁻) = y_e²·m_δW/(8π)·β³
β = √(1−4m_e²/m_δW²) = 0.9973
Γ = 9.26×10⁻⁵ MeV
τ = ħ/Γ = 7.1×10⁻¹⁸ s
```

**正電子能量 (靜止系)**: E_e⁺ = m_δW/2 = 6.98 MeV
→ 靜止衰變只能解釋 sub-GeV 正電子, 無法解釋 10-300 GeV AMS-02 數據!

**⚠️ 質量選用澄清**: docs 用 m_δW = 13.95 MeV (O37 W-field 漲落質量) 做衰變源。若用整鏈最重模式 m_44 = 55.8 MeV, 靜止衰變正電子能量最多 m_44/2 = 27.9 MeV (script 01 JSON max_static_decay 值) — 仍遠低於 AMS-02 GeV 級。兩者皆不改變「靜止衰變到唔到 GeV」嘅結論。
