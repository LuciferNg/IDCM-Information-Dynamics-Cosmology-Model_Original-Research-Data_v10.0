## 最終定理 (已證, 誤差 <1.3e-5°)

設 S = {v_i, i=0..59} = A₅·v₀ 正則軌道 (60 元素, 穩定子平凡), 圖邊 = 角距離 < 28°。

**存在唯一 r₀ ∈ A₅ 令對徑映射 π 滿足**:

```
g_{π(i)} = g_i · r₀           ∀ i ∈ [0,60)      (右乘 — 60/60 驗證)
v_{π(i)} = r_i · v_i          r_i = g_i·r₀·g_i⁻¹  (共軛 180° 旋轉 — 60/60)
a_i = g_i·a_{r₀}              (軸共軛)
ε := angle(v_{π(i)}, −v_i) = 2·arcsin(|v₀·a_{r₀}|) = 5.3401° 常數
```

**r₀ 性質**:
- 180° 旋轉 (2-fold), 軸 a_{r₀} = (RA 328.2825°, Dec **+18.0000°**)
- **Dec = arcsin(1/(2φ)) = sin(18°)** — φ 結構直接嵌入!
- a_{r₀} = (cos18°·cos(328.28°), cos18°·sin(328.28°), sin18°) = (φ/2·cos..., −1/2·cos..., 1/(2φ))

**ε 閉式**:
```
ε = 2·arcsin(|v₀·a_{r₀}|) = 5.340126° (理論)
實測: 5.340114° (std 0.000056°) — 差異 1.2e-5° 🟢
|v₀·a_{r₀}| = 0.0465845 = sin(2.6701°)
```

## 5.34° 本質分析

**5.34° 冇獨立閉式** — 佢係:
1. 冷斑方向 v₀ 到 A₅ 2-fold 軸網格嘅最近距離 × 2
2. 由冷斑位置 (209°, −57°) 同 r₀ 軸 (328.28°, +18°) 決定
3. Monte Carlo: random 方向嘅 ε 中位數 ~4.5°, 冷斑 5.34° = 58 百分位 — **完全普通**

**結構性嘅係「常數性」, 唔係「5.34° 本身」**:
- 對全部 60 節點, ε 完全相同 (std 0.00006°)
- 呢個常數性 = 對徑映射係右乘固定元素嘅直接後果
- 如果 60 節點只係 random 點集, ε 會隨節點大幅變化

## φ 嵌入 (新發現)

r₀ 軸 Dec = +18.0000°:
- sin(18°) = 1/(2φ) = (√5−1)/4 = 0.309017
- 18° = π/10 — 正二十面體嘅 5-fold 對稱角
- 呢個唔係巧合: A₅ 嘅 2-fold 軸網格本身由 φ 決定 (正十二面體/二十面體頂點座標含 φ)

**但注意**: 18° 係 r₀ 軸嘅性質, 唔係 ε 嘅性質。ε = 5.34° 係 v₀ 同 a_{r₀} 嘅夾角函數, 唔係 φ 直接數。
