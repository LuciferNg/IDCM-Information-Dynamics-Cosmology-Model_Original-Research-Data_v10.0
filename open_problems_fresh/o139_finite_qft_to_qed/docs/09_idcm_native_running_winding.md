## 三、參數定律：為何係 9 而唔係其他數

IDCM 兩個端點（O142/O160）：

```
α⁻¹(0)   = C(B²,2) + F_proj
α⁻¹(M_Z) = C(B²,2) + 2B
```

加上結構關係 **`F_proj = B² + 1`**：

```
Δα⁻¹ = F_proj − 2B = B² − 2B + 1 = (B−1)²
```

而 `N_gen = B − 1` ⇒ **`Δα⁻¹ = N_gen²`**。

⇒ **「為何係 9？」因為 B = 4 定死 N_gen = 3，而 running 係 N_gen²。**
換 branching 就變 4（B=3）、16（B=5）、25（B=6）—— **呢個就係「不同條件下會怎樣變化」，而且係結構性嘅**（來自 `F_proj = B²+1` 加兩端點構造，唔係擬合）。
