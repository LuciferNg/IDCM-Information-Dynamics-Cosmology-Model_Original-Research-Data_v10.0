## 四、LAYER 1 — 階梯已推導，而且係 RGE 嘅正確變數 🟢

```
a_ℓ       = a / 4^ℓ
p_min     = ħc·π / R_world
Λ_ℓ       = 44 · p_min · 4^ℓ
```

| 檢查 | 結果 |
|:---|:---|
| `p_min = ħc·π/R_world` vs 項目常數 4.864543e−33 eV | rel.dev **2.00e−08** |
| `Λ_ℓ = 44·p_min·4^ℓ` vs 項目常數 2.140399e−31 eV | rel.dev **1.74e−08** |
| `ln Λ_ℓ − (ln Λ_0 + ℓ·ln4)`，ℓ = 0…79 | **1.421e−14** |

**⇒ `ln Λ_ℓ` 對 ℓ 嚴格線性。** 而一圈跑動
`α⁻¹(Q) = α⁻¹(0) − (2/3π)·Σ_f N_cQ_f²·ln(Q/m_f)` 對 `ln Q` 線性
⇒ **α⁻¹ 對 ℓ 嚴格線性。階梯就係 RGE 嘅自然變數。**

**用戶嘅前提係正確嘅 —— LAYER 1 冇缺口。**

## 五、LAYER 2 — 兩個端點各自好靚 🟢

| 量 | 結構 | 量度 | 偏差（結構 − 量度） |
|:---|:---:|:---:|:---:|
| α⁻¹(0) | 137 | 137.035999178 | **−0.035999178**（−0.026%） |
| α⁻¹(M_Z) | 128 | 127.930 | **+0.070000000**（+0.055%） |
| **跑動** | **9** | **9.105999** | **−0.105999178**（−1.164%） |

### ★ 關鍵：兩個端點誤差**反號**

- 結構 137 **偏低**（−0.035999178）
- 結構 128 **偏高**（+0.070000000）
- ⇒ 佢哋**唔抵消，而係相加**：`0.035999178 + 0.070000000 = 0.105999178`

**⇒「兩個端點各自中到 0.03–0.06%」同「佢哋嘅差差 1.18%」完全相容 —— 唔係矛盾，係算術必然。** 呢個就係點解缺口（1.18%）比任何單一端點誤差大 20–40 倍。

驗證：`d₀ − d_M = −0.035999178 − (+0.070000000) = −0.105999178` ≡ 跑動缺口（精確到 1e−9）。

## 六、LAYER 3 — 整個缺口就係一條斜率 🔴

因為 α⁻¹ 對 ℓ 線性（§4），問題塌縮成**一個數**：

```
結構斜率  9/ℓ(M_Z)     = 0.130161  /level
物理斜率  9.106/ℓ(M_Z) = 0.131694  /level
比率                   = 1.01178   (+1.178%)
```

**斜率 = 真空極化係數 = 物質內容，唔係幾何。**
階梯定**軸**（邊個能量），物質內容定**速率**。所以推導咗嘅階梯**結構上唔可能**補呢個缺口。

## 七、★ 修正：δ **唔係** 13.2σ 異常

`docs/07` R2 寫「δ = +0.1060 ± 0.008 → 13.2σ 偏離整數 9」。呢個數字**用實驗誤差做分母**，等於假設結構整數 9 係**精確預言**。檢驗該假設：

| 分母 | 值 | δ/分母 |
|:---|:---:|:---:|
| 實驗誤差 `σ_exp` | 0.008 | **13.2σ**（= docs/07 R2 嘅數字） |
| **理論層不確定性**（強子處理差） | **1.1654** | **0.0910** |

`spread/δ = 11.0×`

**⇒「13.2σ」係真嘅，但佢係關於實驗誤差嘅陳述，唔係關於 IDCM 嘅陳述。**
用理論層不確定性做分母，偏差係 **0.0910 —— 一個 sigma 嘅 9.1%**。

誠實嘅裁決**唔係**「IDCM 被 13σ 排除」，而係「**目標本身唔夠銳利去分辨 δ，兩個方向都唔成立**」。`docs/07` R2 由本節限定。
