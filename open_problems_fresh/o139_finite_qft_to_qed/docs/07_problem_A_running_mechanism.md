## 三、★ R1：A1 結構證明（`Σ_f N_c Q_f² = 2B` 為何必然）

`docs/03` §7B 記錄咗 `3 + 4 + 1 = 8 = 2B` 但標為「精確數值恆等，結構必然性未證」。**現在證明：**

逐扇區代數化（`Q_e = 1`、`Q_u = 2/3`、`Q_d = 1/3`、`N_c = 3`）：

| 扇區 | 表達式 | 值 | IDCM 結構量 |
|:---|:---|:---:|:---:|
| 輕子 | `N_gen · N_c · Q_e²` = 3·1·1² | **3** | **B − 1** |
| up 型 | `N_gen · N_c · Q_u²` = 3·3·(2/3)² | **4** | **B** |
| down 型 | `N_gen · N_c · Q_d²` = 3·3·(1/3)² | **1** | **1** |
| **總** | `Σ_f N_c Q_f²` | **8** | **2B** |

閉式：

```
Σ_f N_c Q_f² / N_gen = 1 + N_c(Q_u² + Q_d²) = 1 + 3·(5/9) = 8/3
                     = 1 (輕子) + 5/3 (夸克)
⇒  Σ_f N_c Q_f² = (8/3)·N_gen
⇒  Σ_f N_c Q_f² = 2B   ⟺   (8/3)N_gen = 2B   ⟺   N_gen = 3B/4 = 3 = B − 1
```

**★★ 所以 `8 = 2B` 唔係數值巧合 —— 佢等價於 IDCM 結構關係 `N_gen = B − 1`（= 3B/4）。**
三個扇區和 `(B−1, B, 1)` **各自**都係結構量。而 running 隨之兩行得出：

```
Δα⁻¹ = F_proj − 2B = (B²+1) − 2B = B² − 2B + 1 = (B−1)² = 9
```

⇒ **A1 已閉合**：`Σ_f N_cQ_f² = 2B` 由「數值恆等」升級為「等價於 IDCM 結構關係」。
（`docs/03` §7B 嘅理由 3 被消除。）

⚠️ **誠實邊界**：呢個等價性用咗 **SM 電荷值**（`Q_u = 2/3`、`Q_d = 1/3`、`Q_e = 1`）同 `N_c = 3`。
**電荷量子化本身**（為何係 1/3 單位、為何 `N_c = 3`）**唔喺本文件範圍** —— 屬 O107/O114 嘅電荷量子化。
所以 A1 嘅準確講法係：`Σ_f N_cQ_f² = 2B` **唔再係額外假設**，佢係「SM 電荷 + `N_gen = B − 1`」嘅必然結果；
但「`N_gen = B − 1`」同「電荷係 1/3 單位」兩者本身仍係 IDCM 嘅結構輸入（分別見 O89 / O107）。
