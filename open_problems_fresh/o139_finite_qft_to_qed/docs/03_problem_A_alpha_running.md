## 一、問題陳述

O160 `docs/21` 只給出 **兩個結構端點**：

```
α⁻¹(0)   = C(B²,2) + F_proj = 120 + 17 = 137     (O142: 3·Tr(I₄₄) + F₅)
α⁻¹(M_Z) = C(B²,2) + 2B     = 120 +  8 = 128     (O142: 2·Tr(I₄₄) + F₅F₆)
Δα⁻¹     = F_proj − 2B      = 9 = N_gen²
```

O160 自認 🟡「命名≠解釋」。問題 A：**中間嘅 Q 有冇函數形式？定係結構上只有兩點？**

## 二、結構約束（可推出嘅嘢）

IDCM 對 α⁻¹(Q) 只有三個輸入：

1. **兩個結構端點** 137 / 128（O142, O160）
2. **費米子質量譜** — 9 個模式，m_f = M₀·γ_n·P_f（O136 `docs/04`）
3. **真空極化核** — O139 scripts/01 已證 **IDCM 唔改動 QED 光子傳播子**，所以核係標準 QED 一圈核

⇒ 函數形式唔係任揀：它係「結構端點 + 物理核」嘅最小構造。

## 三、精確一圈真空極化

```
Δα(Q²) = (2α(0)/π)·Σ_f N_c Q_f²·∫₀¹ dx·x(1−x)·ln[1 + Q²x(1−x)/m_f²]
```

**精確**（自動含閾值行為）。Q ≫ m_f 時退化為教科書式
`(α/3π)ΣN_cQ_f²[ln(Q²/m²) − 5/3]`，因為

```
∫₀¹ x(1−x) dx            = 1/6      （腳本數值驗證 1e-12）
∫₀¹ x(1−x) ln[x(1−x)] dx = −5/18    （腳本數值驗證 1e-8；被積函數喺 x=0,1 有可積 log 奇點）
```

交叉檢查：Q = 100 GeV（top 退耦）時精確式 vs 漸近式差 **0.0075%** ✅

## 六、Scheme 發現（🟡 新）

文獻嘅 α⁻¹(M_Z) 有兩個 scheme：

⇒ **IDCM 結構對 (137, 128) 對應嘅係 MS-bar 跑動，唔係 fermion-only 跑動。**

## 七、Null test — 9 嘅結構分解

三個候選讀數：

| # | 表達 | 類型 |
|:-:|:---|:---|
| (i) | 9 = N_gen² = 3² | 代數恆等 |
| (ii) | 9 = F_proj − 2B = 17 − 8 | 代數恆等（O142/O160） |
| (iii) | 9 = N_d − F₅·L₄ = 44 − 35 | 符號庫匹配 |

Window-coverage null test（17 個符號庫，{a, a·b, a+b, a−b, a·b·c}）：

```
窗口 [7,11] 覆蓋率 = 5/5 = 100%
  7: hit (5)   8: hit (8)   9: hit (5)   10: hit (8)   11: hit (9)
等於 9 嘅表達式：5 個
```

⇒ **窗口全覆蓋 ⇒ (iii) 冇選擇性，屬巧合類**（同撤回嘅 ℓ_min = 60 同類）。
⇒ 但 (i) 同 (ii) **唔係符號庫匹配** — 係同一代數物件（N_gen² = F_proj − 2B）嘅兩條獨立恆等。**結構辨識 ≠ 機制推導。**

## 七B、候選機制：Σ_f N_c Q_f² = 2B（🟡 觀察，非閉合）

α⁻¹(M_Z) = C(B²,2) + 2B = 120 + 8。**2B = 8 有冇物理對應量？**

一個完整 SM 世代嘅費米子電荷平方和：

```
Σ_f N_c Q_f² = 3(1)(1)² + 3(3)(2/3)² + 3(3)(1/3)²
             = 3·1 + 9·(4/9) + 9·(1/9)
             = 3   + 4       + 1        = 8
```

| 扇區 | 值 |
|:---|:---:|
| 輕子（3 世代 × 1 色 × 1²） | 3 |
| up-type（3 世代 × 3 色 × (2/3)²） | 4 |
| down-type（3 世代 × 3 色 × (1/3)²） | 1 |
| **Σ_f N_c Q_f²** | **8** |
| 2B = 2×4 | **8** |
| C(B²,2) + ΣN_cQ_f² | 120 + 8 = **128** ✓ |

⇒ Σ_f N_c Q_f² = **8 = 2B 精確**（SM 量子數嘅恆等，唔係擬合）。
⇒ 結構符號「2B」因此**有一個物理讀數**：總費米子電荷平方權重。

**⚠️ 但呢個唔係機制推導**，三個理由：

1. 一圈跑動給 Δα⁻¹ = 9.293，唔係 8（對數項加 1.29）；差 **16.2%**
2. Q = 0 端點嘅修正係 F_proj = 17，唔係 8 — **兩端點唔共享此機制**
3. 冇 IDCM 推導顯示 Σ_f N_c Q_f² **必須**等於 2B（此處係精確數值恆等，但結構必然性未證）

⇒ 記為 🟡 **候選讀數**，唔係閉合。
