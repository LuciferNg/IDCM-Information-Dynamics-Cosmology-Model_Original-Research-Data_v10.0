**問**：`137 → 137.035999177` 這個 dressing（+0.035999177）可否由 IDCM 結構推導？

## 3. 機制 1 — cutoff 真空極化：**排除**

標準一圈關係（bare coupling at cutoff Λ ↔ Thomson 極限）：

```
α⁻¹(0) = α⁻¹(Λ) + (1/3π) Σ_f N_c Q_f² [ ln(Λ²/m_f²) − 5/3 ]     (只算 m_f < Λ 嘅費米子)
```

問：若 IDCM 嘅結構 137 係 cutoff Λ 上嘅 **bare** 值，需要幾大嘅 Λ 才產生 0.036？

```
Λ_req（含 −5/3 scheme 常數）= 1.393178 MeV = 2.7264 m_e
Λ_req（純 leading log）      = 0.605473 MeV = 1.1849 m_e
```

### 3.1 IDCM 尺度清單 — 每個真實尺度都**過衝**

| 尺度 | 值 | 貢獻 Δα⁻¹ | vs 需要嘅 0.036 |
|:---|:---|:---:|:---:|
| m_e（定義點） | 0.510999 MeV | 0.000000 | — |
| **m₁ = M₀·2sin(π/88)**（最輕 K_Chain 模） | **1.991698 MeV** | 0.111842 | **3.11×** |
| Λ_mass = M₀·ω_max | 55.801830 MeV | 0.819088 | **22.75×** |
| Λ_ℓ(69) FSR | 74.582 GeV | — | — |
| Λ_ℓ(70) FSR | 298.328 GeV | 2.640700 | **73.35×** |

> **⚠️ 驗證附註 (2026-09-15，scripts/12 F9 獨立重算)**：
> 本表嘅 `Δα⁻¹` 用 **electron-only** 和（`scripts/07` D3 嘅 `only_e = [(m_e, 1.0)]`）——
> 呢個喺 `Λ_req = 1.393 MeV` 係**正確**嘅（該尺度下只有電子係 active），
> 但喺 `Λ_mass = 55.80 MeV` 同 `Λ_ℓ(70)` 就**保守**咗：加上所有較輕費米子（`u,d` 等）之後
> `Λ_mass` → **1.619869（45.00×）**、`Λ_ℓ(70)` → **10.879680（302.22×）**，兩者都**更加超射**。
> ⇒ **排除結論不變，反而更強**（表內數字係下界）。

★★ **決定性觀察**：K_Chain 質量譜在 `m₁ = 1.991698 MeV` **以下有禁區**（唯一比 m₁ 輕嘅物理態係投影出嘅電子 m_e = 0.511 MeV）。
而產生 0.036 嘅唯一 cutoff `Λ_req = 1.393 MeV` **正正落喺呢個禁區內**。

⇒ 需要嘅 cutoff **低於理論自身嘅最輕模式** ⇒ 唔係任何 IDCM 尺度。
⇒ 函數 Δα⁻¹(Λ) 單調 ⇒ 無其他解。
⇒ **機制 1 排除。**

## 4. 機制 2 — 乘性（scheme）重標定：**排除**


## 7. 機制 5 — 為何 α 唔可能係 IDCM 的**輸出**（renormalization condition 定理）

> 呢一節唔需要數值，但它決定咗整個問題嘅性質。

1. **任何**規範理論中，長距離耦合 α(0) 嘅值係一個 **renormalization condition（輸入）**。
   有限 IDCM 晶格移除 UV 發散，但**唔會**固定有限部分。有限晶格仍然有自由嘅 bare coupling `g_bare`；
   改變 `g_bare` 會把 α(0) 平移任意量（有限晶格間距 + 有限模式數令每個圈積分有限，
   但佢哋嘅**和**只係一個乘 `g_bare²` 嘅純數）。

2. ⇒ 身份 `α⁻¹(0) = C(B²,2) + F_proj = 137` 最多只能係一個**關於輸入嘅陳述**，唔係對輸入嘅推導。

3. IDCM **可以**推導嘅係 **running** —— 兩個尺度耦合之間嘅關係。而偏差正正落喺呢度：
   `d_run = 9`（IDCM）vs `9.085`（物理）。running 嘅 **0.94% 誤差**，就係兩個端點上嘅 +0.036 / −0.049。

4. ⇒ **dressing 問題唔係獨立問題**。佢同問題 A 嘅「為何 running = N_gen² = 9」（docs/03 §七）係**同一個缺口**。
   解決 A 就解決 dressing；冇其他路。

```
所需 running: 9.084999 = N_gen² × (1 + 0.009444)
⇒ 結構身份需要一個 0.9444% 修正（O(1e−3)，唔係 O(1)）
```
