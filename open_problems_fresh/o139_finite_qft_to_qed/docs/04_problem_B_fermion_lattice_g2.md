## 四、B3b — 示範性定量估計（係數係 O(1)，見警告）

### 4.1 硬 cutoff 主積分（解析 vs 數值，1e-5 內吻合）

```
∫_{|k|<Λ} d⁴k/(k²+Δ)³ = π²·[ 1/(2Δ) − 1/(Λ²+Δ) + Δ/(2(Λ²+Δ)²) ]
等價形式              1/Δ_eff = 1/Δ · 1/(1+Δ/Λ²)²        （代數恆等，1e-14 驗證）
Λ→∞ 極限              = π²/(2Δ)                            ✅
```

### 4.2 a_e(Λ) — 帶硬 cutoff 嘅 Schwinger 項

Feynman 參數形式（q² = 0 磁形因子）：

```
a_e = (α/2π)·∫₀¹dx∫₀^{1−x}dy·2(1−x)/[(1−x)²+y]  =  α/2π      ← 腳本驗證 = 1.000000000000
```

把 cutoff 經 1/Δ → 1/Δ_eff 插入，令 ε = 1−x、r = m²/Λ²，y-積分可解析做出
（用 1/[t(1+rt)²] = 1/t − r/(1+rt) − r/(1+rt)²）：

```
a_e(Λ) = (α/2π)·∫₀¹ dε·2ε·[ F(t₂) − F(t₁) ]
F(t)   = ln(t/(1+rt)) + 1/(1+rt),   t₁ = ε²,   t₂ = ε(1+ε)
```

### 4.3 喺 Λ = 55.80 MeV 評估

| 粒子 | m (MeV) | m/Λ_mass | a(Λ)/a(∞) | Δrel |
|:---|:---:|:---:|:---:|:---:|
| e | 0.5110 | 0.00916 | 0.9998882034 | **−1.118e−4** |
| μ | 105.66 | 1.893 | 0.1931395399 | **−8.069e−1** |

電子：a_e 偏移 1.2965e−7，實驗誤差 1.3e−13
⇒ 差 **9.97e+05 倍**實驗誤差 ⇒ **決定性證偽**
μ 子更嚴重（m_μ > Λ_mass，圈圖主導區**完全**喺 cutoff 之上）

### ⚠️ 係數警告（誠實標明）

硬 cutoff 係經**純量主積分**插入，對 log-主導項精確。次主導分子結構（∝k^αk^β）
帶一個 log 發散項，喺精確 F₂ 中同其他分子項相消；剩餘 cutoff 依賴係 O(m²/Λ²)，
係數係 O(1)，此表示法**唔固定該係數**。
由於結論係 ~10⁶ σ 嘅證偽，O(1) 係數不確定性無關緊要 —— 而且 **B3a 已獨立解決**。

## 八、B7 — Null test 同判定

Window-coverage null test（同 A 一樣嘅 17 符號庫）：

```

  67: hit (2)   68: hit (5)   69: miss (0)   70: miss (0)   71: miss (0)
```

⇒ 窗口**唔係**全覆蓋；ℓ = 69, 70, 71 **零表達式**。
⇒ ℓ ≳ 69 **唔係**符號庫產物（對比已撤回嘅 ℓ_min = 60，當時窗口 100% 覆蓋）。
⇒ 但它亦**唔係結構恆等** — 佢係**由觀測量導出嘅界**（a_e），呢個正是應該嘅性質。
