## 三、❌ 修正 #5：措辭過強（本輪新抓）

初版審計寫「**標準 QED α⁻¹ 跑動喺 Q < m_e 之下恆等於零**」— **太強**。

**精確陳述**（三點）：

```
(a) α(0) 按定義就係 Thomson limit（Q = 0 處定義），所以 Q→0 時 α(Q)→α(0)
(b) 對 Q² << m_e²，精確 1-loop 真空極化係
        Π(Q²) ≈ -(α/(15π))·(Q²/m_e²)        ← 唔係 log！
    即偏離係 O(Q²/m_e²)，唔係「恆等零」
(c) log 跑動公式 α⁻¹(Q) = α⁻¹(μ₀) − (1/(3π))ln(Q²/μ₀²)
    係 ASYMPTOTIC (Q >> m_e) 結果，喺 m_e 以下給錯符號/行為
```

原子尺度 (Q = 13.6 eV)：`(Q/m_e)² = 7.08×10⁻¹⁰`。
→ 偏離 ~10⁻⁹，**可忽略但唔係零**。O139 結論不受影響，只係措辭要修。
