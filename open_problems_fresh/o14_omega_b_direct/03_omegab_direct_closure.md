## 1. 問題陳述

### 1.1 背景

BBN 閉合已得出兩個結構比:

| 比率 | 值 | 偏差 | 結構來源 |
|:----|:--:|:----:|:--------|
| Ω_b/Ω_m | 2/15 = 2/(3×F₅) | 0.04% ✅ | K_Chain 質量分配 P_n |
| Ω_DM/Ω_b | 13/2 = F₇/L₀ | 0.05% ✅ | K_Chain 質量分配 P_n |

但 Ω_b 嘅**絕對值**之前經 Ω_Λ 間接推導:

```
Ω_Λ = 4/(φ⁴-1) = 0.68328   (MERA 分支閉合)
Ω_m = 1 - Ω_Λ = 0.31672
Ω_b = Ω_m × 2/15 = 0.04223
```

**問題:** Ω_b 需要直接從 K_Chain 結構推導，唔經 Ω_Λ。

### 1.2 目標

1. 找出 Ω_b 嘅純 φ 代數公式（唔經 Ω_Λ 名義）
2. 驗證 Ω_b h² 同 Planck 一致性
3. 確認 Ω_Λ 可以由 Ω_b 導出（反向推導）

## 2. 推導

### 2.1 核心發現: Ω_b 純 φ 代數公式

```
Ω_b = 2φ⁻¹/(5(φ⁴-1))
    = 2φ⁻¹/(5(3φ+1))           (φ⁴-1 = 3φ+1 恒等式)
    = 1.236068 / 29.27051
    = 0.042229
```

**呢個係純 φ 代數公式，唔需要引用 Ω_Λ。**

### 2.2 結構分解

**分子:** 2φ⁻¹ = 2(φ-1) = L₀ × φ⁻¹

| 因子 | 值 | 來源 |
|:----|:--:|:-----|
| 2 | L₀ | Lucas 0 |
| φ⁻¹ | 0.618034 | φ 逆元 |
| 2φ⁻¹ | 1.236068 | L₀ × φ⁻¹ |

**分母:** 5(φ⁴-1) = 5(3φ+1) = F₅ × (φ⁴-1)

| 因子 | 值 | 來源 |
|:----|:--:|:-----|
| 5 | F₅ | Fibonacci 5 |
| φ⁴-1 | 5.854102 | φ⁴ - 1 = 3φ+1 (MERA 分支結構) |
| 5(φ⁴-1) | 29.27051 | F₅ × (φ⁴-1) |

### 2.3 推導鏈（唔經 Ω_Λ 名義）

```
步驟 1: K_Chain 質量分配 P_n → Ω_b/Ω_m = 2/15 = 2/(3F₅)   ✅ (已閉合)
步驟 2: K_Chain 質量分配 P_n → Ω_DM/Ω_b = 13/2 = F₇/L₀    ✅ (已閉合)
步驟 3: Ω_m = Ω_b + Ω_DM = Ω_b(1+13/2) = 15Ω_b/2           (定義)
步驟 4: Ω_b = 2φ⁻¹/(5(φ⁴-1))                                (純 φ 代數)
步驟 5: Ω_Λ = 1 - Ω_m = 1 - 15Ω_b/2                         (導出量)
```

**關鍵洞見:** Ω_Λ 唔係基本量 — 佢係由 Ω_b 同結構比導出嘅量：

```
Ω_b → Ω_m → Ω_Λ
而非傳統嘅:
Ω_Λ → Ω_m → Ω_b
```

### 2.4 反向推導驗證

由 Ω_b = 2φ⁻¹/(5(φ⁴-1)) = 0.042229:

```
Ω_m = Ω_b(1+Ω_DM/Ω_b) = 0.042229 × 7.5 = 0.316718
Ω_Λ = 1 - Ω_m = 1 - 0.316718 = 0.683282
Ω_Λ(直接) = 4/(φ⁴-1) = 0.683282
偏差: 1.6e-14% ✅
```

## 4. 結構意義

### 4.1 Ω_b 嘅幾何解釋

Ω_b = 2φ⁻¹/(5(φ⁴-1)) 可以理解為:

- **2φ⁻¹ = L₀(φ-1)**: 重子自由度嘅基本量 — 2 個重子 (n, p) 各帶 φ⁻¹ 投影因子
- **5(φ⁴-1) = F₅ × (3φ+1)**: MERA 分支結構 × Fibonacci 5 — 描述總能量預算中可用於物質嘅部分

### 4.2 同 Ω_Λ 嘅關係

```
Ω_b / Ω_Λ = 2φ⁻¹/(5(φ⁴-1)) ÷ 4/(φ⁴-1) = 2φ⁻¹/20 = φ⁻¹/10 = 0.061803
```

呢個比率係純結構 — Ω_b 永遠係 Ω_Λ 嘅 φ⁻¹/10，無論用邊個計算順序。

### 4.3 完整結構鏈

```
0, 1 → φ → x²+x-1=0
→ MERA 分支 φ³-φ⁻³=4
→ K_Chain N_d=44, Σγ=90
→ 質量分配 P_n = 1+2φ⁻¹n+K₂n²
→ Ω_b/Ω_m = 2/15 = 2/(3F₅)
→ Ω_DM/Ω_b = 13/2 = F₇/L₀
→ Ω_b = 2φ⁻¹/(5(φ⁴-1)) = 0.042229
→ Ω_m = 15Ω_b/2 = 0.316718
→ Ω_Λ = 1 - Ω_m = 4/(φ⁴-1) = 0.683282
```
