## 二、Q1-T1：計數對應定理（✅ 6 檢查）

**「一階 ≡ 一次 B-穿越 ≡ 一層」喺計數層面成立 — 因兩側共享同一 B 計數：**

```
環側 (O139/O168):  88 = B·2L₅ = 4×22;  每模組 = 22 sites = 2L₅
                  一階 = 穿越 B=4 模組 = 4×(π/2) = 2π 反常相位
樹側 (P10):       K_Tree 分支因數 B=4;  一層 = 4→1 isometry
                  FSR 層比 = 4 = B (Δℓ = log₄(n_p/n_o), O140 docs/12)
```

**結構錨（唔係擬合）** — O124 docs/08 §C：
- `b₀ = Tr(T̂^B) = L₄ = 7`（T̂ = Fibonacci 矩陣；C1-C2 ✅）
- `b₀ 指數 = B = 模穿越數`：88//(2L₅) = 4（C3 ✅）
- `深度 = 一個分支週期: Tr(T̂^B) = L₄`（C4 ✅）
- 簿記閉合：`2μ²Δα⁻¹ = B·9 = 36`; `F₁₁ = 53 + 36 = 89`（A5-A6 ✅）

⟹ **「一階」嘅費米子生成數 N_gen = B−1 亦係 B 計數嘅投影**（Δα⁻¹ = N_gen² = (B−1)²，O139 參數定律 B=2..6 逐 B 成立）。

## 四、Q1-T3：相位-標度正交（✅ 承接 O231 A/B 二分）

O140 docs/12 提供精確兩坐標：
- **floor(ℓ)** = 觀察者尺格網層 → = 樹深（標度坐標）
- **frac(ℓ)** = 探針喺格網嘅相位位置 → = 環相位（winding 累積坐標）

⟹ **running「階數」= frac 相位繞數計數；K_Tree「深度」= floor 格網層。兩者正交。**
O231 Q4 已閉合嘅 A/B 二分就係呢個正交性：A 結構層（β≡0 定點，住喺固定樹深：P10 Up@0/Down@7/Lepton@14）+ B 演化層（環相位繞數路徑）。
