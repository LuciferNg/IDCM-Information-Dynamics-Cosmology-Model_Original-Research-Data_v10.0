## 二、唯一性定理（Q3-UNIQ）

> **設 88-site 環帶平移不變 connection（每-site 相位 q 常數）。若**
> ① 單值性: 88q ∈ 2πℤ ⟹ q = 2πm/88（m ∈ ℤ）
> ② B=4 模組分區: 每模組 = 22 sites = 四分之一環 ⟹ 模組相位 = m·π/2 精確角
> ③ 每單位 running = 一整圈 = 最小非零繞數（O139/O168 定義）
> **則 m = 1 唯一 ⟹ q = 2π/88。零自由參數。**

**枚舉證據（m = 0..12）**：

| m | q_m/2π | 模組相位 | 整圈相位 | 判定 |
|:-:|:------:|:--------:|:--------:|:----:|
| 0 | 0 | 0 | 0 | ✗ 無 running |
| **1** | **1/88** | **π/2** | **2π** | **✓ 唯一解** |
| 2 | 1/44 | π | 4π | ✗ 模組相位錯倍 |
| 3 | 3/88 | 3π/2 | 6π | ✗ |
| 4 | 1/22 | 2π | 8π | ✗ |
| 5 | 5/88 | 5π/2 | 10π | ✗ m≡1(mod 4) 但模組相位 5π/2 ≠ π/2 精確角 |
| ... | ... | ... | ... | ✗ |

- B1：模組相位 = π/2 **精確角**（非 mod 2π）⟹ 只有 m=1（m=5 得 5π/2，相位差唔係四分之一圈）
- B2：最小非零繞數 ⟹ m=1
- B3：m=0 矛盾（Δα⁻¹ = 9 ≠ 0 已量度）
- B4：m≥2 每單位多圈，違「一整圈」定義

**替代數值全滅**（結構剛性，第④硬測試）：任何 q ≠ 2π/88 要麼模組相位錯（m=2,3,4…），要麼多繞（m≥5 ≡ 1 mod 4），要麼零相位（m=0）。
