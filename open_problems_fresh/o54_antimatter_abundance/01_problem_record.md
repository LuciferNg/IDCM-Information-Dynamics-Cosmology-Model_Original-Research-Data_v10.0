## 一、問題陳述

宇宙學最大嘅開放問題之一：**點解宇宙有物質而冇（可觀測嘅）反物質？**

### 1.1 觀測事實

| 量 | 值 | 來源 |
|:---|:---|:---|
| η_B = (n_B − n_B̄)/n_γ | 6.062×10⁻¹⁰ | IDCM BBN 已閉合 (0.62%) |
| n_B̄/n_γ | < 10⁻¹⁵（重子區）| Big Bang Nucleosynthesis + CMB |
| 反物質區域 | 冇觀測到（星系尺度）| γ-ray 湮滅輻射上限 |
| AMS-02 反質子/質子比 | ~10⁻⁴（宇宙線，次級）| AMS-02 |
| 正電子豐度 | 宇宙線異常（PAMELA/AMS）| 次級 or DM 訊號 |
| 反氦候選 | 冇確認（AMS-02 上限 ~10⁻⁹）| AMS-02 |

**核心張力：** ΛCDM 需要 Sakharov 三條件（B 破壞、C/CP 破壞、非平衡）+ 具體 baryogenesis 機制，但全部機制都有未解決問題（sphaleron 擦除、電弱相變一階性、CP 破壞源）。IDCM 嘅 η_B 係**結構常數**（0.62% 閉合），但**反物質嘅完整命運未講**。

### 1.3 問題分解

**Q1. 反物質豐度喺 IDCM 中係咩？**
- η_B 只量度 (n_B − n_B̄)。IDCM 結構是否預測 n_B̄ = 0？
- K_Chain 投影機制係咪本質上「物質-反物質不對稱」？

**Q2. 正電子（宇宙線）來源？**
- AMS-02 正電子異常 (positron fraction 上升) — IDCM 有冇結構預測？
- 係咪 W-field 衰減產物？P_n 譜有冇正電子通道？

**Q3. 反物質區域排除嘅結構論證？**
- ΛCDM: 湮滅輻射上限 → 冇反物質區域。
- IDCM: 如果物質 = K_Chain beat 投影，反物質 = 反相 beat？有冇「反投影」機制？
- O33 已有「黑洞反投影 T_pipe†」— 反物質係咪同一機制嘅另一面？

**Q4. 重子-反重子差額嘅結構來源？**
- η_B 已閉合，但差額 (B−B̄) 嘅「符號」點解係正？
- 係咪 K_Chain 方向性（操作維=時間）嘅必然結果？

**Q5. CP 破壞與反物質？**
- IDCM δ_CP = 66.40° (CKM) + 2π/5 (PMNS) 已閉合 — 呢啲相位同反物質豐度有冇結構關係？

```

### 2.3 K_Chain 模式與粒子

```
u → n=20 (B×F₅ = 4×5)
