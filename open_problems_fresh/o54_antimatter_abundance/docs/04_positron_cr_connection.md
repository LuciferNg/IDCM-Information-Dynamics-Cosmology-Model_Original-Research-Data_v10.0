## 一、問題

O54 剩餘開放問題：正電子宇宙射線譜精確接駁。W-field 模式共振能量 E_n = M₀·ω_n ≈ 2-56 MeV，但 AMS-02 觀測到嘅正電子分數上升喺 10-500 GeV。如何接駁？

## 二、物理圖像

```
W-field 共振 → CR Lorentz boost → 觀測正電子
E_res = 47.6 MeV
E_e⁺ = γ_p · E_res (γ_p = E_p/m_p)
CR 譜: dN/dγ_p ∝ γ_p^(-p), p = 2.7
```

三層次接駁：
1. **W-field 模式產生率**: Γ_n = M₀·γ_n, 高頻模式 (n=22-44) 主導
2. **CR Lorentz boost**: E_e⁺ = γ_p · E_res, 能量標度由 CR 譜決定
3. **觀測譜形**: f_W(E) = 0.0400 · E^0.258, 冪律上升

## 五、接駁機制

### 5.1 W-field 模式共振

```
W-field 模式 n:  共振能量 E_n = M₀·ω_n
                產生率 Γ_n = M₀·γ_n
                高頻模式 (n=22-44): Γ_n 最大, 共振能量 39-56 MeV
```

### 5.2 CR Lorentz boost

```
正電子能量 E_e⁺ = γ_p · E_res = (E_p/m_p) · E_res
E_p = CR 質子能量
γ_p = E_p/m_p = Lorentz 因子

E_e⁺ = 10 GeV → γ_p = 10⁴/47.6 = 210
E_p = 210 × 0.938 = 197 GeV
```

### 5.3 譜形卷積

```
dN_W/dE ∝ Σ_n Γ_n · (E/E_n)^{-p} · Θ(E − E_n)
         = (Σ_n Γ_n · E_n^p) · E^{-p}  (for E > E_n)
         ∝ E^{-p}

但 f_W(E) = (dN_W/dE)/(dN_sec/dE + dN_W/dE) ∝ E^{γ_sec-p}
→ 觀察到 f_W ∝ E^0.258 → γ_sec - p = 0.258 → p = 2.7-0.258 = 2.44
```
