## 一、撤回聲明

**上一輪結論「反物質 = 結構上不存在 (n_B̄ = 0 精確)」係錯誤嘅 over-claim。**

錯誤源頭：檢查 1 發現「K_Chain 冇負頻率模式」後，我錯誤推論「反粒子不存在」。
正確解讀：**實模式 (ψ = ψ*) 只係話 K_Chain 本徵模式自身係 CPT 共軛不變 — 唔等於 SM 粒子嘅反粒子自由度唔存在。** 反粒子係投影機制 (CY₃ 激化) 之後嘅荷結構問題，唔係 K_Chain 譜正負問題。

## 四、新結構假設：局部反投影機制

### 4.1 投影 → 反投影對偶

O33 已有反投影算子：**T_pipe† = I − T_pipe**（黑洞通道）。

**修正後假設**：反投影唔止喺黑洞啟動 — **任何局部能量密度 ρ > ρ_c 嘅過程都會局部反轉投影**：

| 過程 | 局部能量注入 | 結果 |
|:---|:---|:---|
| 宏觀宇宙 (平均) | ρ ≪ ρ_c | 冇反物質生成 |
| 宇宙射線碰撞 | 高能 (GeV-TeV) | **反質子/正電子 (次級)** |
| 加速器 | 極高能 (GeV-TeV) | **反氫/反氦-4 (人造)** |
| 黑洞 | ρ > ρ_c | 完整反投影 (回收) |

### 4.2 Pair production = 局部反投影

- γ + γ → e⁺ + e⁻ 需要 E > 2m_e = 1.022 MeV
- γ + p → p̄ + ... 需要 E > 2m_p = 1.877 GeV
- **反物質產生 = 局部能量集中 > 2m 閾值 = 局部反轉 T_pipe**
- 能量守恆 Σγ = 90 確保：投影 + 反投影 = 守恆對（物質 + 反物質可同時產生）

### 4.3 宏觀冇反物質嘅結構理由

- 投影 T_pipe 係**全局單向**（宇宙平均狀態）：宏觀物質主導
- 反投影需要**局部能量密度超閾值**：宇宙射線碰撞、加速器、黑洞先做到
- **冇局部超閾值 → 冇反物質區域 → 冇湮滅輻射 → 觀測一致**
