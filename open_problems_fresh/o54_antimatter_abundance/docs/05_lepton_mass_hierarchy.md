## 一、問題

O54 剩餘問題：電子質量放大因子。從 O53 已知 F_proj = 17 (kernel 模式數) 放大質子質量，但電子 (及其他輕子) 嘅放大路徑不同。

## 二、關鍵發現

每個粒子經唔同 K_Chain 模式 × 唔同投影路徑得到質量：

```
m_particle = M₀ × γ_n × F_proj_particle
            ↑       ↑          ↑
        標度能   模式能量   投影放大因子
```

## 三、投影路徑含義

### 3.1 電子路徑: L₆/F₅

```
F_proj(e) = L₆/F₅ = 18/5 = 3.6
L₆ = 18 (Lucas 數, 邊界相關)
F₅ = 5 (Fibonacci 數, 生成元相關)
→ 電子 = 最低頻模式 (n=1) × 邊界/生成元比
```

### 3.2 μ 子路徑: Nd−E_proj

```
F_proj(μ) = Nd − E_proj = 44 − 28.5 = 15.5
Nd = 44 (總模式數)
E_proj = 28.5 (投影能量, T_pipe 保留)
→ μ 子 = DM 模式 (n=7) × 剩餘模式數
```

### 3.3 τ 子路徑: Nd−L₄

```
F_proj(τ) = Nd − L₄ = 44 − 7 = 37
L₄ = 7 (Lucas 數 = φ⁴+φ⁻⁴)
→ τ 子 = 高頻模式 (n=20) × 總模式減 DM 索引
```

## 四、結構規律

```
模式跳躍: 1 → 7 → 20 (間隔 6=F₅+1, 13=F₇)
投影放大: 3.6 → 15.5 → 37 (代數越高質量越大)

代數越高:
  - 模式頻率越高 (γ_n 越大)
  - 投影路徑越長 (F_proj 越大)
  - 質量越大 (e: 0.5MeV, μ: 106MeV, τ: 1777MeV)
```
