## 二、核心結果（全部 mpmath 40-50 dps 實測，scripts/01 10/10 PASS）

### 2.1 tan² 有 pole → 唔可以做譜基底 🔴

- tan²(44π/88) = tan²(π/2) = **∞**（cos²=0，實測 4.27e-86）
- sin/cos 88 格全有限；tan 喺第 44 格（Nyquist/對稱中點）發散
- Σtan²(nπ/88) 全和發散（pole 主值不定義）⟹ 唔係 L² 物件
- **判定：tan² 唔可以替換 sin/cos 做譜加權**；換咗即刻爆 n=44

### 2.2 但「tan = 三角波」直覺成立 ✅（用戶直覺有實質內容）

- **arctan∘tan = 三角波摺疊（fold）**：實測全部 88 格（pole 除外）✓
  `arctan(tan x) = x − π·⌊x/π + ½⌋`（摺疊入 (−π/2, π/2)）
- 三角波 = **方波嘅積分**（Fourier: Σ sin(nx)/n²）⟹ tan 係「二元/位元結構 → 連續量」嘅自然橋
- IDCM 有大量二元結構：O7 阻挫邊 Ising 位元、O189 mod-2 商群 Rule90、O223 2-coloring、O222 sign_rank、O225 τ-對合、O226 對映 —— **呢啲先係 tan 潛在適用層**

### 2.3 88 = 8×11：tan 內建八角子格 ✅

- tan(nπ/88) 喺 n=11k（k=1..8）取**八角分圓值**：
  √2−1, 1, √2+1, **pole**, −√2−1, −1, 1−√2
- 即 88 格內建一個**八角/正方形子結構**（O223 30 個正方形面同系）
- 代數身份：tan(11π/88)=tan(π/8)=√2−1；tan(33π/88)=tan(3π/8)=√2+1

### 2.4 新發現：Σtan² 精確整數閉式 🆕

```
Σ_{n=1}^{43} tan²(nπ/88) = 1247  EXACT（mpmath 1e-20 級）
閉式: (N−1)(N−2)/6 = C(87,2)/3 = 29×43

驗證: scripts/01 對 N=88 通過；Σcsc² 對照 = 2581 = (88²−1)/3 ✓
```

- 1247 係**三角數/3** 結構 —— O137（Σ=55=F₁₀）同一家族「格點完備和」
