## 定理 1 (寫入可逆性)

O7 相位滑移 (寫入) 係**熱力學可逆操作**: 每寫入移除熵 ΔS, 花費能量 ΔE,
兩者由寫入溫度 T_write 聯繫 (ΔE = T_write·ΔS):

```
ΔE_write = B(n)·γ·|cosθ_i|          (O41: B(n) = 123/88, γ = 192 μK)
T_write  = γ = 4N_d + B² = 192 μK   (O41 μK→能量換算因子)
ΔS_write = ΔE_write/T_write = B(n)·|cosθ_i|·k_B
        |cosθ|=1: ΔS_write = B(n) k_B = 1.3977 k_B = 2.017 bits
```

**零熵稅**: 寫入本身唔產生熵 (ΔE = TΔS 可逆) — 預算唔會因寫入而漏。

## 離散 Landauer 算子 (O41 有限尺寸修正, 重現)

```
E_min = L₁₀/(4N_d) = 123/176 = 0.698864
      = ln2 + 1/176 + O(1/N²)         (殘餘 3.46e-5 ~ 1/176² = 3.23e-5)
L₁₀ = round(4N_d·ln2 + 1) = 123       (整數化閉合)
B(n) = 2 E_min = 123/88               (每寫入 = 2 個模式單位)
```
