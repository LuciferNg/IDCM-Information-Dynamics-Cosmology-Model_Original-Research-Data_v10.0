## 2. P1 殘餘 — K_σ 可導出性

### 2.1 候選尺度

| 候選 | 值 |
|:-----|:--:|
| π/88 rad (site 半相位) | 2.0455° |
| **2π/88 rad (site 相位)** | **4.0909°** |
| 2π/44 rad | 8.1818° |
| **採用 FWHM (O41 冷斑 R8)** | **4.1700°** |
| σ = FWHM/2.355 | 1.7707° |
| 節點最近鄰角 | 26.0913° |
| 節點 Nyquist 尺度 180/ℓ_Nyq (ℓ_Nyq=6.9) | 25.7° |

| 比 | 值 | 偏離 |
|:---|:--:|:----:|
| FWHM / (2π/88) | **1.0193** | **1.93%** |
| σ / (π/88) | 0.8657 | 13.43% |

**⟹ 4.17° ≈ 2π/88 = 4.0909° 只差 1.93%** — 一個誘人嘅巧合，但**冇機制**；
σ 與 π/88 差 13% ⟹ 唔係簡單對應。**唔可以**聲稱已導出（禁後驗擬合）。

### 2.2 取樣/混疊要求 — 唔會鎖定核

- 節點間距 26.09° ⟹ 取樣 Nyquist ℓ_Nyq = **6.90**
- 要 band-limit 到 ℓ_Nyq：FWHM ~ 26°
- **但 5-design 已精確保護 ℓ≤2**（2ℓ = 4 ≤ t = 5），唯一洩漏通道 ℓ'=5 已知
- FWHM 26° 會令節點場 std 由 41.7 → **20.5 μK** 並**摧毀 ℓ=3 模態**（ℓ=3 係大尺度模）

| FWHM | 節點場 std | T₉ | T₂₀ |
|:----:|:----------:|:--:|:---:|
| 4.17° | 41.73 | −102.48 | +41.73 |
| 10.0° | 33.53 | −88.16 | +52.06 |
| 26.0° | 20.54 | −48.47 | +23.43 |

**⟹ 取樣要求唔鎖定 K_σ：任何 FWHM < 節點間距都保留 ℓ=3 模態。**

### 2.3 ★ 節點相關結構 (意外好消息)

| 量 | 值 |

所以 docs/08 §7 嘅次序統計量處理係**正確適用**嘅（唔需要額外嘅相關校正）。
