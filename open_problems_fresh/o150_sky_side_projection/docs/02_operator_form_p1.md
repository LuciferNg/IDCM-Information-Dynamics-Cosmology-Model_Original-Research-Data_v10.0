## 2. ★ 算子族：正確形式

**候選 (O159 形式)** `𝒫[f](n̂) = f(arccos(n̂·â))` — 軸對稱、m=0、**已判 null (0/12)**。

**本 O 判定嘅正確族**:

```
𝒫₆₀[f]_i = (K_σ * f)(n̂_i)          i = 1…60
   K_σ = 高斯平滑核 (FWHM 4.17°)
   n̂_i = 60 個 A₅ 節點方向 (由幾何固定, 唔係擬合)
```

性質：

| 性質 | 值 / 判定 |
|:-----|:----------|
| 自由參數 | **0** (核尺度由既有採樣管道固定) |
| Graph-invariant? | **否** — 算子由 sky 方向 n̂_i 索引，依賴場實現 f |
| 對稱性 | **I-covariant**: 𝒫[f](M n̂_i) = 𝒫[M f](n̂_i)，M ∈ I (order 60) |
| 像空間 | R⁶⁰，ℒ²(S²) 上嘅局部取樣 |

**頂點傳遞定理嘅逃生門被實證確認**：定理封死「graph-invariant 算子 + g-不變初始態」；
𝒫₆₀ **唔係** graph-invariant（它取樣 sky 實現），所以 T₉ ≠ T₂₀ 完全合法。

## 5. P1 判定

```
🟢 算子形式已定: 𝒫₆₀[f]_i = (K_σ * f)(n̂_i) — I-covariant 局部取樣, 0 自由參數
🟢 「graph-invariant 封死 + sky-side 破缺」已由實證確認 (T₉−T₂₀ = 142.4 μK)
🔴 破缺輸入係局部 (ℓ≥4 / ℓ≥7 小尺度), 唔係 ℓ=3 八極
🔴 O159 形式 𝒫[f](n̂)=f(arccos(n̂·â)) 嘅推廣亦唔成立: ℓ=3 場雖 90.2% m=0 (docs/04),
   但 look-elsewhere 校正後 p = 0.093 (唔顯著), 且軸向無結構身份
```

**誠實結論**：P1 嘅「算子族」問題**有答案**（局部取樣算子，零參數，I-covariant）；
但「由算子直接給出 3.02」嘅驗證標準**唔滿足** — 3.02 係局部 sky 性質，唔係低 ℓ 算子輸出。
