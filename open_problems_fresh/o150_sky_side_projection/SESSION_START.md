## 六. 已知陷阱 (必讀，唔好重蹈)

1. **★ 座標系**: `a5_nodes.txt` 係 **RA/Dec (ICRS)**；Planck 地圖係**銀河座標**。
   必須 `SkyCoord(ra, dec, frame='icrs').galactic` 轉換才可採樣。直接用 → 軸向全錯
   (O143 曾中，產生假軸 (241.00°, 2.79°))。
   ⚠️ 但 ℓ-投影統計 `span{Y_ℓm(n̂_j)}` 對**整體旋轉不變** ⟹ 功率/p 值免疫，只有軸向受影響。
2. **採樣管道** (對齊 O182 scripts/02b): `read_map(field=0)` → reorder 驗證 (n2r) →
   `hp.smoothing(fwhm=4.17°)` → `hp.ang2pix` 最近像素 → ×1e6 μK。
   驗證: 自算 SMICA vs temps2 應該 corr = 1.000000, max|Δ| = 0.000 μK。
3. **Fibonacci 球面構造**: 第三分量必須 `sin(lat)`，唔係 `lat`。否則軸向量唔歸一化
   (‖â‖ = 1.027)，軸向與對齊角度全偏 (O143 scripts/30/31 曾中)。
4. **譜簡併**: 用譜簽名判自同構軌道前**必須先查多重度**；簡併子空間內基底任意。
   判自同構要**顯式構造** (networkx `GraphMatcher`)，唔靠啟發式。
5. **f-string 陷阱**: Python f-string 內唔可以有字面大括號 (`{ℓ'm',ℓm}` → SyntaxError)；
   亦禁 Unicode 下標/上標 (會 SyntaxError，docstring 都計)。用 ASCII。
6. **環境**: 背景任務一律用 `/usr/bin/python3` (background shell 嘅 `python3` 係 miniforge 空環境，
   缺 numpy/scipy/healpy/astropy)。execute_code sandbox 亦冇 numpy。
7. **計數約定**: σ 用 `ddof=1`；corr 用 Pearson (`np.corrcoef`) 唔係 Spearman；
   著色 sign 約定 = `(color==1) == (T<0)` (color[0]=1 錨定)。
   (O143 文檔核對首跑 6 個 FAIL 全部係呢類約定錯誤。)
8. **唔好改其他 O 目錄** — 上游發現要下游自我修正時，寫入下游 O 嘅 `SESSION_START.md`
   加一節「★★ 上游修正點 — 待本 O 修改」，由該 O session 自行執行。
9. **禁後驗擬合** — 候選算子唔可以係「目標值 − 已知常數」構造項 (tautology)；
   唔可以 φ-power 湊數。每個候選要過 null test。
