## 4. 第三通道: 黑洞 = 轉化器 (唔係累積器)

```
累積器 (ΛCDM):  物質落入 → 永鎖 (直到 Hawking 10⁶⁷-10¹⁰⁰ yr) → 殘骸化問題
轉化器 (IDCM):  物質落入 → T_pipe† 反投影 → sync 返池 (O121)
                黑洞本體 = 投影截斷邊界 (準永久, 冇蒸發)
                增長受轉化率限制 + T_ring 極限環重置 → 平衡增長
```

→ 黑洞 = 「回收站 + 轉化器」: 流入物質返池 (循環閉合),
本體準永久 (冇三狀態), 增長有上限 (冇殘骸化) — **三面一致**.
