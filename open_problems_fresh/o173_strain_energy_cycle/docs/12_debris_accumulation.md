# O173 docs/12 — 恆星級殘骸累積測試 (用戶 09-12 第三挑戰) 🟢

## 問題
黑洞冇清理機制 → 恆星級黑洞 + 白矮/中子星不斷累積 → 殘骸密度爆炸上升?
(「宇宙最終滿係死星」)

## 答案: 唔會 — 清理機制 (兩層) + 形成率衰減 (P1)

### A. 問題形式化
```
ρ_star = 1.5e8 M☉/Mpc³;  f_debris ≈ 2% (WD~1% + NS~0.5% + 恆星級BH~0.3%)
ρ_debris(z=0) ≈ 3.0e6;  殘骸形成率 = 0.02×0.02 = 4e-4 M☉/yr/Mpc³
冇清理假設 → 線性上升 (+3e3/Mpc³/Gyr)
```

### B. 清理機制 (兩層, 零新常數)
1. **層1 — 恆星級黑洞 = 轉化器**: 有事件視界 = 局部 T_pipe† 反投影區 (O121 **通用**)
   → 落入物質經 T_pipe† 轉化返池 — 同 SMBH 同一通道
2. **層2 — 白矮/中子星 (冇視界)**: 雙星合併 / 落入恆星級黑洞或 SMBH
   → 被吸收 → 經層1 返池

殘骸唔係「鎖死」— 係「**慢速返池**」: τ_rec 長但通道存在.

### C. 就算冇清理: 形成率衰減 → 固定點
```
P1 (docs/04): N(z) ∝ 4^{−ℓ} = 1/(1+z) — 形成率層級下降
Cosmic noon (z~2) 後 SFRD 跌 10× → 殘骸形成率同步跌
→ 累積率 → 0, 密度趨向固定點 ρ_debris∞ = 總恆星質量×2% = 4.0e6
而家 3.0e6 → 尚有 1.33× 空間 — 有限, 唔會 100% 鎖死
```

### D. 時標
```
雙倍時標 (冇清理) = 7.5 Gyr
形成率跌 10× → 實際增長遠低於線性 (收斂中)
T_ring 84.63 Gyr = 極限環週期 — 清理/再生週期級
```

### E. P15 預言 (可證偽)
**恆星級殘骸密度 (WD+NS+BH) 隨 z 演化 = 恆星形成史 × f_debris**
(冇額外累積/冇爆炸上升; 形成率跌 → 密度趨平)

**測試**: 白矮星/中子星計數密度 (Gaia 完整樣本, 深場), 恆星級黑洞合併率 —
若觀測到殘骸密度超出形成史預期 → 冇清理機制 → IDCM 錯.
