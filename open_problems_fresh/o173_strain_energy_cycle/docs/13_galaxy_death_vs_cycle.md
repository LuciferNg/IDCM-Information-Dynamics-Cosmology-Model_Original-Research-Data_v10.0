## 答案: 層級分離 — 個體熄火 ⊂ 整體循環, 唔衝突

### B. 層級分離
```
星系 (個體): 局部凝聚體, 氣體供應有限
  - 壽命 = 氣體耗盡時標 (~10 Gyr 級)
  - 熄火後 = 殘骸庫 → 慢速返池 (docs/12)
宇宙 (整體): 能量循環系統 (Noether Q=44, O161)
  - 池再生 = 阻挫邊翻轉 + 共軛流入 — 唔係注入舊星系
  - 新凝聚喺新節點出現 (P1: N(z) ∝ 4^{−ℓ} 層級結構)
「冇熱寂」= 整體循環唔停, 唔等於「每個星系永生」
```

### D. 觀測 — 死亡係 staggered, 唔係同時

```
「到處死亡」= 所有星系同時死 — 冇發生, 形成史錯開
```
