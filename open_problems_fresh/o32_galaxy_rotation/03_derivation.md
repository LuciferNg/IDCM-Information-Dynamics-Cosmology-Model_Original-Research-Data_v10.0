## 1. 公理 (Axioms)

IDCM 框架內嘅基本假設:

- **A1**: K_Chain 係 44-site 閉合環, 周長 R_H = c/H₀ = 4129.94 Mpc
- **A2**: H₀_idcm = c/R_H = 72.59 km/s/Mpc (結構定義, 非膨脹率)
- **A3**: K_Tree 係 B=4 分支嘅 33-level 尺度階梯
- **A4**: W-field 係 K_Chain 諧波嘅集體場, 喺 g < a₀ 時耦合放大引力
- **A5**: 星系嘅「DM 效應」= K_Chain 幾何投影, 唔係粒子暈

## 2. 定義 (Definitions)

### 2.1 a₀ (臨界加速度)

```
a₀ ≡ c²/(2πR_H) = c·H₀/(2π) = 1.1225×10⁻¹⁰ m/s²
```

呢個係 K_Chain 環嘅固有加速度標度 — 光繞環一圈嘅向心加速度除以 2π。

### 2.2 RAR 插值函數

```
g_obs = g_bar·(1 + √(1 + 4a₀/g_bar))/2
```

即 MOND 嘅 simple interpolation (μ(x) = x/(1+x)), 但 a₀ 係結構常數而非 fit 參數。

## 3. 定理 (Theorems)

### 定理 1: a₀ 係零自由參數結構常數

**證明:**
1. H₀_idcm = c/R_H (A2)
2. a₀ = c·H₀/(2π) = c²/(2πR_H)
3. R_H 係 K_Chain 幾何, c 係常數 → a₀ 完全由結構決定
4. 冇任何 fit 參數 ✅ QED

### 定理 2: BTFR 斜率 = 4 (深 MOND 極限)

**證明:**
1. 深 MOND 極限 (g_bar << a₀): g_obs → √(g_bar·a₀)
2. g_obs = V²/R, g_bar = G·M_bar/R²
3. V²/R = √((GM_bar/R²)·a₀)
4. V⁴ = G·M_bar·a₀ ✅ QED

**驗證:** V = 100 km/s → M = 6.71×10⁹ Msun (典型星系 ✅)

### 定理 3: m₇ 唔可能係星系 DM 粒子暈

**證明:**
1. m₇ = 13.8 MeV, Ω_DM = 0.26 → ρ_DM = 2.57×10⁻²⁷ kg/m³
2. 30 kpc 球內 DM 質量 = 4.3×10⁶ Msun
3. 觀測需要 ~10¹² Msun → 差 2.3×10⁵ 倍
4. → m₇ 只係宇宙學密度標度, 星系 DM 必須係幾何效應 ✅ QED

### 定理 4: Kepler 引力完全失敗

**證明 (數值):**
1. 純重子引力 fit 175 星系: χ²/dof = 158.4
2. IDCM a₀ fit: χ²/dof = 11.0
3. Δχ² = 474,022 (Kepler - IDCM)
4. → 必須有額外效應 ✅ QED

## 5. 物理詮釋

### 5.1 點解 a₀ = cH₀/2π?

K_Chain 環 (周長 R_H) 上嘅基本模式 (mode 1):
- 光繞環一圈: T = 2πR_H/c = 84.6 Gyr
- 環向心加速度: a_ring = c²/R_H = 7.05×10⁻¹⁰ m/s²
- 角度平均: a₀ = a_ring/2π = 1.12×10⁻¹⁰ m/s²

呢個係「環加速度嘅 1/2π 平均」— 完全幾何。

### 5.2 星系尺度嘅 DM 效應

喺星系尺度 (kpc), 加速度 g << a₀ 嘅區域:
- 重子引力唔夠 → 旋轉曲線應該下降 (Kepler)
- K_Chain mode 1 嘅 W-field 耦合 → 額外引力
- 等效 MOND 插值 → 平坦曲線

### 5.3 m₇ 嘅角色

m₇ = 13.8 MeV (P7 mode) 提供宇宙學 DM 密度 (Ω_DM/Ω_b = 13/2),
但星系尺度嘅「DM 暈」唔係粒子 — 係 K_Chain 諧波投影。
