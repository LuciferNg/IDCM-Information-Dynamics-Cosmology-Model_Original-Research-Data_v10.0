## 5. W-field 場論 (script 19) ✅

### 5.1 F(y) 驗證

| y | F'(y) 解析 | F'(y) 數值 | match |
|:--|:----------|:----------|:-----:|
| 0.01 | 0.090909 | 0.090909 | ✅ |
| 0.10 | 0.240253 | 0.240253 | ✅ |
| 1.00 | 0.500000 | 0.500000 | ✅ |
| 10.00 | 0.759747 | 0.759747 | ✅ |
| 100.00 | 0.909091 | 0.909091 | ✅ |

**F(y) = y - 2√y + 2ln(1+√y), F'(y) = √y/(1+√y) = μ(x)** ✅

**代數驗證:**
```
d/dy [y - 2√y + 2ln(1+√y)]
= 1 - 1/√y + 2·(1/(1+√y))·(1/(2√y))
= 1 - 1/√y + 1/(√y(1+√y))
= 1 - 1/√y·[1 - 1/(1+√y)]
= 1 - 1/√y·[√y/(1+√y)]
= 1 - 1/(1+√y)
= √y/(1+√y)  ✅ QED
```

### 5.2 ∇W = Δg 驗證

```
W ≡ a₀·ln(1 + |∇Φ|/a₀)
∇W = a₀·(∇Φ/a₀)/(1+|∇Φ|/a₀) = a₀·x/(1+x) = a₀·μ(x) = Δg  ✅
```

### 5.3 ω₁ 連接

```
ω₁ = (88c/R_H)·sin(π/88) = 7.389e-18 rad/s
ω₁/2π = 1.176e-18 Hz
(ω₁/2π)/(a₀/c) = 3.1409 = 88·sin(π/88) ≈ π (偏差 0.021%)

精確: a₀ = c·ω₁/(2π·88·sin(π/88)) — 數值驗證 2.30e-16 一致!
```

**獨立驗算:**
```
a₀ = c·ω₁/(2π·88·sin(π/88))
ω₁ = 88c·sin(π/88)/R_H
→ a₀ = c·88c·sin(π/88)/R_H/(2π·88·sin(π/88))
     = c²/(2πR_H)  ✅ 恆等式!
```

88·sin(π/88) ≈ π 偏差: π²/(6·88²) = 0.0212% (理論, sin 展開第三項)
