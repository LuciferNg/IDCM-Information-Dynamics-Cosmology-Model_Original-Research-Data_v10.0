## GAMA 數據 (Wright et al. 2017, MNRAS 470, 2839)

```
雙 Schechter 擬合:
  M* = 10^10.78 = 6.03e10 Msun
  α₁ = -0.62, φ*₁ = 2.93e-3
  α₂ = -1.50, φ*₂ = 0.63e-3
```

## IDCM 預言

```
dN/dM_total ∝ M^(-4/3)·exp(-M/1.89e12)  (總重子)
M_c = 1.89e12 Msun                       (Schechter 截止)
α = 4/3 = 1.333                          (低質量端冪律)
```

## 對比結果

### 🟢 M_c 截止命中 (需 SHMR 轉換)

| 量 | 值 | 說明 |
|:---|:---|:-----|
| M_c/M*_GAMA | 31.4 | 星體形成效率 ~3.2% |
| M_c/M*_SDSS | 41.4 | 星體形成效率 ~2.4% |
| ΛCDM SHMR (Behroozi+2013) | 2-5% | 高質量端一致 ✅ |

**M_c 嘅截止位置正確，但需要星體→halo 質量轉換才能直接比較。**

### 🟡 低質量端斜率偏差 ~12%

| 來源 | α (低質量端) | 偏差 |
|:-----|:------------|:----:|
| IDCM | 4/3 = 1.333 | — |
| GAMA | 1.50 (α₂) | 12.5% |
| SDSS | 1.47 (α₂) | 10.3% |
| ΛCDM PS | 1.9-2.0 | 42-50% |

IDCM 斜率比 GAMA 低 12%，但遠遠好過 ΛCDM Press-Schechter (50% 偏差)。
可能原因：星體形成效率嘅質量依賴性 (SHMR 喺低質量端更陡)。

### 🔴 χ² 直接比較不可行

直接 χ² 比較失敗 (χ²/dof ~10¹¹)，因為：
1. IDCM 質量函數未歸一化 (只係比例形式)
2. GAMA 係星體質量, IDCM 係總質量 (差 31×)
3. 星體→halo 轉換係質量依賴嘅複雜函數

**需要質量依賴嘅 SHMR 模型才能做嚴格 χ² 檢驗。**
