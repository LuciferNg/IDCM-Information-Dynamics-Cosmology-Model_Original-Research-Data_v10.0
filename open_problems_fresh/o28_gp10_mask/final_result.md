# O28 — Planck gp10 冷斑 mask 校正

## 狀態: 🔴 已閉合（負面結論 — 冇節點對應）

## 結論
Planck 2013 第二冷斑 gp10 (l=32°, b=-8°) 喺 SMICA 中尺度 (4.17-7.0°) 唔存在任何冷結構 —
「gp10 冷斑」好可能係 Cruz 2011 Nside=16 variance/skewness 統計嘅偽影或前景驅動。
Mask 校正後冷 centroid 移離節點 (10°→18-20°)，最近節點 node21 距離 10.05° (+95.5 μK 熱)。
隨機對照確認 10.05° 完全正常 (P(≤10.05°)=0.477)。O5 結論「第二冷斑冇節點對應」更穩固。

## 關鍵公式
- gp10 位置: (l, b) = (32°, −8°), fsky = 7%
- Nside=16 var ratio: σ²_gp10/σ²_rest = **0.745**（唔係 high variance）
- Nside=16 skew: +0.125（正偏，唔係負偏 → 冇冷尾）
- 0.5° peak: (32.4, −5.5) = −215 μK → 4.17° 三地圖 −9~−17 μK（振幅崩潰 = 前景）
- Mask 校正 centroid: bcut≥10° → (38.4, −16.1), 最近 node21 = 19.7°
- 隨機對照: P(nearest ≤ 10.05°) = 0.477（銀河面條帶）/ 0.454（全天）/ 0.447（gp10 30° 內）
