# 17. G5 結果 — 矩形判據之充要刻畫（`g5-contract-v1`，2026-09-30）

## §0 一句話結論

B3R2 之可構成性判據（操作定義：存在合法 4-tuple）**已化為可計算之精確判準**：
**可構成 ⟺ ∃ 行對 `a ≠ a2` 之過濾後共同列數 `c(a,a2) ≥ 2`**（`c` 含 self-exclusion 與 anti 過濾），
在 **6,892** 個測試個案（含「4 個設定上全部 ≤ 5 對之 pair 集」之**窮盡掃描**）上與凍結暴力枚舉
**逐 case 一致、零反例**。並得**必要／充分條件階梯**：`|P| ≥ 4`、`∃deg_out ≥ 2`、`∃deg_in ≥ 2`、
**injective ⟹ 不可構成（B3R2 定理成為推論）**；`k ≥ 6 ⟹ 可構成`（`k` = raw 共同列數），
界 **`k − c ≤ 4` 且被恰好達到**（`Q = {0,1,11,10,30,31}` 給 `k = 6, c = 2`）。
**稀疏唔強制**：`rz(5) = 12`、KST 上界 `527 ≫ 21` ⟹ canonical 前綴之不可構成係**形狀**性質；
其**局部成因**亦已定位：canonical trail 前綴有 **45** 個行對共用列，但**冇一對**共用**兩**列（`raw 矩形 = 0`）
—— 唔係 anti 過濾殺死，係 trail 之**列稀疏**。

## §2 五項結構發現

1. **★ 判據可計算化（T1）**：`c(a,a2) ≥ 2` 為**充要**，且經**窮盡小族**（4 設定上全部 ≤ 5 對）＋ 7 條已知前綴共 6,892 個案逐 case 驗證、**零反例**。此後可構成性唔再需要 4-tuple 暴力枚舉。
2. **★ 必要條件階梯使 B3R2 定理成為推論**：B3R2 之「雙射前綴 ⟹ 不可構成」= 本輪必要條件 `∃deg_out ≥ 2` 之特例（`deg_out ≤ 1 ⟹` 判準恆假）；627 個 injective 前綴全部不可構成 ✓。
3. **★ 充分條件之常數 `4` 係緊**：`k − c ≤ 4`（self-exclusion 最多殺 2 列 ＋ anti 完美匹配最多殺 2 列），且由 `Q = {0,1,anti(0),anti(1),30,31}`（`k = 6, c = 2`）**恰好達到**；故 `k ≥ 6` 係保證可構成之**最低**門檻。
4. **★ 稀疏唔強制（T4）**：`rz(3,4,5) = 6,9,12` 精確（全枚舉），KST 上界 `527` 遠高於預算 `21` ⟹ 「21 條邊之無矩形集」**大量存在**；canonical 前綴之不可構成**唔可以**歸因於邊數少。⚠️ `3(n−1)` 線性模式**唔可**外推（KST 之 `n^{3/2}` 漸近 ⟹ 係小 n 現象）。
5. **★ canonical 不可構成之**局部**成因**：`euler_canonical` 之 `Σk = 45`（大量行對共用**一**列）但 `raw 矩形 = 0`（**冇**行對共用**兩**列）⟹ 主因係 trail 之**列稀疏**，而**唔係** anti 過濾（`Σc = Σk`，一個都冇被殺）；`euler_rectangle` 反例組（raw 2、`c = 2`）顯示**只要**出現一對共用兩列即可構成。**普遍性**：Eulerian 前綴之可構成性罕見（0%／19.0%／0.1%，級別已標明精確或抽樣）⟹ canonical 之不可構成係**典型**而非異常。
