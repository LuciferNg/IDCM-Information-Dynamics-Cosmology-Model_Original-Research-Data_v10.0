## §2 定義（凍結，唔准見數後改）

- **前綴** `P`：一組有序對 `(a,b)`（可含 loop，即 `b = a`；B3R2 把 loop 歸為對角污染類，但判據本身唔排除）。
- `A(P) = {a : ∃b, (a,b) ∈ P}`；`B(P) = {b : ∃a, (a,b) ∈ P}`。
- `deg_out(a) = |{b : (a,b) ∈ P}|`；`deg_in(b) = |{a : (a,b) ∈ P}|`。
- **anti**：`scripts/15.build_anti` 之逐字定義（`sgn(dot) < 0` 且 `dot² = ‖u_a‖²‖u_b‖²`，Q(√5) 精確）。凍結事實（I6）：`anti` 無固定點、每行恰 **1** 個 True、共 **31** 對。
- **可構成**：`feasible_chsh(M, den, mode='all4', P, anti, ids)` 返回 `best ≠ None`（即域大小 `dom > 0`）。
  （域 = 全部 `(a, a2, i, j)`：`a ≠ a2`、`(a,i),(a2,i),(a,j),(a2,j) ∈ P`、`i ≠ a, i ≠ a2, j ≠ a, j ≠ a2, j ≠ i`、四格皆非 `anti`。）
- **判準量**：`k(a,a2) = |{q ∈ B(P) : (a,q),(a2,q) ∈ P}|`（**raw** 共同列數）；`
  c(a,a2) = |{q ∈ B(P) : (a,q),(a2,q) ∈ P, q ∉ {a,a2}, ¬anti[a][q], ¬anti[a2][q]}|`（**過濾後**存活列數）。
- **T1 判準（本輪主張）**：可構成 ⟺ `∃ a ≠ a2 ∈ A(P) : c(a,a2) ≥ 2`。
  **凍結 ASCII 形式（供 impl 字串對齊）**：`c(a,a2) >= 2`。
- **rz(n)**：`n × n` 0-1 矩陣、無 2×2 全 1 子矩陣之**最大 1 數**（＝ no-rectangle 最大邊數，行=首座標、列=次座標）。
- **類**：`K_n*`（無 loop 完全有向圖）之 Eulerian 電路；`EC(n)` 依 BEST 定理（G4 P4 已獨立驗）。

## §3 定理（本輪要驗；兩方向都要，唔准只驗容易嘅一邊）

- **T1（充要）**：如 §2。**⟸**：兩個存活列即給出合法 4-tuple（四格子皆在 `P`，且 `q ∉ {a,a2}` ⟹ 水平／垂直相異；`j ≠ i` ⟹ 垂直相異）⟹ 域非空。
  **⟹**：若域非空，取該 4-tuple，令 `q = i, q' = j` ⟹ 兩者皆在 `c` 之集合內（同 `(a,a2)` 行對）⟹ `c ≥ 2`。
  **機器驗**：對凍結判據（暴力）逐 case 對齊（P1）。
- **T2（必要條件階梯）**：
  (a) `|P| ≥ 4`（四格兩兩相異：`a ≠ a2`、`i ≠ j` ⟹ 四個有序對互異）；
  (b) `∃ a : deg_out(a) ≥ 2`（同一行需兩列）；(c) `∃ b : deg_in(b) ≥ 2`；
  (d) **injective 前綴**（`∀a: deg_out(a) ≤ 1`）⟹ 不可構成 ⟹ **B3R2 定理（雙射 ⟹ 不可構成）成為 (b) 之推論**。
- **T3（充分條件＋界之緊）**：由 I6（anti 完美匹配）：
  (a) `c(a,a2) ≥ k(a,a2) − 4`（self-exclusion 最多殺 2 列、anti 最多殺 2 列）；
  (b) 故 `k ≥ 6 ⟹ c ≥ 2 ⟹ 可構成`；
  (c) `k ≤ 1 ⟹ 不可構成`（`c ≤ k`）；
  (d) **界緊**：`k = 2..5` 兩個方向皆有實例（可構成／不可構成）——須給出實例（P3）。
- **T4（非強制）**：小 `n = 3,4,5` 之 `rz(n)` 以**全枚舉**精確求得；`N = 62` 以 KST 上界 `≈ N(N−1)/2·√…`（具體：`n/2·(1+√(4n−3))`）作上界。
  若 `21 ≪` 上界 ⟹ **稀疏唔強制不可構成**（即 canonical 前綴之不可構成係**形狀**性質，唔係尺寸性質）。
- **T5（過濾效應）**：`k − c ≤ 4` 對全部測試前綴成立；並量化「若無過濾則可構成、過濾後不可構成」之案例數。

## §4 六格判據（每格報值 ＋ ✅／🟡／🔴）

- **P1 充要判準**：判準（T1）vs 凍結暴力枚舉，在測試集 = {5 家族前綴，G4 canonical，G4 rectangle，**以及全部合成族**（見 P2/P3 之構造 + 小矩陣族）} 上逐 case 一致。報 `一致/總數`；任何反例即 🔴。
- **P2 必要條件**：(a)–(d) 各逐 case 驗；並**重建 B3R2 之「雙射 ⟹ 不可構成」**（用凍結 `diag`／`anti-diag`／`stride` 前綴檢 deg_out ≤ 1 ⟹ 判準恆假）。
- **P3 充分條件與界緊**：(a)–(d)；報 `k ≥ 6` 之實例數、`k = 2..5` 之兩方向實例、`k ≤ 1` 之實例數。
- **P4 極值**：`rz(3), rz(4), rz(5)` 精確（全枚舉）；`N = 62` KST 上界；比值 `21 / 上界`。
- **P5 過濾效應**：逐前綴報 `Σk` vs `Σc`、`max(k − c)`、被過濾消滅之矩形對數；並驗 `k − c ≤ 4`。
- **P6 類內普遍性**：`n = 4` **全類精確**（`EC(4)` 固定首邊 = 256；配以寫死之「前綴長度」）之可構成比例；`n = 5`（若全枚舉超時：§5 之 fallback）與 `n = 62`（**必然抽樣**）用寫死 LCG 抽樣。**裁決**：精確部分 ✅／抽樣部分 🟡，P6 整體 = 🟡（除非全部精確）。

## §5 盲測窗與預註冊（見數前寫死）

1. **未見數前唔准填**：P3 之實例清單、P4 之 `rz(3..5)` 數值與上界比值、P6 之比例。
2. **抽樣規則（寫死）**：LCG `x_{n+1} = (1103515245·x_n + 12345) mod 2^31`，種子 `20260930`；
   **隨機 Hierholzer**：每步由當前點之**剩餘出邊（升序列表）**中以 LCG 均勻取一；（唔用 `random` 模組）。
   樣本數 `K = 1000`（n = 62）、`K = 1000`（n = 5）。
3. **前綴長度規則（寫死）**：`L = min(21, |E|)`（21 = G4 之預算上限，44 讀 ⟹ 3 + 20·2）；小 n 對照用 `L = min(21, |E|)` 同式。
   ⚠️ **退化申報（見數前）**：`n ≤ 5` 時 `|E| = n(n−1) ≤ 20 ≤ 21` ⟹ 前綴 = **整條電路** ⟹ 可構成性**平凡為真**（`K_4*` 已含 2×2）。故小 `n` 之非平凡類內問題**必須**另設**較短前綴**：`L_small = 5`（n = 4）、`L_small = 9`（n = 5）——呢兩個長度**見數前寫死**，唔准見數後調。
4. **fallback 規則（寫死）**：`n = 5` 之全類枚舉若超過 **600 秒** 或節點數超 **3×10⁷**，即改用 K = 1000 之 LCG 抽樣，並在 P6 明文標 🟡。
5. **P3 搜索規則（寫死）**：對 `(a,a2) = (0,1)` 及每個 `k ∈ {2,3,4,5}`，按**字典序**掃 `C(62,k)` 內之共同列集 `Q`，取**首 2000 個**候選，報「首個可構成」與「首個不可構成」之 `Q`（有則報，無則報無）。
6. **class 約定（寫死）**：電路 = 由點 `0` 出發、**首邊 `(0,1)`** 之邊序列（即 BEST 固定首邊計數之成員）。
7. **節點上限（ASCII 形式供 impl 對齊）**：`30000000`。
