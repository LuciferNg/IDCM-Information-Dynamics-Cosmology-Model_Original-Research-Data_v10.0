## §2 CHSH 全表（精確有理數；`|S| = |E(a,b) − E(a,b′) + E(a′,b) + E(a′,b′)|`）

| 統計量 | E1（共同 λ 對照） | E2（史機器） |
|---|---|---|
| `raw`（無約束） | **4** argmax `(E27,E28,V01,E28)` | **4** argmax `(E27,E28,V10,E27)` |
| `distinct`（`a≠a′`、`b≠b′`）| **4** argmax `(E27,E28,V01,E28)` | **4** argmax `(E27,E28,V10,E27)` |
| `distinct + antipodal-free` | **4** 同上 | **4** 同上 |
| **`all4`（四 setting 兩兩相異，六對約束）** | **2** argmax `(V00,V01,E00,F06)` | **3** argmax `(E27,E28,V01,E29)` |

**關鍵解析（唔可以含混）**
1. `raw`／`distinct`／`distinct+anti` 之 **4** 係**對角 artifact**：該 argmax 有 `b′ = a′ = E28`，
   令和式中出現**對角項** `C[E28][E28] = +1` EXACT —— 而 `+1` 是 **memo 命中律**（同 ctx 第二讀唔寫世界）
   之直接後果。物理上冇任何相關可以恰為 `+1`（對任何方向），故此 4 **唔係**任何物理超額。
2. **最嚴統計量 `all4`** 排除 `a′ = b′` 等跨翼重合 ⟹ E1 = **2**（`≤ 2` ✓ 符合 LHV；亦係本輪**唯一**對
   P1 之有效檢驗）而 E2 = **3 > 2** ✓ **真超額**（argmax `(E27,E28,V01,E29)` 四 setting 兩兩相異）。
3. 故 **E2 ≠ E1 之差異**唔係 λ 分佈（`p_k ≡ 均勻`，已證）而係 **ledger 狀態**：E2 之四項讀自**唔同歷史位置**，
   各自之 ledger（live ctx）唔同 ⟹ 同一「狀態分佈」下機器之**轉移與取值**唔同 ⟹ 四項唔可以由單一共同 λ 聯合表示
   ⟹ Bell 前提（共同 λ）**失效** ⟹ `|S| > 2` 成為可能並實際發生。
