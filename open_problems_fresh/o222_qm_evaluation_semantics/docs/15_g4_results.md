# 15. G4 結果 — 讀取次序之結構導出：**Eulerian 類**（`g4-contract-v1`，2026-09-30）

## §0 一句話結論

**讀取次序由凍結結構導出 = memo 有向圖之 Eulerian 類**（唔係單一次序：`EC(62)` 有 5187 位）。
類內**每邊 2 讀**、全電路 **7565** 讀乃**結構強制**（T2）；類內**公平度 ≤ 1**（P6）。
在 B5 預算（44 讀／pass）下，**無 loop 之最大對數 = 21**（3 + 20·2 = 43 讀），Eulerian 電路**恰達此上界**——
而 B3R2 五條人為家族中最好者（`lex`／`stride`／`antidiag`）只有 **15** 對（全屬浪費；`diag` 之 22 對係**全對角**，
結構上**不可用於 CHSH**）。canonical 前綴在矩形判據下**不可構成**，但**存在**一條 Eulerian 電路其前綴含 2×2 矩形，
其 `all4` = **13/15 < 2** ⟹ **最優性同可量測性可以並存**（上限 21 對），且**仍然冇 Bell 違反**。

## §2 三項結構發現

1. **★ 結構強制 = 次序「類」，唔係次序**：由成本律（P1 精確）可得：一條**無 loop**邊要省一個讀，唯一途徑係**第一個 read 命中** ⟹ 需 `t = a` ⟹ 即「下一對之尾 = 上一對之頭」⟹ **Eulerian**。
   故「最優 ⟺ Eulerian」係**結構等價**（T2(iii)，`n = 3` 全枚舉反例 0）。但 `EC(62) ≈ 10^5187` ⟹ 結構**只**逼出類；
   **唯一性問題係「類內代表之自由」**，唔係結構欠定。B3R2 五大家族**皆非** Eulerian（P6 公平度大）：即人為次序**唔係類之成員**。
2. **★ 上限 21（無 loop）由成本律＋預算共同逼出**：首對 ≥ 3 讀、其後每對 ≥ 2 讀 ⟹ `k` 對 ≥ `3 + 2(k−1)`；
   `45` 讀 = `5535/88 = 62.897 > 61.5` ⟹ **22 對不可能**；`43` 讀 = `5289/88 = 60.102 < 61.5` ⟹ **21 對可行**（Eulerian 實測正是 21）。
   `diag` 之 22 對 = 44 讀**全部係對角（loop）**，故其「多一對」係**用結構上不可參與 CHSH 之對換返嚟**。
3. **★ 最優性 ⊥ 可量測性（類內可並存）**：canonical 代表**不可構成**（trail 稀疏），但類內**存在**含矩形之成員（P5b），
   且 `all4` = 13/15 **< 2** ⟹ 兩約束（Eulerian ＋ 2×2）**唔互相排斥**，上限同在 21 對；而 22 對**必然**含 loop ⟹ 結構上**唔可能**「22 對 ＋ 可構成」。**仍然冇 Bell 違反**（與 B3R2 一致）。
