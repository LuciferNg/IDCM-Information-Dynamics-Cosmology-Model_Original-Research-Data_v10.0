## §1 L-SEQ：動態機器（狀態機，寫死；唔准改）

### 1.1 世界態與 h 表（結構性、唯一）

```
World state   G ∈ 2I              # 精確四元數，Q(√5) 上；一條連續世界線
Read operator h(ctx) ∈ 2I         # ★ 由結構唯一決定，見下
h 之指派：對每條凍結軸 u_ctx，取 2I 中「階最小」且其 3-向量部分 ∥ u_ctx 之元素；
          同階多個 ⟹ 取正規化後 (P,Q) 整數四元組字典序最小者。（階：V 類 5、F 類 3、E 類 4 ⟹ 旋轉階 5/3/2）
```

- ⚠️ **一致性硬檢查**：`scripts/08` 必須由零重建 2I（`|2I| = 120`、unit、逆閉）並**逐字重現** `data/04_b2_settings.json`

  重現失敗 ⟹ 合約 FAIL，禁止出數。

### 1.2 三個基本操作（凍結；精確算術，零浮點）

```
read(ctx):
    if L 之 live 條目之 ctx == ctx:              # ★ memo 命中（R1 D1-b：命中 ≡ 冷算，值相同）
        return live 條目之 value                 #   命中 = 唔重複寫入（單值律；此即令演化非純平移之關鍵）
    v  ← K(G, ctx) = sign( u_ctx · (G n̂) )      # 逐字複用 docs/03 之 H2/H3（含平局規則）
    L.append( (ctx, v, G) )                      # memo 條目：記低讀取當時之世界態（容量 1）
    G  ← G · h(ctx)                              # ★ 讀取＝寫入：世界沿該軸推進
    n_reads += 1 ; n_writes += 1
    return v

rollback():
    (ctx, v, G_at) ← L.pop()                    # 撤銷 memo 條目
    G ← G_at                                    # 精確還原（等價 G·h(ctx)⁻¹；單值、無浮點）
    n_rollbacks += 1
    return (ctx, v)

reconcile(ctx):                                 # R1-B5「回滾 = memo 撤銷 + ctx 重入」之機械化
    rollback(); v2 ← read(ctx)                  # 重入；單值 ⟹ v2 必等於被撤銷之值（此點本身係檢查）
    return v2
```

### 1.3 Run protocol（凍結）

```
一個 pass = 依 docs/03 §1.2 之凍結枚舉次序，走全部 3844 有序對 (a,b) 一次。
每個對：(1) x_a ← read(a)   (2) x_b ← read(b)   (3) reconcile(b)
        ⟹ 淨效果：世界線每對推進 h(a)·h(b)；reconcile 之作用係證明「該對只可於此序重現」
           （逆序 = 另一個對 (b,a)，值一般唔同 ⟹ Δ_order ≠ 0 係預期結構現象）
pass 之起始世界態：g_r = 由 seed 222 之 splitmix64 抽 index ∈ [0,120)，
        以整數拒絕採樣（rejection）保證精確均勻；g_r 之抽樣**與 setting 無關**。
```

- **H13**：`n_passes R = 1000`（E1/E2 共用；E2 另報 R = 1 之單條長世界線作診斷）。
- **H14**：seed = **222**（與 B2 之 H9 同 seed，便於對照）。
- **H15**：抽樣 = splitmix64（純函數、無 import 狀態）＋ 120 整數拒絕採樣。

### 1.4 兩個估量器（**皆預註冊、皆必須全報**）

| 估量器 | 世界線 / λ | 定義（**精確可算，非取樣**） | 結構類 |
|---|---|---|---|
| **E1（共同 λ）** | 每個 pass 重抽，G_0 ~ 均勻(2I) | `C1[a][b] = (1/120) Σ_{G∈2I} K(G,a)·K(G·h(a), b)` | λ = G_0 之分佈與 setting 無關 ⟹ **LHV ⟹ `\|S\| ≤ 2` 可證**（自檢用） |

**精確性說明（H17）**：世界態空間只有 120 個元素 ⟹ 全部量皆**精確**可算：
`p_0` = 均勻；每對 (a,b) 之狀態轉移為確定性映射（含 memo 命中 ⟹ **非純平移**）⟹ `p_{k+1} = p_k ∘ T^{-1}` 精確推進。
**定理級觀察（跑前已知）**：若演化保持均勻（純平移），則 `p_k ≡ 均勻` ∀k ⟹ **E2 ≡ E1** ⟹ 亦 ≤ 2。
故 E2 之全部內容 = **memo 命中令演化非純平移**所致；此點唔係參數，係結構。

**H18（E2 之 λ 診斷，必須全報）**：四個時期各自之 `p_k` 統計（max/min/變異）、`p_k` 與均勻之 L1 距離、
每時期 marginal `P(x=+1)`。
**H19（MC 交叉核對）**：E1 另以 R = 1000 個 pass 之經驗值核對（必須與精確值一致至 MC 誤差）；
E2 另以單條長世界線（R = 1）之確定性軌跡核對符號。
**H20（null 預算）**：null ① 10³ draws（隨機軸＋隨機 h 指派，精確 E1/E2 表）② 枚舉次序置換 200 draws
