# O222 — R21/N1 合約：秩 3 實現之**剛性**（`n1-rigidity-v1`）

**於任何 N1 數字之前寫定。** 前置事實（已認證）：`sign_rank(K) = 3` EXACT（R20/M3 上界＋M7 組合排除）。
**問題**：600 個認證候選（`data/40_candidates.json`，1e-4 整數格）係**同一組合型**（剛性），抑或各異（柔性）？
若剛性 ⟹「秩 3 實現之結構來源」係 well-posed 問題（存在唯一（至對稱）典範構型可供辨識）；若柔性 ⟹ 需另尋不變量。

## 判定（機械、精確整數）
- 每個候選：`U`（120×3 整數）→ 12 個列類型之代表（取每類首個索引）→ 計
  `gram_sign(i,i') = sgn(u_i·u_{i'})`（12×12，對角為 +）；
- 同法計 `V`（62×3）之 `vsign(j,j') = sgn(v_j·v_{j'})`（62×62，對角 +）。
- 統計：全部 600 候選中 `gram_sign` 之**相異型數**、`vsign` 之相異型數；另報「12 代表之兩兩內積號」與 K 之關聯（對照組）。
## 判定語言
✅ 剛性 = 相異型 1 且非退化；🟡 = 型數少但 > 1；🔴 = 型數多（柔性，無唯一構型）。
## 界線
候選來自浮點發現協定（格化 1e-4），故剛性陳述僅在**該族**內成立；非對全部秩 3 實現之證明。

## N1 結果（`n1-rigidity-v1`，全部精確整數）

由 `data/40_candidates.json`（600 = 每 r 200）分 r 統計，對每候選取 U 之 12 個列類代表：

- **r = 3（200 候選）**：`gram_sign`（12×12）相異型 = **1 種（200/200 全同）**；`vsign`（62×62）相異型 = **1 種（200/200 全同）**。
- r = 4：Gram 型 93 種（最大重數 75）；`vsign` 200 種。
- r = 5：Gram 型 107 種（最大重數 61）；`vsign` 200 種。
- 全部 r 之候選皆有**恰好 12 個列類型**（＝K 之 12 個）✓（前一版統計把 r = 4/5 以 3 維截斷計算，屬實作錯，已修正為按 r 用全維）。

**判定：✅ 剛性。** 秩 3 實現（200 次獨立發現、不同種子、不同重啟）**組合型唯一**：12 點之 Gram 號差型與 62 平面之號差型**完全不變** ⟹ 該構型至對稱唯一。
**推論**：（i）「秩 3 實現之結構來源」係 **well-posed** 問題（有唯一典範構型可辨識）；（ii）r = 4／5 之柔性顯示 **3 為最小且剛性之秩** ⟹ 與 `sign_rank(K) = 3` EXACT 一致且互相加強。

**界線**：剛性在 200 候選族內成立（浮點發現＋1e-4 格化＋精確認證）；非對「所有」秩 3 實現之形式證明（下一步 N2 可由**代數辨識**該唯一型，或以**對稱性論證**封口）。
