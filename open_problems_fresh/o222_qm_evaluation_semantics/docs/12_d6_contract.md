## §0 範圍與聲稱上限（先寫死）

**問**：IDCM 之 lazy 求值層（thunk／force／memo／sharing）與 QM 之四類對象（態／測量／記錄／糾纏）之間，**存在嘅係咩結構對應**？

**方法論鐵律（本輪核心）**：
1. **唔接受名詞字典**。表格每一格必須由 ①**已凍結物件**（附所有者、可獨立重跑）＋ ②**可計算之結構謂詞**（定義於 §2，判 ✅／🟡／🔴 **機械可判**）＋ ③**量到嘅數字** 三件齊備支持。
2. **禁自創語義**：不得發明新映射（尤其 **G1 之 `ctx → s` 明文禁自創**）。缺項如實報 🔴。
3. **判據先於數字**（§2 於跑之前凍結）；唔准事後改謂詞、改門檻、只報靚格。
4. 聲稱上限：**唔**宣稱導出 QM／Hilbert 空間／複內積／Born 律／量子非局域；本輪只判「**結構對應之有無**」，並明寫每格**缺咩**。

## §2 謂詞表（**見數前凍結**；四組共 16 格）

**判據定義（機械可判）**：
- **✅** = 謂詞對**全部**測試實例成立，且對應物為已凍結物件；
- **🟡** = 部分成立，**或**成立但缺少 QM 側之**必要**結構成分（須明寫缺咩）；
- **🔴** = 被否證／唔存在（須附反例或「唔存在」之檢查方式）。

### P1 — thunk ↔ 態

| 格 | 謂詞（可計算） | 判據 |
|:-:|:---|:---|
| **P1a** | G 對 𝒜 之**軌道分解**恰為 `{12, 20, 30}`，且**與 `type` 標籤逐一相符**（即 `type` 係 G-不變）| ✅ ⟺ 軌道數 = 3 且大小多重集 = `{12,20,30}` 且每軌道型別單一 |
| **P1b** | **態轉移之確定性＋可逆性**：對每個 a，映射 `s ↦ MUL[s][h(a)]` 係 2I 上之**雙射**；`read` 之值由 `(s, ctx)` 唯一決定 | ✅ ⟺ 62/62 皆雙射 |
| **P1c** | **合成律**：存在張量積型合成結構（引用 𝒯 = K_chain ⊗ K_tree）| ✅ ⟺ 上游檔案明文寫出該積結構（provenance）；**(ii) 維數自洽**若上游**冇載維數** ⟹ 降為 **🟡**（明寫「維數不可獨立核」）|

### P2 — force ↔ 測量

| 格 | 謂詞（可計算） | 判據 |
|:-:|:---|:---|
| **P2a** | **重讀幂等**：同一 `(s, ctx)` 連讀兩次 ⇒ 同值（memo 命中律）| ✅ ⟺ **120×62 = 7440/7440** 全中 |
| **P2b** | **歷史（語境）依賴**：存在 `(s₁,s₂)` 使 `K[s₁][ctx] ≠ K[s₂][ctx]`（值非僅由 ctx 決定）| ✅ ⟺ 歷史敏感 ctx 數 ≥ 1（並報數）|
| **P2c** | **不可逆性**：`rollback` 還原 `s` 但 **ledger 只增不減**（無刪除操作、無就地改寫）| ✅ ⟺ 全 pass 內 ledger 長度單調不減且 `read` 從不改寫既有項 |
| **P2d** | **機率結構（Born 型）**：值集是否為非負歸一權重／是否符合 `0 ≤ p ≤ 1 ∧ Σp = 1` | ✅ ⟺ 有 Born 型機率；實測 C1 為**簽名關聯**、逐列和 = 0 ⟹ 預期 **🔴**（須報值集與列和）|

### P3 — memo ↔ 記錄

| 格 | 謂詞（可計算） | 判據 |
|:-:|:---|:---|
| **P3a** | **append-only ＋ 一致性**：全 pass 內每次 push 之 `(ctx, v)`，其後任何命中返 `v` 皆一致 | ✅ ⟺ 全 pass 零不一致 |
| **P3b** | **穩定性（classicality）**：已寫入項之值**永不改變**（後續任何操作）| ✅ ⟺ 逐項檢查通過 |
| **P3c** | **冗餘度／可及性**：記錄之可及深度（`read` 只查頂項 ⇒ 冗餘度 = 1）| ✅ ⟺ 冗餘度 ≥ 2（QM 側要求環境冗餘）；實測 = 1 ⟹ 預期 **🔴**（明寫「單副本記錄，無環境冗餘」）|

### P4 — sharing ↔ 糾纏

| 格 | 謂詞（可計算） | 判據 |
|:-:|:---|:---|
| **P4a** | **非因式化**：`rank_ℚ(C) > 1` ⇒ 唔可以寫成兩邊函數之積（`u ⊗ v`）| 報 `rank_ℚ(C1)`、`rank_ℚ(C2)`、另報 `rank_ℚ(C1_rev)` 與對蹠表；✅ ⟺ 秩 > 1 |
| **P4b** | **CHSH**（引 B3R2，唔重推）| 引 **B3R2** 之權威值：預算內乾淨 `all4` = 16/15、13/15 < 2；無限制 2／3 ⟹ **🔴** 無量子超額 |
| **P4c** | **no-signalling**：逐 setting 之條件 marginal = **1/2 EXACT**（3844/3844），且逐列和 = 0 | ✅ ⟺ 全部精確成立 |

## §4 禁區

1. **唔准**以名詞對應（「thunk 就係態」）當 ✅；每格必須有謂詞＋數字。
2. **唔准**自創映射（G1 之 `ctx → s` 明文禁）；缺項報 🔴。
3. **唔准**事後改謂詞／門檻／判據（改動須走 §6 amendment ＋重凍 ＋保留首跑 log）。
4. **唔准**只報部分格（16 格全報）。
5. **唔准**把「成立」升級為「導出 QM」；結論只可講**結構對應**。
6. CHSH 只**引** B3R2，唔重推；若需數值，以 `data/15_b3r2_results.json` 為準。
