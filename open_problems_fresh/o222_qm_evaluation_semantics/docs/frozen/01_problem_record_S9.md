## 一、問題陳述

O221 已把 IDCM 之離散代數 𝒯 推向連續極限，並在 QM 側得出一個**否定式**結論：

**調律者診斷（2026-09-29，原文要點）**：
> 「O221 是把 IDCM 連接到 GR，現在是時候開辟新戰線 O222，目標就是 QM … 而最大問題就是 IDCM 只有 Lazy Load，沒有疊加態，必需要把 Lazy Load 機制解出來才能連接 QM，什麼時候基於什麼會確定為粒子態，基於什麼會確定為波動態，什麼是量子態，自洽性回滾的機制又是什麼，然後才是考慮兩者之間的連接通道。」

**核心問題（四問）**：

```
Q1  粒子態 / 波動態之判定準則 — 「基於什麼、什麼時候」一個延遲項被確定為粒子態或波動態？
    （要求：準則必須係結構的（由 𝒯 + 已有不變量導出），唔可以係時間觸發 / 外部條件）

Q3  自洽性回滾機制 — 強制失敗時點算？回滾之觸發條件、邊界（預算）、窗口（時間粒度）係咩？
```
