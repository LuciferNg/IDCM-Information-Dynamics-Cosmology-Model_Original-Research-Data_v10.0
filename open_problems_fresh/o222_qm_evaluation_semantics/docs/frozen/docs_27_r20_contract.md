## §3 八項判定格

### M1 —「fooling set ⟹ sign_rank ≥ t」蘊含關係之審計
- **謂詞**：(a) K 之 5 對見證子矩陣在**值上** = `2I − J`（精確）且 `rank(2I−J_5) = 5`（精確行列式 = −48）；(b) 機械展示**反例族**：存在 3×3 實矩陣 `M`，全部對角 > 0、全部非對角 < 0、而 `det M = 0`（精確有理驗證）。
- **判準**：若 (b) 成立 ⟹「對角正／非對角負 ⟹ 非奇異」**假**，故 R19 由 fooling set 推 `sign_rank ≥ t` 之步驟**無效** ⟹ 報 **🔴（對該蘊含）**；同時須給出**有效替代**：fooling set 僅證明 `rank_R(K) ≥ 5`（子矩陣秩 ≤ 矩陣秩）。
- **禁**：以「文獻慣例」代替證明；若無法證明蘊含有效，一律報 🔴。

### M2 —`sign_rank(K)` 之**有效**下界（只接受可證命題）
- **謂詞**：逐項檢定下列工具並取其**最大有效值** `L_max`：
  1. **秩 1 排除**：若 `sign(B) = K` 且 `rank B = 1`，則 `K = σ τᵀ` ⟹ `rank_R(K) ≤ 1`；實測 `rank_R(K) = 6` ⟹ `sign_rank ≥ 2`（有效）。
  2. **arrangement 計數界**：`sign_rank = r` ⟹ 相異**列**數 ≤ `2 Σ_{k<r} C(m−1,k)`（`m = 120`）、相異**行**數 ≤ `2 Σ_{k<r} C(n−1,k)`（`n = 62`）。逐 `r = 2..5` 檢定是否排除。
  3. 明確記錄：R19 之「≥ 5」**不**列入 `L_max`（依 M1 為無效）。
- **判準**：`L_max` 由**逐項精確**計算得出；本格報 ✅ 若全部檢定可機械重跑（數字本身可小；**禁止**為求好看而放入未證命題）。
- **誠實條款**：若 `L_max < 5` ⟹ 必須在結果文檔首段明寫「R19 之 `∈ [5,6]` 之下界**被下修**為 `[L_max, 6]`」。

### M3 —`rank-r` 符號實現之**構造搜尋**（唯一真缺口正面攻擊）
- **凍結發現協定**（只可**提出**候選；成立與否由 §2 精確機器裁決）：
  - 目標函數 `f(U,V) = Σ_{i,j} exp(−K_ij·(U Vᵀ)_ij)`，`U ∈ R^{120×r}`、`V ∈ R^{62×r}`。
  - 最佳化：Adam，`lr = 0.01`，`steps = 4000`，`restarts = 200/每 r`，初始化 `N(0, 1/r)`；
    種子 `numpy.random.default_rng(20260930 + 1000·r + k)`，`k = 0..199`（**協定凍結**）。
  - `r` 依 **5 → 4 → 3 → 2** 次序（先取最大可能之改進）。
  - 接受條件（浮點，只決定「值唔值得精確驗」）：`min margin ≥ 1e-3`。
  - 候選轉整數：`w → round(w·10⁴)/10⁴`（分母 ≤ 10⁴），輸出至 `data/40_candidates.json`（附協定參數與種子）。
- **認證（`scripts/41`，精確）**：對每個候選，以 `Fraction` 精確重算全部 **7440** 個符號；須**逐個**嚴格非零且等於 `K` ⟹ 認證 `sign_rank(K) ≤ r`。
  - 亦須精確認證**實現矩陣秩** `rank(U Vᵀ) = r′`（精確有理消元），報 `r′`（允許 `r′ < r`，此時以 `r′` 為上界）。
- **判準**：✅ 若存在**已認證**之 `r < 6` 構造（附證書與精確數字）；🔴 若全協定跑完而**無**任一候選通過精確認證（須記錄嘗試總數、最好 margin、時間）。
- **禁**：把「搜尋唔到」講成「唔存在」；**禁**以浮點 margin 當結論。

### M4 —Q5c 殘差之**精確極小多項式**
- **物件**：`G = Σ_{n=28}^{44} (ζ₈₈ⁿ + ζ₈₈^{−n}) ∈ Z[ζ₈₈]`（首 6 個係數須逐字吻合 R19 記錄 `[−3,−2,−2,−2,0,0]`；`Tr_K(G) = −40`）。
- **謂詞**：精確構造 `P(X) = Π_{a∈Gal/K}(X − σ_a(G)) ∈ Z[X]`（`deg = 20`），並機械驗證：
  1. `P(G) ≡ 0 (mod Φ₈₈)`（精確整數多項式）；
  2. 20 個共軛**兩兩相異**（`Z[x]/Φ₈₈` 內精確不等式）；
  3. 首項係數 1；`[X¹⁹]P = 40 = −Tr_K(G)`；
  4. `P` 之係數全為**整數**（由 `c_k = Tr_abs(h_k)/40` 導出，導出值須為整數，否則報錯）。
- **判準**：✅ 若 1–4 全成立（此時 `P` = `G` 之極小多項式，因 `deg P = 共軛軌道大小 = 20`）；否則 🔴。

### M5 —G1 override 機制之**值層定理**（取代兩項被否證之預測）
- **謂詞**：以凍結配對協定（P2 語意之**獨立重寫**、經 P8 逐對未命中比對 0 mismatch）對全部 **120** 個起始態精確枚舉，並把 override **分兩類**：
  - 類 A：**首讀**命中（memo 頂 `ctx` 相符）而回傳值 ≠ 正確值 `K[s][ctx]`；
  - 類 B：**回滾後重讀**命中而回傳值 ≠ 正確值 `K[s][b]`。
  機械輸出：每態 `(A, B, A+B)`；並檢定 (i) `A+B` 之全域集合 = R19 掃描集合（`s0=0 → 58`、範圍 `[55,81]`、`=65` 恰 10 態）；(ii) `min A ≥ 1` 且 `min B ≥ 1`（**兩路皆載**為協定之必然，非偶然）。
- **判準**：✅ 若 (i)(ii) 全中（附逐態表）；🔴 否則。機制陳述須寫成**可機械重跑的句子**（「override ⟺ 命中且 memo 頂之寫入態 ≠ 當前態」），並以枚舉數據驗證而非敘述。

### M6 —G4 類內代表之**結構選擇子**
- **謂詞**：由 P6 取五個凍結次序之**總讀數**（整數）；計算最小值之**達成集合**。
- **判準**：✅ 若最小值**唯一達成**（此時代表由「最小總讀數」此一不變量**唯一決定**，且該不變量為凍結成本律所定義）；🟡 若並列（則代表確為約定，須寫明）；判定後須在結果文檔標明「**唔係**協定強制，而係以成本律為選擇子」。
