## §2 格與謂詞

- **K1（`sign_rank(K)` 之精確值）**：三個子塊必須同時成立 ⟹ ✅
  ① **rank 上界證書**：由 120×62 之 `K` 選 6 條獨立列，以 `Fraction` 解出一個 6×6 可逆子式後，
     **逐列精確驗證**其餘 114 列皆為該 6 列之有理線性組合 ⟹ `rank_R(K) ≤ 6`（**精確有理算術**）。
  ② **fooling set ≥ 6**：顯式構造 6 對 `(s_k, a_k)`，滿足 `K[s_k][a_k] = +1` 且 `k ≠ l` 時
     `K[s_k][a_l] = −1` ⟹ 依 fooling-set 引理 `sign_rank(K) ≥ 6`。
  ③ `sign(K) = K`（`K` 本身係 ±1/0 矩陣）⟹ `sign_rank(K) ≤ rank_R(K) ≤ 6`。
  ⟹ **`sign_rank(K) = rank_R(K) = 6` EXACT**。
- **K1b（amplitude 尖銳化）**：由 K1 之等式推出：**任何** rank 因式分解皆 ≥ 6，且實數分解已達 6
  ⟹ 複（amplitude）模型**無 rank 優勢** ⟹ 「amplitude 缺口」**唔係** rank 現象。
  **謂詞**：K1 三塊全成立 ⟹ 本格 ✅（**推論格，非新計算**）。
- **K2（C2 一般閉式）**：**命題** `hits = #reads − #ledger_entries`（每次未命中恰寫 1 條、命中寫 0 條）。
  由 L4 之 `replay_protocol` 全 pass 重算三者，並驗 `#entries = 2N(N−1) = 7564`、`#reads = 2×3844 = 7688`
  ⟹ `hits = 124` **精確**。推廣式：`hits(full pass) = 2·#pairs − 2N(N−1)`。
- **K3（G1 語義修訂形式化）**：把 D5 之自洽檢查由**狀態層**改為**值層**：
  `R_rev(G, ctx) := (memo_v[ctx] == sgn(u_ctx · (G n̂)))`。**定理**：`R_rev` 可由凍結記錄**判定**
  （值比較；唔需 `ctx → s` 之自創映射）。**量化＋機制檢定**：
  ① 全 pass 命中數重算（應 124）；② override 數重算（stored ≠ fresh，應 65）；
  ③ **機制檢定**：逐個 override 檢查其是否為**回滾後**之命中（rollback 只彈 ledger、**唔回退 memo**
     ⟹ memo 頂為 stale）；**謂詞**：**全部** 65 個 override 皆為回滾後命中，**且**非回滾後之命中
     一個都唔 override ⟹ ✅（否則如實報 🔴）。
- **K4（G8 冗餘判準）**：區分兩種冗餘並各自量化：
  `R_det` = 由 `(協定, 輸入序列)` **決定性重建** ledger 之份數（重建必須 0 mismatch）；
  `R_indep` = 凍結記錄中**互相獨立**之副本數。**判準**：冗餘「有信息」⟺ 副本**非**決定性相關。
  **謂詞**：① 重建 0 mismatch；② `R_det = 2`（trivial）；③ `R_indep = 1` ⟹
  **`R ≥ 2` 在「獨立副本」義下仍失敗，但缺口性質精確化為「架構，非算術」**（🔴 維持，前提寫明）。
- **K5（Q5c 成因）**：**命題**殘差 `= 123/2 − Σ_{n=28}^{44} γ_n`，而譜和
  `Σ_{n≥28} γ_n = 4[(17/2) − C/2]`，`C = Σ_{n=28}^{44} cos(πn/44)`。**謂詞**：
  ① 有理骨架精確：`|{n ≥ 28}| = 17`、`4×(17/2) = 34`、`Σ_{n=1}^{44} γ_n = 90`（表值，≤1e-9）；
