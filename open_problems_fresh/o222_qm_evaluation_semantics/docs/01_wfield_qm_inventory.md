## 四、Bell 不等式：定位為本 O 之核心戰場

### 4.1 為何 Bell 係唯一未做且最難者
- 語料 0 命中（W13）：**IDCM 從未處理 Bell / CHSH / EPR / 糾纏 / 無信號**。
- 其他 QM 疑難（測量佯謬、路徑積分、Born、退相干）**已由 W-field 相關 O 計算**（W1–W12），可引用並已在本輪驗證。
- Bell 唔可以靠引用解決：佢要求「**相關函數本身**」同「**反事實聯合分佈之存在性**」——兩者都係 IDCM 從未寫低嘅物件。

### 4.2 結構論題（候選，🔴 未驗證）
Bell 定理之前提有三：① 定域性 ② **反事實確定性**（counterfactual definiteness：每個 setting 之結果**預先存在**）③ 自由選擇。IDCM 之延遲求值語言對 ② 給出**類型級**否定：

```
未強制之延遲項 T 冇「值」。
「若改量 a′ 會得咩」= 一個從未被強制、亦唔會被強制嘅項
                      ⟹ 唔係「未知」，係【未存在】。
⟹ 反事實聯合分佈 P(A_a, A_a′, B_b, B_b′) 在 lazy 語言中【唔存在】（ill-typed），
   而 Bell 不等式之推導必須有此聯合分佈。
```
⚠️ **但呢個逃逸必須係「貴」嘅，唔可以係 cheap**：
- 若只係「值隨機、讀時才抽」= 標準 hidden-variable model ⟹ **仍然滿足 Bell**（classical bound 2）。隨機性本身唔能違反 Bell。
- 真正嘅逃逸點 = **相異 setting 之讀取算子不能共存** —— 呢個正好接上 D2 判準 C1：`ℓ_read ≥ 3`（Aut-破缺、分辨節點）之讀**唔可以兩個同時 memo 一致**（因為兩者都要分裂 120 對稱，而分裂方式唔同）。⟹ **粒子化機制（C1）與 Bell 違反機制係同一個**（候選，🔴）。
- 另一條要證：**共享 ≠ 傳播**。call-by-need 之 sharing 係語義（同一 thunk 之兩消費者），唔係動力學（冇 propagator）⟹ 無信號候選定理（memo 一致性 ⟹ 邊際分佈與對手 setting 無關）。
