# 21. G1 + G8 結果 — 缺口可否由凍結記錄推導（2026-09-30）

## §0 一句話結論

**G1 之缺口唔係「映射唔存在」，而係「層次讀錯」**：`ctx → s` 可以由凍結寫入規則**逐字讀出**
（`s_coord(ctx) = idx[h(ctx)]`，62/62 單射、7440/7440 行為核對零不符）；代入 D5 之觸發
`|N(s) - s| > 0` 後，觸發量**平方範數 ∈ {2, 3, 5/2 + √5/2} 精確三分**且**只依 ctx 唔依 s**
⟹ 觸發在全部 7440 步成立 ⟹ **D5 之字面自洽回滾會拒絕每一次 memo（空轉）**，即該層之語義必須改讀為
**值層**。**G8 之冗餘分層**：ledger 條目 **7564 = 62 × 122 完全均勻**（120 個起始態皆同）但
**R_consistent = 1**（62/62 ctx 皆有**衝突**副本 ⟹ stale 唔算冗餘）；唯一多重性（K 行 10 重簡併、
2I orbit {12,20,30}）**全部不可觀測** ⟹ **R ≥ 2 失敗（🔴 維持）**。

## §2 四項結構發現

1. **★ `ctx → s` 唔需要自創**：凍結寫入規則本身**就係** ctx 索引之態映射
   （`read (miss) ⟹ s := MUL[s][h(ctx)]`，`scripts/09`／`scripts/12` 兩份凍結源逐字並存）。
   ⟹ 舊判定「唔存在於凍結記錄」係**可修**嘅：映射存在，**缺口在語義層**。
2. **★ D5 觸發之量 = orbit 不變量**：`|N(s) - s|²` 之三值分類
   `5/2 + √5/2`（12 個 ctx）／`3`（20 個）／`2`（30 個）**恰好**＝2I 對 62 軸之三軌道
   `{12, 20, 30}`（審計以**精確 tuple 鍵**獨立重算軌道閉包，partition **完全相等**）。
   ⟹ 鎖距**只係軌道標籤**，唔係逐軸自由量；同時解釋「只依 ctx」。
3. **★ 冗餘 ≠ 多重性**：ledger 內同一 ctx 有 **122** 條副本，但**衝突**（`+1` 與 `−1` 並存）遍及
   **全部 62** 個 ctx ⟹ 副本**互相矛盾** ⟹ **R_consistent = 1**。另一方面，態空間有 **10 重
   K 行簡併**（`{10: 12}`）＋軌道多重性，但**不可觀測**、且**唔係獨立 fragment** ⟹
   **唔構成 QM 之環境冗餘**（`R ≥ 2`）⟹ **D6 P3c 之 🔴 維持，但成因由「無副本」精確化為
   「副本唔一致、多重性不可觀測」**。
4. **★ ledger 長度有閉式**：全 pass 後 ledger = **2N(N−1) = 7564**，且**每個 ctx = 2(N−1) = 122**
   —— 120 個起始態**完全一致**（均勻性精確成立）；並有恆等式
   `124（2-miss 對數）= 命中數`、`Σ(misses − 1) = 7564`。
