> 2026-09-08 | scripts/10 = 500 trials/family, FULL stride-2 | 閉合 docs/05 開放項 5

## 1. 方法

scripts/05 用 uniform 密度解析估計 (低估 γ-比密集區背景)。升級:
- **p_global**: 家族全域均勻抽 500 個隨機 target, 3σ 窗內命中 ≥ 實際嘅比例
- **p_loc (位置條件化)**: target 附近 ±10×3σ 抽樣 — 問「若家族喺 target 附近有密度, 隨機鄰近 target 會唔會都中?」— 修正簇集區域誤判

## 3. 誠實方法論修正 (重要)

- **p_loc = 0.51 (m_W/m_Z|O88)**: O88 喺 0.8814 附近有普通密度 — 隨機鄰近 target 有 ~50% 機會都搵到 ≥1 個 3σ 窗命中 ⇒ **raw scan 嘅「唯一性」全球輕微 (p=0.014)、局部屬預期** — 單靠 raw scan 應該評 🟡
- **維持 🟢 嘅理由 = O158 結構先驗 + 精度**: 唯一 3σ 窗格**就係** (21,24) 結構對 (21 = F₈ = C(L₄,2) = K_tree−dim(G_SM), 24 = 21+N_gen, 45-和家族支持, blind null p≈0.008) + dev 0.04σ (比 3σ 窗窄 15×) — 結構推導嘅對恰好係掃描唯一窗格, 唔係 random near-miss
- **方法論規則更新**: obs 判決 = p_loc + 結構身份 + 精度三合一; p_global 細但 p_loc 大 = 密度簇集, 唔宣稱 (sin²θ₂₃ R88 實例: p_global=0.000 但 p_loc=0.33 — 純簇集)
