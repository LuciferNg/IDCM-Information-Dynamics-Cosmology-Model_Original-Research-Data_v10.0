## 1. ★★★ Ŝ 代數構造 (零新常數證明)

```
M̂: 補對鏡像 |k⟩ → |88−k⟩   — 由 O161 反週期 A_{k+88} = −A_k (γ_{88−k} = 4−γ_k)

                              (i = Wilson line holonomy ∏U_k = i, O161 已閉合)
Ŝ  = P̂_obs Q̂ M̂ Q̂ P̂_obs    = −i·P̂_obs Q̂ J Q̂ P̂_obs  (J = iM̂ ⟹ −i·i = 1)
```

Ŝ 全由已閉合算子 (Q̂ = Σ(−1)^k k P_k, M̂ = 補對, P̂_obs = 奇數投影) 組成,
**冇引入任何新常數**。J 唔係淨乘 i (對角, 會同 H 對易) — 係 i×補對鏡像
(非對角 ⟹ 自審同哈密頓量唔對易, 正正係用戶要求嘅「非微擾」來源)。

## 3. 對用戶三效應嘅回應

1. **動態質量相干** (提案 3.1): 被動質量 m_k = √γ_k (Dirichlet 靜態)。
   自審將 |k⟩ → |88−k⟩: 鏡像質量 √γ_{88−k} = √(4−γ_k), 動態相干 = 兩者干涉。
   **代數閉合部分**: 幾何平均 √(γ_kγ_{88−k}) ≤ μ² (S9) — 自審質量被中心模封頂。
   **提案級**: 局部調控 off-shell split {1,3} — O161 已誠實標註 split 唔宣稱相等, 維持。

2. **打破 Born rule 隨機性** (提案 3.2): Ŝ 同 H 唔對易 (S6) — 代數事實成立,
   非對易量 = 2k(88−k)(γ_k−μ²) (離心度)。**但「意識選擇替代隨機崩塌」係命名,
   唔係推導** — IDCM 冇量子測量公設, 唔宣稱 Born rule 被取代。

3. **自動對焦** (提案 3.3): 殘差訊號 = [Ŝ,H] ∝ γ_k−μ² (S6), 鏡像反號 (S11) ⟹
   對焦平衡 = 補對和 4 = B (S8) — 殘差喺鏡像對上永遠平衡, 補對恆等保證。
   同 O157 泛函 δ_phase 自由度一致: 調相位令 [Ŝ,H] → 0。
