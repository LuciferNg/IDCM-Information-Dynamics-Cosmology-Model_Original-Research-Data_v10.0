# O160 docs/06 — ★★★ 中心模定理 (Central-Mode Theorem)

> 2026-09-08 | scripts/07 = 18/18 PASS | 閉合 docs/05 開放項 1 (λ₁₇ = μ² 機制)

## 1. 定理

**∀ M 偶數, 4sin²(kπ/2M) 譜喺 k = M/2 有 μ² = 2 模** (sin²(π/4) = 1/2 算術)。

IDCM 三個 Laplacian 譜全部命中 (M = 譜 half-site 數):

| 譜 | 公式 | M | 中心模 | 值 | 結構維度 |
|:---|:-----|:--|:------|:---|:---------|
| 88-site 對偶鏈 | γ_k = 4sin²(kπ/176) | 88 | k = 44 | **2 = μ²** | 44 = N_d |
| 33-tree Dirichlet | λ_c = 4sin²(cπ/68) | 34 | c = 17 | **2 = μ²** | 17 = F_proj |
| 44-chain 次框架 | γ44_n = 4sin²(nπ/88) | 44 | n = 22 | **2 = μ²** | 22 = 2L₅ = log₂B |

## 2. λ₁₇ = μ² 嘅結構強制鏈 (機制閉合)

```
K_tree = 2·F_proj − 1           (33 = 2×17−1; O155 K_tree = F₉−1 閉合引用)
⇒ Dirichlet 譜分母 68 = 2(K_tree+1) = 4·F_proj
⇒ c = F_proj 自然係四分之一點:  λ₁₇ = 4sin²(17π/68) = 4sin²(π/4) = 2  EXACT
```

即係: **λ₁₇ = μ² 唔係巧合, 係樹長度 = 2×投影維度−1 嘅必然後果**。F_proj 由樹結構自動成為 π/4 模。

## 3. 統一讀法: μ² = 所有譜嘅中心模

- 每個譜分母 = 4×結構維度 (176 = 4·N_d, 68 = 4·F_proj, 88 = 4·2L₅)
- 中心模 = 結構維度本身 (N_d / F_proj / 2L₅) — 全 T̂ 衍生 (C10)
- 唯一性: 譜內冇其他 μ² 模 (C6: 88 鏈只有 44, 樹只有 17, 44 鏈只有 22)
- **μ² = 2 嘅「自對偶」本質 = 譜中心**: E−O = 2 (O159 閉式) = γ₄₄ = λ₁₇ 四重身份 (C7)

## 4. 新恆等: 中心對稱 (鏡像) 和

- **γ_{44+j} + γ_{44−j} = 4 = B ∀j=1..43** (sin²(π/4+x)+sin²(π/4−x) = 1)
- **λ_{17+j} + λ_{17−j} = 4 = B ∀j=1..16** (樹版)
- 平行於已知補對和 γ_k + γ_{88−k} = 4 (O155 T26) — 兩條恆等都出 B, 一個係鏡像 (中心對稱), 一個係補角 (端點對稱)。鏡像恆等係中心模定理嘅直接後果 (C8)。

## 5. 意義

λ₁₇ = μ² 由「樹第 F_proj 個 mode」升級做「樹譜中心模」—— 同 γ₄₄ = μ² (鏈譜中心模) 完全平行。**μ² 唔係兩個譜各自嘅巧合, 係所有 IDCM Laplacian 譜共享嘅中心值**, 喺中心模出現 (4sin²(π/4))。呢個係 O152「數字即算子」嘅又一例: μ² = 中心模算子值。
