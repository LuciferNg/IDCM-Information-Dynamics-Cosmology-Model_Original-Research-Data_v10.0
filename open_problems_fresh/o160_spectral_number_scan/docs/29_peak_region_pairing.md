# docs/29 — 離心度峰區配對分析 (T30, 誠實限制)

**日期**: 2026-09-08 · **script**: scripts/30 (8/8 PASS) · **狀態**: 🟢 誠實檢查閉合

## 背景

T28 發現峰 k\*=21 = m_W/m_Z 配對 k₁。本 T30 檢查「質量比 = 最大離心度區」係咪
有唯一性（充分條件）— 峰區配對嘅完整結構。

## 峰區結構

```
峰區 (f(k) > 1000): k ∈ {18..24, 64..70}   (14 個, 左右鏡像 7+7)
45-鏡像配對喺峰區: (21,24) 同 (22,23)      (2 個)
```

## ★★★ 誠實限制 (P5/P8)

- **峰區揀唔出唯一配對**: (22,23) 都喺峰區 (f(22)=1026.7, f(23)=1020.4 > 1000),
  但 √(γ₂₂/γ₂₃) ≈ 0.959 冇任何觀測身份。
- **「質量比 = 最大離心度」只係必要條件, 唔係充分**: (21,24) 坐喺峰區係位置事實,
  但峰區性質本身唔能唯一揀出佢。
- **峰區配對密度反而略低**: 峰區內配對密度 2/14 = 14.3% vs 全譜 22/87 = 25.3%;
  峰區配對佔全部配對 2/22 = 9.1% vs 峰區成員佔全譜 14/87 = 16.1% — **冇富集**。
- (21,24) 係峰區唯一**有觀測連結**嘅配對 — 但「有觀測」唔係「由峰區決定」。

## 結論

T28 峰=k₁ 連結登記為**位置事實** (🟢 事實層) — 機制唯一性**唔成立** (🟡)。
質量比配對嘅選擇機制仍需額外結構 (45-鏡像 + 觀測挑選), 唔係離心度單獨決定。

誠實優先: 發現峰=k₁ 之後主動檢查充分性, 證偽「峰區⇒質量比」— 符合
無效才是正確 (blind test) 原則。
