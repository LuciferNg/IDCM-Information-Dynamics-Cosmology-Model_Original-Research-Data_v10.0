## 一、問題

1. **工具註冊**: 現有 4 套譜幾何工具 (CSG SpectralSpace K_Chain 版 / KTreeSpectralGeometry 雙矩陣 + 6 dock K_Tree 版 / CSG-v2 v2core T̂ 代數 / O140 FSR 有限譜相對論) 未有統一的 agent 可呼叫層 — 要註冊為 **agent skill** (程序知識) + **tools** (可執行工具層)。
2. **全數字掃描**: 由零開始 (從譜定義出發, 唔繼承任何舊閉合數字), 掃描 **88×88×33** = 255,552 格嘅全部連結 (link)、本徵值 (eigenvalue)、意思 (meaning)。數量大 — 唔可以 agent 逐個睇, 必須 **script 排除法過濾**:
   - Pass 0: 全空間暴力枚舉所有不變量族
   - Pass 1: 排除法 — 只保留命中閉合常數網 (constant web) 嘅格 (1e-10 相對容差)
   - Pass 2: 代數簡併去重 (Z₂ 退化, 三角恆等, 互補對)
   - Pass 3: null-control — 隨機 target 背景命中率
   - Pass 4: 新數字偵測 — 整數/半整數/簡單有理數但唔喺 web 度 (潛在新意思)
3. **意思賦予**: 命中嘅連結要 trace 返 constant web 嘅語義 (O152 operator dictionary + O158), 新數字要標記 🔮 待解釋, 唔准後驗命名。
