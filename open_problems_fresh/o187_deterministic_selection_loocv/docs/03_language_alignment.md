## 一、裁定問題（預註冊）

O187 係「(n, P_f) 配對選擇」母題。後續出現兩套語言：

- **L1（O136/O187 原語言）**: 質量 `m = M₀·γ_n·P_f`
  - `M₀ = 27.900915 MeV`（O34/O38 標度）
  - `n ∈ {1, 7, 14, 20, 33, 34}`（γ 譜模式）
  - `P_f ∈ 結構池`（L₆/F₅=3.6, N_d−E_proj=15.5, N_d−L₄=37, N_d−L₅=33, F₇=13, N_d=44）
- **L2（O209 冪律語言）**: 質量 `m = M₀′·|Δm|^α`
  - `M₀′ = e^(−13.5071) MeV`（**擬合標度，唔係 O136 個 M₀**）
  - `n ∈ {1, 2, 3, 4, 5, 7, 9, 11, 13}`（G1∧G2 質量無關唯一集）
  - `α ≈ 2.6333`（79/30 結構候選）

**問題**: L1 ⊆ L2（或 L2 ⊆ L1）？同一物嘅兩種參數化，定真正分歧？

判定基準：
- (i) L2 n-set 落 L1 形式：`C_f = m/(M₀γ_n)`（用 L2 n）應落入 L1 P_f 池（±2% 相對）
- (ii) `P_f_implied = (M₀′/M₀)·|Δm|^α/γ_n` 應落入 L1 P_f 池（±2% 相對）
- (iii) 兩語言各自 fit 品質 RMS(ln)

## 三、裁定

> **兩語言唔可以對齊（0/8、0/8）。O209 嘅 n-set 喺 L1 形式下完全唔落入**
> **P_f 池；P_f_implied 亦都唔入池。「γ·P_f 語言 = |Δm|^α 語言」被否證。**

物理意義：
- **L1 贏 fit、輸質量無關**：γ_n·P_f 有大量自由度（6 模式 × 6 池值），
  可以 fit 得好好，但 (n,P_f) 配對係後驗揀出嚟（O187 原投訴成立）
- **L2 贏質量無關、輸形狀**：n-set 由 G1∧G2 質量無關鎖定，但單一冪律
  得 2 參數，形狀 fit 差 68 倍，LOOCV 中位偏差 70.4%（O136 已判）
- **冇公式同時有「質量無關唯一性」+「完美 fit」** —— 呢個先係
  O187 核心問題嘅真正剩餘：*需要一個語言同時滿足 (a) 質量無關選擇律
  (b) LOOCV 逐點 <5% (c) fit 誤差 <1%*，而家冇。
