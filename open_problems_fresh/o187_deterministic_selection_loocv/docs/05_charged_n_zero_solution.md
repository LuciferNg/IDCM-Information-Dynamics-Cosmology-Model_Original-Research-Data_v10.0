## 三、裁定 Q2：結構必然 — 第三代對數域外

反事實對照（獨立計算）揭示根源：

```
反事實 D（S={1..13} × 池, 逐粒最佳）:
  c  → n=13 pf=44  dev = 22.5%   🔴
  τ  → n=13 pf=44  dev = 44.6%   🔴
  b  → n=13 pf=44  dev = 76.5%   🔴

最大可達質量 (n=13, pf=44):  M₀·γ₁₃·44 = 941 MeV ≪ c(1270), τ(1778), b(4180)
```

**原因**：γ_n 對 n≤13 有上限 → 池最大值 44 → 質量上限 ~0.94 GeV。
第三代（c/τ/b）需要大 n（γ₂₀, γ₃₃, γ₃₄）先夠大 —— 但 **n=14/20/33/34
全部唔過 G2（A₅ 等向）**。

```
⟹ 結構衝突（本質）:
   第三代質量大  → 需要 γ 大  → 需要 n 大 (>13)  → 唔過 G2
   G2 質量無關   → 只畀細 n  → 質量上限 ~1 GeV → 第三代 fit 唔到
```

**G2（A₅ 等向）同 PDG 第三代質量本質衝突** —— 除非 P_f 池有更大值
（結構池得 44）或者質量公式唔係 γ·P_f。呢個解釋埋路線 A 嘅觀察：
O209 corr 0.988 但 RMS 0.5872 —— 冪律 fit 第三代係咁差嘅原因。
