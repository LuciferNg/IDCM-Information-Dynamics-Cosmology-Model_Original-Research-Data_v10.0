## 三、核心負面發現

### 3.1 n 同質量冇單調關係（後驗搜索鐵證）

```
μ: n=7,  m=105.7 MeV     ← 細 n 大質量
s: n=14, m=93.0 MeV      ← 大 n 細質量
```

n 唔係質量排序 → P_f 同 γ_n 嘅配對係「揀」出嚟, 唔係推導出嚟。

### 3.2 c-quark n=34 係特例

- 34 **唔喺** O136 selected_n = [1,2,3,7,8,10,12,14,15,20,21,26,27,30,33]
- 34 = F₉ 係 Fibonacci, 但為擬合而加入
- **按原則 3: c 無法歸隊 → 承認 FAIL**（唔破壞集合）

### 3.3 γ_n 代數性質（冇特殊標記）

## 四、真結構部分（保留）

### 4.1 質量比 = γ 比（同一 P_f 組內）

```
P_f = N_d−E_proj (15.5):  μ/u = γ₇/γ₁ = 48.0  (PDG: 48.9)  ✅
P_f = L₆/F₅ (3.6):        s/e = γ₁₄/γ₁ = 180.3 (PDG: 182.0) ✅
```

γ_n 係 C₄₄ 固有譜（零自由度）。同一 P_f 應用喺唔同 n → 質量比 = γ 比 — 呢部分係真結構預測，唔受後驗選擇影響。

### 4.2 局限

質量比規則只鎖定「相對」質量 — 唔鎖定 n 本身。n 必須由量子數先驗鎖定, 質量比先有用 → 循環依賴。
