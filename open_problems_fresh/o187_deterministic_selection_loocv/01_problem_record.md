## 一、問題

O136 嘅費米子質量公式 `m = M₀ × γ_n × P_f` 中：

- ✅ `γ_n` = C₄₄ 固有譜（零自由度，真結構）
- ✅ `P_f` 值 = Lucas/Fibonacci/N_d 組合（結構常數）
- 🔴 **但 `(n, P_f)` 嘅配對選擇係後驗搜索**：

| 粒子 | n | P_f | 問題 |
|:-----|:--|:----|:-----|
| e⁻ | 1 | L₆/F₅ | 點解 n=1？ |
| μ⁻ | 7 | N_d−E_proj | 點解 n=7 而唔係 8？ |
| τ⁻ | 20 | N_d−L₄ | 點解 n=20 而唔係 21？ |
| u | 1 | N_d−E_proj | 同 e 一樣 n=1 但唔同 P_f？ |
| d | 1 | N_d−L₅ | 又係 n=1？ |
| s | 14 | L₆/F₅ | 點解 n=14？ |
| c | 34 | F₇ | **🔴 34 唔喺 selected_n！特例！** |
| b | 33 | N_d | 點解 n=33？ |

**組合自由度**: 6 P_f × 44 n = 264 種組合，揀 8 個命中 → 事後參數空間搜尋。

**密度效應**: b-quark 0.01% 偏差 — 但有 163 個候選喺 <1% 窗口，幾乎任何值都中。

## 二、三不原則驗證協議（必守）

### 原則 1：先驗單射映射（No Post-hoc Selection）

必須存在一個純代數映射：

```
f: (Q, T₃, Generation g, Color) ↦ (n, P_f)
```

**禁止**：
- ❌ 讀取任何 PDG 質量數據
- ❌ 從質量反推 n/P_f
- ❌ 用「匹配誤差 < X%」做選擇標準

**允許**：
- ✅ 量子數 (Q, T₃, g, Color)
- ✅ C₄₄ ⊗ C₅ 拓撲性質（v₂(n) 2-adic、Lucas 階、Fibonacci 階）

### 原則 2：留一交叉驗證（LOOCV 盲測）

```
訓練: 7 個費米子 → 建立選擇律 f
測試: 第 8 個 → 預測 (n, P_f)
通過: 第 8 個嘅 n 同 P_f 被唯一鎖定, 質量誤差喺預期範圍
```

**流程**：
1. 封閉規則：用 7 粒子建立 f，完全唔睇第 8 個
2. 鎖定預測：f(Q,T₃,g,Color) → (n*, P_f*)
3. 質量計算：m* = M₀×γ_{n*}×P_f*
4. 對比 PDG：誤差 < 預期範圍先算通過
5. 8 次 LOOCV 全部通過 → 先算結構閉合

### 原則 3：淘汰特例與廢棄 n=34

- ❌ c-quark n=34 唔喺 O136 selected_n 集合 → **必須回歸代數約束**
- 若 c 無法由先驗規則鎖定 n=34 → **承認 FAIL**，唔為擬合破壞集合
- selected_n = [1,2,3,7,8,10,12,14,15,20,21,26,27,30,33] 係既有代數約束

## 四、待推導結構（工作假設）

### 4.1 v₂(n) 2-adic 分類（O137 基礎）

O137 已證：費米子反週期量子化 `n·L ≡ 44 (mod 88)`, `L = N_d/2^{v₂(n)}`。

| n | v₂(n) | 2-adic 結構 |
|:--|:------|:------------|
| 1 | 0 | odd |
| 7 | 0 | odd |
| 14 | 1 | 2×7 |
| 20 | 2 | 4×5 |
| 33 | 0 | odd |
| 34 | 1 | 2×17 🔴 |

### 4.2 Lucas/Fibonacci 階分類

```
L₀=2, L₁=1, L₂=3, L₃=4, L₄=7, L₅=11, L₆=18, L₇=29
F₅=5, F₆=8, F₇=13, F₈=21
```

P_f 值:
```
L₆/F₅ = 18/5 = 3.6
N_d−E_proj = 44−28.5 = 15.5  (E_proj = 28.5 = ?)
N_d−L₄ = 37
N_d−L₅ = 33
F₇ = 13
N_d = 44
```

### 4.3 質量比結構（真結構部分）

同一 P_f 應用喺唔同 n → 質量比 = γ 比:
```
s/e = γ₁₄/γ₁ = 180 倍 (實驗: 93/0.511 = 182)
μ/u = γ₇/γ₁ = 48 倍 (實驗: 105.66/2.16 = 48.9)
```
呢個係真結構 — γ 比無選擇。

## 五、成功標準

1. **單射映射存在**: f 對 9 個費米子全部唯一鎖定 (n, P_f)
2. **LOOCV 8/8 通過**: 每次用 7 訓練預測第 8, 質量誤差 < 5%
3. **零特例**: c-quark n=34 由規則鎖定, 或者承認 FAIL
4. **零 PDG 讀取**: 推導過程只用量子數 + 拓撲性質

**失敗模式**: f 唔存在 / LOOCV < 8/8 / 需要特例 → O187 保持 🔴 開放,
O136 嘅質量譜降級為「後驗擬合」而非「結構推導」。
