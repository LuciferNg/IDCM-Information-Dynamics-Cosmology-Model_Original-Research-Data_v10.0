## 一、定理 A: artanh 身份 (k_odd 純邊界修正)

**定理**: 全鏈奇累積量 k_odd (n≥3) = n![tⁿ]·artanh(δ(t))，δ(t) = sinh(2t)/(88·I₀(2t))。

- 證明: ① arcsine[0,4]（觀察者 sector）奇累積量 κ_odd = 0 ∀n≥3 (A2 ✅, κ₁=2 例外) —
  由對稱性: arcsine-on-[0,4] 對稱於 2, 奇中心矩消失; ② 全鏈 K = K_arc + ΔK (O194 Thm 1),
  ΔK = ln[1 + sinh(2t)/(88·I₀(2t))] = ln(1+δ); ③ ΔK 奇部 = artanh(δ) = δ + δ³/3 + δ⁵/5 + ...
  (δ 奇函數: sinh 奇 / I₀ 偶) ⟹ k_odd = n![tⁿ]·artanh(δ) (A1 ✅, n=3..59 全中)。
- **結構讀取**: 全鏈 k_odd 唔係「arcsine 整數 + 修正」— 係**純修正**。
  幾乎整數現象 (k_odd ≈ 整數) 嘅對象本身 = 邊界修正嘅累積量, 唔係觀察者側。

## 四、定理 D: 11-週期定理 (k₁₂ anomaly 閉合)

**定理**: v₁₁(den k_n) = n − ⌊(n−1)/11⌋ (n=1..80 全 PASS, D1 ✅)。
即 v₁₁(k_n) = −(n − ⌊(n−1)/11⌋)。

- **k₁₂ 分母 11 指數 anomaly 唔係零星** — 係週期 11 = L₅ 規律第一個位:
  anomaly 位 = n ≡ 1 (mod 11), n ≥ 12: {12, 23, 34, 45, 56, 67, 78} (等差 11)。
