## 1. ★ P1b — `y_n` 之場身份（類比 → 歸一化慣例）

### 1.1 問題陳述

`docs/05` §1.5 之殘餘 🟡：「**φ_n 係 W 玻色模態, 套用費米子 Yukawa 形式 (√2 m/v) 仍屬類比**」。
關鍵張力：SM 之 `y_f = √2m_f/v` 之所以成立，係因為**質量由 Higgs VEV 生成**（`m_f = y_f v/√2`）；
但 K_chain 玻色模態之質量 `m_n = M₀ω_n` **並非** VEV 生成。故「套 Yukawa 形式」似乎無根據。

### 1.2 結構關係（精確恆等式）

```
ω_n ≡ √γ_n      （拍頻 = K_chain 特徵值平方根；K_chain 幾何定義）
⟹ γ_n ≡ ω_n²    對 n = 1..87 全部精確 (script A1.1: max|γ_n−ω_n²| = 0.0)
```

**語義**：K_chain 譜有**兩支**——
- **玻色支**：模態能量 `m_n = M₀·√γ_n = M₀·ω_n`（O36 質量譜）
- **費米支**：粒子質量 `m_f = M₀·γ_k·F_f`（O54 質量公式）

兩支由**平方映射**相連、共用同一 `M₀` 與同一組模態指標 `{1, 7, 20}`。

### 1.3 比值 — 零參數、Λ-無關

```
m_f / (M₀ω_k) = ω_k·F_k                    （純結構, script A2 e/μ/τ 全 PASS）
y_n = √2·m_n/v_SM   ;   y_f = √2·M₀γ_kF_f/v_SM
⟹ y_n / y_f(k) = ω_n / (γ_k·F_k) = 1/(ω_k·F_k)     （M₀、v_SM 完全相消）
```
script A3：e/μ/τ 三例比值精確；A3.x 驗 `y_n·v_SM/(√2M₀) = ω_n` 精確 → **M₀、v_SM 相消確認**。

### 1.4 絕對歸一化 `Λ` 之地位 — **Λ 不攜帶物理信息**

script A4：對 `Λ ∈ {M₀, v_eff, ⟨W⟩, M_Pl, v_SM}`，同一物理質量 `m_f` 皆可由相應 `y_f = √2m_f/Λ` 復現
⟹ **歸一化係慣例，物理內容 = 質量本身同比值**。
`Λ` 之**唯一**非任意選擇係由 `L_total` 之 **SM 扇區（Higgs 機制）** 強制：`L_Yuk = −Σy_f ψ̄ψ H`，
費米子質量唯一來源 = `⟨H⟩ = v_SM/√2` ⟹ `Λ = v_SM`。

### 1.5 裁定

| 項 | 狀態 |

### 2.2 ⚠️ 更正（append-only）：docs/04 §4 之 `⟨W⟩` 用錯

### 2.3 ★ 缺落之結構岔路 — 重力誘發支

```
L_grav = M_Pl²R/2 + ξ|W|²R   →   ⟨W⟩ 處有效 EH 係數 = M_Pl²/2 + ξ⟨W⟩²
```

| 支 | 條件 | `ξ` | 效應 `ξ⟨W⟩²/M_Pl²` |
|:---|:-----|:----|:------------------|
| **(i) 重力基本** | `M_Pl²` 為樹級輸入 | 自由（~O(1)） | < 1e-40（不可分辨） |
| **(ii) 重力誘發 (Sakharov)** | `M_Pl² = 2ξ⟨W⟩²` | **`M_Pl²/(2⟨W⟩²) = 1.556722e39`（確定, 零自由參數）** | **恰 1/2** |

script B2：`ξ_induced = 1.556722e+39`；`ξ⟨W⟩²/M_Pl² = 1/2` 精確；兩支效應比 = **5.0e40 倍**。
docs/04 §4 只列了 (i)（且 `⟨W⟩` 用錯）——**漏咗 (ii)**。

### 2.4 裁定

`ξ` **唔係自由參數，亦唔係獨立缺口** —— 係**二元結構岔路**：
- 重力基本 ⟹ `ξ` 不可觀測（<1e-40）；
- 重力誘發 ⟹ `ξ = M_Pl²/(2⟨W⟩²)` **確定**（零自由參數），效應恰 1/2。

**岔路之選擇 = 「`M_Pl` 係基本抑或 W-凝聚誘發」= 零錨問題 = O213**（與 R1 同源）。
⟹ N3 維持 🟡，但內容**收窄**至零錨岔路，**非本 O 可獨立解**。
