# POINTER → O86：非最小耦合常數 ξ 未推導（G9）

## 一、裁決

O86 §2.1 使用 `L_ζ = ζ·W·R`，`ζ = M_Pl·λ = 1.99e17 GeV`（O86 自身已標為「候選」）。

O204 §P1（形式強迫定理）用 U(1)_W 不變性 + 解析性 + SSB 窮舉，導出勢之唯一最低次形式
`V = −μ²|W|² + λ|W|⁴`。**同一形式審計邏輯施加到非最小耦合**：

| 項 | U(1)_W 不變？（W → e^{iα}W） |
|---|---|
| `ζ·W·R` | **✗**（W 線性項） |
| `ξ·|W|²·R` | ✓（ξ 無量綱） |
| `ξ·R·|∂W|²` | ✓ |

寫 `W = (M₀+h)e^{iθ}`：`ξ|W|²R = ξ(M₀² + 2M₀h + h²)R`，而 `ζWR = ζ(M₀+h)R`。
識別線性項要求 `ζ = 2ξM₀` ⟹ `ξ = ζ/(2M₀) = 3.57e18`（**非 O(1)**）
⟹ `ζWR ≠ ξ|W|²R`（唔同項）。

## 二、G9 裁決

> **P1 形式強迫（作用量之勢）唔延伸到非最小耦合。**
> U(1)_W 不變性要求 `ξ|W|²R` 之 `ξ` 為**新無量綱常數**，P1 **唔固定** ξ。
> **⟹ 非最小耦合常數未推導（G9）。**

🟡 候選（無機制）：`ξ = λ = 2/123`（與四次耦合同源）。
