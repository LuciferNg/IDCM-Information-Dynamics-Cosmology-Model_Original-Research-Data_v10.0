## 〇、問題（承接 docs/04）

X/Y 玻色子標度 —— **由觀測推，禁硬編碼**。舊污染值 `M_GUT=1e16 / M_PS=1e14 / M_R=1e12` 係硬編碼（已刪）；本階段由質子衰變下限 `τ_p > 2.4×10³⁴ yr`（Super-K, PDG）**量綱式**倒推唯一自由標度 Λ。

## 一、X/Y 玻色子（§A）

- 質量係數 = `λ₄ − λ₂ = λ₂(N_gen−λ₂) = 0.060656936533`（docs/04 恆等 ✓）
- 數目 = 3×2×2 = **12**（色×弱×正反）
- 耦合強度 ~ g_X（g 級）⟹ 質子衰變係交換圖 = **d=6 有效算子**

## 二、量綱式（§B）

```
Γ_p = c·α_X²·m_p⁵ / M_XY⁴          (c ~ O(1))
M_XY > (α_X²·m_p⁵·τ_min/ħ)^{1/4}   [τ 秒 → Γ GeV]
```

- ★ M_XY = g_X · xy_coeff · Λ（Λ = 唯一自由標度）
- 單位檢查: m_p⁵/M⁴ 質量次元 1 ✓

## 三、★★ 觀測下限（§C）

| 耦合 | M_XY 下限 |
|:--|:--|
| α₂ (弱層次) | > **5.52×10¹⁵ GeV** |
| α_s (強層次) | > **1.04×10¹⁶ GeV** |

- τ_p > 2.4×10³⁴ yr = 7.57×10⁴¹ s（Super-K, PDG）✓

## 四、★★ 整體標度 Λ（§D）

```
Λ = M_XY / (g·xy_coeff)  >  1.41×10¹⁷ GeV  =  M_Pl / 87
```

- Λ 係唯一自由標度（模式數/賦值/恆等 **全由結構出**；冇 M_GUT/M_PS/M_R 階梯 ✓）

## 五、誠實限制（§E）

- ⚠️ 量綱式：冇強子矩陣元 (f_p)、冇 renormalization、冇 phase space ⟹ **數量級級，非精密**
- ⚠️ 未驗證 X/Y 是否真正耦合到 B−L（需費米子嵌入, docs/05 §F）—— 若 X/Y 唔載 B−L，質子更安全
- ★★ 結論：標度 Λ ≳ 10¹⁷ GeV（M_Pl 量級）由 τ_p 推 —— 與舊污染值 1e16 差 ~1 數量級，但**推導途徑完全不同**（量綱式 vs 硬編碼）
