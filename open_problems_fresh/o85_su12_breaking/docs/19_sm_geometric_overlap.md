## 三、核心發現

### A. S_f 三點係 per-particle 投影路徑，冇統一函數（C1 ✅）

O54 docs/05 已閉合輕子 S_f（重現 3/3）：

```
e:  S_f = L₆/F₅          = 18/5    = 3.6   (n=1)
μ:  S_f = N_d − E_proj   = 44−28.5 = 15.5  (n=7)
τ:  S_f = N_d − L₄       = 44−7    = 37    (n=20)
```

**統一函數檢驗**（真計算）：
- 線性外推 (1,3.6)→(7,15.5)：預測 S(20)=**41.28 ≠ 37**（差 4.28，超 tolerance）
- 「N_d − X」模板：三點要求 X = 40.4 / 28.5 / 7——**冇統一結構身份**（40.4 唔係結構數；28.5=E_proj、7=L₄ 各自離散）
- 質量重現：m_e=0.5118 / m_μ=105.80 / m_τ=1770.8 MeV（obs 偏差 0.16%/0.13%/0.34%）✅

⟹ S_f 係**每粒子離散投影路徑**（O54 docs/05 §二「每個粒子經唔同 K_Chain 模式 × 唔同投影路徑」）——唔係 n 嘅函數 ⟹ **VL S(m) 唔可以由輕子三點外推**。

### B. CY₃ κ 幾何重疊已證偽，積分路徑封閉（C2 ✅）

O137 Phase 4（docs/06，2026-10-07）已執行 **P_f 拓撲重疊算子 8 個組合**：

- `P_f(n) = Σ κ_ijk·c_n(i)·c_n(j)·c_n(k)` 零模波函數重疊（零參數）
- 結論 🔴 **證偽**：「P_f 重疊算子（8 版本）全部冇選擇律——候選唔突出、玻色子冇抑制、質量譜冇 match SM」「模式選擇係 chain-side 離散結構；**CY₃ 幾何只提供質量比例，唔提供模式存在性**」

⟹ docs/18 原記載嘅「或 CY₃ 重疊積分」路徑**已被自家 O137 封閉**——唔存在可用嘅 CY₃ 幾何積分做 S(m)。

### C. VL 單態 = 基礎單態（y=0 無複合嵌入）（C3 ✅）

O85 docs/12（17/17 PASS 已閉合）記錄：
- `y_i = {0, ±1/3, ±2/3, ±1}`（Σ=0 零跡 + 1/3 階量子化）
- (iii) **ν^c 需要 Y=0**——基礎單態無超荷載體
- 7 個單態 = 3 對相反 + 1 個 0

VL 單態無複合嵌入（唔似 SM 費米子經 `66 = 12∧12` 複合）⟹ 自重疊 `⟨ψ_m|ψ_m⟩ = 1`（正規化恆等）⟹ **S(m)=1 係結構必然，唔係 fit**。

### D. S=1 一致性（C3b/c/d，真計算）

```
m_VL(m) = (√2M₀/v)·γ_m²·Λ_min,  Λ_min = M_Pl/87 (docs/06)
m_VL(1)  = 5.840e+08 GeV
m_VL(13) = 1.444e+13 GeV   (λ² 階梯單調 ✅)

      ⟹ 階梯破壞 + 同 C1 外推翻案一致（唔可借）
```
