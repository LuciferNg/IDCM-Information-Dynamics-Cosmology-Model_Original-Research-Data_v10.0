## 3. D3 — tree sector 正則相位算子 = π + atan(β)

tree sector 內**唯一帶 π 相位嘅物件** = Fibonacci F-matrix 元：

```
F^{τττ}_{τ;τ,τ} = −φ⁻¹ = e^{iπ} · φ⁻¹
                    ↑        ↑
                  arg = π   |·| = β  (其角 = atan β)
```

（A₅/Fibonacci anyon 融合符號；同 idcm-flavor-physics skill 記錄一致。）

組合樹扇區內僅有嘅兩個相位資源（**π** 同 **atan(β)**）：

```
δ_PMNS = π + atan(β) = 180° + 31.717474° = 211.717474°
```

**機制敍述**: tree sector 嘅 CP 相位 = 「F-matrix 融合符號嘅 π」+「tree 能階比 β 嘅角」。
即 PMNS 相位 = tree 扇區嘅**正則相位算子**作用結果，唔需要任何新常數。
