## 4. 但係——意外發現：峰→谷距離 90 = Σγ_even

```

```

其餘距離: 99 = 90+9, 81 = 90−9, 63 = 90−27 = 90−3·9

## 5. 真正結論：谷位唔係「44 週期鋸齒」型

- **峰位**：44×7 步進（=308 ≈ 聲學週期）+ Δs 鋸齒（−2/−20）→ 306/288 交替 ✅ 閉合
- **谷位**：聲學 trough（437, 716, 1040, 1346 ≈ ΛCDM T1-T4 ~400/700/1000/1300），
  **冇額外 44 週期層**（相位分散 spread=29）

即係話「峰+谷一體」模型正確形式唔係「谷都係 44N+s′」——而係：
```
峰 = 44N + s（鋸齒層, 已閉合）     → 306/288 交替
谷 = 峰之間嘅聲學 trough（平滑層）  → 跟聲學週期 ~300, 冇鋸齒
```
