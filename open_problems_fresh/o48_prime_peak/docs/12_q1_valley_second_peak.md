# O48 / Q1.16 — 「谷係咪另一頻率嘅峰？」

> **日期**: 2026-10-09
> **狀態**: ✅ 4/4 PASS — 谷唔係另一頻率；谷係 9-梳上嘅中間相點
> **Script**: `32_q1_valley_second_peak.py`
> **調律者問題**: 「即是谷也可能是另一頻率的峰？」

## 直接答案

**唔係另一頻率。** 谷同峰共享同一聲學週期 (~297) 同一 9-梳 (ℓ≡5 mod 9)，
但谷**冇 44-鋸齒**（mod 44 分散，26 script 已證）——谷唔係「第二組 IDCM 峰」。

## 證據（scripts/32, 4/4 PASS）

### A. 峰+谷合併序列 — 單一 9-梳
```
合併: [221, 464, 527, 734, 815, 1058, 1121, 1355, 1409]
間距: [243, 63, 207, 81, 243, 63, 234, 54]  = 9×{27, 7, 23, 9, 27, 7, 26, 6}
全部 9 倍數 ✓；谷 4 點全 ≡5 mod 9 ✓
```

### B. 谷間距中心 = 峰間距中心 = 297
```
峰間距:     [306, 288, 306, 288]  中心 = 297.0
Plik 谷間距: [270, 324, 297]      中心 = 297.0   ✅
O9 谷間距:   [279, 324, 306]      中心 = 303.0
```
→ 同一聲學頻率 ~297，唔係另一頻率。

### C. 谷偏近後峰（唔係半週期反相）
```
谷→後峰: [63, 81, 63, 54] = 9×{7, 9, 7, 6}
谷→後峰佔峰間隙比例: 0.206, 0.281, 0.206, 0.188 → 平均 0.220
(¼=0.25 附近 — 如果係聲學反相 trough 應該 ½=0.5)
```
→ 谷係「峰後 22% 點」唔係「峰間中點」——谷位置揭示峰形不對稱。

### D. 峰間隙分解 (n 步距, ℓ=9n+5)
```
峰1→峰2: 谷步距 a=27, b=7   a+b=34  (峰間距 306=34×9)
峰2→峰3: a=23, b=9          a+b=32  (峰間距 288=32×9)
峰3→峰5: a=27, b=7          a+b=34
峰5→峰7: a=26, b=6          a+b=32
```

## 裁決

1. ✅ 峰+谷 = **單一 9-梳上嘅完整點列**（ℓ≡5 mod 9，峰谷交替）
2. ✅ 谷間距中心 297 = 峰間距中心 297 → **同頻率**
3. ✅ 谷偏近後峰 (22%) → 谷係峰間隙嘅「¾-¾ 分點」（a:b ≈ 27:7 = 3.86:1）
4. ❌ 谷冇 44-鋸齒 → 谷唔係「另一組 IDCM 峰」；峰先有 44N+s 相位迴路
