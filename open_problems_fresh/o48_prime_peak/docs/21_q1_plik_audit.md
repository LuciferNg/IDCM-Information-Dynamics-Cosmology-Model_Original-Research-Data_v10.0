## 1. 發現：Plik-lite 檔案係 3-block 結構

`cl_cmb_plik_v22.dat`（613 rows）實際包含：

```
block1: 215 rows, ℓ 32..2492  → TT C_ℓ   (每 ℓ 最大值, 正值, 正常譜)
block2: 199 rows, ℓ 32..1988  → TE        (中間值, 有負值)
block3: 199 rows, ℓ 32..1988  → EE        (最小值, 138 個負值)
(O214 scripts/06 header 明載: "bval, X_data, X_sig (215 TT + 199 TE + 199 EE)")
```

QL scripts（28/30/31/32/33/34/43/45-48）全部 `sorted(plik)` 讀晒 613 行
→ **每個 ℓ 有 3 個值，谷位/統計被 TE/EE 污染**！
