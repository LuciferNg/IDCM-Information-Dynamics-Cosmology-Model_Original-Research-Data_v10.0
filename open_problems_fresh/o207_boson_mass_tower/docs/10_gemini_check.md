## 二、G1 詳細核實 — 直接探測

### 2.1 反衝能量

```
E_R ≈ 2 m_e v² (m_χ ≫ m_e 極限):
  v = 10⁻³c (SHM 典型)  ⟹ E_R ≈ 1.022 eV
  要 E_R ≥ 13.7 eV (SR0 閾值) 需 v ≥ 3.66×10⁻³ c = 1098 km/s
  SHM escape velocity ≈ 544 km/s = 1.8×10⁻³ c
⟹ SHM 束縛速度反衝全部 < 13.7 eV 閾值
```

### 2.2 ★ 反證 — XENONnT SR0 單/少電子分析

```
arXiv 2411.15289 / PRL 133, 191002 (XENON Collaboration):
  - 能量閾值降至 13.7 eV (單電子 S2, W = 13.7 eV/quantum)
  - ROI: S2 ∈ [10, 174] PE, 對應 1-5 電子
  - 「We set stringent new limits on DM-electron scattering via a
    heavy mediator with a mass within 10-20 MeV/c²」
  - m₇ = 13.8 MeV 正正落入 10-20 MeV 範圍!
```

**⟹ Gemini「完全免疫」唔準確**：SR0 分析已設 10-20 MeV DM-e 上限。
但 SHM 束縛速度反衝 ~1 eV < 13.7 eV 閾值——所以上限對「典型速度」DM
敏感度有限（主要靠高 v 尾部 + 太陽反射上散射）。

### 2.3 修正判決

```
「絕對盲區」→「閾值以下, 10-20 MeV 上限存在」
   現狀: m₇ 典型反衝 ~1 eV, 落喺 XENONnT SR0 閾值 (13.7 eV) 之下
   但 10-20 MeV 質量窗已有 stringent limits (重介子)
   ⟹ 直接探測係「部分敏感」: 典型散射探唔到, 高 v 尾部可探
   ⚠️ 更精確: 需睇 SR0 Fig.5 panel A 具體 σ_χe 上限值 (文獻圖, 本 script 冇數值)
```

## 三、G2 詳細核實 — NA64 束流

### 3.1 ε 值

```
NA64 (PRL 131.161801, 2023): 9.37e11 EOT, 2016-2022
  1-100 MeV invisible A′ 世界最強 ε 限制
  排除 αD ≤ 0.1, 0.001 ≲ mχ ≲ 0.1 GeV
  ε 喺 13.8 MeV 區域: 文獻排除圖 ~1e-4 級 (2019/2023)
  Gemini 引 1.2×10⁻⁵: 可能係 2023-24 數據 (9.5e11 EOT, 倍增) 之值
  ⟹ 1.2×10⁻⁵ 需 NA64 2023-24 發表確認 (Status 2024: 分析中)
```

### 3.2 ★ ε 適用性（關鍵）

```
NA64 ε 限制係對 dark-photon (kinetic mixing ε) 模型
IDCM m₇ 係玻色塔模式 (W-field 激發), B4 閉合 L_KS:
  L_KS = Σ m_n·Q_f·φ_n·ψ̄ψ  (Yukawa 型, 耦合係數 = 塔質量)
⟹ ε 限制唔直接適用 — 除非 m₇ 被識別為 A′ (未推導)
   若 m₇ ↔ A′ 映射建立 (B4 延伸), 則 NA64 ε ≲ 1e-4 (現行) 係有效邊界
   Gemini 1.2×10⁻⁵ 係更嚴邊界 (若 2023-24 數據確認)
```

### 3.3 修正判決

```
NA64 係主通道 (方向正確), 但:
  ① ε 值現行文獻 ~1e-4, 1.2×10⁻⁵ 待 2023-24 數據確認
  ② ε 適用性取決於 m₇ ↔ A′ 映射 (B4 未推導 kinetic mixing)
⟹ 「唯一有效邊界」需加條件: 若 m₇ 係 A′ 且 ε 已映射
```
