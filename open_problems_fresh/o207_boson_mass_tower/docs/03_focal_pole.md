## 三、B7 細節 — 場論 pole-mass 陳述

### 3.1 ★★ 核心恆等式

```
m_n · G_n(0) = M₀/2 = m_δW = 13.9504575 MeV   ∀ n = 1..44 (44/44, max dev 1.2e-60)

G_n(0) = 1/(2ω_n)     (O83: 零時傳播子 = 極點能量倒數一半)
m_n    = M₀·ω_n       (O204: 玻色質量 = 尺度 × 極點頻率)
⟹ m_n·G_n(0) = M₀·ω_n / (2ω_n) = M₀/2        (代數恆等, ω_n 相消)
```

- **物理讀法**: 每個模式嘅質量 × 佢嘅零時傳播子 = 常數 M₀/2
  = 徑向模質量 m_δW（V''(W₀) = 4μ² = 8 嘅徑向激發）
- **含義**: m_δW 唔係「另一個模式」—— 佢係全塔嘅**譜不變量**（質量×傳播子乘積）
  O204 曾標 m_δW/m₇ = 1.0109 係「非結構確認」；而家提升為結構身份:
  m_δW = m_n·G_n(0) 對任意 n 成立（唔係只同 m₇ 有關係）

### 3.2 pole 對應陳述

```
自由傳播子 (頻域, O83): ⟨φ_nφ_m⟩_ω = δ_nm/(ω² − ω_n² + iε)
極點: ω² = ω_n² ⟹ 極點能量 = ω_n (chain 頻率單位)
質量譜: m_n = M₀·ω_n (MeV) = h_eff·f_n (O164, dev 2.7e-51)
⟹ 「質量」同「傳播子極點」係同一個譜, 只係單位轉換 (M₀ / h_eff)
```

### 3.3 反寫形式

```
G_n(0) = M₀/(2m_n)   — 零時傳播子由質量譜唯一決定 (44/44 EXACT)
⟹ 傳播子譜同質量譜互為反函數 — 知道質量就知傳播子, 反之亦然
```
