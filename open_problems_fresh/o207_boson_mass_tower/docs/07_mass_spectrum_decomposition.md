## 四、三個核心問題

### Q1 玻色為何 γ^{1/2} 而費米 γ¹?

```
玻色: m_n = M₀·ω_n — 質量 = 尺度 × 頻率 (O164 質量-頻率鎖 m = h_eff·f)
費米: m_f = M₀·γ_n·C_f — 質量 = 尺度 × 譜能量 × 形狀 (O137 Decoupling)
⟹ 玻色子質量係「頻率譜」, 費米子質量係「能量譜×形狀」—
   同一鏈譜 γ_n 嘅兩個唔同函數 (√γ vs γ), 指數 1/2 vs 1
   對應 O204 γ-冪律 m² ∝ γ^{2n_ins}, n_ins = 1/2 (玻色) / 1 (費米)
```

### Q2 玻色為何 C_b = 1?

```
費米 C_f: CY₃ 幾何重疊 (φ=9 張量) — 觀察者側需要「投影形狀」
玻色 C_b = 1: 世界介質 (Z₂-偶) — 質量純譜, 無投影修正
⟹ C_b = 1 係扇區結構必然 (O206 Z₂ 分離), 唔係缺失
```

### Q3 質量譜生成規則?

```
m_n = M₀ · 2sin(πn/88), n = 1..44
  1. M₀: 唯一有量綱錨 (O38)
```
