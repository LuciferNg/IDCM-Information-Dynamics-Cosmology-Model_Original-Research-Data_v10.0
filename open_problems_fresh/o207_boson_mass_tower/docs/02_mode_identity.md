## 三、★★ Pythagorean 恆等式細節

```
γ_n = 4sin²(πn/88);  γ_{44−n} = 4sin²(π(44−n)/88) = 4cos²(πn/88)
γ_n + γ_{44−n} = 4(sin² + cos²) = 4 = γ_44          (配對律, O204/O206 已立)
⟹ m_n² + m_{44−n}² = M₀²·(γ_n + γ_{44−n}) = M₀²·4 = (2M₀)² = m_44²
```
