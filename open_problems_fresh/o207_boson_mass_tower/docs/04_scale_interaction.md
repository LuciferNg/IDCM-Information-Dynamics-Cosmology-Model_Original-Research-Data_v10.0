## 二、B2 細節 — 標度起源（誠實負結果）

### 2.1 數字

```
v_EW/M₀ = 246220 MeV / 27.900915 MeV = 8824.80019
log_φ(ratio) = 18.880087   → 最近整數 19, dev 0.64%  (唔係純 φ 冪)
log_88(ratio) = 2.029180   → 唔係整數              (唔係純 88 級數)
結構池 2-因子: 90×98 = 8820 (dev 0.054%) — 唯一 <1% 命中 (×2 對稱)
```

### 2.2 Null test（O206 docs/12 §C 方法）

- 結構數池 26×26 = 676 候選, <1% 命中 = **2**（90×98 及其對稱）
- 隨機池 100k 對 (1..1000) 每對命中率 0.067% ⟹ 676 候選期望命中 = **0.45**
- ⚠️ 2026-09-21 審計修正: 原 script 用 threshold = 期望×10 = **4.5**（保守 margin）
- ⟹ 結構命中 2 < threshold 4.5 — **無結構閉合, 標為巧合級**
- ⚠️ 90×98 = Σγ × h²¹（90 = 世界譜和, 98 = complex structure）係有趣組合
  但 0.054% 偏差 + 冇機制（點解 v_EW = Σγ·h²¹·M₀?）⟹ 按 O168 判準
  「近距命中冇機制 = 巧合」→ 🟡 巧合級, 唔宣稱

### 3.2 Z₂ 相容性（關鍵）
