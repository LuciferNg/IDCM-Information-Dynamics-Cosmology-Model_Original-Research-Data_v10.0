  Wien bridge 振盪頻率:
    f = 1/(2πRC), R=10kΩ, C=10nF
    f = 1/(2π·10⁴·10⁻⁸) = 1591.5 Hz ≈ 1.59 kHz ✓

  起振條件: 增益 1+Rf/Ri ≥ 3
    Ri=10k, Rf=33k → 增益 = 1+33/10 = 4.3 > 3 ✓
    (留 43% 裕量, 防元件容差)

  耦合強度 (Kuramoto):
    K = 1/(2·R_c·C)
    R_c=12k → K = 1/(2·12k·10nF) = 4167 rad/s
    對比 GRT-39 最佳 K=0.08 (歸一化) — 電路級 4167 rad/s ✓

  阻挫邊 (反相器):
    V_out = -(R_fb/R_in)·V_in = -(10k/10k)·V_in = -V_in
    → 精確 π 相移 ✓

  過阻尼 (γ≥2.0):
    方案 1: 耦合電阻調節 (R_c 細 → 耦合強 → 但阻尼由 γ 決定)
    方案 2: 加 RLC 阻尼支路 L=100mH + C=100nF + R=25Ω
    最簡: 電源去耦 + 電阻網絡 (實測調 R_c 到無振鈴)

  ══════════════════════════════════════════════════════════
  🧪 T1-T6 測試協議
  ══════════════════════════════════════════════════════════

  T1 上電鎖定:
    AC 檔量每個節點 Vout → 全部 ~1.0-1.5 Vrms (振盪!)
    → 5 節點都振 = 起振成功

  T2 阻挫邊相位:
    AC 檔比較 Vout4 (U2A pin1) 同 Vout0 (U1A pin1)
    兩者相位差 ≈ 180° (經反相器後鎖定)
    → 冇示波器: 量反相器 U2B pin7 電壓 = Vout4 反相
    → 反相器輸出同 Vout4 幅度相同, 相位反 180°

  T3 注入翻轉:
    DDS 輸出 1.59kHz 反相信號 → 節點 0 (經 1k)
    注入 0.5 週期 (0.3ms) 脈衝
    → 節點 0 相位翻轉 180° (量 Vout0 同 Vout4 關係改變)

  T4 阻挫圖案改變:
    阻挫邊 (4,0) 狀態翻轉: 由「同色」變「異色」
    → Vout0 相位改變 ~180°

  T5 持久性:
    停止注入, 等 10s
    → 再量: 圖案保持 (Vout0 冇彈返)

  T6 可重複性:
    重複 T3-T5 ×10 次 → 每次結果一致

  通過 = 5/5 節點振盪 + 阻挫鎖定 + 翻轉 + 持久 + 可重複
