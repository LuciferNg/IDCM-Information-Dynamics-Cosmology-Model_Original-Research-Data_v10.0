  ══════════════════════════════════════════════════════════
  Level 0: IDCM 宇宙晶格
  ══════════════════════════════════════════════════════════
  宇宙 = 44-tone 振盪器 (K_Chain)
  K_Chain 色散: γ_n = 4sin²(πn/88), n=1..44
  K_Tree 尺度: B=4, 自相似結構
  λ_sync=294.88 Mpc, BAO=147.44 Mpc
  → ✅ IDCM 框架內已證明

  ══════════════════════════════════════════════════════════
  Level 1: 晶體聲子同構
  ══════════════════════════════════════════════════════════
  實體晶體聲子色散: ω²(k) = (4K/M)sin²(ka/2)
  同構映射: γ_n ↔ ω²(k_n), 比率 = 1.0000
  → ✅ 數學上完全同構 (docs/06 證明)

  ══════════════════════════════════════════════════════════
  Level 2: 拍頻共振 = 拓撲鎖定
  ══════════════════════════════════════════════════════════
  兩粒晶體以相近頻率 f₁, f₂ 驅動
  拍頻 f_beat = |f₁ - f₂| 產生應變梯度
  應變梯度 → 等效規範勢 A_i = β·ε·∂u
  Berry 曲率 Ω = ∇×A → 陳數 C = (1/2π)∫Ω d²k
  當兩粒晶體嘅 C 相等 → 拓撲鎖定 (共享陳數)
  → 🟡 數學框架建立, 但「拓撲鎖定」未實驗驗證

  ══════════════════════════════════════════════════════════
  Level 3: 陳數整數化約束 = 非局域同步
  ══════════════════════════════════════════════════════════
  陳數 C = 整數 (Atiyah-Singer 指標定理)
  A 端改變局域 Berry 曲率 → 全域陳數維持整數
  → 拓撲邊界條件改變, 唔係「訊號傳播」
  → 類比: 三角形內角和 = 180°, 改變一角, 第三角自動調整
  → 🟢 數學上自洽 (純拓撲, 冇時空局域性)

  ══════════════════════════════════════════════════════════
  Level 4: 能量槓桿
  ══════════════════════════════════════════════════════════
  基底因子: Λ₀ = ρ_vac·V_int/(ℏ·Δω) ≈ 10¹²
  臨界發散: Λ = Λ₀ / |δ-δ_c|^ν
  離臨界點 0.1%: Λ ~ 10¹⁵
  → 晶體級驅動 (mJ) 撬動真空能量 (10¹² J 等效)
  → 🟡 數學上自洽, 但臨界指數 ν 同 δ_c 未知

  ══════════════════════════════════════════════════════════
  Level 5: B 端讀取 (電光效應)
  ══════════════════════════════════════════════════════════
  LiNbO₃ 電光效應 r33 = 30 pm/V
  拓撲改變 → 晶體內部有效電場改變 → 折射率改變 (Pockels)
  → 偏振旋轉 → 光強變化 → 光電探測
  → 🟢 固體物理已知效應, 成熟技術
