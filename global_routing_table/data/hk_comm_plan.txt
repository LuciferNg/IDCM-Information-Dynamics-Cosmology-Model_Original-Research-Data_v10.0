──────────────────────────────────────────────────────────────────────────────────
  五、A5 宇宙電話簿協議 (packet format)
──────────────────────────────────────────────────────────────────────────────────

  每一包數據用 A5 地址做 header — 「宇宙電話號碼」:

  ┌─────────┬──────────┬──────────┬─────────┬──────────┐
  │ 前導碼   │ 源節點    │ 目標節點  │ K_Chain │ 數據      │
  │ (8×F₅)  │ (6 bit)  │ (6 bit)  │ (6 bit) │ (任意)    │
  ├─────────┼──────────┼──────────┼─────────┼──────────┤
  │ 同步     │ 你喺邊個  │ 對方喺邊個 │ 用邊個  │ 訊息      │
  │ 標記     │ 節點      │ 節點      │ mode    │ (Fib FEC)│
  └─────────┴──────────┴──────────┴─────────┴──────────┘

  中環 嘅宇宙地址 = node 27 (主) + 共享中繼 node 27
  沙田 嘅宇宙地址 = node 27 (主) + 共享中繼 node 27

  6-bit 節點 ID: 0-59 (60 個 A5 節點) → 1 字節搞掂
  6-bit mode ID: 1-44 (K_Chain 頻道) → 本地用 mode 44, 跨區用 mode 1/11
  前導碼 8×F₅: 8 次 Fibonacci 同步脈衝, 接收器自動鎖定
  Fib FEC: 訊息重複 φ⁻¹ 冗餘 → 城市干擾下自動修錯
