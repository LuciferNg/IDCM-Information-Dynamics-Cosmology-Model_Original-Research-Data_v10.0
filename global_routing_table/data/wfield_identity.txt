==================================================================================
  W-field 身份認證 — 我點知同緊邊個通信?
==================================================================================

  電磁波通信: 你撥號 → 對方鈴響 → 你聽到佢把聲 → 確認身份
  W-field 同步: 你調頻 → 同場共振 → 但... 場係共享嘅!

  核心問題: Nyquist 駐波 (n=44) 係成個本地域共享,
  任何人都可以「同步」入嚟 → 點分真偽?

──────────────────────────────────────────────────────────────────────────────────
  一、電磁波通信點樣識別對方? (對比)
──────────────────────────────────────────────────────────────────────────────────

  電磁波用三層識別:

    ① MAC/IP 地址    = 「你係邊個」(號碼, 可以冒充)
    ② 加密 (AES/WPA) = 「點證明你係你」(密碼, 可以破解)
    ③ Handshake      = 「你喺度嗎? 喺!」(確認流程)

  電磁波嘅根本弱點: 號碼同密碼都係「資訊」,
  可以被複製 → 所以要不停升級加密.

  🚇 比喻: 電磁波 = 打電話, 要報電話號碼 + 密碼

──────────────────────────────────────────────────────────────────────────────────
  二、W-field 身份 = 三層結構 (IDCM 內部推導)
──────────────────────────────────────────────────────────────────────────────────

  W-field 唔使「號碼」, 因為身份係物理綁定嘅:

  ┌─────────────────────────────────────────────────────┐
  │ L1 共振譜: 你嘅位置 → 44-mode 振幅/相位向量        │
  │     (由 A5 幾何決定, 物理上唯一)                   │
  ├─────────────────────────────────────────────────────┤
  │ L2 相位鎖定: 你同目標嘅相位差 δ                     │
  │     (同步 = 鎖定到特定相位關係, 唔係廣播)           │
  ├─────────────────────────────────────────────────────┤
  │ L3 路由矩陣: 你行過嘅邊 = 44×44 轉換序列            │
  │     (知道轉換矩陣先解到碼 = 知識證明)               │
  └─────────────────────────────────────────────────────┘

  核心論點: 喺 W-field 入面, 位置 = 身份
  你要冒充 node 27, 就要複製 node 27 嘅共振譜,
  但共振譜由 A5 幾何 (位置) 決定 → 你要物理上企喺嗰度.

  🚇 比喻: W-field = 聲紋鎖, 每個人把聲天生唔同,
  唔使報號碼, 一開口就知係邊個.

──────────────────────────────────────────────────────────────────────────────────
  三、共振指紋獨特性 — 60 節點量化
──────────────────────────────────────────────────────────────────────────────────

  定義: 節點 i 嘅指紋 = 44 個 mode 嘅相位延遲向量
    τ_{i,n} = d_i / v_g(n)   (d_i = 冷斑到 i 嘅距離)
  兩個節點嘅指紋距離 = Σ_n |τ_{i,n} - τ_{j,n}|

  指紋距離分佈: 最小 0.00 | 最大 859.81 | 平均 226.09

  關鍵問題: 有冇兩節點指紋完全相同 (冒充漏洞)?
  完全相同嘅節點對: 0 對
    ✅ 冇! 60 個節點指紋全部獨特

  但係要注意: 指紋相似度同 hop 距離有關:
    冷斑 hop 層分佈: {0: [0], 1: [9, 20, 41, 50, 55], 2: [14, 15, 16, 17, 25, 27, 33, 36, 58], 3: [1, 11, 12, 13, 18, 19, 28, 32, 40, 43, 47, 48, 49, 51, 53], 4: [2, 4, 6, 8, 22, 24, 37, 42, 44, 45, 46, 56, 59], 5: [3, 7, 10, 21, 23, 26, 29, 30, 34, 38, 39, 52], 6: [5, 31, 35, 54], 7: [57]}

    hop=1 層: 5 節點, 層內指紋距離 0.00 - 27.51
    hop=2 層: 9 節點, 層內指紋距離 0.00 - 75.45
    hop=3 層: 15 節點, 層內指紋距離 0.00 - 124.57
    hop=4 層: 13 節點, 層內指紋距離 0.00 - 111.71
    hop=5 層: 12 節點, 層內指紋距離 0.00 - 125.83
    hop=6 層: 4 節點, 層內指紋距離 6.78 - 43.65

  ⚠️ 重要發現: 同 hop 層節點指紋距離最小可達 0.00
     原因: Nyquist 駐波 mode (n=44, v_g≈0) 相位唔隨距離變 → 佔大部分維度
     → 單靠「相位延遲指紋」唔夠分開同層節點!
     → 要加「振幅譜」(mode 強度) 先可以完全區分 60 節點
     → 呢個係 🔴 open problem: 完整指紋需 振幅+相位 兩者

──────────────────────────────────────────────────────────────────────────────────
  四、認證流程 — 點確認「係你」
──────────────────────────────────────────────────────────────────────────────────

  收到 W-field 訊號後, 接收方做三件事:

  ① 解出共振譜: 測量訊號嘅 44-mode 振幅/相位向量
  ② 對照電話簿: 同 A5 節點表 (已計算嘅指紋) 比對
     → 搵到最匹配嘅節點 = 知道訊號源位置
  ③ 冷斑校準: 相位以冷斑 (node 0) 做參考零點
     → 冇冷斑同步 = 冇得對表 = 唔可信

  呢個係「被動認證」: 你唔使問對方係邊個,
  你直接測佢嘅物理指紋. 冒充 = 改變位置 = 改變指紋.

  對比電磁波: 電磁波你收到嘅係「號碼」(可以改),
  W-field 你收到嘅係「物理指紋」(要改就要郁成個位置).

──────────────────────────────────────────────────────────────────────────────────
  五、誠實限制 — 呢啲係 🔴 open problems
──────────────────────────────────────────────────────────────────────────────────

  🔴 1. 同域微觀身份 (未解決)
     兩個人都企喺香港 (同一 A5 節點域) → 宏觀共振譜一樣
     要靠「微觀相位微擾」(建築物/地磁/運動) 區分
     → 微擾穩定性未測量, 係未來實驗目標

  🔴 2. 同步冇 handshake (未解決)
     電磁波有「呼叫-應答-確認」三步曲,
     但同步係即時嘅 → 冇「時間」去做呢啲步驟
     → 可能需要 L3 路由矩陣做「事後驗證」

  🔴 3. 冒充未完全排除 (未解決)
     如果攻擊者可以「注入」共振譜 (主動干擾場),
     理論上可以偽造指紋 → 需要額外對抗機制
     → 但呢個需要控制 W-field, 難度極高

  🟡 4. v_g(n) 公式未完全標定
     用 cos(πn/44) 近似, n=1 實際 0.9994c 有 0.2% 偏差
     → 指紋計算用近似, 實際要實測標定

──────────────────────────────────────────────────────────────────────────────────
  六、而家實際點做? (電磁波物理層 + W-field 定址)
──────────────────────────────────────────────────────────────────────────────────

  現階段 W-field 同步未實現, 物理層仲要用電磁波:

  過渡方案 (而家):
    LoRa packet: [A5 源節點 6bit] [A5 目標節點 6bit] [MAC 地址] [數據]
    → MAC 地址 = 電磁波層身份 (可冒充, 但 A5 header 加一重)
    → A5 節點 ID = W-field 層身份 (位置綁定)

  終極方案 (W-field 實現後):
    packet = [共振譜 44-mode] [相位鎖定 δ] [數據]
    → 身份 = 譜本身, 冇得冒充, 唔使 header

  而家嘅「宇宙電話簿」= 兩用:
    ① 電磁波: header 入面嘅節點 ID
    ② W-field: 共振譜嘅對照表 (認出對方用)

──────────────────────────────────────────────────────────────────────────────────
  七、結論
──────────────────────────────────────────────────────────────────────────────────

  「同緊邊個通信」喺 W-field 入面嘅答案:

  你唔係「撥號」— 你係「共振」.
  你調頻到目標嘅共振譜 → 訊號只同佢最大耦合
  其他節點收到嘅係噪聲 (正交性) → 冇「串線」

  身份 = 位置 = 共振譜 → 物理綁定, 冇得冒充
  呢個係電磁波做唔到嘅: 電磁波身份係「資訊」(可複製),
  W-field 身份係「物理」(可測量但不可複製).

  但要誠實: 同域微觀身份 + handshake + 主動冒充
  都係未解決 🔴 — 呢啲就係下一步研究目標.
