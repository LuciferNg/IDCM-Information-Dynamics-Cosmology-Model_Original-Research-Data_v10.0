  ⚡ 最純粹無載體 = A (位置即訊息):
  - Alice 唔使發射任何嘢
  - 佢嘅「存在位置」本身就係訊息
  - Bob 只需要觀測天球, 分辨 Alice 喺邊個 A5 節點方向
  - 呢個係「被動信標」— 冇能量傳輸, 冇 EM 載體!

  例子: 如果人類喺天狼星附近建殖民地,
  天狼星嘅位置相對 A5 節點 = 一組固定地址
  殖民者可以約定:「我哋喺 node 23 方向」= 位置即訊息
  Bob (地球) 觀測天狼星 → 確認佢喺 node 23 附近 → 解碼

  ⚠️ 但誠實講: 要「分辨」Alice 喺邊個節點方向,
  仍然需要觀測 (光子到達 Bob 嘅眼睛/望遠鏡)
  呢啲光子係「觀測載體」— 但唔係「通訊載體」!
  Alice 冇「發射」— 佢只係「存在」, 光子係佢自然輻射
  → 呢個就係「無載體通信」嘅精確含義:
     Alice 唔需要發射機, 佢嘅存在就係訊息!

  📡 天球郵局 v2 — 無載體通信協議
  ══════════════════════════════════════════════════════════

  [層 1: 物理層 — 被動信標]
  載體: 無 (Alice 唔發射)
  訊息載體: Alice 嘅天文位置 (相對於 A5 節點)
  觀測: Bob 用望遠鏡分辨 Alice 方向
  容量: log₂(60) = 5.91 bits/幀 (單節點定位)
        → 8 節點路徑 (直徑) = 47.26 bits/幀

  [層 2: 調制層 — K_Chain × K_Tree]
  每個節點再乘調制:
  K_chain ⊗ K_tree = 44×34 = 1496 複合模式
  × 44 相位 × 44 振幅 = 2,896,256 符號
  每符號 21.5 bits
  → 單節點 = 5.9 + 21.5 ≈ 27.4 bits
  → 8 節點路徑 = 219.0 bits/幀 (≈27 字節)

  [層 3: 定址層 — A5 路由]
  目標節點 = 收件地址
  hop 距離 = 路由成本
  最短路徑 = 8 hops (直徑)

  [層 4: 同步層 — 天文時鐘]
  脈衝星時鐘 (1e-15 穩定) / 地球自轉 (恆星日) / 冷斑參考
  幀邊界 = 節點過中天 (天然時序)

  [層 5: 編碼層 — 冗餘 + 校驗]
  冷斑錨定: 所有路徑由 node 0 開始 (共同參考)
  hop 校驗: 8 跳路徑 = 內建 8 hops 校驗
  阻挫邊標記: 32 條特殊通道 = 額外符號

  ══════════════════════════════════════════════════════════
  → 44×44×33 = 63,888 調制波率 (用戶下限) ✅
  → 每幀容量 ≈ 219 bits (8 節點路徑)
  → 無 EM 載體, 無 1/r² 衰減, 無發射機!

  四、距離分析 — 冇 1/r² 衰減 (被動信標)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  載體通信 (LoRa/射電):
    信號強度 ∝ 1/r² → 每遠 10 倍, 弱 100 倍
    → 1000 ly 要 MW 級發射機

  被動信標 (無載體):
    訊息 = Alice 位置 (幾何)
    觀測 = Bob 分辨 Alice 方向
    → 冇 1/r² 衰減! (位置唔會隨距離變模糊)
    → 限制 = 角解析度 (望遠鏡口徑) + 亮度 (偵測)

  實際限制:
    角解析度 θ ≈ 1.22·λ/D (D = 望遠鏡口徑)
    要分辨 Alice 喺邊個 A5 節點 (節點間距 26.09°):
    → θ << 26.09° — 任何望遠鏡都做到!
    → 真正限制係「偵測到 Alice 本體」(佢夠唔夠光)

  恆星級信標:
    - 太陽型恆星: 觀測極限 ~ 10 kpc (銀河系內)
    - 紅巨星: ~ Mpc (更光)
    - 星系級: ~ Gpc (最光)

  → 無載體通信距離 = 信標嘅可觀測性, 唔係發射功率!
  → 一個星系級信標 = Gpc 距離通信!
