  二、晶振 — 任何物質都得? 頻率對就行?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  晶振共振頻率公式 (厚度剪切/厚度縱向):
    f_res = v/(2·d)     d = 晶片厚度, v = 對應聲速

  材料無限制! 任何有聲速嘅固體都有機械共振:

  ✅ 答案: 任何物質理論上都得 — 頻率對 = 厚度啱!
  ⚠️ 但工程條件:
     1. 壓電性: 冇壓電 = 要外部換能器 (效率大減)
     2. 溫度穩定: 石英 AT-cut 零溫度係數 (其他材料漂移)
     3. Q 值: 石英 Q~10⁵-10⁶ (極高), 水冰 Q~10³ (低)
     4. 加工: 石英可以精確切割, 水冰會溶!
  → 晶振標準 = 石英 (合成石英, 工業成熟)
  → 水冰/鹽: 概念可行, 實驗玩具 (低 Q, 難加工)

  📌 特別案例: 冰嘅壓電性
  - 冰 Ih 理論上有壓電效應 (質子無序打破中心對稱)
  - 但極弱 (d33 ~ 0.02 pC/N, 石英嘅 1/100)
  - 1960-70 年代研究過冰晶體共振器 (南極冰層聲學)
  - 結論: 冰可以做聲子介質/波導, 但做主動晶振唔實際

  三、44×44×33 調制方案 — K_Chain × K_Tree 複合本徵模式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  K = K_chain ⊗ K_tree 嘅複合本徵模式:

  λ_{n,m} = γ_n · μ_m
    γ_n = 4·sin²(πn/88)   (n = 1..44, chain 色散)
    μ_m = φ^{L-m}         (m = 0..33, tree 尺度階梯, L = 53/8)

  ══════════════════════════════════════════════════════════
  44 (chain modes) × 34 (tree levels) = 1496 個複合本徵模式
  ══════════════════════════════════════════════════════════

  每個複合模式 (n,m) 係一個「調制波率」:
  - 對應晶體嘅一個聲子模式 (波數 n × 尺度層 m)
  - n = 晶體布里淵區波數 (K_Chain 同構)
  - m = 晶體結構層級 (原子 → 晶胞 → 晶粒 → 宏觀)

  44×44×33 嘅含義:
  - 44 (chain modes): 同一尺度層嘅 44 個振動模式
  - 44 (相位/頻率編碼): 每個模式嘅 44 級相位調制
  - 33 (tree levels): 33 個尺度層 (m = 0..33)
  → 最少 44×44×33 = 63,888 種調制波率
  → 但結構上係 44×34 = 1496 個複合本徵模式,
    每個模式再乘相位/振幅編碼

  鈮酸鋰 8×8 聲子矩陣天線 (433 MHz 聲波):

  聲波長: λ = v/f = 6570.0/4e+08 = 15.173 μm
  單元間距: d = λ/2 = 7.587 μm
  陣列尺寸: 8×8 × d = 60.7 μm (約 0.06 mm)

  波束形成:
  方向 φ 需要相位梯度: Δθ = 2π·d·sin(φ)/λ
  相位梯度 = π·sin(φ) (因為 d=λ/2)

  每個單元: 一個 433 MHz SAW 共振器 (鈮酸鋰叉指換能器 IDT)

  調制方案:
  - 頻道 = (chain mode n, tree level m) 複合模式
  - 每頻道調制: 相位 (44 級) × 振幅 (44 級)
  - 波束 = 空間方向 (矩陣相位梯度)
  - 時間 = 幀序列

  ⚠️ 誠實標記:
  - 呢個係「聲子通信」: 信號喺晶體內部以聲速傳播
  - 唔係 LoRa 電磁波: 唔會穿過空氣/真空
  - 用途: 晶片間通信 / 晶體內部邏輯 / 感測器網絡
  - 唔係宇宙通信 (宇宙距離需要真空傳播 = 電磁波/光)
