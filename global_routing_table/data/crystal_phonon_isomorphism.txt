  五、晶振物理 — 任何物質都得? (頻率對就行?)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  晶振 (crystal oscillator) 嘅物理:

  石英晶振 = 石英片嘅厚度剪切共振:
    f_res = v_s / (2·d)      (d = 晶片厚度, v_s = 剪切聲速)
    32.768 kHz → d = v_s/(2f) = 5750/(2·32768) ≈ 87.7 mm?? 錯!

  正確: 石英 AT-cut 剪切聲速 ~ 3320 m/s:
    32.768 kHz → d = 3320/(2·32768) = 50.7 μm (好薄!)
    10 MHz     → d = 3320/(2·1e7) = 166 μm
    433 MHz    → d = 3320/(2·4.33e8) = 3.8 μm (極薄, 易碎)

  任何物質都得? 技術上係:
    f_res = v_s/(2d) — 頻率只由「聲速 + 厚度」決定
    水冰: v_s=3200, 要 32.768 kHz → d = 48.8 μm (可以!)
    鹽:   v_s=4600, 要 32.768 kHz → d = 70.2 μm (可以!)
    但...
    ⚠️ 要「壓電」先可以直接電激發! (石英/鈮酸鋰/羅謝爾鹽)
    ⚠️ 非壓電材料 (水冰/鹽/鑽石) 要外部換能器 (壓電片貼上去)
    ⚠️ 溫度穩定度: 石英 AT-cut 係零溫度係數, 其他材料會漂移

  → 答案: 任何物質「理論上」都得 (頻率對 = 厚度啱),
    但工程上要壓電性 + 溫度穩定 → 石英獨佔鰲頭!
