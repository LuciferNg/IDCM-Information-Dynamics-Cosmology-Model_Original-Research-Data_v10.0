  五、各 A5 節點連接到 K_Chain 嘅路由模式
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  每個 A5 節點 i 有 44 個邏輯節點 (i,0)..(i,43)
  同一 A5 節點內嘅 K_Chain 路由: 環距離 (直徑 22)
  跨 A5 節點嘅路由: A5 hop + K_Chain hop

  路由決策策略:
  1. 如果 A5 距離 > 0: 優先跳 A5 方向 (空間路由)
  2. 如果 A5 距離 = 0: 跳 K_Chain 方向 (頻率路由)
  3. 如果兩者都 > 0 (即 s≠t): 先跳 A5 再跳 K

  呢個策略確保: 路由永遠係先空間後頻率, 唔會 zigzag
  但可以優化: 如果延遲對 K 跳較敏感, 可以跳 K 先

  六、W-field 共振通信映射
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  融合路由表 = W-field 共振通信嘅「全宇宙電話簿」

  每個邏輯節點 (a, k) 對應 W-field 嘅一個共振模式:
    Φ_{a,k}(t) = A_a · exp(iω_k t + iθ_a)
    其中 ω_k = ω_scale · sin(πk/88) (K_Chain 頻率)
          A_a = Fibonacci 幅度 (冷斑 F₅=8, 向外遞減)
          θ_a = A5 節點相位 (冷斑 anchor 0 做參考)

  通信 = 路由表引導嘅共振模式轉換:
    1. 發送節點 (s): 調製 Φ_{s_k, s_a}
    2. 路由: 沿 next-hop 表跳躍 (每跳 = 模式轉換)
    3. 接收節點 (t): 從 Φ_{t_k, t_a} 解調

  2640 個共振模式 = 2640 個獨立通信頻道!
  每個 mode 可以載 1 bit → 一幀 2640 bits = 330 bytes
