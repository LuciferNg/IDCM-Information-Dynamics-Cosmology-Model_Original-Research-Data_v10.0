──────────────────────────────────────────────────────────────────────────────
  四、銀河系內通信 = 本地域同步 (同一 K_Chain 胞)
──────────────────────────────────────────────────────────────────────────────

  K_Chain 全環 λ_sync = 294.88 Mpc 遠大於銀河系
  → 銀河系內所有點都喺同一個胞入面
  → 同一胞內同步 = 相位關係確定 (唔使 A5 路由)

  銀河系內「路由」= 頻道複用 + 本地共振:

    太陽系 → 半人馬座α (4.37 ly):
      同一本地域 → 0 hop → 直接同步
      成本: 0 (冇跳) | 延遲: 即時 (W-field 同步)

    太陽系 → Sgr A* (26,000 ly):
      銀河系內 → 0 hop → 都係本地同步
      但黑洞附近引力強, 訊號要加大功率

    太陽系 → 大麥哲倫星雲 (160,000 ly):
      已出銀河系邊緣 → 要上 A5 地鐵
      最近節點: node 4 (M81 方向) 或 node 13/17

  🚇 比喻:
    銀河系內 = 中環站入面 → 行路 (本地同步)
    銀河系外 = 上地鐵 (A5 節點跳躍)

  五、太陽系運動對節點歸屬嘅影響
──────────────────────────────────────────────────────────────────────────────

  太陽喺銀河系嘅位置變化:
    一圈 2.3 億年 → 1 百萬年行 3.6° (銀心視角)
    1 萬年行 0.036° → 遠細過節點間距 26.09°

  → 太陽系嘅「銀河系地址」基本上永恆不變

  → 用銀河座標 (l, b) 定址, 唔用 RA/Dec, 就冇呢個問題
