  物理圖像:
  K_Chain = 44-site 環 (宇宙晶格振動)
  A5 節點 i = 天球上嘅位置 (冷斑軌道)

  耦合: 節點 i 對 mode n 嘅響應 = 幾何投影
  c_{i,n} = |ψ_n(v_i)|²  (mode n 喺方向 v_i 嘅振幅)

  簡化模型 (K_Chain 環投影到天球):
  mode n 沿環有 k_n = n·(2π/R_H) 嘅波數
  投影到天球: 環 = 大圓 (冷斑軌道)
  節點 v_i 喺大圓嘅位置 → 相位 φ_i
  c_{i,n} = cos²(n·φ_i/2 + δ_n)  (駐波投影, n=44 係 Nyquist)

  更實際: 用節點嘅球面座標 (θ_i, φ_i) 直接投影
  c_{i,n} = |Y_{n,m}(θ_i, φ_i)|²  (球諧投影, m=n 簡化)

  二、相位滑移 π — 模式共振條件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  節點 i 嘅 W-field 相位:
  θ_i = Σ_n c_{i,n}·a_n    (模式振幅投影)

  相位滑移 π (翻轉):
  Δθ_i = Σ_n c_{i,n}·Δa_n = π

  方案 A: 單一模式共振
    Δa_n = π / c_{i,n}
    對 ΔE=0 節點 (k=2): 需要 c_{i,n} 大 → 揀最大耦合模式

  方案 B: 雙模式拍頻 (beat)
    兩個模式 (n1, n2) 拍頻 ω_beat = |ω_n1 - ω_n2|
    拍頻累積相位: Δθ(t) = Δa·(1 - cos(ω_beat·t))
    當 ω_beat·t = π: Δθ = 2Δa → 翻轉!

  方案 C: 全域同步模式 (n=44, Nyquist)
    ω_44 = 2 (最大), v_g = 0 (駐波)
    全域相位鎖定 → 最強耦合
    激發 n=44 → 所有節點相位同步滑移?
    但 ΔE=0 節點需要「局部」翻轉 → 要局部模式!
