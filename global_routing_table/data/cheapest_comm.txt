  一、地球自轉影響
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  恆星日: 23.9345 小時
  自轉速率: 15.0410°/hour = 0.004178°/s

  冷斑位置: RA=48.3°, Dec=-20.4°
  從地表睇, 冷斑每日經過天頂一次
  經過天頂嘅時間 = f(latitude, longitude, date)

  地球自轉對通信嘅影響:
  1. 固定方向天線只能接收特定時間窗口嘅節點
  2. 全向天線 + 軟體選擇性接收可以解決
  3. 時間窗口 = 天然嘅「時間編碼」頻道

  二、太陽系移動影響
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  太陽系繞銀心速度: 220 km/s
  相對論效應: β = 0.000734
  年視差: 151.3656 arcsec/year

  對冷斑位置嘅影響: 151.3656 arcsec/year
  冷斑 angular size: R8 = 4.17° = 15012 arcsec
  需要 99 年先會偏離 1 個冷斑直徑

  結論: 太陽系移動對通信影響可忽略 (< 0.1 arcsec/decade)
  但路由表需要每 ~10^4 年 recalibrate 一次

  通信協定:

  1. 同步階段: 雙方用冷斑做時間基準
     - 冷斑經過天頂嘅時刻 = t₀ (由經緯度 + 日期計算)
     - 雙方校準時鐘到 t₀

  2. 編碼階段: Alice 用觀測時間 encode 信息
     - 地球自轉 = 天然時鐘
     - 每 24 小時 = 360° = 60 個 A5 節點
     - 每 24 min = 1° = 一個節點嘅 angular width
     - Alice 喺約定時間 t 觀測節點 i
     - 時間 t = t₀ + i × 24min (i = 0..59)
     - Bob 知道 t → 知道 Alice 觀測邊個節點

  3. 解碼階段: Bob 用路由表 decode
     - Bob 知道 Alice 觀測嘅節點 i
     - 路由表話俾 Bob 知: 節點 i 嘅所有鄰居、距離、路徑
     - 信息 = 節點 i 嘅路由表內容

  4. 地球自轉補償: 軟體自動計算
     - 知道 latitude/longitude → 計算冷斑經過天頂時間
     - 知道 UTC → 計算當前可見節點
     - 全向天線 + 軟體濾波 = 不受自轉影響

  5. 太陽系移動補償: 每 ~10^4 年更新路由表一次
     - 當前冷斑位置: RA=48.3°, Dec=-20.4°
     - 年視差: ~0.0002 arcsec
     - 10^4 年後: ~2 arcsec (仍遠小於 4.17° 冷斑尺度)

  - 只能單向通信 (Alice → Bob)
