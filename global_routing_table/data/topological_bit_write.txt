┌──────────────────────────────────────────────────────────────┐
│  A5 晶網: 60 節點, 120 邊                          │
│  阻挫邊: 32 (同色相鄰, 高能)                            │
│  正常邊: 88 (異色相鄰, 低能)            │
│                                                              │
│  Ising 模型: H = -Σ J·σ_i·σ_j                                │
│  σ = +1 (冷) / -1 (熱)                                       │
│  完美邊 (異色): σ_i·σ_j = -1 → 能量 +J... 等等, 重新定義      │
│                                                              │
│  標準 Ising: H = -J·σ_i·σ_j, 同向 (σ_i=σ_j) 低能             │
│  但 A5 著色: 同色相鄰 = 阻挫 (高能)                           │
│  → 反鐵磁 Ising (J < 0): 反平行先低能                        │
│  H = +|J|·σ_i·σ_j → 同色 (+1) 高能, 異色 (-1) 低能           │
└──────────────────────────────────────────────────────────────┘

  一、Ising 能量 — 阻挫 = 高能態
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Ising 能量:
  H_total = Σ_⟨ij⟩ σ_i·σ_j = -56.0
    = 阻挫邊 32 (32 條, 每條 +1)
    + 正常邊 -88 (88 條, 每條 -1)
  檢查: 32×(+1) + 88×(-1) = -56 ✅ -56.0

  → 阻挫邊 = +1 (高能, 反鐵磁 frustrated)
  → 正常邊 = -1 (低能, 反鐵磁 satisfied)
  → 總能量 H = -56.0 (正值 = 整體 frustrated)

  翻轉統計:
  每節點翻轉 → 4 條邊狀態全反轉 (阻挫 ↔ 正常)
  ΔE = -2·σ_i·Σ_j σ_j — 能量變化由鄰居顏色決定

  節點按阻挫邊數分類:

    0 條阻挫邊: 8 節點
    1 條阻挫邊: 40 節點
    2 條阻挫邊: 12 節點

  能量變化分佈: min=+0, max=+8
  → 翻轉節點可以升高或降低能量 (視乎鄰居)
  → 降低能量嘅翻轉 = 自發傾向 (放能)
  → 升高能量嘅翻轉 = 需要注入能量 (寫入!)

  三、信息容量 — 阻挫邊圖案編碼
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  信息容量分析:

  ① 阻挫邊狀態 (32 bits):
     32 條阻挫邊, 每條可翻轉 (阻挫↔正常) = 32 bits 原始
     但受圖著色約束 (翻轉節點 = 4 邊一齊變)

  ② 節點翻轉編碼:
     翻轉 1 節點: C(60,1) = 60 → 5.91 bits
     翻轉 2 節點: C(60,2) = 1770 → 10.79 bits
     翻轉 3 節點: C(60,3) = 34220 → 15.06 bits

  ③ 最大獨立集 (同時可翻轉, 無互相干擾):
     貪婪 MIS 大小 = 20 節點
     同時翻轉 MIS: 2^20 = 2^20 種圖案
     → 20 bits/幀 (獨立翻轉)

  ④ 動態編碼 (時序):
     翻轉順序 = 額外維度
     連續 k 步: 每步 4.32 bits → k×4.32 bits

  📝 拓撲位元寫入-讀取協議
  ══════════════════════════════════════════════════════════

  [寫入] Alice 喺節點 i 翻轉顏色 (拓撲操作):
    1. 施加局部場 h_i (物理機制 🔴 待推導)
    2. σ_i 翻轉 → 4 條邊狀態反轉
    3. 阻挫邊圖案改變 = 訊息寫入!
    4. 能量變化 ΔE 釋放/吸收 → 修復波 (上 script)

  [傳播] 修復波沿 A5 最短路徑:
    1. 翻轉事件 = 應變能釋放
    2. 波沿 BFS 路徑傳播 (≤ 8 hops)
    3. 速度 = c (因果性)

  [讀取] Bob 觀測阻挫邊圖案:
    1. 測量節點顏色 (CMB 溫度/極化)
    2. 計算阻挫邊分佈
    3. 對比參考圖案 → 解碼翻轉位置
    4. 翻轉序列 → 訊息

  [同步] 天文時鐘:
    脈衝星 / 地球自轉 / 冷斑 (node 0 固定)
