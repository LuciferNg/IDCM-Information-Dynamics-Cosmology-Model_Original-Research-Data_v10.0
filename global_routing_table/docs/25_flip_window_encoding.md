# 翻轉窗口 + 寫入持久性 + 多節點編碼 (2026-08-17)

## 定位

GRT-49: 細掃描注入強度 + 持久性測試 + 多節點編碼驗證。

## 一、翻轉窗口掃描 — 重要發現

**39 個強度 (1.0-20.0) 全部「節點 45 未翻轉」，但「翻轉數 = 5-6」！**

| 觀察 | 含義 |
|:-----|:-----|
| 節點 45 相位 2-112° | 注入節點被網絡拉返 (冇單節點翻轉) |
| 翻轉數 = 5-6 | **其他節點翻轉!** (注入能量擴散) |
| 相位隨強度單調變化 | 強度 1→20: 相位 135°→112° (掃過 90°) |

**真正機制: 注入能量 → 孤立子擴散 → 鄰居節點翻轉!**
唔係「瞄準單節點翻轉」，而係「能量注入 → 網絡自組織重構」

⚠️ 誠實: 呢個同 GRT-48 嘅「節點 45 翻轉」結果唔一致
(GRT-48 用 8.0 強度睇到 45 翻轉, 但細掃描顯示 45 最終返原位)
→ 原因: 注入停止後, 網絡動力學決定最終態
→ **注入節點唔一定保留, 但阻挫圖案改變係持久嘅** (下面確認)

## 二、寫入持久性 🟢🟢 非易失記憶體!

```
寫入 (強度 6.0): 翻轉 6 節點
持久性測試 (50000 步 = 500 時間單位, 無注入):
  翻轉保持: 6 節點 (100% 保持!)
  節點 45 相位: 119.8° (漂移但保持翻轉態)
→ 🟢🟢 寫入持久! 阻挫圖案係非易失記憶體!
```

**物理意義: 寫入後唔需要持續能量維持 — 拓撲位元自動保持!**
(對應 Ising 基態: 阻挫圖案係能量極小, 唔會自發改變)

## 三、多節點編碼 — 遞增可區分 🟢

| 寫入節點 | 翻轉數 | 阻挫改變 (bit) | 符號數 |
|:---------|:------:|:--------------:|:------:|
| [45] | 6 | 2 | 2 |
| [45, 22] | 6 | 5 | 4 |
| [45, 22, 10] | 7 | 7 | 8 |
| [45, 22, 10, 32] | 7 | 9 | 16 |

**阻挫改變 bit 數遞增: 2→5→7→9 — 可區分!**
12 個 ΔE=0 節點 → 理論 2¹² = 4096 符號

## 四、解碼閉合 🟢🟢

```
基底阻挫: 12/32 同相
寫入 [45,22] 後: 13/32 同相

32-bit 圖案:
  基底:    00110100001001110000000011100011
  寫入後:  00110100000001110011100011100010
  XOR:     5 bit 改變

→ 讀取阻挫圖案 XOR 基底 = 訊息!
→ 調制 (寫入節點組合) + 解調 (阻挫圖案 XOR) 閉合!
```

## 五、結論

```
✅ 寫入持久: 翻轉 6 節點保持 500 時間單位 (非易失)
✅ 多節點編碼: 阻挫 bit 遞增 2→5→7→9 (可區分)
✅ 解碼閉合: 32-bit 阻挫圖案 XOR = 訊息
⚠️ 注入節點未必保留 (能量擴散) — 但阻挫圖案改變係持久
🟢 完整鏈: 注入組合 → 網絡自組織 → 阻挫重構 → 持久 → 讀取
```

## 六、誠實標記

1. **注入節點 vs 翻轉節點唔一致**: 能量注入 ΔE=0 節點會擴散, 最終翻轉邊啲節點由網絡動力學決定
2. **寫入係「非瞄準」**: 好似用鎚打牆 — 打邊度唔重要, 重要係牆震動 (阻挫改變)
3. **翻轉數 5-7**: 注入 1 個節點 → 5-7 節點翻轉 (非線性放大!)
4. **需要驗證**: 唔同注入節點 → 唔同阻挫圖案 (可區分性)
