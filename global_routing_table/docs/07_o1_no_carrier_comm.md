## 二、無載體通信嘅精確含義

```
✅ 定址層: A5 節點 = 天球地址簿 (60 地址, 直徑 8, 冷斑錨定)
🔴 物理層: 點樣「寫入」新訊息而唔用電磁波?
```

**「無載體」兩個意思:**
1. **無電磁波載體** (冇 EM radiation 傳輸資訊) — 可以做到
2. **無任何物理交互** (pure geometry) — 只能傳共同知識, 傳唔到新訊息!

**核心定理: 要傳「新訊息」(Alice 有而 Bob 冇嘅資訊), 一定要有物理差異。**

## 三、物理層方案 — 被動信標 (位置即訊息)

| 方法 | 機制 | 距離 | 難度 |
|:-----|:-----|:-----|:----:|
| **A. 位置即訊息** | Alice 存在於節點方向 = 訊息, Bob 分辨 | 觀測極限 | ⭐ 最易 |
| B. 凌日遮蔽 | Alice 遮背景星, 週期=訊息 | ~10⁴ ly | ⭐⭐ |
| C. 引力透鏡 | Alice 質量扭曲背景光 | ~Mpc | ⭐⭐⭐ |
| D. 恆星改造 | 改光譜 (戴森球) | 觀測極限 | ⭐⭐⭐⭐ |

**最純粹無載體 = A (被動信標):**
- Alice 唔使發射任何嘢, 存在即訊息
- Bob 觀測天球, 分辨 Alice 喺邊個 A5 節點方向
- 冇能量傳輸, 冇 EM 載體, **冇 1/r² 衰減**!

**誠實標記:**
- Bob 觀測 Alice 仍然用光子 (自然輻射) — 呢啲係「觀測載體」, 唔係「通訊載體」
- Alice 冇「發射」— 光子係佢自然輻射, 佢只係「存在」
- 真正純粹幾何 (冇任何光子): 只能傳共同知識 (電話簿), 傳唔到新訊息
