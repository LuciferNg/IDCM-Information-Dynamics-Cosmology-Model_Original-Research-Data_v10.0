# 設計優化 + 穩定性分析 (2026-08-17)

## 定位

基於 GRT-40 發現（基底阻挫 12/32 ≠ Ising 32/32 + 寫入需 K≥0.8），優化設計及分析穩定性。

## 一、基底優化 — 重大突破 🟢🟢

**對稱初始條件令阻挫數 12/32 → 32/32 完美匹配 Ising 基態！**

| 方案 | 阻挫數 | 壓制比 | 狀態 |
|:-----|:------:|:------:|:----:|
| A 隨機初始 | 12/32 | 1.090 | 🟡 |
| **B 對稱初始 (冷0/熱π)** | **32/32** | 1.105 | 🟢🟢 |
| C 冷斑錨定 | 16/32 | 1.164 | 🟡 |
| D 漸進耦合 | 14/32 | 1.139 | 🟡 |
| **E 對稱+錨定** | **32/32** | 1.113 | 🟢🟢 |

**物理意義**: A5 著色（冷色/熱色）本身就係 Ising 基態嘅編碼！
- 上電時按著色設初始相位（冷色 θ=0, 熱色 θ=π）
- 網絡鎖定到完美 32/32 阻挫 = Ising 基態
- **電路直接「記憶」拓撲基態!**

**電路對應**: 上電時 node 0（冷斑）先起振, 其餘節點按著色設相位 — 用 RC 延時網絡實現（冷色節點先起, 熱色後起）

## 二、寫入 — 基態太穩定嘅物理

對稱基底（32/32 = Ising 基態）寫入測試:

```
K=0.3-1.0 脈衝: 0/32 改變 🔴
K=0.3-0.5 協同: 0/32 改變 🔴
```

**呢個係物理正確**: 基態 = 能量極小 = 最穩定!
- 由基態去激發態需要**真正越過勢壘**（唔係脈衝可以）
- 對應 IDCM: 寫入需要注入 2|h_i| 能量（相位滑移成本）
- **基態穩定 + 寫入難 = 記憶體特性!** （讀取容易, 寫入要能量 — 正正係拓撲位元嘅定義）

## 三、穩定性分析 — 全部 🟢🟢

### 3.1 鎖定時間
```
平均: 16 ms | 最大: 20 ms
→ ✅ 極快鎖定 (電路一上電就穩定)
```

### 3.2 參數擾動 (K 誤差)
```
K ±20%: 阻挫圖案 0/32 改變 🟢🟢
→ 電阻容差完全冇問題 (碳膜 5% 都得)
```

### 3.3 電源雜訊 (頻率抖動)
```
抖動 0.1-1%: 0/32 改變 🟢🟢
抖動 2%:     2/32 改變 🟡
→ 1% 內穩定 (7809 穩壓足夠)
```

### 3.4 溫度漂移
```
100-5000 ppm: 0/32 改變 🟢🟢
→ 碳膜電阻 (100ppm/°C) 到 50°C 溫升都穩定
→ 金屬膜 (50ppm) 更穩
```

### 3.5 冷斑錨定
```
冇錨定 3000 步: 0/32 改變 (自然穩定)
→ 錨定可選 (但推薦保持參考系)
```

## 四、設計建議總結

### 電路升級
```
1. 基底: 對稱初始 (冷0/熱π) — 上電 RC 延時網絡
2. 寫入: 需要真正能量注入 (越過勢壘) — 強脈衝 或 PLL 翻轉
3. 穩定性: 已確認穩健 — 平價元件就得
```

### 元件建議
| 元件 | 建議 | 原因 |
|:-----|:-----|:-----|
| 電阻 | 金屬膜 1% (50ppm) | 溫度穩定 |
| 電容 | C0G 陶瓷 | 溫度穩定 (比 X7R 好) |
| 電源 | 7809/7909 + 100nF 去耦 | 雜訊 <1% |
| 錨定 | 16.384MHz 晶振 → 分頻 1.6kHz | 參考時鐘 |

### 成本影響
```
金屬膜電阻: +¥3 (混裝包)
C0G 電容:   +¥5
晶振+分頻:  +¥2 (CD4060 分頻器)
→ 升級成本: ~¥10 (總成本 ¥169)
```
