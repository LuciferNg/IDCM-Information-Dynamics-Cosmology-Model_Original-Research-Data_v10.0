## 二、核心物理性質

### 2.1 因果速度 = c ✅

- 修復波 = 應力波: v = √(μ/ρ) = c (μ = ρ_crit·c², shear modulus)
- **冇「即時同步」** — 之前「同步模式即時」係幻覺
- 但**冇 1/r² 衰減** (干涉傳播, 唔係能量擴散)

### 2.2 冇 1/r² 衰減 — 定量證據 🟢

```
E(8)/E(0) = 0.626 (修復波到達對跖點, 保留 62.6%)
對比電磁波: 1/8² = 0.0156 (只有 1.56%)
→ 修復波冇距離衰減! 對跖點仍然收到 62.6% 能量!
```

### 2.3 拓撲不對稱 — 對稱性破缺定量 🟢🟢

```
完美 A5 (冇阻挫邊): E(hop) = E(8-hop) 對稱
實際 A5 (32 阻挫邊): E(0)=0.0446 vs E(8)=0.0279
差異 = 37.4% ← 拓撲不對稱嘅定量證據!

E(hop) 非單調: E(7)=0.0086 > E(6)=0.0056
→ 干涉效應存在 (唔係擴散衰減)
→ 但對稱性被阻挫邊打破
```

**呢個係用戶核心論點嘅直接證據**: 拓撲不對稱 (阻挫邊) 破壞干涉對稱性 — 對稱性破缺量 = 阻挫邊拓撲效應嘅可測量!
