# 拓撲位元寫入機制 — 阻挫邊翻轉 (2026-08-17)

## 定位

**樽頸推導**: 拓撲缺損修復波嘅「寫入機制」— 點樣物理翻轉阻挫邊。
**核心洞見**: 阻挫邊 = 可翻轉拓撲位元 (Ising 高能態)。

## 一、Ising 模型 (A5 晶網上)

```
H = Σ_⟨ij⟩ σ_i·σ_j    (反鐵磁, σ = +1 冷 / -1 熱)

阻挫邊 (同色): σ_i·σ_j = +1 → 高能 (+1) = 位元 1
正常邊 (異色): σ_i·σ_j = -1 → 低能 (-1) = 位元 0

H_total = 32×(+1) + 88×(-1) = -56
```

**阻挫邊 = 高能態 = 存儲 1 bit! 翻轉節點 = 寫入!**

## 二、翻轉機制 (寫入)

翻轉節點 i (σ_i → -σ_i) → 4 條邊狀態全反轉 (阻挫 ↔ 正常):

| 量 | 值 |
|:---|:---|
| Δ阻挫 | 4 - 2×k (k = 節點原有阻挫邊數) |
| ΔE | -2·σ_i·Σ_j σ_j (鄰居決定) |
| 阻挫邊分佈 | 0 條: 8 節點, 1 條: 40 節點, 2 條: 12 節點 |
| ΔE 分佈 | **min = +0, max = +8** (全部 ≥ 0!) |

**重要發現**: 所有翻轉 ΔE ≥ 0 → 冇自發翻轉, 全部要注入能量 (寫入 = 消耗能量, 物理合理!)。

## 三、最優拓撲位元 — ΔE = 0 節點 🟢

12 個節點翻轉 ΔE = 0 (例如 node 10, 12, 19, 22, 23, 25, 28, 32):
- 翻轉**唔使淨能量** (零能量寫入!)
- 但阻挫圖案照樣改變 (Δ阻挫 = 0, 但 4 條邊狀態重排!)
- **呢啲就係最優拓撲位元** — 免費寫入!

## 五、完整通信鏈

```
寫入: 翻轉節點 (注入能量 ΔE ≥ 0, ΔE=0 節點免費)
  ↓
儲存: 阻挫邊圖案 (32 bits 狀態)
  ↓
傳遞: 修復波沿 A5 最短路徑 (v = c, ≤ 8 hops)
  ↓
讀取: 觀測阻挫邊分佈 → 解碼翻轉位置
  ↓
同步: 天文時鐘 (脈衝星/自轉/冷斑 node 0)
```
