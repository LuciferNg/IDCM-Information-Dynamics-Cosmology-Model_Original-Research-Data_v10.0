| 電路元件 | 數學對應 |

## 二、兩個數學模型

### Kuramoto (純相位) ❌ 唔夠
```
θ̇_i = ω_i + Σ K_ij·sin(θ_j - θ_i - β_ij)
```
假設振幅相同 → **睇唔到電壓壓制** (比 1.00) — 誠實失敗!

### Van der Pol (真實電路) ✅ 正確!
```
ẍ_i + μ(x_i²-1)ẋ_i + ω²x_i = Σ K_ij(x_j - x_i)
```
非線性飽和 → 振幅動態 → **壓制出現!**
- μ = Wien bridge 飽和強度 (AGC/非線性)
- K>0 正常邊 (電阻), K<0 阻挫邊 (反相器)
