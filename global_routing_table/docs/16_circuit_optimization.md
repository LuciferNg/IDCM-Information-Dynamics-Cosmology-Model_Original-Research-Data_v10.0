## 二、重大模型差距發現 🔴🔴

**Van der Pol 耦合網絡嘅「阻挫圖案」≠ Ising 模型嘅「阻挫」!**

```
Ising 模型 (IDCM):
  阻挫 = 能量極小嘅拓撲性質 (32 邊固定, 靜態)
  翻轉節點 = 改變阻挫邊 (能量變化)

Van der Pol 電路:
  相位鎖定 = 動力學吸引子 (符號模式由初始條件決定)
  脈衝/重聯只會暫時擾動 → 彈返原位 (0/32 改變)
```

**根本原因:**
1. Van der Pol 加性耦合 → 相位鎖定係**全域穩定吸引子**
2. 阻挫邊符號 x_i·x_j 由鎖定相位決定, 唔係由 β=π 強制
3. 網絡「記住」初始條件, 唔係「記住」拓撲

**含義:**
- 電路可以演示**相位鎖定 + 振幅壓制** (7/12 LED 熄滅 ✅)
- 但**寫入 (翻轉阻挫圖案) 需要真正越過勢壘**
- 單靠加性耦合 + 脈衝唔夠 — 需要**非線性/雙穩態節點**

## 三、真正嘅寫入電路 — 需要雙穩態

**對應 Ising 阻挫嘅正確電路模型:**

```
方案 A: Schmitt trigger 節點 (雙穩態)
  每個節點 = 雙穩態振盪器 (兩個穩定相位: 0 和 π)
  阻挫邊 = 反相耦合
  寫入 = 強脈衝越過勢壘 (翻轉雙穩態)

方案 B: 乘性耦合 (Kuramoto-Sakaguchi 型)
  θ̇_i = ω_i + Σ K_ij·sin(θ_j - θ_i - β_ij)
  β=π 真正強制反相 → 阻挫邊係「硬」約束
  → 呢個先對應 Ising 阻挫!
```

**Kuramoto-Sakaguchi 帶 β=π 先係正確模型!**
- 之前 37 用 Kuramoto (β 正確) 但振幅固定 (睇唔到壓制)
- 37b 用 Van der Pol (振幅動態) 但 β 弱 (寫唔入)
- **正確: Kuramoto-Sakaguchi + Van der Pol 混合!**

## 五、GRT-40 結果 (混合模型)

**複數振盪器 + 硬 π 相位耦合:**
```
基底: 阻挫 12/32 (部分) — 動力學鎖定態由初始條件決定
振幅壓制: 1.048 (冇) — 複數模型壓制唔明顯

寫入測試:
  K=0.3-0.5: 0/32 改變 (寫唔入)
  K=0.8:   3/32 改變 🟢
  K=1.0:   5/32 改變 🟢
```

**結論: 硬 π 耦合 + 強耦合 (K≥0.8) 先寫得入!**
- 相位脈衝有效 (改變阻挫邊符號)
- 需要 K ≥ 0.8 (強耦合) — 對應電阻 R ≤ 2.5kΩ
- 基底阻挫 12/32 唔係 32/32 — 動力學 vs 拓撲嘅差距
- **寫入成功但基底唔完美** — 誠實記錄

**電路對應升級:**
- 正常邊: 電阻耦合
- 阻挫邊: 反相器 + 相位鎖定 (PLL) — 硬 π
- 寫入: π 相位脈衝 (需 K≥0.8, R≤2.5kΩ)
- 純 TL074 被動電路: 演示鎖定+壓制 ✅
- 寫入需要: PLL/鎖相主動控制 🔴
