# IDCM v10.0 — Beat Formula φ-power 全表達式化簡

## 核心公式

$$R_{ij,kl} = \frac{\text{beat}(i,j)}{\text{beat}(k,l)} = \frac{|\omega_i - \omega_j|}{|\omega_k - \omega_l|}$$

其中 $\omega_n = 2|\sin(\pi n/88)|$，$n=1,\dots,44$。

## 7 個 CKM Beat Ratio 嘅 φ-power 表達式

### 1. $\tan(\theta_{12})$ — Cabibbo 角

**三角函數形式：**
$$\tan(\theta_{12}) = \frac{\text{beat}(5,6)}{\text{beat}(19,25)} = \frac{\sqrt{2} \cdot \cos(\pi/16) \cdot \sin(\pi/176)}{\sin(3\pi/88)} = 0.2316035403$$

**φ-power 閉合形式：**
$$\tan(\theta_{12}) = \varphi^{-3} - \varphi^{-11} + \varphi^{-16} - \varphi^{-24} + \varphi^{-29} - \varphi^{-37} + \varphi^{-42} - \cdots$$

**指數模式：** $3 \xrightarrow{+8} 11 \xrightarrow{+5} 16 \xrightarrow{+8} 24 \xrightarrow{+5} 29 \xrightarrow{+8} 37 \xrightarrow{+5} 42 \xrightarrow{+8} \cdots$

**閉合形式：**
$$\tan(\theta_{12}) = \frac{\varphi^{-3}}{1 + \varphi^{-8}} + \frac{\varphi^{-16}}{1 - \varphi^{-8}} = 0.2316106712$$

### 2. $\tan(\theta_{23})$

**φ-power 閉合形式：**

### 3. $\sin(\theta_{13})$
