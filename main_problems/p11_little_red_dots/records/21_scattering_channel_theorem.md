## 2. 定理 (數值驗證 PASS)

**對稱 kernel 卷積保對稱**: 若 I(ν) 繞 ν₀ 對稱, K 繞 0 對稱 → I*K 繞 ν₀ 對稱。

驗證 (模態對 ±418 km/s × Thomson exp kernel v_e=1000 km/s):
- 峰高比: 1.0000 → 1.0000 (**偏差 0.00%** — 對稱性完全保持) ✅
- 峰距: 836.1 → 757.2 (收縮 9.4%) — 寬 kernel 塗污令外觀峰距縮, 係**外觀效應**
  非對稱破壞; 對兩線同等 (Thomson 波長無關) ⟹ **Δv(Hβ)/Δv(Hα) 比值判別唔受影響**

⟹ **純 Thomson 散射唔可能令模態對變唔對稱** — record 19/20 嘅觀測唔對稱
**必須**來自非散射 channel (吸收 / bulk 流 / 幾何遮蔽)。

## 3. 吸收 channel 定量 (Part B+D)

吸收因子 e^{−τ(v)} 對藍/紅峰不對等 (藍峰穿更多凝聚層):

| τ_c (對稱基) | 峰高比 R = A_藍/A_紅 | 對稱破壞 |
|:--:|:--:|:--:|
| 0.1 | 0.819 | 18.1% |
| 0.3 | 0.549 | 45.1% |
| 0.5 | 0.368 | 63.2% |
| 1.0 | 0.135 | 86.5% |

IDCM hop 階梯定量 (D): Δτ(836 km/s) ∝ Σhop·(峰距/2v_scale) —
τ_c=1.0 → R=0.870 (藍弱); τ_c=2.0 → R=0.757

**預言: 藍峰弱紅峰強 (R<1) 且方向固定**。
