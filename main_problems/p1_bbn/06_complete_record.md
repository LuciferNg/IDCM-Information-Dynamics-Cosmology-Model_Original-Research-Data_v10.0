## 2. 推導

### 2.1 η_B 結構公式（🟢 閉合, 0.62%）

**推導鏈：** 0,1 → φ → Ω_Λ → Ω_m → Ω_b → η_B

```
Ω_Λ = 4/(φ⁴-1)     = 0.68328   (MERA 分支閉合常數)
Ω_m = 1 - Ω_Λ      = 0.31672
Ω_b = Ω_m/(1+Ω_DM/Ω_b) = 0.04221
Ω_b h² = 0.02224   vs Planck 0.02237 ± 0.00015  → 偏差 0.57%
η_B = n_b/n_γ = Ω_b ρ_c / (m_p n_γ)
    = 6.0622×10⁻¹⁰  vs BBN 擬合 6.1×10⁻¹⁰  → 偏差 0.62% ✅
```

其中 ρ_c = 3H₀²/8πG, n_γ = 2ζ(3)/π² × (k_B T_CMB/ħc)³, T_CMB = 2.7284 K。

**物理意義：** η_B 唔係「重子-光子比」而係 K_Chain 質量幾何分配嘅投影。ΛCDM 要 fit，IDCM 係結構常數。

**⚠️ 單位坑（已記錄）：** m_p 必須用 kg (938.272×1.78266e-30) 唔係 MeV — 否則 η_B 會錯 10³⁰ 倍。

### 2.2 n/p 比 = γ₇/γ₂₀（🟢 閉合, 0.17% — O13 機制已推導）

**發現：** n/p = 1/7 可以由 K_Chain 兩個模式本徵值比得出：

```
γ₇  = 4sin²(7π/88)   = 0.2446   (DM 模式! m_7 = 13.8 MeV)
γ₂₀ = 4sin²(20π/88)  = 1.7154
γ₇/γ₂₀ = 0.14262  vs  1/7 = 0.14286  → 偏差 0.17% ✅
```

**物理意義：** n/p 比唔係 weak 反應 freeze-out 嘅時間演化，而係 K_Chain 模式 n=7 (DM 模式) 同 n=20 嘅本徵值比。

**O13 機制推導（2026-08-20）：** W-field 投影 K = K_chain ⊗ K_tree 中：
- u quark → n=20 (B×F₅=4×5)
- d quark → n=7 (L₄=φ⁴+φ⁻⁴)
- 7+20 = 27 = 3³ = N_gen³ (isospin 雙重態)
- n(udd) = γ₇²×γ₂₀, p(uud) = γ₂₀²×γ₇ → n/p = γ₇/γ₂₀
- **結構比，唔係 freeze-out 亦唔係 freeze-in — 零熱力學假設**

詳見 `o13_np_ratio_mechanism/03_complete_closure.md`
