## 2. R1 — D/H 指數衝突正名

**原文（06 §2.4 + §2.6）**:

```
§2.4: D/H_pred = 2.53×10⁻⁵ × (η_B/6.1×10⁻¹⁰)^(-1.6) = 2.555×10⁻⁵
§2.6: D/H = 2.53×10⁻⁵ × (η_B/6.1×10⁻¹⁰)^(-φ)      = 2.555×10⁻⁵
```

**問題**：同一份文檔內 D/H 冪律用兩個唔同指數（-1.6 同 -φ）。-1.6 係 ΛCDM 核網絡
經驗近似；-φ = -1.618034 係 O13 已推導嘅**結構指數**（K_Chain 譜比）。

**判定**：
- **權威 = -φ**（O13 結構推導, §2.6 正確；§2.4 嘅 -1.6 係過渡近似）
- 數值差：|(-1.6)-(-φ)| = 0.018034 → D/H 相對差 0.018034×ln(η_rel)。
  η_rel = 6.2116e-10/6.1e-10 = 1.0183 → Δln = 0.01813 → 差 0.033% —— 觀測誤差內唔可分辨，
  但**結構上 -φ 唯一**（O13）。
- **修正動作**: 06 append 更正註（本檔 §5）註明「§2.4 -1.6 為過渡, 權威 -φ」;
  本 session scripts/02 已用 -φ 重算。

## 3. R2 — ³He/H 循環引用拆解（重要修正）

### 3.1 拆解

06 §2.6 寫：
```
³He/H = φ⁻² × D/H = φ⁻² × 2.555×10⁻⁵ = 9.759×10⁻⁶
      vs Cooke 2022 9.76×10⁻⁶  → 偏差 0.01% ✅
```

**拆解**: 9.76×10⁻⁶ 喺度當「Cooke 2022 觀測」，但
```
9.76×10⁻⁶ = φ⁻² × 2.555×10⁻⁵   (0.381966 × 2.555e-5 = 9.7592e-6)
```
即「觀測值」本身就係 IDCM 用舊 D/H=2.555e-5 嘅**預測值** —— **循環引用**。

| 量 | 值 | 性質 |
|:--|:--|:--|
| (³He/⁴He) Orion | (1.77±0.13)×10⁻⁴ | 直接量度 |
| (³He/⁴He)_p | (1.043±0.089)×10⁻⁴ | 模型外推 (SM 值 (1.257±0.017)e-4 內 2σ) |
| **(³He/H)_p** | **< (1.09±0.18)×10⁻⁵** | **經驗上限（唔係測量值!）** |

(³He/H) 係所有輕核素中**觀測最差**嘅（PDG 2022: "the poorest observational
determination of all of the light nuclides"）。冇直接 primordial 測量值。
