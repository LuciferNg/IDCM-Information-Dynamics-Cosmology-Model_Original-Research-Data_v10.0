# IDCM BBN 元素豐度問題 — 問題記錄

## 問題陳述

ΛCDM 中，**大爆炸核合成 (Big Bang Nucleosynthesis, BBN)** 係宇宙年齡 ~3 分鐘時嘅事件：
- 質子+中子 freeze-out → 氘 (D)、氦-3 (³He)、氦-4 (⁴He)、鋰-7 (⁷Li) 合成
- 產量只依賴一個參數：**重子-光子比 η_B = n_B/n_γ ≈ 6.1×10⁻¹⁰**
- 成功預測：D/H ≈ 2.5×10⁻⁵、⁴He 質量分數 Y_p ≈ 0.245、⁷Li/H ≈ 1.6×10⁻¹⁰

**IDCM 框架挑戰：**
- 無大爆炸、無膨脹、無「早期宇宙」熱歷史
- z = 結構座標 ℓ = log₄(1+z)，唔係回溯時間
- 宇宙係 44-tone 諧波振盪器，有 SYNC 周期 T=84.64 Gyr
- 物質 = K_Chain beat frequency 經 CY₃(36,98) 投影激化
- 元素豐度係**觀測事件**（恆星光譜、星際介質吸收線直接量度），唔依賴大爆炸假設

**目標：** 用 IDCM 結構框架解釋元素豐度，提出可分辨預測。
