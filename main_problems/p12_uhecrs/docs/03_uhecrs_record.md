## 2. 能量尺度推導 🟢

### 2.1 晶格承載極限（Nyquist）

宇宙晶格能承載嘅最細波長 = 44 步黃金層級：

```
λ_min = L_P × φ^44 = 2.535×10⁻²⁶ m

- L_P = Planck 長度（晶格最細尺度）
- φ^44 = 44 步黃金放大（44 = N_d = K_Chain 站點數）
- 呢個係離散網格嘅固有極限 — 同 z≈17 Nyquist cutoff 同一物理

**公式：**

```
