# Gunn-Peterson 槽的本質：IDCM 結構投影閾值解釋

## 問題：ΛCDM 如何解釋 GP 槽？

ΛCDM 框架中，Gunn-Peterson (GP) 槽喺 z≈6 嘅突然出現被解釋為 **「再電離化事件」**：
- 第一代恆星 (Pop III) 喺 z≈15-20 形成
- 發出 UV 光子游離星系際介質 (IGM) 嘅中性氫
- 到 z≈6 時 IGM 完全游離 → GP 槽消失
- 光學深度 τ_GP(z) 隨紅移平滑演化（再電離泡泡生長→合併）

**問題：** 呢個解釋需要多個自由參數（Pop III IMF、escape fraction、星系形成效率、feedback...），而且觀測顯示 GP 槽嘅出現其實**相當突然**，唔係平滑過渡。

---

## IDCM 解釋：結構投影閾值

IDCM 框架中，GP 槽喺 z≈6 嘅出現係 **K_Chain 結構投影閾值**，唔係時間演化事件。

### 核心機制

K_Chain 有 44 個 mode，每個 mode n 有一個激活紅移：

$$z_n = \frac{\gamma_n}{\gamma_2} \cdot z_c - 1$$

其中：
- $\gamma_n = 4\sin^2(\pi n/88)$ = K_Chain eigenvalue
- $\gamma_2 = 0.020357$ = SYNC mode eigenvalue
- $z_c = 0.6$ = SYNC bump 位置

### 關鍵閾值

| Mode n | γ_n | z_n | ℓ = log₄(1+z) | 意義 |
|:------:|:---:|:---:|:-------------:|:-----|
| 1 | 0.0051 | -0.85 | — | 永遠激活 |
| 2 | 0.0204 | 0.60 | 0.339 | SYNC bump |
| 3 | 0.0457 | 0.35 | 0.215 | 低z |
| 4 | 0.0810 | 1.39 | 0.628 | 中z |
| 5 | 0.1261 | 2.72 | 0.947 | 中高z |
| **6** | **0.1807** | **4.33** | **1.207** | **GP 開始** |
| **7** | **0.2446** | **6.21** | **1.425** | **GP trough** |
| 8 | 0.3179 | 8.34 | 1.574 | 深高z |
| 9 | 0.4004 | 10.80 | 1.704 | 高z |
| 10 | 0.4919 | 13.50 | 1.818 | 高z |

### 物理圖像

**激活前（z > z_n）：** Mode n 未激活，對應嘅 beat frequency 未產生，該頻帶嘅光子唔存在 → 觀測到吸收（中性氫特徵）

**激活後（z < z_n）：** Mode n 已激活，beat frequency 產生足夠光子 → 觀測到發射（游離區域）

**GP 槽嘅結構：**
- 喺 z < 4.33：Mode 1-6 全部激活 → 充分游離 → GP 槽消失
- 喺 4.33 < z < 6.21：Mode 6 激活但 mode 7 未激活 → 部分游離 → GP 吸收開始
- 喺 z > 6.21：Mode 7 仍未激活 → 不足夠嘅 beat frequency → 完全吸收 → GP trough

**呢個解釋嘅關鍵優勢：**
1. **零自由參數** — 所有 z_n 來自 K_Chain 結構
2. **離散跳躍** — 因為係 mode 激活閾值，唔係平滑演化
3. **可預測** — 高z 區域應該有其他 mode 激活閾值對應嘅特徵

## 與 ΛCDM 嘅關鍵區別

| 方面 | ΛCDM | IDCM |
|:----|:-----|:-----|
| GP 槽成因 | 第一代星系游離 IGM | K_Chain mode 激活閾值 |
| z≈6 嘅意義 | 再電離完成時間 | **Mode n=7 激活點** |
| τ_GP(z) 形狀 | 平滑演化（泡泡生長） | **離散跳躍（mode 激活）** |
| 自由參數 | 多個（IMF, f_esc, SFR...） | **0**（全部來自 φ 結構） |
| 高z 預測 | 再電離早期 → 弱吸收 | 更多 mode 閾值 → 離散結構 |

## 觀測驗證

### 已存在證據
- GP 光學深度喺 z≈5.5-6.5 有**急劇轉變**（Becker+2001, Fan+2006）
- 呢個轉變嘅陡峭程度難以用平滑再電離模型解釋

### 可驗證預測
1. 高z 嘅 Lyα 光學深度應該有**多個離散跳躍**，對應其他 mode 激活閾值
2. 跳躍位置：z≈8.34 (mode 8), z≈10.80 (mode 9), z≈13.50 (mode 10)
3. JWST NIRSpec 可以檢測呢啲高z 特徵

---

## 總結

**Gunn-Peterson 槽唔係「再電離事件」，而係 K_Chain 結構投影閾值嘅自然表現。**

Mode n=7 喺 z=6.21 嘅激活閾值直接解釋 GP 槽喺 z≈6 嘅出現，無需任何天體物理假設。呢個解釋嘅核心預測——**離散跳躍 vs 平滑演化**——可以通過 JWST 高z 光譜觀測驗證。
