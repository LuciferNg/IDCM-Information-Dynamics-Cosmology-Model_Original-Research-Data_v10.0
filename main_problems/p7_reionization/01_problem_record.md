# IDCM 再電離問題 — 問題記錄

## 問題陳述

ΛCDM 中，早期宇宙有一段 **再電離化時期 (Epoch of Reionization, EoR)**：
- 第一代恆星/星系 (Pop III) 喺 z≈15-20 形成
- 發出 UV 光子游離星系際介質 (IGM) 嘅中性氫
- 到 z≈6 時 IGM 完全游離
- 觀測證據：Gunn-Peterson trough (z>6 類星體)、CMB 光深 τ≈0.054、Lyα 發射線星系密度下降 (z>7)、21 cm 信號

**IDCM 框架挑戰：**
- 無大爆炸、無膨脹、無「早期宇宙」
- z = 結構座標 ℓ = log₄(1+z)，**唔係回溯時間**
- 宇宙係 44-tone 諧波振盪器，有 SYNC 周期 T=84.64 Gyr
- 物質 = K_Chain beat frequency 經 CY₃(36,98) 投影激化
- z≈17 = Nyquist cutoff (44-site 離散化)

**目標：** 用 IDCM 結構框架解釋同一組觀測數據，並提出可分辨預測。
