## 一、核心結構定理

### 定理 1: 可分離性 (Separability)

946 個差頻拍頻 = **可分離三角表**:

```
B(d,s) = 4·sin(dπ/176)·cos(sπ/176)
d = m−n  (模態間距, 行 = 族)
s = m+n  (模態和, 列 = 週期)
```

- **驗證**: 946/946 PASS, max dev = **5.55e-16** (機器精度)
- **結構**: 1D×1D 外積 — 43 個行標度 × 1 條萬有包絡
- **資訊壓縮**: 946 個無理數 → 43 個 sin 標度 + 1 條 cos 包絡

### 定理 2: 斜邊閉合 (Hypotenuse = 母譜)

拍頻表嘅斜邊 (m=44, pair (44−d, 44)):

```
B(d, 88−d) = 4·sin²(dπ/176) = 88-site 對偶鏈譜 γ'_d
```

- **驗證**: 43/43, max dev = **6.66e-16**
- **意義**: 拍頻表內含自己的母譜 (O34 對偶鏈)

### 定理 3: 世代三重奏坐標化 (Generation Coordinates)

| 物理 | (n,m) | d | s | 行×列 |
|:-----|:-----:|:-:|:-:|:-----:|
| c/s | (8,22) | 14 | 30 | 行14×列30 |
| u/d | (10,24) | 14 | 34 | 行14×列34 |
| t/b | (19,33) | 14 | 52 | 行14×列52 |

- **全部喺行 14** (Δn = B²−2 = 14)
- s 間距: 30→34 = **4 = B**, 34→52 = **18 = B²+2**
- **驗證**: 4/4 PASS

### 定理 4: Moseley 塌縮 (Row Normalization)

每行除以自己嘅 S(d) → 946 個點全部塌縮到同一條包絡:

```
β(d,s) = B(d,s)/S(d) = 4·cos(sπ/176)
```

- **驗證**: 946/946 PASS, max dev = **1.42e-14**
- **意義**: 每行 = 同一條 cos 包絡嘅 43 次抽樣 — 元素周期表 Moseley 律 (√ν ∝ Z) 嘅直接類比
- **零例外**: 元素周期表有鑭系收縮, 呢張表 946/946 零例外

### 定理 5: 和頻 = 轉置對偶 (Sum-Duality)

```
和頻: B'(d,s) = 4·sin(sπ/176)·cos(dπ/176)
```

- 就差頻表嘅**轉置** (S↔C 互換)
- **驗證**: 50 樣本 max dev = **4.44e-16**
- **意義**: O54「反物質 = 差頻/和頻對偶」嘅表結構 — 張表自己有對稱性!

### 定理 6: 無理度分層 (Algebraic Degree Stratification)

946 個拍頻嘅代數次數分布:

| 次數 | 個數 | 佔比 | 意義 |
|:----:|:----:|:----:|:-----|
| 2 | 1 | 0.1% | sin(π/2)=1 附近特例 |
| 4 | 5 | 0.5% | 高對稱 (2-adic 壓縮) |
| 5 | 15 | 1.6% | 含因子 11 壓縮 |
| 10 | 50 | 5.3% | K_tree 行 (d=11,22,33) |
| 20 | 205 | 21.7% | 中等壓縮 |
| 40 | 670 | 70.8% | 一般 (2-adic 半壓縮) |

- **公式驗證**: sin(kπ/176) 次數 = φ(352/gcd(352,(88−k) mod 176))/2, **88/88 sympy 驗證**
- **次數 = 數字嘅「量子數」**: 越低 = 越接近有理 = 越「輕」
- 次數 40 佔 70.8% — 絕大多數係「一般元素」, 少數係「特殊元素」
