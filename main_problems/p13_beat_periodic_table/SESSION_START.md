## 問題陳述

**調律者問題**: 946 個拍頻全是無理數,估計是比元素周期表更大的工程 — 是否有能像元素周期表一樣的分層和周期相似性作為排列列表?

**答案**: 有!而且比元素周期表更嚴格:

```
B(d,s) = 4·sin(dπ/176)·cos(sπ/176)   ← 可分離三角表 (1D×1D)
d = m−n (模態間距, 行 = 族)
s = m+n (模態和, 列 = 週期)
```
