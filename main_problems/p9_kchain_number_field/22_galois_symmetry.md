### 2. 有理骨架係 Galois 不變量 (數域內在結構)

```
Σγ = 90:  σ_a(Σγ) = Σ σ_a(γ_n) = Σ γ_{an mod 88} = 90  ∀a  ✅
pairing:  σ_a(γ_n) + σ_a(γ_{44−n}) = γ_{an} + γ_{44a−an} = 4  ∀a
          (因為 44a ≡ 44 (mod 88) ∀a 奇數)
```

⟹ **90 同 4 唔係 numerological coincidence — 佢哋係 Gal(ℚ(ζ₈₈)⁺/ℚ)-不變量**，由分圓域結構本身強制。

### 5. ω_n 對照: 88 vs 176 數域差異嘅群論根源 ★

```
ω_n = 2cos(π(44−n)/88),  ℚ(ζ₁₇₆)⁺, |Gal| = 40
```
