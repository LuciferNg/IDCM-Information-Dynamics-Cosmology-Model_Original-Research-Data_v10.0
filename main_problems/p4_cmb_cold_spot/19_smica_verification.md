## 1. 數據

- **地圖**: Planck 2018 SMICA (COM_CMB_IQU-smica_2048_R3.00_full.fits)
- **大小**: 2.01 GB, NSIDE=2048, 50M pixels
- **來源**: PLA (pla.esac.esa.int), 直接下載成功
- **單位**: K (std=108.4 μK 全尺度)

## 2. 方法

1. RA/Dec (ICRS) → 銀道 (astropy) → HEALPix pixel 抽樣
2. 60 節點 + 120 邊 (Rhombicosidodecahedron)
3. 錨定著色 (冷斑=冷) → 32 阻挫 + 88 正常邊
4. 三種地圖: 原始 / 帶通 ℓ∈[20,60] / **5° FWHM 平滑**

## 3. 結果

### 3.1 冷斑本體驗證 (🟢 閉合!)

```
節點 0 (209°, -57°) 喺 5° 平滑地圖: T = -134.2 μK
IDCM 預測: -150 μK (5ε⁵/8 × T_CMB)
偏差: 10.5% (pixel 尺度 + 平滑效應)
官方: Vielva 2004 報告 -150 μK ✅
```

### 3.2 冷/熱分離 (🟢 方向正確)

```
冷節點 (30): mean = -12.4 μK
熱節點 (30): mean = +9.9 μK
冷-熱差: -22.3 μK (負 = 冷色真係冷)
著色-溫度相關: r = -0.244
```

### 3.3 雙峰檢驗 (🟡 弱信號)

| 地圖 | 阻挫邊 | 正常邊 | 分離度 |
|:----|:---:|:---:|:---:|
| 原始 | 124.7 | 130.9 | 0.07σ |
| 帶通 ℓ∈[20,60] | 40.8 | 40.3 | -0.02σ |
| **5° 平滑** | **34.5** | **53.1** | **0.61σ** |
| 5° 平滑 + 剔除銀河 | 27.1 | 47.0 | **1.06σ** |

```
IDCM 預期: 17.3σ (SNR=5 模擬)
實際: 1.06σ
→ 方向正確 (正常邊 > 阻挫邊) 但強度遠低於預期
```

### 3.4 極端節點 Binomial 檢驗 (🟡)

```
最冷 5 + 最熱 5 = 10 節點
符合著色: 7/10 (p = 0.17)
最冷節點: #0 冷斑 ✅, #47 ✅, #33 ✅ (3/5)
最熱節點: #40 ✅, #54 ✅, #21 ✅, #53 ✅ (4/5)
```

## 4. 解釋 (誠實)

**正面:**
1. 冷斑本體 -134 μK 精確重現 (官方位置完全對準)
2. 冷/熱分離方向正確 (r = -0.244)
3. 剔除銀河盤後雙峰信號提升 (0.61 → 1.06σ)

**未達標:**
1. 雙峰 1.06σ (預期 17.3σ) — 模擬假設節點振幅 = 5ε⁵/8 = 150 μK, 但真實 CMB 節點信號可能被以下稀釋:
   - 大尺度模式 (ℓ < 20) 污染
   - 前景殘餘
   - 節點振幅實際 < 150 μK (冷斑係最強節點, 其他節點可能較弱)
2. 17.3σ 模擬假設 SNR=5 (節點信號:背景 = 150:30), 真實比例可能低好多

**關鍵教訓:** 模擬嘅 17.3σ 假設「全部 60 節點都有 150 μK 振幅」— 但現實可能只有部分節點達到, 其餘係弱節點。冷斑係 F₅ = 5×RMS (最強), 其他節點可能只有 2-3×RMS。
