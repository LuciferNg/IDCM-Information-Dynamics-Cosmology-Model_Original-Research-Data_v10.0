## 1. 高 ℓ 峰 m=5,6,7 驗證（🟡 誠實記錄）

### 1.1 IDCM 公式外推

```
ℓ₅ = 44×27+11 = 1199

ℓ₇ = 44×32+4  = 1412
```

### 1.2 CAMB raw (unlensed_scalar) 比對

```
CAMB raw 峰 (sigma=8): 220, 537, 814, 1129, 1427, 1739

m=1: IDCM 220   vs CAMB 220  → 0.00% ✅
m=2: IDCM 537   vs CAMB 537  → 0.00% ✅
m=3: IDCM 810   vs CAMB 814  → 0.49% ✅
m=4: IDCM 1014  vs CAMB 1129 → 11.34% ❌
m=5: IDCM 1199  vs CAMB 1129 → 5.84% ❌
m=6: IDCM 1340  vs CAMB 1427 → 6.49% ❌

```

### 1.3 分析

**m=1-3 完美閉合（0.00-0.49%），但 m=4 開始 CAMB 偏離。**

可能原因:
1. CAMB raw 譜喺 damping tail 峰好弱，峰檢測不穩定
2. CAMB 用 ΛCDM 物理（聲波阻尼），高 ℓ 峰位同 IDCM 結構外推有本質差異
3. IDCM 公式 m=4 (1014) 對 CAMB (1129) 11% 偏差 — **呢個係真實張力，唔可以假裝閉合**

**誠實結論：** IDCM 峰公式對 m=1-3 強閉合，但 m=4+ 外推未獲 CAMB 支持。需要 ACT DR4 / SPT-3G 觀測數據最終裁決。
