## 3. ★ 核心診斷：1ℓ 格 λ_loc 方法失效

### 3.1 窗寬依賴表（同一數據, 只改窗寬）

| 窗寬 | 1418-1700 | 1700-2000 | 2000-2400 |
|--:|--:|--:|--:|
| 10ℓ | 264.5 | 262.1 | 105.1 |
| 20ℓ | 330.8 | 449.5 | 227.6 |
| 40ℓ | 351.2 | 503.5 | 556.4 |
| 80ℓ | 288.7 | 609.1 | 768.2 |
| 160ℓ | 263.8 | 455.8 | 690.8 |

```
⟹ λ_loc 隨窗寬系統漂移 2-7× —— 高ℓ尾曲率大，λ_loc = 「窗內平均斜率」，
  唔係「瞬時局部斜率」。窗寬依賴 = 本質，唔係 bug。
⟹ 任何 λ_loc 數值必須連窗寬一齊報；跨 script 比較必須同窗寬。
```

### 3.2 全段單 fit vs binned（PR4 1ℓ 格）

| ℓ 段 | PR4 1ℓ 全段 fit | R10 binned (Planck/SPT/ACT) | 偏離 |
|:--|--:|--:|--:|
| 1418-1700 | 316.7 | 308 | +2.8% ✅ |
| 1700-2000 | 568.8 | 410 | **+39%** |
| 2000-2400 | 875.4 | 420 | **+108%** |

```
⟹ PR4 1ℓ 格譜高段衰減比 binned 譜慢（λ 大 = 衰減慢）2-3 倍
   可能原因: ①高ℓ beam error / foreground residual 抬功率
            ②1ℓ 格 fit 對高ℓ低 SNR 點敏感受權重影響
            ③PR4 vs PR3 高ℓ校準差 > 段內 7.2%
   ⟹ 未診斷（超出 P3 範圍），但確立「1ℓ 格 λ_loc 唔可作分段 λ 量度」
```

### 3.3 ⚠️ R13 T5 修正（自查）

```
R13 T5 曾報「1ℓ 格 λ_loc 前兩段 316.2/413.8 = binned 308/410 一致
⟹ P3 R10 分段 λ 結構第四數據集獨立確認」
⟹ 撤回: 20ℓ 窗巧合。40ℓ 窗即 390；全段 fit 1700-2000 = 568.8 (+39%)。
   1ℓ 格唔能確認分段 λ。分段 λ 結構 (308→646) 仍以 binned 三實驗
   (R10 spread 7.1%) 為唯一穩健基礎。
```

## 4. 判決

```
🔴 logistic 過渡假說 (半週期/lnφ → 全間隙/lnφ): 用 1ℓ λ_loc 測唔到
   —— 唔算否證, 算「方法不可判別」(λ_loc 噪聲 + 窗寬依賴)
🔴 ℓ_t 結構身份: 完全未閉合 (最近候選差 530ℓ)
🔴 上升比 2.508 vs 2.061: 測試無效 (端點值係窗寬 artifact)
✅ 方法結論: 1ℓ 格 λ_loc 只用於「形狀粗判」; 分段 λ 必須用 binned 數據
   (R10 方法) 或段內單 fit on binned points
```
