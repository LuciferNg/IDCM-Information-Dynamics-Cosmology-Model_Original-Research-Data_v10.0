## 2. 驗證結果

### 2.1 Planck 2018 論文 (arXiv:1807.06209)

```
100θ* = 1.0411 ± 0.0003  (聲學尺度, 0.03% 精度)
→ θ* = 0.010411 rad
→ ℓ_A = π/θ* = 301.76
→ IDCM 候選 ℓ_A = 2×CY₃+M = 2×134+33 = 301
→ 偏差 0.25% ✅
```

**ℓ_A 結構公式閉合：** ℓ_A = 2×CY₃+M = 301 vs Planck 301.76 (0.25%)

### 2.2 CAMB 獨立生成（Planck 2018 參數）

用 CAMB 2.0.1 + Planck 2018 最佳擬合參數生成 raw C_ℓ 譜，自動峰檢測：

```
As = 2.099×10⁻⁹ (ln(10¹⁰As)=3.044)
raw_cl=True 峰位置: 220.0, 536.0, 813.0, ...
```

| 峰# | CAMB raw | IDCM 公式 | 偏差 | 狀態 |
|:-:|:-------:|:---------:|:----:|:----:|
| 1 | 220.0 | 220 | 0.000% | 🟢 |
| 2 | 536.0 | 537 | 0.186% | 🟢 |
| 3 | 813.0 | 810 | 0.370% | 🟢 |

**峰 1-3 獨立驗證 0.0-0.4% 吻合！**

⚠️ **坑（已記錄）：** CAMB 預設輸出係 **lensed** 譜 — 峰位置被透鏡平滑推偏 (286/584/843 vs 220/537/810)。必須用 `raw_cl=True` 先係聲學峰嘅真實位置。文獻觀測值 (Planck binned) 亦係 lensed 但 binned 處理唔同。

### 2.3 ACT DR4 論文 (arXiv:2007.07288)

```
- "D220" = 第一峰高度 (ℓ=220) — 確認第一峰位置
```
