  B. 薄片 (10×10×0.5mm) vs 幻想嘅 10mm 立方體
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  差異:
  ┌──────────────────────────────────────────────────────────┐
  │  幻想: 10×10×10mm 立方體                                 │
  │  現實: 10×10×0.5mm 薄片                                 │
  │                                                          │
  │  體積: 1000 mm³ → 50 mm³ (細 20 倍)                     │
  │  → 聲子模式由「體聲子」變「表面聲波 (SAW)」             │
  │  → 厚度方向只有 0.5mm → 厚度剪切模式 ~3.2 GHz           │
  │  → 但呢個係好事! SAW 模式更容易驅動同讀取                │
  │                                                          │
  │  對光學讀取嘅影響:                                       │
  │  薄片 0.5mm → 雷射可以直接穿過!                          │
  │  → 透射式干涉, 唔使反射式                               │
  │  → 訊號更強, 對準更容易                                  │
  └──────────────────────────────────────────────────────────┘

  薄片聲子模式:
    厚度: 0.5 mm
    厚度剪切共振: 0.0 GHz (太高)
    表面聲波 (SAW): 40-200 MHz (用 IDT 叉指電極)
    拍頻: 5-50 kHz (由兩個 SAW 頻率差決定)
