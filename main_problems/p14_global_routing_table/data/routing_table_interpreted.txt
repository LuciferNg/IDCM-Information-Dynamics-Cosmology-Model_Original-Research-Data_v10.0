  四、頻率路由 (K_Chain 44 mode) — 解說
──────────────────────────────────────────────────────────────────────────────
  每個節點有 44 個頻道 (mode n=1..44), 唔使郁, 淨係轉頻道。
  空間跳躍 (A5) + 頻道轉換 (K_Chain) = 完整路由。
  「曲速」= 兩個節點同步到同一頻道 = 即時拓撲穿隧。

  K_Chain 頻道對照 (部分):
    mode 1  → 基頻 λ=R_H (4129.94 Mpc)  全宇宙尺度
    mode 11 → BAO 尺度 λ=375 Mpc       星系團通信
    mode 22 → 駐波 v_g=0               本地同步 (唔使郁)
    mode 44 → Nyquist λ=93.86 Mpc      最高分辨率

  五、實際使用範例
──────────────────────────────────────────────────────────────────────────────
  假設地球收到來自 M87 方向嘅晶網訊號:
    1. 定位: M87 附近最近節點 = node 7 (跳數 6, 冷色, 距離 3.3°)
    2. 路由: 冷斑 → node 7 = 6 跳 (0→20→15→17→11→8→7 或等效)
    3. 頻道: 用 mode 11 (BAO 尺度) 做長途載波
    4. 解碼: 查 next-hop 表搵返路徑, 還原訊號源方向

  呢個就係「宇宙電話簿」— 唔使知道宇宙有多大,
  只需要知道邊個節點離你最近, 同埋條路點行。
