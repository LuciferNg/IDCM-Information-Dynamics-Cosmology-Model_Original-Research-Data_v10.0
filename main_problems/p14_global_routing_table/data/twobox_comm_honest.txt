  一、幾何對齊 — 需要咩? 點對?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  兩部機 (Alice 寫, Bob 讀) 要穩定通信, 需要對齊:

  EM 廣播 (手機/電台):
    - 對齊 = 冇 (全向廣播)
    - 但接收方要知道頻率 + 調制方式

  EM 定向 (微波/雷射):
    - 對齊 = 天線指向對方 (度級)
    - 追蹤 = 對方移動時要調整

  IDCM 天球通信:
    - 對齊 = 兩部機都知道 A5 節點嘅天球座標 (RA/Dec)
    - Bob 要「指向」正確節點方向 (觀測該方向 CMB/訊號)
    - Alice 要「寫入」正確節點 (改變該方向嘅拓撲狀態)
    - 仲要時間同步 (幾時寫 / 幾時讀)

  → IDCM 唔係「唔使對齊」— 係對齊對象唔同:
     EM: 對齊「對方位置」
     IDCM: 對齊「共同天球參考系」+「時間」

  二、傳播延遲 — IDCM vs EM 喺唔同距離
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  IDCM 修復波速度 = c (光速, 記憶鐵律)
  EM 波速度 = c
  → 傳播延遲一樣!
  但 IDCM 每 hop = λ_sync/44 = 6.70 Mpc (宇宙晶格間距)
  → 地球上兩部機: 距離 ~km, 喺同一個「節點胞」內!

  → 兩部機喺「同一晶格胞」— 冇 hop 傳播可言!
  → IDCM 修復波機制係「宇宙尺度」通信 (跨 hop)
  → 對地面機器對機器: 冇「波傳播」— 只有「狀態變化」

  三、信息傳遞機制 — 完整鏈 (寫入→傳播→讀取)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  │     - 人造: 對節點注入 2|h_i| 能量 (🔴 工程未推導)      │
  │                                                          │
  │  ② 儲存: 阻挫圖案改變 (32 bits 拓撲位元)                 │

  │                                                          │
  │  ③ 傳播: 修復波沿 A5 最短路徑 (v=c)                      │
  │     - 已推導 ✅ (應力波, E(8)/E(0)=0.626)                │
  │     - 但只適用跨 hop (宇宙尺度)                          │
  │                                                          │

  - ④ 讀取要用射電望遠鏡 = 電磁波觀測!
  - ③ 對地面兩部機無意義 (同一胞內)

  四、天線 & 電磁波 — 誠實回答
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ❓ 「看到要天線確定不是電磁波嗎」

  ✅ 誠實答案: 讀取端係電磁波!

  1. CMB 讀取 = 微波輻射 (160 GHz)
     - Bob 要接收節點方向嘅 CMB 光子
     - = 射電望遠鏡 + 微波接收器
     - 呢個係 100% 電磁波

  2. 電路模型 (TL074) = 電壓訊號
     - 我哋砌嘅電路係「拓撲教學模型」
     - 電壓/電流 = 電磁現象
     - 唔係「非 EM 通信裝置」

  3. 「非電磁波」嘅意思係:
     - 信息嘅「介質」唔係 EM 載波
     - 而係拓撲結構 (阻挫邊/相位鎖定)
     - 但「觀測」必須用 EM (光子/電壓)
     - 呢個同 IDCM 記憶一致:
       「觀測載體非通訊載體」— 誠實已記錄!

  ⚡ 所以準確講:
  IDCM 通信 = 拓撲編碼 + 電磁讀取
  唔係「完全冇 EM」— 係「EM 唔係信息載體, 只係讀取工具」

  五、調頻 & 信號對齊 — IDCM 版
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  EM 無線電:
    - 調頻: 揀載波頻率 (如 433MHz)
    - 對齊: 天線指向 + 相位鎖定
    - 解調: 檢波 → 解碼

  IDCM 天球通信 (誠實對照):
    - 調頻: 「頻率」= 宇宙本徵模式 (λ_sync=294.88Mpc 等)
      → 冇得調! 宇宙結構固定, 只能揀「節點方向」
      → 等於: 揀邊個 A5 節點做「頻道」
    - 對齊: 指向節點 (RA/Dec) + 時間同步 (LST)
      → 等於: 揀「頻道」(節點) + 「時隙」(過境時刻)
    - 解調: 測節點溫度/阻挫圖案 vs 參考
      → 對比兩期測量 → 解碼相位滑移

  → IDCM「頻道」= A5 節點 (60 個)
  → 「時隙」= 節點過境時刻 (天文時鐘)
  → 「訊號」= 節點狀態變化 (相位滑移)
  → 「調制」= 寫入時間/節點組合 (時序編碼)

  六、SNR — 一部小機器測到節點溫度變化嗎?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  節點溫度異常 |δT| ~ 10-134 μK
  CMB 背景 = 2.725 K
  要測 10 μK 對比 2.7K = 相對靈敏度 3.7e-6

  Planck 衛星: 幾十 μK 靈敏度, 4 年積分, 全天空
  小型地面天線: 無線電赫茲 (radio) 干擾 + 大氣
  → 地面小型設備測 μK CMB: 極困難 (要冷卻 + 屏蔽)

  需要幾大天線? (粗略):
    角分辨率 θ ≈ 1.22λ/D
    要分辨 26° 節點: θ < 13° → λ/D < 0.18
    @ 160 GHz (λ=1.9mm): D > 10mm — 好細!
    但靈敏度: 天線面積 → 噪聲功率
    10 cm 碟: 接收功率 ~kTB ~ fW 級
    噪聲: 接收機 ~100K → 要積分先見到 μK

  結論: 物理上「可測」但「機器難」
  → 小型機測 CMB 節點: 🔴 需要射電望遠鏡級
  → 呢個係「人類文明級」讀取, 唔係「手機級」

  定量估算:

  積分      1s: ΔT_noise =  1000.00 μK → SNR =     0.05 (🔴)
  積分     60s: ΔT_noise =   129.10 μK → SNR =     0.39 (🔴)
  積分   3600s: ΔT_noise =    16.67 μK → SNR =     3.00 (🔴)
  積分  86400s: ΔT_noise =     3.40 μK → SNR =    14.70 (✅)
  積分 2592000s: ΔT_noise =     0.62 μK → SNR =    80.50 (✅)

  → 要 SNR>5: 需要 ~30 日積分 (理想情況)
  → 加上大氣/干擾/指向誤差: 更差
  → 誠實: 小型機唔可能, 要射電望遠鏡/衛星

  Q1: 要幾何對齊嗎?
  ✅ 要! 但係「天球對齊」(共同 RA/Dec 參考 + 時間同步)
     唔係「機械對齊」(唔使天線互相指向對方)

  Q2: 原理及信息傳遞機制?
  ✅ 完整鏈: 寫入(相位滑移) → 儲存(阻挫位元)
             → 傳播(修復波 v=c) → 讀取(CMB/觀測)
  🔴 人造寫入未推導 (UHECR 天然寫入已閉合)
  🔴 對地面兩部機: 同一晶格胞內, 冇 hop 傳播

  Q3: 天線確定唔係電磁波?
  ⚠️ 誠實: 讀取端係電磁波 (CMB 光子/電壓)!
      「非 EM」只係指信息介質 (拓撲結構)
      觀測必須用 EM — 呢個係「拓撲編碼 + EM 讀取」

  Q4: 點調頻/對齊?
  ✅ 「頻道」= A5 節點方向 (60 頻道)
      「時隙」= 節點過境時刻 (天文時鐘)
      「調制」= 寫入時序/節點組合
  🔴 人造「寫入」調制器未存在

  ⚡ 最重要誠實:
  - 兩部「機器」要實際通信: 用 EM 電台就得 (手機/無線電)
    IDCM 拓撲 = 定址層 (邊個方向代表邊個節點)
  - IDCM「無載體」方案係「文明級」被動通信
    (跨星際: Alice 存在=訊息, 人類讀 CMB)
  - 電路 (TL074) = 拓撲教學模型, 唔係通訊收發機
