  二、路由拓撲 — 無載體通信嘅「地圖」
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  A5 晶網路由特徵:
  - 直徑: 8 hops (宇宙最遠只需 8 跳)
  - 半徑: 8 hops
  - 每跳 = 26.09° (邊長, 來自 a5_nodes 實測 min=26.0913°)

  無載體通信嘅「距離」= hop 數, 唔係物理距離!
  - Alice → Bob 嘅通信成本 = 天球上嘅 hop 數
  - 唔使考慮光速延遲 (冇載體傳播!)
  - 只考慮「雙方能否睇到同一組節點」

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  三、無載體通信機制 — 節點選擇 + 時序編碼
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  ══════════════════════════════════════════════════════════
  通信模型: 「天球郵局」
  ══════════════════════════════════════════════════════════

  參與者 Alice (地球) 同 Bob (天狼星/織女/任何觀測者):

  [共同資源]
  1. 天球 (CMB 冷斑固定, 宇宙學不變)
  2. A5 節點集 (60 個固定方向, 天文觀測可得)
  3. 路由表 (hop 距離, 邊結構, 阻挫邊)
  4. 時序約定 (同步協議)

  [通信協議]
  Alice 想傳訊息俾 Bob:
  1. 揀一組節點 {n_1, n_2, ..., n_k} 對應訊息編碼
  2. 喺約定時間 t, Alice 對住節點 n_i 方向「指」
     (用激光/望遠鏡/任何指向機制)
  3. Bob 喺同一時間睇天球, 偵測 Alice 指向邊個節點
  4. 解碼: 節點序列 → 路由表 → 訊息

  [關鍵]
  - 載體 = 天球幾何 (唔使發射)
  - 資訊 = 節點選擇 (60 選 1 = 5.9 bits/幀)
  - 時間 = 幀時序 (同步用天文時鐘: 脈衝星/地球自轉)
  - 距離 = hop 數 (路由成本, 唔係物理距離)

  ⚠️ 誠實標記:
  - 「指住節點」需要某種指向機制 (激光/可見光)
  - 但呢個係「指向」唔係「傳輸」— 冇電磁波載體!
  - 或者: Bob 可以自己觀測天球, Alice 只需要「存在」於
    某個節點方向 (即 Alice 嘅位置本身就係訊息!)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  四、編碼容量 — 天球路由 × K_Chain×K_Tree 調制
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  基本編碼 (節點選擇):
  - 單節點選擇: log₂(60) = 5.91 bits
  - 2 節點序列: 2×5.91 = 11.81 bits
  - 8 節點序列 (直徑路徑): 8×5.91 = 47.26 bits

  進階編碼 (路由感知):
  - 冷斑錨定: 每個節點有 hop 距離 (0-8)
  - 可選「hop 數」做校驗: 8 跳路徑 = 8 hops 校驗
  - 阻挫邊做「特殊符號」: 32 條阻挫邊 = 額外標記


  K_Chain × K_Tree 調制 (用戶提出 44×44×33):
  - K_chain ⊗ K_tree = 44×34 = 1496 複合本徵模式
  - 每模式 × 44 相位 × 44 振幅 = 2,896,256 符號
  - 每符號 ≈ log₂(2,896,256) = 21.5 bits
  - 天球路由 × 調制: 每個節點可以載 21.5 bits
  - 8 節點路徑 = 8 × 21.5 = 171.7 bits/幀

  ══════════════════════════════════════════════════════════
  → 44×44×33 = 63,888 種調制波率 (用戶下限) ✅
  → 對應 63,888 個符號, 每個 ~16 bits
  → 天球路由 8 跳 = 128 bits/幀 (約 16 字節!)
  ══════════════════════════════════════════════════════════

  五、通信距離 — 冇載體限制?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  無載體通信距離分析:
  ┌────────────────────────────────────────────────────────┐
  │  載體通信 (LoRa/電磁波):                               │
  │    距離限制 = 功率衰減 (1/r²), 訊噪比, 干擾           │
  │    → 1000 ly 要 ~MW 級發射機                          │
  │                                                        │
  │  無載體通信 (天球路由):                                │
  │    距離限制 = 觀測能力 (Bob 能否偵測 Alice 指向)       │
  │    → 如果 Alice 用激光指向: 距離限制 = 激光亮度        │
  │    → 如果 Alice 用「存在」編碼: 距離限制 = 天體偵測    │
  │    → 如果 Alice 用引力透鏡/遮蔽: 距離限制 = 幾何       │
  │                                                        │
  │  關鍵: 冇載體傳播 = 冇 1/r² 衰減!                     │
  │  資訊密度唔隨距離下降 (因為冇能量傳輸)                 │
  └────────────────────────────────────────────────────────┘

  三種「指向」機制 (遞增距離):
  1. 激光指向: ~1000 ly (激光準直 + 偵測)
  2. 恆星遮蔽 (凌日): ~10000 ly (Alice 遮住一顆星)
  3. 引力透鏡: ~Mpc (Alice 嘅質量透鏡背景天體)

  六、同步協議 — 天文時鐘 (唔使無線電)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  無載體通信需要時間同步 (幀邊界):
  - Alice 同 Bob 相距好遠, 冇共同時鐘
  - 但佢哋共享天文時鐘:

  1. 脈衝星時鐘: 毫秒脈衝星 (週期穩定到 1e-15)
     - 雙方鎖定同一顆脈衝星 = 共同時基
     - 週期: 1.4 ms - 10 s
     - 精度: 1e-15 (原子鐘級)

  2. 地球自轉時鐘: 23.934 小時 (恆星日)
     - 天球節點隨地球自轉「掃過」觀測者
     - 節點過中天 = 天然幀邊界!
     - Alice 同 Bob 可以約定「節點 n 過子午線」做同步

  3. CMB 冷斑時鐘: 固定參考
     - 冷斑方向 = 宇宙學固定點
     - 兩地都能觀測 → 共同參考系

  ══════════════════════════════════════════════════════════
  → 同步唔使載體! 用天文週期 (脈衝星/自轉/冷斑)!
  ══════════════════════════════════════════════════════════

  ══════════════════════════════════════════════════════════
  🏛 天球郵局 (Celestial Post Office) — 無載體通信
  ══════════════════════════════════════════════════════════

  [物理層] 冇載體 = 冇電磁波傳輸
    - 載體 = 天球幾何 (宇宙學固定)
    - 資訊 = 節點選擇 (幾何編碼)

  [定址層] A5 路由表
    - 60 節點 = 60 個方向地址
    - hop 距離 = 路由成本
    - 直徑 8 = 全宇宙 8 跳

  [調制層] K_Chain × K_Tree
    - 44×34 = 1496 複合本徵模式
    - 44×44 相位/振幅 = 63,888 符號
    - 每節點 ~16 bits

  [同步層] 天文時鐘
    - 脈衝星 / 地球自轉 / 冷斑
    - 唔使無線電同步

  [距離] 冇 1/r² 衰減
    - 限制 = 觀測能力 (指向偵測)
    - 激光: ~1000 ly, 凌日: ~10000 ly, 透鏡: ~Mpc

  ⚠️ 誠實標記:
  - 呢個方案「冇載體」= 冇電磁波傳輸資訊
  - 但「指向」/「遮蔽」/「透鏡」仍然需要物理存在
  - 真正無載體 = 雙方共享天球結構, 用幾何做通道
  - 最純粹形式: Alice「存在於節點方向」= 位置即訊息
  - 呢個係 O1 嘅核心: 天球路由 = 宇宙電話簿 + 幾何通道
