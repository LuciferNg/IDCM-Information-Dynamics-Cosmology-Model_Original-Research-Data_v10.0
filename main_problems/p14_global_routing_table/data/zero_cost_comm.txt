  方案一: 路由表 = 訊息本身 (零成本, 即時)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  原理: 路由表係 deterministic 嘅 — 冷斑位置決定咗一切.

  步驟:
  1. Alice 觀測冷斑 (RA=48.3°, Dec=-20.4°, ΔT=-134.2μK)
  2. Alice 查路由表: 冷斑 = 節點 0, 對跖 = 節點 57, 直徑 = 8
  3. Bob 做同一樣嘢
  4. Alice 同 Bob 各自有完全一樣嘅 2640 節點路由表
  5. 佢哋唔使 send 任何嘢 — 因為路由表已經係共同知識

  成本: $0 (所有數據已公開: Planck 衛星 + 已計算路由表)
  速度: 即時 (無需傳輸)
  容量: 2640 個共振頻道 = 330 bytes 共同知識
  限制: 只能傳遞路由表內嘅資訊, 唔可以傳遞任意訊息

  方案二: 冷斑 + 路由表 = 宇宙時鐘同步 (零成本)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  原理: 冷斑嘅 ΔT = -134.2 μK 係宇宙級嘅時間基準.

  Alice 同 Bob 各自觀測冷斑:
  - Alice 喺 t_A 觀測到冷斑
  - Bob 喺 t_B 觀測到冷斑
  - 如果佢哋知道各自嘅 A5 節點位置, 可以計算光行差
  - 從而同步時鐘, 誤差 = 冷斑角分辨率 / c

  冷斑角尺度: R8 = 4.17° FWHM
  時間同步精度: 4.17° × (π/180) × (R_H/2) / c ≈ 0.1 Gyr
  (宇宙尺度, 唔係實驗室尺度)

  成本: $0
  用途: 宇宙尺度時鐘同步, 唔係日常用

  方案三: W-field 同步模式 = 被動監聽 (零成本)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  原理: 宇宙中任何 W-field 擾動都會沿路由表傳播.

  如果宇宙中某處有事件 (如超新星、星系合併):
  - 事件 = W-field 局部擾動
  - 擾動沿 A5 最短路徑傳播 (最多 8 hops)
  - 觀測者喺節點 i 可以檢測到「來自節點 j 嘅擾動」
  - 路由表 = 擾動源定位嘅查詢表

  步驟:
  1. 檢測到 W-field 異常 (CMB 溫度起伏)
  2. 對比路由表: 異常模式 = 節點 j 嘅 signature
  3. 路由表話你知: 節點 j 到節點 i 嘅 hop 距離
  4. 從而推斷事件源位置

  成本: $0 (用現有 CMB 數據)
  用途: 被動宇宙監聽, 定位宇宙事件

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  原理: 60 個 A5 節點 = 60 個宇宙導航衛星.

  如果 Alice 知道佢喺邊個 A5 節點附近:
  - 佢可以查路由表: 到任何其他節點嘅 hop 距離
  - hop 距離 = 宇宙尺度嘅「導航距離」
  - 唔使 GPS 衛星, 唔使訊號發射

  定位方法:
  1. 觀測冷斑方向 (RA, Dec)
  2. 計算冷斑 BFS 距離: d = hop[0, i]
  3. 如果 d=0: Alice 喺冷斑位置
  4. 如果 d=1: Alice 喺冷斑 4 個鄰居之一
  5. 如果 d=2: Alice 喺 8 個節點之一
  6. ⋯ 直到 d=8: Alice 喺對跖點

  成本: $0 (只需要冷斑方向 + 路由表)
  精度: 每個 hop = 26° 天空角 = 宇宙尺度
