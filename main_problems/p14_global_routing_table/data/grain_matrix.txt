  B. 合成聲子能帶形成條件
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  聲子相干性:
    Q = 100000
    線寬 Δf = 1000.0 Hz
    相干時間 τ = 0.0002 s
    相干長度 L_coherence = 0.9 m (!)

  耦合要求: J_ph > 1/Q = 1.0e-05
    即 exp(-k·gap) > 1.0e-05
    最大容許間距 gap_max = 104.44 μm

    🟢 間距 1.00μm < 最大 104.44μm → 耦合足夠!

  顆粒數量:
    1m³ = 1mm³ 顆粒 × 1000000000 粒
    若每粒 1mm³: 1.0e+09 粒
    排列: ~1000 × 1000 × 1000

  C. 最小可行矩陣（唔需要 1m³）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  最小可行矩陣:
    單元: 3×3×3 = 27 顆 1mm 石英
    體積: 27 mm³ (比 1m³ 細 3.7×10⁷ 倍)
    成本: ~¥1 (27 粒石英粉)
    但量子霍爾讀取需要 2DEG...

  更實際嘅最小方案:
    1cm³ 石英片 (1cm × 1cm × 1mm)
    表面沉積 2DEG (石墨烯或 GaAs 量子井)
    底部貼 PZT 壓電驅動器
    體積: 1 cm³ (比 1m³ 細 10⁶ 倍)
    成本: ~¥10³-10⁴ (石英片 + 石墨烯 + 微加工)
    可以放喺桌上! 唔使超導磁鐵?

  面積縮小嘅代價:
    1m³ → 面積 1m²
    1cm³ → 面積 1cm² = 10⁻⁴ m²
    B_eff 需要增大 10⁴ 倍
    即 |δ-δ_c| 要細 10⁴ 倍: 10⁻⁶ → 10⁻¹⁰
    🟡 可行但調諧難度大增

  🎯 GRT-59 顆粒矩陣可行性分析
  ══════════════════════════════════════════════════════════

  🟢 顆粒矩陣嘅優點:
    1. 成本低 (1/50 整塊晶體)
    2. 可擴展 (逐粒調諧, 逐粒替換)
    3. 表面積大 (壓電驅動效率高)
    4. 可以設計耦合相位 (超材料)
    5. 缺陷容忍度高

  🟡 顆粒矩陣嘅挑戰:
    1. 顆粒間距要 < 聲子相干長度 (~mm)
    2. 1μm 間距需要精密組裝
    3. 每粒嘅晶軸取向要一致
    4. 合成聲子能帶嘅拓撲性質要驗證

  🟢 1cm³ 石英片方案 (Recommend):
    唔係「顆粒矩陣」, 而係「薄片 + 2DEG」
    體積細 10⁶ 倍, 但調諧難度增 10⁴ 倍
    可行, 但需要極高穩定性

  🟢 真正最小可行實驗:
    用現成嘅「表面聲波 (SAW) 器件」!
    石英 SAW 濾波器 (¥10-100) 已經有
    叉指換能器 (IDT) 做壓電驅動
    2DEG 可以係 GaAs 量子井
    → 成個實驗 ~¥10⁵-10⁶
    → 桌面級! 唔使 1m³!
