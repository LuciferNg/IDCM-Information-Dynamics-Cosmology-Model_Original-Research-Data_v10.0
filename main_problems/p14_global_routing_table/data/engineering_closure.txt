  A. 換能器傳遞函數 — V_inj(t) → Δθ_i = π
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  物理模型: 節點 i (Wien bridge 振盪器) 輸出 V_i = A·cos(ωt + θ_i)
  注入: 通過耦合電阻 R_inj 接入外部驅動 V_inj(t) = A_d·cos(ωt + φ_d)

  節點微分方程 (KCL + 運放虛地):
    C·dV_i/dt = (V_inj - V_i)/R_inj + Σ_j (V_j - V_i)/R_c

  用復振幅 (V_i = Re[Ũ_i·e^{jωt}]):
    jωC·Ũ_i = (Ũ_inj - Ũ_i)/R_inj + Σ_j (Ũ_j - Ũ_i)/R_c

  相位動力學 (Kuramoto 形式, 慢變近似):
    θ̇_i = ω + K_inj·sin(φ_d - θ_i) + Σ_j K_c·sin(θ_j - θ_i - α_ij)

  其中:
    K_inj = 1/(2·R_inj·C)  ← 注入耦合強度 (換能器增益!)
    K_c   = 1/(2·R_c·C)    ← 節點間耦合

  → 注入訊號相位 φ_d 相對節點相位 θ_i:
     sin(φ_d - θ_i) > 0 → 節點加速 (θ_i 增加)
     sin(φ_d - θ_i) < 0 → 節點減速

  → 相位滑移 π 條件: 注入訊號與節點反相 (φ_d = θ_i + π)
     持續驅動直至 θ_i 穿越勢壘 (saddle point) 落入新穩定井

  換能器數值 (C = 10nF):
     R_inj |  K_inj (rad/s) |      換能器增益 |      π 滑移所需時間*
  -------- | -------------- | ---------- | --------------
      1000 |        50000.0 |    50000.0 |         62.8 μs
     10000 |         5000.0 |     5000.0 |        628.3 μs
    100000 |          500.0 |      500.0 |       6283.2 μs

  * 理想無阻尼下嘅數量級; 實際要克服勢壘, 時間更長
  → 換能器設計: R_inj = 10kΩ (同耦合電阻一致)
    K_inj = 5000 rad/s → π 滑移 ~0.63 ms (半週期)
    = 注入半週期反相信號 → 完成相位滑移!
  → 實體實現: 運放加法器 (V_inj 加權注入) 或 變容二極體調相

  B. RLC 阻尼映射 — γ = (R/2)·√(C/L) ≥ 2.0
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  物理對應: 節點間耦合網絡嘅能量耗散
  過阻尼條件 (RLC 串聯):
    ζ = (R/2)·√(C/L) ≥ 2.0

  另: Van der Pol 非線性阻尼 μ ↔ AGC 增益
    起振條件: 增益 > 3 (1 + Rf/Ri > 3)
    飽和強度 μ ∝ (增益 - 3) 嘅非線性修正

  目標: f_res = 1.59 kHz, ζ = (R/2)√(C/L) ≥ 2.0
        L |  C (f=1.59k) |    ζ=2.0 需 R |      實際 R 建議 |     實際 ζ
  ------- | ------------ | ------------ | ------------ | --------

     1.0mH |    10000.0nF |       40.0Ω |         40Ω |      2.0
    10.0mH |     1000.0nF |      400.0Ω |        400Ω |      2.0
