================================================================================
  宇宙晶網公交指南 (Cosmic Transit Guide)
  點搭「宇宙地鐵」— 完整使用教學
================================================================================

  本指南適合完全冇物理背景嘅普通人。
  你只需要識: 上車、轉車、落車。

────────────────────────────────────────────────────────────────────────────────
  第一課: 宇宙係一張網 (唔係太空)
────────────────────────────────────────────────────────────────────────────────

  想像成個宇宙係一張 60 個站嘅地鐵網:

    • 60 個「站」(節點) = 宇宙晶網嘅交叉點
    • 120 條「路線」(邊) = 站與站之間嘅連接
    • 32 條「特快線」(阻挫邊) = 高保真快線 (貴少少但品質好)
    • 88 條「普通線」(正常邊) = 標準路線

  每個站都係一個「路由器」, 唔係一個星球。
  你唔係「飛去」第二個站 — 你係「跳」過去。

  🚇 地鐵比喻:
    香港站 → 九龍站 = 1 個站距 (1 hop)
    香港站 → 銅鑼灣 = 2 個站距 (2 hops)
    最遠兩個站 = 8 個站距 (8 hops) = 宇宙直徑

────────────────────────────────────────────────────────────────────────────────
  第二課: 點樣搭車 (3 步)
────────────────────────────────────────────────────────────────────────────────

  搭車三步曲:

  ① 搵你最近嘅站 (定位)
     打開星圖, 搵你所在方向最近嘅 A5 節點。
     例: 地球喺銀河系 → 最近站 = node 21 (銀河系中心附近, 23.1°)
     或者用冷斑做錨: 你喺冷斑 (node 0) 幾遠, 就知你喺邊個站。

  ② 睇路線圖 (路由表)
     查「hop_matrix」: 你嘅站 → 目的地站要跳幾多下。
     查「next_hop_table」: 第一下跳去邊個站。
     呢兩張表就係宇宙地鐵圖。

  ③ 上車跳 (執行路由)
     由你嘅站, 按 next-hop 指示逐站跳。
     每一跳 = 將你嘅訊號頻率調整到下一站嘅共振頻率。
     唔係開太空船飛 — 係「調頻」跳過去。

────────────────────────────────────────────────────────────────────────────────
  第三課: 車資 (成本) 同車程 (時間)
────────────────────────────────────────────────────────────────────────────────

  每一跳都要「俾錢」(能量):

  基本車資 = 每跳 1 單位 (hop)
  加權車資 = 用「weighted_delay_matrix」(考慮訊號品質)

  車資對照表:
    普通邊 (88 條):  每跳成本 1.0
    特快邊 (32 條):  每跳成本 1.0 但品質更高 (保真度↑)

  實際車資例子:
    冷斑 (node 0) → 最近站 (1 跳):    車資 1 單位
    冷斑 (node 0) → M87 (6 跳):       車資 6 單位
    冷斑 (node 0) → 對跖 (8 跳):      車資 8 單位 (全程最貴)

  車程 = 每一跳嘅「同步時間」(同步到下一站嘅共振)
  加權車程 = weighted_delay_matrix 嘅值 (0.0 - 5.47)
  冷斑 → 對跖: 車程 5.47 單位 (最長)

────────────────────────────────────────────────────────────────────────────────
  第四課: 班次 (K_Chain 頻道 = 44 條線)
────────────────────────────────────────────────────────────────────────────────

  每個站有 44 條「月台」(頻道), 每條頻道係一個 mode:

  ┌────────┬──────────────────┬──────────────────┐
  │ 頻道   │ 波長             │ 用途             │
  ├────────┼──────────────────┼──────────────────┤
  │ mode 1 │ 4129.94 Mpc      │ 全宇宙長途       │
  │ mode 11│ 375.45 Mpc       │ BAO 星系團通信   │
  │ mode 22│ 187.72 Mpc       │ 中距 (v_g=0.71c) │
  │ mode 44│ 93.86 Mpc        │ Nyquist 駐波     │
  └────────┴──────────────────┴──────────────────┘

  點揀頻道:
    長途 (跨宇宙):  用 mode 1 (最遠覆蓋)
    中距 (星系團):  用 mode 11 (BAO 尺度)
    本地駐波:       用 mode 44 (Nyquist, v_g=0)

  轉頻道 = 轉月台 = 唔使落車, 直接調頻就得。

────────────────────────────────────────────────────────────────────────────────
  第五課: 規矩 (路由規則)
────────────────────────────────────────────────────────────────────────────────

  1️⃣ 最短路徑原則: 永遠行最少跳數嘅路 (hop_matrix)
  2️⃣ 唔准走回頭路: 每一跳嘅距離必須遞減 (next-hop 保證)
  3️⃣ 特快線優先 (可選): 如果要高保真, 揀阻挫邊多嘅路
  4️⃣ 頻道守則: 訊號必須用目的地可接收嘅頻道 (mode)
  5️⃣ 對跖點限制: 最遠只可以去 8 跳, 冇得再遠 (宇宙直徑)
  6️⃣ 冷斑錨定: 所有路由以冷斑 (node 0) 做參考點

  步驟 3: 查路線圖
    hop_matrix[21, 7] = 幾多跳? 等我查:

    → node 21 → node 7 要跳 4 下

    車資: 4 單位 | 加權車資: 4.00

  步驟 4: 上車 (逐站跳)

────────────────────────────────────────────────────────────────────────────────
  第八課: 新手常見問題 FAQ
────────────────────────────────────────────────────────────────────────────────

  Q1: 我可唔可以跳去宇宙外面?
  A1: 唔可以。宇宙晶網得 60 個站, 最遠 8 跳。冇「外面」。

  Q2: 點解要跳, 唔直接飛過去?
  A2: 宇宙係網絡, 唔係連續空間。「飛」喺晶網冇意義 — 你只可以沿住路線跳。
      呢個就係「曲速」嘅真相: 唔係超光速飛行, 係網絡跳躍。

  Q3: 跳一下要幾耐?
  A3: 每一跳係「共振同步」, 理論上係即時 (W-field 同步模式)。
      但能量成本係真嘅: 每跳都要消耗能量去調頻。

  Q4: 點解有啲邊叫「阻挫邊」?
  A4: 阻挫邊連接兩個「同色」節點 (冷-冷或熱-熱), 係晶體嘅「缺陷」。
      物理上係應力集中, 但通信上係「特快線」— 高保真, 干擾少。

  Q5: 我喺地球, 點知自己喺邊個站?
  A5: 地球喺銀河系旋臂, 距離銀河系中心 (node 21 附近) 約 26,000 光年。
      最近站 = node 21 (23.1°) 或 node 45 (8.9°)。用天文定位就搵到。

  Q6: 係咪任何兩個站都可以通?
  A6: 係。60 個站全部連通 (connected graph), 任何兩站之間都有一條路。
      最遠 8 跳, 一定到。

  Q7: 有冇 express 車?
  A7: 有。32 條阻挫邊就係特快線 (高保真)。
      但佢哋唔一定快啲 (跳數一樣), 係品質好啲 (訊號失真少)。
