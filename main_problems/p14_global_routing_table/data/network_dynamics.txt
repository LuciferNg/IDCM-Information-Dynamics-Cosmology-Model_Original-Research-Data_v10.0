  四、時間尺度分析
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  時間尺度 (dt=0.01, 1 時間單位 = 100 步):
  - 注入持續: 50 步 = 0.5 時間單位
  - 注入期間: 相位偏離隨強度增加
  - 注入後: 網絡重鎖定 (彈返或保持)

  物理時間對應 (Wien 頻率 1.6kHz, T=0.625ms):
  - 1 時間單位 (100 步) ≈ 100·dt·T... 
  - 更合理: 1 步 = 1/100 週期, 1 時間單位 = 1 週期 = 0.625 ms
  - 注入 0.5 時間單位 = 0.31 ms (半週期)
  - 模擬 60 時間單位 = 37.5 ms (60 週期)
  - 持久測試 500 時間單位 = 0.31 s
