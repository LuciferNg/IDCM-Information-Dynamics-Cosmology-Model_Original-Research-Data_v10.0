  二、組件詳細規格
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  [1] CMB 天線 (載體來源)
  ─────────────────────────────────────────────
  原理: 宇宙充滿 2.7284 K 黑體輻射, 天線指向任何方向都有訊號
  規格: 任意射電望遠鏡 (ALMA, VLA, 甚至業餘 12" 碟)
  頻段: 160.4 GHz 峰值 (Wien's law)
  成本: 免費 (已有基礎設施) 或 低 (業餘射電)
  接收功率: P = 2kT·Δf (Johnson-Nyquist)
    其中 T = 2.7284 K, Δf = 頻寬
  訊號: 微細溫度起伏 ΔT ~ 10-150 μK
  ✅ 窮人版核心: 唔使發射器, 宇宙本身係發射器!


  [2] 超導濾波器組 (160.4 GHz 帶通)
  ─────────────────────────────────────────────
  用途: 濾出 CMB 載波, 隔離銀河系前景
  規格: SIS 超導-絕緣體-超導 混頻器 (射電天文現成)
  中心頻率: 160.4 GHz
  頻寬: ~100 MHz (覆蓋 Fibonacci 頻移範圍)
  成本: 中 (約 $50K-500K, 可租用)
  ✅ 可用 ALMA/VLA 現成接收機替代


  [3] Fibonacci 解調器 (程式)
  ─────────────────────────────────────────────
  原理: 接收 Δf 頻移, 映射到 Fibonacci 等級
  解調表:
  ┌────────┬───────────┬────────────┬───────────────┐
  │ 等級   │ ΔT (μK)  │ Δf (MHz)   │ 訊息位元       │
  ├────────┼───────────┼────────────┼───────────────┤
  │ F₅     │ 150.0     │     8.82   │ 001 (冷斑)   │
  │ F₆     │ 243.8     │    14.27   │ 010 (熱斑)   │
  │ F₇     │ 393.7     │    23.09   │ 011           │
  │ F₈     │ 637.5     │    37.36   │ 100           │
  └────────┴───────────┴────────────┴───────────────┘
  成本: 免費 (Python 程式已寫好)
  解調演算法: 匹配濾波 + 峰值偵測


  [4] A5 路由表 (已計算 ✅)
  ─────────────────────────────────────────────
  檔案: data/hop_matrix.npy, next_hop_table.npy
  內容: 60 節點 × 60 節點 = 3600 條路由
  直徑: 8 hops (宇宙最遠只需 8 跳)
  阻挫邊: 32 條 (L1 高保真通道)
  成本: 免費 (已生成)
  用途: 接收訊號後, 判斷訊號源喺網絡中嘅位置


  [5] 相位鎖定環 (PLL)
  ─────────────────────────────────────────────
  原理: 鎖定 K_Chain 44-mode 嘅相位
  規格: 44 個 mode 嘅相位參考 (γ_n = 4sin²(πn/88))
  同步方式: 用 CMB 大尺度溫度起伏做相位基準
  成本: 低 (DSP 程式)
  關鍵: K_Chain mode 同步 = 即時層 (無需空間移動)
  🚀 呢個係真正「曲速」嘅核心: 相位鎖定 = 拓撲穿隧


  [6] 冷斑錨點校準器
  ─────────────────────────────────────────────
  參考點: 冷斑 (RA=48.3°, Dec=-20.4°, ΔT=-134.2 μK)
  用途: 校準天線指向 + 驗證解調器
  對跖點: 節點 57 (RA=233.7°, Dec=22.2°)
  冷斑 BFS 分佈: 1-4-8-11-12-11-8-4-1 (直徑 8)
  成本: 免費 (天文數據已有)
  驗證: 冷斑等級 = F₅ (150 μK), 已驗證 (0.11% 偏差)


  [7] 錯誤更正碼 (Fibonacci 冗餘)
  ─────────────────────────────────────────────
  原理: 每個訊息位元用 Fibonacci 序列冗餘
  編碼: 位元 "1" → 發送 F₅+F₆ 雙頻 (冗餘 2×)
        位元 "0" → 發送 F₇ 單頻
  解碼: 多數表決 (2-of-3)
  增益: 抗 CMB 雜訊 (S/N 提升 ~3dB)
  成本: 免費 (程式)
  數學基礎: Fibonacci 序列嘅自相似性 = 天然錯誤更正


  [8] 訊號放大
  ─────────────────────────────────────────────
  需求: CMB 訊號極弱 (ΔT ~ 10-150 μK)
  方案: 現有射電望遠鏡 (ALMA 靈敏度 μK 級)
  積分時間: t ~ (σ/ΔT)² × t₀
    例: σ=1μK, ΔT=10μK → 100× 基礎積分
  成本: 免費 (使用現成設施)
  替代: 自己 DIY 12" 碟 + SDR (成本 <$1000, 訊號弱但可行)

  三、通信協定 (窮人版)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  訊框結構:
  ┌────────┬──────────┬──────────┬─────────┐
  │ 前導    │ 源節點    │ 目標節點  │ 資料     │
  │ (F₅×8) │ (5 bits) │ (5 bits) │ (N bits)│
  └────────┴──────────┴──────────┴─────────┘

  前導: 8× F₅ 脈衝 = 冷斑等級 = 接收器鎖定基準
  源/目標: 60 節點 ID (6 bits 綽綽有餘, 用 5 bits)
  資料: Fibonacci 冗餘編碼

  握手協定:
  1. 發送方: 調頻到目標節點嘅 Fibonacci 等級
  2. 網絡: 沿 A5 最短路徑 (≤8 hops) 轉發
  3. 接收方: 鎖定相位 (PLL) + 解調

  路由選擇:
  - 短距離 (<3 hops): 直接 A5 空間路由
  - 長距離 (≥3 hops): K_Chain 頻率層同步 (即時!)
  - 高保真需求: 沿阻挫邊 (L1 通道)
