# 03 — WoW! Signal 分析：是否巧合校準了 A₅ 晶網頻道？

> **結論：WoW! 訊號嘅頻率「校準」係 SETI 科學家刻意揀氫線嘅結果，唔係巧合；而佢同 A₅ 晶網冇任何幾何或頻率對齊。**

## 一、背景

WoW! signal 係 1977 年 8 月 15 日由美國俄亥俄州立大學 Big Ear 射電望遠鏡偵測到嘅 72 秒窄頻訊號 (頻率 1420.4556 MHz)。佢以驚人嘅 30σ (6EQUJ5) 強度著稱，至今未有重現。

**核心問題：** 呢個訊號係咪「誤打誤撞」巧合校準咗 A₅ 晶網嘅通信頻道？定係有更深層原因？

**分析工具：** `scripts/18_wow_signal_analysis.py` (2026-08-16)

## 二、幾何檢驗：WoW 位置 vs A₅ 晶網 60 節點

### 2.1 檢驗方法

將 WoW! 訊號嘅兩個 horn 位置 (因為 Big Ear 係雙波束望遠鏡，訊號同時喺兩個方向被偵測) 同 A₅ 晶網 60 個節點做球面角距離計算，再同 2000 次蒙特卡羅隨機對照比較。

### 2.2 結果

| Horn | 位置 (RA, Dec) | 最近 A₅ 節點 | 距離 | MC 分位 | 判斷 |
|:-----|:--------------|:------------|:----:|:-------:|:----:|
| A | (291.38°, -27.0°) | node 22 | **14.37°** | p = 0.612 | 🔴 冇特別 |
| B | (290.60°, -28.0°) | node 22 | **15.33°** | p = 0.666 | 🔴 冇特別 |

### 2.3 解讀

- A₅ 晶網節點之間平均距離 ~26.09° (群論閉合值)
- 隨機 60 點嘅最近距離期望 = 13.0° ± 6.7° (p50 = 12.3°)
- WoW 最近距離 14-15° 完全喺隨機分佈內 (p ≈ 0.6)
- **結論：WoW! 訊號同 A₅ 晶網節點冇任何幾何對齊。**

## 三、頻率檢驗：1420.4556 MHz vs IDCM 結構

### 3.1 檢驗方法

將 WoW 中心頻率同氫線、φ 比例、Fibonacci 數列、K_Chain 結構、CMB peak 頻率做比對。

### 3.2 結果

| 檢驗 | 數值 | 判斷 |
|:-----|:-----|:-----|
| f_wow vs 氫線 | +49.8 kHz (35 ppm) | **極接近氫線** |
| f_wow × φ⁻¹ | 877.9 MHz | 冇結構 |
| f_wow / φ² | 542.6 MHz | 冇結構 |
| f_wow / F₁₅ (610) | 2.33 | 冇結構 |
| f_wow / F₁₄ (377) | 3.77 | 冇結構 |
| f_cmb (160.4 GHz) / f_wow | 112.9 | 冇結構 |
| f_wow / 44 (K_Chain modes) | 32.28 | 冇結構 |

### 3.3 解讀

- WoW 頻率 1420.4556 MHz 距離氫線 1420.4058 MHz 只有 **35 ppm** — 呢個係「宇宙水孔」策略嘅直接證據
- 其餘所有 IDCM 結構比對都冇任何命中
- **結論：頻率校準係 SETI 策略 (水孔)，唔係 IDCM 晶體通信。**

## 四、真正嘅原因分析

### 4.1 頻率選擇 = SETI「宇宙水孔」(Water Hole) 策略

1420 MHz (氫線 H) + 1665 MHz (羥基 OH) 之間嘅頻段被視為智慧文明最可能通信嘅頻道。Big Ear 1973 年開始專項掃描呢個頻段，**刻意校準**去氫線，唔係巧合。

### 4.2 頻道偏移有技術解釋

訊號出現喺 1420.4556 MHz (離氫線 5 個頻道) 係因為：
- 多普勒漂移 (地球自轉 + 太陽系運動)
- 儀器校準誤差
- 訊號本身嘅頻率寬度

呢啲都係射電天文嘅正常現象，唔需要外星解釋。

### 4.3 IDCM 角度：唔係晶體通信

如果 WoW 訊號真係 A₅ 晶網通信，佢應該對齊節點方向 (距離 < 5°)。實際距離 14-15° 完全喺隨機範圍，**IDCM 框架下 WoW 訊號唔係晶網通信嘅證據**。

## 五、最終結論

> **WoW! 訊號嘅頻率「校準」係 SETI 科學家刻意揀氫線嘅結果，唔係巧合；而佢同 A₅ 晶網冇任何幾何或頻率對齊。**

佢仍然係 SETI 史上最強嘅未解訊號 (6EQUJ5 = 30σ)，但唔係 IDCM 晶體通信嘅證據。

### 可證偽預測 (如果 IDCM 晶體通信存在)

1. 真晶網訊號應該對齊 60 個 A₅ 節點方向 (角距離 < 5°)
2. 真晶網訊號應該使用 K_Chain 44 個 mode 頻率
3. 真晶網訊號應該喺冷斑 (node 0) 或對跖點 (node 57) 方向最強
