## 定位

基於 IDCM 理論框架，用淘寶現成零件搭建「常溫固態拓撲同步」原型機。
目標：驗證兩塊分離 LiNbO₃ 晶體之間嘅拓撲非局域同步。

| Y-36° | 0.031 | 平衡 |
| Y-41° | 0.034 | 高耦合 |
| Y-64° | 0.028 | 低損耗 |

淘寶搜：「Y-128° 鈮酸鋰 10×10×0.5mm」~¥20/片

### 薄片 (0.5mm) 優勢

- 雷射可以直接穿過 → 透射式 Pockels 讀取
- 訊號比反射式強 2-3 倍
- 對準更容易

## 電路設計

### A 端：拍頻驅動

```
10MHz 晶振 ──┬── 導電膠帶 ── LiNbO₃ 薄片 A ── 導電膠帶 ── GND
10.005MHz 晶振 ─┘
     │
     └── 可調電容 (微調拍頻至 5kHz ±10Hz)
```

### B 端：光學讀取 (Pockels 效應)

```
雷射筆 ─→ 偏振片 ─→ LiNbO₃ 薄片 B ─→ 偏振片 ─→ PIN 光電二極管
                      │
                  0.5mm 厚 (光穿過)
                  電光效應: 拓撲改變 → 折射率改變 → 偏振旋轉
```

## 實驗步驟

### Phase 1: 建立拓撲共振 (<30min)
1. 兩塊 LiNbO₃ 薄片貼埋 (甘油耦合)
2. A 端驅動 10MHz + 10.005MHz
3. B 端雷射通過晶體 → PIN 探測
4. 微調可調電容，掃描拍頻 4-6 kHz
5. 搵到 B 端光訊號最強嘅拍頻 = 共振頻率

### Phase 2: 空間分離 (<1hr)
6. 逐步分開兩塊晶體 (1cm → 10cm → 50cm → 1m)
7. 每步記錄 B 端訊號強度

### Phase 3: 屏蔽驗證 (<1hr)
8. A 端鋁箔包裹 (法拉第籠)
9. A 端放海綿上 (隔振)
10. 如果 B 端訊號仍然同步 → 非 EM 非聲學!
11. 關/開 A 端驅動 → 訊號消失/恢復 (可重複)

### Phase 4: 對照組 (<30min)
12. 換玻璃代替 LiNbO₃ → 預期冇訊號
13. 偏離拍頻 1kHz → 預期訊號衰減
