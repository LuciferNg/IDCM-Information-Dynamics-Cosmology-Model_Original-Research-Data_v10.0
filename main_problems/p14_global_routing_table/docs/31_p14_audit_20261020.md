## 三、審計發現 — 3 個問題 ✍️

### ⚠️ 1. GRT-33 相位模型內部不一致 (wfield_phase_access.txt)
- GRT-33 用隨機相位 θ~N(0,0.3) 生成 h_i, **冇對 ΔE=0 節點特判 θ=π/2**
- 結果: node 45 (ΔE=0) 顯示 h=+128.97 μK, ΔE_phase=257.94
- 但 GRT-47/48/docs/24: node 45 係 ΔE=0, h≈0, 壁壘 2.83
- **定性**: 兩代模型 (隨機相位 vs 相位正交), GRT-33 嘅「✅ 免費」係純圖論判據 (k=2), 唔係 h≈0
- **影響**: docs/24 閉合理論 (GRT-47 起) 正確; GRT-33 輸出表有誤導性
- **建議**: GRT-33 加 ΔE=0 特判 θ=π/2, 或標明「隨機相位示意」非物理預言

### ⚠️ 2. H0 = 72.59 ≠ IDCM 錨定 67.4071 (scripts 06/10/31)
- scripts 06/10/31 用 H0=72.59 km/s/Mpc
- IDCM 錨定: H₀=67.4071 (O127, c=R·ω_ring)
- 06/10: H0 只定義冇用 (dead code) — 冇影響 ✋
- 31: H0 用嚟計 ρ_crit → μ → 應變能 (2.80e59 J = 1.565e12 M☉)
  - 用 67.4071 會變 ~2.4e59 J (差 ~16%)
- **定性**: script 內部一致 (用 72.59 重算 100% 吻合), 但 H0 選值同 O 系列不一致
- **建議**: 31 改用 IDCM 錨定 H0, 或註明 H0=72.59 為舊值

### ⚠️ 3. 「群論閉合 0.000011°」冇出處 (GRT-29)
- GRT-29: 「每跳 = 26.09° (邊長, 群論閉合 0.000011°)」
- 26.09° 本身正確 (實測 min=26.0913°, 04/15 audit 驗證)
- 但「群論閉合 0.000011°」全庫搜尋無源 (scripts/docs/data 都冇)
- **定性**: hardcode 文字, 冇計算支持
- **建議**: 刪除或補充出處
