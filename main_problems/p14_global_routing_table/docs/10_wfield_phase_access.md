```

冷色節點 (30): δT < 0 → θ ∈ (π/2, 3π/2)
```

## 三、寫入機制 — 相位滑移 π

```
θ_i → θ_i + π
cos(θ_i + π) = -cos(θ_i) → δT_i → -δT_i (溫度反號!)
→ 冷色 ↔ 熱色 (顏色翻轉!)
→ 阻挫邊圖案改變 (訊息寫入!)
```

**相位滑移 π = 拓撲操作 (disclination 移動) = 晶體位錯 analog!**
