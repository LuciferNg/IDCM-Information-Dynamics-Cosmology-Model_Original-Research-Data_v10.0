## 三、W6: 寫入成本 — 彈性成本 = N·(2πm/N)² EXACT

對全環 twist m (θ_i = 2πmi/N):

```
elastic cost C(m) = Σ_i (Δθ_i)² = N·(2πm/N)² = 4π²m²/88   [EXACT, wrap 無關 m≤21]
γ_m = 4sin²(πm/88)   (K_Chain 譜)
C(m)/γ_m = 88·(x/sin x)²,  x = πm/88
  細 m: (x/sin x)² → 1  ⟹  C ≈ N·γ_m = 88·γ_m
  m=21: (x/sin x)² = 1.208 ⟹  C/γ = 106.5 (與實測 106.5 完全吻合!)
```

**結構身份**: 彈性成本 = K_Chain 譜 γ_m × N(環長) × 細 m 修正。
**但** ⚠️ 呢個係「twist 儲存嘅相位梯度彈性能」— 唔等於 O41 嘅 ΔE_write (B(n)·γ·|cosθ|)
兩者語義唔同: O41 = L1 翻轉單節點成本; C(m) = L0 全環 twist 建構成本。連接未做。
