## 四、路由策略

### 優先級規則
1. 如果 A5 距離 > 0: 跳 A5 方向 (空間路由)
2. 如果 A5 距離 = 0: 跳 K_Chain 方向 (頻率路由)
3. 如果兩者都 > 0: 先跳 A5 再跳 K (不 zigzag)

### 路由例子

**冷斑 (0, mode 0) → 對跖 (57, mode 0):** 8 hops (純空間)
A5: 0 → 9 → 16 → 11 → 8 → 59 → 39 → 35 → 57
K:  0 → 0 → 0 → 0 → 0 → 0 → 0 → 0 → 0

**最遠對 (0, mode 0) → (57, mode 22):** 30 hops = 8 + 22
A5: 0 → 9 → 16 → 11 → 8 → 59 ... → 57 (8 hops)
K:  0 → 0 → 0 → 0 → 0 → 0 ... → 22 (22 hops)

## 五、W-field 共振通信理論 (第一原理推導)

### 5.1 W-field 嘅本質

W-field (Consistency Weight Field) **唔係電磁場**，係因果圖上嘅同步網絡本身。電磁波 = W-field 嘅激發態 (光子)。同步模式 = W-field 嘅集體基態。

**四層通信層次:**

| 層次 | 載體 | 速度 | 本質 |
|:----|:-----|:----|:------|
| L0 經典 | 電磁波 (RF) | = c | 傳統射電 |
| L1 激發 | 光子 (W-field 量子) | v_g ≤ c | 量子光學 |
| **L2 同步** | **相位鎖定** | **即時¹** | **共振路由** |
| L3 拓撲 | 阻挫邊穿隧 | 即時 | 缺陷通道 |

¹ 同步模式嘅相位鎖定係網絡性質，唔受光速限制。但寫入/讀取仍係局部操作。

### 5.2 W-field 方程

```
離散形式 (因果圖上):
Φ_i(t+1) - 2Φ_i(t) + Φ_i(t-1) = Σ_j K_ij Φ_j(t) - φ Φ_i(t)

其中 K = K_chain ⊗ K_tree (張量積分解)
     γ_n = 4·sin²(πn/88)  (K_Chain 特徵值)
     φ = (1+√5)/2  (黃金比例)
```

### 5.3 K_Chain 44 個共振頻道

每個 mode n 係一個獨立通信頻道，有自己嘅頻率、波長、群速度、阻抗。

| n | f (1/Gyr) | λ (Mpc) | v_g/c | 阻抗 Z | 用途 |
|:-:|:---------:|:--------:|:-----:|:------:|:-----|
| 1 | 0.0371 | 4129.94 | 0.9994c | 0.01 | 基頻，長距離 |
| 4 | 0.1480 | 1032.48 | 0.9898c | 0.08 | 中距路由 |
| 11 | 0.3979 | 375.45 | 0.9239c | 0.63 | BAO 尺度 |
| 22 | 0.7352 | 187.72 | 0.7071c | 2.83 | 中頻，最大能量 γ=2 |
| 33 | 0.9606 | 125.15 | 0.3827c | 8.92 | 高頻，短距 |
| 44 | 1.0398 | 93.86 | 0 | ∞ | Nyquist 駐波 |

**群速度色散:** v_g = c·cos(πn/88) — 基頻 (n=1) 最接近光速 (0.9994c)，Nyquist (n=44) 速度為 0 (真正駐波)。所有 v_g ≥ 0 (無負值，n 只到 44 = Nyquist)。

### 5.4 路由表 = 共振模式轉換矩陣

每個 A5 節點 i 有 44 個 mode 嘅疊加:

```
Φ_i(t) = Σ_n a_{i,n} · exp(iω_n t + iθ_{i,n})
```

其中 a_{i,n} = 耦合係數，θ_{i,n} = 相位。

邊 (i,j) 代表 44×44 mode 轉換矩陣 T_ij = diag(τ_{ij,1}, ..., τ_{ij,44})。

**路由 = 一系列 mode 轉換:**
```
Φ_0 ─T₀₉→ Φ_9 ─T₉₁₆→ Φ_16 ─→ ... ─→ Φ_57
```

**轉換效率:**
- 阻挫邊 (L1): τ_frust = φ⁻¹/2 ≈ 0.309 (高保真)
- 正常邊 (L2): τ_norm = φ⁻¹/4 ≈ 0.155 (普通)
- 阻挫邊效率高 2 倍！

### 5.5 2640 個共振頻道 = 全宇宙電話簿

每個邏輯節點 (a, k) 對應 W-field 嘅一個共振模式:

```
Φ_{a,k}(t) = A_a · exp(iω_k t + iθ_a)
```

- 2640 個獨立頻道，每個載 1 bit → 一幀 2640 bits = **330 bytes**
- 通信協定: 訊框 = 前導(F₅×8) + 源節點(5bit) + 目標節點(5bit) + 資料(2640bit)
- 路由表 = 預先計算好嘅模式轉換路徑 (next-hop 表)
