# 電子零件模擬原理 — 嚴格推導 (2026-08-17)

## 定位

調律者問: 「研究優化及用電子零件模擬的原理」— 呢份係嚴格推導點解用 TL074 + 電阻 + 電容 + LED 可以模擬幾何阻挫 + U(1) 相位鎖定。

## 一、Wien Bridge 振盪器 → Van der Pol 振盪器

### 1.1 Wien Bridge 電路方程

標準 Wien bridge 振盪器 (TL074 + R1C1 串聯 + R2C2 並聯 + Rf/Ri 增益):

```
傳遞函數: H(jω) = [jωRC / (1 + jωRC)]²  ·  (1 + Rf/Ri)

Barkhausen 條件: |H| ≥ 1, ∠H = 0
→ ω₀ = 1/(RC), 增益 ≥ 3
```

### 1.2 化簡到 Van der Pol

Wien bridge 嘅非線性飽和 (運放輸出擺幅限制) 令振盪幅度穩定。用**慢變包絡近似** (slowly varying envelope), 振盪 x(t) = r(t)·cos(ω₀t + φ(t)) 嘅包絡 r(t) 滿足:

```
ṙ = (μ/2)·r·(1 - r²)        ← Van der Pol 振幅方程!
φ̇ = 0                        ← 相位自由 (等時性振盪器)

其中 μ ∝ (增益 - 3) 嘅非線性修正
```

**推導**: Wien bridge 幅值飽和 → 等效非線性阻尼項 -μ(x²-1)ẋ → Van der Pol 方程:
```
ẍ + μ(x²-1)ẋ + ω₀²x = 0
```

### 1.3 物理對應

| Wien Bridge 電路 | Van der Pol 項 |
|:-----------------|:---------------|
| 運放增益 (1+Rf/Ri) | μ 非線性飽和 |
| R·C 乘積 | ω₀ = 1/RC 振盪頻率 |
| 輸出擺幅限制 | (1-x²) 飽和項 |
| 起振條件 增益>3 | μ>0 (自激振盪) |

## 二、電阻耦合 → 擴散耦合

### 2.1 節點間電阻

兩個振盪器節點 i, j 用電阻 R_c 連接:

```
KCL: i_R = (V_i - V_j)/R_c

節點方程: C·dV_i/dt = Σ_j (V_j - V_i)/R_c
→ dV_i/dt = (1/R_c·C)·Σ_j (V_j - V_i)
```

### 2.2 相位動力學 (Kuramoto 推導)

設 V_i = r·cos(ωt + θ_i), 用緩變近似, 相位 θ_i 滿足:

```
θ̇_i = ω + K·Σ_j sin(θ_j - θ_i - β_ij)
K = 1/(2·R_c·C)  (耦合強度 = 電阻倒數!)
```

**K ∝ 1/R_c** — 電阻越細, 耦合越強!

### 2.3 阻挫邊 (反相器)

阻挫邊用反相放大器 (V_out = -V_in):

```
β_ij = π  (相位差 π)
→ sin(θ_j - θ_i - π) = -sin(θ_j - θ_i)
→ 反相耦合 = 排斥! (反同步傾向)
```

**呢個就係 Ising 反鐵磁嘅 Kuramoto 對應!**

## 三、Ising ↔ Kuramoto 嚴格對應

### 3.1 能量 vs 相位動力學

```
Ising:      H = -Σ J_ij·σ_i·σ_j,  σ_i = ±1
Kuramoto:   θ̇_i = ω + Σ K_ij·sin(θ_j - θ_i - β_ij)

對應: σ_i → e^{iθ_i} (相位取代 Ising 自旋)
      J_ij → K_ij (耦合強度)
      反鐵磁 J<0 → β_ij = π (反相耦合)
```

### 3.2 穩定條件

Ising 基態 = 能量極小
Kuramoto 鎖定態 = 相位差固定

**但係!** (重要發現, GRT-40):
```
Ising 基態: 全局唯一 (32 阻挫邊固定, 拓撲決定)
Kuramoto 鎖定: 由初始條件決定 (多吸引子!)
```

**動力學吸引子 ≠ 能量基態** — 電路自然鎖定嘅阻挫圖案唔一定係 Ising 基態! (實測 12/32 vs 理論 32/32)

### 3.3 需要雙穩態先等價

要令電路「記住」拓撲基態, 需要:
```
方案 A: 硬 π 耦合 (相位鎖定環 PLL)
  每個阻挫邊用 PLL 鎖定 π 相位差 → 強制反相
  實測: K≥0.8 時寫入 3-5/32 邊成功

方案 B: Schmitt trigger 雙穩態節點
  每節點兩個穩定相位 (0, π)
  阻挫邊 = 反相器強制交替
  → 呢個先真正對應 Ising
```

## 四、LED 相位指示 → 電壓壓制

### 4.1 反並聯 LED

兩顆 LED 反並聯跨接節點輸出:

```
V_AC = |V_i - V_ref|  (交流幅值)

同相節點 (θ_i ≈ θ_ref): V_AC 大 → LED 亮
正交節點 (θ_i ≈ π/2):  V_AC ≈ 0 → LED 熄滅
```

### 4.2 ΔE=0 節點壓制

Van der Pol 網絡實測: ΔE=0 節點 (k=2 阻挫) 振幅細 11-50%:

```
原因: 節點連接 2 條阻挫邊 (反相) + 2 條正常邊 (同相)
     反相耦合 (排斥) + 同相耦合 (吸引) 互相抵銷
     → 淨驅動力細 → 振幅壓制
     → 對應 CMB: ΔE=0 節點溫度 ≈ 0 μK (SMICA 已驗證!)
```

**三重閉合: 電路壓制 ↔ 理論 ΔE=0 ↔ SMICA 溫度≈0**

## 五、參數優化結果 (GRT-39)

### 5.1 最佳工作點

| 參數 | 最佳值 | 電路對應 | 壓制比 |
|:-----|:------:|:---------|:------:|
| 耦合 K | **0.08** | R_c ≈ 12.5kΩ | **0.507** |
| 非線性 μ | 5.0 | AGC 中等飽和 | 0.534 |
| 失諧 σω | 0 Hz | 1% 電阻 OK | 0.628 |

### 5.2 物理規律

```
K 太細 (<0.05): 冇鎖定 (各自振盪, 壓制消失)
K 最佳 (0.08):  阻挫壓制最強 (ΔE=0 係其他嘅一半)
K 太大 (>0.15): 全鎖死 (振幅平均化, 壓制消失)

→ 中間存在「阻挫壓制窗」!
→ 呢個窗就係電路可觀測嘅「幾何阻挫」特徵
```

### 5.3 寫入條件 (GRT-40)

```
Van der Pol 加性耦合: 寫唔入 (0/32) — 鎖定態太穩定
複數振盪器 + 硬 π:    K≥0.8 寫入 3-5/32

→ 寫入需要: 強耦合 (K≥0.8, R≤2.5kΩ) + 相位脈衝
→ 或者: PLL/雙穩態節點 (主動相位控制)
```

## 七、誠實結論

1. **純被動電路 (TL074 + 電阻 + 電容 + LED)**:
   - ✅ 可以演示: 相位鎖定 + 阻挫壓制 (ΔE=0 LED 熄滅)
   - ✅ 成本 ~$15, 三用電表可測
   - ❌ 唔可以寫入 (鎖定態太穩定)

2. **寫入需要升級**:
   - 🔴 主動相位控制 (PLL) 或雙穩態節點
   - 或強耦合 (K≥0.8) + 相位脈衝 (GRT-40 實測 3-5/32)
   - 呢個對應 IDCM: 寫入需要能量注入 (2|h_i|) — 一致!

3. **電路係「教學模型」唔係「宇宙通信」**:
   - 演示拓撲阻挫嘅宏觀實現
   - 但唔代表宇宙真係電路
