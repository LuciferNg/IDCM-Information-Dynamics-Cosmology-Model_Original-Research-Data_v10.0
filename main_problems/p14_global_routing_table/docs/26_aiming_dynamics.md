# A-B-C: 可區分性 + 網絡動力學 + 精確瞄準 (2026-08-17)

## 定位

調律者: 「A B C 順序，還要推導網絡動力學，怎樣精確及瞄準」
A = 可區分性 (唔同注入 → 唔同圖案?)
B = 網絡動力學 (能量傳播/翻轉波/非線性響應)
C = 精確瞄準 (點樣控制最終態?)

## A: 可區分性 (GRT-50)

**9/12 唯一圖案** — 唔同注入節點 → 唔同阻挫圖案!

```
注入節點: 10, 12, 19, 22, 23, 25, 28, 32, 37, 40, 45, 46
唯一圖案: 9 個 (碰撞組: 22=28=32=37 全部一樣)
兩兩距離: min 0 / mean 3.2 / max 6 bit
最大碼集: 9 節點 (Hamming ≥ 2)
容量: 3.2 bits/幀
```

**碰撞原因: 22/28/32/37 = A5 對稱性等價節點** (同一軌道, 局部環境相同)
→ 呢 4 個節點物理上無法區分 (注入效果一樣)
→ 其餘 9 個節點 = 可用碼集

## B: 網絡動力學 (GRT-51) — 關鍵發現!

**欠阻尼 (γ=0.1) 系統持續振盪, 唔會鎖定!**

```
γ=0.1: 翻轉 34 節點, 動能 20941 (混沌!)
γ=0.5: 翻轉 8, 動能 8917 (仍振盪)
γ=1.0: 翻轉 4, 動能 19.5 (接近穩定)
γ=2.0: 翻轉 6, 動能 0.000 (🟢🟢 完全靜止!)
γ=5.0: 翻轉 6, 動能 0.000 (🟢🟢 完全靜止!)
```

**γ≥2 = 過阻尼 → 系統衰減到穩定態 (6 節點保持翻轉)**

物理: 真實有損耗網絡 (電路電阻/宇宙耗散) 自然係過阻尼
→ 之前 GRT-49 嘅「振盪」係欠阻尼假象!
→ 真實系統: 注入 → 衰減 → 鎖定到能量極小

時間尺度:
- 注入 0.5 時間單位 (半週期)
- 重鎖定 ~60 時間單位
- 持久: 500+ 時間單位 (非易失)

色散: 首翻轉 1.5-3.5 時間單位到達 1-8 hops
→ 波前速度 ~2-4 hops/時間單位 (快!)

## C: 精確瞄準 (GRT-52) — 自組織吸引子!

**過阻尼下, 4 種瞄準策略嘅結果:**

| 策略 | 結果 |
|:-----|:-----|
| 脈衝整形 (強度×持續) | 🟢 能量包 75-1000 → 翻轉 6-7, 圖案 1 bit 改變 |
| 時序 (先後 vs 同時) | 🔴 0 bit 差異 (過阻尼洗走時序) |
| 相位 (同相 vs 反相) | 🔴 0 bit 差異 (過阻尼淹沒相位) |
| 瞄準 (目標 vs 鄰居) | 🟡 全部一樣 (網絡自組織) |

**關鍵發現: 過阻尼 sine-Gordon = 自組織吸引子系統**
- 最終圖案由**全局能量極小**決定, 唔係注入細節!
- 時序/相位/瞄準精度全被吸引子「洗走」
- 但呢個係**穩健性**: 寫入唔需要精確瞄準!

## 誠實標記

1. **9/12 可區分** (3 個對稱性碰撞) — 實際容量 3.2 bits/幀
2. **過阻尼先鎖定** — 欠阻尼係混沌, 真實系統假設有耗散
3. **時序/相位失效** — 過阻尼嘅代價: 失去 2 個調制維度
4. **能量域調制** — 新概念: 訊息喺能量唔喺時序
5. **γ=2 係臨界** — 要更精細掃描過渡區
