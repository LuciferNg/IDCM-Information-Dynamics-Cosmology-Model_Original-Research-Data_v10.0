## 二、機制解析

### 建立: 需要集體相位斜坡 (T4)
```
θ_i = 2πi/22, i = 0..21   →  每步差 π/11 = 0.286 rad
winding = 1.000  固定點, cos(k) = cos(π/11) > 0 穩定區
```
- 22 連續節點 = N/4 覆蓋 (唔係半環 — 稱呼修正); 相位喺 22 節點內捲入 0→2π
- 呢個係**集體操作** (22 節點協同), 唔係單節點局部翻轉
- 一般 m: 斜坡覆蓋需要連續節點數目 ≥ ⌈2πm/(每步可容忍差)⌉ (未閉合最小定律)

### 擦除: 單節點滑移 π 就夠 (T1)
- twist m=1 中, 節點 0 相位 = 0; 滑移 π → θ_0 = π
- 令 θ_1−θ_0 ≈ 0.071−π → wrap 到 −π+0.071 (跨 ±π 壁壘)
- **winding 係 wrap 計數: 一條邊跨壁壘 = 成個 winding 冇咗**
- 500 單位後仍係 0: 破壞係永久性 (新 fixed point 0)

### 單節點滑移喺同步態冇用 (T2)
- θ_0=π 瞬間 winding=−1 (π 差 → wrap −π)
- 但 cos(k=π) = −1 < 0: **反相係唔穩定 twist**, 鬆弛令佢衰減返 m=0
- ⟹ 反相 sector (m=22..43 對應) 唔止唔穩定, 連瞬態都維持唔到

## 三、L1 vs L0 寫入對稱性 (重要結構對比)

| | L1 阻挫位元 (O220/41) | L0 winding (本推進) |
|:--|:--|:--|
| **寫入** | 局部翻轉節點 (ΔE=(123/88)·192·\|cosθ_i\|) | **集體斜坡** (22 節點 = N/4 覆蓋 0→2π) |
| 寫入成本 | B(n)·γ·\|cosθ_i\| (每節點) | 建立全域梯度的總操作 (未定量) |
| **擦除** | 🔴 貴 (Landauer 7.04e3×, 一次性介質) | 🟢 **平** (單節點滑移 π) |
| 擦除/寫入比 | 7.04e3 (寫入豁免 Landauer) | <<1 (擦除比寫入容易) |
| 保護 | 🔴 亞熱障無保護 (28×) | 🟢 噪聲不變量 (W4) |

**對稱性反轉**: L1 寫入容易、擦除貴、保護差 vs L0 寫入難 (集體)、擦除平、保護好。
