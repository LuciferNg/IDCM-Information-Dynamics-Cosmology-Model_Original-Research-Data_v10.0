
## 三、接駁線路 (39 步逐 pin)

### 電源
```
兩顆 9V 電池串聯: 電池1(+)→電池2(-) [中點=GND]
電池1(-)=-9V | 電池2(+)=+9V
U1 pin4=-9V pin8=+9V | U2 pin4=-9V pin8=+9V
去耦: 每 IC pin8→100nF→GND, pin4→100nF→GND
```

### IC 分配
```
TL074 #1 (U1): U1A=節點0 U1B=節點1 U1C=節點2 U1D=節點3
TL074 #2 (U2): U2A=節點4 U2B=反相器(阻挫邊) U2C/D=備用
```

### 節點模組 (每節點, 以節點0=U1A 為例)
```
pin1(out) → R1(10k) → C1(10nF) → pin3(+)  [Wien 串聯臂]
pin3 → R2(10k) → GND | pin3 → C2(10nF) → GND  [Wien 並聯臂]
pin2(-) → Ri(10k) → GND | pin2 → Rf(33k) → pin1  [負回授]
```

### 耦合邊 (正常 4 條, 電阻 12k)
```
26. Vout0 → 12k → 節點1-
27. Vout1 → 12k → 節點2-
28. Vout2 → 12k → 節點3-
29. Vout3 → 12k → 節點4-
```

### 阻挫邊 (反相器 U2B)
```
30. Vout4 → R_in(10k) → U2B pin6(-)
31. U2B pin6 → R_fb(10k) → U2B pin7(out)
32. U2B pin5(+) → GND
33. U2B pin7 → 12k → 節點0-
```

### LED + 注入
```
34-38. Vout_i → 1k → 紅LED∥綠LED(反並聯) → GND
39. DDS out → 1k → 節點0- (或 R_inj=10k 直接)
```
