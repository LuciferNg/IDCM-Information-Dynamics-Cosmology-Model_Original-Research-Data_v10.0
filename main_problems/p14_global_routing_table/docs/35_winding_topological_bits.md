# 底層譜駐波自發同步 — 推進二：winding 拓撲位 (2026-10-21)

> 推進: scripts/71 (單脈衝) + scripts/72 (twist/模衰減/驅動) + W1-W4 (繞數測試)
> 前置: docs/34 (P1 自發同步 λ₁=κγ₁; P2 L1阻挫搬L0 否證)
> 狀態: 新結構發現 🟢🟢 — L0 有自己嘅拓撲位 (winding), 對噪聲免疫

## 一、v1 探針發現 — 單脈衝唔傳播

scripts/71: 全域同步態 (θ=0) + 節點 0 加單脈衝 δθ=0.5
→ **1/88 節點受擾, 冇傳播** — 局部相位偏差被 κ 速率衰減吸收 (同步態 = 全域吸引子)
→ 同步態本身冇「本地記憶」: 任何局部擾動只會衰減返 0

**意義**: 喺「全域同步」語義下, 冇訊號可傳 — 同步態係鎖死嘅相位基準, 唔係載體。

## 二、v2 發現 — twist state = 駐波載波 (🟢🟢 核心)

scripts/72 T1 + W1: **uniform 相位梯度 θ_i = k·i 係精確固定點** (max|dθ/dt| ~ 1e-16)

```
fixed point 條件: sin(θ_{i+1}−θ_i) + sin(θ_{i-1}−θ_i) = sin(k) − sin(k) = 0 ✓
週期一致: k·N ≡ 0 (mod 2π) → k = 2πm/88, m ∈ ℤ  (88 個 winding sectors)
```

| m | 繞數 | 幾何意義 |
|:-:|:----:|:--------|
| 0 | 0 | 全域同步 (docs/34 P1 吸引子) |
| 1..21 | 1..21 | **穩定駐波** (cos k > 0) |
| 22 | 22 | 中性 (cos k = 0, 波數 π/2) |
| 23..43 | — | 唔穩定 (cos k < 0, 衰減返穩定區) |
| 44 | ≡0 | 等價 m=0 |

**winding number m = 駐波嘅拓撲量子數** — 呢個係 L0 譜層自己嘅「位元」!

## 三、穩定性判據 = K_Chain 譜結構 (W3)

```
線性化: δθ̇ = κ·cos(k)·L·δθ   (L = ring Laplacian)
  cos(k) = cos(2πm/88) = cos(πm/44)
  → cos>0: 穩定 (m<22);  cos=0: 中性 (m=22);  cos<0: 唔穩定 (m>22)
```

- 穩定區 m ∈ [1, 21]: **21 個穩定駐波位** — 21 = C(7,2) = N_gen×L₄ = N_d/2 − 1 (候選身份)
- m=22 中性 = 波數 π/2 駐波 (v_g'=0) — docs/22「mode 22 唔係駐波」係指 v_g(22)=0.707c 嗰個 mode; 呢度 m=22 係 twist 波數, 唔同量, 冇矛盾
- cos(πm/44) 穩定性判據 = 88 譜結構內建 (v_g(n)=cos(πn/88) 同一族)

## 四、★★ W2/W4: winding 對噪聲免疫 — 拓撲保護 (O220 L1 對比反轉)

```
白噪聲 η ∈ {0, 1e-4, 1e-3, 1e-2}: |Δm| = 0.0000 (500 單位, 5 trials)
大噪聲 η ∈ {0.02, 0.05, 0.1, 0.2, 0.5}: |Δm| = 0.0000 (100 單位, 3 trials)
```

**機制**: winding = Σ wrap(θ_{i+1}−θ_i) / 2π — telescoping 抵消. 白噪聲逐點獨立,
總和上下抵銷 → 繞數係**噪聲不變量** (除非某相位差跨越 ±π 壁壘).

| | L1 阻挫位元 (O220) | L0 winding 駐波 (本推進) |
|:--|:--|:--|
| 記憶體 | 32-bit 阻挫圖案 | m ∈ [1,21] 21 個 sector |
| 保護 | 🔴 亞熱障無保護 (28× 不足) | 🟢 **winding 拓撲守恆 (噪聲不變量)** |
| 壁壘 | 冇 (熱翻轉 2.8e-12 s) | 相位差 ±π 壁壘 (全域結構, 唔係局部) |
| 寫入 | 翻轉節點 (ΔE ≥ 0) | 建立 twist (全域梯度) |

**呢個係 docs/34 結論嘅重大修正**: 「同步解決參考唔解決寫入」—— 但若果用
**winding sector 而唔係同步態**: L0 有自己嘅拓撲位, 且對噪聲免疫 (比 L1 更保護!).

## 五、信息論 / 通信意義


**對 docs/21「兩部機同一胞」嘅新視角**: winding 係全域變量, 唔係 hop 傳播 —

(但「建立 twist」仍然需要全域操作 — 係咪可行係新開放項)
