## 一、⚠️ docs/37 修正 — C(m) 唔係能量, O41 γ 唔係譜量

**修正 1**: docs/37 §六 #1 講「兩個都係 γ 譜量」— **錯**。
O41 嘅 γ = 192 係 **μK↔IDCM 單位換算因子** (γ = 4N_d + B² = 176+16 = 192 μK/單位),
唔係 K_Chain 譜 γ_n = 4sin²(πn/88)。兩個 γ 撞名, 語義完全不同。

**修正 2**: C(m) = Σ(Δθ)² 係「彈性梯度 L2 範數」, **本身唔係能量**。
真 twist 能量 = Kuramoto 勢能差 (QU1 驗證):

```
V(m) = −K Σ cos(θ_{i+1}−θ_i) = −88K·cos(2πm/88)   (全環 uniform twist)
ΔV(m) = 88K(1 − cos(2πm/88))
細 m 近似: 1−cos x ≈ x²/2 → ΔV ≈ (K/2)·C(m)     ← C(m) 只係 x² 近似!
```

| m | ΔV (IDCM) | (K/2)·C | 比率 |
|:-:|:---:|:---:|:---:|
| 1 | 0.0140 | 0.0140 | 0.9996 |
| 5 | 0.3468 | 0.3505 | 0.9894 |
| 11 | 1.6109 | 1.6963 | 0.9496 |
| 21 | 5.1076 | 6.1825 | 0.8261 |

⟹ ΔV = (κ/2)·C(m) 只有細 m 成立 (x²/2 近似); 大 m 偏離 (1−cos ≠ x²/2)。
**正確公式: ΔV(m) = 88κ(1−cos(2πm/88)) EXACT。**

## 四、#4 偶模群速度判據 — 補充物理意義

```
穩定 m < 22 ⟺ v_g(2m) = cos(2πm/88) > 0
m = 22:  v_g(44) = cos(π/2) = 0  →  中性 (駐波: 冇群速度 = 冇傳播 = 不增不減)

m > 22:  v_g < 0  →  向後波 → 唔穩定 (docs/35 W3 已證衰減)
```

**補充**: m=22 twist 即係「駐波 twist」本身 (v_g=0) — 中性唔係偶然,
係「冇傳播 = 冇失穩機制」。呢個同 docs/22「mode 22 唔係駐波」並無矛盾
(嗰個講 v_g(22)=cos(π/4)=0.707 嘅運算模式; 呢個係 twist 波數 k=π/2 嘅幾何)。
