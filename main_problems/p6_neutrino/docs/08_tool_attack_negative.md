## 1. 🧰 工具 #1：hop 層 bound-state 定位器（scripts/06）

**目的**：檢證「t = Δ/2 係能隙內 bound state 位置嘅自然產物」定係 post-hoc fit。

**模型**：Feshbach 缺陷散射——chain {γₙ}，缺陷喺位置 x₀（權重 ψₙ(x₀)² = sin²(nπx₀/88)）；
bound state E* 滿足 det[1 − t·G₀(x₀,E*)] = 0，即 t(x₀,E*) = 1/G₀(x₀,E*)。
對目標 γ₁、γ₂ 分別計 t₁(x₀)、t₂(x₀)，掃描 x₀ ∈ [1,88]。

**結果（誠實否定）**：
```
同時命中 Δ/2 (±5%): 0 個位置
G₀(x₀,γ₁) = G₀(x₀,γ₂) 交叉點: 0
γ₁ 最近 t 值: ±0.0137 (dev 160.7%)  ← 負 hop 都冇近 Δ/2
γ₂ 最近 t 值: ±0.0087 (dev 138.5%)
```

**判決**：**hop 階梯機制唔係「單缺陷散射」路**。由 O179 權重（hop 階梯 [1,4,8,11,12,11,8,4,1]）形成嘅係「週期勢 Bloch 態」而唔係局部缺陷極點——tight-binding N-環本身（N=8/10 週期）先係正確框架。t=Δ/2 唔會由任意位置缺陷湧現；如要閉合，必須由 hop 通道週期（2B/2F₅）詞彙推 hop 強度。

## 2. 🧰 工具 #2：譜積↔log10 身份搜尋器（scripts/07）

**目的**：檢證「1/γ₆−1/76 或 1/76 係唔係譜積（Chebyshev/det 商/對數）自然產物」。

**方法**：事前定義 24 個 operator 子譜（1..44 / 45..88 / 奇偶 / mod3 / mod4 / 11-block / Lucas / Fib / mode6&mirror / 4,5,6 / 全譜）× {lnP, lnP/2, 2lnP, log10P, −log10P, 1/lnP, lnP/ln88, lnP/ln88²} ＋ 全雙子譜 ln 商。目標：5.5197738（=1/γ₆−1/76）同 0.0131579（=1/76）。

**結果（誠實否定）**：
```
單子譜命中 (dev<1%): 1  — Fib mod -log10P = 5.4701 (dev 0.90%)
   → Fib mod 子譜有 8 個 mode (1,2,3,5,8,13,21,34,55), 密度命中, 非 operator
雙子譜 ln 商命中 (dev<0.5%): 1  — ln(56..66 / 1..44) = 5.5412 (dev 0.39%)
   → 56..66 係隨機 11-block, 唔係 operator 身份, 密度命中
Chebyshev: Π 2sin(nπ/88) = 88 ✓, Πγₙ = 88² = 7744 ✓ (理論)
half-ln 身份: ½ln(Π/Π_rem) = ln(1/γ₆) = 1.71072 (=1.71092, 譜積一致)
```

**判決**：**1/76 唔係譜積自然產物**（Chebyshev Π 全譜 = 88²，移除 mode-6 對 → ln(1/γ₆)，冇 76 出現）；**1/γ₆−1/76 冇任何 operator 子譜身份**。→ 1/76 修正係 log10 尺度嘅「加法修正」，唔係 ln/det 自然湧現。剩餘 #2 嘅「log10↔譜」映射仍然冇工具級證據。
