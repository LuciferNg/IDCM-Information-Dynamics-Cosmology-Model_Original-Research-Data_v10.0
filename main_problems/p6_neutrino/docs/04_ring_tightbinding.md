## 1. 🟢 統一發現：γ_eff = γ_B + Δ·cos(2π/N)，N ∈ {8, 10}

之前 docs/02 命名「正多邊形半中心角」；本次升級為 **N-環 tight-binding 第一 Bloch 激發**：

```
N-節點環 (cycle graph) tight-binding: H = t·Σ(|i⟩⟨i+1|+h.c.)
  本徵譜: E_m = 2t·cos(2πm/N),  m=0..N−1
  第一激發 (m=1): E₁ = 2t·cos(2π/N)

m₁: γ₁ = γ₄ + Δ·cos(π/4) = γ₄ + Δ·cos(2π/8)   → N=8
m₂: γ₂ = γ₄ + Δ·cos(π/5) = γ₄ + Δ·cos(2π/10)  → N=10
hop: t = Δ/2 (半能隙 hop 強度)
```

**角身份**：cos(2π/8) = cos(45°) = 正八邊形中心角 = 1/√2 EXACT；cos(2π/10) = cos(36°) = 正十邊形中心角 = φ/2 EXACT。同 cos(π/4)、cos(π/5) 完全一致（π/4 = 2π/8，π/5 = 2π/10）。

## 2. 🟢 N 嘅結構身份（點解 8 同 10）

```
88-site = 2·N_d = 8×11 = (2B)×L₅   → N=8 = 2B = 2×K_Tree 分支 (O68, B=4)

## 4. 🔮 預言：m=2 第二激發（可測但未見結構對應）

```
