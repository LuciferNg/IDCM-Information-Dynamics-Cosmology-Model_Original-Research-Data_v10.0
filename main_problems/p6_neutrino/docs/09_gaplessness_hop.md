## 1. 🟢 核心推導：t = Δ/2 = 無間隙（gaplessness）條件

```
IDCM 連續性原則（零新常數）:
  任何 interference hop 帶，唔可以同 K_Chain 連續譜之間留 gap
  （gap = 額外維度量/新常數，違背結構原則）

hop 帶: N-環 tight-binding，bandwidth 4t，帶頂 (m=0, cos=1):
  E_top = γ₄ + 2t

無間隙 ⟹ 帶頂接上 chain 譜頂 γ₅:
  γ₄ + 2t = γ₅  ⟹  t = (γ₅−γ₄)/2 = Δ/2   EXACT, 唯一
```

**驗證**：γ₄+2T₀ = 0.1261005500 = γ₅ ✓（scripts/08 §1）
- t 掃描 0.5–1.5×T₀：只有 t=T₀ 令 gap=0，其他全部留帶隙Δ/2、Δ/4、…（scripts/08 §2）
- 帶底 2γ₄−γ₅ = 0.03593 > 0：正譜保證（唔越零）✓
