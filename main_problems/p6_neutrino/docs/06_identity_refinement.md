## 1. 🟢 Δ 嘅 9 = n₄+n₅（mode 下标和），唔係 N_gen²

之前 O49 docs 標「4sin(9π/88)sin(π/88) (9 = N_gen²)」。用三角恒等式精修：

```
sin²A − sin²B = sin(A+B)sin(A−B)
γ₅−γ₄ = 4sin²(5θ) − 4sin²(4θ),  θ=π/88
      = 4·sin((5+4)θ)·sin((5−4)θ)
      = 4·sin(9θ)·sin(θ)

→ sin(9θ) 嘅 9 由 A+B = 5+4 必然產生 — 係 mode 下标和
→ N_gen² = 9 只係數值同一/同構, 唔係來源
```

**結論**：Δ 嘅 9 正確 operator 身份 = **n₄+n₅**（能隙兩端 mode 之和）。N_gen² 標籤修正為「數值同一（9 = 3²），結構來源 = 4+5」。呢個唔改變數值，但改變身份歸屬——後續引用用「9 = n₄+n₅」，唔好用「N_gen² 導致 9」。
