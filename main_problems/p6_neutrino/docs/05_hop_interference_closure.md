## 1. 🟢 核心發現：m₁/m₂ 角 = O179 hop 干涉核

O179（已閉合，73/73 PASS）位置權重：

```
W(i) ∝ (frust+1) · [1 + (B/L₅)·cos(π·hop/4)]
hop 階梯: [1,4,8,11,12,11,8,4,1]; <hop> = 4 = B
cos 週期: hop/4 → 2π 週期 = hop 週期 8 = 2B
```

**hoр=1 干涉核：cos(2π·1/8) = cos(π/4)** —— 正正係 m₁ 角！

| 中微子 | 角 | O179 身份 |
|:---|:---|:---|
| m₁ | cos(π/4) = cos(2π/8) | 2B-hop 週期（= hop 階梯週期 8），hoр=1 干涉核 |
| m₂ | cos(π/5) = cos(2π/10) | 2F₅-hop 週期（A₅ decagon），hoр=1 干涉核 |
| hop=4（B） | cos(2π·4/8) = cos(π) = −1 | 干涉相消圈（O179 重心定理，LRD 錨點 hop=4） |

**統一**：束縛態角 = `cos(2π·hop/N)`，N ∈ {2B, 2F₅}，**hop = 1**。
之前 docs/04 嘅「N-環 tight-binding 第一激發」而家有實質出處：**N = O179 hop 週期**（8 = 2B 鏈週期，10 = 2F₅ A₅ 週期），hop=1 即第一干涉模。
